C1F4: Sprite: Lollipop
The Lollipop sprite, which is a single frame that is 12 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 53 (see SpritesTable).
Sprite_Lollipop C1F4 DEFB $12 Height = 12 pixels.
