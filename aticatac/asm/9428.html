9428: Handle Bookcase
The handler for the bookcase, which is a secret door that only the wizard can use. This is the same as HandlerBarrel but for the sprite IDs 11 to 20.
Input
IX The door entity
HandlerBookcase 9428 LD A,($EA90) Fetch the sprite ID of the player from Player.
942B SUB $11 Subtract 11 to make the wizard's sprite IDs start at zero.
942D JR HandlerSecretDoor_Check Jump to HandlerSecretDoor_Check to check for the secret door.
