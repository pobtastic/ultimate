8134: Throw Axe
Used by the routine at HandlerKnight.
Launches an axe for the knight, unless a weapon is already in flight or the player is in a doorway. The axe sprites have the IDs 40 to 47 and are animated by HandlerAxe.
Input
IX The player entity
ThrowAxe 8134 LD A,($EA98) Return if a weapon is already in flight.
8137 AND A
8138 RET NZ
8139 LD A,($5E2D) Return if the player is in a doorway.
813C AND A
813D RET NZ
813E CALL SoundsAxeThrow Call SoundsAxeThrow to make the axe throwing sound.
8141 CALL SetWeaponVelocity Call SetWeaponVelocity to set the velocity of the weapon.
8144 LD HL,$EA98 Point HL at the player weapon at PlayerWeapon.
8147 LD (HL),$40 Write 40 to the weapon, the sprite ID of the first axe frame.
8149 JR LaunchWeapon Jump to LaunchWeapon to launch the axe.
