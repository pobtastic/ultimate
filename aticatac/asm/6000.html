6000: Security Check
Used by the routine at GameEntry.
A short check on the second byte of FRAMES. The game only continues into GameInitialisation when it holds the expected value; otherwise the "RET" takes its return address from the game variables at GameOptions.
SecurityCheck 6000 DI Disable interrupts.
6001 LD SP,$5E00 Set the stack pointer to 5E00.
6004 LD A,($5C79) Fetch the second byte of FRAMES.
6007 CP $25 Return if the second byte of FRAMES is not 25 which is the value that the game expects.
6009 RET NZ
600A JP GameInitialisation Jump to GameInitialisation to initialise the game.
