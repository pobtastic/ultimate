9710: Messaging: Game Complete
The messages that GameComplete prints. Each one starts with the attribute to colour it with and ends with a character that has bit 7 set.
GameCompleteMessages 9710 DEFM $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "CONGRATULATIONS".
9711 DEFM "CONGRATULATION","S"+$80
GameCompleteMessage_Escaped 9720 DEFM $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "YOU HAVE ESCAPED".
9721 DEFM "YOU HAVE ESCAPE","D"+$80
