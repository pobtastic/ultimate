7C19: Game Initialisation
Used by the routine at SecurityCheck.
Clears the first 10 bytes of the game variables, selects the main font and then runs the game selection menu. The menu is drawn by GameMenu and the keyboard is scanned for the keys "1" to "6" and "0" until "0" is pressed. Each key changes the control method or the character stored in GameOptions and moves the highlight on the menu, and "0" starts the game at StartGame. The entry point at Game_Restart is also used to return to the menu when a game ends.
Clear the first 10 bytes of the game variables.
GameInitialisation 7C19 LD HL,$5E00 Point HL at the game options at GameOptions.
7C1C LD B,$10 B=10 (the number of bytes to clear).
GameInitialisation_Loop 7C1E LD (HL),$00 Clear a byte of the game variables.
7C20 INC HL Move HL on to the next byte of the game variables.
7C21 DJNZ GameInitialisation_Loop Decrease the byte counter by one and loop back to GameInitialisation_Loop until all 10 bytes have been cleared.
7C23 LD HL,$BE4C Write BE4C (the main font, see MainFont) to FontPointer.
