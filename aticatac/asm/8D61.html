8D61: Reset Game State
Used by the routine at StartGame.
Restores the entities and the other game data that start at Player to their initial state, ready for a new game. The initial state is kept in the copy of the data that starts at Initialisation_Player.
ResetGameState 8D61 LD HL,$600D Point HL at the player initialisation data at Initialisation_Player.
8D64 LD DE,$EA90 Point DE at the player at Player.
8D67 LD BC,$1570 BC=1570 (the number of bytes of game data).
8D6A LDIR Copy the initial game data over the live game data.
8D6C RET Return.
