9FFB: Store Entity
Used by the routines at HandlerAxe, HandlerFireball, HandlerSword, HandlerBatlet, HandlerPumpkin, HandlerSparkle, HandlerGhostlet, HandlerSpikey, HandlerBlob, HandlerPop, HandlerGhoul, HandlerMummy, HandlerDracula, HandlerFrankenstein, HandlerDevil, HandlerWitch, HandlerMonk, HandlerHunchback, HandlerFoodItem, ControlPlayer, HandlerPickupItem and HandlerMushroom.
Saves the position and sprite ID of an entity so that RemoveEntity and SetEntityAttributes_Moved can use them after the entity has moved.
Input
IX The entity
StoreEntity 9FFB LD A,(IX+$03) Write the entity X position to Previous_X_Position.
9FFE LD ($5E16),A
A001 LD A,(IX+$04) Write the entity Y position to Previous_Y_Position.
A004 LD ($5E17),A
A007 LD A,(IX+$00) Write the entity sprite ID to Previous_Sprite_Id.
A00A LD ($5E15),A
A00D RET Return.
