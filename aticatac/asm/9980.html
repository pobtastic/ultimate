9980: Set Graphic Attributes
Used by the routine at HandlerRoomItem.
Sets the attributes of the cells that a graphic covers. This is the same as DrawGraphic but with the handlers in SetGraphicAttributesHandlers, which are the routines from SetAttributes_Upright onwards.
Input
B The attribute
C The graphic ID
D The Y position
E The X position
SetGraphicAttributes 9980 LD HL,$9985 Point HL at the set graphic attributes handlers at SetGraphicAttributesHandlers.
9983 JR DrawGraphic_Dispatch Jump to DrawGraphic_Dispatch to draw the graphic.
