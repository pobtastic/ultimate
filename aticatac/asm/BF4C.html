BF4C: Main Font
The graphics for the characters 20 to 5A of the main font, which include the digits and the capital letters. The graphic for a character is eight bytes, one for each row. PrintScreen finds the graphic from the character code and the font pointer in FontPointer, so the pointer for this font is BE4C which is 0100 bytes before the first graphic. The digits can be printed from their numbers by pointing the font pointer at MainFont_Zero, the graphic for "0" (see Score_1UP).
