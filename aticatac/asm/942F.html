942F: Handle Clock
The handler for the clock, which is a secret door that only the knight can use. This is the same as HandlerBarrel but for the sprite IDs 01 to 10.
Input
IX The door entity
HandlerClock 942F LD A,($EA90) Fetch the sprite ID of the player from Player.
9432 DEC A Subtract one, to make the knight's sprite IDs start at zero.
This entry point is used by the routines at HandlerBarrel and HandlerBookcase.
HandlerSecretDoor_Check 9433 CP $10 Jump to HandlerSecretDoor_Closed if the player is not the right character.
9435 JR NC,HandlerSecretDoor_Closed
9437 CALL OpenDoorway Call OpenDoorway to open the doorway.
943A JP HandlerDoorExit Jump to HandlerDoorExit to handle the exit of the door.
HandlerSecretDoor_Closed 943D CALL CloseDoorway Call CloseDoorway to close the doorway.
9440 JP HandlerRoomItem Jump to HandlerRoomItem to handle a room item that does nothing.
