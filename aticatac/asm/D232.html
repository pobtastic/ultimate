D232: Sprite: Mushroom
The Mushroom sprite, which is a single frame that is 10 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is A1 (see SpritesTable).
Sprite_Mushroom D232 DEFB $10 Height = 10 pixels.
