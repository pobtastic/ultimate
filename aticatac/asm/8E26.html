8E26: Handle Knight
The handler for the knight (sprite IDs 01 to 10) when it is the character being played. It is the same as HandlerSerf, except that the slowing is 03 on each frame and the fire button throws an axe (see ThrowAxe). The second part of this routine is used by the other characters as well: it makes creatures (see SpawnCreature), takes energy from the player every sixteen frames, and displays the character.
Input
IX The knight entity

8E2F CALL ControlPlayer Call ControlPlayer to move the knight.
8E32 LD E,(IX+$06) Fetch the X velocity.
8E35 LD D,(IX+$07) Fetch the Y velocity.

8E3A JR Z,HandlerKnight_Fire

8E3F AND %00000011 Keep only bits 0-1.
8E41 JR NZ,HandlerKnight_Fire Jump to HandlerKnight_Fire unless this is every fourth frame.
Move on to the next frame of the animation, for the left set of sprites.

Work out which axis the knight is moving fastest on, by comparing the sizes of the velocities.
8E4C LD A,D Fetch the Y velocity.
8E4D AND A Jump to HandlerKnight_CompareAxes if the Y velocity is positive.
8E4E JP P,HandlerKnight_CompareAxes
8E51 NEG Make it positive.
HandlerKnight_CompareAxes 8E53 LD C,A Keep the Y speed in C.
8E54 LD A,E Fetch the X velocity.
8E55 AND A Jump to HandlerKnight_Compare if the X velocity is positive.
8E56 JP P,HandlerKnight_Compare
8E59 NEG Make it positive.
HandlerKnight_Compare 8E5B CP C Jump to HandlerKnight_Horizontal if the knight is moving more across than up or down.
8E5C JR NC,HandlerKnight_Horizontal

8E5F AND A Test the sign of the Y velocity.

8E66 ADD A,$04 Add 04.
