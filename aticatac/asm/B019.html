B019: Sprite: Apple
The Apple sprite, which is a single frame that is 10 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 56 (see SpritesTable).
Sprite_Apple B019 DEFB $10 Height = 10 pixels.
