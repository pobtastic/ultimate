A48B: Sound Effect Eating
The handler of the sound entity for the sound set up by SoundsEating. The count in the second byte of the entity is decreased on each pass of the main loop. When it goes below zero the entity is cleared. Until then it plays a tone of 08 cycles, and the count picks the half period from the table at TableTonesEating.
Input
IX The sound entity
SoundEffectEating A48B DEC (IX+$01) Decrease the count of notes, and jump to ClearSound if it is below zero.
A48E JP M,ClearSound
A491 LD C,(IX+$01) Fetch the count.
A494 LD B,$00 B=00.
A496 LD HL,$A4A0 Point HL at the eating tones at TableTonesEating.
A499 ADD HL,BC Add the count to the address of the table.
A49A LD B,(HL) Fetch the half period from the table.
A49B LD C,$08 C=08 (the number of cycles).
A49D JP SoundsBeep Jump to SoundsBeep to play the tone.
