AF2E: Sprite: Key
The Key sprite, which is a single frame that is 0A pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 81 (see SpritesTable).
Sprite_Key AF2E DEFB $0A Height = 0A pixels.
