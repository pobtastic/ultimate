80CB: Reset Player Data
Used by the routine at StartGame.
Clears the game variables by filling memory from SpriteWidth up to 5FFF with 00. This leaves the game options and font pointer alone.
ResetPlayerData 80CB LD HL,$5E10 Point HL at the sprite width at SpriteWidth.
80CE LD B,$60 B=60 (i.e. finish once we reach 6000).
80D0 JR ResetScreen_Fill Jump to ResetScreen_Fill to fill the memory with the value to write.
