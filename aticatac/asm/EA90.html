EA90: Player
Entities are 8-byte records, held in the table that starts here.
Offset Description
00 Sprite ID (also the index of the handler in HandlerTable)
01 Room ID
02 Used by the handler of the entity
03 X position (pixels)
04 Y position (pixels)
05 Attribute
06 Used by the handler of the entity
07 Used by the handler of the entity
The player is the first entity. Every entity from here up to RoomItemEntities is a copy of the data from Initialisation_Player onwards, which ResetGameState copies when a game starts, and this one is set up from PlayerTemplate for each life by PreparePlayer.
Player EA90 DEFB $00 Sprite ID (the frame that the player is drawn with).
PlayerRoom EA91 DEFB $00 Room ID (the room that the player is in).
EA92 DEFB $00 Used by the handler of the entity.
EA93 DEFB $00 X position.
EA94 DEFB $00 Y position.
EA95 DEFB $00 Attribute.
EA96 DEFB $00 Number of rows drawn so far while the player is appearing (see HandlerPlayerAppearing).
EA97 DEFB $00 Sprite ID of the character (see PreparePlayer).
