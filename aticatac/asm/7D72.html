7D72: Messaging: Game Selection Title Text
The first byte is the attribute used for the whole title, followed by the text, which ends with a character that has bit 7 set. It is printed by GameMenu.
GameSelection_Title 7D72 DEFM $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "ATICATAC GAME SELECTION".
7D73 DEFM "ATICATAC GAME SELECTIO","N"+$80
