80C2: Reset Attribute Buffer
Used by the routine at ClearScreen.
Points at the attribute buffer and jumps into ResetCopier to fill it with 00.

80C5 LD B,$5B B=5B (i.e. finish once we reach the end of the attribute buffer).
80C7 LD C,$00 Set the value to write in C to 00.
