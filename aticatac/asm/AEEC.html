AEEC: Sprite: Blank
The Blank sprite, which is a single frame that is 10 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 31 (see SpritesTable).
Sprite_Blank AEEC DEFB $10 Height = 10 pixels.
