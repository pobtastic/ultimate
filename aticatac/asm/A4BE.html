A4BE: Sprite Table
The address of the data for each sprite, starting with sprite ID 01 (so the entry for an ID is at offset ID - 01 times 02). The ID is the first byte of an entity record, and is also its handler index (see HandlerTable). FetchSprite reads the table, and each sprite starts with its height (see Sprite_Knight_Down_1).
