9260: Set Door Sprites
Used by the routines at HandlerDoorClosed and HandlerDoorLocked.
Writes a sprite ID to both halves of a door.
Input
A The sprite ID
IX The door entity
SetDoorSprites 9260 PUSH IX Copy IX into HL, as the address of this half of the door.
9262 POP HL
9263 LD (HL),A Update the sprite ID of this half of the door.
9264 EX AF,AF' Hold the sprite ID in AF'.
9265 LD A,L Fetch the low byte of the address of this half.
9266 XOR %00001000 Flip bit 3, to get the address of the other half of the door.
9268 LD L,A Keep the address of the other half of the door in L.
9269 EX AF,AF' Fetch the sprite ID from AF'.
926A LD (HL),A Update the sprite ID of the other half of the door.
926B RET Return.
