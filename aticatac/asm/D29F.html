D29F: Sprite: Spanner
The Spanner sprite, which is a single frame that is 10 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 8B (see SpritesTable).
Sprite_Spanner D29F DEFB $10 Height = 10 pixels.
