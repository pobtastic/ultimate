C124: Sprite: Can
The Can sprite, which is a single frame that is 14 pixels high. Each frame is its height, followed by two bytes for each row, so the sprite is 10 pixels wide. The sprite ID is 50 (see SpritesTable).
Sprite_Can C124 DEFB $14 Height = 14 pixels.
