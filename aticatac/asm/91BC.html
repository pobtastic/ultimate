91BC: Handle Trap Closed
The handler for a trapdoor that is closed (sprite ID 18). It is opened by HandlerTrap_Toggle when the counter in CounterLow is zero.
Input
IX The trapdoor entity
HandlerTrapClosed 91BC LD A,($5E12) Fetch the counter from CounterLow.
91BF AND A Test whether the counter is zero.
91C0 JP NZ,HandlerRoomItem Jump to HandlerRoomItem if it is not.
91C3 JR HandlerTrap_Toggle Jump to HandlerTrap_Toggle to toggle the trapdoor between open and closed.
