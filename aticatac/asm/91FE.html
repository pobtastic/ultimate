91FE: Handle Room Item
Used by the routines at HandlerDoorClosed, HandlerTrapClosed, HandlerTrapOpen, HandlerDoorExit, HandlerDoorLocked, HandlerCaveDoorLocked, HandlerClock, HandlerDoorACGExit and FallThroughTrapdoor.
The handler for the items in a room that do nothing. The attributes of the cells that it covers are set by SetGraphicAttributes every time, but the graphic is only drawn (by DrawItemGraphic) when GameFlags is zero.
Input
IX The item entity
HandlerRoomItem 91FE LD E,(IX+$03) Fetch the X position of the item.
9201 LD D,(IX+$04) Fetch the Y position of the item.
9204 DEC D Move up one pixel.
9205 LD C,(IX+$00) Fetch the graphic of the item.
9208 LD B,(IX+$05) Fetch the attribute of the item.
920B CALL SetGraphicAttributes Call SetGraphicAttributes to set the attributes.
920E LD A,($5E14) Fetch the game flags from GameFlags.
9211 AND A Test whether any of the game flags are set.
9212 RET NZ Return if they are.
Continue on to DrawItemGraphic.
