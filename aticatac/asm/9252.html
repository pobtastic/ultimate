9252: Handle Cave Door Locked
The handler for the locked cave doors (sprite IDs 0C to 0F). This is the same as HandlerDoorLocked, but the doors become sprite ID 01.
Input
IX The door entity
HandlerCaveDoorLocked 9252 CALL CheckDoorKey Call CheckDoorKey to see whether the player has the key.
9255 JP NC,HandlerRoomItem Jump to HandlerRoomItem if not.
9258 LD A,$01 A=01 (the sprite ID of an unlocked cave door).
925A JR HandlerDoorLocked_Unlock Jump to HandlerDoorLocked_Unlock to unlock the door.
