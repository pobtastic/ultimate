7EE6: Handler Table
The address of the handler for each kind of 8-byte entity record, indexed by the first byte of the record (the sprite ID, see SpritesTable). ProcessAction reads the entry and calls the handler. The same handler is shared by all of the sprites of one kind of entity, so the knight sprites all point to HandlerKnight, and so on. Entries that no entity uses point to CreateDelay, which does nothing.
