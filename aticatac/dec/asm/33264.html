33264: Handle Fireball
The handler for a fireball, which has the sprite IDs 52 to 55. Advances the animation frame and flickers the colour.
Input
IX The weapon entity
HandlerFireball 33264 CALL StoreEntity Call StoreEntity to save the position of the weapon.
33267 LD A,(IX+0) Fetch the sprite ID of the fireball and add one, to move on to the next frame.
33270 INC A
33271 AND %00000011 Keep only bits 0-1 (there are 4 animation frames).
33273 ADD A,52 Add 52 to point to the correct frame/ sprite ID (the fireball base sprite ID is: 52).
33275 LD (IX+0),A Write the new frame/ sprite ID back to the entity.
33278 LD A,(23672) Fetch FRAMES.
33281 RLA Rotate A left, which moves bit 0 into bit 1.
33282 AND %00000010 Keep only bit 1.
33284 ADD A,69 Add 69 to get an attribute of INK:CYAN, PAPER:BLACK (BRIGHT) or INK:WHITE, PAPER:BLACK (BRIGHT).
33286 LD (IX+5),A Set the attribute of the fireball.
Continue on to HandlerWeapon.
