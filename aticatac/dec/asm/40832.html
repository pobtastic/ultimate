40832: Prepare Draw 2/ 3 Byte Sprite
Used by the routines at RemoveEntity and DisplayEntity.
Gets everything ready to draw (or erase) the sprite at the position which was last recorded by StoreEntity. Sprites are drawn using the exclusive OR operation, so drawing a sprite for a second time erases it.
The number of rows to draw is written to Old_Sprite_Row_Count, and the shifting routine at DrawOldSpriteRow_Aligned is set up to move the sprite along by the position MOD 8 pixels.
Output
C 0
DE The address of the first row of sprite data to draw
HL The screen address of the bottom row of the sprite
