32195: Run Main Loop
Used by the routines at DrawRoom and EnterRoom.
Runs the game one entity at a time. Whenever FRAMES has changed since the last time, UpdateFixedEntities runs the handlers of the three fixed entities starting at Player. Each entity from ItemEntities onwards that is in the same room as the player is then given to ProcessAction, and every 16-byte record from CreatureRecords onwards after that. Finally the room items are processed by DrawRoom. If the room has not been drawn yet (bit 0 of GameFlags is clear) the entities are skipped and DrawRoom is run immediately.

32207 LD A,(24084) Jump to MainLoop_Entities if the entities in the room have already been drawn (bit 0 of GameFlags is set).
32210 BIT 0,A
32212 JR NZ,MainLoop_Entities
32214 LD IX,61152 Point IX at the end of the entity table, so that no entities are processed at RoomItemEntities.
32218 JR DrawRoom Jump to DrawRoom to draw the room.
Each pass of this loop considers one of the 8-byte entities.

32224 LD A,(24067) Fetch the FRAMES value from the previous pass.

32237 LD HL,32243 Point HL at the address for the handler to return to at MainLoop_NextEntity.
32240 JP Z,ProcessAction Process the entity with ProcessAction if it is in the same room as the player.
Move on to the next 8-byte entity.
MainLoop_NextEntity 32243 LD DE,8 DE=0008 (the size of an entity).

32248 PUSH IX Copy IX to HL (using the stack).
32250 POP HL
