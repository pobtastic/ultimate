24576: Security Check
Used by the routine at GameEntry.
A short check on the second byte of FRAMES. The game only continues into GameInitialisation when it holds the expected value; otherwise the "RET" takes its return address from the game variables at GameOptions.
SecurityCheck 24576 DI Disable interrupts.
24577 LD SP,24064 Set the stack pointer to 24064.
24580 LD A,(23673) Fetch the second byte of FRAMES.
24583 CP 37 Return if the second byte of FRAMES is not 37 which is the value that the game expects.
24585 RET NZ
24586 JP GameInitialisation Jump to GameInitialisation to initialise the game.
