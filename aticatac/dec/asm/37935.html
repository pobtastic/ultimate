37935: Handle Clock
The handler for the clock, which is a secret door that only the knight can use. This is the same as HandlerBarrel but for the sprite IDs 1 to 16.
Input
IX The door entity
HandlerClock 37935 LD A,(60048) Fetch the sprite ID of the player from Player.
37938 DEC A Subtract one, to make the knight's sprite IDs start at zero.
This entry point is used by the routines at HandlerBarrel and HandlerBookcase.
HandlerSecretDoor_Check 37939 CP 16 Jump to HandlerSecretDoor_Closed if the player is not the right character.
37941 JR NC,HandlerSecretDoor_Closed
37943 CALL OpenDoorway Call OpenDoorway to open the doorway.
37946 JP HandlerDoorExit Jump to HandlerDoorExit to handle the exit of the door.
HandlerSecretDoor_Closed 37949 CALL CloseDoorway Call CloseDoorway to close the doorway.
37952 JP HandlerRoomItem Jump to HandlerRoomItem to handle a room item that does nothing.
