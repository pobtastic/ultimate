37308: Handle Trap Closed
The handler for a trapdoor that is closed (sprite ID 24). It is opened by HandlerTrap_Toggle when the counter in CounterLow is zero.
Input
IX The trapdoor entity
HandlerTrapClosed 37308 LD A,(24082) Fetch the counter from CounterLow.
37311 AND A Test whether the counter is zero.
37312 JP NZ,HandlerRoomItem Jump to HandlerRoomItem if it is not.
37315 JR HandlerTrap_Toggle Jump to HandlerTrap_Toggle to toggle the trapdoor between open and closed.
