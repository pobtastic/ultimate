41459: Print Colour String
Used by the routines at GameMenu, GameOver, GameStats and GameComplete.
Prints a string of characters, and sets the attribute of each character cell it uses. The string data starts with the attribute, followed by the characters, and bit 7 of the last character is set to mark the end of the string.
