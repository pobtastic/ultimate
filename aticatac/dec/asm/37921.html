37921: Handle Barrel
The handler for the barrel stack, which is a secret door that only the serf can use. The doorway is opened by OpenDoorway when the player is the serf (sprite IDs 33 to 48), and then the door is used (see HandlerDoorExit). For anyone else the doorway is closed by CloseDoorway and the door is just shown (see HandlerRoomItem).
Input
IX The door entity
HandlerBarrel 37921 LD A,(60048) Fetch the sprite ID of the player from Player.
37924 SUB 33 Subtract 33 to make the serf's sprite IDs start at zero.
37926 JR HandlerSecretDoor_Check Jump to HandlerSecretDoor_Check to check for the secret door.
