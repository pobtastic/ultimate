24116: Inventory 2
The slot of the inventory for the item that has been carried for the second shortest time. A slot is the address of the entity of the item (two bytes, low byte first, or 0 if the slot is empty), then the sprite ID and the attribute of the item.
Inventory_Slot2 24116 DEFW 3632
24118 DEFB 0 The sprite ID of the item.
Inventory_Slot2_Attribute 24119 DEFB 0 The attribute of the item.
