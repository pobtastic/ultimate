37928: Handle Bookcase
The handler for the bookcase, which is a secret door that only the wizard can use. This is the same as HandlerBarrel but for the sprite IDs 17 to 32.
Input
IX The door entity
HandlerBookcase 37928 LD A,(60048) Fetch the sprite ID of the player from Player.
37931 SUB 17 Subtract 17 to make the wizard's sprite IDs start at zero.
37933 JR HandlerSecretDoor_Check Jump to HandlerSecretDoor_Check to check for the secret door.
