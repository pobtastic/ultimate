37458: Handle Cave Door Locked
The handler for the locked cave doors (sprite IDs 12 to 15). This is the same as HandlerDoorLocked, but the doors become sprite ID 1.
Input
IX The door entity
HandlerCaveDoorLocked 37458 CALL CheckDoorKey Call CheckDoorKey to see whether the player has the key.
37461 JP NC,HandlerRoomItem Jump to HandlerRoomItem if not.
37464 LD A,1 A=1 (the sprite ID of an unlocked cave door).
37466 JR HandlerDoorLocked_Unlock Jump to HandlerDoorLocked_Unlock to unlock the door.
