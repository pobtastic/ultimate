36874: Check Obstacles
Used by the routine at ControlPlayer.
Checks whether an entity would hit one of the items in the room if it moved along each axis. This is the same as CheckRoomBounds, but for each of the items in the list for the room (see DrawRoom) whose attribute does not have bit 3 set. The position that the entity would move to is tested against a rectangle for the item. The byte at offset 6 of the item gives the left side in its top four bits (signed) and the width in its bottom four bits, and the byte at offset 7 gives the top and the height in the same way, all in units of four pixels. If the position is in the rectangle then the flag for the axis in offset 2 of the entity is set if the attribute of the item has bit 2 set, and cleared if it does not.
Input
DE The pixels to move (X in E and Y in D)
IX The entity
