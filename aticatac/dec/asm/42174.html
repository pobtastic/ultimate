42174: Sprite Table
The address of the data for each sprite, starting with sprite ID 1 (so the entry for an ID is at offset ID - 1 times 2). The ID is the first byte of an entity record, and is also its handler index (see HandlerTable). FetchSprite reads the table, and each sprite starts with its height (see Sprite_Knight_Down_1).
