33099: Throw Fireball
Used by the routine at HandlerWizard.
Launches a fireball for the wizard, unless a weapon is already in flight or the player is in a doorway. The fireball sprites have the IDs 52 to 55 and are animated by HandlerFireball.
Input
IX The player entity
ThrowFireball 33099 LD A,(60056) Return if a weapon is already in flight.
33102 AND A
33103 RET NZ
33104 LD A,(24109) Return if the player is in a doorway.
33107 AND A
33108 RET NZ
33109 CALL SoundsFireball Call SoundsFireball to make the fireball sound.
33112 CALL SetWeaponVelocity Call SetWeaponVelocity to set the velocity of the weapon.
33115 LD HL,60056 Point HL at the player weapon at PlayerWeapon.
33118 LD (HL),52 Write 52 to the weapon, the sprite ID of the first fireball frame.
This entry point is used by the routines at ThrowAxe and ThrowSword.
