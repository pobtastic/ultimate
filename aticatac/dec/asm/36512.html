36512: Lose Life
Used by the routines at TakeEnergyFromPlayer, HandlerKnight, HurtPlayer and RemoveMushroom.
Takes one of the lives of the player, or ends the game if there are none left. The player is set to the vanishing sprite 103 (see HandlerPlayerVanishing), with the number of rows to erase (at offset 6) set to the height of the sprite and the sprite ID that it came from (at offset 7). If the entity is a character then the position that was saved by StoreEntity is used first.
Input
IX The entity of the character
LoseLife 36512 LD A,(24097) Fetch the number of lives from PlayerLives.
36515 AND A Test whether there are no lives left.
36516 JP Z,GameOver Jump to GameOver if there are none.
See Infinite Lives.

36526 DEC A Subtract one to get the ID that starts at zero.
36527 CP 48 Jump to LoseLife_Character if the entity is a character.
36529 JR C,LoseLife_Character
36531 LD A,(60048) Fetch the sprite ID of the player from Player.
