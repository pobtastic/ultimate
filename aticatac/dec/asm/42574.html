42574: Graphics Attributes Table
The address of the attribute data for each graphic, starting with graphic ID 1 (the same IDs as GraphicsTable). GetGraphicAttributeDetails reads the table and SetGraphicAttributes sets the attributes. Each set starts with its width and height in character cells, followed by one attribute byte for each cell.
