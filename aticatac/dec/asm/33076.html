33076: Throw Axe
Used by the routine at HandlerKnight.
Launches an axe for the knight, unless a weapon is already in flight or the player is in a doorway. The axe sprites have the IDs 64 to 71 and are animated by HandlerAxe.
Input
IX The player entity
ThrowAxe 33076 LD A,(60056) Return if a weapon is already in flight.
33079 AND A
33080 RET NZ
33081 LD A,(24109) Return if the player is in a doorway.
33084 AND A
33085 RET NZ
33086 CALL SoundsAxeThrow Call SoundsAxeThrow to make the axe throwing sound.
33089 CALL SetWeaponVelocity Call SetWeaponVelocity to set the velocity of the weapon.
33092 LD HL,60056 Point HL at the player weapon at PlayerWeapon.
33095 LD (HL),64 Write 64 to the weapon, the sprite ID of the first axe frame.
33097 JR LaunchWeapon Jump to LaunchWeapon to launch the axe.
