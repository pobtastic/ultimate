31769: Game Initialisation
Used by the routine at SecurityCheck.
Clears the first 16 bytes of the game variables, selects the main font and then runs the game selection menu. The menu is drawn by GameMenu and the keyboard is scanned for the keys "1" to "6" and "0" until "0" is pressed. Each key changes the control method or the character stored in GameOptions and moves the highlight on the menu, and "0" starts the game at StartGame. The entry point at Game_Restart is also used to return to the menu when a game ends.
