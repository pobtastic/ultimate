32971: Reset Player Data
Used by the routine at StartGame.
Clears the game variables by filling memory from SpriteWidth up to 24575 with 0. This leaves the game options and font pointer alone.
ResetPlayerData 32971 LD HL,24080 Point HL at the sprite width at SpriteWidth.
32974 LD B,96 B=96 (i.e. finish once we reach 24576).
32976 JR ResetScreen_Fill Jump to ResetScreen_Fill to fill the memory with the value to write.
