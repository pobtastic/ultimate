32955: Fill Memory
Used by the routine at ResetAttributes.
Writes a single byte to memory from the target address, up to (but not including) the first address whose high byte is the end value.
Input
HL Target address
B The high byte of the end address (the fill stops at an LSB of 0)
C Value to write
ResetCopier 32955 LD (HL),C Write the fill value to the byte at the target address.
32956 INC HL Move on to the next address.
32957 LD A,H Loop back to ResetCopier until the target address has reached the end address.
32958 CP B
32959 JR NZ,ResetCopier
32961 RET Return.
