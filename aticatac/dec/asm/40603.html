40603: XOR Sprite Loop
Used by the routines at DrawEntity, RemoveEntity and DisplayEntity.
XORs the old sprite and the new sprite onto the screen one row at a time, working up from the bottom row. The row counters are in C and C' (in the normal and the shadow register sets), and each register set holds the screen address in HL and the sprite data address in DE for one of the two sprites. When the counters run out, any rows left over in Old_Sprite_Row_Count and New_Sprite_Row_Count are drawn.
Drawing a sprite a second time erases it, so the old sprite is removed from where it was and the new sprite is drawn where it is now.
XORSpriteLoop 40603 LD A,C Fetch the number of rows of the old sprite that are left.
40604 AND A Jump to XORSpriteLoop_Swap if there are no rows of the old sprite left to draw.
40605 JR Z,XORSpriteLoop_Swap
40607 DEC C Decrease the row counter by one.
40608 CALL DrawOldSpriteRow Call DrawOldSpriteRow to draw the old sprite row.
