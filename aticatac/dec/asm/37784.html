37784: Read Cursor Keys
Used by the routine at ReadControls.
Reads the cursor keys in the same way as the controls from ReadControls are returned. Bit 0 is right (8), bit 1 is left (5), bit 2 is down (6), bit 3 is up (7) and bit 4 is fire (0). A bit is reset when the key is pressed.
Output
A The state of the keys
