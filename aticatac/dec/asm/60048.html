60048: Player
Entities are 8-byte records, held in the table that starts here.
Offset Description
0 Sprite ID (also the index of the handler in HandlerTable)
1 Room ID
2 Used by the handler of the entity
3 X position (pixels)
4 Y position (pixels)
5 Attribute
6 Used by the handler of the entity
7 Used by the handler of the entity
The player is the first entity. Every entity from here up to RoomItemEntities is a copy of the data from Initialisation_Player onwards, which ResetGameState copies when a game starts, and this one is set up from PlayerTemplate for each life by PreparePlayer.
Player 60048 DEFB 0 Sprite ID (the frame that the player is drawn with).
PlayerRoom 60049 DEFB 0 Room ID (the room that the player is in).
60050 DEFB 0 Used by the handler of the entity.
60051 DEFB 0 X position.
60052 DEFB 0 Y position.
60053 DEFB 0 Attribute.
60054 DEFB 0 Number of rows drawn so far while the player is appearing (see HandlerPlayerAppearing).
60055 DEFB 0 Sprite ID of the character (see PreparePlayer).
