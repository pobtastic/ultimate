36193: Reset Game State
Used by the routine at StartGame.
Restores the entities and the other game data that start at Player to their initial state, ready for a new game. The initial state is kept in the copy of the data that starts at Initialisation_Player.
ResetGameState 36193 LD HL,24589 Point HL at the player initialisation data at Initialisation_Player.
36196 LD DE,60048 Point DE at the player at Player.
36199 LD BC,5488 BC=5488 (the number of bytes of game data).
36202 LDIR Copy the initial game data over the live game data.
36204 RET Return.
