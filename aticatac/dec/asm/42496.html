42496: Graphics Table
The address of the pixel data for each graphic, starting with graphic ID 1 (so the entry for an ID is at offset ID - 1 times 2). The ID is the first byte of a room item or door record, and is also its handler index (see HandlerTable2). GetGraphicDetails reads the table. Each graphic starts with its width in bytes and its height in pixels, and the graphics are drawn by DrawGraphic. The colours are in the attributes of the same graphic (see GraphicsAttributesTable).
