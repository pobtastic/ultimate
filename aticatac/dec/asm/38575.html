38575: Visit Room
Used by the routine at EnterRoom.
Marks a room as having been visited, by setting its bit in the table of visited rooms at VisitedRooms. The table has one bit for each room, 8 rooms to a byte. The bit to set is worked out from the room ID and written into the SET instruction at 38598 (self modifying code), which then sets it.
Input
A The room ID

38591 AND %00111000 Keep only bits 3-5.
38593 OR %11000110 Set bits 1-2, 6-7. This makes the second byte of the instruction SET n,(HL) for the bit.
38595 LD (38599),A Write this value to 38599, which updates the bit to set.
38598 SET 0,(HL) Set the bit to mark the room as having been visited.
