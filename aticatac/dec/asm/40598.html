40598: Fetch Actor Sprite
Used by the routine at PrepDraw2.
Fetches the address of the graphic for the sprite ID of an entity (held in the first byte of its record), by using FetchSprite.
Input
IX The entity
Output
DE The sprite address
FetchActorSprite 40598 LD A,(IX+0) A=the sprite ID from *IX+0.
40601 JR FetchSprite Jump to FetchSprite to fetch the sprite.
