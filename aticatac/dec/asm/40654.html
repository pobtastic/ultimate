40654: Draw Old Sprite Row
XORs one row of the old sprite onto the screen, then moves up to the row above. The row is two bytes of graphic data, which are written to two bytes of the screen when the sprite is aligned to a character cell, and otherwise are shifted along and written to three bytes.
Input
DE The address of the row of sprite data
HL The screen address
Output
DE The address of the next row of sprite data
HL The screen address of the row above
The entry point for a sprite which is aligned to a character cell. DrawOldSpriteRow_Shift jumps here when the shift is the one which does nothing.
DrawOldSpriteRow_Aligned 40654 EX DE,HL DE=the row of sprite data, and HL=the address of the next row.
40655 EX (SP),HL Fetch the screen address, and the address of the next row of sprite data is stored on the stack.
40656 LD A,D Fetch the first byte of the row.
40657 XOR (HL) Exclusive OR it onto the screen.
40658 LD (HL),A Write the result to the screen.
40659 INC L Move to the next byte on the screen.
40660 LD A,E Fetch the second byte of the row.
40661 XOR (HL) Exclusive OR it onto the screen.
40662 LD (HL),A Write the result to the screen.
40663 POP DE Fetch the address of the next row of sprite data.
40664 DEC L Move back to the first byte on the screen.
40665 JP ScreenPosition1PixelAbove Jump to ScreenPosition1PixelAbove to move up one pixel row.
This entry point is used by the routine at XORSpriteLoop.

Self modifying code; the operand of this command is written by 40849. It jumps into the run of shifts below so that the row is moved the right number of pixels, or to DrawOldSpriteRow_Aligned for a sprite which does not need to be shifted.
