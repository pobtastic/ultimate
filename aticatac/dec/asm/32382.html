32382: Process Action
Used by the routine at MainLoop.
Calls the handler of an entity. The handler's address is read from HandlerTable, indexed by the first byte of the entity record, and entered through the 233 (JP (HL)) at 23728. The entry point at ProcessAction_Dispatch is used when the return address has already been stacked, and the one at ProcessAction_Lookup when the table of handlers in HL is not HandlerTable.
Input
IX The entity
HL The address for the handler to return to
ProcessAction 32382 PUSH HL Stash the return address on the stack.
This entry point is used by the routine at UpdateFixedEntities.
ProcessAction_Dispatch 32383 LD HL,32486 Point HL at the handler table at HandlerTable.
This entry point is used by the routine at ProcessRoomItem.
Double the first byte of the entity to create an offset in BC.
ProcessAction_Lookup 32386 LD C,(IX+0) Fetch the first byte of the entity, which is its sprite ID.
This entry point is used by the routine at DrawGraphic.
ProcessAction_Offset 32389 LD B,0 B=0.
32391 SLA C Double BC, which gives two bytes for each sprite ID.
