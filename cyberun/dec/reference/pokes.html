Infinite Ships
POKE 62671,0
Removes the instruction which would otherwise take a ship away each time one is lost, so that the number of ships at 62957 never goes down.
62671 DEC A
To:
62671 NOP
Infinite Fuel
POKE 52304,0
Removes the instruction in UseFuel which would otherwise add the amount of fuel used to the fuel level, so that the level that is set at the start of each life never changes.
52304 ADD HL,DE
To:
52304 NOP
