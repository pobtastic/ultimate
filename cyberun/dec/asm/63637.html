63637: Read Shape Header
Used by the routine at BuildShiftedShapeB.
Reads the header of a description of a shape and sets up the counters that the routines at BuildShiftedShapeA and BuildShiftedShapeB use. The first byte is the number of strips, which is stored in ScratchPair and 23583. The second byte is the number of rows, which is stored in ScratchValue and TileNumber. The third byte is the number of bytes in a row. The entry point at ReadShapeHeader_Rows skips the first byte.
Input
HL Address of the description
Output
HL Address of the first byte after the header
C Number of bytes in a row
D 250, the page of the table of bytes shifted by two pixels
