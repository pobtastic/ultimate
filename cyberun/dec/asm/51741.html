51741: Frame Parameters
The values that DrawFrame uses to draw the frame round the playfield. The addresses are screen addresses, and DrawHUD sets up the two tables.
FrameParameters 51741 DEFW 22464 Left vertical line
51743 DEFW 22493 Right vertical line
51745 DEFB 160 Number of rows in the vertical lines
51746 DEFW 22241 Bottom horizontal lines
51748 DEFW 17985 Top horizontal lines
51750 DEFW 0 Address of the corner table (set by DrawHUD)
51752 DEFB 6 Number of ticks along each edge
51753 DEFW 0 Address of the tick table (set by DrawHUD)
51755 DEFB 22 Pixel row of the top edge
51756 DEFB 232 Pixel column of the right edge
51757 DEFB 28 Length of the horizontal lines, in bytes
FrameParameters_Second 51758 DEFB 20,2,71 Attribute area for the panel behind the text
