34448: Update Control Icon
Used by the routines at RunTitleMenu and ShowTitleScreen.
Slides the icon for a player's control method towards the row of the selected method and draws it.
Input
IX Address of the control icon data (see ControlIconPlayerOne)
DE Address of the sprite of the icon
UpdateControlIcon 34448 LD A,(IX+2) Fetch the selected control method.
34451 LD HL,34564 Use the table of icon positions at ControlIconPositions.
34454 CALL AddAToHL Add the control method to the address.
34457 LD A,(HL) Fetch the target position of the icon.
34458 SUB (IX+1) Subtract the current position of the icon.
34461 JR Z,UpdateControlIcon_Draw Jump to UpdateControlIcon_Draw if the icon is already in place.
34463 BIT 7,A Jump to UpdateControlIcon_Up if the icon is above the target.
34465 JR NZ,UpdateControlIcon_Up
34467 INC (IX+1) Move the icon one pixel closer.
34470 JR UpdateControlIcon_Draw Jump to UpdateControlIcon_Draw.
UpdateControlIcon_Up 34472 LD A,(IX+1) Fetch the current position of the icon.
34475 SUB 4 Move the icon four pixels closer.
34477 LD (IX+1),A Store the new position.
UpdateControlIcon_Draw 34480 LD L,(IX+0) Fetch the pixel position of the icon into HL.
34483 LD H,(IX+1)
34486 JP DrawBitmap Draw the icon.
