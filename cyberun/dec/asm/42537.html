42537: Erase Aligned Row Directly
Erases one row of a sprite that is aligned to a byte from the screen. The entry point depends on the width of the sprite in bytes, from six bytes at EraseAlignedRowDirectly to one byte at EraseAlignedRowDirectly_Sixth. Each byte clears the pixels of the screen that are set in the sprite.
Input
DE' Address of the data of the sprite
HL' Screen address of the row
EraseAlignedRowDirectly 42537 LD A,(DE) Fetch a byte of the sprite.
42538 CPL Invert it.
42539 AND (HL) Clear the pixels of the screen.
42540 LD (HL),A Store the byte.
42541 INC L Move on to the next byte of the screen.
42542 INC DE Move on to the next byte of the sprite.

EraseAlignedRowDirectly_Next 42572 LD A,(23592) Fetch the low byte of the screen address of the start of the row.
42575 LD L,A Restore it.
