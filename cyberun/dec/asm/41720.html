41720: Sprite Variables
Variables used by DrawSprites.
SpriteVariables 41720 DEFB 0 Width of the first sprite in bytes.
41721 DEFB 0 Width of the second sprite in bytes.
SpriteVariables_RightEdge 41722 DEFB 0 Set when DrawSprites is to draw sprites that reach beyond the right of the playfield, which makes it take 96 off both horizontal positions.
41723 DEFB 239,175,173,141,137,9,8,0 Masks used to dissolve the second sprite, which are picked by the value at 41730.
