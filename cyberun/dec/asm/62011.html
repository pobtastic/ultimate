62011: Get Random Numbers
Used by the routines at ChooseItemSites, RunTitleMenu and RunLife.
Makes two new random numbers at RandomNumbers, using a pointer to a byte of memory that is moved on one place each time and stays below 45056. The byte that it points to is added to each number, together with the value of the value of the controls (see ReadControls), so pressing the controls at different times changes the numbers.
