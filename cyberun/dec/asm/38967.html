38967: Chase Player Briefly
Behaviour code used for objects of type 23 (see RunObjectBehaviour). Makes the object accelerate towards the player and then gives it a new lifetime.
Input
IX Address of the object
ChasePlayerBriefly 38967 PUSH IY Stash IY on the stack.
38969 LD IY,51429 Use the player's object.
38973 CALL AccelerateTowardsTarget Accelerate towards the player.
38976 POP IY Bring IY back off the stack.
38978 LD A,(39883) Fetch the first byte of the random seed.
38981 AND %00001111 Keep four bits.
38983 ADD A,10 Add ten.
38985 LD (IX+21),A Set the lifetime of the object.
38988 RET Return.
