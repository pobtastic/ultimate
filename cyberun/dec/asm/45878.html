45878: Draw Rows
Used by the routine at DrawShot.
Draws rows of a buffer onto the screen by ORing them in, going up the screen from the row that HL is at. The number of rows is the value in 41432 and a row is B bytes of the buffer, which has eight bytes to a row.
Input
B Number of bytes in a row
DE Address of the buffer
HL Screen address
