36397: Apply Collision Effects
Used by the routine at UpdateEnemies.
Works out what happens when the player's ship hits an object. The object sets the byte at 36396 when it is updated, and each bit of that byte selects an effect:
Bit Effect
7 Slow the ship down (SlowShip)
6 Damage the ship (DamageShip)
5 Drain fuel (DrainFuel)
4 Bounce the ship (BounceShip)
3 Mark the object as destroyed (DestroyObject)
2 Add fuel (AddFuel)
1 Add a ship (AddShip)
0 Mark the object as hit (MarkObjectHit)
Input
IX Address of the object
