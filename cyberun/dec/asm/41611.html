41611: Find Object Screen Address
Used by the routines at UpdateSpecialShot, UpdateShot, DrawShot and UpdateLeftShot.
Finds the screen address of a position that is held in an object.
Input
IX Address of the object
Output
HL Screen address
FindObjectScreenAddress 41611 LD L,(IX+11) Fetch the horizontal position.
41614 LD H,(IX+12) Fetch the vertical position.
41617 JP GetScreenAddress Find the screen address.
