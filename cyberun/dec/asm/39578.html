39578: Play Music Until Key Pressed
Used by the routine at ShowTitleScreen.
Plays a tune made of notes, which ends with 255. The tune stops as soon as a key is pressed.
Input
DE Address of the first note
PlayMusic_WaitKey 39578 XOR A Select every keyboard row.
39579 CALL ReadKeyboardPort Read the keyboard.
39582 RET NZ Return if a key is pressed.
39583 LD A,(DE) Fetch a note.
39584 CP 255 Jump to PlayMusic_Return if it is the end of the tune.
39586 JR Z,PlayMusic_Return
39588 CALL PlayNote Play the note.
39591 JR PlayMusic_WaitKey Jump back to PlayMusic_WaitKey for the next note.
