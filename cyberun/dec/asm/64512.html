64512: Copy Game Down
Used by the routine at GameEntry.
Used by the loader before the game starts: GameEntry calls this routine to move the encrypted game from 24192 down to 23680. The helper at 24576 copies it here from 24610. The routine is in the area of memory where the shift tables are built afterwards, so it is overwritten when the game starts.
CopyGameDown 64512 LD HL,24192 Set the source address in HL.
64515 LD DE,23680 Set the destination address in DE.
64518 LD BC,40320 Set the number of bytes to copy in BC.
64521 LDIR Copy the game down.
64523 RET Return.
The next four bytes are not used.
64524 LD SP,65024 Set the stack pointer to 65024.
64527 DI Disable interrupts.
