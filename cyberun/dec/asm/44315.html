44315: Draw Object
Used by the routines at UpdateObject, UpdateType14, UpdateCrystalStack and UpdateMapObjects.
Draws the sprite that was set up for an object by PrepareDraw, unless both the width in 41431 and the number of rows in 41432 are zero.
DrawObject 44315 LD A,(41431) The rows of the first sprite.
44318 LD C,A C=A.
44319 LD A,(41432) The rows of the second sprite.
44322 OR C Set the bits of A that are set in C.
44323 RET Z Return if the zero flag is set.
44324 JP DrawSprites Jump to DrawSprites.
