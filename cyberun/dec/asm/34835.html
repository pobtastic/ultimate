34835: Fire Random Shot
Used by the routines at UpdateType13 and UpdateType19.
Occasionally fires a shot from an object, when the flag at 41431 is set.
Input
IX Address of the object
FireRandomShot 34835 LD A,(41431) Fetch the flag from 41431.
34838 AND A Test it.
34839 RET Z Return if it is clear.
34840 LD A,(39883) Fetch the first byte of the random seed.
34843 AND %00101111 Keep only some of the bits.
34845 RET NZ Return if any are set, so a shot is only fired now and then.
34846 JR FireShot Jump to FireShot.
