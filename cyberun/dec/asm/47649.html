47649: Check Terrain Collision
Used by the routines at NudgeObject and RunFrame.
Checks whether an object has run into the terrain and bounces it when it has. The tiles come from StartTerrainCheck and SelectNextTile. A tile record starts with the number of boxes, and each box is five bytes: its position, its width, its height and its flags. Bits 2 to 5 clear means a slope (TestSlopeCollision); otherwise the box is a rectangle (TestBoxesOverlap). A rectangle with bits 4 and 5 clear reverses, halves and limits the vertical speed. Any other rectangle does the same to the horizontal speed, and skips the halving when the collision mode is zero. The mode in HorizontalStepSize is 255 for the ship, 128 when the object should stop, and zero otherwise. The ship also plays the crash or bump sound and changes the scroll speed.
Input
B Height of the object
C Width of the object
IX Address of the object
Output
$5C1C Non-zero if the object hit something
