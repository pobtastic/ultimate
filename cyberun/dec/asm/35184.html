35184: Reverse Vertical Speed
Used by the routine at FireShot.
Part of FireShot. Sets a random speed and, unless the object is moving fast, reverses its vertical direction.
Input
IX Address of the shot
IY Address of the object
ReverseVerticalSpeed 35184 CALL SetRandomSpeed Give the object a random speed.
35187 LD A,(IX+18) Fetch the second state byte of the shot.
35190 CP 103 Jump to FireShot_Sound if it is 103 or higher.
35192 JP NC,FireShot_Sound
35195 LD A,(IY+9) Fetch the vertical speed of the object.
35198 NEG Negate it.
35200 LD (IY+9),A Store it.
35203 JP FireShot_Sound Jump to FireShot_Sound.
