35928: Accelerate Towards Player
Used by the routine at ProcessObjectFlags.
Sets the acceleration of an object so that it heads towards the player. Objects of type 29 and 30 are left alone.
Input
IX Address of the object
AccelerateTowardsPlayer 35928 LD A,(IX+0) Fetch the type of the object.
35931 CP 29 Is it 29?
35933 RET Z Return if so.
35934 CP 30 Is it 30?
35936 RET Z Return if so.
35937 LD A,(23601) Fetch the value from ContactFlags.
35940 AND %10000000 Keep bit 7.
35942 RET NZ Return if it is set.
