57405: Compare Slot With Site
Used by the routine at MakeTiles.
Compares a slot for a pick-up with a site, using the column, the row and the position. The result is that the zero flag is set if the slot holds the pick-up for the site, and is clear if not or if the slot is free.
Input
IX Address of the site
IY Address of the slot
Output
F Zero flag set if the slot has the pick-up
