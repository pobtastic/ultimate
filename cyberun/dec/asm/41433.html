41433: Clip Second Sprite
Used by the routines at PrepareDraw and UpdateStarLayer.
Fetches the header of the second sprite and clips it to the playfield.
Input
DE Address of the sprite
Output
B Number of rows
C Index of the routine that draws the sprite
DE Address of the first row of data
H Width in bytes
ClipSecondSprite 41433 LD HL,(41429) Fetch the position of the second sprite.
41436 CALL ReadSpriteHeader Read the header of the sprite.
41439 LD A,(41430) Fetch the vertical position.
41442 CALL ClipSpriteVertically Clip the sprite at the top and bottom of the playfield.
41445 LD A,L Fetch the clipped vertical position.
41446 LD (41430),A Store it.
41449 RET Return.
