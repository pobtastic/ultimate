37626: Set Facing
Used by the routines at UpdateObject and UpdateType19.
Sets the first state byte of an object to zero, or one if the object is moving left.
Input
IX Address of the object
SetFacing 37626 LD (IX+19),0 Clear the first state byte.
37630 BIT 7,(IX+7) Test bit 7 of the horizontal speed.
37634 RET Z Return if it is clear.
37635 INC (IX+19) Set the first state byte to one.
37638 RET Return.
