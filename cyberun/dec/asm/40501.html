40501: Test Slope Collision
Used by the routine at CheckTerrainCollision.
Tests whether a box touches an object with a sloping face. Bits 6 and 7 of the byte at offset 4 of the object select one of four ways the slope can face, and the bottom three bits are the steepness. The result is stored in 23580, and when the box does touch the object the depth that it has gone into the slope is stored in 23578. The position of the box comes from 52794 and its size from 52796.
Input
IX Address of the object
