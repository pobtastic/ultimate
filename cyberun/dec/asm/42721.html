42721: Erase Shifted Row In Buffer
Erases one row of a sprite that is not aligned to a byte from the buffer used by DrawSprites, using the shift table that B points to. Each byte of the sprite makes two bytes in the buffer. The entry point depends on the width of the sprite in bytes, from five bytes at EraseShiftedRowInBuffer to one byte at 42777.
Input
B High byte of the shift table
DE' Address of the data of the sprite
HL' Address in the buffer
