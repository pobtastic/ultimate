23700: Map Table
One byte for each of the 290 objects that are placed on the map, in the order of the table at TerrainData. The bottom six bits are the kind of object (see ObjectKinds). Bit 7 is set once player one has destroyed the object and bit 6 once player two has, so that AddMapObjects does not put it back. PlayLife changes the code that tests and sets the bit to suit the current player. MaskMapTable masks all of the bytes with a value that depends on the number of players.
