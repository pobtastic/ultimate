58328: Set Slope Parameters
Used by the routines at SetUpSegment and ReadSegmentShapes.
Looks up the three parameters of the type of the current segment in the table at SlopeParameters and stores them in the variables at HorizontalStep. A type of 7 or more is for a segment that is upside down: it sets UpsideDownSegment to 128 and uses the parameters of the type less seven. It then sets SlopeDirection to 1 when the second parameter is negative and to 255 when it is not, and in the second case changes the JR instruction at SetUpPiece_Patched to skip two bytes.
