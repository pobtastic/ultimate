56317: Draw Mirrored Rows From Edge
Used by the routine at JumpToDrawingRoutine.
Draws the rows of a piece of a slope back to front, two bytes wide, going up the screen two pixel rows at a time, starting from the second column of the row (see DrawSlopeRowsFromEdge). Each byte of the picture is reversed using the table at 63744 (B is set to 249). The jumps at DrawMirroredRowsFromEdge_PatchFirst and DrawMirroredRowsFromEdge_PatchSecond are changed by SetUpPiece to skip bytes when only part of the piece is to be drawn.
Input
A Number of pairs of pixel rows to draw
HL Screen address
SP Address of the picture
