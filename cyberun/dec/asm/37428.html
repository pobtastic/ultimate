37428: Score Destroyed Object
Used by the routines at ExplodeHitObject, CheckShotCollisions and UpdateType19.
Adds the points for an object to the score of player one. The points come from the table at PointsTable, indexed by the type of the object. Objects of type 13 and 27 are worth 592 points. The points are doubled if bit 3 of the second flags of the object is set.
Input
IX Address of the object
ScoreDestroyedObject 37428 LD A,(IX+0) Fetch the type of the object.
37431 CP 13 Jump to ScoreDestroyedObject_Fixed if it is 13.
37433 JR Z,ScoreDestroyedObject_Fixed
37435 CP 27 Jump to ScoreDestroyedObject_Table if it is not 27.
37437 JR NZ,ScoreDestroyedObject_Table
ScoreDestroyedObject_Fixed 37439 LD BC,592 Set the points to 592.
37442 JR AddToScore Jump to AddToScore.
