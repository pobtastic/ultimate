41664: Add Speeds To Position
Adds two speeds to the two coordinates of an object. Nothing in the game refers to this routine.
Input
IX Address of the object
AddSpeedsToPosition 41664 LD A,(IX+2) Fetch the first coordinate.
41667 LD B,(IX+5) Fetch the first speed.
41670 ADD A,B Add the speed.
41671 LD (IX+2),A Store the coordinate.
41674 LD A,(IX+3) Fetch the second coordinate.
41677 LD B,(IX+6) Fetch the second speed.
41680 ADD A,B Add the speed.
41681 LD (IX+3),A Store the coordinate.
41684 RET Return.
