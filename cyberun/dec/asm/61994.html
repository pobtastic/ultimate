61994: Title Frame Parameters
The values that DrawFrame uses to draw the frame of the title screen, which has the same layout as the table at FrameParameters.
TitleFrameParameters 61994 DEFW 22464 Left vertical line
61996 DEFW 22495 Right vertical line
61998 DEFB 176 Number of rows in the vertical lines
61999 DEFW 22241 Bottom horizontal lines
62001 DEFW 17921 Top horizontal lines
62003 DEFW 0 Address of the corner table (set by ShowTitleScreen)
62005 DEFB 6 Number of ticks along each edge
62006 DEFW 0 Address of the tick table (set by ShowTitleScreen)
62008 DEFB 6 Pixel row of the top edge
62009 DEFB 248 Pixel column of the right edge
62010 DEFB 31 Length of the horizontal lines, in bytes
