44019: Mark Cell Destroyed
Used by the routine at CheckObjectHitByShot.
Sets the bit for the map cell of an object in the bitmap at CurrentPlayerState_MapCells (found by FindCellBit), unless the item number in A is below 6. The bit number is written straight into the operand of the SET instruction at 44037, so this routine modifies its own code.
Input
A Item number of the object
IX Address of the object
MarkCellDestroyed 44019 CP 6 Return if A is less than 6.
44021 RET C
44022 LD E,(IX+1) The map column.
44025 LD D,(IX+4) The map zone.
44028 CALL FindCellBit Call FindCellBit.
44031 LD A,B A=B.
44032 ADD A,198 Add 198 to A.
44034 LD (44038),A The bit of the map cell.
44037 SET 0,(HL) Set bit 0 of the byte at the address in HL.
44039 RET Return.
