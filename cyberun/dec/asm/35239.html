35239: Shot Tables
Two overlapping tables used by FireShot. The first holds a byte of flags for each kind of shot (the table starts at CopyPosition_Return, so the first byte is for kind one). The second holds four bytes for each kind of shot, starting at ShotTables_Speeds: the horizontal speed, the vertical speed and the two state bytes of the shot.
Only kinds 3, 7 and 8 are known to be used.
