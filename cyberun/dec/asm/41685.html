41685: Subtract Speeds From Position
Subtracts two speeds from the two coordinates of an object. Nothing in the game refers to this routine.
Input
IX Address of the object
SubtractSpeedsFromPosition 41685 LD A,(IX+2) Fetch the first coordinate.
41688 LD B,(IX+5) Fetch the first speed.
41691 SUB B Subtract the speed.
41692 LD (IX+2),A Store the coordinate.
41695 LD A,(IX+3) Fetch the second coordinate.
41698 LD B,(IX+6) Fetch the second speed.
41701 SUB B Subtract the speed.
41702 LD (IX+3),A Store the coordinate.
41705 RET Return.
