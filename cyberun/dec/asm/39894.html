39894: Beam Variables
The state shared by the four flickering beams drawn by UpdateBeams.
BeamVariables 39894 DEFB 0 The pattern of the beams, which is zero while they are switched off.
39895 DEFB 0 The attribute of the beams.
39896 DEFB 1 The number of frames until the beams change.
39897 DEFB 0 Set to 1 when at least one beam was drawn this frame.
