52811: Picture Offsets Pointer
A pointer into PictureOffsets that DrawTerrain sets: to the start of the table when the horizontal offset has no pixels to the side of a whole byte, or one byte on otherwise. SetUpPiece adds the offset of the type to set SegmentPictureOffsets.
