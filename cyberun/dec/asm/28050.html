28050: Tile Scripts
The scripts that draw the tiles. A script is a list of segments of ground. It starts with up to three prefix bytes (153, 255 and 153), then the number of segments, then the segments. The pointers at TileScriptPointers start at one of the prefix bytes or at the number: a script drawn from the first 153 is upside down and back to front, from the 255 is back to front, from the last 153 is upside down, and from the number is drawn as it is. DrawTerrain reads the scripts.
Each segment is the pixel column and the pixel row where it starts, one byte with the type of slope in the top four bits and the length in the bottom four bits (zero is 16), and, only for a flat type (0 or 7), two more bytes that give the shape at each end.
