33607: Adjust Terrain Slope
Used by the routine at DrawVerticalEdge.
Works out how much to adjust the drawing of a terrain tile when it is next to a sloping tile. The tile codes 144 to 147 are the four slope tiles; the codes of the two tiles under consideration are held at StartShape and EndShape.
Input
E Direction flag set by the caller
IX Address of the object
Output
C Number of extra rows to draw
L Adjusted vertical position
AdjustTerrainSlope 33607 LD A,(IX+1) Fetch the map column of the object.
33610 AND A Test it.
33611 RET Z Return if it is zero.
33612 LD HL,(23603) Fetch the two tile codes from StartShape into HL.
33615 LD BC,0 Clear the adjustment (B) and the extra row count (C).
33618 CALL AdjustTerrainSlope_First Check the first tile code.
33621 CALL AdjustTerrainSlope_Second Check the second tile code.
Slope tile 145 can add an extra row.
33624 LD A,L Fetch the first tile code.
33625 CP 145 Jump to AdjustTerrainSlope_Tile93 if it is not slope tile 145.
33627 JR NZ,AdjustTerrainSlope_Tile93

33631 JR NZ,AdjustTerrainSlope_Tile93
33633 LD A,E Fetch the direction flag.
33634 AND A Test it and jump to AdjustTerrainSlope_Tile93 if it is set.
33635 JR NZ,AdjustTerrainSlope_Tile93

Slope tile 147 can add an extra row too.
