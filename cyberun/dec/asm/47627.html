47627: Zero Small Speed
Used by the routines at ReverseAndHalveSpeed, CheckSpecialShot and CheckTerrainCollision.
Sets a speed to zero if it is too small to matter. The speed is a signed number, which is changed if it is below 100 or above 65368.
Input
HL Speed
Output
HL New speed
ZeroSmallSpeed 47627 LD A,H A=H.
47628 AND A Jump to ZeroSmallSpeed_Negative if A is not zero.
47629 JR NZ,ZeroSmallSpeed_Negative
47631 LD A,L A=L.
47632 CP 100 Return if A is 100 or more.
47634 RET NC
47635 LD HL,0 HL=0.
47638 RET Return.

47641 LD A,L A=L.
