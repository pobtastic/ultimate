57909: Get Tile
Used by the routine at MakeTiles.
Gets the number of the tile at a column and a row of the map. It also stores the column, after it has wrapped, at NextColumn. If the row is zero there is no tile above the first row of the map, so the tile is blank and the address is moved up a row, ready for the next tile.
Input
DE 96
H Row
L Column
Output
A Tile number
HL Address in the map
