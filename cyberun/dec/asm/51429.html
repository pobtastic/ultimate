51429: Ship Object
The player's ship. The first 24 bytes have the layout of an enemy slot, as described at EnemySlots, and then there are some extra fields:
Offset Contents
24 Bit 7 is set when the ship is facing left
25-26 Copy of the horizontal speed (offsets 7 and 8) taken at the end of the frame
27-28 Copy of the vertical speed (offsets 9 and 10) taken at the end of the frame
29-30 Horizontal then vertical position at which the ship was last drawn, which is used to erase it
31 What the ship is about to pick up: 192 plus the number of an item to carry, or the number of a part to fit
