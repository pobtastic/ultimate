42803: Draw Aligned Row In Buffer
Draws one row of a sprite that is aligned to a byte into the buffer used by DrawSprites. The entry point depends on the width of the sprite in bytes, from six bytes at DrawAlignedRowInBuffer to one byte at 42828.
Input
DE Address of the data of the sprite
HL Address in the buffer
