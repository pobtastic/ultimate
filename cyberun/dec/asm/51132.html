51132: Ship Top Object
The object that is used to draw the top of the ship: its type, its position on the screen, and some flags. The flag at 51135 has bit 7 set when it faces left, and 51137 is the number of frames for which it is shown as hit. There is a second copy of it that is kept for the other player.
