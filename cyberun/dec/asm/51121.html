51121: Test Direction
Used by the routine at DrawShipTop.
Tests the flag at 51135, which has bit 7 set when the object is facing left. If it is not, L is increased, B is made 249 and the zero flag is set.
Input
L Horizontal position
Output
A Zero if not facing left
B 249 if not facing left
F The zero flag is set if the object is not facing left
TestDirection 51121 LD A,(51135) The ship top faces left.
51124 BIT 7,A Return if bit 7 of A is set.
51126 RET NZ
51127 LD B,249 B=249.
51129 INC L Advance L.
51130 XOR A Clear A.
51131 RET Return.
