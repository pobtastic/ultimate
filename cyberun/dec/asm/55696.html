55696: Adjust Edge Address
Used by the routine at DrawVerticalEdge.
Moves the screen address in HL one cell to the left when the horizontal speed is negative. The last four instructions, which would move it back and count a step less, cannot be reached because the speed is known to be negative.

C Number of steps left
HL Screen address
