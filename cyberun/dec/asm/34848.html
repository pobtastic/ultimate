34848: Fire Shot When Hit
Used by the routine at UpdateMapObjects.
Occasionally fires a shot from an object that has been hit.
Input
IX Address of the object
FireShotWhenHit 34848 LD A,(39883) Fetch the first byte of the random seed.
34851 AND %01011010 Keep only some of the bits.
34853 RET NZ Return if any are set.
34854 BIT 7,(IX+16) Test bit 7 of the flags of the object.
34858 RET Z Return if it is clear.
Continue on to FireShot.
