41450: Clip First Sprite
Used by the routines at PrepareErase and UpdateStarLayer.
Fetches the header of the first sprite and clips it to the playfield.
Input
DE Address of the sprite
Output
B Number of rows
C Index of the routine that draws the sprite
DE Address of the first row of data
H Width in bytes
ClipFirstSprite 41450 LD HL,(41427) Fetch the position of the first sprite.
41453 CALL ReadSpriteHeader Read the header of the sprite.
41456 LD A,(41428) Fetch the vertical position.
41459 CALL ClipSpriteVertically Clip the sprite at the top and bottom of the playfield.
41462 LD A,L Fetch the clipped vertical position.
41463 LD (41428),A Store it.
41466 RET Return.
