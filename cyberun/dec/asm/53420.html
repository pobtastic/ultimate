53420: Segment Codes
A code for each of the sixteen types of segment, which DrawTerrain stores at offset 4 of the record that it makes for the segment (the first four bytes are the position and size). Purpose not yet known.
SegmentCodes 53420 DEFB 4,1,2,3,65,66,67,8,129,130,131,193,194,195,16,32
