37130: Step Object State
Used by the routines at UpdateType1C, UpdateType1D, UpdateType14 and UpdateMapObjects.
Steps through a sequence held in the two state bytes of an object. If bits 4 and 5 of the first state byte are equal to one, the bottom four bits of the first state byte count up and wrap round when they reach the value in the bottom four bits of the second state byte. Otherwise, bits 4 and 5 of the first state byte are adjusted. Purpose not yet known.
