40275: Find Beam Extent
Used by the routine at UpdateBeams.
Works out where a beam is drawn and how long it is. The beam number is held at 23582: bit 0 selects the side of the screen on the horizontal axis and bit 1 selects the side on the vertical axis. The screen address that is returned is where the beam starts.
Input
DE Second scroll position (from 52801)
HL First scroll position (from 52805)
IX Address of the beam variables
Output
B Length of the beam in bytes, or zero if there is no beam
C Pattern of each byte, rotated to match the fine scroll
HL Screen address of the start of the beam
