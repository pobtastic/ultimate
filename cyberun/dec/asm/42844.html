42844: Draw Shifted Row In Buffer
Draws one row of a sprite that is not aligned to a byte into the buffer used by DrawSprites, using the shift table that B points to. Each byte of the sprite makes two bytes in the buffer. The entry point depends on the width of the sprite in bytes, from five bytes at DrawShiftedRowInBuffer to one byte at 42892.
Input
B High byte of the shift table
DE Address of the data of the sprite
HL Address in the buffer
