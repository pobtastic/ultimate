56391: Draw Mirrored Slope Rows
Used by the routine at JumpToDrawingRoutine.
Draws the rows of a piece of a slope back to front, two bytes wide, going up the screen two pixel rows at a time. Each byte of the picture is reversed using the table at 63744 (B is set to 249). The jump at DrawMirroredSlopeRows_Patch is changed by SetUpPiece to skip bytes when only part of the piece is to be drawn, and the last words of each group are entered at DrawMirroredSlopeRows_Last and DrawMirroredSlopeRows_Second.
Input
A Number of pairs of pixel rows to draw
HL Screen address
SP Address of the picture
