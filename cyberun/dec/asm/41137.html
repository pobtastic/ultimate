41137: Print Character
Used by the routine at PrintText.
Prints one character of text. The character is drawn from the bottom row to the top, so the screen address moves up the screen. The instruction at PrintCharacter_Mode is changed by PrintText to either carry straight on or to jump to PrintWideCharacter, which prints wide characters.
Input
B' Attribute
DE Address of the character code
HL Screen address
HL' Attribute address
Output
HL Screen address of the next character
HL' Attribute address of the next character
