55514: Fill Slope Edge
Used by the routine at EndSegment.
Clears the pixels at the end of a sloped segment when the world is moving horizontally and the shape code of the segment says that it is a slope (bit 0 of the shape code that goes with the direction, in StartShape or EndShape). The screen address of the end is found from SavedScreenAddress, moved to either side, and FillStripWithPattern fills a strip there with zeros.
