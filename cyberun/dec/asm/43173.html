43173: Add To Stack
Used by the routine at DrawShot.
Adds one or two units to the height of the stack at StackHeight (which hangs below the ship) if the item that is carried at 62977 is item number 6. The limit is 18. The screen is cleared where the new units will be drawn. This is a best reading of the code. An object with a state of zero does not add anything.
Input
IX Address of the object

43176 AND A Return if it is zero.
