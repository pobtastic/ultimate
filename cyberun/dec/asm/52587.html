52587: Read Segment Shapes
Used by the routine at DrawTerrain.
Reads the two bytes that give the shapes at the ends of a flat segment from the script and stores them in StartShape and EndShape. It changes them if the tile is drawn back to front or upside down. When the tile is back to front the horizontal position of the segment is mirrored and its type is changed with the table at MirrorTypeTable. The routine finally stores the address of the rest of the script in ScriptPointer.
Input
HL Address of the shape bytes in the script
Output
HL Address of the next segment in the script
