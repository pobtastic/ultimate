45423: Read Input Device
Used by the routine at ReadControls.
Reads the device that was chosen on the title screen: the keyboard (0), a Kempston joystick (1), a Cursor joystick (2) or a Sinclair Interface 2 joystick (3). The result is in the same layout for all of them. The keyboard has no joystick, so the keys of the middle two rows are all for up, the top row is for fire, the number keys are for the extra key, and the keys of the bottom row alternate between right and left.
Output
C Controls: bit 0 is right, bit 1 left, bit 3 up, bit 4 fire and
bit 5 the extra key
