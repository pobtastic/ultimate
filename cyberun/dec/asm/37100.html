37100: Process Object Flags
Used by the routines at UpdateType14, UpdateType1E and UpdateCrystalStack.
Remembers the address of the object in CurrentObject. If bit 4 of its flags is set the object is removed. Otherwise, bit 3 of the flags is cleared and, if it had been set, the routine returns; if not, the object is drawn and made to accelerate towards the player.
Input
IX Address of the object
ProcessObjectFlags 37100 LD (44358),IX Store the address of the object in CurrentObject.
37104 BIT 4,(IX+16) Jump to ProcessObjectFlags_Bit3 if bit 4 of the flags of the object is clear.
37108 JR Z,ProcessObjectFlags_Bit3
37110 LD (IX+0),255 Free the slot.
37114 RET Return.
ProcessObjectFlags_Bit3 37115 BIT 3,(IX+16) Test bit 3 of the flags of the object.
37119 RES 3,(IX+16) Clear bit 3.
37123 RET NZ Return if it was set.
37124 CALL PrepareDraw Draw the object.
37127 JP AccelerateTowardsPlayer Make the object accelerate towards the player.
