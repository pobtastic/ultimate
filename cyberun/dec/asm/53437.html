53437: Draw Terrain
Used by the routine at ScrollWorld.
Draws the terrain of the four tiles that are in view, by running the script of each tile. The number of the tile is kept in TileNumber: bit 0 is set for a tile below the first and bit 1 for a tile to the right. The scripts of the tiles are found from the table at TileScriptPointer. Each tile is a list of segments, and each segment is set up with SetUpSegment and ReadSegmentShapes and then drawn step by step, each step of a segment being a piece of picture. TilesChanged is non-zero when the tiles have changed, and then the routine also makes a record of each segment in the area from GameEntry: a count byte for the tile followed by five bytes for each segment (the position, the size and the code from SegmentCodes), which the routines that move objects use to test for collisions with the terrain. The segments that are not near the position at PositionAcross and PositionDown are not drawn.
