6D92: Tile Scripts
The scripts that draw the tiles. A script is a list of segments of ground. It starts with up to three prefix bytes (99, FF and 99), then the number of segments, then the segments. The pointers at TileScriptPointers start at one of the prefix bytes or at the number: a script drawn from the first 99 is upside down and back to front, from the FF is back to front, from the last 99 is upside down, and from the number is drawn as it is. DrawTerrain reads the scripts.
Each segment is the pixel column and the pixel row where it starts, one byte with the type of slope in the top four bits and the length in the bottom four bits (zero is 10), and, only for a flat type (00 or 07), two more bytes that give the shape at each end.
