E244: Get Blank Tile
Used by the routine at GetTile.
Used by GetTile when the row is zero. Moves the address back up a row and returns a blank tile.
Input
DE 60
HL Address in the map
Output
A Tile number (zero)
HL Address in the map, one row up

E245 SBC HL,DE Subtract DE and the carry from HL.
E247 XOR A Clear A.
