898E: Copy Position
Used by the routines at SpawnEnemy and StartDebrisPiece.
Copies the position of one object to another.
Input
IX Address of the object to copy to
IY Address of the object to copy from
CopyPosition 898E LD A,(IY+$01) Copy the map column.
8991 LD (IX+$01),A
8994 LD A,(IY+$02) Copy the horizontal position.
8997 LD (IX+$02),A
899A LD A,(IY+$04) Copy the map zone.
899D LD (IX+$04),A
89A0 LD A,(IY+$05) Copy the vertical position.
89A3 LD (IX+$05),A
CopyPosition_Return 89A6 RET Return.
