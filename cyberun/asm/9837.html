9837: Chase Player Briefly
Behaviour code used for objects of type 17 (see RunObjectBehaviour). Makes the object accelerate towards the player and then gives it a new lifetime.
Input
IX Address of the object
ChasePlayerBriefly 9837 PUSH IY Stash IY on the stack.
9839 LD IY,$C8E5 Use the player's object.
983D CALL AccelerateTowardsTarget Accelerate towards the player.
9840 POP IY Bring IY back off the stack.
9842 LD A,($9BCB) Fetch the first byte of the random seed.
9845 AND %00001111 Keep four bits.
9847 ADD A,$0A Add ten.
9849 LD (IX+$15),A Set the lifetime of the object.
984C RET Return.
