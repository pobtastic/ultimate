83CE: Print Text Repeatedly
Used by the routines at CompletePlanet, DrawHUD and ShowTitleScreen.
Calls PrintText several times with the same text record.
Input
B Number of times to print the text
DE Address of the text record
PrintTextRepeatedly 83CE PUSH BC Save the counter.
83CF CALL PrintText Print the text record.
83D2 POP BC Restore the counter.
83D3 DJNZ PrintTextRepeatedly Decrease the counter by one and loop back to PrintTextRepeatedly until none remain.
83D5 RET Return.
