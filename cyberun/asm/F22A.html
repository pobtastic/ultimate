F22A: Title Frame Parameters
The values that DrawFrame uses to draw the frame of the title screen, which has the same layout as the table at FrameParameters.
TitleFrameParameters F22A DEFW $57C0 Left vertical line
F22C DEFW $57DF Right vertical line
F22E DEFB $B0 Number of rows in the vertical lines
F22F DEFW $56E1 Bottom horizontal lines
F231 DEFW $4601 Top horizontal lines
F233 DEFW $0000 Address of the corner table (set by ShowTitleScreen)
F235 DEFB $06 Number of ticks along each edge
F236 DEFW $0000 Address of the tick table (set by ShowTitleScreen)
F238 DEFB $06 Pixel row of the top edge
F239 DEFB $F8 Pixel column of the right edge
F23A DEFB $1F Length of the horizontal lines, in bytes
