A59F: Draw Sprites Directly
Used by the routines at DrawPiece, RunFrame, DrawShipTop, DrawSideFlames and DrawMainFlame.
Erases one sprite and draws another straight on the screen instead of using a buffer. The rows of the two sprites are dealt with one at a time, alternating between an erased row and a drawn row, so that they stay in step. The sprite that is lower on the screen starts first, as the rows of a sprite go up the screen, and its first rows are done by themselves until the other sprite starts. The sprites are set up by SetSecondRowGroup and SetFirstRowGroup, which store the number of rows at 5C1C and 5C1D. The first sprite is erased using the alternate registers and the second sprite is drawn using the main registers.
Input
DE Address of the data of the second sprite
DE' Address of the data of the first sprite
HL Screen address of the second sprite
HL' Screen address of the first sprite
IX Routine that draws the second sprite
IY Routine that erases the first sprite

A5A3 EXX Switch to the first sprite.

A5A5 LD ($5C28),A Store it as the start of a row.

A5A9 LD A,($5C1D) Fetch the number of rows of the second sprite.
A5AC EX AF,AF' Keep it in the alternate accumulator.
A5AD LD A,($5C1C) Fetch the number of rows of the first sprite.

A5B4 LD A,($5C1D) Fetch the number of rows of the second sprite.
A5B7 AND A Test it.
A5B8 JP Z,DrawSpritesDirectly_Row Jump to DrawSpritesDirectly_Row if the second sprite has no rows.
A5BB LD A,($A289) Fetch the vertical position of the first sprite.
A5BE LD C,A Store it in C.
A5BF LD A,($A28A) Fetch the vertical position of the second sprite.
A5C2 SUB C Subtract the position of the first sprite.
A5C3 JP Z,DrawSpritesDirectly_Row Jump to DrawSpritesDirectly_Row if they start on the same row.
A5C6 JR NC,DrawSpritesDirectly_Second Jump to DrawSpritesDirectly_Second if the second sprite is the lower one.
The first sprite is the lower one, so do its first rows by themselves.
A5C8 NEG Make the difference positive.
A5CA LD C,A Store it in C.
A5CB LD A,($5C1C) Fetch the number of rows of the first sprite.
A5CE SUB C Take off the difference.
A5CF LD ($A289),A Store it for later.
A5D2 JR C,DrawSpritesDirectly_First Jump to DrawSpritesDirectly_First if the first sprite has fewer rows than that.
A5D4 LD A,C Otherwise use the difference as the number of rows to do.
A5D5 LD ($5C1C),A Store it.
DrawSpritesDirectly_First A5D8 XOR A Clear A.
A5D9 EX AF,AF' Make the second sprite have no rows for now.
A5DA CALL DrawSpritesDirectly_Row Do the rows of the first sprite.
A5DD EXX Switch to the second sprite.
A5DE LD A,($A289) Fetch the number of rows that are left for the first sprite.
A5E1 LD ($5C1C),A Store it.
A5E4 LD A,($5C1D) Fetch the number of rows of the second sprite.
A5E7 EX AF,AF' Restore it.
A5E8 JP DrawSpritesDirectly_Row Jump to DrawSpritesDirectly_Row to do the rows of both sprites.
The second sprite is the lower one, so do its first rows by themselves.
DrawSpritesDirectly_Second A5EB LD C,A Store the difference in C.
A5EC LD A,($5C1D) Fetch the number of rows of the second sprite.
A5EF SUB C Take off the difference.
A5F0 LD ($A28A),A Store it for later.

A5F5 LD A,C Otherwise use the difference as the number of rows to do.
A5F6 EX AF,AF' Store it.

A5FA LD ($A289),A Keep it.
A5FD XOR A Clear A.
A5FE LD ($5C1C),A Make the first sprite have no rows for now.
