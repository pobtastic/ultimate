F3BD: Start New Game
Used by the routine at RunGame.
Sets up a new game: the objects on the map are all put back, the state of both players is reset and each player is given five ships. If the players were swapped by the last game they are swapped back, the second player is given no ships in a game with one player, the control devices that were chosen by the menu are copied for the players, the scores are set to zero and the sites of the items are chosen for both players.
