B356: Erase Rows
Used by the routine at DrawShot.
Erases rows from the screen, going up from the row that HL is at, using the same layout as DrawRows but with the number of rows in A1D7. The alternate registers are used.
Input
B' Number of bytes in a row
DE' Address of the buffer
HL' Screen address

B360 LD B,C B=C.
