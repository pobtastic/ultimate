8934: Set Falling Speed
Used by the routine at FireShot.
Gives an object a random speed and then sets its vertical acceleration.
Input
IY Address of the object
SetFallingSpeed 8934 CALL SetRandomSpeed Give the object a random speed.
8937 LD A,(IY+$09) Fetch the vertical speed.
893A AND A Test it.
893B JR Z,SetRandomSpeed_Remove Remove the object if it is zero.

893F AND %00000111 ...and keep three bits.
8941 JR NZ,SetFallingSpeed_Flags Jump to SetFallingSpeed_Flags if any are set.

SetFallingSpeed_Flags 8947 LD (IY+$10),$25 Set the flags of the object to 25.
894B LD A,(IY+$00) Fetch the type of the object.

895B LD A,($F5ED) Fetch the number of ships left from F5ED.

895F ADD A,A
8960 LD ($896E),A ...and restart the timer.
8963 LD (IY+$13),$08 Change the state of the object to 08.
