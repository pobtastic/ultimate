F8E2: Build Shifted Shape A
Used by the routine at BuildShapeTables.
Merges a description of a shape into the buffers, once for each of the three shifts, using the first of the two formats. The description starts with the number of rows and the number of bytes in a row; the rows follow. Each row is merged into the buffer, with the byte that is left over at the end of the row from the shifted bytes, and the buffer moves on 30 bytes after each shift.
Input
HL Address of the description
HL' Address of the buffer for the shifted shape
