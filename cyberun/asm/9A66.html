9A66: Initialise Game
Used by the routine at StartGame.
The game starts here, after StartGame. It sets up the stack, makes the border black, builds the shift tables and then carries on at RunGame.
InitialiseGame 9A66 LD SP,$5B80 Set the stack pointer to 5B80.
9A69 XOR A Set the border to black.
9A6A OUT ($FE),A
9A6C CALL BuildTables Build the shift tables.
9A6F JP RunGame Jump to RunGame.
