9A9A: Play Music Until Key Pressed
Used by the routine at ShowTitleScreen.
Plays a tune made of notes, which ends with FF. The tune stops as soon as a key is pressed.
Input
DE Address of the first note
PlayMusic_WaitKey 9A9A XOR A Select every keyboard row.
9A9B CALL ReadKeyboardPort Read the keyboard.
9A9E RET NZ Return if a key is pressed.
9A9F LD A,(DE) Fetch a note.
9AA0 CP $FF Jump to PlayMusic_Return if it is the end of the tune.
9AA2 JR Z,PlayMusic_Return
9AA4 CALL PlayNote Play the note.
9AA7 JR PlayMusic_WaitKey Jump back to PlayMusic_WaitKey for the next note.
