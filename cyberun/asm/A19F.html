A19F: Fetch Object Frame Table
Used by the routines at UpdateStarLayer, DrawShipTop and FetchSpriteType.
Fetches the entry for the type of an object from the table at FrameTableAddresses.
Input
IX Address of the object
Output
DE The entry
FetchObjectFrameTable A19F LD C,(IX+$00) Fetch the type of the object.
A1A2 LD HL,$AF3D Use the table.
A1A5 CALL GetTableEntry Fetch the entry.
A1A8 EX DE,HL Put it in DE.
A1A9 RET Return.
