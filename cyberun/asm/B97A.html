B97A: Compare Tile Position
Used by the routine at FindTileRecord.
Compares a map column and zone with another.
Input
B Zone
C Column
D Column to compare
E Zone to compare
Output
F The zero flag is set if they are the same
CompareTilePosition B97A LD A,D A=D.
B97B CP C Return if A is not C.
B97C RET NZ
B97D LD A,E A=E.
B97E CP B Compare A with B.
B97F RET Return.
