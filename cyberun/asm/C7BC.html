C7BC: Ship Top Object
The object that is used to draw the top of the ship: its type, its position on the screen, and some flags. The flag at C7BF has bit 7 set when it faces left, and C7C1 is the number of frames for which it is shown as hit. There is a second copy of it that is kept for the other player.
ShipTopObject C7BC DEFB $01
C7BD DEFB $68
C7BE DEFB $61
C7BF DEFB $00
C7C0 DEFB $00
C7C1 DEFB $00
ShipTopObject_Second C7C2 DEFB $01,$68,$61,$00,$00,$00
