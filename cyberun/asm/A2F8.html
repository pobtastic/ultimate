A2F8: Sprite Variables
Variables used by DrawSprites.
SpriteVariables A2F8 DEFB $00 Width of the first sprite in bytes.
A2F9 DEFB $00 Width of the second sprite in bytes.
SpriteVariables_RightEdge A2FA DEFB $00 Set when DrawSprites is to draw sprites that reach beyond the right of the playfield, which makes it take 60 off both horizontal positions.
A2FB DEFB $EF,$AF,$AD,$8D,$89,$09,$08,$00 Masks used to dissolve the second sprite, which are picked by the value at A302.
