BE43: Select Next Tile
Used by the routine at CheckTerrainCollision.
Chooses the next tile for CheckTerrainCollision to check the object against, from the tiles that the object overlaps and the count in TileNumber, then carries on at FindTilesOverlapped.
SelectNextTile BE43 LD A,($5C1D) The tiles still to test.
BE46 CP $01 Jump to SelectNextTile_Column if A is not 01.
BE48 JR NZ,SelectNextTile_Column
BE4A LD A,($5C2A) The object reaches into the next column.
BE4D AND A Jump to SelectNextTile_Column if A is zero.
BE4E JR Z,SelectNextTile_Column
BE50 LD A,($5C2B) The object reaches into the zone above.
BE53 AND A Jump to SelectNextTile_Column if A is zero.
BE54 JR Z,SelectNextTile_Column
BE56 CALL SelectPreviousZone Call SelectPreviousZone.
BE59 CALL SelectNextColumn Call SelectNextColumn.
BE5C LD A,($5C2B) The object reaches into the zone above.
