D2DA: Test Top Row
Used by the routine at DrawTerrain.
Tests the vertical position of the start of a segment of a tile in the top row against the vertical position in B.
Input
B Vertical position to test against
Output
F Zero if the start of the segment is at the position or below it
TestTopRow D2DA LD A,($CE44) The segment row.
D2DD CP B Return if A is less than B.
D2DE RET C
D2DF XOR A Clear A.
D2E0 RET Return.
