F8C2: Fetch Shifted Byte
Finds the second byte of a byte of a shape that has been shifted to the right. The entry point at FetchShiftedByte_Count first sets the byte count to the width of a row and the one at FetchShiftedByte_Byte does not change HL.
Input
C Number of bytes in a row
D Page of the table of shifted bytes
HL Address of the byte to shift
Output
A The second byte of the shifted byte
FetchShiftedByte F8C2 INC HL Advance HL.
This entry point is used by the routine at BuildShiftedShapeA.
FetchShiftedByte_Count F8C3 LD B,C B=C.
This entry point is used by the routines at BuildShiftedShapeA and BuildShiftedShapeB.
FetchShiftedByte_Byte F8C4 LD E,(HL) Read HL into E.
F8C5 INC D Advance D.
F8C6 LD A,(DE) Read DE.
F8C7 DEC D Step D back.
F8C8 RET Return.
