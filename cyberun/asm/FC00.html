FC00: Copy Game Down
Used by the routine at GameEntry.
Used by the loader before the game starts: GameEntry calls this routine to move the encrypted game from 5E80 down to 5C80. The helper at 6000 copies it here from 6022. The routine is in the area of memory where the shift tables are built afterwards, so it is overwritten when the game starts.
CopyGameDown FC00 LD HL,$5E80 Set the source address in HL.
FC03 LD DE,$5C80 Set the destination address in DE.
FC06 LD BC,$9D80 Set the number of bytes to copy in BC.
FC09 LDIR Copy the game down.
FC0B RET Return.
The next four bytes are not used.
FC0C LD SP,$FE00 Set the stack pointer to FE00.
FC0F DI Disable interrupts.
