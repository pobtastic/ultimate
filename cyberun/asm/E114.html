E114: Add Map Objects
Used by the routine at LoadMapObjects.
Puts the objects of one column of the map in free slots of the map objects. An object is skipped if the current player has destroyed it (bit 7 of its byte in the table at MapTable is set, or bit 6 for player two), if it is not on one of the two rows that are on the screen or if there is already a slot for it. It is put in the first free slot of the first three slots, or in the fourth if none of them is free. Its column, row, position and kind are set from the tables. The slot holds the index of the object in offsets 18 and 19 so that the object can be marked as destroyed later.
Input
B Number of objects in the column
C Column
HL Address of the first object in MapTable
IX Address of the first object in TerrainData
