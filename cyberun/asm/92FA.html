92FA: Set Facing
Used by the routines at UpdateObject and UpdateType19.
Sets the first state byte of an object to zero, or one if the object is moving left.
Input
IX Address of the object
SetFacing 92FA LD (IX+$13),$00 Clear the first state byte.
92FE BIT 7,(IX+$07) Test bit 7 of the horizontal speed.
9302 RET Z Return if it is clear.
9303 INC (IX+$13) Set the first state byte to one.
9306 RET Return.
