90A7: Move Object And Stop
Used by the routines at UpdateType1C and UpdateType1D.
Sets HorizontalStepSize to 80 and nudges the object. When the value in ScratchValue is not zero, the object is also marked, stopped and a sound is played.
Input
IX Address of the object
MoveObjectAndStop 90A7 LD A,$80 Set HorizontalStepSize to 80.
90A9 LD ($5C25),A
90AC CALL NudgeObject Nudge the object.
90AF LD A,($5C1C) Fetch the value from ScratchValue.
90B2 AND A Test it.
90B3 JP Z,MoveObject Jump to MoveObject if it is zero.
90B6 SET 3,(IX+$17) Set bit 3 of the second set of flags of the object.
90BA XOR A Clear the speeds of the object.
90BB LD (IX+$07),A
90BE LD (IX+$08),A
90C1 LD (IX+$09),A
90C4 LD (IX+$0A),A
90C7 CALL PlayShortCrashSound Play a sound.
90CA JP MoveObject Jump to MoveObject.
