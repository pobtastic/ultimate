F30B: Clear Bytes
Used by the routines at ResetLife, ResetPlayerState and BuildShapeTables.
Sets a number of bytes of memory to zero.
Input
B Number of bytes
HL Address
Output
HL Address after the last byte
ClearBytes F30B LD (HL),$00 Store 00 at the address in HL.
F30D INC HL Advance HL.
F30E DJNZ ClearBytes Decrease B and jump to ClearBytes until none remain.
F310 RET Return.
