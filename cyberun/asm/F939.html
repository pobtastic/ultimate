F939: Build Shifted Shape B
Used by the routine at BuildShapeTables.
Merges a description of a shape into the buffers, once for each of the three shifts, using the second format. The description starts with the number of strips, the number of rows and the number of bytes in a row. Each row is merged into the buffer next to the chequered background. When the flag at HorizontalStepSize is set the background is merged differently, as the shape is back to front.
Input
HL Address of the description
HL' Address of the buffer for the shifted shape
