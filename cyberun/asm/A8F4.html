A8F4: Check Map Object Collisions
Used by the routine at RunFrame.
Checks whether the ship is touching any of the first four map objects in the slots at MapObjectSlots. When it is, most objects bounce the ship back, but a type 1B object in state four or five fills the fuel gauge, which is held in FuelLevel, and flashes the ship, and is then removed and marked as destroyed in the map table.
