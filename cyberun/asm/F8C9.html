F8C9: Merge Next Shifted Byte
Used by the routines at BuildShiftedShapeA and BuildShiftedShapeB.
Moves on to the next byte of a shape and merges the first byte of the shifted value of the byte that was fetched. The entry point at MergeNextShiftedByte_Merge merges A.
Input
DE Address in the table of shifted bytes
HL Address of the byte of the shape
HL' Address in the buffer
Output
HL Address of the next byte of the shape
MergeNextShiftedByte F8C9 INC HL Advance HL.
F8CA LD A,(DE) Read DE.
This entry point is used by the routine at BuildShiftedShapeB.
MergeNextShiftedByte_Merge F8CB EXX Switch to the alternate registers.
F8CC OR (HL) Set the bits of A that are set in the byte at HL.
F8CD LD (HL),A Write A where HL points.
F8CE EXX Switch to the alternate registers.
F8CF RET Return.
