C8E5: Ship Object
The player's ship. The first 18 bytes have the layout of an enemy slot, as described at EnemySlots, and then there are some extra fields:
Offset Contents
18 Bit 7 is set when the ship is facing left
19-1A Copy of the horizontal speed (offsets 07 and 08) taken at the end of the frame
1B-1C Copy of the vertical speed (offsets 09 and 0A) taken at the end of the frame
1D-1E Horizontal then vertical position at which the ship was last drawn, which is used to erase it
1F What the ship is about to pick up: C0 plus the number of an item to carry, or the number of a part to fit
