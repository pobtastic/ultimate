8FCA: Bounce Ship
Used by the routine at ApplyCollisionEffects.
Bounces the player's ship off an object, by exchanging half of the speed of each of them.
Input
IX Address of the object that was hit
IY Address of the player's object

8FCD LD E,(IY+$1A)
8FD0 LD H,(IX+$07) Fetch the horizontal speed of the object into HL.
8FD3 LD L,(IX+$08)
8FD6 SRA H Halve it.
8FD8 RR L
8FDA CALL NegateNumber Negate it.
8FDD LD (IX+$07),H Store it as the new speed of the object.
8FE0 LD (IX+$08),L

8FE4 LD (IY+$19),H Store the result as the new speed of the player.
