9EE3: Read Pause Keys
Used by the routines at CheckPause and CheckPauseAndSilence.
Tests the SPACE and CAPS SHIFT keys.
Output
F The zero flag is set if either key is pressed
ReadPauseKeys 9EE3 LD A,$7F Select the keyboard row with SPACE.
9EE5 OUT ($FD),A Put the row on the address lines.
9EE7 IN A,($FE) Read the keyboard.
9EE9 AND %00000001 Keep the bit for SPACE.
9EEB RET Z Return if SPACE is pressed.
9EEC LD A,$FE Select the keyboard row with CAPS SHIFT.
9EEE OUT ($FD),A Put the row on the address lines.
9EF0 IN A,($FE) Read the keyboard.
9EF2 AND %00000001 Keep the bit for CAPS SHIFT.
9EF4 RET Return.
