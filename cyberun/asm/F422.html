F422: Run Game
Used by the routines at InitialiseGame and PrepareLife.
Runs the game, starting with the title screen: it makes a new game, draws the screen and the HUD and prints the number of the player. Returns here from PrepareLife when all the ships have gone.
RunGame F422 CALL ShowTitleScreen Call ShowTitleScreen.
