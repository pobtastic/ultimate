838B: Adjust Second Slope Tile
Used by the routine at AdjustTerrainSlope.
Looks at the second tile code of the pair for AdjustTerrainSlope.
Input
C Extra row count
E Direction flag
Output
C Updated extra row count
AdjustTerrainSlope_Second 838B LD A,($5C34) Fetch the second tile code from EndShape.
838E CP $93 Jump to AdjustTerrainSlope_Second93 if it is slope tile 93.
8390 JR Z,AdjustTerrainSlope_Second93
8392 CP $92 Jump to AdjustTerrainSlope_Second92 if it is slope tile 92.
8394 JR Z,AdjustTerrainSlope_Second92
8396 RET Return, as no other tile needs adjusting.
AdjustTerrainSlope_Second92 8397 LD A,E Fetch the direction flag.
8398 AND A Test it.
8399 RET Z Return if it is clear.
839A INC C Add an extra row.
839B RET Return.
AdjustTerrainSlope_Second93 839C LD A,E Fetch the direction flag.
839D AND A Test it.
839E RET NZ Return if it is set.
839F INC C Add an extra row.
83A0 RET Return.
