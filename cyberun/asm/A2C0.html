A2C0: Add Speeds To Position
Adds two speeds to the two coordinates of an object. Nothing in the game refers to this routine.
Input
IX Address of the object
AddSpeedsToPosition A2C0 LD A,(IX+$02) Fetch the first coordinate.
A2C3 LD B,(IX+$05) Fetch the first speed.
A2C6 ADD A,B Add the speed.
A2C7 LD (IX+$02),A Store the coordinate.
A2CA LD A,(IX+$03) Fetch the second coordinate.
A2CD LD B,(IX+$06) Fetch the second speed.
A2D0 ADD A,B Add the speed.
A2D1 LD (IX+$03),A Store the coordinate.
A2D4 RET Return.
