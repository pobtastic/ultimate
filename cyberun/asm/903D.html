903D: Start Explosion
Used by the routine at ExplodePlayerShip.
Turns an object into an explosion (type 15).
Input
IX Address of the object
StartExplosion 903D LD (IX+$00),$15 Set the type of the object to 15.
9041 LD (IX+$13),$50 Set its first state byte to 50.
9045 LD (IX+$14),$05 Set its second state byte to 05.
9049 LD A,($9BCC) Fetch the second byte of the random seed.
904C AND %00000011 Keep two bits.
904E RRCA Rotate them into the top of the byte.
904F RRCA
9050 LD (IX+$15),A Set the lifetime of the object.
9053 OR %00000001 Set bit 0 and return.
9055 RET Return.
