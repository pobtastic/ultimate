A21C: Read Sprite Size
Used by the routine at DrawShipTop.
Reads the width and the number of rows from the header of a sprite.
Input
DE Address of the sprite
Output
B Number of rows
DE Address of the first row of data
H Width in bytes
ReadSpriteSize A21C LD A,(DE) Fetch the width.
A21D LD H,A Store it in H.
A21E INC DE Move on to the number of rows.
A21F LD A,(DE) Fetch it.
A220 LD B,A Store it in B.
A221 INC DE Move on to the data.
A222 RET Return.
