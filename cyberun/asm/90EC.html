90EC: Process Object Flags
Used by the routines at UpdateType14, UpdateType1E and UpdateCrystalStack.
Remembers the address of the object in CurrentObject. If bit 4 of its flags is set the object is removed. Otherwise, bit 3 of the flags is cleared and, if it had been set, the routine returns; if not, the object is drawn and made to accelerate towards the player.
Input
IX Address of the object
ProcessObjectFlags 90EC LD ($AD46),IX Store the address of the object in CurrentObject.
90F0 BIT 4,(IX+$10) Jump to ProcessObjectFlags_Bit3 if bit 4 of the flags of the object is clear.
90F4 JR Z,ProcessObjectFlags_Bit3
90F6 LD (IX+$00),$FF Free the slot.
90FA RET Return.
ProcessObjectFlags_Bit3 90FB BIT 3,(IX+$10) Test bit 3 of the flags of the object.
90FF RES 3,(IX+$10) Clear bit 3.
9103 RET NZ Return if it was set.
9104 CALL PrepareDraw Draw the object.
9107 JP AccelerateTowardsPlayer Make the object accelerate towards the player.
