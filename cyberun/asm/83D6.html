83D6: Complete Planet
Used by the routine at FinishPlanet.
Shows the "planet completed" message and sets up the next planet. The text records at PlanetCompleteText are printed, with the name of the planet just finished and the name of the next planet filled in, then the player is rewarded with a sound and a short delay before new item sites are chosen for the next planet.
Print the first four lines of the message.
CompletePlanet 83D6 LD DE,$84A9 Use the first text record at PlanetCompleteText.
83D9 LD B,$04 Set a counter in B for four records.
83DB CALL PrintTextRepeatedly Print the four text records.
Fill in the name of the planet just completed.
83DE LD A,($F5F9) Fetch the planet number from F5F9.
83E1 ADD A,A Multiply it by sixteen, the length of a name in PlanetNames.
83E2 ADD A,A

83E5 LD HL,$8459 Use the table of planet names and add the offset.
83E8 CALL AddAToHL
83EB LD DE,$8505 Use the planet name slot in the text record at PlanetCompleteText_FirstRecord.
83EE LD C,$10 Set the length of the name in C.
83F0 LDIR Copy the name of the planet just finished into the text record.
Fill in the name of the next planet, wrapping round after the last one.
83F2 LD A,($F5F9) Fetch the planet number again.
