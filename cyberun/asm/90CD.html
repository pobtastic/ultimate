90CD: Reverse Object Speed
Used by the routines at MoveObjectBackAndForth and StartTerrainCheck.
Negates both speeds of an object.
Input
IX Address of the object
ReverseObjectSpeed 90CD LD H,(IX+$07) Fetch the horizontal speed into HL.
90D0 LD L,(IX+$08)
90D3 CALL NegateNumber Negate it.
90D6 LD (IX+$07),H Store the new horizontal speed.
90D9 LD (IX+$08),L
90DC LD H,(IX+$09) Fetch the vertical speed into HL.
90DF LD L,(IX+$0A)
90E2 CALL NegateNumber Negate it.
90E5 LD (IX+$09),H Store the new vertical speed.
90E8 LD (IX+$0A),L
90EB RET Return.
