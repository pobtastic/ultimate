CA1D: Frame Parameters
The values that DrawFrame uses to draw the frame round the playfield. The addresses are screen addresses, and DrawHUD sets up the two tables.
FrameParameters CA1D DEFW $57C0 Left vertical line
CA1F DEFW $57DD Right vertical line
CA21 DEFB $A0 Number of rows in the vertical lines
CA22 DEFW $56E1 Bottom horizontal lines
CA24 DEFW $4641 Top horizontal lines
CA26 DEFW $0000 Address of the corner table (set by DrawHUD)
CA28 DEFB $06 Number of ticks along each edge
CA29 DEFW $0000 Address of the tick table (set by DrawHUD)
CA2B DEFB $16 Pixel row of the top edge
CA2C DEFB $E8 Pixel column of the right edge
CA2D DEFB $1C Length of the horizontal lines, in bytes
FrameParameters_Second CA2E DEFB $14,$02,$47 Attribute area for the panel behind the text
