8820: Fire Shot When Hit
Used by the routine at UpdateMapObjects.
Occasionally fires a shot from an object that has been hit.
Input
IX Address of the object
FireShotWhenHit 8820 LD A,($9BCB) Fetch the first byte of the random seed.
8823 AND %01011010 Keep only some of the bits.
8825 RET NZ Return if any are set.
8826 BIT 7,(IX+$10) Test bit 7 of the flags of the object.
882A RET Z Return if it is clear.
Continue on to FireShot.
