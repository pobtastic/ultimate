AD1B: Draw Object
Used by the routines at UpdateObject, UpdateType14, UpdateCrystalStack and UpdateMapObjects.
Draws the sprite that was set up for an object by PrepareDraw, unless both the width in A1D7 and the number of rows in A1D8 are zero.
DrawObject AD1B LD A,($A1D7) The rows of the first sprite.
AD1E LD C,A C=A.
AD1F LD A,($A1D8) The rows of the second sprite.
AD22 OR C Set the bits of A that are set in C.
AD23 RET Z Return if the zero flag is set.
AD24 JP DrawSprites Jump to DrawSprites.
