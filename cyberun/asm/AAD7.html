AAD7: Check Item Pickup
Used by the routine at UpdateMapObjects.
Checks whether the ship can pick up an object. A type 1E object can only be picked up when its item number is the one that is wanted at F602; objects with an item number of 0A can never be picked up. CheckItemPickup_Touch does the pick up if the ship is touching the object.
