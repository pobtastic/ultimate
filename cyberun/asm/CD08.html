CD08: Set Up Segment
Used by the routine at DrawTerrain.
Sets up the variables for a segment of the tile, whose type is at offset 03 of the segment record. When the tile is drawn upside down the type is first changed with the table at FlipTypeTable. SetSlopeParameters then loads the three steps of the type. The routine stores a vertical step of 04 if the type has none (and so is flat), and stores the absolute values of the column and horizontal steps in ColumnStepSize and HorizontalStepSize. If the tile is upside down it moves the pixel position of a vertical segment sideways.
