9D0E: Check Beam Hit
Used by the routine at UpdateBeams.
Checks whether the ship is touching a beam, and if so hurts it.
CheckBeamHit 9D0E LD A,($96AB) Fetch the delivery flag from 96AB.
9D11 AND A Test it.
9D12 RET NZ Return if it is set.
9D13 LD E,$01 Set the height of the beam to one pixel.
9D15 CALL TestBoxAgainstShip Test whether the beam touches the hit box of the ship.
9D18 LD A,($5C1C) Fetch the result of the test.
9D1B AND A Test it.
9D1C RET Z Return if the beam missed.
9D1D LD A,$10 Wait 10 frames before the beam can hurt the ship again.
9D1F LD ($9D2F),A Store the delay.
9D22 JP DamageShip_Hit Damage the ship.
