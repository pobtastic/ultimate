A6E1: Erase Shifted Row In Buffer
Erases one row of a sprite that is not aligned to a byte from the buffer used by DrawSprites, using the shift table that B points to. Each byte of the sprite makes two bytes in the buffer. The entry point depends on the width of the sprite in bytes, from five bytes at EraseShiftedRowInBuffer to one byte at A719.
Input
B High byte of the shift table
DE' Address of the data of the sprite
HL' Address in the buffer
EraseShiftedRowInBuffer A6E1 LD A,(DE) Fetch a byte of the sprite.
A6E2 LD C,A Use it to look up the left part in the shift table.
A6E3 LD A,(BC) Fetch the left part.
A6E4 CPL Invert it.
A6E5 AND (HL) Clear the pixels of the buffer.
A6E6 LD (HL),A Store the byte.
A6E7 INC B Move to the table of right parts.
A6E8 INC L Move on to the next byte of the buffer.
A6E9 LD A,(BC) Fetch the right part.
