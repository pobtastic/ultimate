D0AC: Segment Codes
A code for each of the sixteen types of segment, which DrawTerrain stores at offset 04 of the record that it makes for the segment (the first four bytes are the position and size). Purpose not yet known.
SegmentCodes D0AC DEFB $04,$01,$02,$03,$41,$42,$43,$08,$81,$82,$83,$C1,$C2,$C3,$10,$20
