C7B1: Test Direction
Used by the routine at DrawShipTop.
Tests the flag at C7BF, which has bit 7 set when the object is facing left. If it is not, L is increased, B is made F9 and the zero flag is set.
Input
L Horizontal position
Output
A Zero if not facing left
B F9 if not facing left
F The zero flag is set if the object is not facing left
TestDirection C7B1 LD A,($C7BF) The ship top faces left.
C7B4 BIT 7,A Return if bit 7 of A is set.
C7B6 RET NZ
C7B7 LD B,$F9 B=F9.
C7B9 INC L Advance L.
C7BA XOR A Clear A.
C7BB RET Return.
