A234: Select Erase Sprite
Used by the routines at PrepareErase and UpdateStarLayer.
Sets up the first sprite, which is the sprite that is erased by DrawSprites.
Input
B Number of rows
C Index of the routine that erases the sprite
H Width in bytes
Output
B High byte of the shift table to use
IY Address of the routine that erases the sprite
SelectEraseSprite A234 LD A,B Fetch the number of rows.
A235 LD ($A1D7),A Store it.
A238 LD A,H Fetch the width.
A239 LD ($5C28),A Store it.
A23C LD HL,$A294 Use the table of routines that erase sprites.
A23F CALL GetTableEntry Fetch the address of the routine.
A242 PUSH HL Put it in IY.
A243 POP IY
A245 JR SelectEraseSprite_Position Jump to SelectEraseSprite_Position.
