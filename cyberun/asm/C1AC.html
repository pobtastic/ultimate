C1AC: Create Ship Piece
Used by the routine at CheckItemDelivery.
Makes an object of type 0C in a slot, with the state in B and a position that is held in four bytes: the map column, the map zone, the horizontal position and the vertical position.
Input
B State of the object
HL Address of the position
IX Address of the slot
