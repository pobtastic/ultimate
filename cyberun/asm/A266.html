A266: Set Second Row Group
Used by the routine at DrawShipTop.
Sets up the counters that are used by DrawSpritesDirectly for the second sprite, and finds the screen address of the sprite. Purpose not yet known.
Input
B Number of rows
H Width in bytes
Output
HL Screen address
SetSecondRowGroup A266 LD A,($BF84) Fetch the vertical position from BF84.
A269 LD ($A28A),A Store it.
A26C LD A,B Fetch the number of rows.
A26D LD ($5C1D),A Store it.
A270 LD A,H Fetch the width.
A271 LD ($5C29),A Store it.
A274 LD HL,($BF83) Fetch the position.
A277 JP GetScreenAddress Find the screen address.
