B312: Ship Acceleration Table
The amounts that UpdateShipSpeeds adds to the speeds of the ship, which are signed numbers with the fraction in the bottom byte.
ShipAccelerationTable B312 DEFW $FFC0 Vertical, when not going up
B314 DEFW $0050 Vertical, when going up
B316 DEFW $FFC0 Horizontal, for the right key
B318 DEFW $0040 Horizontal, for the left key
B31A DEFW $0000 Horizontal drag, when not moving
B31C DEFW $FFF4 Horizontal drag, one way
B31E DEFW $000C Horizontal drag, the other way
