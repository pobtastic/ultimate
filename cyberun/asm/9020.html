9020: Add Ship
Used by the routine at ApplyCollisionEffects.
Gives the player an extra ship, up to a maximum of ten.
AddShip 9020 LD A,($F5ED) Fetch the number of ships from F5ED.
9023 INC A Add one.
9024 CP $0A Is it ten?
9026 RET Z Return if so.
9027 LD ($F5ED),A Store the new number of ships.
902A CALL PlayHitSound Play the explosion sound.
902D JP PrintShipsRemaining Show the number of ships.
