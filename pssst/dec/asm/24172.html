24172: Robbie State
Robbie is the first of the objects which are updated in each pass.

State_Robbie_Colour 24175 DEFB 0 Colour attribute.
State_Robbie_Flags 24176 DEFB 0 Flags: bit 0 is set when Robbie faces left, bit 2 is set while he cannot pick up an item and bit 3 is set when he has just picked up a can.
24177 DEFB 0 Not used.
