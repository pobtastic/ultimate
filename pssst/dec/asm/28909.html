28909: Frame Update
Used by the routine at MainLoop_NewPass.
Called from the main loop when a new frame has started. It does a "fast pass" over the first four objects (Robbie, the spray can and the two weapons) so that they are updated once per frame, and then returns to the slow pass. It does this by changing the code at 28988 so that the pass ends after the weapons, and at 29007 so that the end of the pass jumps to ResetModifiedInFrame, and then running the main loop from MainLoop.
