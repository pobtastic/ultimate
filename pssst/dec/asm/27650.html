27650: Grow Smoke Bomb
Used by the routine at UpdateSmokeBomb.
Moves a smoke bomb onto the next size of cloud, up to type 6.
Input
IX Smoke bomb object
GrowSmokeBomb 27650 LD A,(IX+0) A=the state of the bomb.
27653 AND %00111111 Keep only bits 0-5 (the type).
27655 CP 6 Compare the type with 6 (the largest cloud).
27657 RET NC Return if the bomb is already the largest cloud.
27658 INC (IX+0) Increment the state of the bomb by one.
27661 RET Return.
