26254: Start Flower Bloom
Used by the routine at UpdateFlower.
The flower has grown to the top of the play area. This turns the flower into a blooming flower, then removes every other object (Robbie, the spray can, the weapons, the leaves, the bugs and the explosion).
Input
IX Flower object
StartFlowerBloom 26254 LD (IX+0),19 Write 19 (the flower in bloom) to IX+0.
26258 LD (IX+4),0 Write 0 to IX+4 (the first stage of blooming).
26262 LD B,4 Set the object counter to 4.
26264 LD HL,24172 HL=State_Robbie_Active (Robbie, the spray can and the weapons).
26267 CALL SetObjectInactive Set the objects inactive using SetObjectInactive.
26270 LD B,11 Set the object counter to 11.
26272 LD HL,24212 HL=Leaf_1_State (the leaves, the bugs and the explosion).
26275 JP SetObjectInactive Jump to SetObjectInactive to set the objects inactive (which returns to the caller).
