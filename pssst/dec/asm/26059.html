26059: Stun Bug
Used by the routines at LeechWeaponHit, MidgesWeaponHit and SlugWeaponHit.
Stuns a bug for 16 updates and plays the sound for a weapon hit.
Input
IX Bug object
StunBug 26059 SET 2,(IX+4) Set bit 2 of IX+4 (stunned).
26063 LD (IX+5),16 Write 16 to IX+5 (the stun timer).
26067 JP PlayRepellentHitSound Jump to PlayRepellentHitSound (which returns to the caller).
