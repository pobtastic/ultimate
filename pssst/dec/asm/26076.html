26076: Explode Bug
Used by the routines at ExplodeRobbie and SlugWeaponHit.
Turns a bug into an explosion. The state of the bug is kept in IX+6 so that the object can be put back to how it was once the explosion has finished (see AnimateExplosion), and the explosion sound plays.
Input
IX Bug object
ExplodeBug 26076 LD A,(IX+0) A=the state of the bug.
26079 LD (IX+5),0 Write 0 to IX+5 (the speed of the animation, which is the fastest).
This entry point is used by the routine at StartExplosion.
ExplodeBug_RememberState 26083 LD (IX+6),A Remember the old state in IX+6.
26086 LD (IX+0),20 Write 20 (an explosion) to IX+0.
26090 LD (IX+4),0 Write 0 to IX+4 (the first frame of the animation).
26094 JP PlayExplosionSound Jump to PlayExplosionSound to play the explosion sound (which returns to the caller).
