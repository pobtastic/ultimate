26524: Start Eating Flower
Used by the routines at UpdateLeech, UpdateMidges and UpdateSlug.
A bug has reached the flower and starts eating it. The flag in bit 3 of IX+4 marks that the bug is eating, IX+5 is set to a random number and IX+6 remembers the Y position of the bug (see EatFlower).
Input
IX Bug object
StartEatingFlower 26524 LD A,R A=the refresh register (a random number).
26526 LD (IX+5),A Write it to IX+5.
26529 LD A,(IX+2) A=the Y position of the bug.
26532 LD (IX+6),A Write it to IX+6.
26535 SET 3,(IX+4) Set bit 3 of IX+4 (eating the flower).
26539 JP DrawObject Jump to DrawObject to draw the bug.
