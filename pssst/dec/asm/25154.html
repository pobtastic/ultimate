25154: Flash First Menu Line
Used by the routine at Game_Restart.
Sets the FLASH attribute for the first of two menu lines and resets it for the second.
Input
HL Pointer to the attribute byte of the first line
Output
HL Pointer to the attribute byte after the second line
MenuAttributeSetFirst 25154 SET 7,(HL) Set the FLASH attribute for the first selection.
25156 INC HL Move onto the next menu attribute.
25157 RES 7,(HL) Unset the FLASH attribute for the second selection.
25159 INC HL Move onto the next menu selection attribute.
25160 RET Return.
