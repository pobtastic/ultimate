27731: Update Leaf
Updates a leaf of the flower. A new leaf grows through four frames (one every eight updates), an eaten leaf shrinks back through them (one every four updates) and is then removed. A leaf is eaten if the flower sinks down to the level of the leaf, or when a bug touches it (see LeafCollision).
Input
IX Leaf object
The object fields used are:
Field Use
+0 bit 6 The leaf is on the left of the flower
+4 The leaf is growing or shrinking
+5 The leaf is being eaten (shrinking)
+6 The frame of the leaf (0 to 3)
UpdateLeaf 27731 CALL StoreEntity Remember the position and state using StoreEntity.
27734 LD A,(24206) A=the Y position of the flower.
27737 CP (IX+2) Compare it with the Y position of the leaf.
27740 JR C,UpdateLeaf_Animate Jump to UpdateLeaf_Animate if the flower is above the leaf.
27742 LD (IX+5),1 Write 1 to IX+5 (the leaf is being eaten).
27746 LD (IX+4),1 Write 1 to IX+4 (the leaf is animating).
UpdateLeaf_Animate 27750 LD A,(IX+4) Jump to UpdateLeaf_Static if the leaf is not animating.
27753 AND A
27754 JR Z,UpdateLeaf_Static
27756 LD A,(IX+5) Jump to UpdateLeaf_Eaten if the leaf is being eaten.
27759 AND A
27760 JR NZ,UpdateLeaf_Eaten
The leaf is growing, which is done every eighth update.
27762 LD A,(24087) A=GameTimer.

27766 AND %00000111 Keep only bits 0-2.
27768 JR NZ,UpdateLeaf_Static Jump to UpdateLeaf_Static if it is not time for the next frame.

UpdateLeaf_Draw 27791 CALL GetLeafSprite Get the sprite of the new frame using GetLeafSprite.

UpdateLeaf_Eaten 27804 LD A,(24087) A=GameTimer.
27807 AND %00000011 Keep only bits 0-1.
27809 JR NZ,UpdateLeaf_Static Jump to UpdateLeaf_Static if it is not time for the next frame.
27811 CALL GetLeafSprite Get the sprite of the current frame using GetLeafSprite.
27814 CALL SetUpPreviousSprite_Address Set up the previous sprite using SetUpPreviousSprite_Address.

27818 DEC (IX+6) Decrease the frame in IX+6 by one.

27833 LD HL,24208 HL=State_Flower_Leaves (the number of leaves on the flower).
