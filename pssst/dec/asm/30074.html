30074: Find Object Sprite
Used by the routine at SetUpPreviousSprite.
Finds the graphic for the current state of an object. This is the same as PrepareOldSprite except that the X position and state are taken from the object.
Input
IX Object
Output
DE Address of the sprite
ActorMoveSprite 30074 LD A,(IX+1) A=the object's X position.
30077 AND %00000110 Keep only bits 1-2.
30079 LD C,A Keep the X position bits in C.
30080 LD A,(IX+0) A=the object's state.
30083 JR ActorGetSpriteAddress Jump to ActorGetSpriteAddress.
