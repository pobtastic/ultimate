28886: Set Objects Inactive
Used by the routines at ResetFlowerLeaf, PlayerTurnEnds, StartFlowerBloom and LevelComplete.
Writes 0 to the state of a number of objects, which makes them inactive.
Input
B Loop counter
HL Object to be updated
SetObjectInactive 28886 LD DE,8 DE=8 (the size of an object).
SetObjectInactive_Loop 28889 LD (HL),0 Set the state of the object to inactive.
28891 ADD HL,DE Move onto the next object.
28892 DJNZ SetObjectInactive_Loop Decrease the object counter by one and loop back to SetObjectInactive_Loop until all of the objects have been made inactive.
28894 RET Return.
