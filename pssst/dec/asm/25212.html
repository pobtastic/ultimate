25212: Game Select Attribute Table
One attribute byte per menu line. The routines that flash the selected line set or clear FLASH in the byte for the line being updated. The first byte belongs to the title, so the flashing code starts at GameSelection_Attributes_Options.
Byte(n) Menu Item
1 Game Selection
2 1 Player Game
3 2 Player Game
4 Keyboard
5 Kempston Joystick
6 Start Game
GameSelection_Attributes 25212 DEFB 71 Attribute for "GAME SELECTION": INK:WHITE, PAPER:BLACK (BRIGHT).
GameSelection_Attributes_Options 25213 DEFB 71 Attributes for "1 PLAYER GAME" and "2 PLAYER GAME".
25214 DEFB 71
25215 DEFB 71 Attributes for "KEYBOARD" and "KEMPSTON JOYSTICK".
25216 DEFB 71
25217 DEFB 71 Attribute for "START GAME": INK:WHITE, PAPER:BLACK (BRIGHT).
