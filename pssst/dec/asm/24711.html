24711: Play Area Strings
Strings used by DrawPlayArea. Each is an attribute byte followed by UDG IDs (see UDG_Brick), where the last UDG ID has bit 7 set to mark the end of the string.
Message_Bricks_LR 24711 DEFB 122 A brick wall string: INK:RED, PAPER:WHITE (BRIGHT), one brick (UDG ID 0 with bit 7 set).
24712 DEFB 128
Message_Bricks_Cubby 24713 DEFB 122 A cubby hole shelf string: INK:RED, PAPER:WHITE (BRIGHT), three bricks (UDG ID 0 with bit 7 set on the last).
24714 DEFB 0
24715 DEFB 0
24716 DEFB 128
Message_Floor 24717 DEFB 50 A floor tile string: INK:RED, PAPER:YELLOW, UDG ID 1 and UDG ID 2 (with bit 7 set).
24718 DEFB 1
24719 DEFB 130
