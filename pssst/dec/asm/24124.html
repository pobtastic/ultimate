24124: Bonus Item State
The bonus item, which sits in a cubby hole until Robbie collects it (see SpawnBonusItem and UpdateBonusItem). It is an object which is not in the main table.
State_BonusItem 24124 DEFB 52 State: 0 when there is no bonus item, or the type 11 12 or 13.
24125 DEFB 50 X position (8 or 232).
24126 DEFB 52 Y position.
24127 DEFB 14 Colour attribute (it flashes).
24128 DEFB 0 What the cubby hole contains while the bonus item is waiting (255).
24129 DEFB 0 The number of the cubby hole.
24130 DEFB 128 Not used.
