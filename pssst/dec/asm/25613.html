25613: Note Table
The pitch and the duration for each of the eight notes of a scale, which are used as the inputs for the ROM BEEPER routine. The pitch is multiplied by four by PlayMusic and, as the pitch gets higher, the duration gets longer so that every note lasts for about the same time.
