27185: Remove Streamer
Used by the routine at UpdateStreamer.
Erases a streamer, which could be using either of the two sprites, and makes the object inactive.
Input
IX Streamer object
RemoveStreamer 27185 LD DE,31121 DE=Sprite_Streamer_1 (the first sprite).
27188 CALL RemoveEntity_Address Erase the sprite using RemoveEntity_Address.
27191 LD DE,31138 DE=Sprite_Streamer_2 (the second sprite).
