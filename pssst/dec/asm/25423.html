25423: Run Main Loop
Used by the routines at SpawnBonusItem and UpdateBonusItem.
The main game loop. The objects from State_Robbie_Active onwards are 8 bytes each, and the loop calls the update routine for the type of each object in turn (see JumpTable_Main). Every update routine returns to NewActor, which moves on to the next object.
A pass starts here with the flower object at State_Flower and carries on up to the last object (the explosion at State_Explosion), then the next pass is started here again. Whenever the frame counter has changed, FrameUpdate is called to update the first four objects (Robbie, the spray can and the two weapons) once. This means that these are updated on every frame no matter how long a pass through the other objects takes.
