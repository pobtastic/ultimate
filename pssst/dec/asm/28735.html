28735: Release Item Lock
Used by the routine at CheckCubbyHole.
Used when Robbie is not level with a cubby hole: if he is empty-handed then he is allowed to pick up or drop an item again.
Input
IX Robbie object
Output
E 0
ReleaseItemLock 28735 LD A,(IX+0) A=the state of Robbie.
28738 DEC A Decrease the state by one (zero if Robbie is empty-handed).
28739 RET NZ Return if Robbie is carrying a can.
28740 RES 2,(IX+4) Reset bit 2 of IX+4 (Robbie can pick up and drop a can again).
28744 RET Return.
