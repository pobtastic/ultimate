24075: Temporary Sprite State
The saved position and state of the object which is being drawn, and the details of the sprites being drawn. The object position and state are saved by StoreEntity and the sprite details are set by SetUpPreviousSprite and SetUpSprite_Address. NewSprite_Width is also used as a dummy object when drawing the items in the cubby holes, so that ColouriseSprite can fetch the colour from 24082.
Actor 24075 DEFB 51 Saved X position of the object.
24076 DEFB 14 Saved Y position of the object.
24077 DEFB 0 Saved state of the object.
24078 DEFB 0 Height of the new sprite in pixel rows (set by SetUpSprite_Address).
NewSprite_Width 24079 DEFB 13 Width of the new sprite in bytes (set by SetUpSprite_Address).
24080 DEFB 0 Rows of the previous sprite still to be erased.
24081 DEFB 0 Rows of the new sprite still to be drawn.
24082 DEFB 44 Colour attribute of the cubby hole item being drawn (set by DrawCubbyHoleItem).
