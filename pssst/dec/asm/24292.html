24292: Explosion State
The explosion, which is the last of the objects (see AnimateExplosion). It is state 21 (which does nothing) until an object explodes.
State_Explosion 24292 DEFB 219 State: 21 inactive or 20 exploding.
24293 DEFB 31 X position.
24294 DEFB 118 Y position.
24295 DEFB 27 Colour attribute.
24296 DEFB 3 The frame of the explosion.
24297 DEFB 19 The mask which sets the speed of the explosion.
24298 DEFB 0 The state of the object which exploded, so that it can be put back.
24299 DEFB 62 Not used.
