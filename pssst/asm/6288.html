6288: Messaging: Game Selection Screen Text
The text of each menu line. There is no attribute byte as that comes from GameSelection_Attributes, and the last character of each string has bit 7 set.
GameSelection_Text 6288 DEFM "GAME SELECTIO","N"+$80 "GAME SELECTION".
6296 DEFM "1 1 PLAYER GAM","E"+$80 "1 1 PLAYER GAME".
62A7 DEFM "2 2 PLAYER GAM","E"+$80 "2 2 PLAYER GAME".
62B8 DEFM "3 KEYBOAR","D"+$80 "3 KEYBOARD".
62C4 DEFM "4 KEMPSTON JOYSTIC","K"+$80 "4 KEMPSTON JOYSTICK".
62D9 DEFM "5 START GAM","E"+$80 "5 START GAME".
