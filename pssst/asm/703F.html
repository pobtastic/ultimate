703F: Release Item Lock
Used by the routine at CheckCubbyHole.
Used when Robbie is not level with a cubby hole: if he is empty-handed then he is allowed to pick up or drop an item again.
Input
IX Robbie object
Output
E 00
ReleaseItemLock 703F LD A,(IX+$00) A=the state of Robbie.
7042 DEC A Decrease the state by one (zero if Robbie is empty-handed).
7043 RET NZ Return if Robbie is carrying a can.
7044 RES 2,(IX+$04) Reset bit 2 of IX+04 (Robbie can pick up and drop a can again).
7048 RET Return.
