65DC: Explode Bug
Used by the routines at ExplodeRobbie and SlugWeaponHit.
Turns a bug into an explosion. The state of the bug is kept in IX+06 so that the object can be put back to how it was once the explosion has finished (see AnimateExplosion), and the explosion sound plays.
Input
IX Bug object
ExplodeBug 65DC LD A,(IX+$00) A=the state of the bug.
65DF LD (IX+$05),$00 Write 00 to IX+05 (the speed of the animation, which is the fastest).
This entry point is used by the routine at StartExplosion.
ExplodeBug_RememberState 65E3 LD (IX+$06),A Remember the old state in IX+06.
65E6 LD (IX+$00),$14 Write 14 (an explosion) to IX+00.
65EA LD (IX+$04),$00 Write 00 to IX+04 (the first frame of the animation).
65EE JP PlayExplosionSound Jump to PlayExplosionSound to play the explosion sound (which returns to the caller).
