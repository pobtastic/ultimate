6077: Print String Rows
Used by the routines at DrawCubbyHoleShelves and DrawPlayArea.
Prints the same string on a number of consecutive character rows, so that a UDG is repeated down the screen.
Input
B Number of rows
DE Pointer to string data
HL Screen position of the first row
Output
HL Screen position of the row below the last one printed
PrintString_Wrapper 6077 PUSH HL Stash HL, DE and BC on the stack.
6078 PUSH DE
6079 PUSH BC
607A CALL PrintStringColour Print the string using PrintStringColour.
607D POP BC Restore BC, DE and HL from the stack.
607E POP DE
607F POP HL
6080 LD A,H Move down 08 pixels onto the next row.
6081 ADD A,$08
6083 LD H,A
6084 DJNZ PrintString_Wrapper Decrease the row counter by one and loop back to PrintString_Wrapper until all of the rows have been printed.
6086 RET Return.
