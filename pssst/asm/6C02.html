6C02: Grow Smoke Bomb
Used by the routine at UpdateSmokeBomb.
Moves a smoke bomb onto the next size of cloud, up to type 06.
Input
IX Smoke bomb object
GrowSmokeBomb 6C02 LD A,(IX+$00) A=the state of the bomb.
6C05 AND %00111111 Keep only bits 0-5 (the type).
6C07 CP $06 Compare the type with 06 (the largest cloud).
6C09 RET NC Return if the bomb is already the largest cloud.
6C0A INC (IX+$00) Increment the state of the bomb by one.
6C0D RET Return.
