5E94: Leaf Data
The four leaves of the flower (see UpdateLeaf). Each leaf is an object of eight bytes. Bit 6 of the state is set when the leaf is on the left of the flower. The other fields are the position, the colour, a flag which is set while the leaf is animating, a flag which is set once it is being eaten, and the frame.
Leaf 1 data.
Leaf_1_State 5E94 DEFB $00 Leaf "1" state.
Value State
00 Inactive
11 Right-hand side
51 Left-hand side
Leaf_1_Pos_X 5E95 DEFB $00 Leaf "1" X position in pixels.
Leaf_1_Pos_Y 5E96 DEFB $00 Leaf "1" Y position in pixels.
Leaf_1_Colour 5E97 DEFB $00 Leaf "1" colour attribute.
Leaf_1_Animating 5E98 DEFB $00 Leaf "1" animating flag (01 while it is growing or shrinking).
Leaf_1_Eaten 5E99 DEFB $00 Leaf "1" eaten flag (01 once the leaf is being eaten).
Leaf_1_Frame 5E9A DEFB $00 Leaf "1" frame ID.
