5B80: Game Entry Point
Moves the whole game image down by one byte, then jumps to the security check. The 2114 bytes from 5EED up to the end of the game at 7FFF are copied to 5EEC onwards.
GameEntry 5B80 DI Disable interrupts.
5B81 LD HL,$5EED Copy 2114 bytes of the game from 5EED to 5EEC.
5B84 LD DE,$5EEC
5B87 LD BC,$2114
5B8A LDIR
5B8C JP SecurityCheck Jump to SecurityCheck.
