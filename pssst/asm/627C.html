627C: Game Select Attribute Table
One attribute byte per menu line. The routines that flash the selected line set or clear FLASH in the byte for the line being updated. The first byte belongs to the title, so the flashing code starts at GameSelection_Attributes_Options.
Byte(n) Menu Item
01 Game Selection
02 1 Player Game
03 2 Player Game
04 Keyboard
05 Kempston Joystick
06 Start Game
GameSelection_Attributes 627C DEFB $47 Attribute for "GAME SELECTION": INK:WHITE, PAPER:BLACK (BRIGHT).
GameSelection_Attributes_Options 627D DEFB $47 Attributes for "1 PLAYER GAME" and "2 PLAYER GAME".
627E DEFB $47
627F DEFB $47 Attributes for "KEYBOARD" and "KEMPSTON JOYSTICK".
6280 DEFB $47
6281 DEFB $47 Attribute for "START GAME": INK:WHITE, PAPER:BLACK (BRIGHT).
