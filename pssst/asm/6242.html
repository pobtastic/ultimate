6242: Flash First Menu Line
Used by the routine at Game_Restart.
Sets the FLASH attribute for the first of two menu lines and resets it for the second.
Input
HL Pointer to the attribute byte of the first line
Output
HL Pointer to the attribute byte after the second line
MenuAttributeSetFirst 6242 SET 7,(HL) Set the FLASH attribute for the first selection.
6244 INC HL Move onto the next menu attribute.
6245 RES 7,(HL) Unset the FLASH attribute for the second selection.
6247 INC HL Move onto the next menu selection attribute.
6248 RET Return.
