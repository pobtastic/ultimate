70D1: Set Leaves Bugs And Explosion Inactive
Sets the leaves, the bugs and the explosion objects to inactive. Nothing calls this entry point; the game uses SetObjectInactive directly.
Reset 70D1 LD HL,$5E94 HL=Leaf_1_State.
70D4 LD B,$0B Set the object counter to 0B.
