6D0C: Update Flower
Updates the flower. Nothing happens until Robbie is active and the "get ready" delay has finished. The number of bugs which were eating the flower in the last pass of the main loop is in BugsEating_Flower (which is reset here once it has been read), and the flower then does one of three things each time the timer in IX+05 runs out:
  • grows by one pixel if no bugs are eating it, and the time until the next step is 20 minus four times the number of leaves (see UpdateFlower_Grow);
  • stays where it is if one bug is eating it;
  • sinks by one pixel if more than one bug is eating it (see SinkFlower).
Every time the flower reaches a multiple of sixteen pixels in height, a new leaf is grown using GrowLeaf. If the flower reaches the top it blooms using StartFlowerBloom.
Input
IX Flower object
The object fields used are:
Field Use
+4 The number of leaves on the flower
+5 The timer until the flower next moves
+6 The number of bugs that were eating the flower last time

6D32 LD A,($5E3B) A=the number of bugs eating the flower from BugsEating_Flower.

UpdateFlower_Grow 6D3E DEC (IX+$02) Decrease the Y position of the flower by one.

6D4C JP C,StartFlowerBloom
6D4F LD A,$20 A=20.
