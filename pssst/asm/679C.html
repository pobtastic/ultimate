679C: Start Eating Flower
Used by the routines at UpdateLeech, UpdateMidges and UpdateSlug.
A bug has reached the flower and starts eating it. The flag in bit 3 of IX+04 marks that the bug is eating, IX+05 is set to a random number and IX+06 remembers the Y position of the bug (see EatFlower).
Input
IX Bug object
StartEatingFlower 679C LD A,R A=the refresh register (a random number).
679E LD (IX+$05),A Write it to IX+05.
67A1 LD A,(IX+$02) A=the Y position of the bug.
67A4 LD (IX+$06),A Write it to IX+06.
67A7 SET 3,(IX+$04) Set bit 3 of IX+04 (eating the flower).
67AB JP DrawObject Jump to DrawObject to draw the bug.
