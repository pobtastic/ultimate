5E0B: Temporary Sprite State
The saved position and state of the object which is being drawn, and the details of the sprites being drawn. The object position and state are saved by StoreEntity and the sprite details are set by SetUpPreviousSprite and SetUpSprite_Address. NewSprite_Width is also used as a dummy object when drawing the items in the cubby holes, so that ColouriseSprite can fetch the colour from 5E12.
Actor 5E0B DEFB $33 Saved X position of the object.
5E0C DEFB $0E Saved Y position of the object.
5E0D DEFB $00 Saved state of the object.
5E0E DEFB $00 Height of the new sprite in pixel rows (set by SetUpSprite_Address).
NewSprite_Width 5E0F DEFB $0D Width of the new sprite in bytes (set by SetUpSprite_Address).
5E10 DEFB $00 Rows of the previous sprite still to be erased.
5E11 DEFB $00 Rows of the new sprite still to be drawn.
5E12 DEFB $2C Colour attribute of the cubby hole item being drawn (set by DrawCubbyHoleItem).
