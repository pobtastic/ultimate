75B9: Store Entity
Used by the routines at UpdateBugCommon, AnimateExplosion, UpdateBloomingFlower, UpdateRepellentSpray, UpdateStreamer, UpdateSmokeBomb, UpdateLeaf, UpdateFlower, GamePlayEntry, UpdateSprayCan, Robbie_CarryingCan and UpdateBonusItem.
Saves the position and state of an object, so that its sprite can be erased from the old position when it is next drawn.
Input
IX Object
StoreEntity 75B9 LD A,(IX+$01) Save the object's X position in Actor.
75BC LD ($5E0B),A
75BF LD A,(IX+$02) Save the object's Y position in 5E0C.
75C2 LD ($5E0C),A
75C5 LD A,(IX+$00) Save the object's state in 5E0D.
75C8 LD ($5E0D),A
75CB RET Return.
