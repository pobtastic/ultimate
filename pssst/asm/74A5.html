74A5: Set Up Previous Sprite
Used by the routine at DrawSprite.
Sprites are drawn by erasing the previous image and drawing the new one at the same time, a row at a time. The routines from here to DisplayEntity_Compare prepare the two images: the main registers hold one sprite and the shadow registers hold the other. Each is set up with the screen address in HL, the sprite width in B, a row count of zero in C and the sprite data pointer in DE.
This entry point finds the previous sprite from the temporary actor state at Actor, using PrepareOldSprite to get its graphic.
SetUpPreviousSprite 74A5 CALL PrepareOldSprite Call PrepareOldSprite.
This entry point is used by the routines at UpdateBloomingFlower, UpdateStreamer, UpdateLeaf and DrawSprite.
Sets up the previous sprite using the sprite data address in DE, rather than looking it up.
SetUpPreviousSprite_Address 74A8 LD HL,($5E0B) Fetch the previous X and Y position from Actor.
This entry point is used by the routine at AnimateExplosion.
The first byte of the sprite is a horizontal offset in pixels.
SetUpPreviousSprite_Offset 74AB LD A,(DE) Fetch the horizontal offset.
74AC INC DE Move onto the sprite width.
74AD ADD A,L Add the horizontal offset to the X position.
74AE LD L,A Store the result back in L.
74AF CALL ScreenAddress Convert the position into a screen address using ScreenAddress.
74B2 LD A,(DE) Fetch the sprite width.
74B3 LD B,A Set the width counter in B to the sprite width.
74B4 INC DE Move onto the sprite height.
74B5 LD A,(DE) Fetch the sprite height.
74B6 LD ($5E10),A Store it in 5E10 as the height of the previous sprite.
SetUpSprite_Finish 74B9 LD C,$00 Set the row count in C to 00 (no rows have been drawn yet).
74BB INC DE Move onto the first byte of the sprite graphic data.
74BC RET Return.
This entry point is used by the routine at DrawSprite.

This entry point is used by the routines at UpdateBloomingFlower, UpdateStreamer and UpdateLeaf.
Work out how many rows of one sprite lie beyond the other.
DisplayEntity_Compare 74F2 LD A,($5E0C) Fetch the previous Y position from 5E0C.
74F5 SUB (IX+$02) Subtract the new Y position.
74F8 JP Z,MaskSprite_Finish_Previous Jump to MaskSprite_Finish_Previous if the two sprites start on the same row.
74FB JP M,DisplayEntity_NewLower Jump to DisplayEntity_NewLower if the new sprite starts lower down the screen.
74FE LD C,A Store the number of extra rows in C.
74FF LD A,($5E10) Fetch the height of the previous sprite from 5E10.
7502 CP C Compare it with the number of extra rows.
7503 JP C,MaskSprite_Finish_Previous Jump to MaskSprite_Finish_Previous if the sprites do not overlap.
7506 SUB C Subtract the extra rows from the height of the previous sprite.
7507 LD ($5E10),A Write it back to 5E10.
750A JP MaskSprite Jump to MaskSprite to erase the extra rows of the previous sprite first.
The new sprite starts lower down the screen, so its extra rows are drawn first.
DisplayEntity_NewLower 750D EXX Switch to the shadow registers.
750E NEG Make the number of extra rows positive.
7510 LD C,A Store the number of extra rows in C.
7511 LD A,($5E11) Fetch the height of the new sprite from 5E11.
7514 CP C Compare it with the number of extra rows.
7515 JP C,MaskSprite_Finish Jump to MaskSprite_Finish if the sprites do not overlap.
7518 SUB C Subtract the extra rows from the height of the new sprite.
7519 JP MaskSprite_Finish_ClearNew Jump to MaskSprite_Finish_ClearNew.
