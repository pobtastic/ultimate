6A3A: Remove Object
Used by the routine at UpdateLeaf.
Erases the sprite of an object at its previous position and makes the object inactive.
Input
DE Sprite data
IX Object
RemoveObject 6A3A CALL RemoveEntity_Address Erase the sprite using RemoveEntity_Address.
6A3D LD (IX+$00),$00 Write 00 to IX+00 (the object is inactive).
6A41 RET Return.
