761A: Sprite Table
The addresses of the sprites for each object type, which are found by PrepareOldSprite and ActorMoveSprite. Types 01-03 (Robbie and the spray can) have eight words each. The first four are for the X position within a character cell (bits 1-2) when bit 6 of the state is clear. The second four are for when bit 6 is set, and have the same four images in the reverse order. Types 01 and 02 (Robbie) share the same images.
Types 04-0D (from SpritesTable_Other: smoke bombs, a slug, repellent, midges, a leech and the bonus items) have four words each. Bit 2 of the X position gives the first or the second image of a pair, and then the same pair is used again when bit 6 of the state is set (or a different pair for the slug, repellent and leech).
