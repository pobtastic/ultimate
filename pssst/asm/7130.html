7130: Next Object
Every update routine returns here. This moves onto the next object and goes round the main loop again, unless it was the last object of the pass. Then the pass ends by continuing at Pause_Loop.
Input
IX Object
NewActor 7130 LD HL,$5E19 Increment RandomNumber by one (this changes the random number).
7133 INC (HL)
7134 LD DE,$0008 DE=08 (the size of an object).
7137 ADD IX,DE Set IX to the next object.
7139 PUSH IX Copy IX to HL using the stack.
713B POP HL
