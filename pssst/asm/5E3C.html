5E3C: Bonus Item State
The bonus item, which sits in a cubby hole until Robbie collects it (see SpawnBonusItem and UpdateBonusItem). It is an object which is not in the main table.
State_BonusItem 5E3C DEFB $34 State: 00 when there is no bonus item, or the type 0B 0C or 0D.
5E3D DEFB $32 X position (08 or E8).
5E3E DEFB $34 Y position.
5E3F DEFB $0E Colour attribute (it flashes).
5E40 DEFB $00 What the cubby hole contains while the bonus item is waiting (FF).
5E41 DEFB $00 The number of the cubby hole.
5E42 DEFB $80 Not used.
5E43 DEFB $5B
