7125: Reset Modified Code In Frame
The end of the fast pass, which is reached from 714F. It puts back the code changed by FrameUpdate, gets the old IX back and returns to the main loop.
ResetModifiedInFrame 7125 CALL ResetModifiedCode Call ResetModifiedCode.
7128 POP IX Restore IX, saved during frame update.
712A XOR A Set FrameUpdated as "not updated" (i.e. 00).
712B LD ($5E20),A
712E EI Enable interrupts.
712F RET Return.
