6127: End Game
Used by the routine at PlayerTurnEnds.
Both players are out of lives. Updates the high score, shows the "GAME OVER" message for the current player and then returns to the game selection screen.
This is a controller with a jump to Game_Restart to return to the game selection screen.
GameOver_ControllerRestart 6127 CALL UpdateHighScore Update the high score using UpdateHighScore.
612A LD A,($5E1E) Jump to GameOver_Restart2UP if the current player (Current_Player) is not 00 (2UP).
612D AND A
612E JR NZ,GameOver_Restart2UP
6130 CALL GameOver_1UP Show the "GAME OVER PLAYER 1" message using GameOver_1UP.
GameOver_Restart 6133 JP Game_Restart Jump to Game_Restart.
GameOver_Restart2UP 6136 CALL GameOver_2UP Show the "GAME OVER PLAYER 2" message using GameOver_2UP.
6139 JR GameOver_Restart Jump to GameOver_Restart.
