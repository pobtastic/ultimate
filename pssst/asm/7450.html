7450: Colourise Sprite
Used by the routines at DrawCubbyHoleItem, AnimateExplosion, UpdateStreamer, UpdateLeaf, UpdateFlower, UpdateSprayCan, DrawObject and UpdateBonusItem.
Writes the colour of an actor into the attribute buffer, covering the character cells that its sprite has just been drawn over. The pixels are drawn first (see DisplayEntity), so until this routine runs the sprite is drawn in the attribute that was already there.
Input
IX Actor object
Before After

7457 LD A,($5E0F) Set the column counter in B' to the sprite width, from NewSprite_Width.

ColouriseSprite_Loop2 746B LD A,H Fetch the MSB of the attribute buffer address.
746C CP $5B Jump to ColouriseSprite_NextRow if the address is beyond the attribute buffer (H is at least 5B).
746E JR NC,ColouriseSprite_NextRow

7472 JR C,ColouriseSprite_NextRow
7474 LD (HL),D Write the colour to the attribute buffer.
7475 INC L Move onto the next column.
7476 LD A,L Fetch the low byte of the address.
7477 AND %00011111 Keep only bits 0-4 (the column).
7479 JR NZ,ColouriseSprite_NextColumn Jump to ColouriseSprite_NextColumn if the column has not wrapped onto the next row.
747B LD A,L Move back to the start of the same row of attribute cells.
747C SUB $20
747E LD L,A
ColouriseSprite_NextColumn 747F DJNZ ColouriseSprite_Loop2 Decrease the column counter by one and loop back to ColouriseSprite_Loop2 until it is zero.
Move up one row of attribute cells.
ColouriseSprite_NextRow 7481 POP HL Restore the address of the start of the row from the stack.

7484 LD BC,$0020

748A LD B,E Reset the column counter from E'.
