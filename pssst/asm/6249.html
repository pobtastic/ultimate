6249: Flash Second Menu Line
Used by the routine at Game_Restart.
Resets the FLASH attribute for the first of two menu lines and sets it for the second.
Input
HL Pointer to the attribute byte of the first line
Output
HL Pointer to the attribute byte after the second line
MenuAttributeSetSecond 6249 RES 7,(HL) Unset the FLASH attribute for the first selection.
624B INC HL Move onto the next menu attribute.
624C SET 7,(HL) Set the FLASH attribute for the second selection.
624E INC HL Move onto the next menu selection attribute.
624F RET Return.
