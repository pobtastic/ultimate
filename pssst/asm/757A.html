757A: Find Object Sprite
Used by the routine at SetUpPreviousSprite.
Finds the graphic for the current state of an object. This is the same as PrepareOldSprite except that the X position and state are taken from the object.
Input
IX Object
Output
DE Address of the sprite
ActorMoveSprite 757A LD A,(IX+$01) A=the object's X position.
757D AND %00000110 Keep only bits 1-2.
757F LD C,A Keep the X position bits in C.
7580 LD A,(IX+$00) A=the object's state.
7583 JR ActorGetSpriteAddress Jump to ActorGetSpriteAddress.
