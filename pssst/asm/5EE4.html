5EE4: Explosion State
The explosion, which is the last of the objects (see AnimateExplosion). It is state 15 (which does nothing) until an object explodes.
State_Explosion 5EE4 DEFB $DB State: 15 inactive or 14 exploding.
5EE5 DEFB $1F X position.
5EE6 DEFB $76 Y position.
5EE7 DEFB $1B Colour attribute.
5EE8 DEFB $03 The frame of the explosion.
5EE9 DEFB $13 The mask which sets the speed of the explosion.
5EEA DEFB $00 The state of the object which exploded, so that it can be put back.
5EEB DEFB $3E Not used.
