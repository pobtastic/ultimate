5E6C: Robbie State
Robbie is the first of the objects which are updated in each pass.
State_Robbie_Active 5E6C DEFB $00 State: 00 inactive, 01 empty-handed or 02 carrying a can of pesticide.
State_Robbie_Pos_X 5E6D DEFB $80 X position.
State_Robbie_Pos_Y 5E6E DEFB $00 Y position.
State_Robbie_Colour 5E6F DEFB $00 Colour attribute.
State_Robbie_Flags 5E70 DEFB $00 Flags: bit 0 is set when Robbie faces left, bit 2 is set while he cannot pick up an item and bit 3 is set when he has just picked up a can.
5E71 DEFB $00 Not used.
State_Robbie_LastItem 5E72 DEFB $00 The last item that Robbie dropped, so that he does not pick it up again straight away.
5E73 DEFB $00 Not used.
