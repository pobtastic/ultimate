7262: Create Bug
Used by the routine at SpawnBug.
Creates a new bug in an inactive bug object, at the cubby hole whose number is in BugStart_CubbyHole. The type and the colour are chosen using the level, and the random number (see BugTypeTable). The bug is cancelled if Robbie is too close to it.
Input
HL The inactive bug object

7264 LD HL,$5F16 Copy 08 bytes of data from DefaultState_Bug to DE.

72A9 LD A,(HL) A=the type of the bug.

72B1 BIT 6,A Jump to CreateBug_Colour if bit 6 is not set.

CreateBug_Colour 72B6 LD A,(HL) A=the colour of the bug.

72BA LD E,$00 E=00 (no collision).
72BC LD HL,$5E6E HL=State_Robbie_Pos_Y (the Y position of Robbie).

72C3 JR NZ,CreateBug_Done Jump to CreateBug_Done if the bug is not on top of Robbie.
