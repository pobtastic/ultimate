601F: Draw Cubby Hole Shelves
Used by the routine at DrawPlayArea.
Draws the five shelves of the cubby holes down one side of the play area, each made of three bricks and each 20 pixels below the last.
Input
DE Pointer to the string for the shelf
HL Screen position of the first shelf
DrawCubbyHoleShelves 601F LD C,$05 Set the shelf counter in C to 05.
DrawCubbyHoleShelves_Loop 6021 LD B,$01 Set the brick counter in B to 01 (one row of bricks per shelf).
6023 CALL PrintString_Wrapper Print the shelf using PrintString_Wrapper.
6026 LD A,H A=the Y position, which PrintString_Wrapper has moved down by 08.
6027 ADD A,$18 Add 18 to move down to the next shelf (20 pixels below the last).
6029 LD H,A Store the Y position in H.
602A DEC C Decrease the shelf counter by one.
602B JR NZ,DrawCubbyHoleShelves_Loop Loop back to DrawCubbyHoleShelves_Loop until all five shelves have been drawn.
602D RET Return.
