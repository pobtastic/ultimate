68ED: Handle Midges Weapon Hit
Used by the routine at UpdateMidges.
A weapon has hit the midges. The repellent spray kills them, a streamer has no effect and a smoke bomb stuns them (and stops them dead).
Input
A State of the weapon
IX Midges object
MidgesWeaponHit 68ED AND %00111111 Keep only bits 0-5 (the type of the weapon).
68EF CP $08 Jump to MidgesWeaponHit_Kill if it is the repellent spray.
68F1 JR Z,MidgesWeaponHit_Kill
68F3 CP $12 Jump to UpdateMidges_NoWeaponHit if it is a streamer.
68F5 JP Z,UpdateMidges_NoWeaponHit
68F8 BIT 3,(IX+$04) Jump to EatFlower if the midges are eating the flower.
68FC JP NZ,EatFlower
68FF LD (IX+$06),$00 Write 00 to IX+06 (stop the vertical movement).
6903 CALL StunBug Stun the midges using StunBug.
6906 JP UpdateMidges_NoWeaponHit Jump to UpdateMidges_NoWeaponHit.
MidgesWeaponHit_Kill 6909 LD BC,$0050 BC=50 (the points for the kill).
690C JP KillLeech_AddPoints Add the points to the score and explode the midges using KillLeech_AddPoints.
