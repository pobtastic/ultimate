6087: Play Area Strings
Strings used by DrawPlayArea. Each is an attribute byte followed by UDG IDs (see UDG_Brick), where the last UDG ID has bit 7 set to mark the end of the string.
Message_Bricks_LR 6087 DEFB $7A A brick wall string: INK:RED, PAPER:WHITE (BRIGHT), one brick (UDG ID 00 with bit 7 set).
6088 DEFB $80
Message_Bricks_Cubby 6089 DEFB $7A A cubby hole shelf string: INK:RED, PAPER:WHITE (BRIGHT), three bricks (UDG ID 00 with bit 7 set on the last).
608A DEFB $00
608B DEFB $00
608C DEFB $80
Message_Floor 608D DEFB $32 A floor tile string: INK:RED, PAPER:YELLOW, UDG ID 01 and UDG ID 02 (with bit 7 set).
608E DEFB $01
608F DEFB $82
