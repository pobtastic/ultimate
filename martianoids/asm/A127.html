A127: Set Robot Facing
Used by the routines at WinRound and ResetLives.
Sets the type that the robot takes on when it has finished materialising, which is the first of the sprites of the robot walking.
SetRobotFacing A127 LD A,$10 Use type 10...
A129 LD ($9695),A ...as the type that the robot takes on after the sequence of sprites that shows it materialising.
A12C RET Return.
