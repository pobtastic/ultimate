A98B: Finish Materialising
The handler for entity type 4B, which is the last sprite that shows an entity materialising. The entity is drawn, and then given the type that it is going to keep. If it is the robot then the controls are cleared.
Input
IX Entity
FinishMaterialising A98B CALL AddEntity Draw the entity using AddEntity.
A98E LD A,(IX+$05) Fetch the type that the entity is going to have...
A991 LD (IX+$00),A ...and set it.
A994 CP $10 Return if it is below 10.
A996 RET C
A997 CP $30 Return if it is 30 or above, as it is not the robot.
A999 RET NC
A99A XOR A Clear the controls...
A99B LD ($9625),A Store the controls.
A99E RET Return.
