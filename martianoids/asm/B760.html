B760: Update Idle Timer
Used by the routine at GameMenu.
Counts down the idle timer. If it reaches zero then the hall of fame is shown, until a key is pressed. The timer is reset if the zero flag is not set when this routine is called.
Input
F The zero flag is reset to reset the timer
UpdateIdleTimer B760 JR NZ,ResetIdleTimer Jump to reset the timer if the zero flag is not set.
B762 LD HL,($9630) Fetch the timer...
B765 DEC HL ...take one off...
B766 LD ($9630),HL ...and store it.
B769 LD A,H Return if the timer has not reached zero.
B76A OR L
B76B RET NZ
