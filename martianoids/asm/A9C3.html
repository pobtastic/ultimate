A9C3: Move Entity
Used by the routines at TryMove and MoveDestroyer.
Moves an entity in the direction that it is heading, by up to the number of steps that is given. The entity stops at the start of a cell if the next cell is not empty. The routine keeps a copy of the position, so that a move can be undone.
Input
B Number of steps to take
DE X position
HL Y position
IX Entity
Output
A 01 if the entity has been blocked
B Number of steps that are left
DE New X position
HL New Y position
F The zero flag is reset if the entity has been blocked
