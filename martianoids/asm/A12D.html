A12D: Try Move
Used by the routines at MoveSpark, MoveThief, MoveProgramPacket, MoveHunter, MovePellet and MoveDome.
Moves an entity in the direction that it is heading, using MoveEntity, and then tests whether it has been blocked. An entity that is blocked by a cell of type 0F is allowed to carry on.
Input
B Number of steps that can still be taken
DE X position
HL Y position
Output
A The type of the cell that is blocking the entity
F The zero flag is set if the entity can carry on
TryMove A12D CALL MoveEntity Move using MoveEntity, and return if the entity can carry on.
