B5CB: Print Character
Used by the routines at PrintMessage, PrintCharacterBlock, PrintBigDigit, PrintSmallNumber, PrintBorderColumn, PrintBorderRow, HallOfFame, EnterInitials and PrintStringColour.
Prints a single character to the display file, at a character position.

A Character code
HL Screen address
