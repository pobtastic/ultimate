B1A3: Fill Memory
Used by the routines at InitialiseGame, WinRound and ClearScreen.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory B1A3 LD E,$00 Set E to 00.
This entry point is used by the routine at ResetAttributes.
FillMemory_WithValue B1A5 LD (HL),E Write E.
B1A6 INC HL Increment HL.
B1A7 DEC BC Decrement BC.
B1A8 LD A,B Loop back until the byte counter is zero.
B1A9 OR C
B1AA JR NZ,FillMemory_WithValue
B1AC RET Return.
