B1A3: Fill Memory
Used by the routines at InitialiseGame, WinRound and ClearScreen.
Writes 00 to every byte of a block of memory. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
HL Start address
BC Number of bytes
FillMemory B1A3 LD E,$00 Set the fill value to 00.
Continue on to FillMemory_WithValue.
