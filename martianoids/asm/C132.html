C132: Note Table
The notes that are used by PlayNote, which are numbered from 00. There are three bytes for each note. They are the delay for each half of a cycle, as two bytes (the first is the number of repeats of the second), and then the number of cycles in the shortest note. The first entry is for the rests, which are not played.
