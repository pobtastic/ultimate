BFFC: Sound Effect Pitches
The pitches of the four sound effects, one list for each effect number. PlaySoundStep reads a list from the end, because it adds the tone counter to the address of the list. It only reaches these bytes when A' is 00, 01, 02 or 03.
SoundEffectPitches BFFC DEFB $40,$70,$40,$70
C000 DEFB $50,$70,$60,$50,$40
C005 DEFB $40,$50,$60,$70,$80,$80,$80
C00C DEFB $30,$60,$30,$60
