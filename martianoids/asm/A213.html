A213: Remove Cloud
The handler for entity type 57, which is the last sprite of a cloud of smoke. It removes the cloud.
Input
IX Entity
RemoveCloud A213 LD (IX+$00),$00 Remove the entity by setting its type to zero.
A217 RET Return.
