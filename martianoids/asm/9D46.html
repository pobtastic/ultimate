9D46: Messaging: Message Text
Message_Sector 9D46 DEFM "SECTOR "," "+$80 Message number 01. The sector number is written into the last character, which is a space until a message with a sector number is printed. "SECTOR n".
Message_ProgramSentFrom 9D4E DEFM "PROGRAM SENT FRO","M"+$80 Message number 02. "PROGRAM SENT FROM".
Message_ProgramHasBeen 9D5F DEFM "PROGRAM HAS BEE","N"+$80 Message number 03. "PROGRAM HAS BEEN".
Message_Destroyed 9D6F DEFM "DESTROYE","D"+$80 Message number 04. "DESTROYED".
Message_BatteryLow 9D78 DEFM "BATTERY LO","W"+$80 Message number 05. "BATTERY LOW".
Message_UnderAttack 9D83 DEFM "UNDER ATTAC","K"+$80 Message number 06. "UNDER ATTACK".
Message_Critical 9D8F DEFM "CRITICA","L"+$80 Message number 07. "CRITICAL".
Message_ProgramReceived 9D97 DEFM "PROGRAM RECIEVE","D"+$80 Message number 08. The game spells this "PROGRAM RECIEVED".
