B717: Messaging: Game Over
The text of the game over message. Each message starts with an attribute byte and its last character has bit 7 set. The number of the player in the second message is modified by ShowGameOver_Player.
Message_GameOver B717 DEFM $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "GAME OVER".
B718 DEFM "GAME OVE","R"+$80
Message_Player B722 DEFM $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "PLAYER " and the number of the player.
B723 DEFM "PLAYER ","1"+$80
