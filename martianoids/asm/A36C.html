A36C: Move Program Packet
The handler for entity types 6E and 6F, which is the program packet that is sent from a transmitter to a sector. It follows the open cells of the map. If it reaches a receiving terminal (a cell of type 09) in a sector that has some energy then the sector is activated, and if it runs into a hazard (a cell of type 01 or 07) then the program is destroyed.
