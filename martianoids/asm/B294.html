B294: Build Shift Tables
Used by the routine at InitialiseGame.
Builds the lookup tables used to shift sprite bytes right by any number of pixels, and the table used to reverse the bits of a byte. The shift tables occupy E000 to EFFF. For each byte value 00 to FF and each shift of 00 to 07 bits to the left, the byte is stored as a 10 bit number. The low byte of the number is stored in page EF for a shift of 00, page ED for a shift of 01, and so on in steps of two pages. The high byte is stored in the page below it. Both are stored at the offset given by the original value. The table at F000 gives the value of each byte with its bits reversed, and is used to flip sprites.
BuildShiftTables B294 LD L,$00 Start with the byte value 00.
BuildShiftTables_NextValue B296 LD D,$00 Clear the high byte of the shifted value.
