A713: End Smoke
The handler for entity type 3B, which is the last sprite of the smoke. If the robot has exploded then it loses a life, and otherwise the entity is removed.
Input
IX Entity
EndSmoke A713 CALL MakeNoiseIfVisible Make the sound of an explosion using MakeNoiseIfVisible.
A716 PUSH IX Copy the address of the entity into HL.
A718 POP HL
A719 LD DE,$9690 Point DE at Entities.
A71C AND A Subtract the address of the robot, and lose a life using LoseLife if the entity is the robot.
A71D SBC HL,DE
A71F JP Z,LoseLife
A722 LD (IX+$00),$00 Otherwise remove the entity by setting its type to zero.
A726 RET Return.
