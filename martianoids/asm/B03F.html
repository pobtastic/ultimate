B03F: Set Light Direction
Used by the routine at TurnLightVertically.
Gives a light a new direction and moves it. The entry points are for turning up, down, left and right.
Input
HL Address of the attribute that the light is going to
IX Light
SetLightUp B03F LD C,$10 Use the code for up.
SetLight_Direction B041 LD A,(IX+$00) Fetch the type of the light.
B044 AND $07 Keep the colour...
B046 OR C ...and add the new direction.
B047 LD (IX+$00),A Store the type of the light.
B04A JP MoveLight_Move Jump to move the light.
This entry point is used by the routine at TurnLightVertically.
SetLightDown B04D LD C,$18 Use the code for down.
B04F JR SetLight_Direction Jump to set the direction.
This entry point is used by the routine at TurnLightHorizontally.
SetLightLeft B051 LD C,$00 Use the code for left.
B053 JR SetLight_Direction Jump to set the direction.
This entry point is used by the routine at TurnLightHorizontally.
SetLightRight B055 LD C,$08 Use the code for right.
B057 JR SetLight_Direction Jump to set the direction.
