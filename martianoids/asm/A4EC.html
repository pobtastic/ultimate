A4EC: Move Hunter
The handler for entity types 60 to 63, which are enemies that hunt for the robot. The enemy heads for the robot, and chooses a new direction when it is blocked.
Input
IX Entity
MoveHunter A4EC CALL ToggleSprite Move on to the next sprite using ToggleSprite.
A4EF CALL RemoveDistantEntity Remove the enemy if it is far away from the camera using RemoveDistantEntity.
A4F2 CALL GetPosition Fetch the position of the enemy.
A4F5 LD B,$40 The enemy can take up to 40 steps in this frame.

A4FA JR NZ,MoveHunter_Blocked Jump if the enemy has been blocked by a cell.

A4FF JR C,MoveHunter_Reverse Jump if there is.
