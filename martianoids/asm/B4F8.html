B4F8: Print Big Digit
Used by the routines at PrintBigNumber and DrawGameScreen.
Prints a digit that is two characters tall, using the digit graphics at DigitGraphics.
Input
A Digit (00 to 09)
HL Screen address
Output
HL Screen address of the next column
PrintBigDigit B4F8 PUSH HL Save the screen address.
B4F9 ADD A,A Double the digit, to give the number of the top half of the digit.
B4FA PUSH AF Save the number.
B4FB CALL PrintScreen Print the top half of the digit using PrintScreen.
B4FE DEC L Move back to the column of the digit.
B4FF CALL MoveDownRow Move down to the next character row using MoveDownRow.
B502 POP AF Restore the number of the top half.
B503 INC A Move on to the bottom half of the digit.
B504 CALL PrintScreen Print the bottom half of the digit.
B507 POP HL Restore the original screen address.
B508 INC L Move on to the next column.
B509 RET Return.
