9F4D: Wait For Frame
Used by the routine at CheckPause.
Waits for the next frame interrupt and then moves the lights that run round the border.
Input
C 01 to start a new light, or 00 to leave the lights as they are
Output
F The zero flag is set if there are no lights left
WaitForFrame 9F4D PUSH BC Save the register.
9F4E LD IY,($9613) Restore IY, which the ROM interrupt routine needs.
9F52 EI Enable interrupts.
9F53 HALT Wait for the next interrupt.
9F54 DI Disable interrupts again.
9F55 POP BC Restore the register.
9F56 LD A,C Fetch the flag.
9F57 CALL MoveLights Move the lights using MoveLights.
9F5A RET Return.
