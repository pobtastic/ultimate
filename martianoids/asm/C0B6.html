C0B6: Play Music Until Key Pressed
Used by the routine at GameMenu.
Plays a tune, but only the first time that it is used, and stops if a key is pressed. The tune is a list of notes that ends with FF. See PlayNote for what the notes are.
Input
DE Address of the tune
Output
F Non-zero flag set if the tune has been played before
PlayMusic_WaitKey C0B6 LD HL,$9637 Point HL at the flag that records that a tune has been played.
C0B9 LD A,(HL) Return if it has been played before.
C0BA AND A
C0BB RET NZ
C0BC SET 0,(HL) Set the flag.
PlayMusic_WaitKey_Loop C0BE XOR A Select every half row of the keyboard.
C0BF CALL ReadKeys Read the keyboard using ReadKeys.
C0C2 JR Z,PlayMusic_WaitKey_Next Jump if no key is pressed.
C0C4 RET Return as a key has been pressed.
PlayMusic_WaitKey_Next C0C5 LD A,(DE) Jump to return if the next note is FF, which is the end of the tune.
C0C6 CP $FF
C0C8 JR Z,PlayMusic_Return
C0CA CALL PlayNote Play the note using PlayNote.
C0CD JR PlayMusic_WaitKey_Loop Loop back for the next note.
