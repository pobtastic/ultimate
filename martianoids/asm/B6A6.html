B6A6: Print Border Row
Used by the routines at DrawBorder and DrawGameScreen.
Prints a row of border characters, alternating between two characters.
Input
HL Screen address of the left end
B Number of characters
C Character code (bit 0 is flipped each time)
PrintBorderRow B6A6 LD A,C Fetch the character code.
B6A7 XOR $01 Switch to the other character of the pair.
B6A9 LD C,A Keep it.
B6AA PUSH BC Save the counters.
B6AB CALL PrintScreen Print the character using PrintScreen.
B6AE POP BC Restore the counters.
B6AF DJNZ PrintBorderRow Loop back until the whole row has been printed.
B6B1 RET Return.
