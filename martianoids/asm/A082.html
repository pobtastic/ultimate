A082: Flicker Transmitter
The handler for entity types 4E and 4F, which are the program transmitters. A transmitter flickers between its two sprites.
Input
IX Entity
FlickerTransmitter A082 LD A,($9617) Fetch the random number...
A085 AND $03 ...limited to 00-03.
A087 RES 0,(IX+$00) Show the first sprite.
A08B RET NZ Return unless the random number was zero.
A08C SET 0,(IX+$00) Otherwise show the second sprite.
A090 RET Return.
