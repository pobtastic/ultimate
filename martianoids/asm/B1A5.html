B1A5: Fill Memory With Value
Used by the routine at ResetAttributes.
Writes a value to every byte of a block of memory.
Input
E Value to write
HL Start address
BC Number of bytes
FillMemory_WithValue B1A5 LD (HL),E Write the fill value to the current address.
B1A6 INC HL Move on to the next address.
B1A7 DEC BC Decrease the byte counter by one.
B1A8 LD A,B Loop back until the byte counter is zero.
B1A9 OR C
B1AA JR NZ,FillMemory_WithValue
B1AC RET Return.
