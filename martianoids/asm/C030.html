C030: Play Melody
Plays a short melody from a list of pitches. It is not used.
PlayMelody C030 LD HL,$C03F Point HL at the melody.
PlayMelody_Loop C033 LD A,(HL) Fetch a pitch.
C034 INC HL Move on to the next one.
C035 AND A Return if it is zero, which is the end of the melody.
C036 RET Z
C037 LD B,A Use it as the pitch.
C038 LD C,$08 Each tone is made of 08 cycles.
C03A CALL PlayWaveSequence Make the tone using PlayWaveSequence.
C03D JR PlayMelody_Loop Loop back for the next one.
