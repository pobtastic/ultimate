A56D: Check Entity Overlap
Used by the routine at MoveProgramPacket.
Checks whether the entity overlaps any of the first fourteen entities, which are the robot, the shots, the enemies and the program packet.
Input
IX Entity
DE X position
HL Y position
Output
IY The entity that has been hit
F The carry flag is set if there is one
CheckEntityOverlap A56D PUSH BC Save the registers.
A56E LD B,$0E There are 0E entities to check.
A570 LD IY,$9690 Point IY at Entities.
A574 JR CheckEnemyOverlap_Next Jump to check them.
