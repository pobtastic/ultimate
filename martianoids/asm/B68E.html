B68E: Fill Attribute Column
Used by the routine at DrawBorder.
Writes an attribute to a run of cells down a column of the attribute file.
Input
HL Address of the first cell
B Number of cells
C Attribute
FillAttributeColumn B68E LD DE,$0020 Set the distance to the next row to 20.
FillAttributeColumn_Loop B691 LD (HL),C Write the attribute.
B692 ADD HL,DE Move down to the next row.
B693 DJNZ FillAttributeColumn_Loop Loop back until all of the cells have been filled.
B695 RET Return.
