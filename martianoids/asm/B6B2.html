B6B2: Move Down Row
Used by the routines at PrintCharacterBlock, PrintBigDigit and PrintBorderColumn.
Moves down by one character row in the display file.
Input
HL Screen address
Output
HL Screen address one character row down
MoveDownRow B6B2 LD A,L Add 20 to the low byte of the address.
B6B3 ADD A,$20
B6B5 LD L,A
B6B6 RET NC Return if that did not move into the next third of the display.
B6B7 LD A,H Otherwise move on to the next third.
B6B8 ADD A,$08
B6BA LD H,A
B6BB RET Return.
