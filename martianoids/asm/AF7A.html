AF7A: Next Light
Used by the routine at MoveLights.
Moves on to the next light, and when all of them have been moved makes the routine return.
Input
IX Light
Output
A 01
F The zero flag is reset
NextLight AF7A LD DE,$0004 Each light is four bytes long.
AF7D ADD IX,DE Move on to the next light.
AF7F PUSH IX Copy the address into HL...
AF81 POP HL Pop it into HL.
AF82 LD DE,$AFAE Point DE at the end of the lights.
AF85 AND A Compare the address with it.
AF86 SBC HL,DE
AF88 JR C,MoveLights_Light Loop back if there are more lights.
AF8A LD A,$01 Set A to 01 and clear the zero flag.
AF8C AND A
AF8D RET Return.
