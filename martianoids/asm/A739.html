A739: Spawn Enemies
Used by the routine at MainLoop.
Called every frame while the robot is alive. It tries to start a new enemy at a random position in the sector that the robot is in, and tries to start a new destroyer in the sector that is under attack. A new enemy starts as the sprites that show it materialising. The enemy is only started if there is a free entity, and if the cell that is chosen at random is empty.

A73F CP $30 Return if it is 30 or above, as the robot is not in a walking state.
