B8CE: Print Text List
Used by the routines at LoseGame, WinRound, EndRound, HallOfFame and NewHighScore_Enter.
Prints a list of lines of text, each with its own attribute and coordinates.
Input
B Number of lines
DE' Address of the attributes
HL Address of the coordinates (X and Y in pixels, for each line)
DE Address of the text
PrintTextList B8CE EXX Switch to the attributes.
B8CF LD A,(DE) Fetch the attribute...
B8D0 LD ($9628),A ...and set it as the colour of the text.
B8D3 INC DE Move on to the next attribute.
B8D4 EXX Switch back to the text.
B8D5 PUSH BC Save the counter.
B8D6 LD A,(HL) Fetch the X coordinate.
B8D7 INC HL Move on to the next coordinates.
B8D8 INC HL
B8D9 PUSH HL Save the address of the coordinates.
B8DA DEC HL Go back to the Y coordinate...
B8DB LD H,(HL) ...and fetch it.
B8DC LD L,A Put the X coordinate in L.
B8DD CALL PrintText Print the text using PrintText.
B8E0 POP HL Restore the address of the coordinates.
B8E1 POP BC Restore the counter.
B8E2 DJNZ PrintTextList Loop back until all of the lines have been printed.
B8E4 RET Return.
