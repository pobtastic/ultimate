B696: Print Border Column
Used by the routine at DrawBorder.
Prints a column of border characters, alternating between two characters.
Input
HL Screen address of the top
B Number of characters
C Character code (bit 0 is flipped each time)
PrintBorderColumn B696 LD A,C Fetch the character code.
B697 XOR $01 Switch to the other character of the pair.
B699 LD C,A Keep it.
B69A PUSH BC Save the counters.
B69B CALL PrintScreen Print the character using PrintScreen.
B69E DEC L Move back to the column of the character.
B69F CALL MoveDownRow Move down to the next character row using MoveDownRow.
B6A2 POP BC Restore the counters.
B6A3 DJNZ PrintBorderColumn Loop back until the whole column has been printed.
B6A5 RET Return.
