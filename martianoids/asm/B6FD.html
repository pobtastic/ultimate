B6FD: Game Over
Used by the routine at LoseGame.
Ends the game. The game over message is shown and then the high score table is updated. If the player has earned a place in the table the hall of fame is shown, and then the game restarts from the title screen.
Show the game over message.
GameOver B6FD CALL ShowGameOver Show the game over message using ShowGameOver.
B700 CALL DrawBorder Draw the border around the screen using DrawBorder.
B703 LD A,$47 Use bright white on black as the attribute.
B705 CALL ClearLargeWindowWithAttributes Clear the large window using ClearLargeWindowWithAttributes.
Update the high score table.
B708 CALL NewHighScore Insert the score into the high score table, if it is high enough, using NewHighScore.
B70B LD A,($9633) Fetch the flag that is set if a name was entered in the table.
B70E AND A Test whether it is set.
B70F JR Z,GameOver_Title Jump to GameOver_Title if not.
B711 CALL HandlerHallOfFame Show the hall of fame using HandlerHallOfFame.
Go back to the title screen.
GameOver_Title B714 JP TitleScreen Jump to TitleScreen to go back to the title screen.
