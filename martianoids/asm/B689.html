B689: Fill Attribute Row
Used by the routines at DrawBorder and DrawGameScreen.
Writes an attribute to a run of cells along a row of the attribute file.
Input
HL Address of the first cell
B Number of cells
C Attribute
FillAttributeRow B689 LD (HL),C Write the attribute.
B68A INC HL Move on to the next cell.
B68B DJNZ FillAttributeRow Loop back until all of the cells have been filled.
B68D RET Return.
