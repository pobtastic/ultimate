B1AD: Clear Screen
Used by the routine at InitialiseGame.
Resets the whole display: the attributes are set to bright white on black and the pixels are cleared.
Before After
ClearScreen B1AD CALL ResetAttributes Set every attribute using ResetAttributes.
B1B0 LD HL,$4000 Point HL at the start of the display file.
B1B3 LD BC,$1800 There are 1800 bytes of pixels to clear.
B1B6 JR FillMemory Clear them using FillMemory.
