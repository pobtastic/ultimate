B4E6: Print Character Block
Used by the routine at DrawPanel.
Prints a rectangle of characters.
Input
DE Address of the character codes
HL Screen address of the top left
B Width in characters
C Height in characters
PrintCharacterBlock B4E6 PUSH BC Save the dimensions.
B4E7 PUSH HL Save the screen address of the start of the row.
PrintCharacterBlock_Character B4E8 LD A,(DE) Fetch the next character code.
B4E9 INC DE
B4EA CALL PrintScreen Print it using PrintScreen.
B4ED DJNZ PrintCharacterBlock_Character Loop back until a row of characters has been printed.
B4EF POP HL Restore the screen address of the start of the row.
B4F0 CALL MoveDownRow Move down to the next character row using MoveDownRow.
B4F3 POP BC Restore the dimensions.
B4F4 DEC C Decrease the row counter by one.
B4F5 JR NZ,PrintCharacterBlock Loop back until every row has been printed.
B4F7 RET Return.
