AEE0: Set Position
Used by the routines at MoveSpark, MoveThief, MoveDestroyer, MoveProgramPacket, MoveHunter, SpawnEnemies, MoveDome and MoveRobot.
Stores the position of an entity.
Input
DE X position
HL Y position
IX Entity
SetPosition AEE0 LD (IX+$01),E Store the X fraction...
AEE3 LD (IX+$02),D ...and the X cell.
AEE6 LD (IX+$03),L Store the Y fraction...
AEE9 LD (IX+$04),H ...and the Y cell.
AEEC RET Return.
