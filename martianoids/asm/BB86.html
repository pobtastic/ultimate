BB86: Start Game Sequence
Used by the routine at GameMenu.
Runs when the key to start the game is pressed. Lights are started around the frame of the screen, and when they have all finished the tune that starts the game is played and the game screen is drawn.
StartGameSequence BB86 LD B,$08 There are eight lights to start.
StartGameSequence_Light BB88 PUSH BC Save the counter.
BB89 CALL DisplayMenu Draw the menu using DisplayMenu.
BB8C LD A,$01 Start a new light using MoveLights.
BB8E CALL MoveLights
BB91 POP BC Restore the counter.
BB92 DJNZ StartGameSequence_Light Loop back until all eight lights have been started.
BB94 CALL DisplayMenu Draw the menu using DisplayMenu.
StartGameSequence_Wait BB97 LD IY,($9613) Restore IY, which the ROM interrupt routine needs.
BB9B EI Enable interrupts...
BB9C HALT ...and wait for the next one.
BB9D DI Disable interrupts again.
BB9E XOR A Move the lights without starting a new one, using MoveLights.
BB9F CALL MoveLights
BBA2 JR NZ,StartGameSequence_Wait Loop back until all of the lights have finished.
BBA4 LD DE,$C289 Point DE at StartGameTune.
BBA7 CALL PlayMusic Play it using PlayMusic.
