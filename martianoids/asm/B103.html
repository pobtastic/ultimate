B103: Finish Joystick Controls
Used by the routines at ReadInterface2, ReadKempstonJoystick and ReadCursorKeys.
Adds the keys that work with every method of control, and stores the controls. Any of the keys Z, X, C, V, Symbol Shift, M, N and B fires the first weapon.
Input
C Controls that were read
FinishJoystickControls B103 LD A,($9625) Fetch the controls that have not been used yet...
B106 AND $BF ...clear the bit for the action key...
B108 OR C ...and add the controls that were read.
B109 LD C,A Keep the controls.
B10A LD A,$7E Read from the keyboard;
Port Number Bit
0 1 2 3 4
7E SHIFT / SPACE Z / SYM X / M C / N V / B
B10C CALL ReadKeys
B10F AND $1E Jump if none of the keys Z, X, C, V, Symbol Shift, M, N and B is pressed.
B111 JR Z,FinishJoystickControls_Store
B113 SET 4,C Set the bit for firing the first weapon.
FinishJoystickControls_Store B115 LD A,C Fetch the controls...
B116 LD ($9625),A ...and store them.
B119 POP BC Restore BC.
B11A LD C,A Return the controls in C as well.
B11B RET Return.
