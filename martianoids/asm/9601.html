9601: Game Entry
Used by the routine at StartGame_Jump.
The game starts here, as the first instruction at 6000 jumps to this address. Interrupts stay disabled for the whole game, apart from the short windows used to wait for the next frame (see WaitForFrame).
GameEntry 9601 DI Disable interrupts.
9602 LD SP,$6000 Move the stack pointer to the top of the area below the game code, as the stack grows downwards from 6000.
9605 IM 1 Select interrupt mode 1.
9607 CALL DecodeSprites Convert all of the sprites to the form used by DrawSprite, using DecodeSprites.
960A LD HL,$C23C Point HL at the font used by the game. Characters start at 20 so this is 0100 below the start of the font data.
960D LD ($5C36),HL Use it as the current character set.
9610 JP InitialiseGame Jump to InitialiseGame to set up the game.
