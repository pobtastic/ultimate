43608: Move Right
Used by the routines at MoveEntity and MoveRobot.
Moves an entity in direction two, which increases the X position. See MoveEntity for how the move works.
Input
B Number of steps to take
DE X position
HL Y position
Output
A 1 if the entity has been blocked
B Number of steps that are left
DE New X position
F The zero flag is reset if the entity has been blocked
