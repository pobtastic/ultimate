46871: Messaging: Game Over
The text of the game over message. Each message starts with an attribute byte and its last character has bit 7 set. The number of the player in the second message is modified by ShowGameOver_Player.
Message_GameOver 46871 DEFM 71 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "GAME OVER".
46872 DEFM "GAME OVE","R"+128
Message_Player 46882 DEFM 71 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT) + "PLAYER " and the number of the player.
46883 DEFM "PLAYER ","1"+128
