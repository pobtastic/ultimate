47310: Print Text List
Used by the routines at LoseGame, WinRound, EndRound, HallOfFame and NewHighScore_Enter.
Prints a list of lines of text, each with its own attribute and coordinates.
Input
B Number of lines
DE' Address of the attributes
HL Address of the coordinates (X and Y in pixels, for each line)
DE Address of the text
PrintTextList 47310 EXX Switch to the attributes.
47311 LD A,(DE) Fetch the attribute...
47312 LD (38440),A ...and set it as the colour of the text.
47315 INC DE Move on to the next attribute.
47316 EXX Switch back to the text.
47317 PUSH BC Save the counter.
47318 LD A,(HL) Fetch the X coordinate.
47319 INC HL Move on to the next coordinates.
47320 INC HL
47321 PUSH HL Save the address of the coordinates.
47322 DEC HL Go back to the Y coordinate...
47323 LD H,(HL) ...and fetch it.
47324 LD L,A Put the X coordinate in L.
47325 CALL PrintText Print the text using PrintText.
47328 POP HL Restore the address of the coordinates.
47329 POP BC Restore the counter.
47330 DJNZ PrintTextList Loop back until all of the lines have been printed.
47332 RET Return.
