45716: Build Shift Tables
Used by the routine at InitialiseGame.
Builds the lookup tables used to shift sprite bytes right by any number of pixels, and the table used to reverse the bits of a byte. The shift tables occupy 57344 to 61439. For each byte value 0 to 255 and each shift of 0 to 7 bits to the left, the byte is stored as a 16 bit number. The low byte of the number is stored in page 239 for a shift of 0, page 237 for a shift of 1, and so on in steps of two pages. The high byte is stored in the page below it. Both are stored at the offset given by the original value. The table at 61440 gives the value of each byte with its bits reversed, and is used to flip sprites.
