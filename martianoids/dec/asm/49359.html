49359: Play Music
Used by the routines at LoseGame, WinRound, EndRound and StartGameSequence.
Plays a tune from start to finish. The tune is a list of notes that ends with 255. See PlayNote for what the notes are.
Input
DE Address of the tune
PlayMusic 49359 LD A,(DE) Jump to return if the next note is 255, which is the end of the tune.
49360 CP 255
49362 JR Z,PlayMusic_Return
49364 CALL PlayNote Play the note using PlayNote.
49367 JR PlayMusic Loop back for the next note.
This entry point is used by the routine at PlayMusic_WaitKey.
PlayMusic_Return 49369 RET Return.
