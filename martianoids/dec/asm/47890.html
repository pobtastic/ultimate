47890: Game Selection Menu
Used by the routines at InitialiseGame and GameMenu_Unused.
Displays the menu and waits for the control method to be chosen and the game to be started. The keys "1" to "4" choose the keyboard, the Kempston joystick, the cursor joystick and Interface II, and "0" starts the game. The menu tune is played once. The choice is held in ControlMethod. If nothing is done for a while then the hall of fame is shown.
