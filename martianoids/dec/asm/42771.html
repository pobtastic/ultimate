42771: End Smoke
The handler for entity type 59, which is the last sprite of the smoke. If the robot has exploded then it loses a life, and otherwise the entity is removed.
Input
IX Entity
EndSmoke 42771 CALL MakeNoiseIfVisible Make the sound of an explosion using MakeNoiseIfVisible.
42774 PUSH IX Copy the address of the entity into HL.
42776 POP HL
42777 LD DE,38544 Point DE at Entities.
42780 AND A Subtract the address of the robot, and lose a life using LoseLife if the entity is the robot.
42781 SBC HL,DE
42783 JP Z,LoseLife
42786 LD (IX+0),0 Otherwise remove the entity by setting its type to zero.
42790 RET Return.
