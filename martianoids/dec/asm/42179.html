42179: Choose Direction
Used by the routine at MoveProgramPacket.
Finds a direction for a program packet to go in, which is the one that it is heading in if that is possible, and otherwise the one to the side, the opposite one, and the other side.
Input
A Direction of the packet
DE X position
HL Y position
Output
A The type of the cell, if the zero flag is set
C The direction that has been chosen
F The zero flag is set if the packet can go on
