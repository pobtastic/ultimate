44837: Move Lights
Used by the routines at WaitForFrame and StartGameSequence.
Moves the lights that travel around the frame of the screen, and starts a new one when it is asked to. This is done every frame. There are eight lights, each of which is a type, a delay, and the address of the attribute that it is in. The lights follow the cells of the frame, which have an attribute of 72, and a light finishes when it gets back to the top left of the frame.
Input
A 1 to start a new light, or 0 to leave the lights as they are
Output
F The zero flag is set if no lights are in use
