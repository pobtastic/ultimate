43314: Materialise Entity
The handler for entity types 64 to 74, which are the sprites that show an enemy, or the robot, materialising. When the entity is going to be the robot it is drawn twice, once at a slight offset, which makes the picture look like it is shimmering. Each sprite is shown for a frame, and the next one is chosen by changing the type.
Input
