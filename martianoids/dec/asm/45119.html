45119: Set Light Direction
Used by the routine at TurnLightVertically.
Gives a light a new direction and moves it. The entry points are for turning up, down, left and right.
Input
HL Address of the attribute that the light is going to
IX Light
SetLightUp 45119 LD C,16 Use the code for up.
SetLight_Direction 45121 LD A,(IX+0) Fetch the type of the light.
45124 AND 7 Keep the colour...
45126 OR C ...and add the new direction.
45127 LD (IX+0),A Store the type of the light.
45130 JP MoveLight_Move Jump to move the light.
This entry point is used by the routine at TurnLightVertically.
SetLightDown 45133 LD C,24 Use the code for down.
45135 JR SetLight_Direction Jump to set the direction.
This entry point is used by the routine at TurnLightHorizontally.
SetLightLeft 45137 LD C,0 Use the code for left.
45139 JR SetLight_Direction Jump to set the direction.
This entry point is used by the routine at TurnLightHorizontally.
SetLightRight 45141 LD C,8 Use the code for right.
45143 JR SetLight_Direction Jump to set the direction.
