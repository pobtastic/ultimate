45475: Fill Memory
Used by the routines at InitialiseGame, WinRound and ClearScreen.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory 45475 LD E,0 Set E to 0.
This entry point is used by the routine at ResetAttributes.
