49370: Play Note
Used by the routines at PlayMusic_WaitKey and PlayMusic.
Plays one note of a tune, by making a tone, or by waiting if it is a rest. The bottom six bits of the note byte are the number of the note (zero is a rest) and the top two bits are one less than the length. The pitch and the duration of the note are found from a table of three bytes for each note: the delay for each half cycle (as two bytes), then the number of cycles that last for the shortest note. The length multiplies it.
Input
A Note byte
DE Address of the note
Output
DE Address of the next note
