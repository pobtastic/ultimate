46328: Print Big Digit
Used by the routines at PrintBigNumber and DrawGameScreen.
Prints a digit that is two characters tall, using the digit graphics at DigitGraphics.
Input
A Digit (0 to 9)
HL Screen address
Output
HL Screen address of the next column
PrintBigDigit 46328 PUSH HL Save the screen address.
46329 ADD A,A Double the digit, to give the number of the top half of the digit.
46330 PUSH AF Save the number.
46331 CALL PrintScreen Print the top half of the digit using PrintScreen.
46334 DEC L Move back to the column of the digit.
46335 CALL MoveDownRow Move down to the next character row using MoveDownRow.
46338 POP AF Restore the number of the top half.
46339 INC A Move on to the bottom half of the digit.
46340 CALL PrintScreen Print the bottom half of the digit.
46343 POP HL Restore the original screen address.
46344 INC L Move on to the next column.
46345 RET Return.
