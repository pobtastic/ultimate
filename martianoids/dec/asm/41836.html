41836: Move Program Packet
The handler for entity types 110 and 111, which is the program packet that is sent from a transmitter to a sector. It follows the open cells of the map. If it reaches a receiving terminal (a cell of type 9) in a sector that has some energy then the sector is activated, and if it runs into a hazard (a cell of type 1 or 7) then the program is destroyed.
