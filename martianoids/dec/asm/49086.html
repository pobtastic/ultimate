49086: Unused Map Address
Part of a way to find the address of a map cell that is not used. It does not clear A first, so it would not work properly.
Input
D Row
E Column
Output
HL Address of the cell
MapAddress_Unused 49086 SRL D Divide the row by four, keeping the bits that come out in the top of A.
49088 RRA
49089 SRL D
49091 RRA
49092 AND 192 Combine them with the column.
49094 OR E
49095 LD E,A
49096 LD HL,50453 Add the offset to the address of the map.
49099 ADD HL,DE
49100 RET Return.
