42349: Check Entity Overlap
Used by the routine at MoveProgramPacket.
Checks whether the entity overlaps any of the first fourteen entities, which are the robot, the shots, the enemies and the program packet.
Input
IX Entity
DE X position
HL Y position
Output
IY The entity that has been hit
F The carry flag is set if there is one
CheckEntityOverlap 42349 PUSH BC Save the registers.
42350 LD B,14 There are 14 entities to check.
42352 LD IY,38544 Point IY at Entities.
42356 JR CheckEnemyOverlap_Next Jump to check them.
