45477: Fill Memory With Value
Used by the routine at ResetAttributes.
Writes a value to every byte of a block of memory.
Input
E Value to write
HL Start address
BC Number of bytes
FillMemory_WithValue 45477 LD (HL),E Write the fill value to the current address.
45478 INC HL Move on to the next address.
45479 DEC BC Decrease the byte counter by one.
45480 LD A,B Loop back until the byte counter is zero.
45481 OR C
45482 JR NZ,FillMemory_WithValue
