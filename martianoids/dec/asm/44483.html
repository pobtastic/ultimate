44483: Set Attacked Sector
Used by the routine at AttackSector.
Changes the sector that is shown as being under attack, and then draws the map of the sectors. The code of a sector has the row in bits 6 and 7 and the column in bits 1 and 2; a row or column of 3 means that there is no sector. The flag that says the old sector is under attack is cleared.
Input
C Code of the sector that is now under attack

44486 LD A,(HL) Fetch the old code...
44487 LD (HL),C ...and store the new one.
44488 CP C Jump to draw the map if the code has not changed.

44500 LD A,C Fetch the old code again...
44501 RLCA ...and move the row into the low bits.
44502 RLCA

44507 JR Z,DrawSectorMap

44513 LD E,A ...and keep the number of the old sector in E.
44514 LD D,0 Clear the high byte of the sector number.
44516 LD HL,38526 Point HL at SectorStates.
44519 ADD HL,DE Add the number of the sector.
