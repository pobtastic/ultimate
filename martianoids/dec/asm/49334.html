49334: Play Music Until Key Pressed
Used by the routine at GameMenu.
Plays a tune, but only the first time that it is used, and stops if a key is pressed. The tune is a list of notes that ends with 255. See PlayNote for what the notes are.
Input
DE Address of the tune
Output
F Non-zero flag set if the tune has been played before
PlayMusic_WaitKey 49334 LD HL,38455 Point HL at the flag that records that a tune has been played.
49337 LD A,(HL) Return if it has been played before.
49338 AND A
49339 RET NZ
49340 SET 0,(HL) Set the flag.
PlayMusic_WaitKey_Loop 49342 XOR A Select every half row of the keyboard.
49343 CALL ReadKeys Read the keyboard using ReadKeys.
49346 JR Z,PlayMusic_WaitKey_Next Jump if no key is pressed.
49348 RET Return as a key has been pressed.
PlayMusic_WaitKey_Next 49349 LD A,(DE) Jump to return if the next note is 255, which is the end of the tune.
49350 CP 255
49352 JR Z,PlayMusic_Return
49354 CALL PlayNote Play the note using PlayNote.
49357 JR PlayMusic_WaitKey_Loop Loop back for the next note.
