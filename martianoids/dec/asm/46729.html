46729: Fill Attribute Row
Used by the routines at DrawBorder and DrawGameScreen.
Writes an attribute to a run of cells along a row of the attribute file.
Input
HL Address of the first cell
B Number of cells
C Attribute
FillAttributeRow 46729 LD (HL),C Write the attribute.
46730 INC HL Move on to the next cell.
46731 DJNZ FillAttributeRow Loop back until all of the cells have been filled.
46733 RET Return.
