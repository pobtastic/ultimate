44340: Queue Program
Used by the routine at UseActionKey_Up.
Adds a program to the queue of programs that the robot is carrying (or adds a blank, if the robot is not picking one up), and then draws the four icons of the queue in the panel. The queue holds five entries, and the oldest one is pushed out of the end.
Input
A Program to add (6), or 0 for a blank
Output
A The entry that was pushed out of the queue (0 if it was blank)
