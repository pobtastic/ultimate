44132: Use Action Key
Handles the action key, which picks up a program from the cell that is in front of the robot, drops a program into it, or installs a program in a socket (a cell of type 15). It only works when the robot is at the start of a cell, and the key has to be released between presses. The programs that the robot carries are kept in a queue, which is handled by QueueProgram.
The first part of the code works out the position of the cell in front of the robot. These entry points are used when the robot is heading up, right and left.
