43863: Move Robot
Used by the routine at MoveRobotHorizontally.
Moves the robot in the direction that it is heading, by the number of steps that is in B. The robot can only turn when it is at the start of a cell: if a turn key is being pressed then the robot turns and carries on in the new direction. When the robot is blocked by something in the map then HandleObstacle deals with it.
Input
B Number of steps to take
IX Robot

Direction three (Y decreasing). The four sections that follow all work in the same way. When the robot is at the start of a cell, and a key to turn is being pressed, the robot is turned and the routine carries on with the section for the new direction. Otherwise the robot moves, and if it was blocked then HandleObstacle is called to deal with the obstacle. This is repeated until there are no more steps.
