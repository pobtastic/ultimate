41485: Animate Cloud
The handler for entity types 84 to 86, which are the sprites of a cloud of smoke. It moves on to the next sprite and draws it. The last sprite of the cloud is handled by RemoveCloud.
Input
IX Entity
AnimateCloud 41485 INC (IX+0) Move on to the next sprite.
41488 JP AddEntity Draw the cloud using AddEntity.
