46310: Print Character Block
Used by the routine at DrawPanel.
Prints a rectangle of characters.
Input
DE Address of the character codes
HL Screen address of the top left
B Width in characters
C Height in characters
PrintCharacterBlock 46310 PUSH BC Save the dimensions.
46311 PUSH HL Save the screen address of the start of the row.
PrintCharacterBlock_Character 46312 LD A,(DE) Fetch the next character code.
46313 INC DE
46314 CALL PrintScreen Print it using PrintScreen.
46317 DJNZ PrintCharacterBlock_Character Loop back until a row of characters has been printed.
46319 POP HL Restore the screen address of the start of the row.
46320 CALL MoveDownRow Move down to the next character row using MoveDownRow.
46323 POP BC Restore the dimensions.
46324 DEC C Decrease the row counter by one.
46325 JR NZ,PrintCharacterBlock Loop back until every row has been printed.
46327 RET Return.
