43403: Finish Materialising
The handler for entity type 75, which is the last sprite that shows an entity materialising. The entity is drawn, and then given the type that it is going to keep. If it is the robot then the controls are cleared.
Input
IX Entity
FinishMaterialising 43403 CALL AddEntity Draw the entity using AddEntity.
43406 LD A,(IX+5) Fetch the type that the entity is going to have...
43409 LD (IX+0),A ...and set it.
43412 CP 16 Return if it is below 16.
43414 RET C
43415 CP 48 Return if it is 48 or above, as it is not the robot.
43417 RET NC
43418 XOR A Clear the controls...
43419 LD (38437),A Store the controls.
43422 RET Return.
