46758: Print Border Row
Used by the routines at DrawBorder and DrawGameScreen.
Prints a row of border characters, alternating between two characters.
Input
HL Screen address of the left end
B Number of characters
C Character code (bit 0 is flipped each time)
PrintBorderRow 46758 LD A,C Fetch the character code.
46759 XOR 1 Switch to the other character of the pair.
46761 LD C,A Keep it.
46762 PUSH BC Save the counters.
46763 CALL PrintScreen Print the character using PrintScreen.
46766 POP BC Restore the counters.
46767 DJNZ PrintBorderRow Loop back until the whole row has been printed.
46769 RET Return.
