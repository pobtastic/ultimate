43172: Finish Robot Turn
The handler for entity types 32 to 47, which are the sprites that the robot has while it is turning. The turn is finished at once; the entity gets one of the types for walking (16 to 31) and the robot is checked for a collision with an enemy. If the robot has hit an enemy it loses some energy, and it is destroyed if it has none left. This routine then handles the entity again as its new type, without drawing it.
