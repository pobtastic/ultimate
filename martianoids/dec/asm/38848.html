38848: Cell Templates
The templates for the cells of the map, which are used to draw them in the same way as entities. Each is 16 bytes long, and they are for the cell types 1 to 15. The first byte of each is the sprite type, and bytes 1 and 3 are offsets for its position, which are all zero. The handler for that sprite type runs on the template, which is how a program and an activated terminal animate.
