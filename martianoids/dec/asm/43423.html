43423: Start Robot
Used by the routines at WinRound and StartGame.
Starts a new life. The robot is given the type that makes it wait, the number of lives goes down by one, the battery is filled up and the robot is shown on the map of the sectors.
StartRobot 43423 LD A,88 Set the type of the robot to 88, which makes it wait.
43425 LD (38544),A
43428 LD A,32 Set its timer to 32 frames.
43430 LD (38550),A
