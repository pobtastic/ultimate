48589: Add Entity
Used by the routines at MoveSpark, AnimateCloud, MoveThief, MoveDestroyer, MoveProgramPacket, MoveHunter, AnimateSmoke, MoveDome, MaterialiseEntity, DrawShiftedEntity, FinishMaterialising and MoveRobotHorizontally.
Adds an entity to the draw list, if it can be seen. The view is centred on the robot (the first entity), and an entity can only be seen if it is within about 16 cells of it. The distances between the entity and the robot in the two directions are projected onto the screen: the sum of them gives the height of the entity above the bottom of the buffer and the difference gives its horizontal position, both in units of one sixteenth of a cell. If it is added then bit 0 of (IX+15) is set. The draw list entry that is added is made of the type of the entity, the horizontal position and the height.
Input
IX Entity
Output
F Carry set if the entity was added
