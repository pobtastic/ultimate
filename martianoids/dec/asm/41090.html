41090: Flicker Transmitter
The handler for entity types 78 and 79, which are the program transmitters. A transmitter flickers between its two sprites.
Input
IX Entity
FlickerTransmitter 41090 LD A,(38423) Fetch the random number...
41093 AND 3 ...limited to 0-3.
41095 RES 0,(IX+0) Show the first sprite.
41099 RET NZ Return unless the random number was zero.
41100 SET 0,(IX+0) Otherwise show the second sprite.
41104 RET Return.
