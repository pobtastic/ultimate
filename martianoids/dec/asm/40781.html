40781: Wait For Frame
Used by the routine at CheckPause.
Waits for the next frame interrupt and then moves the lights that run round the border.
Input
C 1 to start a new light, or 0 to leave the lights as they are
Output
F The zero flag is set if there are no lights left
WaitForFrame 40781 PUSH BC Save the register.
40782 LD IY,(38419) Restore IY, which the ROM interrupt routine needs.
40786 EI Enable interrupts.
40787 HALT Wait for the next interrupt.
40788 DI Disable interrupts again.
40789 POP BC Restore the register.
40790 LD A,C Fetch the flag.
40791 CALL MoveLights Move the lights using MoveLights.
40794 RET Return.
