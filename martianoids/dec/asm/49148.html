49148: Sound Effect Pitches
The pitches of the four sound effects, one list for each effect number. PlaySoundStep reads a list from the end, because it adds the tone counter to the address of the list. It only reaches these bytes when A' is 0, 1, 2 or 3.
SoundEffectPitches 49148 DEFB 64,112,64,112
49152 DEFB 80,112,96,80,64
49157 DEFB 64,80,96,112,128,128,128
49164 DEFB 48,96,48,96
