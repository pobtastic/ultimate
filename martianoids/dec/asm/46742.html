46742: Print Border Column
Used by the routine at DrawBorder.
Prints a column of border characters, alternating between two characters.
Input
HL Screen address of the top
B Number of characters
C Character code (bit 0 is flipped each time)
PrintBorderColumn 46742 LD A,C Fetch the character code.
46743 XOR 1 Switch to the other character of the pair.
46745 LD C,A Keep it.
46746 PUSH BC Save the counters.
46747 CALL PrintScreen Print the character using PrintScreen.
46750 DEC L Move back to the column of the character.
46751 CALL MoveDownRow Move down to the next character row using MoveDownRow.
46754 POP BC Restore the counters.
46755 DJNZ PrintBorderColumn Loop back until the whole column has been printed.
46757 RET Return.
