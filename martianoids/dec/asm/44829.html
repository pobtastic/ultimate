44829: Check Lights
Used by the routine at MoveLights.
Checks whether any of the lights are in use.
Input
B Number of lights
HL Address of the first light
DE Size of a light
Output
F The zero flag is set if no lights are in use
CheckLights 44829 XOR A Start the count of lights at zero.
CheckLights_Next 44830 OR (HL) Combine the type of the light with the others...
44831 ADD HL,DE ...and move on to the next light.
44832 DJNZ CheckLights_Next Loop back until all the lights have been checked.
44834 RET Z Return if no lights are in use.
44835 JR MoveLights_Update Jump to move the lights.
