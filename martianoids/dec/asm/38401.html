38401: Game Entry
Used by the routine at StartGame_Jump.
The game starts here, as the first instruction at 24576 jumps to this address. Interrupts stay disabled for the whole game, apart from the short windows used to wait for the next frame (see WaitForFrame).
GameEntry 38401 DI Disable interrupts.
38402 LD SP,24576 Move the stack pointer to the top of the area below the game code, as the stack grows downwards from 24576.
38405 IM 1 Select interrupt mode 1.
38407 CALL DecodeSprites Convert all of the sprites to the form used by DrawSprite, using DecodeSprites.
38410 LD HL,49724 Point HL at the font used by the game. Characters start at 32 so this is 256 below the start of the font data.
38413 LD (23606),HL Use it as the current character set.
38416 JP InitialiseGame Jump to InitialiseGame to set up the game.
