Title Tune
Played by 47905 while the menu is shown, until a key is pressed. The music data is at TitleTune.
Start Tune
Played by 48039 when a game is started. The music data is at StartGameTune.
Level Complete Tune
Played by 39522 when a round has been won. The music data is at RoundWonTune.
Game Over Tune
Played by 39481 and 39650 when the game is lost. The music data is at GameLostTune.
Shot Sound
Played by 42667.
Short Beep
Played by 40770, 41046, 44118 and 47774.
Low Tone
Played by 40724, 41599, 42317, 43150 and 44095.
Explosion
Played by 40169 and 40172. The pitches come from random places in the ROM, so this is one example.
Random Noise
Played by 42765 and EndSmoke, when the entity is visible. The pitches come from random places in the ROM, so this is one example.
Appearing Sound
Played by 43328 and 43365. The pitch is random, so this is one example.
Action Sound
Started by 44182 when the action key is used. Four tones. PlaySoundStep does not read the effect number. Each tone's pitch list is chosen from A' at that frame. This is the sound at the start of play, when the first tone's A' is 80.
Program Sent Sound
Started by 40517 when a program packet is sent. Five tones. The pitch list is chosen from A', not from effect number 1. This is the sound at the start of play.
Sector Activated Sound
Started by 42048 when a sector is activated. Seven tones. The pitch list is chosen from A', not from effect number 2. This is the sound at the start of play.
Program Destroyed Sound
Started by 41972 when a program is destroyed. Four tones. Effect 0 is also four tones and the effect number is not read, so this is the same sound as the action sound. This is it at the start of play.
