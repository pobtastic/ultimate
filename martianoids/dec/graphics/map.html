Map

The map of the world is stored at Map. It is 64 cells on a side, but only the first 49 columns and rows have anything in them. The lower four bits of each cell are the type that it is now, and the upper four bits are the type that it started as. The picture uses the current type, or the initial type when the cell is empty.

Type 0 is empty ground. The other types are the walls, terminals, batteries and hazards listed with the templates at CellTemplates. The purple lines mark the nine sectors of 16 by 16 cells. North is at the top. Drag to move, and use the mouse wheel or pinch to zoom.
