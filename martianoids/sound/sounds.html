Title Tune
Played by BB21 while the menu is shown, until a key is pressed. The music data is at TitleTune.
Start Tune
Played by BBA7 when a game is started. The music data is at StartGameTune.
Level Complete Tune
Played by 9A62 when a round has been won. The music data is at RoundWonTune.
Game Over Tune
Played by 9A39 and 9AE2 when the game is lost. The music data is at GameLostTune.
Shot Sound
Played by A6AB.
Short Beep
Played by 9F42, A056, AC56 and BA9E.
Low Tone
Played by 9F14, A27F, A54D, A88E and AC3F.
Explosion
Played by 9CE9 and 9CEC. The pitches come from random places in the ROM, so this is one example.
Random Noise
Played by A70D and EndSmoke, when the entity is visible. The pitches come from random places in the ROM, so this is one example.
Appearing Sound
Played by A940 and A965. The pitch is random, so this is one example.
Action Sound
Started by AC96 when the action key is used. Four tones. PlaySoundStep does not read the effect number. Each tone's pitch list is chosen from A' at that frame. This is the sound at the start of play, when the first tone's A' is 50.
Program Sent Sound
Started by 9E45 when a program packet is sent. Five tones. The pitch list is chosen from A', not from effect number 01. This is the sound at the start of play.
Sector Activated Sound
Started by A440 when a sector is activated. Seven tones. The pitch list is chosen from A', not from effect number 02. This is the sound at the start of play.
Program Destroyed Sound
Started by A3F4 when a program is destroyed. Four tones. Effect 00 is also four tones and the effect number is not read, so this is the same sound as the action sound. This is it at the start of play.
