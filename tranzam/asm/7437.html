7437: Sprite: Tombstone
The sprite of a tombstone (sprite ID 0F), which an object is changed to when the car hits it. The first byte is the height in lines; each line is then two bytes.
Sprite_Tombstone 7437 DEFB $10 Height = 10 pixels.
