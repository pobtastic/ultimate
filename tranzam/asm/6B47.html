6B47: Draw Objects
Used by the routine at HandlerPlayer.
Goes through the map points (MapPoints), from the one that CurrentObject points to, and draws each one that is in view of the player's car. The map points are in order of their X position, so it stops at the first one which is more than 60 map units away horizontally. Map points which are too far away vertically are skipped.
Before After
DrawObjects 6B47 LD BC,($5E19) Fetch the first map point that might be in view (CurrentObject).
Handle the next map point. A' is used to hold flags which say which side of the player's car the map point is on; bit 1 is set when it is to the right and bit 0 is set when it is higher up the map.

6B4C EX AF,AF' Exchange A with A' to clear the flags.
6B4D LD A,(BC) Fetch the X position of the map point.
6B4E INC BC Move on to the Y position of the map point.
6B4F LD D,A Keep the X position in D.
6B50 CALL ScaleValue_DivideByEight Call ScaleValue_DivideByEight to convert it to map units in DE.
6B53 LD HL,($5E05) Fetch the player's X position on the map (PlayerMapPosition).
6B56 AND A HL=HL - DE (the horizontal distance to the map point).
6B57 SBC HL,DE
6B59 JR NC,DrawObjects_CheckRangeX Jump to DrawObjects_CheckRangeX if the map point is not to the right of the player's car.
6B5B CALL NegateHL Call NegateHL to make the distance positive.
6B5E EX AF,AF' Switch to the flags.
6B5F XOR %00000010 Flip bit 1 (the map point is to the right).
6B61 EX AF,AF' Switch back.
DrawObjects_CheckRangeX 6B62 PUSH HL Stash the distance on the stack.
6B63 EX DE,HL Keep the distance in DE.
6B64 LD HL,$0060 Set the furthest distance in view, 0060.
6B67 AND A Take the distance away from the furthest distance in view.
6B68 SBC HL,DE
6B6A POP HL Restore the distance (HL) from the stack.
6B6B RET C Return if the map point is more than 60 units away horizontally.
6B6C LD A,L Fetch the horizontal distance (the low byte).
6B6D LD ($5E17),A Store the horizontal distance in Object_Distance_X.
6B70 LD A,(BC) Fetch the Y position of the map point.
6B71 INC BC Move on to the sprite ID of the map point.
6B72 LD D,A Keep the Y position in D.
6B73 CALL ScaleValue_DivideBySixteen Call ScaleValue_DivideBySixteen to convert it to map units in DE.
Pick the attributes for the objects; they depend on the time of day.
