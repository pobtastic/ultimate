6949: Plot Map Points
Used by the routine at CreateWindow.
Plots a dot on the map in the sidebar for every entry in the map points table at MapPoints, except place names and collected cups (which are marked with 60). One pixel on the map is 80 map units.
Before After

PlotMapPoints_Loop 694C LD HL,$4708 HL=4708 (pixel co-ordinates of the bottom left of the map: H is the Y position and L is the X position).

6965 LD A,(BC) Fetch the sprite ID of the map point.
6966 INC BC Increment the map pointer in BC by one. Now pointing to the next record.

Check if finished. The stack contains the start of the next record, or the first byte past the end of the map points.

6977 LD HL,$7CD6 Point HL at the end of the map points (Sprite_Car_1, one byte past the end of MapPoints).
697A AND A Reset the carry flag.
