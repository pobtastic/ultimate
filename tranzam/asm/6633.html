6633: Handler: Car
Moves and draws one of the two cars (the entities at Entity_Car_1 and Entity_Car_2), which chase the player. The car is drawn at its position relative to the player, but only when it is closer than 58 map units in both directions. It is then steered towards the player, bounces off objects, and destroys the player if it hits.
Byte Contents
00 State (02), or the sprite ID while the car is being drawn
01 X position on the screen
02 Y position on the screen
03 Colour (00 or 02), or the attribute while the car is drawn
04-05 X position (twice the map position)
06-07 Y position (twice the map position)
08 X speed (bit 7: moving to lower X; bits 0-4: speed)
09 Y speed (bit 7: moving to lower Y; bits 0-4: speed)
0A Flags (bit 0: car is drawn; bit 7: faster car)
0B Sprite ID
Before After
Input
IX Car entity

Choose which of the 10 car sprites to use, so that the car points in the direction it is moving. The quadrant of travel comes from the direction bits (bit 7) of the two speeds, and the angle within it from CarDirectionTable using the top three bits of each speed.
66D8 PUSH BC Stash the direction flags on the stack.
66D9 LD A,(IX+$09) Fetch the Y speed and keep it in E.
66DC LD E,A
66DD RLCA Rotate A left so that bit 0 is the direction bit of the Y speed.
66DE LD C,(IX+$08) Fetch the X speed and keep it in B.
66E1 LD B,C
66E2 RLC C Rotate C left so that bit 0 is the direction bit of the X speed.
66E4 XOR C Exclusive OR A with C.
66E5 AND %00000001 Keep only bit 0.
66E7 SLA C Shift C left so that bit 1 is the direction bit of the X speed.
66E9 OR C Combine the bits.
66EA AND %00000011 Keep only bits 0-1 (the quadrant).
66EC SLA A Multiply the quadrant by 04.
66EE SLA A
66F0 LD C,A Keep the quadrant in C.
66F1 LD A,B Fetch the X speed.
66F2 RRA Divide the X speed by four.
66F3 RRA
66F4 AND %00000111 Keep only bits 0-2.
66F6 LD B,A Keep the X speed bits in B.
66F7 LD A,E Fetch the Y speed.
66F8 RLA Rotate A left.
66F9 AND %00111000 Keep only bits 3-5.
66FB OR B Combine with the X speed bits.
66FC LD E,A E=the index into the table.
66FD LD D,$00 D=00.
66FF LD HL,$683B Point HL at the table of angles (CarDirectionTable).
6702 ADD HL,DE Add the index to the start of the table.
6703 LD A,(HL) Fetch the angle from the table.
6704 CP $FF Compare the angle with FF.
6706 JR Z,HandlerCar_Colour If the car has no speed then keep the same sprite and jump to HandlerCar_Colour.
6708 BIT 2,C Jump to HandlerCar_SetSprite if the quadrant is not odd.
