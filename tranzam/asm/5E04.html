5E04: Player X Position
The position of the player's car along the map. It is a 24-bit number made up of a fraction of a map unit and then the position in map units. The fraction is needed because the car moves by less than one map unit each frame (see HandlerAccelerate). The map is 1800 map units wide.
PlayerMapPosition_Fraction 5E04 DEFB $2C Fraction of a map unit.
PlayerMapPosition 5E05 DEFW $0E30 Position in map units.
