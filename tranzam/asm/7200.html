7200: Reset Attribute Buffer
Used by the routine at CreateWindow.
Sets the border to black, clears the screen with ResetScreen, then fills the attribute file with the background attribute at Background_Attribute.
Before After
ResetAttributes 7200 XOR A Set the border to BLACK.
7201 OUT ($FE),A
7203 CALL ResetScreen Call ResetScreen.
7206 LD HL,$5800 Point HL at the attribute buffer (5800).
7209 LD B,$5B B=5B (i.e. finish once we reach the end of the attribute buffer).
720B LD A,($5E44) Fetch the background attribute (Background_Attribute) as the value to write.
720E LD C,A
720F JR ResetCopier Jump to ResetCopier.
