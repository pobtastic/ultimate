6A73: Move On To Next Entity
The return address for every entity handler (see MainLoop). Moves on to the next entity or, when all of the entities have been handled, plays the engine sound and then waits while the game is paused.
NextEntity 6A73 LD DE,$000C Set the size of an entity (000C).
6A76 ADD IX,DE IX=IX + DE (point to the next entity).
6A78 PUSH IX Copy the entity pointer into HL (using the stack to do so).
6A7A POP HL
6A7B LD BC,$5EA4 Point BC at the end of the entities (Entities_End, the first byte after the last entity).
6A7E AND A Reset the carry flag.
6A7F SBC HL,BC Compare the entity pointer with the end of the entities.
6A81 JP C,MainLoop Jump to MainLoop if there is another entity to handle.
6A84 CALL SoundsEngine Call SoundsEngine to play the engine sound.
