60FB: Play Sound
Used by the routines at PlayNoise and PlaySquareWave.
Flips the speaker bit (bit 4) of the value held at SoundStore and writes the result to port FE. The lower bits of the value set the border colour.
PlaySound 60FB LD A,($5E47) Fetch the speaker and border state from SoundStore.
60FE XOR %00010000 Flip bit 4 (the speaker).
6100 LD ($5E47),A Write the new speaker and border state back to SoundStore.
6103 OUT ($FE),A Write the state to port FE which sets the speaker and the border colour.
6105 RET Return.
