5B80: Game Entry Point
The entry point of the game. The code and data from 5F01 onwards are held one byte higher in memory than they are used, so they are moved down by one byte before control is passed to SecurityCheck.
GameEntry 5B80 DI Disable interrupts.
5B81 LD HL,$5F01 Move 20FF bytes from 5F01 to 5F00.
5B84 LD DE,$5F00
5B87 LD BC,$20FF
5B8A LDIR
5B8C JP SecurityCheck Jump to SecurityCheck.
