6B42: Set Day Object Attributes Pointer
Used by the routine at DrawObjects.
Points HL at the attributes for the objects in the daytime, then rejoins DrawObjects where the sprite ID is read.
SetDayObjectAttributes 6B42 LD HL,$6BE6 Point HL at the day time object attributes (DayObjectAttributes).
