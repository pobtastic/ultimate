6E19: Bounce Off X Edge
Used by the routines at HandlerAccelerate and SubtractX.
Reverses the direction in X, sounds the bounce and carries on.
BounceX 6E19 LD A,($5E11) Fetch the quadrant of the direction (5E11).
6E1C XOR %00000011 Flip bits 0 and 1.
6E1E LD ($5E11),A Write the quadrant back to 5E11.
6E21 LD A,($5E10) Fetch the direction (Player_Direction).
6E24 CPL Flip all the bits.
6E25 LD ($5E10),A Write the direction back to Player_Direction.
6E28 LD A,$05 Set the bounce counter to 05.
6E2A LD ($5E45),A Write the bounce counter to BounceCounter.
6E2D CALL SoundsBounce Make the bounce sound using SoundsBounce.
