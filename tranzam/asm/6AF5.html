6AF5: Handler: Objects
Used by the routine at HandlerPlayer.
Looks after the objects (07 slots from Object_1_State). DrawObjects sets bit 7 of the sprite ID of each object that is in view, so for each slot this clears that bit for objects still in view, erases the objects which are no longer in view and frees their slots. Empty slots just waste a little time.
HandlerObjects 6AF5 LD HL,$5E50 Point HL at the first object (Object_1_State).
6AF8 LD B,$07 Set the object counter to 07.
CheckObjectActive 6AFA BIT 7,(HL) If bit 7 is not set on the current objects sprite ID value, jump to EraseObject.
6AFC JR Z,EraseObject
6AFE RES 7,(HL) Reset bit 7 of the sprite ID.
