5E20: Actor Buffer
The old state of the actor whose sprite is being erased and drawn again (see StoreEntity and DisplayEntity).
Actor_Position_X 5E20 DEFB $00 X Position.
Actor_Position_Y 5E21 DEFB $00 Y Position.
Actor_SpriteID 5E22 DEFB $00 Sprite ID (00 if there is no sprite to erase).
HeightPixels 5E23 DEFB $3A Height (in pixels).
WidthBytes 5E24 DEFB $EF Width (in bytes).
CurrentSpriteHeight 5E25 DEFB $22 Number of lines of the old sprite left to erase.
HeightLines 5E26 DEFB $22 Number of lines of the new sprite left to draw.
