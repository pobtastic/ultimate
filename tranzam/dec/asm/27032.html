27032: Set Pixels
Used by the routines at UpdateRadar, FlashPlayerMarker, UpdateTerrainDot and PlotMapPoints.
Sets a block of pixels. Writes the opcode operand for 198 (which makes PlotPixels_Column set a bit) to 27047, then continues at PlotPixels.
Input
B Height of the block in pixels
C Width of the block in pixels
HL Pixel co-ordinates of the bottom left of the block (H is the Y position and L is the X position)
SetPixels 27032 LD A,198 Write 198 to 27047.
27034 LD (27047),A
