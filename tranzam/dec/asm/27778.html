27778: Get Map Distance
Used by the routine at UpdateCurrentObject.
Finds the distance between the first co-ordinate of the player's map position at PlayerMapPosition and the value in DE. The carry flag is set when the distance is less than 96.
Input
DE Map position
Output
HL Distance
F The carry flag is set when the distance is less than 96
