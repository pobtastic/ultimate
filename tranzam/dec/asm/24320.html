24320: Security Check
Used by the routine at GameEntry.
The game only starts when the second byte of FRAMES is 88. If it is any other value then this returns to the caller instead of running the game.
SecurityCheck 24320 DI Disable interrupts.
24321 LD A,(23673) Fetch the second byte of FRAMES.
24324 CP 88 Return if A is not equal to 88.
24326 RET NZ
Continue on to GameInitialisation.
