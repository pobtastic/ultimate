24487: Game Select Attribute Table
One attribute byte per menu line. The routines that flash the selected line set or clear FLASH in the byte for the line being updated. The first byte belongs to the title, so the flashing code starts at GameSelection_Attributes_Options.
GameSelection_Attributes 24487 DEFB 96
Byte(n) Menu Item
1 Game Selection
2 1 Keyboard
3 2 Joystick
4 3 Start Game
