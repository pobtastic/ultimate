24096: Actor Buffer
The old state of the actor whose sprite is being erased and drawn again (see StoreEntity and DisplayEntity).
Actor_Position_X 24096 DEFB 0 X Position.
Actor_Position_Y 24097 DEFB 0 Y Position.
Actor_SpriteID 24098 DEFB 0 Sprite ID (0 if there is no sprite to erase).
HeightPixels 24099 DEFB 58 Height (in pixels).
WidthBytes 24100 DEFB 239 Width (in bytes).
CurrentSpriteHeight 24101 DEFB 34 Number of lines of the old sprite left to erase.
HeightLines 24102 DEFB 34 Number of lines of the new sprite left to draw.
