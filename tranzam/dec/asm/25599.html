25599: Handler: Pick Up Cup
Used by the routine at CollectCup.
Awards the points for a cup, which are 512 for the first cup up to 5632 for the eighth (the number of cups already collected plus one, doubled, in hundreds). If this was the last of the eight cups then the "congratulations" messaging is shown along with the time taken, "Best Time Today" is updated if it has been beaten, and a new round starts (without resetting the lives). Otherwise the number of cups collected is displayed.
Calculate number of points to award.
HandlerCup 25599 LD A,(24124) Fetch the number of cups collected so far (Cups_Collected).
25602 INC A Work out the points as (cups collected + 1) * 2 in BCD.
25603 ADD A,A
25604 DAA
Adds points to score.
25605 LD B,A Set the points to award, in hundreds (as BCD).
25606 LD C,0 Set the units and tens of the points to 0.
25608 CALL AddPointsToScore Add the points to the score using AddPointsToScore.
Handle incrementing the cup counter.

25614 INC (HL)

Compare the time taken with the best time, one byte at a time starting with the most significant.
25656 LD HL,24064 Point HL at the best time (BestTime_1).
25659 LD DE,24113 Point DE at the time taken (Time_1).
25662 LD B,3 Set the byte counter to 3.
BestTime_Compare 25664 LD A,(DE) Compare the byte of the time at DE against the byte of the best time at HL.
25665 CP (HL)
25666 JR C,BestTime_Update If the time is less than the best time then jump to BestTime_Update.
25668 JR Z,BestTime_Compare_Next If the bytes are the same then jump to BestTime_Compare_Next.
25670 JR HandlerCup_Delay The time is more than the best time, so jump to HandlerCup_Delay.
BestTime_Compare_Next 25672 INC HL Move onto the next BestTime_1 byte.
25673 INC DE Move onto the next Time_1 byte.
25674 DJNZ BestTime_Compare Decrease the byte counter by one and loop back to BestTime_Compare until all of the bytes have been compared.
