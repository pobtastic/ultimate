27693: Update Current Object
Used by the routine at HandlerAccelerate.
Moves the pointer at CurrentObject so that it still points to the first map point which is within 96 map units of the player's X position.
UpdateCurrentObject 27693 XOR A Write 0 to Flag_PointerMovedBack (it is set to 1 if the pointer moves back).
27694 LD (24091),A
27697 LD BC,(24089) Fetch the pointer to the first map point in view (CurrentObject).
Look at the earlier map points to see if the pointer has to move back.
