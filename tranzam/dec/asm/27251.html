27251: Move On To Next Entity
The return address for every entity handler (see MainLoop). Moves on to the next entity or, when all of the entities have been handled, plays the engine sound and then waits while the game is paused.
NextEntity 27251 LD DE,12 Set the size of an entity (0012).
27254 ADD IX,DE IX=IX + DE (point to the next entity).
27256 PUSH IX Copy the entity pointer into HL (using the stack to do so).
27258 POP HL
27259 LD BC,24228 Point BC at the end of the entities (Entities_End, the first byte after the last entity).
27262 AND A Reset the carry flag.
27263 SBC HL,BC Compare the entity pointer with the end of the entities.
27265 JP C,MainLoop Jump to MainLoop if there is another entity to handle.
27268 CALL SoundsEngine Call SoundsEngine to play the engine sound.
