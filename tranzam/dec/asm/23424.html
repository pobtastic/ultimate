23424: Game Entry Point
The entry point of the game. The code and data from 24321 onwards are held one byte higher in memory than they are used, so they are moved down by one byte before control is passed to SecurityCheck.
GameEntry 23424 DI Disable interrupts.
23425 LD HL,24321 Move 8447 bytes from 24321 to 24320.
23428 LD DE,24320
23431 LD BC,8447
23434 LDIR
23436 JP SecurityCheck Jump to SecurityCheck.
