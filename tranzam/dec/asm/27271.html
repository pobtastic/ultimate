27271: Pause Game
Waits for as long as "SHIFT" is held down, then counts the frame and starts the main loop again.
Pause_Loop 27271 LD A,254 Read from the keyboard;
Port Number Bit
0 1 2 3 4
254 SHIFT Z X C V
27273 OUT (253),A
27275 IN A,(254)
27277 BIT 0,A Is "SHIFT" being pressed? If it is then jump back to Pause_Loop.
27279 JR Z,Pause_Loop
27281 LD HL,(24105) Fetch the game timer from GameTimer.
27284 INC HL Add one to the game timer, as a frame has passed.
27285 LD (24105),HL Write the new game timer back to GameTimer.
27288 JP MainLoop_NewPass Jump to MainLoop_NewPass to handle the entities again.
