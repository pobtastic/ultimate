28160: Bounce Off Y Edge
Used by the routines at HandlerAccelerate and SubtractY.
Reverses the direction in Y, sounds the bounce and carries on with the X direction.
BounceY 28160 LD A,(24081) Fetch the quadrant of the direction (24081).
28163 XOR %00000001 Flip bit 0 to reverse the direction in Y.
28165 LD (24081),A Write the quadrant back to 24081.
28168 LD A,(24080) Fetch the direction (Player_Direction).
28171 CPL Flip all the bits to reverse the direction within the quadrant.
28172 LD (24080),A Write the direction back to Player_Direction.
28175 LD A,5 Set the bounce counter to 5.
28177 LD (24133),A Write the bounce counter to BounceCounter.
28180 CALL SoundsBounce Make the bounce sound using SoundsBounce.
28183 JR HandlerAccelerate_MoveX Jump to HandlerAccelerate_MoveX.
