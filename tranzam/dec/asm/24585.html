24585: Run Main Loop
Used by the routines at HandlerCup and Pause_Loop.
The game loop. Each pass runs the handler for each of the three entities held from Entity_Player (the player's car and the two opponent cars), in turn. The handler is chosen by the entity state held in the first byte of the entity, using the table at JumpTable_Main. Once every entity has been handled NextEntity plays the engine sound, checks for a pause and starts the loop again.
State Meaning
0 Inactive
1 Player car driving
2 Opponent car driving
3 Player car exploding
