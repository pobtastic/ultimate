26896: Move Down One Row
Used by the routines at AttributesPlayArea and DrawHUDPanel.
Adds 32 to an address, which moves it down by one character row in the attribute buffer or the screen buffer (for as long as it stays within the same third of the screen).
Input
HL Current address
Output
HL Address one row down
MoveDownOneRow 26896 LD A,L L=L + 32 (one row).
26897 ADD A,32
26899 LD L,A
26900 LD A,H H=H + 0 (but include the carry from above).
26901 ADC A,0
26903 LD H,A
26904 RET Return.
