27435: Scale Value
Used by the routine at CollisionCup.
Converts a map position held in a single byte into map units, by shifting D right through E so that DE is D * 256 shifted right by a fixed number of bits. ScaleValue multiplies by 64 ScaleValue_DivideByEight multiplies by 32 (used for the X position of a map point) and ScaleValue_DivideBySixteen multiplies by 16 (used for the Y position of a map point).
Input
D Value to scale
Output
DE Scaled value
