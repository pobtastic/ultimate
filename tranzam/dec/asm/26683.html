26683: Car Direction Table
The angle of travel of a car, which is 0 when moving vertically and 4 when moving horizontally. Each row is for a different value of bits 2-4 of the Y speed and each column is for a different value of bits 2-4 of the X speed. The first entry is 255 as the car is not moving.
