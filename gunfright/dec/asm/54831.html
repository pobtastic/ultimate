54831: Draw Tile Row
Used by the routines at DrawTelegramFrame and DrawBorder.
Draws a number of tiles side by side.
Input
A The tile
E The number of tiles
BC The address of the tile set
HL The screen address of the left
A' The attribute
Draw a tile and move on to the next column.
DrawTileRow 54831 PUSH AF Stash the tile on the stack.
54832 CALL DrawTile Call DrawTile.
54835 POP AF Restore the tile from the stack.
54836 INC L Move on to the next column.
54837 DEC E Count down the tiles.
54838 JR NZ,DrawTileRow Jump to DrawTileRow if there are any left.
54840 RET Return.
