48466: Draw Object
Used by the routines at HandleOutlawGun, HandleMuzzleFlash, HandleBulletHole and HandleSingleFrameObject.
Draws the sprites of an object which does not move with the town: the objects of the duel and the ones which stay in one place on the screen. The position of the object, which is a single byte for each direction, is where its sprites are drawn from. This routine also counts the object as drawn, which means that the stage is still running.
Input
IX The address of the object
DrawObject 48466 LD H,0 Clear H.
48468 LD L,(IX+2) Fetch the horizontal position of the object.
48471 LD (41550),HL Set the horizontal position for drawing.
48474 LD L,(IX+4) Fetch the vertical position of the object.
48477 LD (41552),HL Set the vertical position for drawing.
48480 JR DrawScrollingObject_CountDrawn Jump to count the object and draw it.
