45696: Draw Wide Sprites
Used by the routines at HandleWaitingOutlaw, DrawOutlawFace, HandleShotOutlaw and HandleDyingOutlaw.
Draws several wide sprites one after another.
Input
B The number of sprites
DE The address of the list of sprite numbers
HL The address in the buffer
Draw each sprite in the list.
DrawWideSprites 45696 LD A,(DE) Fetch the number of the next sprite.
45697 INC DE Move on to the next sprite in the list.
45698 PUSH BC Stash the number of sprites on the stack.
45699 PUSH DE Stash the address of the list on the stack.
45700 CALL DrawWideSprite Draw the sprite.
45703 POP DE Retrieve the address of the list.
45704 POP BC Retrieve the number of sprites.
45705 DJNZ DrawWideSprites Loop back until all of the sprites have been drawn.
45707 RET Return.
