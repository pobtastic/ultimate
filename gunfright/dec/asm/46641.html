46641: Check Sheriff Touch
Used by the routines at HandleMoneyBag, HandleTumbleweed, HandleHorse, HandleCactus, HandleOutlaw and HandleBystander.
Checks whether the sheriff, on foot or on his horse, is touching the object being handled. It does nothing while ProtectionTimer is not zero.
Input
IX The address of the object
Output
F The carry flag is set if the sheriff is touching the object
IY The address of the sheriff
