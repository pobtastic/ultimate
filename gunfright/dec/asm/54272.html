54272: Draw Poster Image
Used by the routine at DrawTownPanel.
Draws an image of thirty-two by eight pixels, as four bytes for each line, with the bottom line first. The addresses of the images are in PosterImagePointers.
Input
A The number of the image
HL The screen address of the bottom left of the image
Find the image.
DrawPosterImage 54272 EX DE,HL Keep the screen address in DE.
54273 LD BC,27334 Point BC at PosterImagePointers.
Find the address of the image.
54276 CALL GetTableEntry Call GetTableEntry.
Read the image with the stack.
54279 LD (41501),SP Set SavedStackPointer.
54283 LD SP,HL Point the stack pointer at the image.
54284 EX DE,HL Put the screen address in HL.
54285 LD B,8 Set a count of 8 lines.
Draw a line.
DrawPosterImage_Line 54287 POP DE Draw the first two bytes of the line.
54288 LD (HL),E
54289 INC HL
54290 LD (HL),D
54291 INC HL
54292 POP DE Draw the next two bytes of the line.
54293 LD (HL),E
54294 INC HL
54295 LD (HL),D
54296 LD DE,65277 Move up one line, and back to the first byte.
54299 ADD HL,DE
54300 DJNZ DrawPosterImage_Line Jump to DrawPosterImage_Line if there are any left.
54302 LD SP,(41501) Restore the stack pointer.
54306 RET Return.
