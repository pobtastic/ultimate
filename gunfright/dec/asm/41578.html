41578: Other Player State
The nineteen bytes of state for the player who is not playing, in the same order as the state of the current player which starts at Bounty. SwapPlayerStates exchanges them.
OtherPlayerState 41578 DEFB 127,255,0,0,127,255,0,0,0,0,0,0 The bounty, the fine, the prices, the level, the skill, the bullets loaded.
OtherPlayerLives 41590 DEFB 0 The number of lives.
41591 DEFB 0,0,0,0,0,0 The rest of the state.
