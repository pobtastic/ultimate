42057: Handle Respawn Delay
Type 25: the pause before the sheriff comes back after losing a life. The delay counter in byte 12 of the slot counts down, and then the object turns into type 26.
HandleRespawnDelay 42057 DEC (IX+12) Decrease the delay counter and return if it has not reached zero.
42060 RET NZ
42061 LD (IX+0),26 Turn the object into type 26.
42065 RET Return.
