42575: Check Telegram Complete
Used by the routine at UpdatePrices.
Checks whether every line of the telegram has been typed in full. A line is complete when its counter has reached 14.
Output
F The zero flag is set if every line is complete
Check each of the six telegram lines.
CheckTelegramComplete 42575 LD HL,43056 Point HL at the first telegram line.
42578 LD DE,18 Set the size of a telegram line in DE.
42581 LD B,6 Set the number of lines to six.
Return unless this line is complete.
CheckTelegramComplete_Loop 42583 LD A,(HL) Fetch the counter of the line.
42584 CP 14 Compare it with the number of characters in a line.
42586 RET NZ Return if the line is not complete.
42587 ADD HL,DE Move on to the next line.
42588 DJNZ CheckTelegramComplete_Loop Loop back until all six lines have been checked.
42590 RET Return.
