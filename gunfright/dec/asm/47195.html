47195: Run Stage Script
Used by the routine at InitialiseGame.
Called every frame. In the duel and the bonus stage, which both have TownOffset set to zero, it runs the routine for the kind of stage which is in StageKind, as long as there are still stages to play (TargetsLeft is not zero). In kind 0 nothing happens, in kind 1 money bags are made, and in kind 2 the duel is set up.
This routine is only for the duel and the bonus stage.
