50034: Convert Cell
Used by the routines at DrawTown and FindObjectsInCell.
Converts the column and the row of a cell between the map and the view. They are the same unless the view is rotated by a half turn, when each is replaced by fifteen minus itself, so that cell (x, y) on the map of sixteen by sixteen is (fifteen minus x, fifteen minus y) in the view. It does nothing when the view is not rotated.
Input
L The column
H The row
Output
L The column to use
H The row to use
Return if the view is not rotated.
