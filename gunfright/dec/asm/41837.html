41837: Initialise Game
Used by the routine at GameStart.
The real start of the game. It checks the loader's signature, clears the game variables, builds the lookup tables, shows the title screen and menu, sets up the first player and then falls into the main loop at MainLoop.
When a game has ended and the high score has been shown, control comes back to RestartGame so that the title screen is shown again.
InitialiseGame 41837 LD SP,24064 Reset the stack pointer to just below the start of the game.
41840 LD A,(23673) Fetch the high byte of the system frame counter.
41843 CP 86 Return unless it holds 86 which is the value the tape loader leaves there.
41845 RET NZ
Clear the game variables.
41846 LD HL,41479 Clear everything from MovementSoundCounter onwards, 358 bytes in all, which covers every game variable.
41849 LD BC,358
41852 JR InitialiseGame_Clear Skip over the shorter clear below.
