54702: Draw Tile Block Reflected
Used by the routine at DrawSidePictures.
The same as DrawTileBlock, except that each row is drawn from right to left and each tile is reflected, which makes a reflection of the block.
Input
B The width of the block
C The height of the block
DE The address of the numbers of the tiles
HL The screen address of the top right
A' The attribute
Draw each row from right to left.

54703 PUSH HL

54705 INC DE
54706 XOR %01000000 Reflect it horizontally.

54709 LD BC,(41487) Fetch TileSetAddress.
