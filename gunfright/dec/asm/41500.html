41500: Options
The choices which are made on the title screen. Bit 0 is set for two players and bits 1 and 2 are the type of controls: zero for the keyboard, one for a Kempston joystick, two for a cursor joystick and three for an Interface 2 joystick. Bit 3 is set when the game starts, and makes a joystick give the direction which the sheriff faces instead of turning him.
