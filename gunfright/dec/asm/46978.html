46978: Start Dying
Used by the routine at KillSheriff.
Turns an object into a dying object (type 9), which falls and bounces, and then lies on the ground as a dead figure.
Input
IX The address of the object
StartDying 46978 LD (IX+0),9 Turn the object into a dying object.
46982 LD (IX+12),250 Set the counter.
46986 LD (IX+13),24 Set the speed of the fall.
46990 LD HL,47012 Point HL at BystanderSpriteLists_DeadFigure.
46993 LD (IX+14),L Store the low byte of the address.
46996 LD (IX+15),H Store the high byte of the address.
46999 RET Return.
