51136: Handle Single Frame Object
Type 5: an object which is drawn once and then removed. MakeFlash makes it. It calls DrawObject and then makes the type 0.
Input
IX The address of the object
Draw the object and remove it.
HandleSingleFrameObject 51136 CALL DrawObject Call DrawObject.
51139 LD (IX+0),0 Make the type 0 and return.
51143 RET
