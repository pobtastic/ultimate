53250: Check Overlap Along Y
Used by the routines at CheckWallsVerticalFirst and CheckWallsHorizontalFirst.
Checks whether the vertical range of an object, after it moves by VerticalSpeed, overlaps the vertical range of a rectangle of a wall. The distance between the middles is compared with half of the height of the object plus the half height of the rectangle.
Input
D The vertical position of the object in the cell
IX The address of the object
IY The address of the rectangle
Output
A The depth into the rectangle, negative if they overlap
F The carry flag is set if the ranges overlap
