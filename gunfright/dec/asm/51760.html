51760: Make Flash
Used by the routine at MakeShot.
Puts a type 5 flash in ObjectSlot_14. It copies the type and position of the object which fires, is eight by eight, and is drawn for one frame from FlashSpriteList.
Input
IX The address of the object which fires
Output
F The carry flag is set
Copy the type and position into ObjectSlot_14.

51762 POP HL
51763 LD DE,41805 Point DE and IY at ObjectSlot_14 (using the stack).
51766 PUSH DE
51767 POP IY
51769 LD BC,5 Set a count of 5.
51772 LDIR Copy the type and position.
Turn the slot into a flash.
51774 LD (IY+0),5 Make the type 5.
51778 LD HL,51801 Point HL at FlashSpriteList.
51781 LD (IY+8),8 Set the horizontal size to 8.

51793 LD (IY+14),L Set the sprite list.
