51127: Handle Body
Type 8: a body lying on the ground. It counts down byte 12 then makes the type 0. HandleDying makes it last for 32 frames.
Input
IX The address of the object
Count down the frames.
HandleBody 51127 DEC (IX+12) Count down byte 12 and return if it is not zero.
51130 RET NZ
This entry point is used by the routines at HandleMoneyBag, HandleTumbleweed, HandleHorse, HandleCactus, HandlePointer, HandleBystander, HandleOutlawGun, MakeBulletHole and HandleSmoke.
Make the type 0.
HandleBody_Remove 51131 LD (IX+0),0 Make the type 0 and return.
