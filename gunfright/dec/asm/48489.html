48489: Draw Sprite List
Used by the routine at HandleCrosshair.
Draws each sprite in the sprite list of an object. A sprite list is made of three bytes for each sprite: the horizontal offset, the vertical offset and the number of the sprite. The offsets are added to the position of the object, and the vertical offset of the object in byte 13. A sprite which would start outside the screen is not drawn. The last byte of the list is 128.

IX The address of the object
