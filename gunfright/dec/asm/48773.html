48773: Draw Sprite Row
Used by the routines at DrawSprite and FinishSpriteRow.
Starts to draw a row of a sprite. The number of rows left is kept in the alternate accumulator while the code for the columns uses A. The jump at SpriteJumpOpcode goes to the code for the columns of the sprite.
DrawSpriteRow 48773 EX AF,AF' Save the number of rows left, and get A.
48774 LD A,(BC) Fetch the first byte of the row from the buffer.
Jump to the code for the columns.
DrawSprite_Jump 48775 JP 41508 Jump to SpriteJumpOpcode.
