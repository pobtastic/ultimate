52645: Test Move Up
Checks the walls for an object that is moving in the direction of heading zero. The front edge is the vertical position plus the vertical size. The two ends of that edge, now and after the move, are checked with CheckWallVertical.
Input
IX The address of the object
Output
F The carry flag is set if the object hit a wall
