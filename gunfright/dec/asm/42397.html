42397: Messaging: Score Text
The messages shown when the top score has been beaten. Each is an attribute byte, the characters and a zero terminator. The 94 in the last message is the dollar sign of the font, and the score digits are written over the spaces after it.
ScoreMessages 42397 DEFB 67 Attribute: INK:MAGENTA, PAPER:BLACK (BRIGHT).
42398 DEFM "WELL DONE" "WELL DONE".
42407 DEFB 0 Terminator.
ScoreMessages_Player 42408 DEFB 68 Attribute: INK:GREEN, PAPER:BLACK (BRIGHT).
42409 DEFM "PLAYER " "PLAYER ".
42416 DEFB 32 The number of the winning player, written by CheckTopScore_Winner. It is a space until then.
42417 DEFB 0 Terminator.
ScoreMessages_TodaysTop 42418 DEFB 70 Attribute: INK:YELLOW, PAPER:BLACK (BRIGHT).
42419 DEFM "TODAYS TOP" "TODAYS TOP".
42429 DEFB 0 Terminator.
ScoreMessages_ScoreIs 42430 DEFB 69 Attribute: INK:CYAN, PAPER:BLACK (BRIGHT).
42431 DEFM "SCORE IS" "SCORE IS".
42439 DEFB 0 Terminator.
ScoreMessages_Score 42440 DEFB 71 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT).
42441 DEFB 94 The dollar sign.
42442 DEFM " " A space.
ScoreMessages_ScoreDigits 42443 DEFM " " Room for the six digits of the score.
42449 DEFB 0 Terminator.
