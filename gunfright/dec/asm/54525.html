54525: Build Shift Tables
Used by the routine at InitialiseGame.
Builds ShiftTables, ReversedShiftTables and ReverseTable, which the routines for drawing sprites use. Each table is a page, which has an entry for each value of a byte at the low byte of the address. For a byte which is moved to the right along a row by six pixels, page 254 has the part which stays in the byte and page 255 has the part which moves into the next byte. Pages 252 and 253 are the same for four pixels, and pages 250 and 251 for two. Pages 246 and 247 244 and 245 and 242 and 243 are the same for the byte with its bits turned round, which is used for sprites which are reflected. ReverseTable has each byte with its bits turned round.
