44848: Play Rumble

Plays sixteen short tones, using the first sixteen bytes of the ROM as the length of each.
Use the first sixteen bytes of the ROM as tone lengths.
PlayRumble 44848 LD HL,0 Point HL at the start of the ROM.
44851 LD E,16 Set the number of tones.
Play each tone.

44854 INC HL Move on to the next byte.
44855 AND %01111111 Keep the bottom seven bits.
44857 LD B,A Use them as the length of a pulse.
