44278: Handle Menu Bullet
The routine for state 4 of a menu entry: a bullet flying across the screen. It moves the bullet right two pixels, draws it and makes a click. Every eight pixels once it is past the left of the text, it prints the next character of the line of text in the bullet's wake. When the bullet reaches the edge of the screen the entry goes back to state 1. If the game has been started, the title screen returns to the caller.
HandleMenuBullet 44278 LD A,(IX+1) Fetch the horizontal position of the bullet.
44281 ADD A,2 Move it two pixels to the right.
44283 LD (IX+1),A Store the new horizontal position of the bullet.
44286 CP 248 Jump to HandleMenuBullet_Finished to finish with the bullet if it has reached the edge.
44288 JP NC,HandleMenuBullet_Finished
44291 CALL DrawMenuSprite Draw the bullet.
44294 CALL PlayBulletSound Make a click.
44297 LD A,(41486) Fetch the number of the entry.
44300 DEC A Subtract one.

44303 DEC A Subtract one.
44304 JR Z,HandleMenuBullet_Controls Jump to HandleMenuBullet_Controls if this is the second entry.
This is the third entry, which always says "START GAME".

Print the next character of the text when the bullet is at the right place.
HandleMenuBullet_Print 44328 LD A,(IX+1) Fetch the horizontal position of the bullet.
44331 SUB 8 Move eight pixels to the left to find the position of the character.
44333 LD E,A Keep the horizontal position of the character in E.
44334 LD A,(IX+2) Fetch the vertical position of the bullet.

44344 RET NZ Return if it is.
