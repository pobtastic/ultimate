52414: Facing Flags
One byte for each heading. Bit 6 flips the sprites, and bit 2 chooses the second set of walking frames. When ViewRotation is set, SetFacingFlags XORs the heading with two, so opposite headings swap.
FacingFlags 52414 DEFB %00000000 Heading zero.
52415 DEFB %01000100 Heading one.
52416 DEFB %00000100 Heading two.
52417 DEFB %01000000 Heading three.
