54819: Draw Tile Column
Used by the routines at DrawTelegramFrame and DrawBorder.
Draws a number of tiles one below another.
Input
A The tile
E The number of tiles
BC The address of the tile set
HL The screen address of the top
A' The attribute
Draw a tile and move down a row.
DrawTileColumn 54819 PUSH AF Stash the tile on the stack.
54820 CALL DrawTile Call DrawTile.
54823 CALL MoveDownRow Call MoveDownRow.
54826 POP AF Restore the tile from the stack.
54827 DEC E Count down the tiles.
54828 JR NZ,DrawTileColumn Jump to DrawTileColumn if there are any left.
54830 RET Return.
