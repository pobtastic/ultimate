51663: Fill Chamber
Used by the routines at ReloadRevolver, FireRevolver, FlashChamber and DrawRevolverDisplay.
Fills a two-by-two block of screen attributes from HL.
Input
A The attribute
HL The address of the first attribute
Set the size of the block.
FillChamber 51663 LD BC,514 Set the width and height to 2.
51666 LD DE,30 Set the distance to the next row to 30.
Fill each row.
FillChamber_Row 51669 PUSH BC Stash the width and height on the stack.
FillChamber_Attribute 51670 LD (HL),A Set an attribute.
51671 INC HL Move on.
51672 DJNZ FillChamber_Attribute Jump to FillChamber_Attribute until the row is done.
51674 ADD HL,DE Move on to the next row.
51675 POP BC Restore the width and height from the stack.
51676 DEC C Jump to FillChamber_Row until all of the rows are done.
51677 JR NZ,FillChamber_Row
51679 RET Return.
