54942: Draw Tile Horizontal
Used by the routine at DrawTilePixels.
Draws a tile reflected horizontally, using the page of bytes turned round which is at 249.
Input
DE The address of the tile
HL The screen address
Draw each line turned round.
DrawTileHorizontal 54942 LD B,8 Set the number of lines.
DrawTileHorizontal_Line 54944 LD A,(DE) Fetch a line and keep it in C.
54945 INC DE
54946 LD C,A
54947 PUSH BC Save the counters.
54948 LD B,249 Point BC at the page of bytes turned round.
54950 LD A,(BC) Draw the line turned round.
54951 LD (HL),A
54952 INC H
54953 POP BC Restore the counters.
54954 DJNZ DrawTileHorizontal_Line Go back for the next line.
54956 RET Return.
