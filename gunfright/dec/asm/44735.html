44735: Sound Effect Notes
The notes of the sound effects. The notes of each effect are played from the end back to the start. The first byte is not used.
SoundEffectNotes 44735 DEFB 32 Not used.
44736 DEFB 48,64,80,96,80,64,128 The first seven notes for HandleHorse (the horse).
SoundEffectNotes_BeforeMoneyBag 44743 DEFB 32 The last note, which is played first.
44744 DEFB 160,48,144,64,128,80,96 The first seven notes for HandleMoneyBag (the money bag).
SoundEffectNotes_BeforeBag 44751 DEFB 44 The last note, which is played first.
44752 DEFB 40,36,32 The first three notes for HandleBag_PlaySound. The fourth note, which is played first, is the first byte of the next routine.
