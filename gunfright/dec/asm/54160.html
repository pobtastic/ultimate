54160: Draw Bounty Digits
Used by the routines at HandleMoneyBag, HandleHorse, TakeFine, GiveReward, HandleBag and ReloadRevolver.
Draws the six digits of Bounty. The number is at a different place on the screen in the town.
Set the attribute and the number.

54162 EX AF,AF'
54163 LD DE,41559 Point DE at Bounty.
Choose the screen address.
54166 LD A,(41575) Fetch TownOffset.
54169 AND A
54170 LD HL,20674 Point HL at 20674 (in the screen buffer).
54173 JR NZ,DrawBountyDigits_Draw Jump to DrawBountyDigits_Draw if this is the town.
54175 LD HL,20594 Point HL at 20594 (in the screen buffer).
Draw the digits.
DrawBountyDigits_Draw 54178 LD B,3 Set a count of 3 bytes.
