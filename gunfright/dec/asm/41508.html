41508: Sprite Jump Opcode
Used by the routines at DrawSpriteRow and DrawFlippedRow.
The opcode of a 195 ("JP") instruction, which is written when the game starts. It is followed by its address, so the routines for drawing sprites jump from here to the code for the columns of the sprite.
SpriteJumpOpcode 41508 DEFB 0
