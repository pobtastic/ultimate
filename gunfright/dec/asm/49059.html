49059: Draw Flipped Aligned Columns
Draws the columns of a sprite which is flipped but not shifted. There is a piece of code for each of up to five columns, and the code for the width of the sprite is where the jump at SpriteJumpOpcode starts. Each piece takes the mask and the pixels for one byte from the sprite data on the stack, turns them round with the table, wipes the screen where the mask is and puts the pixels in. It works from right to left.
The jump at SpriteJumpOpcode starts here for five columns.
