45685: Count Down Delay
Used by the routine at HandlePointer.
Counts down byte 13 of an object by two. When it goes below zero it is set to a new value, and so a figure which calls this routine gets an event every few frames.
Input
A The new value
IX The address of the object
CountDownDelay 45685 DEC (IX+13) Count down byte 13.
45688 DEC (IX+13) Count it down again.
45691 RET P Return if it has not gone below zero.
45692 LD (IX+13),A Set it to the new value.
45695 RET Return.
