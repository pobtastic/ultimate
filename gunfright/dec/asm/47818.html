47818: Messaging: Draw Text
The two "DRAW!!" messages, each of which is an attribute byte (red, then yellow), characters and a zero byte. Each "!" is the character code 93 which is why they are not text.
DrawMessages 47818 DEFB 66 Attribute: INK:RED, PAPER:BLACK (BRIGHT).
47819 DEFM "DRAW" "DRAW"
47823 DEFB 93,93 Two exclamation marks.
47825 DEFB 0 Terminator.
DrawMessages_Yellow 47826 DEFB 70 Attribute: INK:YELLOW, PAPER:BLACK (BRIGHT).
47827 DEFM "DRAW" "DRAW"
47831 DEFB 93,93 Two exclamation marks.
47833 DEFB 0 Terminator.
