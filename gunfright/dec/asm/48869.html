48869: Finish Sprite Row
Used by the routines at DrawAlignedColumns and DrawFlippedAlignedColumns.
Moves to the next row of the buffer after a row of a sprite has been drawn, and starts the next row if there are any left.
FinishSpriteRow 48869 LD A,(41511) Fetch the distance from SpriteRowStep to the start of the next row.
48872 ADD A,C Add it to the low byte of the buffer address.
48873 LD C,A Set the low byte.
48874 LD A,B Fetch the high byte.
48875 ADC A,0 Add the carry.
48877 LD B,A Set the high byte.
48878 EX AF,AF' Fetch the number of rows left.
48879 DEC A Take one off.
Draw the next row if there are any left.
48880 JP NZ,DrawSpriteRow Jump to DrawSpriteRow if there are any.
48883 LD SP,(41501) Restore the stack pointer.
48887 RET Return.
