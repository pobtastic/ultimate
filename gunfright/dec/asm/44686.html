44686: Fill Attribute Column
Used by the routine at GameMenu.
Sets the attributes of one column of the screen, which is twenty four cells.
Input
C The attribute
HL The address of the attribute at the top of the column
FillAttributeColumn 44686 LD B,24 Set the number of rows.
44688 LD DE,32 Set the distance between rows.
FillAttributeColumn_Loop 44691 LD (HL),C Set the attribute of the cell.
44692 ADD HL,DE Move down a row.
44693 DJNZ FillAttributeColumn_Loop Loop back until every row has been done.
44695 RET Return.
