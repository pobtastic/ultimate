45708: Draw Wide Sprite
Used by the routine at DrawWideSprites.
Draws a sprite which is eight rows high and four bytes wide into a buffer which has twenty four bytes in each row. The pixels are combined with what is already in the buffer. The horizontal pixel position is in SpriteHorizontalPosition: if it is not a multiple of eight, the sprite data is a list of indexes into the tables which shift a byte by two, four or six pixels, and the sprite takes five bytes in each row of the buffer. The routine takes the data from the stack to make it faster.
Input
A The number of the sprite
HL The address in the buffer
Find the data of the sprite.

45724 AND %00000110 Keep the offset within the byte.
45726 JR Z,DrawWideSprite_Aligned Jump to DrawWideSprite_Aligned if the sprite is on a byte boundary.
The sprite is not on a byte boundary, so shift it using the shift tables.

45731 LD A,8 Set the number of rows to eight.

DrawWideSprite_Done 45777 LD SP,(41501) Restore the stack pointer.
