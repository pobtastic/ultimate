54000: Draw Double Lines
Used by the routine at DrawDoubleHeightCharacter.
Draws 4 bytes as 8 lines, with each byte drawn twice.
Input
DE The address of the bytes
HL The screen address
Output
DE The address after the bytes
Draw four bytes, each on two lines.
DrawDoubleLines 54000 LD B,4 Set a count of 4 bytes.
DrawDoubleLines_Next 54002 LD A,(DE) Draw the next byte on two lines.
54003 INC DE
54004 LD (HL),A
54005 INC H
54006 LD (HL),A
54007 INC H
54008 DJNZ DrawDoubleLines_Next Jump to DrawDoubleLines_Next if there are any left.
54010 RET Return.
