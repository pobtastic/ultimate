48074: Move Duel Outlaw
Used by the routine at HandleWaitingOutlaw.
Moves the outlaw in the duel by his speeds. Both his positions are single bytes in this stage.
Input
IX The address of the outlaw
MoveDuelOutlaw 48074 LD A,(IX+2) Fetch the horizontal position.
48077 ADD A,(IX+1) Add the horizontal speed.
48080 LD (IX+2),A Set the new horizontal position.
48083 LD A,(IX+4) Fetch the vertical position.
48086 ADD A,(IX+3) Add the vertical speed.
48089 LD (IX+4),A Set the new vertical position.
48092 RET Return.
