51093: Handle Smoke
Type 7: a puff of smoke. It counts down byte 12 then calls GetTableEntry to fetch a sprite list from SmokeSpriteLists. It jumps to HandleBody_Remove when the counter goes below zero.
Input
IX The address of the object
Count down the frames.
HandleSmoke 51093 DEC (IX+12) Count down byte 12.
51096 JP M,HandleBody_Remove Jump to HandleBody_Remove if it is negative.
Point at SmokeSpriteLists.
51099 LD BC,51115 Point BC at SmokeSpriteLists.
This entry point is used by the routine at HandleBystander.
Choose the sprite list. BC holds the table.
ChooseSpriteList 51102 LD A,(IX+12) Fetch byte 12.
51105 CALL GetTableEntry Call GetTableEntry.
51108 LD (IX+14),L Set the sprite list and return.
51111 LD (IX+15),H
51114 RET
