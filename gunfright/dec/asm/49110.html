49110: Draw Flipped Row
Used by the routines at DrawFlippedSprite and FinishFlippedSpriteRow.
Starts to draw a row of a flipped sprite. The number of rows left is kept in the alternate accumulator while the code for the columns uses A. The jump at SpriteJumpOpcode goes to the code for the columns of the sprite.
DrawFlippedRow 49110 EX AF,AF' Save the number of rows left, and get A.
49111 LD A,(BC) Fetch the first byte of the row from the buffer.
Jump to the code for the columns.
DrawFlipped_SpriteJump 49112 JP 41508 Jump to SpriteJumpOpcode.
