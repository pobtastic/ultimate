47066: Messaging: Game Over Text
The two messages of the game over screen. Each is an attribute byte, the characters and a zero terminator.
GameOverTexts 47066 DEFB 69 Attribute: INK:CYAN, PAPER:BLACK (BRIGHT).
47067 DEFM "GAME OVER" "GAME OVER".
47077 DEFB 0 Terminator.
GameOverTexts_Player 47078 DEFB 69 Attribute: INK:CYAN, PAPER:BLACK (BRIGHT).
47079 DEFM "PLAYER " "PLAYER ".
47086 DEFB 63 The number of the player, written by ShowGameOver.
47087 DEFB 0 Terminator.
