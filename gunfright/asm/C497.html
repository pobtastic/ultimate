C497: Clip Edge Strip Top
Used by the routine at DrawStripGraphic.
Skips the rows of an image that are below PlayfieldBuffer. A is the number of those rows, negated. It starts drawing at 48 and jumps to DrawStripGraphic_Draw.
Input
A The number of rows below the buffer, negated
HL The address of the image
Skip the rows that are below the buffer.

C49D RET M Return if there are none left.
C49E RET Z
C49F LD B,$00 Skip the image data for those rows.
