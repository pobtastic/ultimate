BE8A: Draw Shifted Columns
Draws the columns of a sprite which is shifted to the right by two, four or six pixels. There is a piece of code for each of up to five columns of the sprite, and the code for the width of the sprite is where the jump at SpriteJumpOpcode starts. Each piece puts a column into two bytes of the buffer, using the table for the shift to split the mask and the pixels in two. The buffer address is in BC.
DrawShiftedColumns BE8A CPL Invert the screen byte, and fetch the mask into E and the pixels into D.
