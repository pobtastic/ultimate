C910: Handle Mounted Sheriff
Type 15: the sheriff on a horse. On every fourth frame it counts RidingTimer down. When that reaches zero, TopSpeed is set to 0A the speed to 08 and the type to 01.
Input
IX The address of the sheriff
Jump to HandleSheriff unless it is time to count down.
HandleMountedSheriff C910 LD A,($A216) Fetch FrameCounter.
C913 ADD A,$02 Add 02.
C915 AND %00000011 Keep the lowest two bits.
C917 JR NZ,HandleSheriff Jump to HandleSheriff if this is not every fourth frame.
Count down RidingTimer.
C919 LD HL,$A209 Point HL at RidingTimer.
C91C LD A,(HL) Jump to HandleSheriff if RidingTimer is zero.
C91D AND A
C91E JR Z,HandleSheriff
C920 DEC (HL) Count RidingTimer down.
C921 JR NZ,HandleSheriff Jump to HandleSheriff if it is not zero.
Get off the horse.
C923 LD A,$0A Set TopSpeed to 0A.
C925 LD ($A21F),A
C928 LD (IX+$05),$08 Set the speed to 08.
C92C LD (IX+$00),$01 Make the type 01.
Continue on to HandleSheriff.
