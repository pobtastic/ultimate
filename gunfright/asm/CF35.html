CF35: Check Wall Vertical
Used by the routine at TestMoveUp.
Checks whether an object that is moving in the direction of heading zero touches a wall in the cell containing a point. If it does, VerticalSpeed is reduced by twice the depth and the object is marked as having hit a wall.
Input
DE The horizontal position of the point
HL The vertical position of the point
IX The address of the object
Output
F The carry flag is set if the object hit a wall
Check the walls, then push the object back if it is touching one.
CheckWallVertical CF35 CALL CheckWallsHorizontalFirst Call CheckWallsHorizontalFirst.
CF38 RET NC Return if the object is not touching a wall.
