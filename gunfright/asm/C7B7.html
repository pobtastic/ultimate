C7B7: Handle Body
Type 08: a body lying on the ground. It counts down byte 0C then makes the type 00. HandleDying makes it last for 20 frames.
Input
IX The address of the object
Count down the frames.
HandleBody C7B7 DEC (IX+$0C) Count down byte 0C and return if it is not zero.
C7BA RET NZ
This entry point is used by the routines at HandleMoneyBag, HandleTumbleweed, HandleHorse, HandleCactus, HandlePointer, HandleBystander, HandleOutlawGun, MakeBulletHole and HandleSmoke.
Make the type 00.
HandleBody_Remove C7BB LD (IX+$00),$00 Make the type 00 and return.
C7BF RET
