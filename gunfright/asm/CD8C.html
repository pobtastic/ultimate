CD8C: Test Move
Used by the routines at HandleOutlaw, HandleBystander, HandleBullet, MovePlayerForward and CheckWallsEachWay.
Checks whether an object can move in the direction of its heading without going into a wall. A wall changes the speeds so that the object stops, and sets bit 0 of the flags.
Input
IX The address of the object
Output
F The carry flag is set if the object hit a wall
Clear bit 0 of the flags, then run the routine for the heading.
TestMove CD8C RES 0,(IX+$07) Clear bit 0 of the flags of the object.
