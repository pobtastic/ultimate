B318: Create Direction Pointer
Used by the routine at CreateTownObjects.
Called every frame in the town. Puts a pointing hand (an object of type 0B) in the sixth object slot, next to the sheriff, if the slot is free. HandlePointer makes it point towards the outlaw.
Use the sixth slot if it is free.
CreateDirectionPointer B318 LD DE,$A2CD Point DE at the sixth object slot.
B31B LD A,(DE) Fetch the type of the object in the slot.
B31C AND A Return if the slot is in use.
B31D RET NZ
