D69E: Draw Tile Horizontal
Used by the routine at DrawTilePixels.
Draws a tile reflected horizontally, using the page of bytes turned round which is at F9.
Input
DE The address of the tile
HL The screen address
DrawTileHorizontal D69E LD B,$08 Set the number of lines.
DrawTileHorizontal_Line D6A0 LD A,(DE) Fetch a line and keep it in C.
D6A1 INC DE
D6A2 LD C,A
D6A3 PUSH BC Save the counters.
D6A4 LD B,$F9 Point BC at the page of bytes turned round.
D6A6 LD A,(BC) Draw the line turned round.
D6A7 LD (HL),A
D6A8 INC H
D6A9 POP BC Restore the counters.
D6AA DJNZ DrawTileHorizontal_Line Go back for the next line.
D6AC RET Return.
