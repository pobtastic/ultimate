B420: Create Outlaw
Used by the routine at CreateTownObjects.
Called every frame in the town. Puts the outlaw (an object of type 0A or 16) in a random cell of the town in the fifth object slot if the slot is free and the cell is not blocked. The outlaw is made faster, and given type 16, if a random number is less than sixteen times the level (the level is reduced by four from level sixteen).

B423 LD A,(DE) Fetch the type of the object in the slot.

B425 RET NZ Return if it is.

B429 LD HL,$B484 Point HL at OutlawTemplate.
