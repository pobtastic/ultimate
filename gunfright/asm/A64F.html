A64F: Check Telegram Complete
Used by the routine at UpdatePrices.
Checks whether every line of the telegram has been typed in full. A line is complete when its counter has reached 0E.
Output
F The zero flag is set if every line is complete
Check each of the six telegram lines.
CheckTelegramComplete A64F LD HL,$A830 Point HL at the first telegram line.
A652 LD DE,$0012 Set the size of a telegram line in DE.
A655 LD B,$06 Set the number of lines to six.
Return unless this line is complete.
CheckTelegramComplete_Loop A657 LD A,(HL) Fetch the counter of the line.
A658 CP $0E Compare it with the number of characters in a line.
A65A RET NZ Return if the line is not complete.
A65B ADD HL,DE Move on to the next line.
A65C DJNZ CheckTelegramComplete_Loop Loop back until all six lines have been checked.
A65E RET Return.
