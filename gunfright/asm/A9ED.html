A9ED: Create Cactus
Used by the routine at CreateTownObjects.
Called every frame in town. Cacti stand in eight fixed cells of the town (see CactusPositions). When the sheriff comes within two cells of one, and the seventh object slot is free, the routine puts a cactus (an object of type 13) in the slot.
Return if the seventh slot is in use.
CreateCactus A9ED LD A,($A2DD) Fetch the type of the object in the seventh slot.
A9F0 AND A Return if the slot is in use.
A9F1 RET NZ
