C2BA: Choose Other Object
Used by the routine at CompareObjectDepths.
Swaps the first object for the second one, which has to be drawn before it.
Input
IY The address of the second object
ChooseOtherObject C2BA LD HL,($A24C) Make the place in the list after the second object the place after the first object.
C2BD LD ($A24A),HL
C2C0 PUSH IY Copy the address of the second object into IX (using the stack).
C2C2 POP IX
C2C4 RET Return.
