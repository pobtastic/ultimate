BEE5: Finish Sprite Row
Used by the routines at DrawAlignedColumns and DrawFlippedAlignedColumns.
Moves to the next row of the buffer after a row of a sprite has been drawn, and starts the next row if there are any left.
FinishSpriteRow BEE5 LD A,($A227) Fetch the distance from SpriteRowStep to the start of the next row.
BEE8 ADD A,C Add it to the low byte of the buffer address.
BEE9 LD C,A Set the low byte.
BEEA LD A,B Fetch the high byte.
BEEB ADC A,$00 Add the carry.
BEED LD B,A Set the high byte.
BEEE EX AF,AF' Fetch the number of rows left.
BEEF DEC A Take one off.
Draw the next row if there are any left.
BEF0 JP NZ,DrawSpriteRow Jump to DrawSpriteRow if there are any.
BEF3 LD SP,($A21D) Restore the stack pointer.
BEF7 RET Return.
