C7C0: Handle Single Frame Object
Type 05: an object which is drawn once and then removed. MakeFlash makes it. It calls DrawObject and then makes the type 00.
Input
IX The address of the object
Draw the object and remove it.
HandleSingleFrameObject C7C0 CALL DrawObject Call DrawObject.
C7C3 LD (IX+$00),$00 Make the type 00 and return.
C7C7 RET
