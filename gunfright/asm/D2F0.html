D2F0: Draw Double Lines
Used by the routine at DrawDoubleHeightCharacter.
Draws 04 bytes as 08 lines, with each byte drawn twice.
Input
DE The address of the bytes
HL The screen address
Output
DE The address after the bytes
Draw four bytes, each on two lines.
DrawDoubleLines D2F0 LD B,$04 Set a count of 04 bytes.
DrawDoubleLines_Next D2F2 LD A,(DE) Draw the next byte on two lines.
D2F3 INC DE
D2F4 LD (HL),A
D2F5 INC H
D2F6 LD (HL),A
D2F7 INC H
D2F8 DJNZ DrawDoubleLines_Next Jump to DrawDoubleLines_Next if there are any left.
D2FA RET Return.
