D2DD: Draw Double Height Character
Used by the routine at DrawCharacter.
Draws the two halves of a character, one on top of the other, each with the attribute.
Input
DE The address of the character
HL The screen address
A' The attribute
Draw the upper half.
DrawDoubleHeightCharacter D2DD PUSH HL Stash the screen address on the stack.
D2DE CALL DrawDoubleLines Call DrawDoubleLines.
D2E1 POP HL Restore the screen address from the stack.
Set the attribute of the upper half.
D2E2 CALL SetTileAttribute Call SetTileAttribute.
Move down a row.
D2E5 CALL MoveDownRow Call MoveDownRow.
Draw the lower half.
D2E8 PUSH HL Stash the screen address on the stack.
D2E9 CALL DrawDoubleLines Call DrawDoubleLines.
D2EC POP HL Restore the screen address from the stack.
Set the attribute of the lower half.
D2ED JP SetTileAttribute Jump to SetTileAttribute.
