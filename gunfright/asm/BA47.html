BA47: Draw Outlaw Face
Used by the routine at HandleShotOutlaw.
Draws the face of the outlaw, which is five sprites, into the buffer, below the body.
Input
HL The address in the buffer
DrawOutlawFace BA47 LD A,($A260) Fetch the level.
BA4A EX DE,HL Swap the address in the buffer into DE.
BA4B LD HL,$B494 Point HL at OutlawNumbers.
BA4E CALL AddAToHL Point HL at the entry for the level.
BA51 LD L,(HL) Fetch the number of the outlaw.
BA52 LD H,$00 Set the high byte.
BA54 LD C,L Make the outlaw number a sixteen bit index in BC.
BA55 LD B,H
BA56 ADD HL,HL Multiply it by four.
BA57 ADD HL,HL
BA58 ADD HL,BC Add the number to make it five times as big.
BA59 LD BC,$B5B0 Point BC at FaceImageNumbers.
BA5C ADD HL,BC Point HL at the sprites of his face.
BA5D EX DE,HL Swap the pointer to the face into DE and the address back into HL.
BA5E LD B,$05 Set the number of sprites to five.
BA60 JP DrawWideSprites Jump to DrawWideSprites.
