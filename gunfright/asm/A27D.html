A27D: Object Slot 1
The first slot, which holds the sheriff in the town, the outlaw in the duel and the first of the money bags in the stage of the bags. There are fifteen slots of sixteen bytes. The first byte of a slot is the type of the object, which is zero for a slot which is not used. The layout of a slot is: byte 00 the type; bytes 01 and 02 the horizontal position; bytes 03 and 04 the vertical position; byte 05 the speed; byte 06 the heading, in bits 6 and 7, with zero for up the screen, one for the right, two for down and three for the left, and the time to turn in bits 0 to 2; byte 07 the flags, in which bit 0 says that the object has bumped into something, bit 1 says that it has been drawn and bit 6 says that it is flipped; bytes 08 and 09 the half width and the half height; bytes 0A and 0B counters; byte 0C the walking frame, in which bit 2 chooses the second set of frames; byte 0D the vertical offset; and bytes 0E and 0F the address of the sprite list.
