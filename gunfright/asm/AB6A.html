AB6A: Scenery List
The scenery sprites in the town. Each has three bytes: the number of the sprite (with bit 6 set if it is flipped), the horizontal offset and the vertical offset from the origin. A zero byte ends the list.
SceneryList AB6A DEFB $01,$20,$20
AB6D DEFB $41,$90,$60
AB70 DEFB $01,$60,$20
AB73 DEFB $41,$C0,$30
AB76 DEFB $00 Terminator.
