C766: Run Table Routine
Used by the routines at InitialiseGame, GameMenu, RunStageScript, DrawObjectsInList, MovePlayer and TestMove.
Calls GetTableEntry to fetch a routine from a table, then jumps to IndirectJump so that the routine returns to the caller of this one.
Input
A The number of the entry
BC The address of the table
Fetch the address and jump to it.
RunTableRoutine C766 CALL GetTableEntry Call GetTableEntry.
C769 JP IndirectJump Jump to IndirectJump.
