B3BD: Create Town Objects
Used by the routine at InitialiseGame.
Called every frame. In the town stage it updates the prices and makes new objects if there are free slots: bystanders, the outlaw, the pointer, money bags, cacti, the horse and the tumbleweed.
Return unless this is the town stage.
CreateTownObjects B3BD LD A,($A267) Return if this is a stage outside the town, which is the duel or the bonus stage.
B3C0 AND A
B3C1 RET Z
Update the prices and make any missing town objects.
B3C2 CALL UpdatePrices Update the prices.
B3C5 CALL CreateBystander Make a bystander if there is a free slot.
B3C8 CALL CreateOutlaw Make the outlaw if there is a free slot.
B3CB CALL CreateDirectionPointer Make the pointer if there is a free slot.
B3CE CALL CreateMoneyBag Make a money bag if there is a free slot.
B3D1 CALL CreateCactus Make a cactus if there is a free slot.
B3D4 CALL CreateHorse Make the horse if there is a free slot.
B3D7 JP CreateTumbleweed Jump to CreateTumbleweed.
