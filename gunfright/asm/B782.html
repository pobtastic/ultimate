B782: Start Dying
Used by the routine at KillSheriff.
Turns an object into a dying object (type 09), which falls and bounces, and then lies on the ground as a dead figure.
Input
IX The address of the object
StartDying B782 LD (IX+$00),$09 Turn the object into a dying object.
B786 LD (IX+$0C),$FA Set the counter.
B78A LD (IX+$0D),$18 Set the speed of the fall.
B78E LD HL,$B7A4 Point HL at BystanderSpriteLists_DeadFigure.
B791 LD (IX+$0E),L Store the low byte of the address.
B794 LD (IX+$0F),H Store the high byte of the address.
B797 RET Return.
