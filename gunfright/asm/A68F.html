A68F: Set Up Player
Used by the routine at SetUpPlayers.
Gives the current player the starting values for a new game: four lives, level zero, a bounty of $280, and the first stage, in which the player shoots twenty money bags.
Give the player four lives and start at level zero.
SetUpPlayer A68F LD A,$04 Write 04 to Lives to give the player four lives.
A691 LD ($A263),A
A694 XOR A Write 00 to Level to start on level zero.
A695 LD ($A260),A
A698 LD ($A261),A Write 00 to Skill to start at the easiest difficulty.
Set the starting bounty and the first stage.
A69B LD BC,$0280 Set the starting bounty of $280 in BC.
A69E CALL AddToBounty Add it to the bounty.
A6A1 LD HL,$0114 Set the number of targets to twenty and the stage type to the money bag shoot.
A6A4 LD ($A264),HL Store them.
A6A7 LD A,$46 Write 46 to ScreenAttribute to colour the border and screen yellow.
A6A9 LD ($A266),A
Make sure the prices are set.
A6AC CALL ResetBulletPrice Make sure the price of a bullet is set.
A6AF CALL ResetHorsePrice Make sure the price of a horse is set.
A6B2 JP ResetFine Jump to ResetFine.
