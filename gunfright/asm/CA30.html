CA30: Make Flash
Used by the routine at MakeShot.
Puts a type 05 flash in ObjectSlot_14. It copies the type and position of the object which fires, is eight by eight, and is drawn for one frame from FlashSpriteList.
Input
IX The address of the object which fires
Output
F The carry flag is set
Copy the type and position into ObjectSlot_14.
MakeFlash CA30 PUSH IX Copy IX to HL (using the stack).
CA32 POP HL
CA33 LD DE,$A34D Point DE and IY at ObjectSlot_14 (using the stack).
CA36 PUSH DE
CA37 POP IY
CA39 LD BC,$0005 Set a count of 05.
CA3C LDIR Copy the type and position.
Turn the slot into a flash.
CA3E LD (IY+$00),$05 Make the type 05.
CA42 LD HL,$CA59 Point HL at FlashSpriteList.
CA45 LD (IY+$08),$08 Set the horizontal size to 08.
CA49 LD (IY+$09),$08 Set the vertical size to 08.
CA4D LD (IY+$0D),$00 Clear the vertical offset.
CA51 LD (IY+$0E),L Set the sprite list.
CA54 LD (IY+$0F),H
CA57 SCF Set the carry flag and return.
CA58 RET
