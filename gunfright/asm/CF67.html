CF67: Find Position In Cell
Used by the routines at CheckWallsVerticalFirst and CheckWallsHorizontalFirst.
Finds the code of the cell at column D and row H in TownMap, and where the object is in that cell. The position in the cell is half the distance from the corner, plus 40.
Input
D The column of the cell
H The row of the cell
IX The address of the object
Output
A The code of the cell
D The vertical position of the object in the cell
E The horizontal position of the object in the cell
F The zero flag is set if the cell is empty
Keep the row and column, and find the corner of the cell.
FindPositionInCell CF67 LD B,H Keep the row in B and the column in C.

CF69 PUSH BC Stash the row and column on the stack.
CF6A LD C,$00 Make DE the corner of the column, and BC the corner of the row.
CF6C LD E,C
Find the horizontal position of the object in the cell.
