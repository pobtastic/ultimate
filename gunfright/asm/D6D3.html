D6D3: Set Attributes
Used by the routines at CheckTopScore, ShowPlayerNumber, GameMenu, ShowGameOver and DrawGameScreen.
Sets all of the attributes to a value.
Input
E The attribute
SetAttributes D6D3 LD HL,$5800 Point HL at 5800 (in the attribute buffer).
D6D6 LD BC,$0300 Set the number of attributes.
D6D9 JR FillMemory_WithValue Jump to clear them.
