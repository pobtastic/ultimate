C6C7: Project Object
Used by the routine at DrawScrollingObject.
Works out where an object is on the screen, in the same way as ProjectCell. It fetches the position from the slot, calls ConvertPosition, and jumps to ProjectCell_Position. The result is put in ScreenHorizontalPosition and ScreenVerticalPosition.
Input
IX The address of the object
Fetch the position and convert it.
ProjectObject C6C7 LD L,(IX+$03) Fetch the vertical position.
C6CA LD H,(IX+$04)
C6CD CALL ConvertPosition Call ConvertPosition.
C6D0 PUSH HL Stash it on the stack.
C6D1 LD L,(IX+$01) Fetch the horizontal position.
C6D4 LD H,(IX+$02)
C6D7 CALL ConvertPosition Call ConvertPosition.
C6DA JR ProjectCell_Position Jump to ProjectCell_Position.
