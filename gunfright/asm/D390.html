D390: Draw Bounty Digits
Used by the routines at HandleMoneyBag, HandleHorse, TakeFine, GiveReward, HandleBag and ReloadRevolver.
Draws the six digits of Bounty. The number is at a different place on the screen in the town.
Set the attribute and the number.
DrawBountyDigits D390 LD A,$47 Set the attribute to INK:WHITE, PAPER:BLACK (BRIGHT).
D392 EX AF,AF'
D393 LD DE,$A257 Point DE at Bounty.
Choose the screen address.
D396 LD A,($A267) Fetch TownOffset.
D399 AND A
D39A LD HL,$50C2 Point HL at 50C2 (in the screen buffer).
D39D JR NZ,DrawBountyDigits_Draw Jump to DrawBountyDigits_Draw if this is the town.
D39F LD HL,$5072 Point HL at 5072 (in the screen buffer).
Draw the digits.
DrawBountyDigits_Draw D3A2 LD B,$03 Set a count of 03 bytes.
D3A4 JP DrawDigits Jump to DrawDigits.
