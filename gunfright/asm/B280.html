B280: Draw Wide Sprites
Used by the routines at HandleWaitingOutlaw, DrawOutlawFace, HandleShotOutlaw and HandleDyingOutlaw.
Draws several wide sprites one after another.
Input
B The number of sprites
DE The address of the list of sprite numbers
HL The address in the buffer
DrawWideSprites B280 LD A,(DE) Fetch the number of the next sprite.
B281 INC DE Move on to the next sprite in the list.
B282 PUSH BC Stash the number of sprites on the stack.
B283 PUSH DE Stash the address of the list on the stack.
B284 CALL DrawWideSprite Draw the sprite.
B287 POP DE Retrieve the address of the list.
B288 POP BC Retrieve the number of sprites.
B289 DJNZ DrawWideSprites Loop back until all of the sprites have been drawn.
B28B RET Return.
