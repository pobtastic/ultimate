D623: Draw Tile Column
Used by the routines at DrawTelegramFrame and DrawBorder.
Draws a number of tiles one below another.
Input
A The tile
E The number of tiles
BC The address of the tile set
HL The screen address of the top
A' The attribute
Draw a tile and move down a row.
DrawTileColumn D623 PUSH AF Stash the tile on the stack.
D624 CALL DrawTile Call DrawTile.
D627 CALL MoveDownRow Call MoveDownRow.
D62A POP AF Restore the tile from the stack.
D62B DEC E Count down the tiles.
D62C JR NZ,DrawTileColumn Jump to DrawTileColumn if there are any left.
D62E RET Return.
