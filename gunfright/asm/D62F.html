D62F: Draw Tile Row
Used by the routines at DrawTelegramFrame and DrawBorder.
Draws a number of tiles side by side.
Input
A The tile
E The number of tiles
BC The address of the tile set
HL The screen address of the left
A' The attribute
Draw a tile and move on to the next column.
DrawTileRow D62F PUSH AF Stash the tile on the stack.
D630 CALL DrawTile Call DrawTile.
D633 POP AF Restore the tile from the stack.
D634 INC L Move on to the next column.
D635 DEC E Count down the tiles.
D636 JR NZ,DrawTileRow Jump to DrawTileRow if there are any left.
D638 RET Return.
