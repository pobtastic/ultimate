D54A: Draw Bounty Symbol
Used by the routine at DrawBounty.
Draws the symbol which goes before the bounty, as a block of two by two tiles.
Set the attribute and the tiles.
DrawBountySymbol D54A LD A,$47 Set the attribute to INK:WHITE, PAPER:BLACK (BRIGHT).
D54C EX AF,AF'
D54D LD DE,$D561 Point DE at BountySymbolTiles.
Choose the screen address.
D550 LD A,($A267) Fetch TownOffset.
D553 AND A
D554 LD HL,$50C0 Point HL at 50C0 (in the screen buffer).
D557 JR NZ,DrawBountySymbol_Draw Jump to DrawBountySymbol_Draw if this is the town.
D559 LD HL,$5070 Point HL at 5070 (in the screen buffer).
Draw the block.
DrawBountySymbol_Draw D55C LD BC,$0202 Set the size of the block to two by two.
D55F JR DrawTileBlock Jump to DrawTileBlock.
