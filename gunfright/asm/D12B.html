D12B: Read Kempston Joystick
Used by the routine at ReadControls.
Reads a Kempston joystick from port 1F.
Output
C The controls
Read the joystick, and start with no controls.
ReadKempstonJoystick D12B IN A,($1F) Read the joystick from port 1F.
D12D LD C,$00 Clear the controls.
Set bit 1 if the joystick is pushed right.
D12F BIT 0,A Set bit 1 if the joystick is pushed right.
