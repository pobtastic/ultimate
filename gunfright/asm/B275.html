B275: Count Down Delay
Used by the routine at HandlePointer.
Counts down byte 0D of an object by two. When it goes below zero it is set to a new value, and so a figure which calls this routine gets an event every few frames.
Input
A The new value
IX The address of the object
CountDownDelay B275 DEC (IX+$0D) Count down byte 0D.
B278 DEC (IX+$0D) Count it down again.
B27B RET P Return if it has not gone below zero.
B27C LD (IX+$0D),A Set it to the new value.
B27F RET Return.
