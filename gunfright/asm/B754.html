B754: Kill Sheriff
Used by the routines at HandleTumbleweed, HandleCactus and HandleOutlaw.
Makes the sheriff die, and removes the bullets. It is used when the sheriff touches something dangerous.
Input
IX The address of the object which killed the sheriff
IY The address of the sheriff
KillSheriff B754 PUSH IX Stash the address of the object on the stack.
B756 PUSH IY Copy the address of the sheriff into IX (using the stack).
B758 POP IX
B75A CALL StartDying Make the sheriff die.
B75D LD A,(IX+$0C) Fetch the counter of the sheriff.
B760 SUB $04 Take four off it.
B762 LD (IX+$0C),A Store the reduced delay counter.
B765 POP IX Retrieve the address of the object from the stack.
B767 LD HL,$A28D Point HL at ObjectSlot_02.
B76A LD BC,$0030 Set the size of the three bullet slots.
B76D JP FillMemory Jump to FillMemory.
