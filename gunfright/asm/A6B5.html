A6B5: Set Up Players
Used by the routine at InitialiseGame.
Gives both players the starting values. In a game for one player the second player is left with no lives.
SetUpPlayers A6B5 CALL SetUpPlayer Set up the first player.
A6B8 CALL SwapPlayerStates Swap to the state of the second player.
A6BB CALL SetUpPlayer Set up the second player.
A6BE LD A,($A21C) Fetch the option flags.
A6C1 BIT 0,A Test bit 0, which is set for a two player game.
A6C3 RET NZ Return if there are two players.
A6C4 XOR A Write 00 to OtherPlayerLives to leave the second player with no lives.
A6C5 LD ($A276),A
A6C8 RET Return.
