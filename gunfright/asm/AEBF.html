AEBF: Sound Effect Notes
The notes of the sound effects. The notes of each effect are played from the end back to the start. The first byte is not used.
SoundEffectNotes AEBF DEFB $20 Not used.
AEC0 DEFB $30,$40,$50,$60,$50,$40,$80 The first seven notes for HandleHorse (the horse).
SoundEffectNotes_BeforeMoneyBag AEC7 DEFB $20 The last note, which is played first.
AEC8 DEFB $A0,$30,$90,$40,$80,$50,$60 The first seven notes for HandleMoneyBag (the money bag).
SoundEffectNotes_BeforeBag AECF DEFB $2C The last note, which is played first.
AED0 DEFB $28,$24,$20 The first three notes for HandleBag_PlaySound. The fourth note, which is played first, is the first byte of the next routine.
