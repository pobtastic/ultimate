D2FB: Draw Game Screen
Used by the routines at InitialiseGame and CheckSheriffLost.
Draws the parts of the screen which do not change during a stage: the border of the playfield, the revolver, the frame of the telegram, the panel for the town and the lives and the bounty. The attributes are first set to the value in E and the screen is cleared.
Input
E The attribute for the whole screen
Set the attributes and clear the screen.
DrawGameScreen D2FB CALL SetAttributes Call SetAttributes.
D2FE CALL ClearScreen Call ClearScreen.
Print the telegram.
D301 CALL PrintTelegram Call PrintTelegram.
Use the tiles of the panel and the border.
D304 LD HL,$8CF0 Set TileSetAddress to ScreenTileSet.
D307 LD ($A20F),HL
Draw the border of the playfield.
D30A CALL DrawBorder Call DrawBorder.
Draw the revolver.
D30D CALL DrawRevolverDisplay Call DrawRevolverDisplay.
Draw the frame of the telegram.
D310 CALL DrawTelegramFrame Call DrawTelegramFrame.
Draw the panel of the town, if this is the town.
D313 CALL DrawTownPanel Call DrawTownPanel.
Draw the pictures at the sides, if this is not the town.
D316 CALL DrawSidePictures Call DrawSidePictures.
Draw the lives.
D319 CALL DrawLives Call DrawLives.
Draw the bounty.
D31C JP DrawBounty Jump to DrawBounty.
