C036: Finish Flipped Sprite Row
Moves to the next row of the buffer after a row of a flipped sprite has been drawn, and starts the next row if there are any left.
FinishFlippedSpriteRow C036 LD A,($A227) Fetch the distance from SpriteRowStep to the start of the next row.
C039 ADD A,C Add it to the low byte of the buffer address.
C03A LD C,A Set the low byte.
C03B LD A,B Fetch the high byte.
C03C ADC A,$00 Add the carry.
C03E LD B,A Set the high byte.
C03F EX AF,AF' Fetch the number of rows left.
C040 DEC A Take one off.
Draw the next row if there are any left.
C041 JP NZ,DrawFlippedRow Jump to DrawFlippedRow if there are any.
C044 LD SP,($A21D) Restore the stack pointer.
C048 RET Return.
