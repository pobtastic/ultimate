A449: Handle Respawn Delay
Type 19: the pause before the sheriff comes back after losing a life. The delay counter in byte 0C of the slot counts down, and then the object turns into type 1A.
HandleRespawnDelay A449 DEC (IX+$0C) Decrease the delay counter and return if it has not reached zero.
A44C RET NZ
A44D LD (IX+$00),$1A Turn the object into type 1A.
A451 RET Return.
