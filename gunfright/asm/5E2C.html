5E2C: Tile Image Numbers
The number of an image for each number of a tile in the lists of tiles of the edges of the cells of the town, which are drawn by DrawStrip. The image is found by exclusive-ORing the number with the swap flag, which turns each image into the other of its pair, and then looking it up in the table at EdgeImagePointers.
