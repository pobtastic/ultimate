A248: Column Flags
The flags, one bit each for sixteen columns of the screen which are each sixteen pixels wide, which say that a wall has been drawn in the column.
ColumnFlags A248 DEFB $C0 The flags for the first eight columns.
A249 DEFB $03 The flags for the last eight columns.
