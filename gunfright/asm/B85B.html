B85B: Run Stage Script
Used by the routine at InitialiseGame.
Called every frame. In the duel and the bonus stage, which both have TownOffset set to zero, it runs the routine for the kind of stage which is in StageKind, as long as there are still stages to play (TargetsLeft is not zero). In kind 00 nothing happens, in kind 01 money bags are made, and in kind 02 the duel is set up.
This routine is only for the duel and the bonus stage.
RunStageScript B85B LD A,($A267) Return if TownOffset is not zero, so this is the town.
