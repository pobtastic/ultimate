BA8B: Check For Early Draw
Used by the routine at HandleWaitingOutlaw.
Reads the controls while the outlaw is waiting. If the player moves the crosshair or fires, the outlaw is provoked and starts to draw at once, and "DRAW!!" appears in yellow, if it is not already on the screen.
Input
IX The address of the outlaw

BA8E AND A Return if the outlaw has already been provoked.
BA8F RET NZ

BA93 AND A Return if nothing has been pressed.
BA94 RET Z
BA95 LD A,$01 Set the flag to one.
BA97 LD (IX+$06),A Store the flag which shows the outlaw is provoked.
BA9A LD (IX+$0A),A Make this the last move.

Print the "DRAW!!" message.
