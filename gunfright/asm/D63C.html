D63C: Set Tile Attribute
Used by the routines at PrintLeftHalfOfCharacter, PrintRightHalfOfCharacter and DrawDoubleHeightCharacter.
Sets the attribute of the character square that holds the screen address.
Input
HL The screen address
A' The attribute
Find the attribute address from the screen address.
