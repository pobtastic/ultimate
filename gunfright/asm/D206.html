D206: Pause Game
Used by the routine at InitialiseGame.
Pauses the game if CAPS SHIFT or SPACE is pressed on its own. PlayPauseSound is played at the start and at the end. The game carries on when CAPS SHIFT or SPACE is pressed again.
Return unless CAPS SHIFT or SPACE is the only key being pressed.
PauseGame D206 LD A,$7E Read from the keyboard;
Port Number Bit
0 1 2 3 4
7E CAPS SHIFT or SPACE Z or SYMBOL SHIFT X or M C or N V or B
D208 CALL ReadKeyboardPort
D20B BIT 0,A Return if neither CAPS SHIFT nor SPACE is pressed.
D20D RET Z
D20E AND %00011110 Keep the bits for the other keys.
D210 RET NZ Return if any of them is pressed.
Play the pause sound.
D211 CALL PlayPauseSound Call PlayPauseSound.
Wait for the key to be released.

D216 CALL ReadKeyboardPort
D219 BIT 0,A
D21B JR NZ,PauseGame_Release
Wait for a key to be pressed.

D21F CALL ReadKeyboardPort
D222 BIT 0,A
