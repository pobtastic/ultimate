44203: Set Up Line
Used by the routine at Draw_Line.
Works out what is needed to draw a line that goes up the screen from the first point (the start) to the second point, one pixel row at a time. The number of steps is the difference between the y positions, and the amount that the x position changes for each step is the difference between the x positions multiplied by 256 and divided by the number of steps (see Divide).
The step count is stored in Line_Step_Count and the direction flags in Line_Direction_Flags (see there). The slope is made negative when the line goes to the left, and it is halved once for each room that the rope is long (the high byte of the length multiplied by two), which scales it to the length of the rope.
Input
HL Start of the line (x position in L, y position in H)
DE End of the line (E is the x position and D is the y position)
Output
A Low byte of the slope
B Number of steps
C Direction of the y position (1 or 255)
DE Slope (x position change per step, multiplied by 256)
HL Start of the line
Find the difference between the y positions (in B) and between the x positions, and the direction flags.
