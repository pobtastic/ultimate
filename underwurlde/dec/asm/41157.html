41157: Sound Effect Next Note
Handler for the object type 138 a sound object. Byte 1 of the object is a count, which it decreases. When the count reaches zero the object is removed. Until then it plays a tone of as many cycles as the count, with a half period that is made from the count rotated left three times, inverted and exclusive ORed with 64. No object of this type is ever created (see Unused_Start_Sound_Object_8A), so the game never plays this sound.
