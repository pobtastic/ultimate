41122: Unused
Never reached, as nothing jumps here. Sets up a sound object of type 137 with a count of 16 in the fifth of the small object records (see Small_Object_Records). The routine at SoundEffect handles that type of object. The entry at Unused_Set_Sound_Object sets up a sound object with the type in B and the count in C.
Input
B Type of the sound object (at 41125)
C Count of the sound object (at 41125)
Unused_Start_Sound_Object_89 41122 LD BC,35088 BC=35088 (type 137 count 16).
Unused_Set_Sound_Object 41125 LD HL,36938 HL=Small_Object_Record_4 (the fifth small object record).
41128 LD (HL),B Store the type of the object.

41130 LD (HL),C Store the count of the object.
