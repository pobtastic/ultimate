38881: Draw New Entity Row
Used by the routine at XORSpriteLoop.
Draws one row of the new sprite, using XOR, and moves up to the next row. It is a copy of DrawOldEntityRow that uses the jump at DrawNewEntityRow_Jump, which is changed by PrepDraw2.
Input
B Page of the shift table
DE Pointer to the pixel data
HL Screen address of the row
C Number of rows left
Output
C Number of rows left
DE Pointer to the next row of pixel data
HL Screen address of the next row
DrawNewEntityRow 38881 LD A,C Copy the row count to A.
38882 EX AF,AF' Store the row count in AF'.
38883 LD A,(DE) Fetch the first byte of the row.
38884 LD C,A Copy it to C to use as the index into the shift table.
38885 PUSH HL Stash the screen address on the stack.
DrawNewEntityRow_Jump 38886 JR DrawNewEntityRow_Jump Jump into the unrolled code. The operand of this instruction is changed by PrepDraw2.
