57064: Handle Dust
Handler for the object types 72 to 75 (a puff of dust). The counter in byte 8 goes down on every call and the puff is removed, and erased, when it reaches zero. Bit 0 of the type follows bit 0 of the counter, which makes the puff flicker between two frames. The puff is removed if Sabreman is not in its room.
