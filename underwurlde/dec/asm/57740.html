57740: Handle Sparkle
Handler for the object types 114 and 115 the sparkle that shows where a bubble has burst (see Handle_Bubble). The counter in byte 8 goes down on each call and the sprite id alternates between 114 and 115 with it. The sparkle is removed (and erased) when the counter reaches zero, and at once if Sabreman is not in the room.
