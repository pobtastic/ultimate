36587: Weapon Slots
The type of the weapon (104 to 107) that Sabreman carries in each of three slots, or 0 for an empty slot. Finish_Object_Pass empties the slots when an action key is first pressed and the handlers of the carried weapons (Handle_Weapon_Pickup) fill them in again. Throw_Weapon throws the first weapon that it finds.
Weapon_Slots 36587 DEFB 0 The first slot.
Weapon_Slots_Second 36588 DEFB 0 The second slot.
36589 DEFB 0 The third slot.
