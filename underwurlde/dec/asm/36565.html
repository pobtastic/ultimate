36565: Game Options
The options that were chosen on the game selection screen (see Select_Game_Options). Only the low two bits are used, as there is only one player. They are the controls that ReadControls reads:
Bits 0-1 Controls
0 Keyboard
1 Kempston Joystick
2 Cursor Joystick
3 Interface II Joystick
