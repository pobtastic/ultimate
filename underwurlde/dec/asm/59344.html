59344: Start Dying
Used by the routines at Handle_Stalactite_Hit and Handle_Sabreman_Falling.
Makes Sabreman die. The sprite id becomes 62 or 63 depending on bit 2 of the sprite id that he has, and the countdown in byte 10 is set to 32. Handle_Death handles the rest.
Input
IX Object record of Sabreman
Start_Dying 59344 LD A,(IX+0) Fetch the sprite id.
59347 RRA Move bit 2 into bit 0.
59348 RRA
59349 AND %00000001 Keep only that bit.
59351 ADD A,62 Add 62.
59353 LD (IX+0),A Set the sprite id.
59356 LD (IX+10),32 Set the countdown to 32.
59360 JP Update_Object_Sprite Jump to Update_Object_Sprite.
