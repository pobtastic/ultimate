60852: Extra Life Template
An object record that Place_Special_Object copies to the first of the two special object records at First_Special_Object_Record, to make an extra life. Place_Guardian uses it for a guardian too and changes the type, the attribute and the position.
Extra_Life_Template 60852 DEFB 127 The type, 127 (see Sprite_Extra_Life_1).
60853 DEFB 0,0,0,0 The x position, the room x, the y position and the room y, which are set when the extra life is placed.
60857 DEFB 71 The attribute, 71 (bright white).
60858 DEFB 0 The number of the entry in the table of extra lives (or of guardians), which is set when the extra life is placed.
60859 DEFB 0,0,0,0,0,0,0,0 Not used.
60867 DEFB 1 The redraw flags, with bit 0 set so that the extra life is drawn without erasing anything.
