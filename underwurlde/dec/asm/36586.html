36586: New Action Key Press Flag
Set to 255 for one pass of the main loop when one of the action keys is first pressed, and to 0 otherwise. The handlers of the weapons (Handle_Weapon_Pickup) use it to pick up a weapon, move it along the weapon slots or drop it, and set it to 254 once they have used it.
