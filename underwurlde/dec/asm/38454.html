38454: Remove Entity
Used by the routines at Handle_Flying_Creature, Remove_Thrown_Weapon, Handle_Falling_Stalactite, Handle_Bubble, Handle_Collectable and Handle_Weapon_Pickup.
Draws the sprite of the object at the position that was stored by StoreEntity, which removes it from the screen because the drawing uses XOR. Nothing new is drawn, so the row count of the new sprite is zero.
Before After RemoveEntity
Input
IX Object record
RemoveEntity 38454 CALL PrepDraw23 Prepare the registers for the sprite at its old position.
38457 EXX Switch to the registers of the new sprite.
38458 XOR A Write 0 to New_Sprite_Row_Count as there are no rows of the new sprite to draw.
38459 LD C,A
38460 LD (36579),A Store A in the second row counter (New_Sprite_Row_Count).
38463 EXX Switch back to the registers of the old sprite.
38464 JP XORSpriteLoop Jump to XORSpriteLoop to draw the sprite.
