44149: Divide
Used by the routines at Print_Completion_Percentage and Set_Up_Line.
Divides H multiplied by 256 by DE, one bit at a time. The quotient has eight bits, so DE must be greater than H for the answer to be right. The quotient is built up in the shadow registers and the working is done in the main registers, so the shadow registers are not preserved.
The line drawing code uses it to find how far to move across for each pixel moved down.
Input
H Dividend (it is multiplied by 256)
DE Divisor
Output
HL Quotient
DE Remainder
