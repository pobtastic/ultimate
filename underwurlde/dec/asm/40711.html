40711: Messaging: Ending Text
The object record of the star that is drawn for each letter A of PENTAGRAM, followed by the text for the ending screen and for the game over screen. The last character of each string has bit 7 set. PrintStringColour prints the strings that start with an attribute byte, and MenuWriteText prints the others using the attribute in Current_MenuAttribute.
Ending_Text 40711 DEFB 144 Sprite id of the star.
40712 DEFB 112 X position (set to 112 and then 144 before the star is drawn).
40713 DEFB 0 Room x.
40714 DEFB 156 Y position.
40715 DEFB 0 Room y.
40716 DEFB 70 Attribute: INK:YELLOW, PAPER:BLACK (BRIGHT).
Ending_Text_Congratulations 40717 DEFM "CONGRATULATION","S"+128 "CONGRATULATIONS"
Ending_Text_Knight_Lore 40732 DEFM "KNIGHT LORE"," "+128 "KNIGHT LORE"
