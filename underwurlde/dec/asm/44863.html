44863: Handle Static Object
Used by the routine at Handle_Plain_Decoration.
Handler for the object types 44 to 47 (rocks) and 84 (spikes). These objects never move, so the sprite is only drawn when the room is drawn. On every other pass the routine just sets the attributes again (see ColourEntity).
An object of type 84 also lets out a bubble now and then (see Release_Bubble).
Input
IX Object record
Handle_Static_Object 44863 BIT 0,(IX+15) Jump to Handle_Static_Object_Draw if the object has just been created (bit 0 of the redraw flags is set).
44867 JR NZ,Handle_Static_Object_Draw
44869 LD A,(IX+0) Fetch the type of the object.
44872 CP 84 Call Release_Bubble to let out a bubble if the type is 84.
