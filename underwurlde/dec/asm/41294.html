41294: Unused
Never reached, as nothing jumps here. It would be a handler for a sound object, like SoundEffect. It decreases byte 1 of the object and removes the object once the count has gone below zero. Until then it uses the count as an index into the table at Unused_Tone_Table to get the half period, and plays eight cycles.
Input
IX Object record
Unused_Handle_Sound_Object 41294 DEC (IX+1) Decrease the count.
41297 JP M,ClearSound Jump to ClearSound if the count has gone below zero.
41300 LD C,(IX+1) Fetch the count.
41303 LD B,0 B=0.
41305 LD HL,41315 HL=Unused_Tone_Table (the table of half periods).
41308 ADD HL,BC Add the count to the address of the table.
41309 LD B,(HL) Fetch the half period.
41310 LD C,8 C=8 (the number of cycles).
41312 JP SoundsBeep Jump to SoundsBeep to play the tone.
