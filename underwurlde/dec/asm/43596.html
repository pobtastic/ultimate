43596: Handle Rope
Handler for the object type 23 which is the rope that hangs from the ceiling of a room (see Set_Up_Rope). It is the handler of record 3 while Sabreman is not holding the rope; when he grabs it the record is cleared and Handle_Sabreman_On_Rope takes over.
Each call lengthens the rope by one (the length is the word at Rope_Length) until its low seven bits reach 56 and sets bit 0 of the redraw flags so that the rope gets drawn.
If the rope is swinging (the displacement in Rope_Displacement_Pixels is not zero) the displacement moves back towards zero by 2 on each call and the counter in byte 6 of the record is set to 3. When the rope hangs straight down, the counter counts down to zero and the redraw flag is set for each count. Finally the position of the end of the rope is worked out (Position_Rope_End) and the rope is drawn (Draw_Rope).

IX Object record of the rope (Rope_Record)
Make the rope longer, up to a length of 56.

43644 SET 0,(IX+15) Set bit 0 of the redraw flags, so that the rope is drawn.
