60994: Move Object Horizontally
Used by the routines at Handle_Flying_Creature and Handle_Carrying_Eagle.
Adds a velocity to the x position of an object. The velocity is multiplied by sixteen and added to the x position and its fraction (byte 10 of the record), so that the position changes by a sixteenth of the velocity in each call. The new x position is returned, but it is not stored in the record: that is up to the caller.
Input
HL The x velocity, with the sign extended to sixteen bits
IX Object record
Output
A The new x position
F The zero flag is set if the new x position is less than 128

61008 LD A,H Fetch the new x position.
61009 BIT 7,A Test bit 7 of the new x position.
