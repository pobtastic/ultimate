38366: Show Game Over
Used by the routines at Show_Ending_Screen and Handle_Death.
Clears the screen, prints how much of the Underwurlde has been explored, prints GAME OVER, waits for key 0 (or a timeout) and then goes back to the game selection screen.
Before After Show_Game_Over
Show_Game_Over 38366 CALL Clear_Screen Clear the screen.
38369 CALL Print_Completion_Percentage Print the percentage of the Underwurlde that has been explored.
38372 LD HL,12376 Set the position of the text (x position 88 y position 48).
38375 LD DE,38409 Point at the text GAME OVER (Game_Over_Text).
38378 CALL PrintStringColour Print the text.
38381 CALL Wait_For_Key Wait for key 0.
38384 JP Select_Game_Options_Restart Jump to Select_Game_Options_Restart to go back to the selection screen.
