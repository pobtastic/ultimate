39125: Move Down Row
Moves a screen address down by one character row.
Input
HL Screen address
Output
HL Screen address of the character cell below
MoveDownRow 39125 LD A,L Fetch the low byte of the address.
39126 ADD A,32 Add 32 to move down one row of the character cells.
39128 LD L,A Store the low byte of the address.
39129 RET NC Return if the move did not cross into the next third of the screen.
39130 LD A,H Fetch the high byte of the address.
39131 ADD A,8 Add 8 to move on to the next third of the screen.
39133 LD H,A Store the high byte of the address.
39134 RET Return.
