39325: Flag Small Objects For Redraw
Used by the routine at Draw_Room.
Sets bit 0 of byte 7 of the first four small object records, so that their sprites are drawn without being erased first.
Flag_Small_Objects_For_Redraw 39325 LD HL,36913 Point at byte 7 of the first small record (Small_Object_Record_0_Redraw_Flags).
39328 LD DE,8 Set the size of a small record to 8.
39331 LD B,4 Set the number of records to 4.
Flag_Small_Objects_For_Redraw_Loop 39333 SET 0,(HL) Set bit 0 of byte 7.
39335 ADD HL,DE Move on to the next record.
39336 DJNZ Flag_Small_Objects_For_Redraw_Loop Decrease the counter and loop back until all of the records are flagged.
39338 RET Return.
