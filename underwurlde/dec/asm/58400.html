58400: Steer Eagle
Used by the routine at Handle_Carrying_Eagle.
Moves the eagle by one pixel in the direction that the player is pressing. If more than one direction is pressed, right has priority, then left, up and down.
Input
IX Object record of the eagle
Steer_Eagle 58400 CALL ReadControls Read the controls (see ReadControls).
58403 BIT 0,A Jump to Steer_Eagle_Right if right is pressed.
58405 JR Z,Steer_Eagle_Right
58407 BIT 1,A Jump to Steer_Eagle_Left if left is pressed.
58409 JR Z,Steer_Eagle_Left
58411 BIT 3,A Jump to Steer_Eagle_Up if up is pressed.
58413 JR Z,Steer_Eagle_Up
58415 BIT 2,A Jump to Steer_Eagle_Down if down is pressed.
58417 JR Z,Steer_Eagle_Down
Steer_Eagle_Right 58419 INC (IX+1) Move the eagle one pixel to the right.
58422 RET Return.
Steer_Eagle_Left 58423 DEC (IX+1) Move the eagle one pixel to the left.
58426 RET Return.
Steer_Eagle_Up 58427 DEC (IX+3) Move the eagle one pixel up.
58430 RET Return.
Steer_Eagle_Down 58431 INC (IX+3) Move the eagle one pixel down.
58434 RET Return.
