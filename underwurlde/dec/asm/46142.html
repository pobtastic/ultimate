46142: Check Decoration Contact
Used by the routines at Handle_Sabreman_On_Rope, Handle_Sabreman_Walking, Handle_Sabreman_Falling, Handle_Sabreman_Tumbling, Handle_Flying_Creature, Move_Thrown_Weapon, Handle_Falling_Stalactite, Handle_Carrying_Eagle, Handle_Carried_Sabreman and Handle_Weapon_Pickup.
Checks whether an object touches one of the decorations, using Check_Object_Contact. In the special rooms (a room y below 16) the four records that start at Object_Record_8 are checked. In the cave rooms the two records that start at Object_Record_10 are checked. The check stops at the first decoration that the object touches.
Interrupts are disabled while the check is made, as the result is kept in AF'.
Input
IX Object record
Output
B 160 less the y position of the top of the decoration
C Contact result (see Check_Object_Contact)
