60060: Handle Projectile
Handler for the object types 108 to 111 which are the daggers and the arrows that Sabreman throws (see Throw_Weapon). It saves the state of the object and moves it in the same way as the other thrown weapons (see Move_Thrown_Weapon).
Input
IX Object record of the projectile
Handle_Projectile 60060 CALL StoreEntity Save the state of the projectile.
60063 JP Move_Thrown_Weapon Jump to Move_Thrown_Weapon to move the projectile.
