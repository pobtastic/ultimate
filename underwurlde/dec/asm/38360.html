38360: Menu Icon Record
The object record that Draw_Menu_Icons uses to draw each of the four menu icons. The sprite id, the y position and the attribute are changed for each icon.
Menu_Icon_Record 38360 DEFB 140 Sprite id (the keyboard icon).
38361 DEFB 32 X position.
38362 DEFB 0 Room x.
38363 DEFB 0 Y position (set by Draw_Menu_Icons).
38364 DEFB 0 Room y.
38365 DEFB 66 Attribute: INK:RED, PAPER:BLACK (BRIGHT).
