38249: Fill Memory
Used by the routines at Select_Game_Options and Clear_Screen.
Writes a value to a block of memory. Entering at FillMemory writes 0; entering at FillMemory_WithValue writes the value in E.
Input
HL Start address
BC Number of bytes
E Value to write (entry point FillMemory_WithValue only)
FillMemory 38249 LD E,0 Set the value to write to 0.
This entry point is used by the routine at Clear_Attributes.
FillMemory_WithValue 38251 LD (HL),E Write the value to the address.
38252 INC HL Move on to the next address.
38253 DEC BC Decrease the byte counter and loop back to FillMemory_WithValue until all of the bytes have been written.
38254 LD A,B
38255 OR C
38256 JR NZ,FillMemory_WithValue
38258 RET Return.
