59309: Collect Extra Life
Used by the routine at Handle_Collectable.
Adds a life when Sabreman has touched an extra life (see Handle_Collectable), prints the number of lives, and marks the extra life as collected in the table at Extra_Life_Table. The routine ends by removing the object.
Input
IX Object record of the extra life
Collect_Extra_Life 59309 LD A,(36570) Fetch the number of lives.
59312 INC A Add one.
59313 DAA Adjust the result to a BCD value.
59314 LD (36570),A Store the number of lives.
59317 CALL Draw_Lives_Print_Number Print the number of lives.
59320 LD A,16 Set the number of entries in the table to 16.
59322 LD HL,60870 Point HL at Extra_Life_Table_First_Flag.
59325 CALL Set_Collected_Flag_Entry Set the collected flag of the extra life.
59328 JR Handle_Collectable_Remove Jump to Handle_Collectable_Remove to remove the object.
