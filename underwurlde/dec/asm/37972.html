37972: Pause Briefly
Used by the routine at Finish_Object_Pass.
A short delay loop. It is the handler of type 0 the type of an empty object record, so a record that is not in use costs a little time instead of none. It is also used to debounce the pause key.
Pause_Briefly 37972 XOR A Start the delay counter at 0 which makes 256 passes round the loop.
Pause_Briefly_Loop 37973 DEC A Decrease the delay counter and loop back until it is zero.
37974 JR NZ,Pause_Briefly_Loop
37976 RET Return.
