46458: Handle Thrown Weapon
Handler for the object types 56 to 59 (orbs). The two low bits of the type are set from the tick counter, which animates the orb. It carries on with Move_Thrown_Weapon.
Input
IX Object record
Handle_Thrown_Weapon 46458 CALL StoreEntity Save the state of the orb.
46461 LD A,(36566) Fetch the tick counter from GameTimer.
46464 AND %00000011 Keep only the two low bits (the frame of the weapon).
46466 LD B,A Store the frame in B.
46467 LD A,(IX+0) Fetch the type.
46470 AND %11111100 Reset the two low bits.
46472 OR B Combine them with the frame.
46473 LD (IX+0),A Store the type.
