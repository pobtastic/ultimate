AF3F: Handle Static Object
Used by the routine at Handle_Plain_Decoration.
Handler for the object types 2C to 2F (rocks) and 54 (spikes). These objects never move, so the sprite is only drawn when the room is drawn. On every other pass the routine just sets the attributes again (see ColourEntity).
An object of type 54 also lets out a bubble now and then (see Release_Bubble).
Input
IX Object record
Handle_Static_Object AF3F BIT 0,(IX+$0F) Jump to Handle_Static_Object_Draw if the object has just been created (bit 0 of the redraw flags is set).
AF43 JR NZ,Handle_Static_Object_Draw
AF45 LD A,(IX+$00) Fetch the type of the object.
AF48 CP $54 Call Release_Bubble to let out a bubble if the type is 54.
AF4A CALL Z,Release_Bubble
AF4D CALL PrepDraw2 Prepare the sprite of the object.
AF50 JP ColourEntity Jump to ColourEntity.
Handle_Static_Object_Draw AF53 JP Update_Object_Sprite Jump to Update_Object_Sprite.
