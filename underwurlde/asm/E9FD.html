E9FD: Weapon Placement Table
Four sets of four records of 08 bytes each, which Place_Weapon_Pickups copies to the small object records at Small_Object_Records (see Handle_Weapon_Pickup). A record has the type (68 to 6B), the x position, the room x, the y position (9F which is the floor, or 8F for one of them), the room y and the attribute (42 red, 43 magenta, 44 green or 45 cyan). Byte 06 (the counter) is zero and byte 07 holds the flags 05 which are bit 0 (no old image to erase) and bit 2 (falling). Each set has one weapon of each type, but in different places.
