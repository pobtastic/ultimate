A14E: Unused
Never reached, as nothing jumps here. It would be a handler for a sound object, like SoundEffect. It decreases byte 01 of the object and removes the object once the count has gone below zero. Until then it uses the count as an index into the table at Unused_Tone_Table to get the half period, and plays eight cycles.
Input
IX Object record
Unused_Handle_Sound_Object A14E DEC (IX+$01) Decrease the count.
A151 JP M,ClearSound Jump to ClearSound if the count has gone below zero.
A154 LD C,(IX+$01) Fetch the count.
A157 LD B,$00 B=00.
A159 LD HL,$A163 HL=Unused_Tone_Table (the table of half periods).
A15C ADD HL,BC Add the count to the address of the table.
A15D LD B,(HL) Fetch the half period.
A15E LD C,$08 C=08 (the number of cycles).
A160 JP SoundsBeep Jump to SoundsBeep to play the tone.
