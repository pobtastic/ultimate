C3DB: Sprite: Blank
The empty sprite, which is only a width and a height. It is used for the sprite ids 00 and 17 (the rope, which has its own drawing code) and for the sound objects 89 8A and 8B.
Sprite_Blank_1 C3DB DEFB $00 Width = 00 bytes.
C3DC DEFB $00 Height = 00 pixels.
