EB72: Decoration Colour Pointers
One pointer to the colour data (see Colour_Data) for each of the object types 79 to 7E which Handle_Coloured_Decoration uses to colour the decorations.
Decoration_Colour_Pointers EB72 DEFW $DC72 The picture of type 79.
EB74 DEFW $DC86 The picture of type 7A.
EB76 DEFW $DC41 The bookshelf, the type 7B.
EB78 DEFW $DC69 The hanging bowl, the type 7C.
EB7A DEFW $DC5D The bowl of flowers, the type 7D.
EB7C DEFW $DC53 The torch, the type 7E.
