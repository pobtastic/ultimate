999D: Flag Small Objects For Redraw
Used by the routine at Draw_Room.
Sets bit 0 of byte 07 of the first four small object records, so that their sprites are drawn without being erased first.
Flag_Small_Objects_For_Redraw 999D LD HL,$9031 Point at byte 07 of the first small record (Small_Object_Record_0_Redraw_Flags).
99A0 LD DE,$0008 Set the size of a small record to 08.
99A3 LD B,$04 Set the number of records to 04.
Flag_Small_Objects_For_Redraw_Loop 99A5 SET 0,(HL) Set bit 0 of byte 07.
99A7 ADD HL,DE Move on to the next record.
99A8 DJNZ Flag_Small_Objects_For_Redraw_Loop Decrease the counter and loop back until all of the records are flagged.
99AA RET Return.
