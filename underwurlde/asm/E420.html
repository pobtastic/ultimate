E420: Steer Eagle
Used by the routine at Handle_Carrying_Eagle.
Moves the eagle by one pixel in the direction that the player is pressing. If more than one direction is pressed, right has priority, then left, up and down.
Input
IX Object record of the eagle
Steer_Eagle E420 CALL ReadControls Read the controls (see ReadControls).
E423 BIT 0,A Jump to Steer_Eagle_Right if right is pressed.
E425 JR Z,Steer_Eagle_Right
E427 BIT 1,A Jump to Steer_Eagle_Left if left is pressed.
E429 JR Z,Steer_Eagle_Left
E42B BIT 3,A Jump to Steer_Eagle_Up if up is pressed.
E42D JR Z,Steer_Eagle_Up
E42F BIT 2,A Jump to Steer_Eagle_Down if down is pressed.
E431 JR Z,Steer_Eagle_Down
Steer_Eagle_Right E433 INC (IX+$01) Move the eagle one pixel to the right.
E436 RET Return.
Steer_Eagle_Left E437 DEC (IX+$01) Move the eagle one pixel to the left.
E43A RET Return.
Steer_Eagle_Up E43B DEC (IX+$03) Move the eagle one pixel up.
E43E RET Return.
Steer_Eagle_Down E43F INC (IX+$03) Move the eagle one pixel down.
E442 RET Return.
