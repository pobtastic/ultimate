98D5: Move Down Row
Moves a screen address down by one character row.
Input
HL Screen address
Output
HL Screen address of the character cell below
MoveDownRow 98D5 LD A,L Fetch the low byte of the address.
98D6 ADD A,$20 Add 20 to move down one row of the character cells.
98D8 LD L,A Store the low byte of the address.
98D9 RET NC Return if the move did not cross into the next third of the screen.
98DA LD A,H Fetch the high byte of the address.
98DB ADD A,$08 Add 08 to move on to the next third of the screen.
98DD LD H,A Store the high byte of the address.
98DE RET Return.
