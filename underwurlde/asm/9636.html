9636: Remove Entity
Used by the routines at Handle_Flying_Creature, Remove_Thrown_Weapon, Handle_Falling_Stalactite, Handle_Bubble, Handle_Collectable and Handle_Weapon_Pickup.
Draws the sprite of the object at the position that was stored by StoreEntity, which removes it from the screen because the drawing uses XOR. Nothing new is drawn, so the row count of the new sprite is zero.
Before After RemoveEntity
Input
IX Object record
RemoveEntity 9636 CALL PrepDraw23 Prepare the registers for the sprite at its old position.
9639 EXX Switch to the registers of the new sprite.
963A XOR A Write 00 to New_Sprite_Row_Count as there are no rows of the new sprite to draw.
963B LD C,A
963C LD ($8EE3),A Store A in the second row counter (New_Sprite_Row_Count).
963F EXX Switch back to the registers of the old sprite.
9640 JP XORSpriteLoop Jump to XORSpriteLoop to draw the sprite.
