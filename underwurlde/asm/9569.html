9569: Fill Memory
Used by the routines at Select_Game_Options and Clear_Screen.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory 9569 LD E,$00 Set the value to write to 00.
This entry point is used by the routine at Clear_Attributes.
FillMemory_WithValue 956B LD (HL),E Write the value to the address.
956C INC HL Move on to the next address.
Decrease the byte counter and loop back to FillMemory_WithValue until all of the bytes have been written.
956D DEC BC Decrement the byte counter.
956E LD A,B Jump back to FillMemory_WithValue until all of the bytes have been written.
956F OR C
9570 JR NZ,FillMemory_WithValue
9572 RET Return.
