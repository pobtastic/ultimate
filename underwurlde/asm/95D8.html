95D8: Menu Icon Record
The object record that Draw_Menu_Icons uses to draw each of the four menu icons. The sprite id, the y position and the attribute are changed for each icon.
Menu_Icon_Record 95D8 DEFB $8C Sprite id (the keyboard icon).
95D9 DEFB $20 X position.
95DA DEFB $00 Room x.
95DB DEFB $00 Y position (set by Draw_Menu_Icons).
95DC DEFB $00 Room y.
95DD DEFB $42 Attribute: INK:RED, PAPER:BLACK (BRIGHT).
