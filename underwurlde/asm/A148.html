A148: Unused
Never reached, as nothing jumps here. Sets up a sound object of type A0 with a count of 10 (see Unused_Start_Sound_Object_89). There is no handler for that type.
Unused_Start_Sound_Object_A0 A148 LD BC,$A010 BC=A010 (type A0 count 10).
A14B JP $A0A5 Jump to Unused_Set_Sound_Object to set up the object.
