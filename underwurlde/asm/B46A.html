B46A: Check Object Contact
Used by the routine at Check_Decoration_Contact.
Checks whether the object at IX touches the object at IY, which is an obstacle. The bytes 0A to 0E of the obstacle record are not used for movement. Instead they describe the size of the obstacle: its half width (byte 0A), the width of its middle (byte 0B), its height (byte 0C), the depth from the top at which the object counts as being beside it (byte 0D) and the offset of the middle from its x position (byte 0E). The y position of an obstacle is the position of its bottom.
The result is returned in C. Bit 2 is set if the objects touch. Bit 7 is set if IX is on the right of the middle of the obstacle. Bit 0 is set if IX is outside the width of the middle. Bit 1 is set if the bottom of IX is in the top part of the obstacle (so that it is standing or landing on it).
When the object touches the top of the obstacle, bit 4 of its contact flags is set (so it is standing on it) unless it is a weapon pickup (see Handle_Weapon_Pickup) or it is outside the width of the middle. An obstacle of type 88 is handled by Check_Rock_Formation_Contact instead.
Input
IX Object record
IY Obstacle record
Output
C Contact result
AF' A0 less the y position of the top of the obstacle
