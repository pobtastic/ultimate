EDB4: Extra Life Template
An object record that Place_Special_Object copies to the first of the two special object records at First_Special_Object_Record, to make an extra life. Place_Guardian uses it for a guardian too and changes the type, the attribute and the position.
Extra_Life_Template EDB4 DEFB $7F The type, 7F (see Sprite_Extra_Life_1).
EDB5 DEFB $00,$00,$00,$00 The x position, the room x, the y position and the room y, which are set when the extra life is placed.
EDB9 DEFB $47 The attribute, 47 (bright white).
EDBA DEFB $00 The number of the entry in the table of extra lives (or of guardians), which is set when the extra life is placed.
EDBB DEFB $00,$00,$00,$00,$00,$00,$00,$00 Not used.
EDC3 DEFB $01 The redraw flags, with bit 0 set so that the extra life is drawn without erasing anything.
