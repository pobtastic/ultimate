9125: Messaging: Game Selection Screen Text
The text of each of the five menu lines. Each string ends with a character that has bit 7 set, which tells PrintStringColour where it finishes.
GameSelection_Text 9125 DEFM "1 KEYBOAR","D"+$80 "1 KEYBOARD"
9130 DEFM "2 KEMPSTON JOYSTIC","K"+$80 "2 KEMPSTON JOYSTICK"
9144 DEFM "3 CURSOR JOYSTIC","K"+$80 "3 CURSOR JOYSTICK"
9158 DEFM "4 INTERFACE I","I"+$80 "4 INTERFACE II"
9167 DEFM "0 START GAM","E"+$80 "0 START GAME"
