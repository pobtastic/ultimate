E1B4: Check Bubble Contact
Used by the routines at Handle_Sabreman_On_Rope, Handle_Sabreman_Walking, Handle_Sabreman_Jumping, Handle_Sabreman_Falling, Handle_Sabreman_Tumbling, Handle_Flying_Creature and Handle_Carrying_Eagle.
Checks whether an object is touching one of the four bubbles (the object records that start at First_Bubble_Record and have the type 58 to 5B).
No bubble is touched if bit 4 or bit 5 of the countdown in byte 0A is set. This is the case for Sabreman for a while after he has started to fall, and it lets him get away from a bubble.
An object touches a bubble when the two are in the same room, the x positions differ by less than 0D and the y position of the object is between zero and 0E pixels above the y position of the bubble.
When there is contact the result in C has bit 2 and bit 1 set (a bubble is always taken as being under the object). Bit 7 is set if the object is to the right of the bubble. Bits 5 and 0 are set if the x positions differ by 0A or more, which means that the object is not near the middle of the bubble. Otherwise the y position of the object is set to 0E less than that of the bubble so that it stands on it, and bit 4 of E and bit 4 of the contact flags (byte 0B) are set.
If the object is Sabreman (the type is between 09 and 1B) and he is touching a bubble while he is near the top of the room (the y position is less than 48) then the bubble pushes him up. In a room with a ceiling he starts tumbling (see Start_Tumbling_Downwards), which draws him and ends the handler that called this routine. In a room with no ceiling he moves into the room above, if his y position is less than 2C. The y position then becomes AF the first bubble record becomes a copy of the record of Sabreman as a bubble (58) at the y position B8 and the new room is drawn.
Input
IX Object record
E Flags of the room (see Read_World_Map)
Output
B A0 less the y position of the object (valid when there is contact)
C Contact result
E Flags of the room, with bit 4 set if the object stands on a bubble
Check_Bubble_Contact E1B4 LD C,$00 Set the contact result to zero.
E1B6 LD A,(IX+$0A) Fetch the countdown.
E1B9 AND %00110000 Keep only bits 4 and 5.
E1BB RET NZ Return if either of them is set.
E1BC PUSH DE Stash the flags of the room.
E1BD LD HL,$8F5A Point HL at First_Bubble_Record.
E1C0 LD DE,$0010 Set DE to the size of an object record.
E1C3 LD B,$04 Set a counter in B for the four bubble records.
Check_Bubble_Contact_Loop E1C5 LD A,(HL) Fetch the type of the record.
E1C6 AND %11111100 Ignore the two low bits.
E1C8 CP $58 Jump to Check_Bubble_Contact_Found if the record holds a bubble.
E1CA JR Z,Check_Bubble_Contact_Found
Check_Bubble_Contact_Next_Record E1CC ADD HL,DE Move on to the next record.
E1CD DJNZ Check_Bubble_Contact_Loop Decrease the record counter and loop back for the next record.
E1CF LD C,$00 Clear the contact result, as no bubble was touched.
E1D1 POP DE Restore the flags of the room.
E1D2 RET Return.
Check_Bubble_Contact_Skip E1D3 POP HL Discard the address of the bubble record.
E1D4 JR Check_Bubble_Contact_Next_Record Jump to Check_Bubble_Contact_Next_Record to try the next bubble.
Check_Bubble_Contact_Found E1D6 PUSH HL Stash the address of the bubble record.
