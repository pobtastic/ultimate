91C0: Run Game
Used by the routine at Select_Game_Options.
Starts a new game and then runs the main loop forever.
The loop at Main_Loop goes through the object records one at a time. Byte 00 of a record is the type of the object, which is used as an index into the Object_Handler_Table handler table. The handler is run with IX pointing at the record and with Finish_Object_Pass stacked as its return address, so every handler ends by returning to Finish_Object_Pass which moves on to the next record.
Start a new game: empty the room table, clear the workspace and the objects, and clear the screen.

This entry point is used by the routine at Finish_Object_Pass.
This is the main loop. The normal pass starts with Sabreman's record, unless his type is from 09 to 1B. Those types are handled with the priority records (see Finish_Object_Pass_Priority_Records), so then the pass starts with the record after his. The first two records are only ever handled as priority records.
