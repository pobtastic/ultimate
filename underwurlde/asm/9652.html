9652: Fetch Actor Sprite
Used by the routine at PrepDraw2.
Fetches the address of the graphic for the sprite of an object. The type of the object is also the id of its sprite. It uses FetchSprite to look the address up.
Input
IX Object record
Output
DE Address of the sprite data
FetchActorSprite 9652 LD A,(IX+$00) Fetch the type of the object (which is also its sprite id).
9655 JR FetchSprite Jump to FetchSprite to look up the address.
