9052: Select Game Options
Used by the routine at Start_Game_Selection.
Sets up the game selection screen and waits for the player to choose a control method and start the game.
The method is chosen with the keys 1 to 4 (see GameSelection_Attributes) and is stored in GameOptions. Pressing 0 starts the game at Run_Game.
Everything from GameOptions up to Select_Game_Options is cleared first, so this routine also gives every object record and every game variable its starting value of zero.
Set the border to black, build the shift tables and clear the game variables, the object records and the attributes.
Select_Game_Options 9052 XOR A Set the border to black by writing 00 to port FE.
9053 OUT ($FE),A
9055 CALL BuildShiftTable Build the shift tables used to draw the sprites.
9058 LD HL,$8ED5 Point at the start of the game variables (GameOptions).
905B LD BC,$017D Set the number of bytes to 017D which reaches Select_Game_Options.
905E CALL FillMemory Fill the variables and the object records with zero.
9061 LD HL,$5800 Point at the start of the attribute buffer (5800).
9064 LD BC,$0300 Set the size of the attribute buffer to 0300.
9067 CALL FillMemory Set every attribute to black ink on black paper.
This entry point is used by the routine at Show_Game_Over.
