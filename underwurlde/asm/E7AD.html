E7AD: Collect Extra Life
Used by the routine at Handle_Collectable.
Adds a life when Sabreman has touched an extra life (see Handle_Collectable), prints the number of lives, and marks the extra life as collected in the table at Extra_Life_Table. The routine ends by removing the object.
Input
IX Object record of the extra life
Collect_Extra_Life E7AD LD A,($8EDA) Fetch the number of lives.
E7B0 INC A Add one.
E7B1 DAA Adjust the result to a BCD value.
E7B2 LD ($8EDA),A Store the number of lives.
E7B5 CALL Draw_Lives_Print_Number Print the number of lives.
E7B8 LD A,$10 Set the number of entries in the table to 10.
E7BA LD HL,$EDC6 Point HL at Extra_Life_Table_First_Flag.
E7BD CALL Set_Collected_Flag_Entry Set the collected flag of the extra life.
E7C0 JR Handle_Collectable_Remove Jump to Handle_Collectable_Remove to remove the object.
