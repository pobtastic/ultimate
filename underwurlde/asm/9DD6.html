9DD6: Special Room Frame Tables
Four tables of eight routines, one table for each part of the frame of a special room (see Draw_Special_Room_Frame). The code from the world map selects the entry. The tables are for the top right, the bottom right, the bottom left and the top left, in that order.
Top right.
Special_Room_Frame_Tables 9DD6 DEFW $9D88 Code 0: a corner (9D88).
9DD8 DEFW Draw_Ceiling_Picture Code 1: the ceiling (Draw_Ceiling_Picture).
9DDA DEFW $9D88 Code 2: a corner (9D88).
9DDC DEFW Draw_Special_Room_Parts Code 3: the ceiling and a corner (Draw_Special_Room_Parts).
9DDE DEFW Draw_Right_Wall_Picture Code 4: the right wall (Draw_Right_Wall_Picture).
9DE0 DEFW Draw_Nothing Code 5: nothing (Draw_Nothing).
9DE2 DEFW Draw_Top_Right_Corner_And_Right_Wall Code 6: a corner and the right wall (Draw_Top_Right_Corner_And_Right_Wall).
9DE4 DEFW Draw_Top_Right_Ceiling_Corner_And_Wall Code 7: the ceiling, a corner and the right wall (Draw_Top_Right_Ceiling_Corner_And_Wall).
