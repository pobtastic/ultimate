B57A: Handle Thrown Weapon
Handler for the object types 38 to 3B (orbs). The two low bits of the type are set from the tick counter, which animates the orb. It carries on with Move_Thrown_Weapon.
Input
IX Object record
Handle_Thrown_Weapon B57A CALL StoreEntity Save the state of the orb.
B57D LD A,($8ED6) Fetch the tick counter from GameTimer.
B580 AND %00000011 Keep only the two low bits (the frame of the weapon).
B582 LD B,A Store the frame in B.
B583 LD A,(IX+$00) Fetch the type.
B586 AND %11111100 Reset the two low bits.
B588 OR B Combine them with the frame.
B589 LD (IX+$00),A Store the type.
