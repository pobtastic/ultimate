9689: Prepare Draw 2 Byte Sprite
Used by the routines at DrawEntity, DisplayEntity, Handle_Static_Object, Handle_Stalactite, Handle_Collectable, Handle_Weapon_Pickup and Handle_Coloured_Decoration.
Gets the registers ready to draw the sprite of the object that IX points at, at its current position.
It does what PrepDraw23 does for the old sprite, but it uses the position and the type of the object, patches the jump at DrawNewEntityRow_Jump (used by the unrolled code at DrawNewEntityRow), and stores the number of rows in New_Sprite_Row_Count and New_Sprite_Height. The number of character cells that the sprite covers in each row (one more than the width if the sprite is not aligned to a character boundary) is stored in New_Sprite_Width.

IX Object record

C 00
