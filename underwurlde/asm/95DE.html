95DE: Show Game Over
Used by the routines at Show_Ending_Screen and Handle_Death.
Clears the screen, prints how much of the Underwurlde has been explored, prints GAME OVER, waits for key 0 (or a timeout) and then goes back to the game selection screen.
Before After Show_Game_Over
Show_Game_Over 95DE CALL Clear_Screen Clear the screen.
95E1 CALL Print_Completion_Percentage Print the percentage of the Underwurlde that has been explored.
95E4 LD HL,$3058 Set the position of the text (x position 58 y position 30).
95E7 LD DE,$9609 Point at the text GAME OVER (Game_Over_Text).
95EA CALL PrintStringColour Print the text.
95ED CALL Wait_For_Key Wait for key 0.
95F0 JP Select_Game_Options_Restart Jump to Select_Game_Options_Restart to go back to the selection screen.
