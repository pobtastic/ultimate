B6D3: Remove Thrown Weapon
Used by the routines at Move_Thrown_Weapon, Handle_Dust, Handle_Explosion and Handle_Sparkle.
Removes a weapon (or other object) that has been drawn, by emptying its record and erasing its sprite. If it has not been drawn there is nothing to erase.
Input
IX Object record
Remove_Thrown_Weapon B6D3 LD (IX+$00),$00 Empty the record by setting the type to zero.
B6D7 LD (IX+$07),$00 Clear byte 07.
B6DB BIT 0,(IX+$0F) Return if the object has not been drawn yet.
B6DF RET NZ
B6E0 JP RemoveEntity Erase the sprite of the object.
