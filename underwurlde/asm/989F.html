989F: Store Entity
Used by the routines at Handle_Sabreman_On_Rope, Handle_Sabreman_Walking, Handle_Sabreman_Jumping, Handle_Sabreman_Falling, Handle_Sabreman_Tumbling, Handle_Plant, Handle_Flying_Creature, Animate_Jellyfish, Handle_Thrown_Weapon, Handle_Dust, Handle_Explosion, Handle_Falling_Stalactite, Handle_Rock_Fragments, Handle_Bubble, Handle_Sparkle, Handle_Carrying_Eagle, Handle_Carried_Sabreman, Handle_Collectable, Handle_Death, Handle_Weapon_Pickup, Handle_Fire, Handle_Projectile and Handle_Guardian.
Stores the position and the sprite id of the object that IX points at, so that the sprite can be found and erased later.
Input
IX Object record
StoreEntity 989F LD A,(IX+$01) Fetch the x position of the object.
98A2 LD ($8EE4),A Store it in Previous_X_Position.
98A5 LD A,(IX+$03) Fetch the y position of the object.
98A8 LD ($8EE5),A Store it in Previous_Y_Position.
98AB LD A,(IX+$00) Fetch the type of the object (its sprite id).
98AE LD ($8EE1),A Store it in Previous_Sprite_Id.
98B1 RET Return.
