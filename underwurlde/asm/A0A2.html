A0A2: Unused
Never reached, as nothing jumps here. Sets up a sound object of type 89 with a count of 10 in the fifth of the small object records (see Small_Object_Records). The routine at SoundEffect handles that type of object. The entry at Unused_Set_Sound_Object sets up a sound object with the type in B and the count in C.
Input
B Type of the sound object (at A0A5)
C Count of the sound object (at A0A5)
Unused_Start_Sound_Object_89 A0A2 LD BC,$8910 BC=8910 (type 89 count 10).
Unused_Set_Sound_Object A0A5 LD HL,$904A HL=Small_Object_Record_4 (the fifth small object record).
A0A8 LD (HL),B Store the type of the object.
A0A9 INC HL Move on to the count.
A0AA LD (HL),C Store the count of the object.
A0AB RET Return.
