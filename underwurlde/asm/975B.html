975B: Draw Old Entity Row
Used by the routine at XORSpriteLoop.
Draws one row of the old sprite, using XOR, and moves up to the next row.
The row is drawn by unrolled code with one piece of 0C bytes for each byte of the row (up to nine bytes). The operand of the jump at DrawOldEntityRow_Jump is changed by PrepDraw23 so that the jump lands on the first piece that is needed. If the sprite is aligned to a character boundary the jump goes six bytes further in, which leaves out the first write.
Input
B Page of the shift table
DE Pointer to the pixel data
HL Screen address of the row
C Number of rows left
Output
C Number of rows left
DE Pointer to the next row of pixel data
HL Screen address of the next row
DrawOldEntityRow 975B LD A,C Copy the row count to A.
975C EX AF,AF' Store the row count in AF'.
975D LD A,(DE) Fetch the first byte of the row.
975E LD C,A Copy it to C to use as the index into the shift table.
975F PUSH HL Stash the screen address on the stack.
DrawOldEntityRow_Jump 9760 JR DrawOldEntityRow_Jump Jump into the unrolled code. The operand of this instruction is changed by PrepDraw23.
