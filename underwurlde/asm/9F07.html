9F07: Messaging: Ending Text
The object record of the star that is drawn for each letter A of PENTAGRAM, followed by the text for the ending screen and for the game over screen. The last character of each string has bit 7 set. PrintStringColour prints the strings that start with an attribute byte, and MenuWriteText prints the others using the attribute in Current_MenuAttribute.
Ending_Text 9F07 DEFB $90 Sprite id of the star.
9F08 DEFB $70 X position (set to 70 and then 90 before the star is drawn).
9F09 DEFB $00 Room x.
9F0A DEFB $9C Y position.
9F0B DEFB $00 Room y.
9F0C DEFB $46 Attribute: INK:YELLOW, PAPER:BLACK (BRIGHT).
Ending_Text_Congratulations 9F0D DEFM "CONGRATULATION","S"+$80 "CONGRATULATIONS"
Ending_Text_Knight_Lore 9F1C DEFM "KNIGHT LORE"," "+$80 "KNIGHT LORE"
PENTAGRAM, with an attribute first. Each of the two gaps is where a star is drawn in place of an A.
Ending_Text_Pentagram 9F28 DEFB $46 Attribute: INK:YELLOW, PAPER:BLACK (BRIGHT).
9F29 DEFM "PENT GR M"," "+$80 "PENT GR M"

Ending_Text_You_Have_Escaped_From 9F4B DEFM "YOU HAVE ESCAPED FROM"," "+$80 "YOU HAVE ESCAPED FROM"
