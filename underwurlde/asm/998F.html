998F: Flag Objects For Redraw
Used by the routine at Draw_Room.
Writes 01 to byte 0F of each of the nineteen object records, so that each of the sprites is drawn without being erased first (see Update_Object_Sprite).
Flag_Objects_For_Redraw 998F LD HL,$8F09 Point at byte 0F of the first record (First_Weapon_Redraw_Flags).
9992 LD DE,$0010 Set the size of a record to 10.
9995 LD BC,$1301 Set the number of records to 13 and the value to flag them with to 01.
Flag_Objects_For_Redraw_Loop 9998 LD (HL),C Set byte 0F of the record.
9999 ADD HL,DE Move on to the next record.
999A DJNZ Flag_Objects_For_Redraw_Loop Decrease the counter and loop back until all of the records are flagged.
999C RET Return.
