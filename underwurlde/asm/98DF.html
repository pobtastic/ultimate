98DF: Print Character
Used by the routines at PrintStringColour and Print_Status_Panel.
Draws a character at a screen address and moves on to the next cell to the right. The attribute is not changed.
The shape of the character comes from the font at Font, which has eight bytes for each code. The address is worked out as ED24 plus eight times the code, so the glyph for code 30 (the digit 0) is the first one of the font. A space (20) is replaced by code 3D which is the blank character of the font.
