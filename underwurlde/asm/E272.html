E272: Start Tumbling Downwards
Used by the routine at Handle_Sabreman_Walking.
Makes Sabreman tumble downwards, as when a bubble pushes him against a ceiling. The sprite becomes 18 the countdown (byte 0A) is set to 1A and the y velocity to 20.
The routine ends by drawing Sabreman and returning to the main loop.
Input
IX Object record of Sabreman
Start_Tumbling_Downwards E272 LD (IX+$00),$18 Set the sprite id to 18 (tumbling).
E276 LD (IX+$0A),$1A Set the countdown to 1A.
E27A LD (IX+$09),$20 Set the y velocity to 20.
E27E LD (IX+$0B),$00 Clear the contact flags.
