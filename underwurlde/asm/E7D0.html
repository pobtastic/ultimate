E7D0: Start Dying
Used by the routines at Handle_Stalactite_Hit and Handle_Sabreman_Falling.
Makes Sabreman die. The sprite id becomes 3E or 3F depending on bit 2 of the sprite id that he has, and the countdown in byte 0A is set to 20. Handle_Death handles the rest.
Input
IX Object record of Sabreman
Start_Dying E7D0 LD A,(IX+$00) Fetch the sprite id.
E7D3 RRA Move bit 2 into bit 0.
E7D4 RRA
E7D5 AND %00000001 Keep only that bit.
E7D7 ADD A,$3E Add 3E.
E7D9 LD (IX+$00),A Set the sprite id.
E7DC LD (IX+$0A),$20 Set the countdown to 20.
E7E0 JP Update_Object_Sprite Jump to Update_Object_Sprite.
