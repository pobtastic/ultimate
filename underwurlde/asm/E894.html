E894: Knock Sabreman Down
Used by the routine at Handle_Sabreman_Walking.
Makes Sabreman tumble when he has been hit by a bubble. The y velocity is the value in B, the countdown in byte 0A is set to 14 and the sprite id to 18 (tumbling). Sabreman is drawn and the routine returns to the main loop.
Input
B Y velocity
IX Object record of Sabreman
Knock_Sabreman_Down E894 LD (IX+$0A),$14 Set the countdown to 14.
This entry point is used by the routine at Handle_Sabreman_Falling.
Knock_Sabreman_Down_Set_Velocity E898 LD (IX+$09),B Set the y velocity.
E89B LD (IX+$00),$18 Set the sprite id to 18 (tumbling).
E89F JP Update_Object_Sprite Jump to Update_Object_Sprite.
