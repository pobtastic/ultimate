AC68: Multiply A By DE
Used by the routines at Position_Rope_End and Move_Rope.
Multiplies A by DE, by adding DE to the product for each bit of A that is set. The product is a word.
Input
A Multiplier
DE Multiplicand
Output
HL Product
MultiplyAByDE AC68 LD HL,$0000 Set the product so far to 00.
AC6B LD B,$08 Set the number of bits to 08.
MultiplyAByDE_Loop AC6D ADD HL,HL Double the product.
AC6E RLCA Move the next bit of the multiplier into the carry.
AC6F JR NC,MultiplyAByDE_Next Jump to MultiplyAByDE_Next if the bit is clear.
AC71 ADD HL,DE Add the multiplicand to the product.
MultiplyAByDE_Next AC72 DJNZ MultiplyAByDE_Loop Decrease the bit counter and loop back until all eight bits of the multiplier have been used.
AC74 RET Return.
