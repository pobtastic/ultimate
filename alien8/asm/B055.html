B055: Handle Mouse Second Part
The handler for the second part of a robot mouse (object 0B). It takes its position from the first part, which comes before it in the table of objects, and sits 0C lower. When the first part is moving it makes a noise and is redrawn.
Input
IX The address of the object
Follow the first part and redraw if it moves.
HandleMouseSecondPart B055 CALL SetPixelAdjustments_Mouse Call SetPixelAdjustments_Mouse.
B058 CALL CopyPreviousPosition Call CopyPreviousPosition.
B05B LD A,(IX-$17) Return if the first part is not moving.
B05E OR (IX-$16)
B061 OR (IX-$15)
B064 RET Z
B065 CALL PlayMouseSound Call PlayMouseSound.
B068 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags.
