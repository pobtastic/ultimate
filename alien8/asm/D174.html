D174: Flip Sprite
Used by the routine at GetSpriteAddress.
Flips the data of a sprite in place, if its flags are not the same as the flags of the object that is going to be drawn. The width byte of a sprite has the vertical flip in bit 7 and the horizontal flip in bit 6. The sprite is flipped vertically by swapping its lines, and horizontally by reversing the bits of each byte and the order of the bytes of each line, with ReversedByteTable.
Input
DE The address of the sprite
IX The address of the object
Output
DE The address of the sprite
Flip the sprite from top to bottom if needed.
