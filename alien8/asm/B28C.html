B28C: Handle Collapsing Block
The handler for a block which collapses (object 2D). When something stands on it the block turns into a sparkle (object 40) and disappears.
Input
IX The address of the object
Collapse if something is standing on the block.
HandleCollapsingBlock B28C CALL SetPixelAdjustments Call SetPixelAdjustments.
B28F BIT 3,(IX+$0D) Test bit 3 of the state.
B293 RES 3,(IX+$0D) Reset bit 3 of the state.
B297 RET Z Return if nothing was standing on the block.
B298 LD (IX+$00),$40 Write 40 as the sprite number.
B29C JP HandleSparkle Jump to HandleSparkle.
