B20B: Restore Object Height
Used by the routines at HandleCircuitMouse and HandleBouncingMouse.
Undoes ExtendObjectDownwards by raising the object by 0C and halving its height.
Input
IX The address of the object
Restore the height and the next object's flags.
RestoreObjectHeight B20B LD A,(IX+$03) Fetch the height of the object.
B20E ADD A,$0C Add 0C.
B210 LD (IX+$03),A Set the height of the object.
B213 SRL (IX+$06) Halve the height of the object.
B217 RES 1,(IX+$27) Reset bit 1 of the next object's flags.
B21B RET Return.
