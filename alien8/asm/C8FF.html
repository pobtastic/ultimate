C8FF: Read Controls
Used by the routines at HandlePlayerLegs and HandleTurningLegs.
Reads the controls that the player is using and stores them in ControlsPressed. The controls are made into a byte, with bit 0 for left, bit 1 for right, bit 2 for walking forward, bit 3 for jumping and bit 4 for picking up and dropping an object. Bit 5 is set by ReadControls_Finish. No controls are read while the game over scene is shown or the game has been completed.
Output
C The controls
