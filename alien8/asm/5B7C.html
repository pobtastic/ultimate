5B7C: Objects Carried
The objects that the player is carrying. There is room for three, each using four bytes: the first byte of each is the number of the object (or zero for an empty space), the second is its flags and the other two are an address that was held in the record of the object. The status panel shows the objects by drawing their sprites.
ObjectsCarried 5B7C DEFB $00,$00,$00,$00 The first object.
ObjectsCarried_Second 5B80 DEFB $00,$00,$00 The second object.
ObjectsCarried_SecondEnd 5B83 DEFB $00 The last byte of the second object.
ObjectsCarried_Third 5B84 DEFB $00,$00,$00 The third object.
ObjectsCarried_ThirdEnd 5B87 DEFB $00 The last byte of the third object.
