B29F: Handle Deadly Object
The handler for the deadly pyramid and tubes (objects 48 and 4B). They are made deadly to touch (see SetDeadlyFlags).
Input
IX The address of the object
Set the pixel offsets and make the object deadly.
HandleDeadlyObject B29F CALL SetPixelAdjustments Call SetPixelAdjustments.
B2A2 JR SetDeadlyFlags Jump to SetDeadlyFlags.
