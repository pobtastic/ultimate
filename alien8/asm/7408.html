7408: Second Object Types
The second table of types of object, which is used after an object of type 1F in the data for a room. It has room for 20 entries but only the first eight are used, since the templates start at ObjectTemplates.
SecondObjectTypes 7408 DEFW $0000 Type 00: unused.
740A DEFW ObjectTemplate_RemoteControlArrowWest Type 01: a remote control arrow pointing west (ObjectTemplate_RemoteControlArrowWest).
740C DEFW ObjectTemplate_RemoteControlArrowNorth Type 02: a remote control arrow pointing north (ObjectTemplate_RemoteControlArrowNorth).
740E DEFW ObjectTemplate_RemoteControlArrowEast Type 03: a remote control arrow pointing east (ObjectTemplate_RemoteControlArrowEast).
7410 DEFW ObjectTemplate_RemoteControlArrowSouth Type 04: a remote control arrow pointing south (ObjectTemplate_RemoteControlArrowSouth).
7412 DEFW ObjectTemplate_RemoteControlBlock Type 05: the remote control block (ObjectTemplate_RemoteControlBlock).
7414 DEFW ObjectTemplate_SpikedDome Type 06: the spiked dome (ObjectTemplate_SpikedDome).
7416 DEFW ObjectTemplate_LandMine Type 07: the land mine (ObjectTemplate_LandMine).
