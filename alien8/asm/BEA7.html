BEA7: Test Object Can Be Picked Up
Used by the routine at HandlePickupAndDrop.
Tests whether an object is one of the four valves (objects 60 to 63) that the player is on or close to.
Input
IX The address of the player
IY The address of the object
Output
F Carry flag set if the object can be picked up
Return unless the object is a valve.
TestObjectCanBePickedUp BEA7 LD A,(IY+$00) Fetch the object number of the object.
BEAA SUB $60 Subtract 60.
BEAC CP $04 Return if it is not a valve.
BEAE RET NC
Continue on to TestNearObject.
