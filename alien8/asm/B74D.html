B74D: Test Object Solid
Used by the routines at TestObjectIntersections, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether collision tests should take any notice of an object. The zero flag is set if the slot is unused or bit 1 of the flags is set.
Input
IY The address of the object
Output
F Zero flag set if the slot is not used or the object is ignored
Return if the slot is empty.
TestObjectSolid B74D LD A,(IY+$00) Fetch the sprite number of the object.
B750 AND A Return if the slot is not used.
B751 RET Z
After invert, bit 1 is set when the object is not ignored.
B752 LD A,(IY+$07) Fetch the flags of the object.
B755 CPL Invert them.
B756 AND %00000010 Keep only bit 1.
B758 RET Return.
