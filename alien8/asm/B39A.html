B39A: Turn Into Sparkle
Used by the routines at HandlePlayerLegs and HandlePlayerTop.
Changes the object into the first frame of a sparkle (object 30) and makes collision tests ignore it, then carries on to deal with the sparkle.
Input
IX The address of the object
Become a sparkle and play the sound.
TurnIntoSparkle B39A LD (IX+$00),$30 Write 30 as the sprite number.
B39E SET 1,(IX+$07) Set bit 1 of the flags.
B3A2 JR HandleSparkle_PlaySound Jump to HandleSparkle_PlaySound.
