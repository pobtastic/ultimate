CAF1: Set Sprite Details
Used by the routines at PrintTableSprite, DrawPanel and PrintBorder.
Sets the sprite number, the flags and the pixel position of an object from four bytes of data.
Input
HL The address of the data
IX The address of the object
Output
HL The address of the byte after the data
SetSpriteDetails CAF1 LD A,(HL) Fetch the sprite number and move on.
CAF2 INC HL
CAF3 LD (IX+$00),A Set the sprite number.
CAF6 LD A,(HL) Fetch the flags and move on.
CAF7 INC HL
CAF8 LD (IX+$07),A Set the flags.
CAFB LD A,(HL) Fetch the pixel x and move on.
CAFC INC HL
CAFD LD (IX+$1A),A Set the pixel x position.
CB00 LD A,(HL) Fetch the pixel y and move on.
CB01 INC HL
CB02 LD (IX+$1B),A Set the pixel y position.
CB05 RET Return.
