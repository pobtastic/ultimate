D157: Calculate Attribute Address
Used by the routines at ColourCells, PrintTextStandardFont and DisplayObjectsCarried.
Finds the address in the attribute file of the character square that holds a pixel. The pixel y position is from the bottom of the screen.
Input
H The pixel y position
L The pixel x position
Output
DE The address of the attribute
Work out the square from the position.
CalculateAttributeAddress D157 PUSH HL Stash HL on the stack.
D158 LD A,H Fetch H, invert it and copy it to H.

D15D SRL H
D15F SRL H
D161 SRL H

D16D LD DE,$5700 Point DE at 5700.
