BC15: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute BC15 AND A Jump to SetFlashingAttribute_Steady if the line is not the first.
BC16 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash BC18 SET 7,(HL) Set bit 7 of the attribute.
BC1A JR SetFlashingAttribute_Next Jump to SetFlashingAttribute_Next.
SetFlashingAttribute_NextLine BC1C DEC A Jump to SetFlashingAttribute_Flash if this is the line.
BC1D JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady BC1F RES 7,(HL) Reset bit 7 of the attribute.
SetFlashingAttribute_Next BC21 INC HL Move on to the next line.
BC22 DJNZ SetFlashingAttribute_NextLine Jump to SetFlashingAttribute_NextLine until all of the lines have been done.
BC24 RET Return.
