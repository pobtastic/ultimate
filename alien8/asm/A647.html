A647: Restart Game
Used by the routines at HandleEndingRobotBottom and HandleAttackingTool.
Clears the game variables from WipedAreaCount onwards, so RandomSeed1, FrameCounter, ControlMethod and RandomSeed2 are kept.
Clear the variables of the last game.
RestartGame A647 LD HL,$5B08 Point HL at WipedAreaCount.
A64A LD BC,$0780 Set the number of bytes to 0780.
A64D CALL FillMemory Call FillMemory.
Continue on to InitialiseGame.
