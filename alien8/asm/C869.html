C869: Continue Comparing Objects
The first object is not held up by the other object, so go on to compare it with the next one. The table at DrawingOrderTable has two entries that come here.
Compare the first object with the next one.
ContinueComparingObjects C869 JP DrawObjectsInOrder_FindSecond Jump to DrawObjectsInOrder_FindSecond.
The other table entry does the same.
ContinueComparingObjects_Alternate C86C JP DrawObjectsInOrder_FindSecond Jump to DrawObjectsInOrder_FindSecond.
