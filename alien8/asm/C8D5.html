C8D5: Draw Next Object
Used by the routine at DrawObjectsInOrder.
Draws an object that does not have to wait for any other object, and flags it as drawn in the list.
Input
IX The address of the object
Flag it drawn and print it.
DrawNextObject C8D5 LD HL,($5B2D) Fetch the place in the list after the first object.
This entry point is used by the routine at CompareWithOtherObject.

C8D9 SET 7,(HL) Flag the object as drawn.

C8DD LD ($C8EF),A
C8E0 LD HL,$5B1E Point HL at ObjectsDrawn.

C8E4 CALL DrawObject Draw the object into the buffer.
