6308: Font
The font used for all of the text in the game, which has a glyph for each of the characters from "0" (ASCII 30) to "Z" (ASCII 5A), eight bytes per glyph. Between "9" and "A" the characters are used for other things: ":" is a second zero, ";" is a full stop, "<" is a hyphen, "=" is the space, ">" is the copyright symbol and "?" and "@" are blank. Text is printed by using the character code as an index from 6188, which is where glyph 00 would be if the font started at ASCII 00. The digits of the numbers are printed with codes 00 to 09 and the font address set to Font.
