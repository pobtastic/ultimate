73C8: Object Types
The addresses of the templates for the types of object that can appear in the data for a room (see RoomData), indexed by the type. Objects of type 1F switch to the second table at SecondObjectTypes for the objects which follow in the room.
ObjectTypes 73C8 DEFW $0000 Type 00: unused.
73CA DEFW ObjectTemplates Type 01: a block (ObjectTemplates).
73CC DEFW ObjectTemplate_FatBottomBlock Type 02: a block which is fat at the bottom (ObjectTemplate_FatBottomBlock).
73CE DEFW ObjectTemplate_FatTopBlock Type 03: a block which is fat at the top (ObjectTemplate_FatTopBlock).
73D0 DEFW ObjectTemplate_BlockMovingUpDown Type 04: a block which moves up and down (ObjectTemplate_BlockMovingUpDown).
73D2 DEFW ObjectTemplate_FallingBlock Type 05: a block which falls when touched (ObjectTemplate_FallingBlock).
73D4 DEFW ObjectTemplate_CollapsingBlock Type 06: a block which collapses (ObjectTemplate_CollapsingBlock).
73D6 DEFW ObjectTemplate_BrokenEgg Type 07: a broken egg (ObjectTemplate_BrokenEgg).
73D8 DEFW ObjectTemplate_ConveyorNorth Type 08: a conveyor which carries objects north (ObjectTemplate_ConveyorNorth).
73DA DEFW ObjectTemplate_ConveyorEast Type 09: a conveyor which carries objects east (ObjectTemplate_ConveyorEast).
73DC DEFW ObjectTemplate_ConveyorSouth Type 0A: a conveyor which carries objects south (ObjectTemplate_ConveyorSouth).
73DE DEFW ObjectTemplate_ConveyorWest Type 0B: a conveyor which carries objects west (ObjectTemplate_ConveyorWest).
73E0 DEFW ObjectTemplate_BlockMovingUpDownWithPlayer Type 0C: a block which moves up and down while the player is on it (ObjectTemplate_BlockMovingUpDownWithPlayer).
73E2 DEFW ObjectTemplate_BlockMovingEastWest Type 0D: a block which moves east and west (ObjectTemplate_BlockMovingEastWest).
73E4 DEFW ObjectTemplate_BlockMovingNorthSouth Type 0E: a block which moves north and south (ObjectTemplate_BlockMovingNorthSouth).
73E6 DEFW ObjectTemplate_DeadlyPyramid Type 0F: a deadly pyramid (ObjectTemplate_DeadlyPyramid).
73E8 DEFW ObjectTemplate_Sparkle Type 10: a sparkle (ObjectTemplate_Sparkle).
73EA DEFW ObjectTemplate_RobotMouseCircuit Type 11: a robot mouse which runs in a circuit (ObjectTemplate_RobotMouseCircuit).
73EC DEFW ObjectTemplate_RobotMouseEastWest Type 12: a robot mouse which runs east and west (ObjectTemplate_RobotMouseEastWest).
73EE DEFW ObjectTemplate_RobotMouseNorthSouth Type 13: a robot mouse which runs north and south (ObjectTemplate_RobotMouseNorthSouth).
73F0 DEFW ObjectTemplate_EggTop Type 14: the top of a broken egg (ObjectTemplate_EggTop).
73F2 DEFW ObjectTemplate_CryonautEast Type 15: a cryonaut looking east (ObjectTemplate_CryonautEast).
73F4 DEFW ObjectTemplate_CryonautSouth Type 16: a cryonaut looking south (ObjectTemplate_CryonautSouth).
73F6 DEFW ObjectTemplate_DeadlyTubes Type 17: deadly tubes (ObjectTemplate_DeadlyTubes).
73F8 DEFW ObjectTemplate_SocketCylinder Type 18: a socket for a cylinder (ObjectTemplate_SocketCylinder).
73FA DEFW ObjectTemplate_SocketCube Type 19: a socket for a cube (ObjectTemplate_SocketCube).
73FC DEFW ObjectTemplate_SocketPyramid Type 1A: a socket for a pyramid (ObjectTemplate_SocketPyramid).

7400 DEFW ObjectTemplate_ClockworkMouse Type 1C: a clockwork mouse (ObjectTemplate_ClockworkMouse).
7402 DEFW ObjectTemplate_ChasingDome Type 1D: a chasing dome (ObjectTemplate_ChasingDome).
7404 DEFW ObjectTemplate_RemoteControlRobot Type 1E: the remote control robot (ObjectTemplate_RemoteControlRobot).
7406 DEFW $0000 Type 1F: the switch to the second table.
