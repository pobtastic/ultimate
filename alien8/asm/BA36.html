BA36: Print Statistics
Used by the routine at GameOver.
Prints the statistics for the game which has ended, using Font: three digits of CryonautsLost, and two digits each of ChambersFoundActivated and ChambersNotActivated. They are counted by CountStatistics.
Print the cryonauts that were lost.
PrintStatistics BA36 LD HL,$6308 Set FontPointer to Font.
BA39 LD ($5B27),HL
BA3C LD DE,$5B3C Point DE at CryonautsLost.
BA3F LD HL,$DBF6 Point HL at ScreenBuffer_CryonautsLost.
BA42 LD B,$02 Set the number of bytes to 02.
BA44 CALL PrintLowDigit Call PrintLowDigit.
Print the chambers that were found activated.
BA47 LD HL,$E1F7 Point HL at ScreenBuffer_ChambersFoundActivated.
BA4A LD B,$01 Set the number of bytes to 01.
BA4C CALL PrintBCDBytes Call PrintBCDBytes.
Print the chambers that were not activated.
BA4F LD HL,$DDF7 Point HL at ScreenBuffer_ChambersNotActivated.
BA52 LD B,$01 Set the number of bytes to 01.
BA54 JP PrintBCDBytes Jump to PrintBCDBytes.
