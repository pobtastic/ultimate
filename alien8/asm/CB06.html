CB06: Print Table Sprite
Used by the routines at DrawPanel and PrintBorder.
Sets the details of an object from four bytes of data, and prints its sprite.
Input
HL The address of the data
IX The address of the object
Output
HL The address of the byte after the data
PrintTableSprite CB06 CALL SetSpriteDetails Call SetSpriteDetails.
CB09 PUSH HL Stash HL on the stack.
CB0A CALL PrintSprite Call PrintSprite.
CB0D POP HL Restore HL from the stack.
CB0E RET Return.
