AA63: Handle Remote Control Arrow
The update routine for the remote control arrows (objects 7A and 7B). Object 7A is west, or north when flipped; object 7B is east, or south when flipped, giving commands 02 to 05.
Input
IX The address of the object
Send a direction if something has landed.
HandleRemoteControlArrow AA63 CALL SetPixelAdjustments Call SetPixelAdjustments.
AA66 LD A,(IX+$0B) Fetch the vertical speed.
AA69 AND A Return if nothing has landed.
AA6A RET Z
AA6B XOR A Write 00 to the vertical speed.
AA6C LD (IX+$0B),A
AA6F LD A,(IX+$07) Fetch the flags of the pad.
AA72 RLCA Move the flip into bit 7.
AA73 AND %10000000 Keep bit 7.
AA75 LD C,A Keep it in C.
AA76 LD A,(IX+$00) Fetch the sprite number.
AA79 AND %00000001 Keep bit 0.
AA7B OR C Combine it with the flip.
AA7C RLCA Move the bits into a command.
AA7D ADD A,$02 Add 02.
AA7F LD C,A Keep the command in C.
AA80 LD HL,$5B42 Point HL at RemoteControlCommand.
AA83 LD A,(HL) Fetch the command.
AA84 AND %10000000 Keep bit 7.
AA86 OR C Combine it with the new command.
AA87 LD (HL),A Set RemoteControlCommand.
AA88 RET Return.
