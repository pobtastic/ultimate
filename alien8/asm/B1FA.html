B1FA: Extend Object Downwards
Used by the routines at HandleCircuitMouse and HandleBouncingMouse.
Lowers the object by 0C and doubles its height, so that it covers both parts of a robot mouse. It also sets bit 1 of the flags of the next object, so that collision tests ignore it. RestoreObjectHeight undoes this.
Input
IX The address of the object
Cover both parts of the mouse.
ExtendObjectDownwards B1FA LD A,(IX+$03) Fetch the height of the object.
B1FD SUB $0C Subtract 0C.
B1FF LD (IX+$03),A Set the height of the object.
B202 SLA (IX+$06) Double the height of the object.
B206 SET 1,(IX+$27) Set bit 1 of the next object's flags.
B20A RET Return.
