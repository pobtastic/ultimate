CBE3: Set Border Attributes
Sets the colours of the panel at the bottom of the screen: black for the two columns at the sides of the window, and bright red for the window itself.
Colour the sides black, then the window bright red.
SetBorderAttributes CBE3 XOR A Set A to 00.
CBE4 LD HL,$5AB6 Point HL at 5AB6 (in the attribute buffer).
CBE7 LD BC,$0103 Set BC to 0103.
CBEA CALL FillWindow Call FillWindow.

CBF6 LD A,$42 Set A to 42.

CBFB LD BC,$0604 Set BC to 0604.
