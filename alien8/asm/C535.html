C535: Block Movement In Z
Used by the routine at BlockMovement.
Brings the speed along z of an object closer to zero until it does not run into any other object. This works in the same way as BlockMovementInX, except that the object that is hit is flagged as touched (bit 3 of its extra flags) if the player is the object that hit it. An object which can be moved gives its speed along z to the other object, and takes on the speeds along x and y of the other object if it has none of its own.
Input
C Speed along x
L Speed along y
H Speed along z
IX The address of the object
Output
H The new speed along z
