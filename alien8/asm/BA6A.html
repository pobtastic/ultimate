BA6A: Print BCD Bytes
Used by the routines at PrintStatistics and PrintLowDigit.
Prints the digits of a number held in BCD, two to each byte.
Input
B Number of bytes
DE Address of the number
HL Address in the screen buffer
Print the upper digit of the byte.
PrintBCDBytes BA6A LD A,(DE) Fetch a byte of the number.
BA6B RRCA Move the upper digit to the lowest four bits.
BA6C RRCA
BA6D RRCA
BA6E RRCA
BA6F AND %00001111 Keep only bits 0 to 3.
BA71 CALL PrintCharacter Call PrintCharacter.
