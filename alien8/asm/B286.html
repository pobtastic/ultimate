B286: Handle Conveyor West
The handler for a conveyor which carries objects west (object 47).
Input
IX The address of the object
Set the westward speed.
HandleConveyorWest B286 LD (IX+$09),$FE Write FE as the speed along the x axis.
B28A JR HandleConveyor Jump to HandleConveyor.
