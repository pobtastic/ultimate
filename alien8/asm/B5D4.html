B5D4: Play Pitch From Table
Plays four beeps at a pitch taken from PitchTable, using bits 0 to 2 of FrameCounter. Nothing in the game uses this routine.
Choose a pitch from the table.
PlayPitchFromTable B5D4 LD A,($5B02) Fetch FrameCounter.
B5D7 AND %00000111 Keep bits 0 to 2.
B5D9 LD L,A Set HL to the entry number.
B5DA LD H,$00
B5DC LD BC,$B5E6 Point HL at the entry in PitchTable.
B5DF ADD HL,BC
B5E0 LD B,(HL) Fetch the pitch.
B5E1 LD C,$04 Set the number of beeps to 04.
B5E3 JP PlayWaveSequence Jump to PlayWaveSequence.
