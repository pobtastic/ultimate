BFAB: Set Wipe And Draw Flags
Used by the routines at HandleLandMine, HandleEndingRobotBottom, HandleRemoteControlRobot, HandleAttackingTool, HandleAlarm, HandleEggTop, SetWipeAndDrawFlagsForObject, HandleValveGhost, HandleValveGhostSparkle, HandleValve, HandleMouseSecondPart, HandleBlockMovingEastWest, SetDeadlyFlagsAndDraw, HandleFallingBlock, HandleFatBottomBlock, HandleMovingBlock, HandleSparkle, PlaySoundAndRedraw, HandlePlayerAppearing and HandlePlayerLegs.
Flags an object to be wiped and drawn again, and flags every other object that overlaps it to be drawn too.
Input
IX The address of the object
Set the wipe and draw bits, then flag overlaps.
SetWipeAndDrawFlags BFAB LD A,(IX+$07) Fetch the flags of the object.
BFAE OR %00110000 Set bits 4 and 5.
BFB0 LD (IX+$07),A Store the flags.
BFB3 JP FlagOverlappingObjects Jump to FlagOverlappingObjects.
