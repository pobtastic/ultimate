C36D: Handle Room Exit
Used by the routine at MovePlayer.
Sends the player to the next room if it has walked out through an arch. Only a player that is near an arch can leave the room, and not while it is still entering the room. The edge that counts is the one in the direction that the player is facing.
Input
IX The address of the object
Return unless near an arch and not entering.
