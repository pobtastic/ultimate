B6CE: Play Footsteps Sound
Used by the routine at HandleWalking.
Plays the footsteps of the player walking, but only on every other frame of the walking animation, which is when the sprite number of the object is even.
Input
IX The address of the object
Return unless this is an even sprite.
PlayFootstepsSound B6CE LD A,(IX+$00) Fetch the sprite number.
B6D1 AND %00000001 Keep only bit 0.
B6D3 RET NZ Return if the sprite number is odd.
Continue on to PlayFootstepsSound_EveryFrame.
