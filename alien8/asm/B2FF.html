B2FF: Handle Fat Bottom Block
The handler for a block which is fat at the bottom (object 1C). The block is moved with gravity. If it is still moving its x and y speeds are cleared and it makes a sound. Otherwise it is only redrawn if it has been moved. HandleFatTopBlock joins this routine at HandleFatBottomBlock_Move.
Input
IX The address of the object
Move the block and redraw it if it has changed.
HandleFatBottomBlock B2FF CALL SetPixelAdjustments Call SetPixelAdjustments.
This entry point is used by the routine at HandleFatTopBlock.
HandleFatBottomBlock_Move B302 CALL SavePosition Call SavePosition.
B305 CALL ApplyGravityAndMove Call ApplyGravityAndMove.
B308 CALL TestObjectMoving Jump to HandleFatBottomBlock_Stop if the block is moving.
B30B JR NZ,HandleFatBottomBlock_Stop
B30D CALL ComparePosition Return if the position is the same.
B310 RET Z
B311 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags.
The block is still moving.
HandleFatBottomBlock_Stop B314 CALL ClearSpeed Call ClearSpeed.
B317 JP PlaySoundAndRedraw Jump to PlaySoundAndRedraw.
