6300: Game Entry Point
The address which the tape loader jumps to once the game has been loaded. It disables interrupts, puts the stack just below ReversedByteTable, and starts the game.
Disable interrupts and start the game.
GameEntry 6300 DI Disable interrupts.
6301 LD SP,$F100 Set the stack pointer to ReversedByteTable.
6304 NOP No operation.
6305 JP StartGame Jump to StartGame.
