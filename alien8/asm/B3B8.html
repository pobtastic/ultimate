B3B8: Retire Object
The handler for the last of the sparkles (object 37). It sets the pixel offsets and makes the object a retired object (object 01).
Input
IX The address of the object
Become a retired object.
RetireObject B3B8 CALL SetPixelAdjustments_Sparkle Call SetPixelAdjustments_Sparkle.
This entry point is used by the routines at HandleValveGhost and HandleValveGhostSparkle.
RetireObject_Retire B3BB LD (IX+$00),$01 Write 01 as the sprite number.
Continue on to PlaySoundAndRedraw.
