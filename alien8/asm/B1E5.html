B1E5: Copy Previous Position
Used by the routine at HandleMouseSecondPart.
Copies the position of the object before this one in the table to this object, with the height lowered by 0C.
Input
IX The address of the object
Copy x, y and height from the previous object.
CopyPreviousPosition B1E5 LD A,(IX-$1F) Fetch the x position of the previous object.
B1E8 LD (IX+$01),A Set the x position of this object.
B1EB LD A,(IX-$1E) Fetch the y position of the previous object.
B1EE LD (IX+$02),A Set the y position of this object.
B1F1 LD A,(IX-$1D) Fetch the height of the previous object.
B1F4 SUB $0C Subtract 0C.
B1F6 LD (IX+$03),A Set the height of this object.
B1F9 RET Return.
