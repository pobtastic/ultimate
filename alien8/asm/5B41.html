5B41: Game Over Scene Stage
Zero until the alarm in the game over scene has flashed 10 times (see HandleAlarm). Then it is set to 01, and is used by the objects which attack the robot: bit 7 is set while one of them is moving, and the lower bits count the attacks that have been made. The game restarts when the count reaches 10.
