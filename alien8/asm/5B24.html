5B24: Game Over Flag
Set when the scene for the end of the game is about to be shown (see GameOver), and not cleared again until the game restarts. While it is set the pixel positions of the objects are left as the scene set them (CalculatePixelCoordinates), no controls are read (ReadControls) and the main loop only refreshes the screen when the panel needs to be redrawn (A6F7).
