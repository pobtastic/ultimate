B712: Test Object Intersections
Used by the routine at HandlePickupAndDrop.
Tests whether an object overlaps any other solid object in the table that starts at PlayerBottomObject, without moving. The object itself is ignored while the table is searched.
Input
IX The address of the object
Output
F Carry flag set if the object intersects another object
Start at the first object with no movement.
