5B2F: Second List Position
The address in the list at ObjectsToDrawList just after the entry of the other object of the pair that DrawObjectsInOrder_First is comparing (the object at IY). If that object has to be drawn first, CompareWithOtherObject copies this address to FirstListPosition.
