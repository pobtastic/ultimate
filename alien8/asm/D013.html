D013: Draw Object
Used by the routine at DrawNextObject.
Draws an object into ScreenBuffer. An object that has the sprite number 01 is removed instead, by making it null.
Input
IX The address of the object
Remove the object if it is retired.
DrawObject D013 LD A,(IX+$00) Fetch the sprite number.
D016 CP $01 Jump to DrawObject_Draw if it is not 01.
D018 JR NZ,DrawObject_Draw
D01A LD (IX+$00),$00 Write 00 to the sprite number.
D01E RET Return.
Find the position and draw the sprite.
DrawObject_Draw D01F RES 4,(IX+$07) Reset bit 4 of the flags.
D023 CALL CalculatePixelCoordinates Call CalculatePixelCoordinates.
D026 RET NC Return if the sprite is not on the screen.
Continue on to PrintSprite.
