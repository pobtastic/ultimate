BD6B: Handle Pickup And Drop
Used by the routine at HandlePlayerLegs.
Picks up or drops an object when the player presses the control for it. A valve which is close enough is picked up. If the player is carrying three objects already then the one that has been carried longest is dropped where the new one was. Otherwise, if the player is carrying something and there is a free place for a special object in the room, the object that has been carried longest is dropped where the player stands, and the player is lifted up by 0C to stand on it.
The routine looks for objects by making the player a little wider, deeper and taller, which is put right when the routine ends.
The objects carried are four lots of four bytes from ObjectsCarriedHeader: the object number, the flags and the address of the entry in SpecialObjects. The first is the place for a new object and the last is the one that has been carried longest.
