CCDE: Make Room Objects
Used by the routine at RetrieveRoom.
Makes the objects of a room from its entry in the room data. The colour of the room is the low three bits of the byte after the length, and the size of the room is the high two bits. The size gives the distance to the walls and the floor level, from the table at RoomSizes. Each type of block is the number of an entry in the table at BlockTypes, which holds the address of a template of one or more objects that already have their coordinates. These are copied into the objects table, along with the number of the room. The types of block end with a FF, or at the end of the entry if there are no more objects. After the FF come the groups of other objects, each with a type in bits 3 to 7 and one less than the number of places in bits 0 to 2, followed by that many positions (see RoomData). Type 00 sets the position offset at PositionOffset, and type 1F switches the table of types from ObjectTypes to SecondObjectTypes. The other types are lists of objects that have a sprite, a size and flags, but no coordinates.
Input

The offset at PositionOffset has the half step along the x axis in bit 0, the half step along the y axis in bit 1, and the offset up the z axis in bits 2 to 7. The place has the x position in bits 0 to 2, the y position in bits 3 to 5 and the height in bits 6 and 7. The x position of the object is the x position times 10, plus 08 if the half step is set, plus 48.
CD81 LD A,($5B19) Fetch the position offset from PositionOffset.

CD85 RLCA
CD86 RLCA

CD89 LD E,A Stash it in E.
CD8A LD A,D Fetch the place.
CD8B RLCA Move the x position into bits 4 to 6.
CD8C RLCA
CD8D RLCA
CD8E RLCA
CD8F AND %01110000 Keep it.
CD91 ADD A,E Add the half step.
CD92 ADD A,$48 Add 48.
CD94 LD (IY+$01),A Set the x position of the object.
