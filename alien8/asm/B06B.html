B06B: Handle Circuit Mouse
The handler for the robot mice (objects 5E and 5F) which run in circuits. When a mouse is blocked, or is not moving, it makes a noise and turns a quarter turn one way or the other, chosen at random. Its speed is then set from the way it faces, and doubled.
Input
IX The address of the object
Move, or turn if the mouse is blocked.
