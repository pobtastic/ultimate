AE5D: Handle Placed Valve
The handler for a valve which has been placed on a socket (objects 64 to 67). It stays where it is.
Input
IX The address of the object
Stop the valve moving.
HandlePlacedValve AE5D CALL SetPixelAdjustments_Valve Call SetPixelAdjustments_Valve.
AE60 XOR A Set A to 00.
AE61 LD (IX+$09),A Stop the speed along the x axis.
AE64 LD (IX+$0A),A Stop the speed along the y axis.
AE67 RET Return.
