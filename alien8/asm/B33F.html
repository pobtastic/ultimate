B33F: Handle Moving Block
The handler for a block which moves up and down (object 1F), and the code which moves the block for HandleRisingBlock. It falls with gravity until it lands, then rises at 03 until it is higher than BlockScratch, when it falls again. The first block sets BlockScratch to its own height. Bit 2 of the state remembers whether it is rising.
