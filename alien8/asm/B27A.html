B27A: Handle Conveyor East
The handler for a conveyor which carries objects east (object 45).
Input
IX The address of the object
Set the eastward speed.
HandleConveyorEast B27A LD (IX+$09),$02 Write 02 as the speed along the x axis.
B27E JR HandleConveyor Jump to HandleConveyor.
