AA4D: Handle Remote Control Block
The update routine for the remote control block (object 80), the pad which tells the robot to stop. It is pressed when its vertical speed is not zero. The command is 01; bit 7 of RemoteControlCommand is left as it was.
Input
IX The address of the object
Send the stop command if something has landed.
HandleRemoteControlBlock AA4D CALL SetPixelAdjustments Call SetPixelAdjustments.
AA50 LD A,(IX+$0B) Fetch the vertical speed.
AA53 AND A Return if nothing has landed.
AA54 RET Z
AA55 XOR A Write 00 to the vertical speed.
AA56 LD (IX+$0B),A
AA59 LD HL,$5B42 Point HL at RemoteControlCommand.
AA5C LD A,(HL) Fetch the command.
AA5D AND %10000000 Keep bit 7.
AA5F OR %00000001 Set the command to 01.
AA61 LD (HL),A Set RemoteControlCommand.
AA62 RET Return.
