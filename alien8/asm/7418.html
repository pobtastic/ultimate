7418: Object Templates
The templates for the objects. Each is a list of one or more objects, each of five bytes: the sprite number, the width, the depth, the height and the flags which are copied into the object (see PlayerBottomObject). A list ends with 00, and when there is more than one object in a list the later ones are attached to the first (a mouse for example has a second part which follows it around). Bit 6 of the flags flips the sprite left to right.
