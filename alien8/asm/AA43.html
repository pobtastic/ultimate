AA43: Remote Control Robot Speeds
The speeds along the x and y axes given to the remote control robot for commands 01 to 05.
RemoteControlRobotSpeeds AA43 DEFB $00,$00 Command 01: stop
AA45 DEFB $FE,$00 Command 02: move west
AA47 DEFB $00,$02 Command 03: move north
AA49 DEFB $02,$00 Command 04: move east
AA4B DEFB $00,$FE Command 05: move south
