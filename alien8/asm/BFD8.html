BFD8: Handle Far Arch
The handler for the far side of an arch (object 03). It only needs to set the adjustments to the pixel position of the sprite, which are not the same when the sprite is flipped.
Input
IX The address of the object
Choose the adjustments from the flip flag.
HandleFarArch BFD8 BIT 6,(IX+$07) Jump to HandleFarArch_Flipped if the sprite is flipped.
BFDC JR NZ,HandleFarArch_Flipped
BFDE LD HL,$FBF0 Set HL to FBF0.
BFE1 JP SetPixelAdjustments_Store Jump to SetPixelAdjustments_Store.
HandleFarArch_Flipped BFE4 LD HL,$FCF8 Set HL to FCF8.
BFE7 JP SetPixelAdjustments_Store Jump to SetPixelAdjustments_Store.
