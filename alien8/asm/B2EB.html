B2EB: Compare Position
Used by the routine at HandleFatBottomBlock.
Compares the position of the object with the one saved by SavePosition.
Input
IX The address of the object
Output
F Zero flag set if the position is the same
Compare x, y and z with SavedPosition.
ComparePosition B2EB LD HL,$5B1B Point HL at SavedPosition.
B2EE LD A,(IX+$01) Fetch the x position.
B2F1 CP (HL) Compare it with the saved x position.
B2F2 RET NZ Return if it is different.
B2F3 INC HL Move on.
B2F4 LD A,(IX+$02) Fetch the y position.
B2F7 CP (HL) Compare it with the saved y position.
B2F8 RET NZ Return if it is different.
B2F9 INC HL Move on.
B2FA LD A,(IX+$03) Fetch the z position.
B2FD CP (HL) Compare it with the saved z position.
B2FE RET Return.
