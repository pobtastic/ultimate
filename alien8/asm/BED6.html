BED6: Test Object Moving
Used by the routines at HandleRemoteControlRobot, HandleValve, HandleFatBottomBlock and HandleExtraLife.
Tests whether the object is moving.
Input
IX The address of the object
Output
F Zero flag set if the object is not moving
Combine the three speeds.
TestObjectMoving BED6 LD A,(IX+$09) Fetch the speed along the x axis.
BED9 OR (IX+$0A) Combine it with the speed along the y axis.
BEDC OR (IX+$0B) Combine it with the speed along the z axis.
BEDF RET Return.
