BB9D: Print Text Single Colour
Used by the routine at DisplayTextList.
Prints a line of text in the colour held in TextAttribute, using the ASCII font at 6188. The last character of the text has bit 7 set. Each character cell has its attribute set as well.
Input
DE Address of the text
HL Pixel position
Point at the ASCII font and keep TextAttribute.
PrintTextSingleColour BB9D PUSH HL Stash the pixel position on the stack.
BB9E LD HL,$6188 Point HL at 6188.
BBA1 LD ($5B27),HL Set FontPointer.
BBA4 POP BC Copy the pixel position to BC (using the stack).
BBA5 PUSH BC
BBA6 CALL CalculateBufferAddress Call CalculateBufferAddress.
BBA9 LD L,C Copy it to HL.
BBAA LD H,B
BBAB LD A,($5B16) Fetch TextAttribute.
BBAE EX AF,AF' Keep the colour in AF'.
BBAF JR PrintTextStandardFont_PrintLine Jump to PrintTextStandardFont_PrintLine.
