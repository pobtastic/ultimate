BAFB: Flash Menu Options
Used by the routine at GameMenu.
Makes the line of the menu for the selected control method flash, and the line for directional control if that is on.
Flash the chosen control method.
FlashMenuOptions BAFB LD HL,$BB15 Point HL at MenuColours_FirstOption.
BAFE LD A,($5B04) Fetch ControlMethod.
BB01 RRCA Move the method to bits 0 and 1.
BB02 AND %00000011 Keep only bits 0 and 1.
BB04 LD B,$04 Set a counter of 04 lines.
BB06 CALL SetFlashingAttribute Call SetFlashingAttribute.
Flash directional control if it is on.
BB09 RES 7,(HL) Reset bit 7 of the attribute.
BB0B LD A,($5B04) Fetch ControlMethod.
BB0E AND %00001000 Keep only bit 3.
BB10 RET Z Return if it is off.
BB11 SET 7,(HL) Set bit 7 of the attribute.
BB13 RET Return.
