AA89: Handle Chasing Dome
The update routine for the chasing dome (objects 78 and 79), which is deadly to touch. It moves towards the player at one unit per pass in each direction.
Input
IX The address of the object
Head towards the player and redraw the dome.
HandleChasingDome AA89 CALL SetPixelAdjustments_Sparkle Call SetPixelAdjustments_Sparkle.
AA8C LD BC,$0101 Set the speed along each axis to 01.
AA8F CALL SetSpeedTowardsPlayer Call SetSpeedTowardsPlayer.
AA92 CALL ApplyGravityAndMove Call ApplyGravityAndMove.
AA95 CALL ToggleSpriteNumber Call ToggleSpriteNumber.
AA98 LD HL,$B6AD Point HL at MovingSoundLengths_ChasingDome.
AA9B CALL PlayMovingSound Call PlayMovingSound.
AA9E JP SetDeadlyFlagsAndDraw Jump to SetDeadlyFlagsAndDraw.
