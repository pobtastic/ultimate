BA62: Print BCD Number
Used by the routines at PrintActivatedChambers and PrintLives.
Prints a number which is held in BCD, using the font with the digits.
Input
B Number of bytes
DE Address of the number
HL Address in the screen buffer
Point at the digit font.
PrintBCDNumber BA62 PUSH HL Stash the screen buffer address on the stack.
BA63 LD HL,$6308 Set FontPointer to Font.
BA66 LD ($5B27),HL
BA69 POP HL Restore the screen buffer address from the stack.
