25705: Room Data
The data for the rooms, in 128 variable length blocks. Each starts with the number of the room and the length of the block (which counts the length byte but not the room number). Next comes a byte for the colour and size of the room: bits 0 to 2 hold the colour, bits 3 to 5 hold a second colour (which SetRoomAttributes copies over the first when the game starts) and bits 6 and 7 choose the size of the room from RoomSizes.
After that come the types of the blocks that make up the walls, doors and other fixtures of the room (see BlockTypes), ending with 255.
The rest of the block lists the other objects in the room. Each starts with a byte holding the type of the object in its upper five bits (see ObjectTypes) and the number of places it appears in, less one, in its lower three bits. Then there is a byte for each of the places, with the x position in bits 0 to 2, the y position in bits 3 to 5 and the height in bits 6 and 7. An object of type 0 does not appear at all: the byte after it is an offset (bit 0 moves later objects half a place along the x axis, bit 1 half a place along the y axis, and bits 2 to 7 up the z axis). An object of type 31 switches to the second table of object types. The objects are built by RetrieveRoom.
