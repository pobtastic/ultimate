43597: Handle Remote Control Block
The update routine for the remote control block (object 128), the pad which tells the robot to stop. It is pressed when its vertical speed is not zero. The command is 1; bit 7 of RemoteControlCommand is left as it was.
Input
IX The address of the object
Send the stop command if something has landed.
HandleRemoteControlBlock 43597 CALL SetPixelAdjustments Call SetPixelAdjustments.
43600 LD A,(IX+11) Fetch the vertical speed.
43603 AND A Return if nothing has landed.
43604 RET Z
43605 XOR A Write 0 to the vertical speed.
43606 LD (IX+11),A
43609 LD HL,23362 Point HL at RemoteControlCommand.
43612 LD A,(HL) Fetch the command.
43613 AND %10000000 Keep bit 7.
43615 OR %00000001 Set the command to 1.
43617 LD (HL),A Set RemoteControlCommand.
43618 RET Return.
