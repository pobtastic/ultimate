53536: Calculate Buffer Address
Used by the routines at UpdateLightYears, PrintTextSingleColour, PrintTextStandardFont, DisplayObjectsCarried, CopyAreaToScreen, DrawChangedObjects and PrintSprite.
Finds the address in ScreenBuffer of the byte that holds a pixel. The buffer has the lines of the screen from the bottom, 32 bytes to a line.
Input
B The pixel y position
C The pixel x position
Output
BC The address in the buffer
Work out the byte from the position.
