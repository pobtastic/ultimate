30435: Special Objects
The table of the 36 special objects: the valves which have to be found and put on the sockets, and the extra lives. Each entry has nine bytes. The first is the number of the object and starts as zero, because the objects are chosen at random when a game starts (by InitialiseSpecialObjects). The next four are the starting position of the object (its x, y and z coordinates and the number of the room), which are copied by InitialiseSpecialObjects to the last four bytes, where the current position is kept (see UpdateSpecialObjects).
