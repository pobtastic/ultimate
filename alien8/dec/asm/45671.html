45671: Handle Conveyor North
The handler for a conveyor which carries objects north (object 68). The conveyor does not move but is given a speed of 2 along the y axis, which is used for the objects which stand on it. The other conveyors set a different speed and continue from HandleConveyor.
Input
IX The address of the object
Set the northward speed.
HandleConveyorNorth 45671 LD (IX+10),2 Write 2 as the speed along the y axis.
This entry point is used by the routines at HandleConveyorEast, HandleConveyorSouth and HandleConveyorWest.
Draw the conveyor and stop it falling.
HandleConveyor 45675 CALL SetPixelAdjustments Call SetPixelAdjustments.
45678 LD A,(IX+11) Fetch the speed along the z axis.
45681 AND A Call PlayHighBeep if something has landed on it.
45682 CALL NZ,PlayHighBeep
45685 XOR A Write 0 as the speed along the z axis.
45686 LD (IX+11),A
45689 RET Return.
