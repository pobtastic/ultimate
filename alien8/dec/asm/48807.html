48807: Test Object Can Be Picked Up
Used by the routine at HandlePickupAndDrop.
Tests whether an object is one of the four valves (objects 96 to 99) that the player is on or close to.
Input
IX The address of the player
IY The address of the object
Output
F Carry flag set if the object can be picked up
Return unless the object is a valve.
