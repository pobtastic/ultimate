46548: Play Pitch From Table
Plays four beeps at a pitch taken from PitchTable, using bits 0 to 2 of FrameCounter. Nothing in the game uses this routine.
Choose a pitch from the table.
PlayPitchFromTable 46548 LD A,(23298) Fetch FrameCounter.
46551 AND %00000111 Keep bits 0 to 2.
46553 LD L,A Set HL to the entry number.
46554 LD H,0
46556 LD BC,46566 Point HL at the entry in PitchTable.
46559 ADD HL,BC
46560 LD B,(HL) Fetch the pitch.
46561 LD C,4 Set the number of beeps to 4.
