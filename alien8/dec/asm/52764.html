52764: Clear Bytes
Used by the routines at CountStatistics, PlaceSpecialObjectsInRoom, HandlePickupAndDrop, ClearRemainingObjects and MakeRoomObjects.
Fills a number of bytes with zero. The entry point at FillBytes fills them with the byte in A.
Input
B Number of bytes
DE Address of the first byte
ClearBytes 52764 XOR A Set A to 0.
This entry point is used by the routine at UpdatePanel.
FillBytes 52765 LD (DE),A Write A.
52766 INC DE Increment DE.
52767 DJNZ FillBytes Jump to FillBytes until B is zero.
52769 RET Return.
