44021: Handle Alarm
The handler for the alarm (object 80) in the game over scene. Every eight frames it changes colour between black and bright yellow and beeps. After 16 changes it retires itself and starts the attacks on the robot by setting GameOverSceneStage.
Input
IX The address of the object
Flash the alarm every eight frames.
