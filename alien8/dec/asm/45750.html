45750: Handle Falling Block
The handler for a block which falls when something stands on it (object 44). It falls by one step on each frame that something is standing on it, and makes a sound unless it has landed.
Input
IX The address of the object
Fall if something is standing on the block.
HandleFallingBlock 45750 CALL SetPixelAdjustments Call SetPixelAdjustments.
45753 BIT 3,(IX+13) Test bit 3 of the state.
45757 RES 3,(IX+13) Reset bit 3 of the state.
45761 RET Z Return if nothing was standing on the block.
45762 LD (IX+11),0 Write 0 as the speed along the z axis.
45766 CALL ApplyGravityAndMove Call ApplyGravityAndMove.
45769 LD (IX+11),0 Write 0 as the speed along the z axis.
45773 BIT 2,(IX+12) Jump to HandleFallingBlock_Redraw if the block has landed.
45777 JR NZ,HandleFallingBlock_Redraw
45779 CALL PlaySoundFromHeight Call PlaySoundFromHeight.
HandleFallingBlock_Redraw 45782 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags.
