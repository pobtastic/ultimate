23420: Objects Carried
The objects that the player is carrying. There is room for three, each using four bytes: the first byte of each is the number of the object (or zero for an empty space), the second is its flags and the other two are an address that was held in the record of the object. The status panel shows the objects by drawing their sprites.
ObjectsCarried 23420 DEFB 0,0,0,0 The first object.
ObjectsCarried_Second 23424 DEFB 0,0,0 The second object.
ObjectsCarried_SecondEnd 23427 DEFB 0 The last byte of the second object.
ObjectsCarried_Third 23428 DEFB 0,0,0 The third object.
ObjectsCarried_ThirdEnd 23431 DEFB 0 The last byte of the third object.
