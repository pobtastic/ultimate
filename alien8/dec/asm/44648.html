44648: Handle Socket
The handler for the sockets (objects 112 to 115). When there are no special objects in the room and the next object slot is free, it creates the sparkle form of the ghost of the valve which fits the socket (see HandleValveGhostSparkle).
Input
IX The address of the object
Create a sparkle in the next object slot.
HandleSocket 44648 CALL SetPixelAdjustments_Legs Call SetPixelAdjustments_Legs.
44651 CALL TestValvesInPlay Return if there are special objects in the room.
44654 RET NZ
44655 LD A,(IX+32) Fetch the sprite number of the next object.
44658 AND A Return if the next object slot is in use.
44659 RET NZ
44660 LD A,(IX+0) Fetch the sprite number of the socket.
44663 AND %00000011 Keep bits 0 and 1.
44665 OR %01101100 Make it a sparkle of that shape.
44667 LD (IX+32),A Set the sprite number of the next object.
44670 JP CalculatePixelPositionOfOtherObject Jump to CalculatePixelPositionOfOtherObject.
