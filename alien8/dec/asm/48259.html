48259: Handle Last Appearing Sparkle
The handler for the last of the sparkles in which the player appears (object 63). The object stops moving and gets back the sprite number which was kept at offset 16 of its record, and the object is handled again straight away with that sprite number.
Input
IX The address of the object
Stop the sparkle and restore the object.
