51077: Draw Objects In Order
Used by the routine at DrawChangedObjects.
Draws the objects in the list at ObjectsToDrawList so that the objects at the back are drawn before the objects in front of them. It takes the first object in the list that has not been drawn yet and compares it with each of the other objects that are waiting. If another object has to be drawn first, that object takes the place of the first object and is compared with the others in its turn. This carries on until an object is found that does not have to wait for any other object, and that one is drawn. This is repeated until the list is empty. The objects drawn are counted in ObjectsDrawn.
Clear the count and find the first object that is still waiting.

Each of the three directions gives a number. The number along z is 0 if the first object is above the other, 1 if the objects overlap along z and 2 if the first object is below. The number along y is 0 if the first object is to the north of the other, 3 if the objects overlap along y and 6 if the first object is to the south. The number along x is 0 if the first object is to the east of the other, 9 if the objects overlap along x and 18 if the first object is to the west. The three numbers are added together in C.
