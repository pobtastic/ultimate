51953: Set Sprite Details
Used by the routines at PrintTableSprite, DrawPanel and PrintBorder.
Sets the sprite number, the flags and the pixel position of an object from four bytes of data.
Input
HL The address of the data
IX The address of the object
Output
HL The address of the byte after the data
SetSpriteDetails 51953 LD A,(HL) Fetch the sprite number and move on.
51954 INC HL
51955 LD (IX+0),A Set the sprite number.
51958 LD A,(HL) Fetch the flags and move on.
51959 INC HL
51960 LD (IX+7),A Set the flags.
51963 LD A,(HL) Fetch the pixel x and move on.
51964 INC HL
51965 LD (IX+26),A Set the pixel x position.
51968 LD A,(HL) Fetch the pixel y and move on.
51969 INC HL
51970 LD (IX+27),A Set the pixel y position.
51973 RET Return.
