45708: Handle Collapsing Block
The handler for a block which collapses (object 45). When something stands on it the block turns into a sparkle (object 64) and disappears.
Input
IX The address of the object
Collapse if something is standing on the block.
HandleCollapsingBlock 45708 CALL SetPixelAdjustments Call SetPixelAdjustments.
45711 BIT 3,(IX+13) Test bit 3 of the state.
45715 RES 3,(IX+13) Reset bit 3 of the state.
45719 RET Z Return if nothing was standing on the block.
45720 LD (IX+0),64 Write 64 as the sprite number.
45724 JP HandleSparkle Jump to HandleSparkle.
