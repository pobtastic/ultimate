46241: Play Music Once
Used by the routine at GameMenu.
Plays a tune, but only if this routine has not played one before. Bit 0 of TunePlayedFlag is set the first time and nothing clears it. The tune stops when a key is pressed (see PlayMusic_WaitKey).
Input
DE Address of the tune
Play only if TunePlayedFlag is clear.
PlayMusicOnce 46241 LD HL,23345 Point HL at TunePlayedFlag.
46244 LD A,(HL) Return if TunePlayedFlag is set.
46245 AND A
46246 RET NZ
46247 SET 0,(HL) Set bit 0 of TunePlayedFlag.
Continue on to PlayMusic_WaitKey.
