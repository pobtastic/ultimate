50406: Block Movement In Y
Used by the routine at BlockMovement.
Brings the speed along y of an object closer to zero until it does not run into any other object. This works in the same way as BlockMovementInX.
Input
C Speed along x
L Speed along y
H Speed along z
IX The address of the object
Output
L The new speed along y
