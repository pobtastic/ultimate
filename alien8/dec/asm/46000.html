46000: Remove Object
Clears the byte whose address is held at offset 16 of the object, which is the number of a special object in SpecialObjects, so that the object does not come back.
Input
IX The address of the object
Clear the special object entry.
RemoveObject 46000 LD L,(IX+16) Fetch the low byte of the address.
46003 LD H,(IX+17) Fetch the high byte of the address.
46006 LD (HL),0 Write 0.
Continue on to RetireObject.
