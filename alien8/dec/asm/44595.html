44595: Handle Valve Ghost Sparkle
The handler for the sparkles shown between appearances of the valve ghost (objects 108 to 111). They hover over the socket in the same way as the ghost (see HandleValveGhost). The sparkle steps through the four shapes, and when it matches the socket it changes back into the ghost.
Input
IX The address of the object
Hover over the socket and step the shape.
HandleValveGhostSparkle 44595 CALL SetPixelAdjustments_Valve Call SetPixelAdjustments_Valve.
44598 CALL TestValvesInPlay Call TestValvesInPlay.

44604 LD A,(IX-29) Fetch the height of the socket.
44607 ADD A,13 Add 13.
44609 LD (IX+3),A Set the height of the sparkle.
44612 CALL NextSpriteNumber Call NextSpriteNumber.
44615 AND %00000011 Keep bits 0 and 1.
44617 LD C,A Keep it in C.
44618 LD A,(IX-32) Fetch the sprite number of the socket.
44621 AND %00000011 Keep bits 0 and 1.
44623 CP C Jump to HandleValveGhostSparkle_Redraw if the shapes are different.
44624 JR NZ,HandleValveGhostSparkle_Redraw
44626 RES 2,(IX+0) Reset bit 2 of the sprite number.
44630 LD (IX+16),2 Write 2 to the frame count.
HandleValveGhostSparkle_Redraw 44634 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags.
