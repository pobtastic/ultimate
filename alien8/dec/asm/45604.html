45604: Handle Block Moving East West
The handler for a block which moves east and west (object 66), and the code shared with HandleBlockMovingNorthSouth. The block follows a target that swings over 32 frames from FrameCounter. Neighbouring blocks are out of step because the low byte of the object address is added in. It moves by 1 each frame, with gravity cancelled out.
The axis is chosen by changing the operands of HandleBlockMoving_Compare and HandleBlockMoving_SetSpeed.
Input
IX The address of the object
