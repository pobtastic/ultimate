50916: Handle Player Top
Does all of the work for the top half of the robot (objects 32 to 43), which is a copy of the bottom half placed 12 above it. The top half is one unit shorter than the bottom half. If the top half has been flagged as killed this flags the bottom half as killed too and turns the player into a sparkle.
Input
IX The address of the object
Turn into a sparkle if killed.
