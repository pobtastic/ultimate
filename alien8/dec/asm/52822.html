52822: Fill Memory
Used by the routines at StartGame, RestartGame, ClearObjects and ClearScreenBitmap.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory 52822 LD E,0 Set E to 0.
This entry point is used by the routines at ClearAttributes and ClearScreenBuffer.
FillMemory_WithValue 52824 LD (HL),E Write E.
52825 INC HL Increment HL.
52826 DEC BC Decrement BC.
52827 LD A,B Jump to FillMemory_WithValue if BC is not zero.
52828 OR C
52829 JR NZ,FillMemory_WithValue
