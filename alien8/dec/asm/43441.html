43441: Handle Spiked Dome
The update routine for the spiked dome (object 129), which is deadly to touch and does not move. If it is ever set moving it is replaced with a sparkle (object 54).
Input
IX The address of the object
Vanish if the dome is moving.
HandleSpikedDome 43441 CALL SetPixelAdjustments_Sparkle Call SetPixelAdjustments_Sparkle.
43444 LD A,(IX+9) Combine the speeds in every direction.
43447 OR (IX+10)
43450 OR (IX+11)
43453 JP Z,SetDeadlyFlags Jump to SetDeadlyFlags if it is not moving.
43456 LD (IX+0),54 Turn it into a sparkle.
43460 JP SetDeadlyFlagsAndDraw Jump to SetDeadlyFlagsAndDraw.
