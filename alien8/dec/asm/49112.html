49112: Handle Far Arch
The handler for the far side of an arch (object 3). It only needs to set the adjustments to the pixel position of the sprite, which are not the same when the sprite is flipped.
Input
IX The address of the object
Choose the adjustments from the flip flag.
HandleFarArch 49112 BIT 6,(IX+7) Jump to HandleFarArch_Flipped if the sprite is flipped.
49116 JR NZ,HandleFarArch_Flipped
49118 LD HL,64496 Set HL to 64496.
49121 JP SetPixelAdjustments_Store Jump to SetPixelAdjustments_Store.
HandleFarArch_Flipped 49124 LD HL,64760 Set HL to 64760.
49127 JP SetPixelAdjustments_Store Jump to SetPixelAdjustments_Store.
