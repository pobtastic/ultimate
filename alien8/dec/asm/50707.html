50707: Keep Object In Room In Y
Used by the routine at BlockMovement.
Brings the speed along y of an object closer to zero until the object stays within the walls of the room. Nothing is done while the object is entering the room, or while it is near an arch, as it can then go out through the wall.
Input
L Speed along y
IX The address of the object
Output
L The new speed along y
Return while entering or near an arch.
