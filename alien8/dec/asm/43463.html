43463: Handle Remote Control Robot
The update routine for the remote control robot (objects 124 to 127). The pads at HandleRemoteControlArrow and HandleRemoteControlBlock leave a command in RemoteControlCommand: bit 7 says a robot is listening, and bits 0 to 5 hold the command. The first robot to be updated claims bit 7 of RemoteControlCommand and bit 7 of IX+16. When a command arrives it sets bit 6 instead and follows the pad until it is released.
Input
IX The address of the object
