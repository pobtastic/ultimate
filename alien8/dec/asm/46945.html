46945: Game Over
Used by the routines at UpdateLightYears, HandleValve and LoseLife.
Ends the game. UpdateSpecialObjects is called, and then if GameCompletedFlag is set the completed message is shown first (see GameCompleted). The game over screen shows "GAME OVER", a rating that depends on the rooms visited (32 rooms to each of four ratings) and on GameCompletedFlag, and the statistics. When a key has been pressed the screen is cleared and the objects of an ending scene are placed (see PlaceSceneObjects). If the game was not completed this is the scene of the robot being beaten up, otherwise it is the scene of the robot ending its journey. The main loop is then entered at RunGame_Frame to run the scene.
