43257: Handle Land Mine
The update routine for the land mine (object 130). It sits on the floor and is deadly to touch. Every so often one mine in the room leaps and falls. Bit 0 of IX+16 is set while it is leaping, bit 1 while it is falling. IX+17 is the height at the top of the leap. LandMineFlag is set while any mine is leaping.
Input
IX The address of the object
