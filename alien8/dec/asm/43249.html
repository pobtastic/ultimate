43249: Check Protection
Used by the routine at StartGame.
Part of the tape protection. The Z80 keeps bit 7 of R as it was last written, and the tape loader leaves it set. If the game was started any other way then bit 7 is clear and the machine is reset.
Reset the machine if bit 7 of R is clear.
CheckProtection 43249 LD HL,0 Point HL at START.
43252 LD A,R Fetch R.
43254 RLA Move bit 7 into the carry flag.
43255 RET C Return if the bit is set.
43256 JP (HL) Jump to START.
