23328: Object Type Table Address
While a room is built by RetrieveRoom this word holds the address of the table of object types that is in use: ObjectTypes at first, and SecondObjectTypes once an object of type 31 has been met in the data for the room. Its high byte is also used by MovePlayer to hold the vertical speed of the player before it was adjusted by the collision routines.
ObjectTypeTableAddress 23328 DEFB 0 The low byte of the address.
PreviousVerticalSpeed 23329 DEFB 0 The high byte of the address, or the previous vertical speed.
