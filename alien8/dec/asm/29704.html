29704: Second Object Types
The second table of types of object, which is used after an object of type 31 in the data for a room. It has room for 32 entries but only the first eight are used, since the templates start at ObjectTemplates.
SecondObjectTypes 29704 DEFW 0 Type 0: unused.
29706 DEFW ObjectTemplate_RemoteControlArrowWest Type 1: a remote control arrow pointing west (ObjectTemplate_RemoteControlArrowWest).
29708 DEFW ObjectTemplate_RemoteControlArrowNorth Type 2: a remote control arrow pointing north (ObjectTemplate_RemoteControlArrowNorth).
29710 DEFW ObjectTemplate_RemoteControlArrowEast Type 3: a remote control arrow pointing east (ObjectTemplate_RemoteControlArrowEast).
29712 DEFW ObjectTemplate_RemoteControlArrowSouth Type 4: a remote control arrow pointing south (ObjectTemplate_RemoteControlArrowSouth).
29714 DEFW ObjectTemplate_RemoteControlBlock Type 5: the remote control block (ObjectTemplate_RemoteControlBlock).
29716 DEFW ObjectTemplate_SpikedDome Type 6: the spiked dome (ObjectTemplate_SpikedDome).
29718 DEFW ObjectTemplate_LandMine Type 7: the land mine (ObjectTemplate_LandMine).
