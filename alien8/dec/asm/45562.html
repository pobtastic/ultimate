45562: Extend Object Downwards
Used by the routines at HandleCircuitMouse and HandleBouncingMouse.
Lowers the object by 12 and doubles its height, so that it covers both parts of a robot mouse. It also sets bit 1 of the flags of the next object, so that collision tests ignore it. RestoreObjectHeight undoes this.
Input
IX The address of the object
Cover both parts of the mouse.
ExtendObjectDownwards 45562 LD A,(IX+3) Fetch the height of the object.
45565 SUB 12 Subtract 12.
45567 LD (IX+3),A Set the height of the object.
45570 SLA (IX+6) Double the height of the object.
45574 SET 1,(IX+39) Set bit 1 of the next object's flags.
45578 RET Return.
