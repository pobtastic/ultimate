43354: Handle Ending Robot Top
The update routine for the top half of the robot in the game completed scene (object 93). The bottom half (object 92) is the previous object, handled by HandleEndingRobotBottom. This copies its pixel y position, colour and flags, 16 pixels higher.
Input
IX The address of the object
Sit on top of the bottom half and colour the cells.
HandleEndingRobotTop 43354 LD A,(IX-5) Fetch the pixel y position of the previous object.
43357 ADD A,16 Add 16.
43359 LD (IX+27),A Store it as the pixel y position.
43362 LD A,(IX-16) Fetch the colour of the previous object.
43365 LD (IX+16),A Use the same colour.
43368 LD A,(IX-25) Fetch the flags of the previous object.
43371 LD (IX+7),A Use the same flags.
43374 JP ColourCells Jump to ColourCells.
