53202: Calculate Pixel Coordinates
Used by the routines at CalculatePixelPositionOfOtherObject, CalculateSpriteSize and DrawObject.
Works out the pixel position of an object on the screen from its x, y and z positions. The pixel x position is x + y - 128 and the pixel y position (from the bottom of the screen) is half of y - x + 128, plus z, less 40, each with the adjustments of the object added. While GameOverFlag is set the pixel positions are left as the scene has set them.
Input
IX The address of the object
Output
F The carry flag is set if the sprite is on the screen
Return if the scene has set the positions.
