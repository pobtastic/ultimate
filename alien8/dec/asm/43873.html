43873: Handle Attacking Tool
The handler for the boxing glove, hammer and hook (objects 81 to 83). In the game over scene they take it in turns to beat the robot, once the alarm has finished flashing (see HandleAlarm).
A tool swings towards the robot for six frames, makes a noise, and swings back for six frames. Bit 7 of the state holds the direction and bit 0 is set while it is attacking. The game restarts after 16 attacks, or if a number key is pressed.
