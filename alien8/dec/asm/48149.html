48149: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute 48149 AND A Jump to SetFlashingAttribute_Steady if the line is not the first.
48150 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash 48152 SET 7,(HL) Set bit 7 of the attribute.
48154 JR SetFlashingAttribute_Next Jump to SetFlashingAttribute_Next.
SetFlashingAttribute_NextLine 48156 DEC A Jump to SetFlashingAttribute_Flash if this is the line.
48157 JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady 48159 RES 7,(HL) Reset bit 7 of the attribute.
SetFlashingAttribute_Next 48161 INC HL Move on to the next line.
48162 DJNZ SetFlashingAttribute_NextLine Jump to SetFlashingAttribute_NextLine until all of the lines have been done.
48164 RET Return.
