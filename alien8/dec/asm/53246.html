53246: Get Sprite Address
Used by the routines at CalculateSpriteSize and PrintSprite.
Fetches the sprite for the sprite number of an object from SpritePointers. The data of the sprite is flipped, in place, if it is not the same way round as the flags of the object say. If there is no sprite for the sprite number, this returns to the routine that called the routine that called it.
Input
IX The address of the object
Output
DE The address of the sprite
