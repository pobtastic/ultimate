45823: Handle Fat Bottom Block
The handler for a block which is fat at the bottom (object 28). The block is moved with gravity. If it is still moving its x and y speeds are cleared and it makes a sound. Otherwise it is only redrawn if it has been moved. HandleFatTopBlock joins this routine at HandleFatBottomBlock_Move.
Input
IX The address of the object
Move the block and redraw it if it has changed.
