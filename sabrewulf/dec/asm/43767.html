43767: Test Position Partly Unchanged
Tests whether either the X position or the Y position an actor has been moved to is the same as the one it started from. This routine is not used.
Input
DE The new position of the actor (E is X and D is Y)
IX Actor record
Output
F Zero flag set if either the X or Y position is the same
TestPositionPartlyUnchanged 43767 DEFB 123 Fetch the new X position of the actor.
43768 DEFB 221,190,3,200 Return if the X positions are the same.
43772 DEFB 122 Fetch the new Y position of the actor.
43773 DEFB 221,190,4 Compare the new Y position with the Y position of the actor.
43776 DEFB 201 Return.
