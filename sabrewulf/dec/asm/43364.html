43364: Handler: Wulf Landing
Handles the second frame of the Wulf pouncing (sprite IDs 89 and 93). When the timer in IX+2 runs out the Wulf goes back to running with a faster velocity than before.
Input
IX Actor record of the Wulf
HandlerWulfLanding 43364 CALL StoreEntity Remember the previous position of the Wulf.
43367 DEC (IX+2) Decrease the pounce timer by one and jump to HandlerWulfLanding_Move if it is not zero.
43370 JR NZ,HandlerWulfLanding_Move
43372 RES 3,(IX+0) Reset bit 3 of the sprite ID to go back to running.
43376 LD (IX+2),16 Set the pounce timer of the Wulf to 16.
43380 LD A,(IX+6) Fetch the X velocity of the Wulf.
43383 AND A Jump to HandlerWulfLanding_Velocity if the velocity is positive.
43384 JP P,HandlerWulfLanding_Velocity
43387 SUB 64 Subtract 64 if the velocity is negative.
HandlerWulfLanding_Velocity 43389 ADD A,32 Add 32 making the velocity faster in either direction.
43391 LD (IX+6),A Set the new X velocity of the Wulf.
HandlerWulfLanding_Move 43394 JP HandlerWulf_Move Jump to HandlerWulf_Move to move the Wulf.
