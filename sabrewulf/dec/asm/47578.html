47578: XOR Sprite Loop
Used by the routines at RemoveEntity, DrawEntity and DisplayEntity.
Draws the old sprite and the new sprite a row at a time, alternating between the two, until every row of both has been drawn. The set of registers that is current on entry belongs to the old sprite, which is drawn by DrawOldEntityRow. The other set belongs to the new sprite, which is drawn by DrawNewEntityRow.
In each set HL is the screen address of the next row (the sprites are drawn from the bottom row upwards), DE points at the pixel data and B is the page of the shift table. C counts the rows that remain.
When both counts reach zero, the counts that are held in Old_Sprite_Row_Count (old sprite) and New_Sprite_Row_Count (new sprite) are loaded and the whole process repeats. The routine returns when those are zero as well. This allows the rows that have no partner to be drawn first (see DisplayEntity).
Draw a row of the old sprite, if it has any rows left.
XORSpriteLoop 47578 LD A,C Fetch the row count of the old sprite.
47579 AND A Set the flags.
47580 JR Z,XORSpriteLoop_NewOnly Jump to XORSpriteLoop_NewOnly if there are no rows left.
47582 DEC C Decrease the row count.
47583 CALL DrawOldEntityRow Draw a row of the old sprite.
Draw a row of the new sprite, if it has any rows left.
47586 EXX Switch to the registers of the new sprite.
47587 LD A,C Fetch the row count of the new sprite.
47588 AND A Set the flags.
47589 JR Z,XORSpriteLoop_OldRow Jump to XORSpriteLoop_OldRow if there are no rows left.
XORSpriteLoop_NewRow 47591 DEC C Decrease the row count.
47592 CALL DrawNewEntityRow Draw a row of the new sprite.
XORSpriteLoop_OldRow 47595 EXX Switch to the registers of the old sprite.
47596 JR XORSpriteLoop Jump to XORSpriteLoop to draw the next pair of rows.
The old sprite has no rows left, so draw the rest of the new sprite.
XORSpriteLoop_NewOnly 47598 EXX Switch to the registers of the new sprite.
47599 LD A,C Fetch the row count of the new sprite.
47600 AND A Set the flags.
47601 JR NZ,XORSpriteLoop_NewRow Jump to XORSpriteLoop_NewRow if there are rows left.
This entry point is used by the routine at DisplayEntity_NewLower.
XORSpriteLoop_Done 47603 EXX Switch to the registers of the old sprite.
This entry point is used by the routine at DisplayEntity.
Both of the counts are zero. Load the row counts that were stored by the preparation routines and go round again, unless they are zero too.
XORSpriteLoop_Reload 47604 LD A,(38563) Fetch the number of rows of the old sprite from Old_Sprite_Row_Count.
47607 LD C,A Copy the number of rows to C.
47608 LD A,(38564) Fetch the number of rows of the new sprite from New_Sprite_Row_Count.
47611 OR C Combine it with the number of rows of the old sprite.
47612 RET Z Return if there are no rows left to draw.
47613 XOR A A=0.

47617 EXX Switch to the registers of the new sprite.
47618 LD A,(38564) Fetch the number of rows of the new sprite from New_Sprite_Row_Count.
47621 LD C,A Copy the number of rows to C.
47622 XOR A A=0.
This entry point is used by the routine at DisplayEntity_NewLower.
XORSpriteLoop_StoreNew 47623 LD (38564),A Write A to New_Sprite_Row_Count.
