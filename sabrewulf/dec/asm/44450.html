44450: Turn Rhino Around
Used by the routines at HandlerSleepingHippoWarthog and HandlerRhino.
Turns a rhino around, by flipping bit 1 of the sprite ID and reversing the X velocity.
Input
IX Actor record
TurnRhinoAround 44450 LD A,(IX+0) Fetch the sprite ID of the rhino.
44453 XOR %00000010 Flip bit 1 (the direction the rhino is facing).
44455 LD (IX+0),A Set the new sprite ID of the rhino.
This entry point is used by the routine at TurnWulfAround.
TurnRhinoAround_Velocity 44458 LD A,(IX+6) Fetch the X velocity of the actor.
44461 NEG Reverse the X velocity.
44463 LD (IX+6),A Set the new X velocity of the actor.
44466 RET Return.
