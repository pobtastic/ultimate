46142: Update Game Menu
Used by the routine at HandlerGameMenu.
Called when the selections on the game selection menu may have changed. Records the selections in PreviousGameOptions and counts down to the hall of fame (see HandlerHallOfFame) and then makes the two selected options (the number of players and the controls) flash, and the others not.

After HallOfFameCheck

There are two player options to choose from (1UP or 2UP game).
46162 LD B,2 Set the number of player options in B to 2.
46164 AND %00000001 Keep only bit 0 (the player options).
46166 CALL HandlerMenuAttributeFlash Flash the selected player option.
46169 LD A,C Restore the game options to A.
46170 RRCA Rotate out the number of players bit.
46171 AND %00000011 Keep only bits 0-1 (the control options).
There are four control methods to choose from.
46173 LD B,4 Set the number of control methods in B to 4.
46175 CALL HandlerMenuAttributeFlash Flash the selected control method.
46178 RET Return.
