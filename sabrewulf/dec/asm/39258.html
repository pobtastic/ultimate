39258: Security Check
Used by the routine at GameEntry.
The first routine run once the game has been decrypted. It checks the second byte of the FRAMES system variable (23673). If this is not 125 the routine returns, and as the stack pointer was set to 24576 by GameEntry the return address is taken from the first two bytes of that routine instead of from a caller.
SecurityCheck 39258 LD A,(23673) Fetch the second byte of the FRAMES system variable (23673).
39261 CP 125 Return unless that byte is 125.
39263 RET NZ
