48218: Multiply A By DE
This code is not used. Multiplies A by DE.
Input
A Number to multiply by
DE Number to multiply
Output
HL The result
MultiplyAByDE 48218 DEFB 33,0,0 HL=0000.
48221 DEFB 6,8 B=8 (the number of bits).
48223 DEFB 41 Double the result.
48224 DEFB 7 Rotate the next bit of A into the carry flag.
48225 DEFB 48,1 Jump to 48228 if the bit is not set.
48227 DEFB 25 Add DE to the result.
48228 DEFB 16,249 Decrease the bit counter by one and loop back to 48223 until it is zero.
48230 DEFB 201 Return.
