42708: Change Orchid Stage
Used by the routine at HandlerOrchid.
Called when the timer of an orchid has run out. Every other frame the growth stage of the orchid (the lowest three bits of the sprite ID) is moved on by one. Whether it grows or shrinks depends on bit 3 of IX+2. When it has finished growing the timer is set to 16 and when it has finished shrinking a new colour is chosen and the timer is set to a random value between 128 and 191.
Input
IX Actor record of the orchid
