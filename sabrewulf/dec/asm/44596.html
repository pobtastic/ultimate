44596: Stop Attack
Used by the routine at PlayerMovement.
Turns an attacking Sabreman back into a walking one, which faces right if the player was attacking to the right and left otherwise. The sprite IDs used are 20 and 16.
Input
C The controls
DE The movement
IX Actor record of the player
StopAttack 44596 BIT 3,(IX+0) Jump to StopAttackLeft if the player was attacking to the left (bit 3 of the sprite ID is reset).
44600 JR Z,StopAttackLeft
44602 LD A,20 Set the walking sprite ID in A to 20.
This entry point is used by the routine at StopAttackLeft.
StopAttack_Sprite 44604 LD (IX+0),A Set the sprite ID of the player.
44607 LD A,16 Set the width of the player in Actor_Width to 16.
44609 LD (38573),A
44612 JP GamePlay_Controls Jump to GamePlay_Controls to carry on with the controls.
