44666: Count Down Orchid Effect
Used by the routines at HandlerYellowOrchid_StandUp and GamePlay_Start.
Every other frame, counts down the orchid effect timer in OrchidEffectTimer. When the timer reaches zero the player goes back to the normal colour. The zero flag is set when the timer is zero or has just reached zero.
Input
IX Actor record of the player
Output
F Zero flag set if the orchid effect is over
HandlerOrchidTimer 44666 LD A,(23672) Fetch the low byte of FRAMES.
44669 AND %00000001 Keep only bit 0.
44671 RET NZ Return every other frame.
44672 LD A,(38576) Fetch the orchid effect timer from OrchidEffectTimer.
See Always walk fast.
44675 AND A Return if there is no orchid effect.
44676 RET Z
44677 DEC A Decrease the orchid effect timer by one.
44678 LD (38576),A Store the orchid effect timer in OrchidEffectTimer.
44681 RET NZ Return if the orchid effect has not run out.
44682 LD (IX+5),71 Set the colour of the player back to INK:WHITE, PAPER:BLACK (BRIGHT).
44686 RET Return.
