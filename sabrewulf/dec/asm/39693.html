39693: Choose Position
Used by the routine at StartNastie.
Chooses a random position for an actor which is about to appear in the player's room, both the X and Y coordinates are between 48 and 175. The position is rejected if the actor would overlap the player (see TestPlayerTouchingActor) or an object in the room (see SlideActorPastObjects).
Input
IX Actor record
Output
DE The Y and X position (D and E)
F Carry flag set if the position is unsuitable
Use a random X position.
ChoosePosition 39693 LD A,(38549) Fetch the random seed from RandomNumber.
39696 AND %01111111 Keep only bits 0-6.
39698 ADD A,48 Add 48.
39700 LD E,A Copy the X position to E.
See Less Enemies.
39701 LD (IX+3),A Set the X position of the actor.

39712 LD (IX+4),A Set the Y position of the actor.
