44479: Start Attack
Used by the routine at GamePlay_Start.
Turns a walking Sabreman into an attacking one with a sword. The new sprite ID is 32 to 47 and depends on the direction the player was facing.
Input
IX Actor record of the player
StartAttack 44479 LD A,(IX+0) Fetch the sprite ID of the player.
44482 RLCA Rotate left, so that bit 2 (set when facing right or down) is moved into bit 3.
44483 AND %00001111 Keep only bits 0-3.
44485 OR %00100000 Set bit 5.
44487 LD (IX+0),A Set the new sprite ID of the player.
44490 LD A,24 Set the width of an attacking player in Actor_Width to 24.
44492 LD (38573),A
44495 RET Return.
