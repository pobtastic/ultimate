44435: Animate Rhino
Used by the routines at HandlerHippoWarthog, HandlerGuardian and HandlerRhino.
Every other frame, flips bit 0 of the sprite ID of an actor to give it the next frame of animation.
Input
IX Actor record
AnimateRhino 44435 LD A,(38547) Fetch the low byte of the game timer from GameTimer.
44438 AND %00000001 Keep only bit 0.
44440 RET NZ Return if bit 0 is set (the actor only animates on alternate passes).
44441 LD A,(IX+0) Fetch the sprite ID of the actor.
44444 XOR %00000001 Flip bit 0 to give the next frame of animation.
44446 LD (IX+0),A Set the new sprite ID of the actor.
44449 RET Return.
