43676: Show Current Game Over
Used by the routine at HandlePlayerDeath.
Shows the game over message for whichever player is active. This simply returns when it is done, as the game continues after the message.
GameOver_Controller 43676 LD A,(38558) Jump to GameOver_1UP_Messaging to show the message for 1UP if player 1 is active (Flag_ActivePlayer is zero).
43679 AND A
43680 JR Z,GameOver_1UP_Messaging
43682 JR GameOver_2UP Jump to GameOver_2UP to show the message for 2UP.
