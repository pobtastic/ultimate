38583: Previous Game Options
The game selection menu uses this to remember the options that it last saw (see HallOfFameCheck), so that the countdown to the hall of fame is restarted when the options change.
It is also used by PrintRoomsVisited to hold the tens and units digits of the percentage of the jungle that has been explored.
