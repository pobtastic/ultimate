41814: Create Object
Used by the routine at SetUpRoomObjects.
Creates an object actor from an entry in the table of room objects (see GenerateRoomObjects). The actor is set up as follows:
Byte Contents
0 The sprite ID, which is 128 plus the type of the object (bits 0-3 of the table entry)
1 The room the player is in
3 The X position
4 The Y position
5 The colour, see ObjectColours
6 The address of the table entry, which CollectPickup clears when the object is collected
Input
A The table entry
DE Address of the actor record
HL Address of the table entry
IX Actor record of the player
