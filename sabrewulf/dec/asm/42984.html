42984: Find Orchid State
Used by the routines at LoadOrchid and SaveOrchid.
Finds the entry in TableOrchidTypes for the layout of a room.
Input
A Room
Output
HL Address of the state of the orchid
Fetch the layout of the room.
HandlerOrchidType 42984 LD L,A Use the room as the offset into the layout table.
42985 LD H,0
42987 LD BC,24678 Point BC at the layout table at Layout.
42990 ADD HL,BC Add the layout table address to get the address of the layout number for the room.
Fetch the state of the orchid for the layout.
42991 LD L,(HL) Fetch the layout number of the room.
42992 LD H,0 Clear H.
42994 ADD HL,HL Double the layout number, as there are two bytes of state for each layout.
42995 LD BC,43000 Point BC at the table of orchid states at TableOrchidTypes.
42998 ADD HL,BC Add the table address to get the address of the state for the layout.
42999 RET Return.
