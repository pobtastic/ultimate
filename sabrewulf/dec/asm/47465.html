47465: Prepare Draw 2 Byte Sprite
Used by the routines at DrawEntity and DisplayEntity.
Gets the registers ready to draw the sprite of the entity that IX points at, at its current position.
It does what PrepDraw23 does for the old sprite, but it uses the position and the sprite of the entity, changes the operand of the jump at DrawNewEntityRow_0 (used by the code at DrawNewEntityRow) and stores the number of rows in New_Sprite_Row_Count and New_Sprite_Height. The number of character cells that the sprite covers in each row (one more than the width if the sprite is not aligned to a character boundary) is stored in New_Sprite_Width.
Input
IX Actor record
Output
B Page of the shift table
C 0
DE Address of the pixel data
HL Screen address of the bottom row
