49028: Sprite Table
The table of sprites, with an entry for each of the 196 sprite IDs. An entry is the address of the sprite for the ID (see FetchSprite). The sprite ID is the first byte of an actor record.
A sprite is stored as its width in bytes, then its height in pixels, and then the pixel data: one byte for every byte of the width, for each row of the sprite. Sprites have no mask, as they are drawn using XOR. Several sprite IDs can share one sprite when an animation repeats a frame.
