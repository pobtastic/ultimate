47417: Prepare Draw 2/ 3 Byte Sprite
Used by the routines at RemoveEntity and DisplayEntity.
Gets the registers ready to draw the sprite of an entity at its old position, which was saved by StoreEntity.
The shift table page is put in B, the screen address of the bottom row is put in HL and the pointer to the pixel data is put in DE. The operand of the jump at DrawOldEntityRow_0 is changed so that the unrolled code that follows it draws the right number of bytes for each row, and the number of rows is stored in Old_Sprite_Row_Count.
Output
B Page of the shift table
C 0
DE Address of the pixel data
HL Screen address of the bottom row
