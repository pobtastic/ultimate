46232: Game Select Attribute Table
The attribute used for each of the eight lines of text of the game selection menu. The routine at HallOfFameCheck sets bit 7 (the flash bit) for the player option and the control option which are selected.
GameSelection_Attributes 46232 DEFB 198
Byte(n) Menu Item
1 1 1 PLAYER GAME
2 2 2 PLAYER GAME
3 3 KEYBOARD
4 4 KEMPSTON JOYSTICK
5 5 CURSOR JOYSTICK
6 6 INTERFACE II
7 0 START GAME
