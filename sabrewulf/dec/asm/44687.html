44687: Start Yellow Orchid Effect
Used by the routine at GamePlay_Start.
Makes the player sit down because of the yellow orchid, for a time of 96 (the orchid effect timer). The sprite ID is 67 if the player is facing left or 71 if the player is facing right, and the player is then handled by HandlerYellowOrchid_StandUp.
Input
IX Actor record of the player
Fetch the current sprite ID of Sabreman.
HandlerYellowOrchid 44687 LD A,(IX+0) Fetch the sprite ID of the player.
This will leave either 0 or 4.
44690 AND %00000100 Keep only bit 2.
Add on 67.
44692 OR %01000011 Set bits 0-1, 6.
The resulting sprite ID will be either "Sabreman: Sitting Left" or "Sabreman: Sitting Right".
44694 LD (IX+0),A Set the new sprite ID of the player.
44697 LD A,96 Set the orchid effect timer in OrchidEffectTimer to 96.
44699 LD (38576),A
44702 JP HandlerYellowOrchid_StandUp_CountDown Jump to HandlerYellowOrchid_StandUp_CountDown to count down the orchid effect.
