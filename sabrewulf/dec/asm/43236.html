43236: Test Wulf Pounce Right
Used by the routine at TestWulfPounce.
Makes a Wulf which is moving right pounce when the player is to the right of it and is attacking to the left (sprite IDs 32 to 39). See TestWulfPounce.
Input
IX Actor record of the Wulf
TestWulfPounceRight 43236 LD A,(38661) Fetch the X position of the player from 38661.
43239 CP (IX+3) Return if the player is to the left of the Wulf.
43242 RET C
43243 LD A,(38658) Fetch the sprite ID of the player from ImmortalData.
43246 SUB 32 Subtract 32 (the first attacking Sabreman sprite ID).
43248 CP 8 Return if the player is not attacking to the left.
43250 RET NC
43251 JR TestWulfPounce_Start Jump to TestWulfPounce_Start to start the pounce.
