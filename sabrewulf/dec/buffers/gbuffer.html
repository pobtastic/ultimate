Game status buffer
Address Length Description
38546 1
Game Options
The options chosen on the game selection menu (see HandlerGameMenu).
Bit(s) Meaning
0 Set for a 2 player game, reset for a 1 player game
1-2 The controls (see below)
Bits 1-2 Controls
0 Keyboard
1 Kempston Joystick
2 Cursor Joystick
3 Interface II Joystick
38547 2
Game Timer
A 16-bit counter which is incremented by UpdateCounters each time every actor has been processed.
38549 1
Random Number
An 8-bit pseudo-random seed. It is updated each time an actor handler is run (MainLoop_RunHandler) and once per pass of the actor table (UpdateCounters).
38550 1
Last Frame
The value of FRAMES the last time MainLoop_NextActor saw a new frame.
38551 1
Frame Updated
Has the frame been updated? This is set by FrameUpdate and cleared by NextActor once the player's actor has been processed.
Value Updated?
0 Not updated
1 Updated
38552 3
1UP Score
The score of player 1, held as three bytes with two BCD digits in each. The most significant byte is first.
38555 3
2UP Score
The score of player 2, held as three bytes with two BCD digits in each. The most significant byte is first.
38558 1
Active Player
Which player is currently active.
Value Player
0 1UP
255 2UP
38559 1
Previous Sprite Id
The sprite ID of the actor that StoreEntity last saved. GetSpriteA uses it to find the sprite that has to be erased, together with the saved position and room.
38560 1
Previous X Position
The X position of the actor that StoreEntity last saved.
38561 1
Previous Y Position
The Y position of the actor that StoreEntity last saved.
38562 1
Previous Room
The room of the actor that StoreEntity last saved.
38563 1
Old Sprite Row Count
The number of rows of the old sprite that DisplayEntity has still to draw. It is set up by PrepDraw23, and is zero when there is no old sprite to erase (see DrawEntity).
38564 1
New Sprite Row Count
The number of rows of the new sprite that DisplayEntity has still to draw. It is set up by PrepDraw2, and is zero when there is no new sprite to draw (see RemoveEntity).
38565 1
New Sprite Height
The height in pixels of the new sprite. It is set up by PrepDraw2 and used by ColourEntity.
38566 1
New Sprite Width
The number of character cells that each row of the new sprite covers. It is one more than the width of the sprite in bytes when the sprite does not start on a character boundary. It is set up by PrepDraw2 and used by ColourEntity.
38568 1
Current menu item colour attribute
The attribute of the line of the game selection menu that is being printed (see GameMenu and MenuWriteText).
38569 2
Saved Actor Pointer
The address of the actor being processed when a new frame started. See FrameUpdate and NextActor.
38571 1
Moved Actor Room
The room of the actor that MoveActor last moved, saved before it moves so that the room it was in is known if it changes room (see SaveOrchid).
38572 1
Player Controls
The controls being pressed by the player, as read by HandlerControls (after the magenta orchid has reversed them). There is a bit for each of left (bit 0), right (bit 1), up (bit 2), down (bit 3) and fire (bit 4).
38573 1
Actor Width
The width in pixels of the actor that is being moved. Each actor handler sets it before moving the actor with MoveActor and CalculateNewPosition, so that the actor can be kept on the screen.
38574 1
Actor Old X Position
The X position of the actor before it moved, saved by SlideActorPastObjects when it stops the actor moving through the objects in the room.
38575 1
Actor Old Y Position
The Y position of the actor before it moved, saved by SlideActorPastObjects when it stops the actor moving through the objects in the room.
38576 1
Orchid Effect Timer
The time left of the effect of an orchid on the player, or zero if there is no effect. It is set by TestOrchidTouched (to 192) and HandlerYellowOrchid (to 96), and is counted down by HandlerOrchidTimer every other frame. When it reaches zero the player goes back to the normal colour. While it is below 47 the player flashes between the colour of the orchid and white.
38577 1
Nastie Spawn Delay
A delay between nasties appearing. It is counted down by SpawnNastie each time every actor has been processed, and a new nastie can only start when it is zero. It is set to 16 at the start of a turn (see StartTurn) and when the player has died (see HandlePlayerDeath).
38578 1
Attribute Set Flag
If this is not zero then DrawRoom_Process uses the second set of attributes of a graphic, if it has one, and resets this to zero. ShowAmulet sets it to draw the pieces of the amulet that have been collected in full colour.
38579 1
Footstep Counter
Incremented by PlayFootstepSound each time a player moves. It times the sound of the footsteps.
38580 1
Flame Spawn Delay
A delay before a flame can start. It is counted down by SpawnFlame while the flame record at ImmortalData_SpareFlame is empty. It is set to 128 at the start of a turn, when the player has died and when the player moves to another room, and to 16 when a flame has been blown up (see BlowUpFlame).
38581 1
Game Delay Timer
At the beginning of each player turn there is a delay to allow the player to be ready for play.
Value Game Mode
128 1UP
255 2UP
The larger delay for a 2UP game is useful for swapping players controls.
38582 1
Percentage Hundreds
The hundreds digit of the percentage of the jungle that has been explored, which is worked out by PrintRoomsVisited.
38583 1
Previous Game Options
The game selection menu uses this to remember the options that it last saw (see HallOfFameCheck), so that the countdown to the hall of fame is restarted when the options change.
It is also used by PrintRoomsVisited to hold the tens and units digits of the percentage of the jungle that has been explored.
38584 2
Hall Of Fame Timer
Counter for game selection screen, which tells the routine when to flip to display the Hall Of Fame (see HandlerHallOfFame).
38586 1
Hall Of Fame Updated Flag
Set to 1 when a score has been entered into the hall of fame, and cleared by NewHighScore. GameOver_ControllerRestart shows the hall of fame at the end of the game if it is set.
38587 1
High Score Position
Used when calculating the players position in the high score table. It is the number of places that the score beat (see NewHighScore_Enter).
38588 1
Active Player: Unknown
Purpose not yet known. It is cleared by InitialisePlayer and swapped with InactivePlayer_Unknown by ChangePlayer when the players change, but it is never read.
38589 1
Active Player Lives
The number of lives of the active player.
38590 1
Active Player: Nastie Limit
The maximum number of nasties that can be in the room of the player at once, which is set by InitialisePlayer.
38591 32
Visited Rooms
A bitmap of the rooms which the active player has visited, with a bit for each of the 0256 rooms (see VisitRoom).
38623 1
Inactive Player: Unknown
The stored copy of ActivePlayer_Unknown for the player who is not playing.
38624 1
Inactive Player Lives
The stored copy of ActivePlayer_Lives for the player who is not playing. A one player game leaves player 2 with no lives.
38625 1
Inactive Player: Nastie Limit
The stored copy of ActivePlayer_NastieLimit for the player who is not playing.
38626 32
Inactive Player: Visited Rooms
The stored copy of VisitedRooms for the player who is not playing.
38658 144
Immortal Data
The table of actors, which runs from here to StoredActorTable. Every actor is held in a 12 byte record, and MainLoop handles each record in turn, using the sprite ID to choose the handler (see JumpTable).
A record is made up of:
Byte Contents
0 Sprite ID (zero for an empty record)
1 Room
2 Hit direction or counter
3 X position
4 Y position
5 Colour
6 X velocity, in sixteenths of a pixel
7 Y velocity, in sixteenths of a pixel
8-11 Used in different ways by different actors
The first 12 records are the player and the actors which are always present, which are set up from InitialActors. They are followed by the nasties (NastieData), the orchid (OrchidData), the objects (ObjectData) and the pieces of the amulet (AmuletData).
38802 72
Nastie Data
The records of the six nasties. A nastie is started in an empty record by StartNastie.
38874 12
Orchid Data
The record of the orchid in the room the player is in. It is set up by LoadOrchid when the player enters a room and stored again by SaveOrchid when the player leaves.
38886 24
Object Data
The records of the two objects in the room the player is in, which are set up by SetUpRoomObjects.
38910 48
Amulet Data
The records of the four pieces of the amulet, which are set up by PlaceAmuletPieces when a game starts. A record has a sprite ID of zero once the piece has been collected.
38958 300
Stored Actor Table
The stored copy of the actor table at ImmortalData for the player who is not playing. The two are swapped by ChangePlayer when the players change.
45828 42
High Scores
Each high score slot uses 3-bytes for the score with the players initials.
Most other Ultimate games only hold the high score.
61440 4096
Shift Table
The lookup table which is used to shift the pixels of a sprite, so it can be drawn at any pixel position. It is built by BuildShiftTable when a game is started and is used by the sprite drawing code (see PrepDraw23).
There are eight pairs of pages, one pair for each of the eight pixel offsets. In each pair the entry for a byte value holds that byte shifted left by the offset, as a 16-bit number: the low byte is in the page 255 - (2 * offset) and the high byte is in the page below it.
