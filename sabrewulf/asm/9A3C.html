9A3C: Spawn Nastie
Used by the routine at UpdateCounters.
Called once every time all of the actors have been processed. If the start-of-turn delay is over, the nastie spawn delay has run out and the player is alive, this looks for an empty record in the nastie table at NastieData and, if one is found, tries to start a new nastie in it with StartNastie.
Return if the start-of-turn delay is still running.
SpawnNastie 9A3C LD A,($96B5) Return if the start-of-turn delay in GameDelayTimer is not zero.
