B21E: Initialise Player
Used by the routine at InitialiseGame.
Sets up the state of the current player: five lives, a limit of three nasties per room, and a new set of actors, amulet pieces and room objects.
Set starting lives.
InitialisePlayer B21E LD A,$05 Set the number of lives in ActivePlayer_Lives to 05.
B220 LD ($96BD),A
B223 LD A,$03 Set the nastie limit in ActivePlayer_NastieLimit to 03.
B225 LD ($96BE),A
B228 XOR A Clear ActivePlayer_Unknown (purpose not yet known, as this is never read).
B229 LD ($96BC),A
B22C CALL ResetActors Reset the actors.
B22F CALL PlaceAmuletPieces Place the amulet pieces.
B232 JP GenerateRoomObjects Jump to GenerateRoomObjects to generate the objects in the rooms.
