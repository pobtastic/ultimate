A8E4: Test Wulf Pounce Right
Used by the routine at TestWulfPounce.
Makes a Wulf which is moving right pounce when the player is to the right of it and is attacking to the left (sprite IDs 20 to 27). See TestWulfPounce.
Input
IX Actor record of the Wulf
TestWulfPounceRight A8E4 LD A,($9705) Fetch the X position of the player from 9705.
A8E7 CP (IX+$03) Return if the player is to the left of the Wulf.
A8EA RET C
A8EB LD A,($9702) Fetch the sprite ID of the player from ImmortalData.
A8EE SUB $20 Subtract 20 (the first attacking Sabreman sprite ID).
A8F0 CP $08 Return if the player is not attacking to the left.
A8F2 RET NC
A8F3 JR TestWulfPounce_Start Jump to TestWulfPounce_Start to start the pounce.
