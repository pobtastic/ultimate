A43B: Handler: Remove Nastie
Handles a nastie which has finished being blown up (sprite ID 0D). The nastie is erased if it is in the same room as the player and the actor record is then emptied.
Input
IX Nastie record
HandlerRemoveNastie A43B LD A,($9703) Fetch the room of the player from 9703.
A43E CP (IX+$01) Jump to RemoveExplosion if the nastie is in a different room to the player.
A441 JR NZ,RemoveExplosion
A443 CALL DrawEntity Erase the nastie from the screen.
This entry point is used by the routine at HandlerDyingNastie.
RemoveExplosion A446 LD (IX+$00),$00 Empty the record by setting the sprite ID to 00.
A44A RET Return.
