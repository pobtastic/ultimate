A951: Send Wulf Right
Used by the routines at ChooseWulfDirection and CompareWulfPosition.
Sends the Wulf to the right.
Input
IX Actor record of the Wulf
SendWulfRight A951 LD (IX+$06),$40 Set the X velocity of the Wulf to 40 (moving right).
A955 SET 2,(IX+$00) Set bit 2 of the sprite ID so that the Wulf faces right.
A959 RET Return.
