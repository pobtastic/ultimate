AAA4: End Game
Used by the routine at HandlePlayerDeath.
Ends the game: shows the game over message for the active player, lets the player enter their name if they have a high score, shows the Hall of Fame if a new score has been entered and then returns to the game selection screen at Game_Restart.
GameOver_ControllerRestart AAA4 LD A,($969E) Jump to GameOver_Restart2UP if player 2 is active (Flag_ActivePlayer is not zero).
AAA7 AND A
AAA8 JR NZ,GameOver_Restart2UP
GameOver_Scores AAAA CALL GameOver_1UP_Messaging Show the game over message for 1UP.
GameOver_NewHighScore AAAD CALL NewHighScore Check for a new high score.
AAB0 LD A,($96BA) Jump to GameOver_Restart if the hall of fame has not been updated (HallOfFameUpdated is zero).
AAB3 AND A
AAB4 JR Z,GameOver_Restart
AAB6 CALL HandlerHallOfFame_Show Show the hall of fame.
GameOver_Restart AAB9 JP Game_Restart Jump to Game_Restart to restart the game.
GameOver_Restart2UP AABC CALL GameOver_2UP Show the game over message for 2UP.
AABF JR GameOver_NewHighScore Jump to GameOver_NewHighScore.
