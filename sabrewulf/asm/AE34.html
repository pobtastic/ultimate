AE34: Stop Attack
Used by the routine at PlayerMovement.
Turns an attacking Sabreman back into a walking one, which faces right if the player was attacking to the right and left otherwise. The sprite IDs used are 14 and 10.
Input
C The controls
DE The movement
IX Actor record of the player
StopAttack AE34 BIT 3,(IX+$00) Jump to StopAttackLeft if the player was attacking to the left (bit 3 of the sprite ID is reset).
AE38 JR Z,StopAttackLeft
AE3A LD A,$14 Set the walking sprite ID in A to 14.
This entry point is used by the routine at StopAttackLeft.
StopAttack_Sprite AE3C LD (IX+$00),A Set the sprite ID of the player.
AE3F LD A,$10 Set the width of the player in Actor_Width to 10.
AE41 LD ($96AD),A
AE44 JP GamePlay_Controls Jump to GamePlay_Controls to carry on with the controls.
