BC67: Music Data
Each byte of music data is a note and the data is terminated by FF. Bits 0-5 select the note from the table at MusicNotes (zero is a rest) and bits 6-7 hold the length of the note minus one (so a note lasts for between one and four units). See PlayNote.
This is the main tune, played when the game is completed and on the game selection screen.
