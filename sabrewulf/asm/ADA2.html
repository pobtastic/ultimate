ADA2: Turn Rhino Around
Used by the routines at HandlerSleepingHippoWarthog and HandlerRhino.
Turns a rhino around, by flipping bit 1 of the sprite ID and reversing the X velocity.
Input
IX Actor record
TurnRhinoAround ADA2 LD A,(IX+$00) Fetch the sprite ID of the rhino.
ADA5 XOR %00000010 Flip bit 1 (the direction the rhino is facing).
ADA7 LD (IX+$00),A Set the new sprite ID of the rhino.
This entry point is used by the routine at TurnWulfAround.
TurnRhinoAround_Velocity ADAA LD A,(IX+$06) Fetch the X velocity of the actor.
ADAD NEG Reverse the X velocity.
ADAF LD (IX+$06),A Set the new X velocity of the actor.
ADB2 RET Return.
