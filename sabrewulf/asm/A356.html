A356: Create Object
Used by the routine at SetUpRoomObjects.
Creates an object actor from an entry in the table of room objects (see GenerateRoomObjects). The actor is set up as follows:
Byte Contents
00 The sprite ID, which is 80 plus the type of the object (bits 0-3 of the table entry)
01 The room the player is in
03 The X position
04 The Y position
05 The colour, see ObjectColours
06 The address of the table entry, which CollectPickup clears when the object is collected
Input
A The table entry
DE Address of the actor record
HL Address of the table entry
IX Actor record of the player
CreateObject A356 PUSH HL Stash the address of the table entry on the stack.
A357 LD C,A Stash the table entry in C.
A358 AND %00001111 Keep only the object type (bits 0-3).
A35A ADD A,$80 Add 80 to get the sprite ID.
A35C LD (DE),A Set the sprite ID of the object.
A35D INC DE Move onto the room of the object.
A35E LD A,(IX+$01) Fetch the room of the player.
A361 LD (DE),A Set the room of the object.
