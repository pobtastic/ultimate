AD69: Knock Back Rhino
Used by the routine at HandlerRhino.
Turns a rhino which has been hit by the sword of the player and sends it away from the player with a velocity of 60 (to the right) or A0 (to the left), depending on which way the player is facing. A warble is played.
Input
IX Actor record of the rhino
KnockBackRhino AD69 LD A,($9702) Fetch the sprite ID of the player from ImmortalData.
AD6C BIT 3,A Jump to KnockBackRhino_Right if the player is attacking to the right (bit 3 of the sprite ID is set).
AD6E JR NZ,KnockBackRhino_Right
AD70 RES 1,(IX+$00) Reset bit 1 of the sprite ID so the rhino faces left.
AD74 LD A,$A0 Set the X velocity in A to A0 (moving left).
KnockBackRhino_Velocity AD76 LD (IX+$06),A Set the X velocity of the rhino.
AD79 CALL PlayWarbleSound Play the warble sound.
AD7C JR UpdateActor Jump to UpdateActor to update the rhino.
KnockBackRhino_Right AD7E SET 1,(IX+$00) Set bit 1 of the sprite ID so the rhino faces right.
AD82 LD A,$60 Set the X velocity in A to 60 (moving right).
AD84 JR KnockBackRhino_Velocity Jump to KnockBackRhino_Velocity.
