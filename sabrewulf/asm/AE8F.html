AE8F: Start Yellow Orchid Effect
Used by the routine at GamePlay_Start.
Makes the player sit down because of the yellow orchid, for a time of 60 (the orchid effect timer). The sprite ID is 43 if the player is facing left or 47 if the player is facing right, and the player is then handled by HandlerYellowOrchid_StandUp.
Input
IX Actor record of the player
Fetch the current sprite ID of Sabreman.
HandlerYellowOrchid AE8F LD A,(IX+$00) Fetch the sprite ID of the player.
This will leave either 00 or 04.
AE92 AND %00000100 Keep only bit 2.
Add on 43.
AE94 OR %01000011 Set bits 0-1, 6.
The resulting sprite ID will be either "Sabreman: Sitting Left" or "Sabreman: Sitting Right".
AE96 LD (IX+$00),A Set the new sprite ID of the player.
AE99 LD A,$60 Set the orchid effect timer in OrchidEffectTimer to 60.
AE9B LD ($96B0),A
AE9E JP HandlerYellowOrchid_StandUp_CountDown Jump to HandlerYellowOrchid_StandUp_CountDown to count down the orchid effect.
