AD93: Animate Rhino
Used by the routines at HandlerHippoWarthog, HandlerGuardian and HandlerRhino.
Every other frame, flips bit 0 of the sprite ID of an actor to give it the next frame of animation.
Input
IX Actor record
AnimateRhino AD93 LD A,($9693) Fetch the low byte of the game timer from GameTimer.
AD96 AND %00000001 Keep only bit 0.
AD98 RET NZ Return if bit 0 is set (the actor only animates on alternate passes).
AD99 LD A,(IX+$00) Fetch the sprite ID of the actor.
AD9C XOR %00000001 Flip bit 0 to give the next frame of animation.
AD9E LD (IX+$00),A Set the new sprite ID of the actor.
ADA1 RET Return.
