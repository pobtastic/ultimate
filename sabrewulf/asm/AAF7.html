AAF7: Test Position Partly Unchanged
Tests whether either the X position or the Y position an actor has been moved to is the same as the one it started from. This routine is not used.
Input
DE The new position of the actor (E is X and D is Y)
IX Actor record
Output
F Zero flag set if either the X or Y position is the same
TestPositionPartlyUnchanged AAF7 DEFB $7B Fetch the new X position of the actor.
AAF8 DEFB $DD,$BE,$03,$C8 Return if the X positions are the same.
AAFC DEFB $7A Fetch the new Y position of the actor.
AAFD DEFB $DD,$BE,$04 Compare the new Y position with the Y position of the actor.
AB00 DEFB $C9 Return.
