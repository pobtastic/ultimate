BDD2: Music Note Table
The pitch delays and cycle counts for each of the notes (see PlayNote). Each entry is four bytes: the delay as two bytes, followed by the 16-bit number of cycles to play, which gets larger as the pitch rises so that every note lasts the same length of time. Entry 00 is unused as it is a rest.
