9E48: Aim Flame Left
Used by the routine at AimFlameAtPlayer.
Sets the X velocity of a flame so that it moves left.
Input
IX Flame record
AimFlameLeft 9E48 LD (IX+$06),$C0 Set the X velocity of the flame to C0 (moving left).
9E4C JR AimFlameAtPlayer_Vertical Jump to AimFlameAtPlayer_Vertical to aim vertically.
