AAED: Test Position Unchanged
Used by the routines at HandlerFlame, HandlerHippoWarthog, HandlerWanderingNastie, HandlerWulf, HandlerFlyingSabreman, ChooseTribesmanVelocity, HandlerRhino, PlayerMovement and GamePlay_Start.
Tests whether the position an actor has been moved to is the same as the position it started from.
Input
DE The new position of the actor (E is X and D is Y)
IX Actor record
Output
F Zero flag set if the position is the same as the position in the
record
TestPositionUnchanged AAED LD A,E Fetch the new X position of the actor.
AAEE XOR (IX+$03) Compare the new X position with the X position of the actor.
AAF1 RET NZ Return if the X positions are different.
AAF2 LD A,D Fetch the new Y position of the actor.
AAF3 XOR (IX+$04) Compare the new Y position with the Y position of the actor.
AAF6 RET Return.
