B498: Game Select Attribute Table
The attribute used for each of the eight lines of text of the game selection menu. The routine at HallOfFameCheck sets bit 7 (the flash bit) for the player option and the control option which are selected.
GameSelection_Attributes B498 DEFB $C6
Byte(n) Menu Item
01 1 1 PLAYER GAME
02 2 2 PLAYER GAME
03 3 KEYBOARD
04 4 KEMPSTON JOYSTICK
05 5 CURSOR JOYSTICK
06 6 INTERFACE II
07 0 START GAME
