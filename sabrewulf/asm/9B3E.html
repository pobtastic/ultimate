9B3E: Jump Table
The handler address for each sprite ID (00-C3), which is C4 entries of two bytes each. The table is indexed by the sprite ID of an actor (see MainLoop). Every handler is called with IX pointing at the actor record. Sprite IDs which have no behaviour of their own point at HandlerEmpty.
Each run of sprite IDs below has the same handler; the sprite names are given by SpritesTable.
