AE7A: Count Down Orchid Effect
Used by the routines at HandlerYellowOrchid_StandUp and GamePlay_Start.
Every other frame, counts down the orchid effect timer in OrchidEffectTimer. When the timer reaches zero the player goes back to the normal colour. The zero flag is set when the timer is zero or has just reached zero.
Input
IX Actor record of the player
Output
F Zero flag set if the orchid effect is over
HandlerOrchidTimer AE7A LD A,($5C78) Fetch the low byte of FRAMES.
AE7D AND %00000001 Keep only bit 0.
AE7F RET NZ Return every other frame.
AE80 LD A,($96B0) Fetch the orchid effect timer from OrchidEffectTimer.
See Always walk fast.
AE83 AND A Return if there is no orchid effect.
AE84 RET Z
AE85 DEC A Decrease the orchid effect timer by one.
AE86 LD ($96B0),A Store the orchid effect timer in OrchidEffectTimer.
AE89 RET NZ Return if the orchid effect has not run out.
AE8A LD (IX+$05),$47 Set the colour of the player back to INK:WHITE, PAPER:BLACK (BRIGHT).
AE8E RET Return.
