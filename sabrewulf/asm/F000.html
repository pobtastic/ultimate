F000: Shift Table
The lookup table which is used to shift the pixels of a sprite, so it can be drawn at any pixel position. It is built by BuildShiftTable when a game is started and is used by the sprite drawing code (see PrepDraw23).
There are eight pairs of pages, one pair for each of the eight pixel offsets. In each pair the entry for a byte value holds that byte shifted left by the offset, as a 16-bit number: the low byte is in the page FF - (02 * offset) and the high byte is in the page below it.
