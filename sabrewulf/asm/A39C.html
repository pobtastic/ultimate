A39C: Find Room Objects
Used by the routine at SetUpRoomObjects.
Finds the entries in the table of room objects which belong to the room an actor is in.
Input
IX Actor record
Output
HL Address of the first of the two table entries for the room
FindRoomObjects A39C LD L,(IX+$01) Fetch the room of the actor.
A39F LD H,$00 Clear H.
A3A1 ADD HL,HL Double the room, as there are two entries for each room.
A3A2 LD BC,$DDEC Point BC at the table of room objects at RoomObjectTable.
A3A5 ADD HL,BC Add the table address to get the address of the entries for the room.
A3A6 RET Return.
