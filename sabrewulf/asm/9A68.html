9A68: Start Nastie
Used by the routine at SpawnNastie.
Turns an empty nastie record into a nastie which is just appearing, unless the player's room already holds the maximum number of nasties (ActivePlayer_NastieLimit) or the position chosen by ChoosePosition is unsuitable. The nastie starts as the first of the five "appearing" sprites (sprite ID 01), in one of four colours chosen from the table at NastieColours using the low bits of the counter at GameTimer.
Input
IX Empty nastie record
Count the nasties which are already in the player's room.
