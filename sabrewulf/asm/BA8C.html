BA8C: Draw New Entity Row
Used by the routine at XORSpriteLoop.
Draws one row of the new sprite, using XOR, and moves up to the next row. It is a copy of DrawOldEntityRow that uses the jump at DrawNewEntityRow_0, which is changed by PrepDraw2.
Input
B Page of the shift table
C Number of rows left
DE Pointer to the pixel data
HL Screen address of the row
Output
C Number of rows left
DE Pointer to the next row of pixel data
HL Screen address of the next row
DrawNewEntityRow BA8C LD A,C Copy the row count to A.
BA8D EX AF,AF' Store the row count in AF'.
BA8E LD A,(DE) Fetch the first byte of the row.
BA8F LD C,A Copy it to C to use as the index into the shift table.
BA90 PUSH HL Stash the screen address on the stack.
DrawNewEntityRow_0 BA91 JR DrawNewEntityRow_0 Jump into the unrolled code. The operand of this instruction is changed by PrepDraw2.
DrawNewEntityRow_Byte_1 BA93 LD A,(DE) Byte 1 of the row: look up the shifted byte for the left cell and XOR it onto the screen.
