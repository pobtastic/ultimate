DC6C: Object Position Table
The positions at which objects can be placed, with an entry of eight bytes for each of the 30 room layouts (the layout of a room is found with the table at Layout). An entry is four X/Y pairs, so there are four possible positions in each layout. SetUpRoomObjects uses bits 6-7 of an entry in RoomObjectTable to choose between the four, and PlaceAmuletPieces puts a piece of the amulet at the first position of a layout.
The entry for layout 01 is all zeros.
ObjectLocation DC6C DEFB $50,$3F,$40,$7F,$88,$7F,$D0,$7F Four X/ Y positions.
