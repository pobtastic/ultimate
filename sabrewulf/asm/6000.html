6000: Game Entry Point
Where the game starts once it has been decrypted. The stack is set up just below this routine and control passes to the security check at SecurityCheck.
GameEntry 6000 DI Disable interrupts.
6001 LD SP,$6000 Set the stack pointer to 6000.
6004 JP SecurityCheck Jump to SecurityCheck.
