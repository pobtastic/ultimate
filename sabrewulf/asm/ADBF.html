ADBF: Start Attack
Used by the routine at GamePlay_Start.
Turns a walking Sabreman into an attacking one with a sword. The new sprite ID is 20 to 2F and depends on the direction the player was facing.
Input
IX Actor record of the player
StartAttack ADBF LD A,(IX+$00) Fetch the sprite ID of the player.
ADC2 RLCA Rotate left, so that bit 2 (set when facing right or down) is moved into bit 3.
ADC3 AND %00001111 Keep only bits 0-3.
ADC5 OR %00100000 Set bit 5.
ADC7 LD (IX+$00),A Set the new sprite ID of the player.
ADCA LD A,$18 Set the width of an attacking player in Actor_Width to 18.
ADCC LD ($96AD),A
ADCF RET Return.
