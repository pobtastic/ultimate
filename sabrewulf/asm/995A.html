995A: Security Check
Used by the routine at GameEntry.
The first routine run once the game has been decrypted. It checks the second byte of the FRAMES system variable (5C79). If this is not 7D the routine returns, and as the stack pointer was set to 6000 by GameEntry the return address is taken from the first two bytes of that routine instead of from a caller.
SecurityCheck 995A LD A,($5C79) Fetch the second byte of the FRAMES system variable (5C79).
995D CP $7D Return unless that byte is 7D.
995F RET NZ
Continue on to GameInitialisation.
