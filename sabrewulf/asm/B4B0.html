B4B0: Messaging: Game Selection Title
The eight lines of text of the game selection menu. The last character of each string has bit 7 set.
String_1UP_Game B4B0 DEFM "1 1 PLAYER GAM","E"+$80 "1 1 PLAYER GAME".
String_2UP_Game B4C0 DEFM "2 2 PLAYER GAM","E"+$80 "2 2 PLAYER GAME".
String_Keyboard B4D0 DEFM "3 KEYBOAR","D"+$80 "3 KEYBOARD".
String_Kempston B4DB DEFM "4 KEMPSTON JOYSTIC","K"+$80 "4 KEMPSTON JOYSTICK".
String_Cursor B4EF DEFM "5 CURSOR JOYSTIC","K"+$80 "5 CURSOR JOYSTICK".
String_InterfaceII B503 DEFM "6 INTERFACE I","I"+$80 "6 INTERFACE II".
String_StartGame B512 DEFM "0 START GAM","E"+$80 "0 START GAME".
String_Copyright B51F DEFM $7F," 1984 A.C.G","."+$80 "© 1984 A.C.G.".
