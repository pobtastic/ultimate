B3D5: Handler: Game Menu
Used by the routine at GameInitialisation.
Shows the game selection menu and waits for the player to start the game. The keys are:
Key Action
1 One player game
2 Two player game
3 Keyboard controls
4 Kempston joystick
5 Cursor joystick
6 Interface II joystick
0 Start the game
The choices are stored in GameOptions.
The tune at MusicData_GameComplete is played while the menu is waiting, and a key press stops it. While nothing is changed the hall of fame is shown after a time (see HandlerHallOfFame).

Handle 1UP game selection.
GameSelect_Check1UP B400 BIT 0,E Jump to GameSelect_Check2UP if key "1" ("1 PLAYER GAME") has not been pressed.
B402 JR Z,GameSelect_Check2UP
B404 RES 0,A Select a one player game by resetting bit 0.
Handle 2UP game selection.
GameSelect_Check2UP B406 BIT 1,E Jump to GameSelect_CheckKeyboard if key "2" ("2 PLAYER GAME") has not been pressed.
B408 JR Z,GameSelect_CheckKeyboard
B40A SET 0,A Select a two player game by setting bit 0.
Handle Keyboard selection.
GameSelect_CheckKeyboard B40C BIT 2,E Jump to GameSelect_CheckKempston if key "3" ("KEYBOARD") has not been pressed.
B40E JR Z,GameSelect_CheckKempston
B410 AND %11111001 Select the keyboard by clearing the control method.
Handle Kempston Joystick selection.
GameSelect_CheckKempston B412 BIT 3,E Jump to GameSelect_CheckCursor if key "4" ("KEMPSTON JOYSTICK") has not been pressed.
B414 JR Z,GameSelect_CheckCursor

B418 OR %00000010 Select the Kempston joystick by setting control method 02.
Handle Cursor Joystick selection.

B41C JR Z,GameSelect_ReadSecondKeyRow
B41E AND %11111001 Clear the control method.
B420 OR %00000100 Select the Cursor joystick by setting control method 04.
