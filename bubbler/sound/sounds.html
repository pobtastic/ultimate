Title Tune
Played by PlayMusic_WaitKey while the title menu is shown, until a key is pressed. The music data is at TitleTune.
Start Tune
Played by PlayMusic when the game is started from the title menu (see LeaveTitleMenu). The music data is at StartTune.
Game Over Tune
Played by PlayMusic when a player has no lives left (see ShowPlayerNumber). The music data is at GameOverTune.
Fanfare
Played by PlayFanfare, which is called by RunGame. The music data is at FanfareTune.
Rising Sweep
Played by PlayRisingSweep when the player collects an item that gives an extra life (see CollectItem).
Buzz
Played by PlayDefaultBuzz. The routine is not called by the game, but the other buzzes use the same code (see 9ED5).
Short Buzz
Played by PlayShortBuzz when a type 05 entity is created (see CreatePuff).
Tiny Buzz
Played by PlayTinyBuzz on every frame that a type 0D entity exists (see UpdateSparkleEntity).
Buzz Sweep
Played by PlayBuzzSweep when a bottle is collected (see CollectBottle).
Random Noise
Played by PlayRandomNoise when a type 07 entity is made (see StartBurst).
Long Buzz
Played by PlayLongBuzz while an entity is following its path (see FollowPath).
Falling Sweep
Played by PlayFallingSweep while an entity is following its path (see FollowPath).
Short Rising Sweep
Played by PlayShortRisingSweep (see RunFrame).
Medium Buzz
Played by PlayMediumBuzz when an extra record is updated (see UpdateExtraRecord).
Slow Fall
Played by PlaySlowFall when entities of the types 08 and 0F change (see UpdateGrowingBubbleEntity and UpdatePickupEntity).
Brief Buzz
Played by PlayBriefBuzz when a type 0E entity is created (see CreateShot).
Shot Sound
Played by PlayShotSound when an entity of the type 09 fires (see UpdateSaucerEntity).
Entity Sound
Played by MakeEntitySound when a type 08 entity is updated while its frame number is below 05 (see UpdateGrowingBubbleEntity). The recording is three plays of the sound, one frame apart, with field 20 of the entity set to 00 0F and 1F.
