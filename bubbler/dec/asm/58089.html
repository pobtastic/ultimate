58089: Draw Frame
Used by the routines at ShowTitleMenu and DrawPanel.
Draws a frame, from an entry of 5 bytes in the table at FrameTable, and moves on to the next entry. The edges of the frame are made with DrawFrameLeft, DrawFrameLeft_Draw and DrawFrameBar, and the corners with DrawFrameCorners.
Input
IX The entry of the frame
Output
IX The next entry

58092 LD (43748),A Store it in the colour rectangle at 43748.
58095 LD L,(IX+0) Fetch the x position of the frame into L.
58098 LD H,(IX+1) Fetch the y position of the frame into H.
58101 PUSH HL Save the position.
58102 PUSH HL Save it again.
58103 INC H Move down a pixel line, to the row below the frame.
58104 LD C,(IX+2) Fetch the width of the frame.
58107 LD B,1 Set the height of the rectangle to one row.
58109 LD (43746),BC Store the width and the height in the rectangle.
58113 CALL FillScratchRectangle Colour the row below the frame.

58120 LD A,H Copy the y position into A.

58122 LD H,A Copy it into H, to find the row above the frame.
58123 CALL FillScratchRectangle Colour the row above the frame.
58126 POP HL Restore the position.
58127 DEC L Move one pixel to the left, beside the frame.
58128 INC H Move down a pixel line.
58129 PUSH HL Save the position.
58130 LD C,1 Set the width of the rectangle to one cell.

58148 CALL FillScratchRectangle Colour the column on the left of the frame.

58152 LD A,(IX+2) Fetch the width of the frame.
