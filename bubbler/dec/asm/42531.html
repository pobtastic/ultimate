42531: Find Hidden Entity
Used by the routine at CreatePuff.
Looks for an entity whose frame has bit 7 set (a hidden entity).
Input
B The number of entities to look at
IY The first entity
Output
IY The hidden entity, if one was found
F Zero flag reset if a hidden entity was found
FindHiddenEntity 42531 LD DE,38 Set the size of an entity.
FindHiddenEntity_Loop 42534 BIT 7,(IY+1) Test bit 7 of the frame of the entity.
42538 RET NZ Return if it is hidden.
42539 ADD IY,DE Move onto the next entity.
42541 DJNZ FindHiddenEntity_Loop Jump back until all of the entities have been tested.
42543 RET Return.
