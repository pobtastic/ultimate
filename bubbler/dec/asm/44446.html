44446: Restore Item Rows
Used by the routines at RunFrame and RunGame.
Replays the table of item records built by BuildDrawList and PrepareEntityItem. For each record, the rows of the screen buffer saved in the record are copied back to the address in the record header, working upwards one row at a time.
RestoreItemRows 44446 LD A,(62720) Read how many item records there are.
44449 AND A Return when there are none.
44450 RET Z
The alternate accumulator counts the records. The first byte of a header is the step back to the previous row.
44451 LD HL,62721 Start at the first record.
RestoreItemRows_Loop 44454 EX AF,AF' Remember how many records remain.
44455 LD A,(HL) Patch the step back to the previous row.
44456 LD (44510),A
44459 INC HL Move on to the screen address.
44460 LD E,(HL) Read the screen address from the header.
44461 INC HL
44462 LD D,(HL)
44463 INC HL
44464 LD A,(HL) Patch the row loop with the width.
44465 LD (44517),A
44468 INC HL Move on to the row count.
44469 LD B,(HL) Read how many rows.
44470 INC HL
44471 LD C,255 Keep the byte count from carrying into the row count.
44473 JP RestoreItemRows_Rows Join the row loop.
RestoreItemRows_Next 44476 EX AF,AF' Repeat for the remaining records.
44477 DEC A
44478 JP NZ,RestoreItemRows_Loop
44481 RET Return.
