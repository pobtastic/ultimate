40333: Update Spider Entity
Updates an entity of the type 16. If the player touches it then it is drawn as normal, otherwise it is freed (see FreeLinkedEntity).
Input
IX The entity
UpdateSpiderEntity 40333 LD BC,32 Set the value to test to 32.
40336 CALL TestEntityVisible Call TestEntityVisible.
40339 JR Z,UpdateSpiderEntity_Free Jump to UpdateSpiderEntity_Free if the zero flag is set.
40341 CALL ProjectEntity Call ProjectEntity.
40344 JP UpdateEntity_Done Jump to UpdateEntity_Done.
UpdateSpiderEntity_Free 40347 JR FreeLinkedEntity Jump to FreeLinkedEntity to free the entity.
