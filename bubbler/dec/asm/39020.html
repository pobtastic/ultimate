39020: Set Entity Defaults
Used by the routines at CreatePickup_FourthSide and CreateSpawnedEntity_GrowingBubble.
Sets the acceleration, the speed and the animation which an entity made by CreatePickup or CreateSpawnedEntity has in common, and then measures its sprite.
Input
IX The entity
SetEntityDefaults 39020 LD (IX+20),255 Set the high byte of the acceleration to 255.
39024 LD (IX+21),176 Set the low byte of the acceleration to 176.
39028 LD (IX+27),16 Set the rate of change of the speed to 16.
39032 LD (IX+28),81 Set the animation counter to 81.
39036 LD (IX+29),118 Set the frame range to 118 so the frames run from 6 to 7.
39040 LD (IX+16),16 Set the speed to 16.
39044 LD (IX+1),32 Set the frame byte to 32.
39048 JP SetEntitySize Measure the sprite.
