57797: Copy Rectangle Rows
Used by the routine at DrawPanel.
Copies rows of bytes into the table at 62722. The first byte is the width of each row, remembered at 62720 and the second is the number of rows, remembered at 62721. Each copied byte is two source bytes on from the last.
Input
DE The address of the data
CopyRectangleRows 57797 LD A,(DE) The width of each row, remembered at 62720.
57798 LD C,A
57799 LD (62720),A
57802 INC DE
57803 LD A,(DE) The number of rows, remembered at 62721.
57804 LD (62721),A
57807 LD HL,62722 The copy starts at 62722.

57811 LD B,C The width is the count for this row.

57815 LD (HL),A

57817 DJNZ CopyRectangleRows_Byte The rest of the row.
57819 EX AF,AF' The next row.
57820 DEC A One fewer row remains.
57821 JR NZ,CopyRectangleRows_Row Another row.
57823 RET Return.
