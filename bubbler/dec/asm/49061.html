49061: Draw Object
Used by the routine at DrawGroupObjects.
Prepares an object of a group for drawing, and then passes it to the routine whose address is the operand of the JP at 49374 which is set by DrawLevelObjects. It works out the screen column and row of the object, and returns without doing anything if the object is not in view. Objects that can be entities are passed to AddObjectEntity first, and an object that has the flag for it in the row of flags of the group is also given an item record with AddItemRecord.
Input
IX The object, which is three bytes
