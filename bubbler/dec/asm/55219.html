55219: Object Flags Table
A table of flags for each kind of object, which is used by TestGroupObjects and DrawBlock. DrawBlock indexes it with the shape kind. Bit 7 clear draws the block as it is. Bits 5-6 clear mirror it, 32 draws it as it is, 64 raises it, and any other value moves the origin back by 16. The index used by TestGroupObjects is made from the object's type byte. Purpose of the other bits is not yet known.
