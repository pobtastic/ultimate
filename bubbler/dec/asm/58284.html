58284: Draw Frame Left
Used by the routine at DrawFrame.
Draws a vertical line of the frame, by setting the bytes of the screen to 60. The entry point at DrawFrameLeft_Draw draws it from an address that is already in HL.
Input
HL The position of the line
IX The entry of the frame
DrawFrameLeft 58284 CALL GetScreenAddress Convert the position into a screen address.
DrawFrameLeft_Move 58287 DEC L Move one byte to the left, beside the frame.
This entry point is used by the routine at DrawFrame.
DrawFrameLeft_Draw 58288 LD B,(IX+3) Fetch the height of the frame in pixel lines.
58291 PUSH HL Save the screen address.
DrawFrameLeft_Loop 58292 LD (HL),60 Draw a pixel line of the edge.
58294 CALL MoveUpALine Move up a pixel line.
58297 DJNZ DrawFrameLeft_Loop Repeat until the whole edge is drawn.
58299 POP HL Restore the screen address.
58300 RET Return.
