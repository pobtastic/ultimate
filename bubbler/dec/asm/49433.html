49433: Draw Bottom Strip
Handles an object for DrawObject when the view is scrolling up, so that only the objects in the strip that has just come into view at the bottom are drawn.
DrawBottomStrip 49433 LD HL,(48033) Fetch the vertical position of the object in the view.
49436 LD A,(23795) Fetch the size of the object.
49439 SRL A Halve it.
49441 LD E,A Copy it into E.
49442 LD D,0 Clear D.
49444 ADD HL,DE Add half of the size to the position.
49445 LD DE,32888 Set the position of the start of the strip at the bottom.
49448 AND A Subtract the start of the strip.
49449 SBC HL,DE
49451 RET C Return if the object is not as far down as the strip.
49452 LD HL,(48033) Fetch the vertical position of the object in the view.
49455 LD DE,65416 Set the distance to move the object up, 65416.
49458 ADD HL,DE Add it.
49459 LD (48033),HL Store the new position.
49462 LD DE,16 Set the distance to move the object down, 16.
49465 JR DrawLeftStrip_AddOffset Draw the object, after moving it.
