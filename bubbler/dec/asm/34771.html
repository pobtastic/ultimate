34771: Level Data
The data of the five levels, which are found with LevelTable. The data of the levels are not in the order of the levels. For each level there is a list of addresses (two bytes each), the number of cells of the map, the header and the map, and then the path entries that the addresses in the list refer to. The path entries of level 3 are stored after those of level 4. The header of a level is 7 bytes: the position that the player starts at (see StartLevel), a byte, and the width and height of the map, which are used by FindGroup. The map has two bytes for each cell. The second is the number of the group of objects in the table at GroupTable, and the first is also used by FindGroup, where 254 and 255 mean that the cell has no group.
Purpose of the data from 34771 to 34798 is not yet known. The last 16 bytes look like a path entry.
