40099: Set Up Shot Sprite
Used by the routines at CreateShot and UpdateSaucerEntity.
Sets the speed and sprite fields of an entity of the type 14 which is made by UpdateSaucerEntity, and then sets its sprite.
Input
IX The entity
SetUpShotSprite 40099 LD (IX+16),68 Set the speed to 68.
40103 LD (IX+20),255 Set field 20 of the entity to 255.
40107 LD (IX+21),200 Set field 21 of the entity to 200.
40111 LD (IX+28),4 Set field 28 of the entity to 4.
40115 LD (IX+29),48 Set field 29 of the entity to 48.
40119 JP SetEntitySize Jump to SetEntitySize to set the sprite of the entity.
