39263: Set Up Creature
Used by the routine at CreateRandomCreature.
Sets up an entity as one of four kinds of creature, using the templates at CreatureTemplates. The first level has only two kinds of creature and the second level has no kind 3.
Input
A The kind of creature (0-3)
C The mask for the random heading
IX The entity
