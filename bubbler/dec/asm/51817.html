51817: Shift View Left Pixels
Shifts the screen buffer to the left by two pixels, by rotating the bits of each row through the stack.
ShiftViewLeftPixels 51817 LD (23770),SP Save the stack pointer.
51821 LD B,128 Set the row count to 128.
51823 LD SP,61881 Point the stack at the last two bytes of the screen buffer.
ShiftViewLeftPixels_Loop 51826 XOR A Shift the rightmost two bytes of the row two pixels to the left, filling the gap with blank pixels.
