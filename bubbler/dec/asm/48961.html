48961: Record Object
Used by the routine at AddObjectEntity.
Records an object in the table of objects at ObjectRecords. If the object is already in the copy of the table at CopiedRecords, the copy of the record is used. Otherwise a new record is made, with the position and kind of the object. The operand of the first instruction is the address of the next free record, and is updated each time.
Input
IX The object
BC The position of the object
DE The position of the object
Fetch the address of the next free record, which is patched in, and check whether there are any records in the copy of the table.
RecordObject 48961 LD HL,0 Set HL to the address of the next free record.
48964 LD A,(48570) Fetch the number of records in the copy of the table.
48967 AND A Test it.
48968 JR Z,RecordObject_New Jump to RecordObject_New to make a new record if there are none.
Look for a record in the copy of the table that has the same position as the object.
48970 PUSH DE Save the y coordinate.
48971 PUSH BC Save the x coordinate.
48972 LD D,C Copy the low byte of the x coordinate into D.
48973 LD IY,48571 Point IY at CopiedRecords.
RecordObject_Find 48977 EX AF,AF' Keep the number of records left.
48978 LD A,D Fetch the low byte of the x coordinate.
48979 XOR (IY+0) Compare it with the one in the record.
48982 JR NZ,RecordObject_Next Jump to RecordObject_Next if it is different.
48984 LD A,E Fetch the low byte of the y coordinate.
48985 XOR (IY+2) Compare it with the one in the record.
48988 JR NZ,RecordObject_Next Jump to RecordObject_Next if it is different.
Found it, so copy the record to the next free record.
48990 PUSH IY Put the address of the record into DE, via the stack...
48992 POP DE ...then swap it with the address of the next free record.
48993 EX DE,HL
48994 LD BC,7 Set the size of a record, 7.
48997 LDIR Copy the record.
48999 EX DE,HL Put the address of the next free record in HL again.
49000 POP BC Restore the x coordinate.
49001 POP DE Restore the y coordinate.
49002 JR RecordObject_Store Jump to RecordObject_Store.
RecordObject_Next 49004 LD A,B Keep B in A.
49005 LD BC,7 Set the size of a record, 7.
49008 ADD IY,BC Move on to the next record in the copy of the table.
49010 LD B,A Bring back B.
49011 EX AF,AF' Fetch the number of records left.
49012 DEC A Decrease it.
49013 JR NZ,RecordObject_Find Jump back to RecordObject_Find until all of the records have been tried.
49015 POP BC Restore the x coordinate.
49016 POP DE Restore the y coordinate.
