40384: Update Sparkle Entity
Updates an entity of the type 13. Field 35 counts down the number of frames that the entity lasts for. It plays a buzz on every frame and flips bit 0 of its frame.
Input
IX The entity
UpdateSparkleEntity 40384 CALL PlayTinyBuzz Call PlayTinyBuzz to play a buzz.
40387 DEC (IX+35) Decrease field 35 of the entity by one.
40390 JR NZ,UpdateSparkleEntity_Flip Jump to UpdateSparkleEntity_Flip if it is not zero.
40392 LD (IX+0),0 Set the type of the entity to 0 to free it.
40396 SET 7,(IX+1) Set bit 7 of the frame of the entity, to hide it.
40400 JP UpdateEntity_Done Jump to UpdateEntity_Done.
UpdateSparkleEntity_Flip 40403 LD A,(IX+1) Fetch the frame of the entity.
40406 XOR %00000001 Flip bit 0.
40408 LD (IX+1),A Store it.
40411 JP UpdateEntity_Project Jump to UpdateEntity_Project to carry on updating the entity.
