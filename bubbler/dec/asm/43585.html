43585: Jump Via Table
Jumps to the routine in a table of addresses.
Input
A The number of the entry in the table
HL The address of the table
JumpViaTable 43585 LD E,A Copy the number of the entry into E.
This entry point is used by the routines at ScrollViewLeft and ScrollViewRight.
JumpViaTable_Index 43586 LD D,0 Clear D.
43588 ADD HL,DE Add the number of the entry to the address of the table...
43589 ADD HL,DE ...twice, to find the entry.
43590 LD A,(HL) Fetch the low byte of the address of the routine.
43591 INC HL Move onto the high byte.
43592 LD H,(HL) Fetch it.
43593 LD L,A Set the low byte of the address.
43594 JP (HL) Jump to the routine.
