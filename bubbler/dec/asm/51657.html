51657: Shift View Left Byte
Shifts the screen buffer to the left by one byte, by using the stack pointer to copy it. The part from ShiftViewLeftByte_Copy is also used to move rows up by MoveRowsUp.
ShiftViewLeftByte 51657 LD HL,58812 Point HL at the second byte of the screen buffer.
51660 LD (23770),SP Save the stack pointer.
51664 LD SP,HL Point the stack at that byte.
51665 DEC HL Point HL at the byte to its left.
51666 LD B,128 Set the row count to 128.
This entry point is used by the routine at MoveRowsUp.
