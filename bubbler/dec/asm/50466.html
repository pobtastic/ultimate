50466: Flip Block Data
Used by the routines at DrawBlockRow and TestBlockRow_Draw.
Flips the data of a block horizontally, by reversing the bits of each byte with the table at 63744 and swapping the bytes. The flag in bit 7 of the first byte is changed to record the flip. This version is for blocks that are 16 pixels wide.
Input
HL The address of the data of the block
IY The shape
The first byte of the tile is a flag. A row size other than 16 is flipped by FlipWideBlockData instead. The mirror of each byte is on page 249.
FlipBlockData 50466 LD A,(HL) Read the tile's flag.
50467 XOR %10000000 Toggle its top bit.
50469 LD (HL),A Write the flag back.
50470 PUSH HL Remember the tile and move past the flag.
50471 INC HL
50472 PUSH DE Remember the addresses.
50473 PUSH BC
50474 LD A,(IY+5) Read the row size.
50477 CP 16 The narrow flip is for a row size of 16.
50479 LD (50512),SP Remember the stack pointer.
50483 JP NZ,FlipWideBlockData Flip a wide tile when the row size differs.
50486 LD A,(IY+6) Read the tile through the stack. The count is the position byte.
50489 LD SP,HL
50490 LD H,249 Use the mirror table on page 249.
