53040: Update Entity
Used by the routines at UpdateBasicEntity and UpdatePuffEntity.
The routine for the types 1 2 and 3 of entity, which is also jumped to by the routines for other types. Moves the entity with MoveEntity, with the entity flagged as moving, and then projects it with ProjectEntity if it is still in use.
Input
IX The entity
UpdateEntity 53040 LD A,(IX+0) Fetch the type of the entity.
53043 AND A Test it.
53044 JR Z,UpdateEntity_Done Jump to UpdateEntity_Done if the entity is not in use.
53046 SET 7,(IX+17) Flag the entity as moving.
This entry point is used by the routines at MakeCreature, UpdatePickupEntity, UpdateGrowingBubbleEntity, ResetEntityMovement, UpdateFoamEntity, UpdateWhirlerEntity, UpdateBatEntity, UpdateDropEntity and UpdateSaucerEntity.
UpdateEntity_Move 53050 CALL MoveEntity Move the entity.
This entry point is used by the routines at MakeEntitySound, UpdateBurstEntity, UpdateSparkleEntity, UpdateShotEntity and UpdateDomeEntity.
UpdateEntity_Project 53053 LD A,(IX+0) Fetch the type of the entity.
53056 AND A Test it.
53057 CALL NZ,ProjectEntity Work out the screen position if the entity is still in use.
This entry point is used by the routines at UpdateBurstEntity, UpdateSpiderEntity, UpdateDiscEntity, UpdateSparkleEntity and UpdatePuffEntity.
UpdateEntity_Done 53060 POP IX Restore the entity.
