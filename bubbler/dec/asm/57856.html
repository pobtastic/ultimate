57856: Update Panel Digits
Used by the routines at RunGame and DrawPanel.
Sets the digits on the panel of the lives and the bottles of each of the players, using GetDigits. The number of lives that is shown is one less than the number the current player has.
UpdatePanelDigits 57856 LD A,(57054) Read the byte at Lives.
57859 AND A See whether A is zero.
57860 JR Z,UpdatePanelDigits_Skip Jump to 57863 if the zero flag is set.
57862 DEC A Step A back.
UpdatePanelDigits_Skip 57863 CALL GetDigits Call GetDigits.
57866 LD (57769),HL Write HL at LivesText_PlayerOne.
57869 LD A,(57085) Read the byte at OtherPlayerState.
57872 CALL GetDigits Call GetDigits.
57875 LD (57775),HL Write HL at LivesText_PlayerTwo.
57878 LD A,(57056) Read the byte at BottlesLeft.
57881 CALL GetDigits Call GetDigits.
57884 LD (57781),HL Write HL at BottlesText_PlayerOne.
57887 LD A,(57087) Read the byte at 57087.
57890 CALL GetDigits Call GetDigits.
57893 LD (57787),HL Write HL at BottlesText_PlayerTwo.
57896 RET Return.
