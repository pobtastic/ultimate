41696: Clear Bytes
Used by the routines at StartGame, RunGame and WipeViewOut.
Sets a number of bytes to zero.
Input
B The number of bytes
HL The address of the first byte
ClearBytes 41696 LD (HL),0 Write zero to the byte.
41698 INC HL Move onto the next byte.
41699 DJNZ ClearBytes Jump back until all of the bytes have been cleared.
