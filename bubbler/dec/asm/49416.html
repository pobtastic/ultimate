49416: Draw Top Strip
Handles an object for DrawObject when the view is scrolling down, so that only the objects in the strip that has just come into view at the top are drawn.
DrawTopStrip 49416 CALL GetSizeOffset Find the position of the object in the view, with its size offset.
49419 LD A,H Copy the high byte of the position into A.
49420 CP 128 Compare it with 128.
49422 LD DE,16 Set the distance to move the object down, 16.
49425 JR NZ,DrawLeftStrip_AddOffset Draw the object, after moving it, if the high byte is not 128.
49427 LD A,L Copy the low byte of the position into A.
49428 CP 8 Compare it with 8.
49430 RET NC Return if the object is not in the strip.
49431 JR DrawLeftStrip_AddOffset Draw the object, after moving it.
