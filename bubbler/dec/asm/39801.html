39801: Test Entity Removal
Used by the routines at UpdateFoamEntity and UpdateBatEntity.
Calls TestEntityVisible with BC set to 32 and, if that returns with the zero flag set, frees the entity and hides its sprite.
Input
IX The entity
TestEntityRemoval 39801 LD BC,32 Set the value to test to 32.
39804 CALL TestEntityVisible Call TestEntityVisible.
39807 RET NZ Return if the zero flag is not set.
39808 LD (IX+0),0 Set the type of the entity to 0 to free it.

39816 RET Return.
