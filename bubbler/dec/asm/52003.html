52003: Shift View Right Byte
Shifts the screen buffer to the right by one byte, by using the stack pointer to copy it. The part from ShiftViewRightByte_Copy is also used to move rows down by MoveRowsDown.
ShiftViewRightByte 52003 LD (23770),SP Save the stack pointer.
52007 LD HL,61881 Point HL at the last two bytes of the screen buffer.
52010 LD SP,HL Point the stack at them.
52011 POP DE Skip those two bytes, which the shift overwrites.
52012 LD B,128 Set the row count to 128.
This entry point is used by the routine at MoveRowsDown.
ShiftViewRightByte_Copy 52014 LD D,(HL) Copy the twenty-four bytes of the next row onto the stack, walking backwards.
