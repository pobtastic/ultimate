51116: Draw Block Section
Draws a section of a block, once for each of the entities that overlap it. Purpose not yet known.
Input
IX The overlapping item

51118 SUB (IX+0) Subtract field 0 of the entity.
51121 JR NC,DrawBlockSection_Skip Jump to 51127 if the carry flag is reset.
51123 CP 241 Jump to DrawBlockSection_Next if it is below 241.
51125 JR C,DrawBlockSection_Next
DrawBlockSection_Skip 51127 LD A,B B moves into A.
51128 CALL DrawBlockBytes Call DrawBlockBytes.
