43580: Add To Address
Used by the routines at ShowTitleMenu, MoveMarker, SetLevelGraphics, SetUpCreature, UpdatePickupEntity, PlayNote, ScrollMessage, CopyColumn, GetDirectionVector, BuildPatternedSprite, DrawSprite, FollowPath, TestEntityPair, TestGroupObjects and UpdateScreen.
Adds a value to an address.
Input
A The value
HL The address
Output
HL The address plus the value
AddToAddress 43580 ADD A,L Add the value to the low byte of the address.
43581 LD L,A Store it.
43582 RET NC Return if there was no carry.
43583 INC H Increase the high byte of the address.
43584 RET Return.
