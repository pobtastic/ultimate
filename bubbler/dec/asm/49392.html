49392: Draw Left Strip
Handles an object for DrawObject when the view is scrolling to the right, so that only the objects in the strip that has just come into view on the left are drawn. The position of the object is moved across by the width of the view, 176 by the entry point at DrawLeftStrip_AddOffset.
DrawLeftStrip 49392 LD HL,(48031) Fetch the position of the object in the view.
49395 LD DE,176 Set the distance to move the object across, 176.
49398 LD A,H Copy the high byte of the position into A.
49399 CP 128 Jump to DrawLeftStrip_AddOffset if the position is below 32768.
49401 JR C,DrawLeftStrip_AddOffset
49403 LD A,L Copy the low byte of the position into A.
49404 CP 16 Compare it with 16.
49406 RET NC Return if the object is not in the strip.
This entry point is used by the routines at DrawTopStrip and DrawBottomStrip.
DrawLeftStrip_AddOffset 49407 LD HL,(48031) Fetch the position of the object in the view.
49410 ADD HL,DE Add the distance to move across.
49411 LD (48031),HL Store the new position.
49414 JR DrawBlock Draw the block of the object.
