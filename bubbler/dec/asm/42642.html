42642: Draw Needle Tip
Used by the routine at DrawDirectionGauge.
Draws the ball at the tip of the needle of a direction gauge into the buffer at 62743 using self-modifying versions of the sprite drawing code at DrawShiftedRows. The ball is drawn from six pairs of mask and picture values at NeedleTipShapes (or the shifted version at 42719), which are taken from the stack. The value of DrawingPosition selects the version by bit 0, and the table of shifts to use by bits 1-2.
