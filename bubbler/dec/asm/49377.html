49377: Draw Right Strip
Handles an object for DrawObject when the view is scrolling to the left, so that only the objects in the strip that has just come into view on the right are drawn.
DrawRightStrip 49377 LD HL,(48031) Fetch the position of the object in the view.
49380 CALL AddRecordSizes Add the sizes of the object, to find its far edge.
49383 LD DE,32944 Set the position of the start of the strip on the right.
49386 AND A Subtract the start of the strip.
49387 SBC HL,DE
49389 RET C Return if the object is not as far across as the strip.
49390 JR DrawBlock Draw the block of the object.
