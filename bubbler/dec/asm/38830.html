38830: Create Spawned Entity
Used by the routine at UpdateSpawnPoints.
Makes an entity from a spawn point, provided that the random number is odd. When it is created the spawn point is made to wait for 7 frames before it may create another entity. The entity which is made depends on its type: the code for types 0 8 and 14 is different.
Input
IX The free entity
IY The entry of the table of kinds (see SpawnKinds)
