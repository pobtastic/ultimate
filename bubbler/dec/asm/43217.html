43217: Reset Attributes
Used by the routines at GameEntry, SwitchPlayer, ShowPlayerNumber and RunGame.
Sets the attributes of the lower two thirds of the screen to bright white on black, using the stack. The same code clears the screen when entered at ClearScreen.
ResetAttributes 43217 LD (23768),SP Save the stack pointer.
43221 LD SP,23296 Point the stack at the end of the attribute file.
43224 LD BC,32770 Set the number of pushes to 256.
43227 LD DE,18247 Set the value to 71 (bright white ink on black paper).
43230 JP ClearScreen_Fill Jump to ClearScreen_Fill.
