54185: Find Path At Position
Used by the routine at TestGroupObjects.
Looks through the entries of the level data, which are found just before the level header at LevelHeaderAddress, for one whose position matches the position of the entity. If one is found the entity is set to follow it by setting fields 36 and 37.
Input
IX The entity
The list is walked backwards from just before the level header. Each entry is a pointer to four position bytes. A match stores the index in field 36 and 72 in field 37.
