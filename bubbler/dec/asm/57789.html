57789: Print Text Records
Used by the routines at ShowEnding, ShowTitleMenu, RunGame and DrawPanel.
Prints a number of text records, one after the other, with PrintText.
Input
DE The address of the first text record
B The number of text records
PrintTextRecords 57789 PUSH BC Remember BC.
57790 CALL PrintText Call PrintText.
57793 POP BC Bring back BC.
57794 DJNZ PrintTextRecords Repeat from PrintTextRecords while B still counts.
57796 RET Return.
