C7E0: Update View Flags
Used by the routines at ScrollViewDown, ScrollViewUp, ScrollViewLeft and ScrollViewRight.
Clears bits of the view flags at ViewFlags that are not set in L.
Input
L The bits to keep
UpdateViewFlags C7E0 LD A,($5CE6) Read the byte at ViewFlags.
C7E3 AND L Keep only the bits of A that are set in L.
C7E4 LD ($5CE6),A Write A at ViewFlags.
C7E7 RET Return.
