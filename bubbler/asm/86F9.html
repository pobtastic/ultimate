86F9: Start Level
Used by the routine at RestoreBottles.
Finds the data of the current level and, when it is entered at StartLevel, places the player at the start of the level (or at the position where the player last restarted) and sets the view to match.
Input
C 01 to place the player, otherwise only find the level data
StartLevel 86F9 LD C,$01 Set the placement flag in C to 01.
This entry point is used by the routines at SwitchPlayer and CollectBottle.
