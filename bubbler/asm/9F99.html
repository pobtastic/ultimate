9F99: Sort Draw List
Used by the routines at RunFrame and RunGame.
Sorts the draw list at DrawList into the order in which the items must be drawn, and builds the sorted list at SortedDrawList. This is a painter's algorithm: an item can only be drawn after every item which is behind it. Each item in the lists has three bytes: flags, and the address of its record. Bit 0 of the flags is set if the record is an entity, and reset if it is a compact record with the three coordinates at offsets 02 04 and 06 which is given the size 06 06 01. Bit 7 is set once the item has been moved to the sorted list. . The routine takes the first item which has not been moved, and compares it with each of the other items which have not been moved. The result for each pair is a number in the range 00-1A made from the relation along the first, second and third coordinates (00 for 'the other item is before this one', 01 for 'they overlap' and 02 for 'the other item is after this one'). The number selects a routine from the table at DrawOrderTable. If the other item has to be drawn first then it becomes the item under consideration (unless it has been tried already, which would be a loop). When an item has no other item that has to be drawn before it, it is moved to the sorted list and the whole process starts again.
