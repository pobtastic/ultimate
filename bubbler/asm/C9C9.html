C9C9: Shift View Left Byte
Shifts the screen buffer to the left by one byte, by using the stack pointer to copy it. The part from ShiftViewLeftByte_Copy is also used to move rows up by MoveRowsUp.
ShiftViewLeftByte C9C9 LD HL,$E5BC Point HL at the second byte of the screen buffer.
C9CC LD ($5CDA),SP Save the stack pointer.
C9D0 LD SP,HL Point the stack at that byte.
C9D1 DEC HL Point HL at the byte to its left.
C9D2 LD B,$80 Set the row count to 80.
This entry point is used by the routine at MoveRowsUp.
ShiftViewLeftByte_Copy C9D4 POP DE Copy the twenty-four bytes of the next row from the stack.
