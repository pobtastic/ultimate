9D8D: Update Spider Entity
Updates an entity of the type 10. If the player touches it then it is drawn as normal, otherwise it is freed (see FreeLinkedEntity).
Input
IX The entity
UpdateSpiderEntity 9D8D LD BC,$0020 Set the value to test to 20.
9D90 CALL TestEntityVisible Call TestEntityVisible.
9D93 JR Z,UpdateSpiderEntity_Free Jump to UpdateSpiderEntity_Free if the zero flag is set.
9D95 CALL ProjectEntity Call ProjectEntity.
9D98 JP UpdateEntity_Done Jump to UpdateEntity_Done.
UpdateSpiderEntity_Free 9D9B JR FreeLinkedEntity Jump to FreeLinkedEntity to free the entity.
