BFA5: Draw Object
Used by the routine at DrawGroupObjects.
Prepares an object of a group for drawing, and then passes it to the routine whose address is the operand of the JP at C0DE which is set by DrawLevelObjects. It works out the screen column and row of the object, and returns without doing anything if the object is not in view. Objects that can be entities are passed to AddObjectEntity first, and an object that has the flag for it in the row of flags of the group is also given an item record with AddItemRecord.
Input
IX The object, which is three bytes
Work out the screen column of the object. This is the depth of the cell plus the sum of the two halves of the first byte of the object, which are its offsets along the x and y axes, less the origin of the view.
DrawObject BFA5 LD H,$00 Set H to the depth of the cell, which is patched in.
BFA7 LD A,(IX+$00) Fetch the first byte of the object.
BFAA ADD A,A Multiply it by sixteen, to move the offset along the y axis to the top four bits...
BFAB ADD A,A
BFAC ADD A,A
BFAD ADD A,A
BFAE LD E,A ...and keep it in E.
BFAF LD A,(IX+$00) Fetch the first byte of the object again.
BFB2 AND %11110000 Keep the offset along the x axis in the top four bits.
BFB4 ADD A,E Add the two offsets to find the low byte of the screen column.
BFB5 JR NC,DrawObject_SetColumn Jump to DrawObject_SetColumn if there was no carry.
BFB7 INC H Increase the high byte of the screen column.
DrawObject_SetColumn BFB8 LD L,A Put the low byte of the screen column in L.
BFB9 LD BC,$0000 Set BC to the origin of the view, which is patched in.
BFBC ADD HL,BC Add the origin to the screen column.
Find out whether the object can be an entity. Objects of kind 81 and 8F are passed to AddObjectEntity, and any other kind is drawn straight away.

BFDC CP $8F Jump to DrawObject_Add if it is kind 8F, so that the bytes are used as they are.
