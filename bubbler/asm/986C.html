986C: Set Entity Defaults
Used by the routines at CreatePickup_FourthSide and CreateSpawnedEntity_GrowingBubble.
Sets the acceleration, the speed and the animation which an entity made by CreatePickup or CreateSpawnedEntity has in common, and then measures its sprite.
Input
IX The entity
SetEntityDefaults 986C LD (IX+$14),$FF Set the high byte of the acceleration to FF.
9870 LD (IX+$15),$B0 Set the low byte of the acceleration to B0.
9874 LD (IX+$1B),$10 Set the rate of change of the speed to 10.
9878 LD (IX+$1C),$51 Set the animation counter to 51.
987C LD (IX+$1D),$76 Set the frame range to 76 so the frames run from 6 to 7.
9880 LD (IX+$10),$10 Set the speed to 10.
9884 LD (IX+$01),$20 Set the frame byte to 20.
9888 JP SetEntitySize Measure the sprite.
