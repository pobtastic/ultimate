CB23: Shift View Right Byte
Shifts the screen buffer to the right by one byte, by using the stack pointer to copy it. The part from ShiftViewRightByte_Copy is also used to move rows down by MoveRowsDown.
ShiftViewRightByte CB23 LD ($5CDA),SP Save the stack pointer.
CB27 LD HL,$F1B9 Point HL at the last two bytes of the screen buffer.
CB2A LD SP,HL Point the stack at them.
CB2B POP DE Skip those two bytes, which the shift overwrites.
CB2C LD B,$80 Set the row count to 80.
This entry point is used by the routine at MoveRowsDown.
ShiftViewRightByte_Copy CB2E LD D,(HL) Copy the twenty-four bytes of the next row onto the stack, walking backwards.
