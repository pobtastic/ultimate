E200: Update Panel Digits
Used by the routines at RunGame and DrawPanel.
Sets the digits on the panel of the lives and the bottles of each of the players, using GetDigits. The number of lives that is shown is one less than the number the current player has.
UpdatePanelDigits E200 LD A,($DEDE) Read the byte at Lives.
E203 AND A See whether A is zero.
E204 JR Z,UpdatePanelDigits_Skip Jump to E207 if the zero flag is set.
E206 DEC A Step A back.
UpdatePanelDigits_Skip E207 CALL GetDigits Call GetDigits.
E20A LD ($E1A9),HL Write HL at LivesText_PlayerOne.
E20D LD A,($DEFD) Read the byte at OtherPlayerState.
E210 CALL GetDigits Call GetDigits.
E213 LD ($E1AF),HL Write HL at LivesText_PlayerTwo.
E216 LD A,($DEE0) Read the byte at BottlesLeft.
E219 CALL GetDigits Call GetDigits.
E21C LD ($E1B5),HL Write HL at BottlesText_PlayerOne.
E21F LD A,($DEFF) Read the byte at DEFF.
E222 CALL GetDigits Call GetDigits.
E225 LD ($E1BB),HL Write HL at BottlesText_PlayerTwo.
E228 RET Return.
