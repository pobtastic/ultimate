674E: Sprite: Foam
The foam sprites, which are drawn by DrawSprite for entities of the type 0A. Each sprite starts with its width in bytes and its height in rows, and the rest is a mask byte and a picture byte for each byte of the width in each row, from the top row down. A set bit in the mask means that the picture replaces the background. The names of the sprites are only descriptions of how they look.
