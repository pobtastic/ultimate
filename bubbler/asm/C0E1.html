C0E1: Draw Right Strip
Handles an object for DrawObject when the view is scrolling to the left, so that only the objects in the strip that has just come into view on the right are drawn.
DrawRightStrip C0E1 LD HL,($BB9F) Fetch the position of the object in the view.
C0E4 CALL AddRecordSizes Add the sizes of the object, to find its far edge.
C0E7 LD DE,$80B0 Set the position of the start of the strip on the right.
C0EA AND A Subtract the start of the strip.
C0EB SBC HL,DE
C0ED RET C Return if the object is not as far across as the strip.
C0EE JR DrawBlock Draw the block of the object.
