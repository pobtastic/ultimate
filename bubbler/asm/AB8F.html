AB8F: Read Controls
Used by the routine at ControlPlayer.
Reads the controls of the current player, using the control method which is selected in Player1ControlMethod (00 for the keyboard, 01 for a Kempston joystick, 02 for a Cursor joystick, otherwise an Interface II joystick). The result has one bit for each control: bit 0 is right, bit 1 is left, bit 2 is down, bit 3 is up and bit 4 is fire.
Output
C The controls which are being used
ReadControls AB8F LD A,($60FB) Fetch the control method of the current player.
AB92 AND A Test it.
AB93 JP Z,ReadControls_Keyboard Jump to ReadControls_Keyboard if it is the keyboard.
AB96 DEC A Decrease it by one.
AB97 JR Z,ReadControls_Kempston Jump to ReadControls_Kempston if it is a Kempston joystick.
AB99 DEC A Decrease it by one.
AB9A JR Z,ReadControls_Cursor Jump to ReadControls_Cursor if it is a Cursor joystick.

AB9E IN A,($FE)
ABA0 LD B,$FF Start with all of the bits set.
ABA2 RRA Move the bit for "0" into the carry flag.
ABA3 RL B Move it into B.
ABA5 RRA Move the bit for "9" into the carry flag.
ABA6 RL B Move it into B.
ABA8 RRA Move the bit for "8" into the carry flag.
ABA9 RL B Move it into B.
ABAB RRA Move the bit for "7" into the carry flag...
ABAC RRA ...and then the bit for "6".
ABAD RL B Move it into B.
ABAF RLA Rotate the bit for "7" back into the carry flag...
ABB0 RL B ...and move it into B.
ABB2 LD A,B Fetch the result.
ABB3 CPL Invert the bits, so that a set bit is a control being used.
ABB4 LD C,A Store it in C.
ABB5 RET Return.
ReadControls_Kempston ABB6 IN A,($1F) Read the Kempston joystick.
ABB8 AND %00011111 Keep the five bits.
ABBA LD C,A Store them in C.
ABBB RET Return.
