D3EB: Test Entity Collisions
Used by the routine at MoveEntity.
Tests the entity against each of the other entities with TestEntityPair. A puff and a shot are not tested. A player skips puffs and sparkles, and a saucer skips shots. A disc, a free slot and a hidden entity are skipped. The direction bytes are 20 during the tests. Afterwards the low bytes of x and y, relative to the patched origins, replace them for TestEntityCells. The step in MoveEntityBack is removed for the tests and then put back.
Input
IX The entity
The direction bytes start at 20 so a hit during the tests has a neutral component. The type of this entity is patched into the skip below.
TestEntityCollisions D3EB LD A,$04 Mark the entity as only touching.
D3ED LD ($DD4C),A
D3F0 LD A,(IX+$00) Remember this entity's type for the skips below.
D3F3 LD ($D41F),A
D3F6 CP $05 A puff is not tested against the others.
D3F8 JR Z,TestEntityCollisions_Finish
D3FA CP $0E A shot is not tested against the others.
D3FC JR Z,TestEntityCollisions_Finish
D3FE LD (IX+$18),$20 Set both direction bytes to 20.
D402 LD (IX+$19),$20

D40F LD IY,$B540 Start at the first entity.

D414 LD A,(IY+$00) Skip an entity that is free.
D417 AND A

D41C JR Z,TestEntityCollisions_Next

D442 PUSH IY It is not tested against itself.
D444 POP HL
D445 PUSH IX
D447 POP DE

D449 SBC HL,DE
D44B CALL NZ,TestEntityPair
TestEntityCollisions_Next D44E LD BC,$0026 Move on to the next entity.

D453 POP BC Bring the count back.
D454 DJNZ TestEntityCollisions_Loop Repeat for the remaining entities.
