5F9A: Random Number State
The state of the random number generator at GetRandomNumber.
RandomNumber_Seed 5F9A DEFW $8E17 The seed, which changes every time a number is made.
5F9C DEFW $8000 The address of the next byte of game memory to mix into the seed.
