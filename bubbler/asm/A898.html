A898: Show Exit Message
Used by the routines at CollectBottle and RunGame.
Prints the message 'EXIT OPEN' on the window if all of the bottles have been collected.
ShowExitMessage A898 LD A,($DEE0) Fetch the number of bottles left from BottlesLeft.
A89B AND A Test it.
A89C RET NZ Return if there are some left.
A89D LD DE,$A8A6 Point DE at ExitMessage.
A8A0 CALL PrintText Print the first part of the message.
A8A3 JP PrintText Print the second part of the message.
