D647: Test Overlap
Used by the routine at TestEntityPair.
Tests whether two ranges overlap. The carry is set when they do, and L is the amount of the overlap. No overlap leaves the carry clear.
Input
HL The start of the first range
DE The start of the second range
B The size of the first range
C The size of the second range
Output
F The carry flag is set if they overlap
L The amount of the overlap
B is the size of the first range and C the size of the second. The result is the smaller amount by which they cross.
