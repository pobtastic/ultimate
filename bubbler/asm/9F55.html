9F55: Play Slow Fall
Used by the routines at UpdatePickupEntity and UpdateGrowingBubbleEntity.
Plays a series of 12 clicks whose lengths slowly increase.
PlaySlowFall 9F55 LD C,$12 Set the number of clicks to 12.
9F57 LD D,$60 Set the base length to 60.
PlaySlowFall_Click 9F59 LD A,C Fetch the number of clicks left.
9F5A ADD A,A Double it.
9F5B ADD A,D Add the base length.
9F5C LD B,A Use it as the length of the click.
9F5D CALL PlayClick Play a click.
9F60 LD A,D Fetch the base length.
9F61 ADD A,$03 Add 03.
9F63 LD D,A Store it.
9F64 DEC C Decrease the number of clicks by one.
9F65 JR NZ,PlaySlowFall_Click Jump back until they have all been played.
9F67 RET Return.
