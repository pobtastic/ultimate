DEC4: Player Number Text
The text record for the message 'PLAYER 1', which is printed by ShowPlayerNumber. The number is changed to suit the player.
PlayerNumberText DEC4 DEFB $40,$5F Position: x=40 y=5F.
DEC6 DEFB $47 Attribute: INK:WHITE, PAPER:BLACK (BRIGHT).
DEC7 DEFB $C8 Length 08 quadruple size.
DEC8 DEFB $19,$15,$0A,$22,$0E,$1B,$27,$01 "PLAYER 1"
