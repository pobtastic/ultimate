9CA3: Set Up Shot Sprite
Used by the routines at CreateShot and UpdateSaucerEntity.
Sets the speed and sprite fields of an entity of the type 0E which is made by UpdateSaucerEntity, and then sets its sprite.
Input
IX The entity
SetUpShotSprite 9CA3 LD (IX+$10),$44 Set the speed to 44.
9CA7 LD (IX+$14),$FF Set field 14 of the entity to FF.
9CAB LD (IX+$15),$C8 Set field 15 of the entity to C8.
9CAF LD (IX+$1C),$04 Set field 1C of the entity to 04.
9CB3 LD (IX+$1D),$30 Set field 1D of the entity to 30.
9CB7 JP SetEntitySize Jump to SetEntitySize to set the sprite of the entity.
