A2E0: Clear Bytes
Used by the routines at StartGame, RunGame and WipeViewOut.
Sets a number of bytes to zero.
Input
B The number of bytes
HL The address of the first byte
ClearBytes A2E0 LD (HL),$00 Write zero to the byte.
A2E2 INC HL Move onto the next byte.
A2E3 DJNZ ClearBytes Jump back until all of the bytes have been cleared.
A2E5 RET Return.
