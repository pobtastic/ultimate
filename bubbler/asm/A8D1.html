A8D1: Reset Attributes
Used by the routines at GameEntry, SwitchPlayer, ShowPlayerNumber and RunGame.
Sets the attributes of the lower two thirds of the screen to bright white on black, using the stack. The same code clears the screen when entered at ClearScreen.
ResetAttributes A8D1 LD ($5CD8),SP Save the stack pointer.
A8D5 LD SP,$5B00 Point the stack at the end of the attribute file.
A8D8 LD BC,$8002 Set the number of pushes to 0100.
A8DB LD DE,$4747 Set the value to 47 (bright white ink on black paper).
A8DE JP ClearScreen_Fill Jump to ClearScreen_Fill.
