B8DD: Add To High Byte
Adds a value to the high byte of an address, carrying into the low byte.
Input
A The value
HL The address
Output
HL The new address
AddToHighByte B8DD ADD A,H Plus H.
B8DE LD H,A A moves into H.
B8DF RET NC Return if the carry flag is reset.
B8E0 INC L Advance L.
B8E1 RET Return.
