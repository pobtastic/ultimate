B7CE: Update Extra Record
Used by the routine at UpdateExtraRecords.
Builds the extra record for an entity, and fills the temporary entity at TemporaryEntity so that SetEntitySize can measure its sprite. Field 1F chooses the size class: below 17 is class 0, below 25 is class 1, and any higher value is class 2. A size index of zero or FF leaves the record unset.
Bit 6 of the flags in field 1E selects the higher frame. The frame written for the temporary entity is the class when the bit is clear, and the class plus three when it is set. The same bit is copied into bit 7 of byte 0C of the extra record. Purpose of the flag beyond that choice is not yet known. The instructions at UpdateExtraRecord_Unused would step the shape bits of the height and then start a burst, but they are not reached: the class is only 0, 1 or 2, so the jump at UpdateExtraRecord_HigherFrame is always taken. The saved zero flag then makes the height adjustment subtract field 1F rather than add the z extent.
The adjusted x coordinate is the entity's x plus half of field 0B its x extent, and the adjusted y coordinate is the entity's y plus half of field 0C its y extent. Both are reduced by a margin taken from the class. The z coordinate is the entity's z less field 1F or 0100 when that would leave the high byte zero. Bytes 02 and 03 of the extra record receive the adjusted x, bytes 04 and 05 the adjusted y, and bytes 06 and 07 the adjusted z. Byte 0B holds the width in bits 0-3 and the frame in bits 4-7. Byte 0C holds the height in bits 0-5.
Input
IX The entity
IY The extra record
Output
A Zero if the record was set up, otherwise non-zero
Leave the record unset when the size index is zero or FF.
