AA41: Jump Via Table
Jumps to the routine in a table of addresses.
Input
A The number of the entry in the table
HL The address of the table
JumpViaTable AA41 LD E,A Copy the number of the entry into E.
This entry point is used by the routines at ScrollViewLeft and ScrollViewRight.
JumpViaTable_Index AA42 LD D,$00 Clear D.
AA44 ADD HL,DE Add the number of the entry to the address of the table...
AA45 ADD HL,DE ...twice, to find the entry.
AA46 LD A,(HL) Fetch the low byte of the address of the routine.
AA47 INC HL Move onto the high byte.
AA48 LD H,(HL) Fetch it.
AA49 LD L,A Set the low byte of the address.
AA4A JP (HL) Jump to the routine.
