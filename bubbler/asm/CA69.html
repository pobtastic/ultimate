CA69: Shift View Left Pixels
Shifts the screen buffer to the left by two pixels, by rotating the bits of each row through the stack.
ShiftViewLeftPixels CA69 LD ($5CDA),SP Save the stack pointer.
CA6D LD B,$80 Set the row count to 80.
CA6F LD SP,$F1B9 Point the stack at the last two bytes of the screen buffer.
ShiftViewLeftPixels_Loop CA72 XOR A Shift the rightmost two bytes of the row two pixels to the left, filling the gap with blank pixels.
