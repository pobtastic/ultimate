C119: Draw Bottom Strip
Handles an object for DrawObject when the view is scrolling up, so that only the objects in the strip that has just come into view at the bottom are drawn.
DrawBottomStrip C119 LD HL,($BBA1) Fetch the vertical position of the object in the view.
C11C LD A,($5CF3) Fetch the size of the object.
C11F SRL A Halve it.
C121 LD E,A Copy it into E.
C122 LD D,$00 Clear D.
C124 ADD HL,DE Add half of the size to the position.
C125 LD DE,$8078 Set the position of the start of the strip at the bottom.
C128 AND A Subtract the start of the strip.
C129 SBC HL,DE
C12B RET C Return if the object is not as far down as the strip.
C12C LD HL,($BBA1) Fetch the vertical position of the object in the view.
C12F LD DE,$FF88 Set the distance to move the object up, FF88.
C132 ADD HL,DE Add it.
C133 LD ($BBA1),HL Store the new position.
C136 LD DE,$0010 Set the distance to move the object down, 10.
C139 JR DrawLeftStrip_AddOffset Draw the object, after moving it.
