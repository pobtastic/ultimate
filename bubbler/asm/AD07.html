AD07: Prepare Entity Item
Used by the routine at BuildDrawList.
Converts the position of the entity with ConvertEntityPosition and adds it to the draw list. Entity types 0C and 10 are only appended with AppendEntityItem. Any other type is also given a record in the table of item records, which holds a copy of the rows of the screen buffer (which are 18 bytes wide) that lie under the entity, so that RestoreItemRows can put them back after the entity has been drawn.
Input
IX The entity
HL Pointer to the next free byte in the table of item records
Output
HL Updated pointer
PrepareEntityItem AD07 PUSH HL Save the item record pointer.
AD08 CALL ConvertEntityPosition Convert the position of the entity.
AD0B POP HL Restore the item record pointer.
AD0C LD A,(IX+$00) Fetch the type of the entity.
AD0F CP $0C Jump to AppendEntityItem if it is type 0C.
AD11 JR Z,AppendEntityItem
AD13 CP $10 Jump to AppendEntityItem if it is type 10.
AD15 JR Z,AppendEntityItem
