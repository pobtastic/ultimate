B43C: Draw Sprite
Used by the routine at DrawEntityItem.
Draws the sprite of an entity into the screen buffer, which is 18 bytes wide. The sprite data is read by using the stack pointer, and the sprite is drawn by one of the row routines in the table at RowRoutineTable, which is chosen using the width of the sprite and whether it is shifted by the low bits of the column. The addresses of the row routine and the step to the previous row are written into the drawing code before it is entered. If the sprite goes beyond the top of the screen buffer, the rows that are not needed are skipped.
