A8E1: Clear Screen
Used by the routines at GameEntry, SwitchPlayer, ShowPlayerNumber and RunGame.
Sets the pixels of the whole screen to zero, using the stack.
ClearScreen A8E1 LD ($5CD8),SP Save the stack pointer.
A8E5 LD SP,$5800 Point the stack at the end of the pixel file.
A8E8 LD BC,$000C Set the number of pushes to 0C00.
A8EB LD DE,$0000 Set the value to 00.
This entry point is used by the routine at ResetAttributes.
ClearScreen_Fill A8EE PUSH DE Write two bytes.
A8EF DJNZ ClearScreen_Fill Jump back until a block of pushes has been done.
A8F1 DEC C Decrease the number of blocks by one.
A8F2 JR NZ,ClearScreen_Fill Jump back until all of the blocks have been done.
A8F4 LD SP,($5CD8) Restore the stack pointer.
A8F8 RET Return.
