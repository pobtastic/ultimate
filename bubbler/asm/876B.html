876B: Set Level Graphics
Used by the routines at SwitchPlayer and RunGame.
Sets up the level which is being played using the table of levels at LevelSettings, which has eight bytes for each level. The colour for the level and the number of bottles to collect are stored, and four of the addresses in the table at TileTable are replaced for the level.
