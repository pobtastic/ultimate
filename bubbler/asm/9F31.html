9F31: Play Falling Sweep
Used by the routine at FollowPath.
Plays a sweep of 3F clicks which get longer, so the pitch falls.
PlayFallingSweep 9F31 LD C,$3F Set the number of clicks to 3F.
PlayFallingSweep_Click 9F33 LD A,C Fetch the number of clicks left.
9F34 XOR %00111111 Flip bits 0-5, to count upwards.
9F36 ADD A,$10 Add 10.
9F38 LD B,A Use it as the length of the click.
9F39 CALL PlayClick Play a click.
9F3C DEC C Decrease the number of clicks by one.
9F3D JR NZ,PlayFallingSweep_Click Jump back until they have all been played.
9F3F RET Return.
