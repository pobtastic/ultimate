B4E8: Draw Shifted Rows
Draws the rows of a sprite that is shifted by one to three pixels, using the stack pointer to read the sprite data. The shifted bytes are found in the tables that start at the page in H, and one more byte than the width is drawn. There are four entry points, which are for widths of four, three, two and one bytes. The address in the table at RowRoutineTable is the entry point for the width.
Input
DE The address in the screen buffer
H The page of the table for the shift
B The number of rows
SP The sprite data
