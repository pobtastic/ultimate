9924: Start Burst
Used by the routines at UpdatePickupEntity, UpdateExtraRecord, RunFrame, TestEntityPair, BurstOtherEntity and CollectItem.
Changes an entity into one of type 07 which is set up using PlayRandomNoise.
Input
IX The entity
StartBurst 9924 LD (IX+$01),$00 Set field 01 of the entity to 00.
9928 LD (IX+$00),$07 Set the type of the entity to 07.
992C CALL SetEntitySize Call SetEntitySize to set the sprite of the entity.
992F LD (IX+$1C),$04 Set field 1C of the entity to 04.
9933 LD (IX+$1D),$88 Set field 1D of the entity to 88.
9937 CALL PlayRandomNoise Call PlayRandomNoise.
