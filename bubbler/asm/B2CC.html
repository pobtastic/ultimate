B2CC: Test Records Against Entity
Used by the routine at PrepareEntityItem.
Tests the entity in IX against each of the 14-byte records in the table at Records that has not already been marked, using TestRecordOverlap.
Input
IX The entity
TestRecordsAgainstEntity B2CC LD A,($BBF6) Read how many records there are.
B2CF AND A Return when there are none.
B2D0 RET Z
B2D1 PUSH IY Remember the record that was in use.
B2D3 LD IY,$BBF7 Start at the first record.
TestRecordsAgainstEntity_Loop B2D7 PUSH AF Remember how many records remain.
B2D8 BIT 7,(IY+$0A) Test the overlap when bit 7 of byte 0A is clear.
B2DC CALL Z,TestRecordOverlap
B2DF LD DE,$0014 Step on to the next record.
B2E2 ADD IY,DE
B2E4 POP AF Repeat for the remaining records.
B2E5 DEC A
B2E6 JR NZ,TestRecordsAgainstEntity_Loop
B2E8 POP IY Restore the record that was in use.
B2EA RET Return.
