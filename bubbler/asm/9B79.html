9B79: Test Entity Removal
Used by the routines at UpdateFoamEntity and UpdateBatEntity.
Calls TestEntityVisible with BC set to 20 and, if that returns with the zero flag set, frees the entity and hides its sprite.
Input
IX The entity
TestEntityRemoval 9B79 LD BC,$0020 Set the value to test to 20.
9B7C CALL TestEntityVisible Call TestEntityVisible.
9B7F RET NZ Return if the zero flag is not set.
9B80 LD (IX+$00),$00 Set the type of the entity to 00 to free it.
9B84 SET 7,(IX+$01) Set bit 7 of the frame of the entity, to hide it.
9B88 RET Return.
