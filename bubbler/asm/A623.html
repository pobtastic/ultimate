A623: Find Hidden Entity
Used by the routine at CreatePuff.
Looks for an entity whose frame has bit 7 set (a hidden entity).
Input
B The number of entities to look at
IY The first entity
Output
IY The hidden entity, if one was found
F Zero flag reset if a hidden entity was found
FindHiddenEntity A623 LD DE,$0026 Set the size of an entity.
FindHiddenEntity_Loop A626 BIT 7,(IY+$01) Test bit 7 of the frame of the entity.
A62A RET NZ Return if it is hidden.
A62B ADD IY,DE Move onto the next entity.
A62D DJNZ FindHiddenEntity_Loop Jump back until all of the entities have been tested.
A62F RET Return.
