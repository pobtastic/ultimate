8C0D: Groups
The groups of objects that are found by the table at GroupTable. The first byte of a group has the number of objects in bits 0-4, and the other bits are flags. The next two bytes are values that DrawGroupObjects shifts once for each object. If bit 4 of the count is set there is an extra byte. The objects follow, with three bytes each. A group with a first byte of 00 has no objects. Purpose of the individual bytes is not yet known.
A group that is not in the table.
