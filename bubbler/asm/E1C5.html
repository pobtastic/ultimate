E1C5: Copy Rectangle Rows
Used by the routine at DrawPanel.
Copies rows of bytes into the table at F502. The first byte is the width of each row, remembered at F500 and the second is the number of rows, remembered at F501. Each copied byte is two source bytes on from the last.
Input
DE The address of the data
CopyRectangleRows E1C5 LD A,(DE) The width of each row, remembered at F500.
E1C6 LD C,A
E1C7 LD ($F500),A
E1CA INC DE
E1CB LD A,(DE) The number of rows, remembered at F501.
E1CC LD ($F501),A
E1CF LD HL,$F502 The copy starts at F502.
CopyRectangleRows_Row E1D2 EX AF,AF' One row.
E1D3 LD B,C The width is the count for this row.
CopyRectangleRows_Byte E1D4 INC DE Copy the next byte, two source bytes on.
E1D5 INC DE
E1D6 LD A,(DE)
E1D7 LD (HL),A
E1D8 INC HL
E1D9 DJNZ CopyRectangleRows_Byte The rest of the row.
E1DB EX AF,AF' The next row.
E1DC DEC A One fewer row remains.
E1DD JR NZ,CopyRectangleRows_Row Another row.
E1DF RET Return.
