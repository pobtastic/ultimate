A8CB: Read Keyboard
Used by the routines at ShowTitleMenu, MoveMarker, PlayMusic_WaitKey, TestPauseKeys and ReadControls.
Reads the rows of the keyboard which are selected by the high byte of the port address.
Input
A The high byte of the port address (00 selects all of the rows)
Output
A The keys which are being pressed (bit set for pressed)
ReadKeyboard A8CB IN A,($FE) Read the keyboard.
A8CD CPL Invert the bits.
A8CE AND %00011111 Keep the bits for the five keys.
A8D0 RET Return.
