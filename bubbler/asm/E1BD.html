E1BD: Print Text Records
Used by the routines at ShowEnding, ShowTitleMenu, RunGame and DrawPanel.
Prints a number of text records, one after the other, with PrintText.
Input
DE The address of the first text record
B The number of text records
PrintTextRecords E1BD PUSH BC Remember BC.
E1BE CALL PrintText Call PrintText.
E1C1 POP BC Bring back BC.
E1C2 DJNZ PrintTextRecords Repeat from PrintTextRecords while B still counts.
E1C4 RET Return.
