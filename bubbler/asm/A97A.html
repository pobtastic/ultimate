A97A: Print Character
Used by the routine at PrintText.
Prints a character of a text record. The shapes of the characters are in the font at Font, and each is seven bytes with the bottom line first.
Input
DE The address of the character
HL The screen address of the bottom line of the character
Output
HL The screen address of the bottom line of the next character
PrintCharacter A97A PUSH DE Save the address of the character.
A97B LD A,(DE) Fetch the character.
A97C EX DE,HL Exchange DE and HL.
A97D PUSH DE Save the screen address.
A97E LD L,A Copy the character into L.
A97F LD H,$00 Clear H.
A981 LD D,H Clear D.
A982 ADD HL,HL Multiply the character by two...
A983 ADD HL,HL ...four...
A984 ADD HL,HL ...and eight.
A985 LD E,A Copy the character into E.
A986 SBC HL,DE Subtract it, to make seven times the character.
A988 LD DE,$64E0 Point DE at Font.
A98B ADD HL,DE Add the offset to find the shape of the character.
A98C POP DE Restore the screen address into DE.
A98D EX DE,HL Exchange DE and HL, so that DE is the shape and HL is the screen address.
A98E PUSH HL Save the screen address.
A98F LD B,$07 Set the number of lines to 07.
PrintCharacter_Patched A991 JR PrintCharacter_Patched Jump to the routine for the size of text (this is patched at A992).
PrintCharacter_Normal A993 LD A,(DE) Fetch a line of the shape.
A994 LD (HL),A Write it to the screen.
A995 INC DE Move onto the next line of the shape.
A996 CALL MoveUpALine Move up a pixel line on the screen.
A999 DJNZ PrintCharacter_Normal Jump back until all of the lines have been written.
A99B POP HL Restore the screen address.
A99C INC L Move onto the next character cell.
A99D POP DE Restore the address of the character.
A99E RET Return.
PrintCharacter_DoubleHeight A99F LD A,(DE) Fetch a line of the shape.
