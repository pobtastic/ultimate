86E5: Level Table
The addresses of the data of each level, which are found by StartLevel. There are four bytes for each level. The first address is the header of the level, which is used with the map and the path entries that are described at LevelData. The second address is not used by the game and its purpose is not yet known.

86E9 DEFW $8868,$8E16
86ED DEFW $89A0,$928B
86F1 DEFW $8976,$8EAE
