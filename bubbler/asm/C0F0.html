C0F0: Draw Left Strip
Handles an object for DrawObject when the view is scrolling to the right, so that only the objects in the strip that has just come into view on the left are drawn. The position of the object is moved across by the width of the view, B0 by the entry point at DrawLeftStrip_AddOffset.
DrawLeftStrip C0F0 LD HL,($BB9F) Fetch the position of the object in the view.
C0F3 LD DE,$00B0 Set the distance to move the object across, B0.
C0F6 LD A,H Copy the high byte of the position into A.
C0F7 CP $80 Jump to DrawLeftStrip_AddOffset if the position is below 8000.
C0F9 JR C,DrawLeftStrip_AddOffset
C0FB LD A,L Copy the low byte of the position into A.
C0FC CP $10 Compare it with 10.
C0FE RET NC Return if the object is not in the strip.
This entry point is used by the routines at DrawTopStrip and DrawBottomStrip.
DrawLeftStrip_AddOffset C0FF LD HL,($BB9F) Fetch the position of the object in the view.
C102 ADD HL,DE Add the distance to move across.
C103 LD ($BB9F),HL Store the new position.
C106 JR DrawBlock Draw the block of the object.
