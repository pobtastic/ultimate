CF30: Update Entity
Used by the routines at UpdateBasicEntity and UpdatePuffEntity.
The routine for the types 01 02 and 03 of entity, which is also jumped to by the routines for other types. Moves the entity with MoveEntity, with the entity flagged as moving, and then projects it with ProjectEntity if it is still in use.
Input
IX The entity
UpdateEntity CF30 LD A,(IX+$00) Fetch the type of the entity.
CF33 AND A Test it.
CF34 JR Z,UpdateEntity_Done Jump to UpdateEntity_Done if the entity is not in use.
CF36 SET 7,(IX+$11) Flag the entity as moving.
This entry point is used by the routines at MakeCreature, UpdatePickupEntity, UpdateGrowingBubbleEntity, ResetEntityMovement, UpdateFoamEntity, UpdateWhirlerEntity, UpdateBatEntity, UpdateDropEntity and UpdateSaucerEntity.
UpdateEntity_Move CF3A CALL MoveEntity Move the entity.
This entry point is used by the routines at MakeEntitySound, UpdateBurstEntity, UpdateSparkleEntity, UpdateShotEntity and UpdateDomeEntity.
UpdateEntity_Project CF3D LD A,(IX+$00) Fetch the type of the entity.
CF40 AND A Test it.
CF41 CALL NZ,ProjectEntity Work out the screen position if the entity is still in use.
This entry point is used by the routines at UpdateBurstEntity, UpdateSpiderEntity, UpdateDiscEntity, UpdateSparkleEntity and UpdatePuffEntity.
UpdateEntity_Done CF44 POP IX Restore the entity.
Continue on to UpdateNextEntity.
