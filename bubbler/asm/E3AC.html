E3AC: Draw Frame Left
Used by the routine at DrawFrame.
Draws a vertical line of the frame, by setting the bytes of the screen to 3C. The entry point at DrawFrameLeft_Draw draws it from an address that is already in HL.
Input
HL The position of the line
IX The entry of the frame
DrawFrameLeft E3AC CALL GetScreenAddress Convert the position into a screen address.
DrawFrameLeft_Move E3AF DEC L Move one byte to the left, beside the frame.
This entry point is used by the routine at DrawFrame.
DrawFrameLeft_Draw E3B0 LD B,(IX+$03) Fetch the height of the frame in pixel lines.
E3B3 PUSH HL Save the screen address.
DrawFrameLeft_Loop E3B4 LD (HL),$3C Draw a pixel line of the edge.
E3B6 CALL MoveUpALine Move up a pixel line.
E3B9 DJNZ DrawFrameLeft_Loop Repeat until the whole edge is drawn.
E3BB POP HL Restore the screen address.
E3BC RET Return.
