A51C: Scroll Time Out Message
Used by the routine at RunFrame.
Scrolls the message 'TIME OUT' across the window, one frame at a time.
ScrollTimeOutMessage A51C LD HL,$FF0E Set the scroll counter to 0E and the character index to FF.
A51F LD ($A921),HL Store them in ScrollCounter and A922.
A522 LD A,$08 Set the length of the message to 08...
A524 LD ($A572),A ...in the operand of the instruction at A571.
ScrollTimeOutMessage_Loop A527 LD IY,($5CF1) Bring back IY from SavedIY.
A52B EI Enable interrupts...
A52C HALT ...and wait for the next frame.
A52D DI Disable interrupts.
A52E LD HL,$A53C Point HL at TimeOutMessage.
A531 CALL ScrollMessage Scroll the message by one step.
A534 LD A,($A922) Fetch the character index from A922.
A537 CP $11 Compare it with 11.
A539 RET Z Return if the message has gone.
A53A JR ScrollTimeOutMessage_Loop Jump back to scroll the message another step.
