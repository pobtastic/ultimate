726A: Tile: Block Faces One
The tiles that are drawn by C5E5, which are shapes for the faces of the blocks of the level. Each starts with a flag that records whether it has been flipped by FlipBlockData, and then has a mask byte and a picture byte for each of the two bytes of the width in each row, from the top row down. The names of the tiles are only descriptions of how they look.
