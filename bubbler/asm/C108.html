C108: Draw Top Strip
Handles an object for DrawObject when the view is scrolling down, so that only the objects in the strip that has just come into view at the top are drawn.
DrawTopStrip C108 CALL GetSizeOffset Find the position of the object in the view, with its size offset.
C10B LD A,H Copy the high byte of the position into A.
C10C CP $80 Compare it with 80.
C10E LD DE,$0010 Set the distance to move the object down, 10.
C111 JR NZ,DrawLeftStrip_AddOffset Draw the object, after moving it, if the high byte is not 80.
C113 LD A,L Copy the low byte of the position into A.
C114 CP $08 Compare it with 08.
C116 RET NC Return if the object is not in the strip.
C117 JR DrawLeftStrip_AddOffset Draw the object, after moving it.
