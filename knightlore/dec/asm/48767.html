48767: Print Character
Used by the routines at PrintBCDNumber and PrintText.
Prints one character in the screen buffer. A character is eight bytes, one for each row from the top. The rows of the screen buffer run from the bottom up, so the rows are stored 32 bytes apart and going down. The font is the one that FontPointer points to.
Input
A Number of the character
HL Address in the screen buffer of the top row
Output
HL Address in the screen buffer of the top row of the next character
PrintCharacter 48767 PUSH BC Stash BC.
48768 PUSH DE Stash DE.
48769 PUSH HL Stash the address in the screen buffer.
48770 LD L,A Copy the number of the character into L.
48771 LD H,0 Clear H.
48773 ADD HL,HL Multiply it by eight.
48774 ADD HL,HL
48775 ADD HL,HL
48776 LD DE,(23495) Fetch the address of the font.
48780 ADD HL,DE Find the data of the character.
48781 EX DE,HL Point DE at it.
48782 POP HL Restore the address in the screen buffer.
48783 LD B,8 Set the number of rows to 8.
PrintCharacter_NextRow 48785 LD A,(DE) Fetch a row of the character.
48786 LD (HL),A Put it in the screen buffer.
48787 INC DE Move on to the next row of the character.
48788 PUSH BC Stash the counter.
48789 LD BC,65504 Set BC to 65504 which is minus the length of a line of the screen buffer.
48792 ADD HL,BC Move down a row in the screen buffer.
48793 POP BC Restore the counter.
48794 DJNZ PrintCharacter_NextRow Jump back to PrintCharacter_NextRow until all of the rows have been done.
48796 POP DE Restore DE.
48797 LD BC,257 Set BC to eight lines up and one byte along.
48800 ADD HL,BC Move to the top row of the next character.
48801 POP BC Restore BC.
48802 RET Return.
