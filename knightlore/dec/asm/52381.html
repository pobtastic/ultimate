52381: Test Overlap In X
Used by the routines at TestObjectIntersections, TestObjectCanBePickedUp, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether two objects overlap in X, once the first has moved by its new speed in X. They overlap when the distance between the X coordinates is smaller than the two widths added together.
Input
C New speed in X of the first object
IX Address of the first object
IY Address of the second object
Output
F The carry flag is set if the objects overlap
TestOverlapInX 52381 LD A,(IX+4) Add the width of the first object to the width of the second object.
52384 ADD A,(IY+4)
52387 LD D,A Stash the total in D.
52388 LD A,(IX+1) Take the X coordinate of the second object off the X coordinate of the first object plus the new speed.
52391 ADD A,C
52392 SUB (IY+1)
52395 JP P,TestOverlapInX_TakeWidths Jump to TestOverlapInX_TakeWidths if it is not negative.
52398 NEG Make it positive.
TestOverlapInX_TakeWidths 52400 SUB D Take the total widths off it, which sets the carry flag if the objects overlap.
52401 RET Return.
