51077: Nudge Objects To Arch
Used by the routine at HandleNearArch.
Nudges the player and the special objects towards the middle of a doorway, if they are close enough to the arch and are flagged to be adjusted. The way in which they are nudged is picked from the table at ArchDirectionTable, by the direction in which the arch faces.
Input
IX Address of the arch object
Nudge each nearby object towards the middle of the doorway.
NudgeObjectsToArch 51077 LD HL,3855 Set the distances that count as near to 15 in X and in Y.
51080 LD IY,23560 Point IY at ObjectsTable.
51084 LD DE,32 Set DE to the size of an object.
51087 LD B,4 Set the number of objects to 4, which is the player and the special objects.
This entry point is used by the routine at NudgeObjectNorthSouth.
