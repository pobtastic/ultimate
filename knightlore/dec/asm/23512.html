23512: Objects Carried
The objects that the player is carrying. There is a place for four of them, each with four bytes, but the first is only used while an object is being picked up, so that the player can carry three. The last of the three is the one that has been carried for longest, and the one that is dropped first.
Byte Contents
0 The graphic number of the object, or 0 if there is not one
1 The flags of the object
2-3 The address of the object in the table of special objects
ObjectsCarried 23512 DEFB 0,0,0,0 The object that has just been picked up.
ObjectsCarried_Newest 23516 DEFB 0,0,0,0 The object that has been carried for the least time.
23520 DEFB 0,0,0,0 The object that has been carried for a time between the others.
ObjectsCarried_Oldest 23524 DEFB 0,0,0,0 The object that has been carried for the longest time.
