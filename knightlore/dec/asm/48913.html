48913: Handle Last Appearing Sparkle
Handles the last of the sparkles that show the player appearing. The object turns into the player, who is no longer dead, and is updated as the player right away.
Input
IX Address of the sparkle object
HandleLastAppearingSparkle 48913 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
48916 RES 6,(IX+13) Clear the flag that says the player is dead.
48920 LD A,(IX+16) Fetch the graphic number of the player.
48923 LD (IX+0),A Make it the graphic number of the object.
48926 JP RunGame_UpdateObject Update the object as the player.
