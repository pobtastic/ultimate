53845: Draw Panel
Used by the routine at RunGame.
Draws the shapes of the panel at the bottom of the screen, using the sprites in the table at PanelSprites. On each side there is a run of five sprites that go up or down in steps, followed by two more sprites. The right side is the left side flipped.
After DrawPanel and UpdateScreen
Draw the left side of the panel, then the flipped right side.
DrawPanel 53845 LD IX,49115 Point IX at the object that holds the details of the sprites of the panel, PanelObject.
53849 LD HL,53886 Point HL at PanelSprites.
53852 CALL SetSpriteDetails Set the details of the first sprite.
53855 LD DE,63504 Set the offsets to 16 in X and 248 in Y, which is 8 down.
53858 LD B,5 Set the number of sprites to 5.
53860 CALL PrintSprites Draw the run of sprites on the left.
53863 CALL PrintTableSprite Draw the second sprite on the left.
53866 CALL PrintTableSprite Draw the third sprite on the left.
53869 CALL SetSpriteDetails Set the details of the first sprite on the right.
53872 LD DE,2064 Set the offsets to 16 in X and 8 in Y, which is 8 up.
53875 LD B,5 Set the number of sprites to 5.
53877 CALL PrintSprites Draw the run of sprites on the right.
53880 CALL PrintTableSprite Draw the second sprite on the right.
53883 JP PrintTableSprite Jump to PrintTableSprite.
