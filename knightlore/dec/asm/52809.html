52809: Save Sprite Info
Used by the routine at RunGame.
Keeps the size and the pixel coordinates of the sprite of an object as its old values, so that the area that it covered can be redrawn when it moves.
Input
IX Address of the object
SaveSpriteInfo 52809 LD A,(IX+24) Save the width of the sprite in bytes.
52812 LD (IX+28),A
52815 LD A,(IX+25) Save the height of the sprite in lines.
52818 LD (IX+29),A
52821 LD A,(IX+26) Save the pixel X coordinate.
52824 LD (IX+30),A
52827 LD A,(IX+27) Save the pixel Y coordinate.
52830 LD (IX+31),A
52833 RET Return.
