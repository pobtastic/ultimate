53815: Set Sprite Details
Used by the routines at PrintTableSprite, DrawPanel and PrintBorder.
Sets the graphic number, the flags and the pixel coordinates of an object from four bytes of data.
Input
HL Address of the data
IX Address of the object
Output
HL Address of the byte after the data
SetSpriteDetails 53815 LD A,(HL) Fetch the graphic number and move on.
53816 INC HL
53817 LD (IX+0),A Set the graphic number of the object.
53820 LD A,(HL) Fetch the flags and move on.
53821 INC HL
53822 LD (IX+7),A Set the flags of the object.
53825 LD A,(HL) Fetch the pixel X coordinate and move on.
53826 INC HL
53827 LD (IX+26),A Set the pixel X coordinate of the object.
53830 LD A,(HL) Fetch the pixel Y coordinate and move on.
53831 INC HL
53832 LD (IX+27),A Set the pixel Y coordinate of the object.
53835 RET Return.
