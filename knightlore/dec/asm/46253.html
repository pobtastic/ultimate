46253: Play Guard Footsteps Sound
Used by the routine at HandleGuardBottomHalf.
Plays the footsteps of a guard or the wizard, but only on every other frame of the walking animation. It carries on into PlayFootstepsSound_Position with a fixed pitch.
Input
IX Address of the object
PlayGuardFootstepsSound 46253 LD A,(IX+0) Fetch the graphic number of the object.
46256 AND %00000001 Test whether it is an odd frame of the animation.
46258 RET NZ Return if it is.
46259 LD B,128 Set the pitch.
46261 LD A,(23458) Fetch the frame counter.
46264 CPL Invert it.
46265 JR PlayFootstepsSound_Position Jump to PlayFootstepsSound_Position.
