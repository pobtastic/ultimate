24832: Game Entry Point
The first instruction run by the tape loader once the game has been loaded. The game uses 23456 as the top of its stack, so the stack grows down into the printer buffer, and then it jumps to StartGame to start a new game.
GameEntry 24832 DI Disable interrupts.
24833 LD SP,23456 Set the stack pointer to 23456.
24836 NOP No operation.
24837 JP StartGame Jump to StartGame.
