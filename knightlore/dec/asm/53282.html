53282: Read Controls
Used by the routine at HandlePlayerLegs.
Reads the controls that the player is using and stores them in ControlsPressed.
Bit Meaning
0 Left
1 Right
2 Walk
3 Jump
4 Pick up (or down on a directional stick)
5 Directional pick up
No control is read during the final animation or while an object is being put into the cauldron.
Output
C The controls
Jump to the reader for the chosen control method.
ReadControls 53282 LD A,(23491) Fetch the final animation flag from FinalAnimationFlag.
53285 LD C,A Stash it in C.
53286 LD A,(23492) Fetch the flag for an object being put into the cauldron from ObjectInCauldronFlag.
53289 OR C Combine the two flags.
53290 LD C,0 Set the controls to none.
53292 JP NZ,ReadControls_Finish Jump to ReadControls_Finish if either flag is set.
53295 LD A,(23460) Fetch the control method from ControlMethod.
53298 RRCA Move the keyboard and joystick choice into bits 0 and 1.
53299 AND %00000011 Keep it.
53301 JP Z,ReadKeyboard Jump to ReadKeyboard if the keyboard is in use.
53304 DEC A Test for the Kempston joystick.
53305 JR Z,ReadKempstonJoystick Jump to ReadKempstonJoystick if it is in use.
53307 DEC A Test for the cursor joystick.
53308 JR Z,ReadCursorJoystick Jump to ReadCursorJoystick if it is in use.
