53282: Read Controls
Used by the routine at HandlePlayerLegs.
Reads the controls that the player is using. The controls are made into a byte in C, with bit 0 for left, bit 1 for right, bit 2 for walking forward, bit 3 for jumping, bit 4 for picking up and dropping an object (or for down, if a joystick with directional control is in use) and bit 5 for picking up and dropping an object with directional control. The byte is stored at ControlsPressed. No control is read during the final animation or while an object is being put into the cauldron.
