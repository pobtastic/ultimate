45786: Play Note
Used by the routines at PlayMusic_WaitKey and PlayMusic.
Plays one note of a tune, or pauses for the length of the note if it is a rest. The note is a square wave made by switching the speaker on and off, so the game is stopped while it plays. Bits 0-5 of the note are the number of the note (see MusicNotes), and bits 6-7 are the length of the note, which is one to four times the basic length of the note.
Input
A The note
DE Address of the note
Output
DE Address of the next note
PlayNote 45786 AND %00111111 Isolate the number of the note.
45788 JR Z,PlayNote_Rest Jump to PlayNote_Rest if it is a rest.
Look up the delays and the number of cycles in the table at MusicNotes.

45791 LD H,0
45793 ADD HL,HL
45794 CALL AddAToHL

Bits 6 and 7 of the note are the length, less one.

45810 RLCA

45816 LD D,H
Multiply the number of cycles by the length of the note.

45820 ADD HL,DE Add the basic length to the total.
45821 JR PlayNote_Multiply Jump back to PlayNote_Multiply.
PlayNote_MultiplyDone 45823 POP DE Restore the address of the note.
Each pass of this loop makes one cycle of the note, so the length of the note is the number of cycles.
PlayNote_Cycle 45824 PUSH BC Save the delay.
45825 XOR A Switch the speaker off.
45826 OUT (254),A
PlayNote_OffDelay 45828 DJNZ PlayNote_OffDelay Wait with the speaker off, using the first byte of the delay for the first pass and 256 for each pass after it.
45830 DEC C Decrease the second byte of the delay and jump back to PlayNote_OffDelay until it is zero.
45831 JR NZ,PlayNote_OffDelay
45833 POP BC Restore the delay, and save it again.
45834 PUSH BC
45835 LD A,16 Switch the speaker on.
45837 OUT (254),A
PlayNote_OnDelay 45839 DJNZ PlayNote_OnDelay Wait with the speaker on for the same length of time.
45841 DEC C Decrease the second byte of the delay and jump back to PlayNote_OnDelay until it is zero.
45842 JR NZ,PlayNote_OnDelay
45844 POP BC Restore the delay.
45845 DEC HL Decrease the number of cycles left to play.
45846 LD A,H Jump back to PlayNote_Cycle until there are none left.
45847 OR L
45848 JR NZ,PlayNote_Cycle
45850 INC DE Point at the next note.
45851 RET Return.
A rest is a silent pause, which is made by waiting one to four times.
PlayNote_Rest 45852 LD A,(DE) Fetch the length of the rest.
45853 INC DE Point at the next note.

45855 RLCA
45856 AND %00000011 Isolate the length of the rest.
45858 INC A Make it one to four.
45859 LD L,A Set the number of times to wait in L.
45860 LD BC,17163 Set the length of the wait.
PlayNote_RestUnit 45863 PUSH BC Save the length of the wait.
PlayNote_RestDelay 45864 DEC BC Decrease the length of the wait.

45866 OR C
45867 JR NZ,PlayNote_RestDelay
