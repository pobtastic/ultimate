52402: Test Overlap In Y
Used by the routines at TestObjectIntersections, TestObjectCanBePickedUp, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether two objects overlap in Y, once the first has moved by its new speed in Y. They overlap when the distance between the Y coordinates is smaller than the two depths added together.
Input
L New speed in Y of the first object
IX Address of the first object
IY Address of the second object
Output
F The carry flag is set if the objects overlap
TestOverlapInY 52402 LD A,(IX+5) Add the depth of the first object to the depth of the second object.
52405 ADD A,(IY+5)
52408 LD D,A Stash the total in D.
52409 LD A,(IX+2) Take the Y coordinate of the second object off the Y coordinate of the first object plus the new speed.
52412 ADD A,L
52413 SUB (IY+2)
52416 JP P,TestOverlapInY_TakeDepths Jump to TestOverlapInY_TakeDepths if it is not negative.
52419 NEG Make it positive.
TestOverlapInY_TakeDepths 52421 SUB D Take the total depths off it, which sets the carry flag if the objects overlap.
52422 RET Return.
