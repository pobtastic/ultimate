48521: Flash Menu Options
Used by the routine at GameMenu.
Makes the line for the chosen control method flash, and does the same to the line for the directional control if it is on. The flashing of all of the other lines is switched off.
FlashMenuOptions 48521 LD HL,48547 Point HL at the colour of the line for the keyboard.
48524 LD A,(23460) Fetch the control method.
48527 RRCA Move the choice of control method into the lowest two bits.
48528 AND %00000011 Keep only the choice.
48530 LD B,4 Set the number of control methods to 4.
48532 CALL SetFlashingAttribute Make the chosen line flash and stop the rest from flashing.
48535 RES 7,(HL) Stop the line for the directional control from flashing.
48537 LD A,(23460) Fetch the control method.
48540 AND %00001000 Keep the bit for the directional control.
48542 RET Z Return if the directional control is off.
48543 SET 7,(HL) Make the line for the directional control flash.
48545 RET Return.
