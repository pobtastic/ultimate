54985: Calculate Pixel Coordinates
Used by the routines at HandlePickupAndDrop, CalculateSpriteSize and DrawObject.
Works out the pixel coordinates of an object on the screen from its X, Y and Z coordinates. The pixel X coordinate is X + Y - 128 and the pixel Y coordinate (from the bottom of the screen) is half of Y - X + 128 plus Z, less 104 each with the adjustments of the object added.
Input
IX Address of the object
Output
F The carry flag is set if the sprite is on the screen, and reset if
it is off the top
