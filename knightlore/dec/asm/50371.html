50371: Handle Table
Handles a table, which falls when there is nothing below it. It plays the sound of a moving object, and is drawn again, only when it is moving, with its speeds in X and Y cleared.
Input
IX Address of the table object
HandleTable 50371 CALL SetPixelAdjustments_Block Set the pixel adjustments of a block.
This entry point is used by the routine at HandleExtraLife.
HandleTable_Fall 50374 CALL ApplyGravityAndMove Apply gravity to the object and move it.
50377 CALL TestObjectMoving Test whether the object is moving.
50380 RET Z Return if it is not.
50381 CALL MovePlayer_Stop Clear the speeds in X and Y.
50384 JP DrawMovingObject Play the sound of a moving object and flag the object to be drawn again.
