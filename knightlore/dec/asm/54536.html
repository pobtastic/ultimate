54536: Clear Bytes
Used by the routines at HandlePickupAndDrop, PlaceSpecialObjectsInRoom, ClearRemainingObjects and MakeRoomObjects.
Fills a number of bytes with zero. The entry point at FillBytes fills them with the byte in A.
Input
B Number of bytes
DE Address of the first byte
ClearBytes 54536 XOR A Set A to 0.
This entry point is used by the routine at PrintLivesGraphic.
FillBytes 54537 LD (DE),A Write A.
54538 INC DE Increment DE.
54539 DJNZ FillBytes Jump to FillBytes until all of the bytes are filled.
