45758: Play Music Until Key Pressed
Used by the routine at GameOver.
Plays the tune that DE points at, one note at a time, and stops as soon as any key is pressed. The keyboard is only checked between notes.
Input
DE Address of the tune
PlayMusic_WaitKey 45758 XOR A Select every row of the keyboard.
45759 CALL ReadKeyboardPort Read the keyboard.
45762 JR Z,PlayMusic_WaitKey_Process Jump to PlayMusic_WaitKey_Process if no key is being pressed.
45764 RET Return, as a key has been pressed.
PlayMusic_WaitKey_Process 45765 LD A,(DE) Fetch the next note of the tune.
45766 CP 255 Jump to PlayMusic_Return if it is the end marker.
45768 JR Z,PlayMusic_Return
45770 CALL PlayNote Play the note.
45773 JR PlayMusic_WaitKey Jump back to PlayMusic_WaitKey for the next note.
