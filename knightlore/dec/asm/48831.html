48831: Display Text List
Used by the routines at GameOver and GameCompleted.
Prints a list of lines of text in the screen buffer, each in its own colour. If the border has not been drawn yet, it is drawn and the screen buffer is copied to the display.
Input
B Number of lines
DE Address of the text
HL Address of the coordinates of the lines (X and Y for each line)
DE' Address of the attributes of the lines
DisplayTextList 48831 EXX Switch to the registers that hold the attributes.
48832 LD A,(DE) Fetch the attribute of the line.
48833 LD (23478),A Store it as the attribute to print with.
48836 INC DE Move on to the next attribute.
48837 EXX Switch back.
48838 PUSH BC Stash the number of lines.
48839 LD A,(HL) Fetch the X coordinate.
48840 INC HL Move on to the next pair of coordinates.
48841 INC HL
48842 PUSH HL Stash the address of the next pair.
48843 DEC HL Point HL at the Y coordinate.
48844 LD H,(HL) Fetch the Y coordinate.
48845 LD L,A Set the X coordinate.
48846 CALL PrintTextSingleColour Print the line.
48849 POP HL Restore the address of the next pair.
48850 POP BC Restore the number of lines.
48851 DJNZ DisplayTextList Jump back to DisplayTextList until all of the lines have been printed.
48853 LD A,(23480) Fetch the flag that says the border has been drawn.
48856 AND A Test it.
48857 RET NZ Return if it has.
48858 INC A Set the flag.
48859 LD (23480),A Store it.
48862 CALL PrintBorder Draw the border.
48865 JP UpdateScreen Copy the screen buffer to the display.
