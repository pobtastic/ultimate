50302: Initialise Special Objects
Used by the routine at InitialiseGame.
Chooses which objects are placed where, at the start of each game. Every entry in the table of special objects gets a graphic number from 96 to 103 one after another from a number that comes from the first random seed and the refresh register, and the place that the object starts in is copied to the place that it is in now.
InitialiseSpecialObjects 50302 LD HL,28658 Point HL at the first special object.
50305 LD A,(23456) Fetch the first random seed.
50308 LD E,A Stash it in E.
50309 LD A,R Fetch a random number from the refresh register.
50311 ADD A,E Add the seed.
50312 LD E,A Stash the result in E.
InitialiseSpecialObjects_Next 50313 LD A,E Copy the number into A.
50314 AND %00000111 Keep the lowest three bits.
50316 OR %01100000 Make it a graphic number from 96 to 103.
50318 LD (HL),A Set the graphic number of the object.
50319 INC HL Move on to the starting position.
50320 INC E Change the number, for the next object.
50321 PUSH DE Stash it.
50322 EX DE,HL Point DE at the starting position.
50323 LD HL,4 Set HL to the offset of the current position.
50326 ADD HL,DE Point HL at the current position.
50327 EX DE,HL Point DE at the current position.
50328 LD BC,4 Set the number of bytes to copy to 4.
50331 LDIR Copy the starting position to the current position.
50333 EX DE,HL Point HL at the next object.
50334 PUSH HL Stash it.
50335 LD BC,28946 Point BC at the end of the table.
50338 AND A Subtract the address of the end of the table.
50339 SBC HL,BC
50341 POP HL Restore the address of the next object.
50342 POP DE Restore the number.
50343 JR C,InitialiseSpecialObjects_Next Jump back to InitialiseSpecialObjects_Next until every object has been done.
50345 RET Return.
