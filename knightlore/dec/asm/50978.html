50978: Handle Far Arch
Handles the graphic numbers 3 and 5 which are the far side of an arch. They only need the pixel adjustments of the sprite, which are not the same when the sprite is flipped.
Input
IX Address of the arch object
HandleFarArch 50978 BIT 6,(IX+7) Jump to AdjustFlippedFarArch if the arch is flipped horizontally.
50982 JR NZ,AdjustFlippedFarArch
50984 LD HL,65015 Set the adjustments of 247 in X and 253 in Y.
