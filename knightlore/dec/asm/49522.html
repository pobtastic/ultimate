49522: Test Object Can Be Picked Up
Used by the routine at HandlePickupAndDrop.
Tests whether an object is a special object that the player is on or close to. The routine continues at TestNearObject.
Input
IX Address of the player
IY Address of the object
Output
F Carry flag set if the object can be picked up
TestObjectCanBePickedUp 49522 LD A,(IY+0) Fetch the graphic number of the object.
49525 SUB 96 Take off the graphic number of the first special object.
49527 CP 7 Compare it with the number of special objects.
49529 RET NC Return if the object is not a special object.

49531 LD BC,0 Set the offset in X to zero.

49535 LD H,C
