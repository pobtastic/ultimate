53157: Compare With Other Object
Handles the other object having to be drawn first. It becomes the first object, and the comparisons start again from the beginning of the list. The objects that have taken the place of the first object are kept in the list at ObjectChain. If the other object is already there the objects hold each other up, and the other object is drawn to break the loop.
Input
IY Address of the other object
Draw the other object first, or break a loop if it is already in the chain.
