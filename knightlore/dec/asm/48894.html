48894: Handle Player Appearing
Handles the sparkles that show the player appearing, which go through the graphic numbers 120 to 126. The graphic changes on every other frame, and each change makes a sound. The last sparkle is handled by HandleLastAppearingSparkle.
Input
IX Address of the sparkle object
HandlePlayerAppearing 48894 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
48897 LD A,(23458) Fetch the frame counter.
48900 CPL Invert it.
48901 AND %00000001 Keep the lowest bit.
48903 RET NZ Return on every other frame.
48904 INC (IX+0) Change to the next graphic.
48907 CALL PlayAppearingSound Play the sound of the player appearing.
48910 JP SetWipeAndDrawFlags Flag the object to be drawn again.
