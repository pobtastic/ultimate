54542: Pause Game
Used by the routine at RunGame.
Pauses the game if CAPS SHIFT or SPACE is pressed on its own. The game waits for the key to be let go of, then for it to be pressed again and let go of again. There is a beep for the start and for the end of the pause.
Return unless CAPS SHIFT or SPACE is pressed on its own.
PauseGame 54542 LD A,126 Read from the keyboard;
Port Number Bit
0 1 2 3 4
126 SHIFT / SPACE Z / SYM X / M C / N V / B
54544 CALL ReadKeyboardPort
54547 BIT 0,A Return if neither CAPS SHIFT nor SPACE is pressed.
54549 RET Z
54550 AND %00011110 Keep bits 1 to 4.
54552 RET NZ Return if any of them is pressed.
Wait for the key to be released.
PauseGame_Release 54553 LD A,126 Read from the keyboard;
Port Number Bit
0 1 2 3 4
126 SHIFT / SPACE Z / SYM X / M C / N V / B
54555 CALL ReadKeyboardPort
54558 BIT 0,A Jump to PauseGame_Release while CAPS SHIFT or SPACE is pressed.
54560 JR NZ,PauseGame_Release
54562 CALL PlayMiddleBeep Play the sound of the pause.
Wait for the key to be pressed.
