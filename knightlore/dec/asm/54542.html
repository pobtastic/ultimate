54542: Pause Game
Used by the routine at RunGame.
Pauses the game if the SPACE key is pressed on its own. The game waits for the key to be let go of, then for it to be pressed again and let go of again. There is a sound for the start and for the end of the pause.
PauseGame 54542 LD A,126 Read the keys SPACE, symbol shift, M, N and B.
54544 CALL ReadKeyboardPort
54547 BIT 0,A Test the SPACE key.
54549 RET Z Return if it is not pressed.
54550 AND %00011110 Keep the other keys.
54552 RET NZ Return if any of them is pressed.
PauseGame_Release 54553 LD A,126 Read the keys.
54555 CALL ReadKeyboardPort
54558 BIT 0,A Jump back to PauseGame_Release while it is pressed.
54560 JR NZ,PauseGame_Release
54562 CALL PlayMiddleBeep Play the sound of the pause.
PauseGame_Wait 54565 LD A,126 Read the keys.
54567 CALL ReadKeyboardPort
54570 BIT 0,A Jump back to PauseGame_Wait until it is pressed.
54572 JR Z,PauseGame_Wait
PauseGame_Finish 54574 LD A,126 Read the keys.
54576 CALL ReadKeyboardPort
54579 BIT 0,A Jump back to PauseGame_Finish while it is pressed.
54581 JR NZ,PauseGame_Finish
54583 JP PlayMiddleBeep Jump to PlayMiddleBeep.
