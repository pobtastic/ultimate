52445: Keep Object In Room In X
Used by the routine at BlockMovement.
Brings the speed in X of an object closer to zero until the object stays within the walls of the room. Nothing is done while the object is entering the room, or while it is near an arch, as it can then go out through the wall.
Input
C Speed in X
IX Address of the object
Output
C The new speed in X
