48716: Print Text
Used by the routine at PrintDayCaption.
Prints a line of text in the screen buffer, using the font that is pointed to by FontPointer. The first byte of the text is the attribute of the line. The attribute of each character is set on the screen at once. The coordinates are the Y coordinate (in the high byte) and the X coordinate, which are expected to be on the stack. The Y coordinate is at the top of the character.
Input
DE Address of the text
PrintText 48716 POP BC Fetch the coordinates.
48717 PUSH BC Stash them again.
48718 CALL CalculateBufferAddress Find the address in the screen buffer.
48721 LD L,C Copy it to HL.
48722 LD H,B
48723 LD A,(DE) Fetch the attribute.
48724 EX AF,AF' Keep it in AF'.
48725 INC DE Point DE at the first character.
