48803: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute 48803 AND A Jump to SetFlashingAttribute_Steady if the line is not the first.
48804 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash 48806 SET 7,(HL) Set bit 7 of the attribute.
48808 JR SetFlashingAttribute_Advance Jump to SetFlashingAttribute_Advance.
SetFlashingAttribute_NextLine 48810 DEC A Jump to SetFlashingAttribute_Flash if this is the line.
48811 JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady 48813 RES 7,(HL) Reset bit 7 of the attribute.
SetFlashingAttribute_Advance 48815 INC HL Move on to the next line.
48816 DJNZ SetFlashingAttribute_NextLine Jump to SetFlashingAttribute_NextLine until all of the lines have been done.
48818 RET Return.
