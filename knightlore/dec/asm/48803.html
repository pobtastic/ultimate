48803: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Switches on the flashing (bit 7) of one in a list of attributes and switches it off for all of the others.
Input
A Position in the list of the attribute that is to flash
B Number of attributes in the list
HL Address of the list
Output
HL Address just beyond the list
SetFlashingAttribute 48803 AND A Test the position.
48804 JR NZ,SetFlashingAttribute_Steady Jump to SetFlashingAttribute_Steady if it is not the first.
SetFlashingAttribute_Flash 48806 SET 7,(HL) Switch on the flashing of the attribute.
48808 JR SetFlashingAttribute_Advance Jump to SetFlashingAttribute_Advance.
SetFlashingAttribute_NextLine 48810 DEC A Count down to the attribute that flashes.
48811 JR Z,SetFlashingAttribute_Flash Jump to SetFlashingAttribute_Flash if this is it.
SetFlashingAttribute_Steady 48813 RES 7,(HL) Switch off the flashing of the attribute.
SetFlashingAttribute_Advance 48815 INC HL Move on to the next attribute.
48816 DJNZ SetFlashingAttribute_NextLine Jump back to SetFlashingAttribute_NextLine until the whole list has been done.
48818 RET Return.
