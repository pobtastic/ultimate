27922: Background Types
The objects that make up each type of background object, which are in the table at BackgroundTypeTable. A list has a group of eight bytes for every object, which ends with a zero byte. The bytes of an object are described by this table.
Byte Contents
0 The graphic number
1-3 The X, Y and Z coordinates
4-6 The width, depth and height
7 The flags
