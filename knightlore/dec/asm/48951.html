48951: Handle Vanishing Object Sparkles
Handles the graphic numbers 185 to 187 which are for sparkles of an object that is going away for good. The entry in the table that the object points to is cleared, and then the object is removed in the same way as the last of the death sparkles.
Input
IX Address of the sparkle object
HandleVanishingObjectSparkles 48951 LD L,(IX+16) Fetch the low byte of the address of the table entry that the object comes from.
48954 LD H,(IX+17) Fetch the high byte.
48957 LD (HL),0 Clear the graphic number of that entry.
Remove the last of the death sparkles.
HandleLastDeathSparkle 48959 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
48962 JP HandleRepelSpell_Vanish Remove the object.
