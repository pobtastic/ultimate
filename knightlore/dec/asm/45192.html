45192: Reset Wipe Flags
Used by the routine at RunGame.
Clears the wipe flag (bit 5 of the flags byte) of every object in the objects table, now that the whole screen has been redrawn.
ResetWipeFlags 45192 LD B,40 Set B to the number of objects in the table.
45194 LD DE,32 Set DE to the size of an object.
45197 LD HL,23567 Point HL at the flags byte of the first object.
ResetWipeFlags_Loop 45200 RES 5,(HL) Reset the wipe flag of the object.
45202 ADD HL,DE Move on to the flags byte of the next object.
45203 DJNZ ResetWipeFlags_Loop Decrease the object counter and loop back to ResetWipeFlags_Loop until all of the objects have been done.
45205 RET Return.
