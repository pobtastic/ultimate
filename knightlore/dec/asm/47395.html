47395: Handle Special Object In Cauldron
Handles the graphics 168 to 175 which show the object that is needed next above the cauldron. The object lasts for a single frame, as it is changed back to the bubbles.
Input
IX Address of the object
HandleSpecialObjectInCauldron 47395 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
47398 LD (IX+0),160 Change the graphic of the object to the bubbles.
47402 JR HandleCauldronBubbles_Draw Jump to HandleCauldronBubbles_Draw.
