53910: Print Border
Used by the routines at GameOver and DisplayTextList.
Draws the border around the playing area, using the sprites in the table at BorderSprites. The four corners are drawn first, then the top and bottom edges, which are each made of 24 sprites that are eight pixels wide, and the left and right edges, which are each made of 128 sprites that are one pixel high.
PrintBorder 53910 LD IX,49115 Point IX at the object that holds the details of the sprites of the panel.
53914 LD HL,53967 Point HL at BorderSprites.
53917 CALL PrintTableSprite Draw the top left corner.
53920 CALL PrintTableSprite Draw the top right corner.
53923 CALL PrintTableSprite Draw the bottom right corner.
53926 CALL PrintTableSprite Draw the bottom left corner.
53929 CALL SetSpriteDetails Set the details of the top edge.
53932 LD DE,8 Set the offsets to 8 in X and 0 in Y.
53935 LD B,24 Set the number of sprites to 24.
53937 CALL PrintSprites Draw the top edge.
53940 CALL SetSpriteDetails Set the details of the bottom edge.
53943 LD B,24 Set the number of sprites to 24.
53945 CALL PrintSprites Draw the bottom edge.
53948 CALL SetSpriteDetails Set the details of the left edge.
53951 LD DE,256 Set the offsets to 0 in X and 1 in Y.
53954 LD B,128 Set the number of sprites to 128.
53956 CALL PrintSprites Draw the left edge.
53959 CALL SetSpriteDetails Set the details of the right edge.
53962 LD B,128 Set the number of sprites to 128.
53964 JP PrintSprites Jump to PrintSprites.
