48929: Start Death Sparkles
Used by the routines at HandleTransformation, HandlePlayerLegs and HandlePlayerTop.
Turns the object into the first of the sparkles that show the player dying, which go through the graphic numbers 112 to 118.
Input
IX Address of the object
StartDeathSparkles 48929 LD (IX+0),112 Set the graphic number to 112.
48933 SET 1,(IX+7) Flag the object to be ignored in the 3D calculations.
48937 JR HandleDeathSparkles_Draw Jump to HandleDeathSparkles_Draw.
