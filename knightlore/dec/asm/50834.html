50834: Set Wipe And Draw Flags

Flags an object to be wiped and drawn again, and flags every other object that overlaps it to be drawn too.
Input
IX Address of the object
SetWipeAndDrawFlags 50834 LD A,(IX+7) Fetch the flags of the object.

50839 LD (IX+7),A Store the flags.
