51955: Leave Room To The East
Sends the player to the room to the east if it has gone past the east edge of the room. The X coordinate is set to 255 which PlacePlayerAtDoor takes as the sign that the player has come out of the east, and so puts it at the west side of the new room.
Input
HL The size of the room in X and Y
IX Address of the object
LeaveRoomToEast 51955 POP HL Unstack the size of the room in X and Y.
51956 LD A,L Work out the coordinate of the east edge of the room.
51957 ADD A,128
51959 LD L,A
51960 LD A,(IX+1) Add the speed in X to the X coordinate, and take the width of the player off it.
51963 ADD A,(IX+9)
51966 SUB (IX+4)
51969 CP L Compare it with the east edge.
51970 RET C Return if the player is still in the room.
51971 LD (IX+1),255 Set the X coordinate to 255.
51975 LD A,(IX+8) Fetch the room number and stash it in L.
51978 LD L,A
51979 INC A Go to the room to the east.
51980 JR ChangeRoomEastWest Jump to ChangeRoomEastWest.
