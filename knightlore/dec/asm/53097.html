53097: Drawing Order Table
The routines that decide what is done about a pair of objects, by the number made from the directions in 52984. The number is the number in Z plus the number in Y plus the number in X. Either the first object is not held up by the other, or the other object has to be drawn first, or the objects fill the same space.
