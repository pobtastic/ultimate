45582: Start Game Tune
The tune played just before a new game starts. Each byte holds a note in bits 0-5 (the index of a note in MusicNotes, where 0 is a rest) and the length of the note in bits 6-7 (0 to 3 for one to four times the basic length of the note). The tune ends with 255. PlayMusic plays it.
