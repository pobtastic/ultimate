49720: Handle Object At Centre Of Room
Used by the routine at HandleObjectDroppedInCauldron.
Handles an object that has been dropped in the cauldron once it is at the centre of the room. If it is above the cauldron it is flagged to be ignored in the 3D calculations and left to fall. When it has dropped to the bottom the object is added to the cauldron.
Input
IX Address of the object
HandleObjectAtCentreOfRoom 49720 LD A,128 Set A to the height of the bottom of the cauldron.
49722 CP (IX+3) Compare it with the Z coordinate of the object.
49725 JR NC,AddObjectToCauldron Jump to AddObjectToCauldron if the object is at the bottom of the cauldron.
49727 SET 1,(IX+7) Flag the object to be ignored in the 3D calculations.
49731 JR HandleObjectDroppedInCauldron_Move Jump to HandleObjectDroppedInCauldron_Move to let it fall.
The object is in the cauldron. If it is the one that is needed next, count it and show that something happens.

49737 CALL FindNextObjectRequired Find the number of the object that is needed next.
49740 LD A,(IX+0) Fetch the graphic number of the object.
49743 AND %00000111 Convert it to the number of the object.
