54586: Fill Memory
Used by the routines at StartGame, RestartGame, ClearScreenBitmap and ClearScreenBuffer.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory 54586 LD E,0 Set the byte to zero.
This entry point is used by the routines at ClearAttributes and FillAttributes.
FillMemory_WithValue 54588 LD (HL),E Fill a byte.
54589 INC HL Move on.
54590 DEC BC Count down the number of bytes.
54591 LD A,B Test whether it is zero.
54592 OR C
54593 JR NZ,FillMemory_WithValue Jump back to FillMemory_WithValue if not.
54595 RET Return.
