47273: Spawn Cauldron Bubbles
Used by the routine at RunGame.
Starts the bubbles that rise out of the cauldron. Nothing happens unless the player is in the cauldron room, the second slot for special objects is empty and the final animation is not under way. The bubbles are copied into the slot from CauldronBubbles.
SpawnCauldronBubbles 47273 LD A,(23568) Fetch the room that the player is in.
47276 CP 136 Compare it with the number of the cauldron room.
47278 RET NZ Return if the player is in another room.
47279 LD DE,23656 Point DE at ObjectsTable_SecondSpecial.
47282 LD A,(DE) Fetch the graphic number of the object.
47283 AND A Test whether the slot is empty.
47284 RET NZ Return if it is in use.
47285 LD A,(23491) Fetch the flag that is set when the final animation starts.
47288 AND A Test it.
47289 RET NZ Return if the final animation has started.
47290 LD HL,47304 Point HL at CauldronBubbles.
47293 LD BC,18 Set the number of bytes to copy to 18.
47296 PUSH DE Copy DE to IX (using the stack).
47297 POP IX
47299 LDIR Copy the bubbles into the slot.
47301 JP SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
