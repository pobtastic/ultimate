44908: Start Game
Used by the routine at GameEntry.
Clears the whole game variables area (from RandomSeed1 up to the end of the objects table at 24840) and then carries on to set up a new game. The low byte of the system FRAMES counter is kept across the clear and used as the first random seed, so that every game plays differently.
StartGame 44908 LD HL,23456 Set HL to the start of the game variables.
44911 LD BC,1384 Set BC to the number of bytes to clear.
44914 LD A,(23672) Read the low byte of the FRAMES system variable.
44917 PUSH AF Stash it on the stack.
44918 CALL FillMemory Clear the game variables.
44921 POP AF Restore the FRAMES value.
44922 LD (23456),A Store it in RandomSeed1 as the first random seed.
44925 JR InitialiseGame Jump to InitialiseGame.
