47196: Set Deadly Flags
Used by the routines at HandleGargoyle, HandleSpikedBall, HandleSpikes and SetDeadlyFlagsAndDraw.
Makes an object deadly, so that the player dies if it touches the object or if the object touches the player.
Input
IX Address of the object
SetDeadlyFlags 47196 LD A,(IX+13) Fetch the flags that go with the object.
47199 OR %10100000 Set the bits that make the object fatal for the player to hit and for it to hit the player.
47201 LD (IX+13),A Store the flags.
47204 RET Return.
