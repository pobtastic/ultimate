55539: Screen Buffer
The buffer that the game draws into before it is copied to the screen by UpdateScreen. It has a byte for every eight pixels of the screen, with 32 bytes to a line, and the lines are in the order from the bottom of the screen to the top, so the first byte is at the bottom left of the screen and a line above is 32 bytes further on. The pixels of the buffer are 0 for a pixel that is not set.
