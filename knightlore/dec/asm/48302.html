48302: Print BCD Number
Used by the routines at GameOver, PrintPercentageComplete, PrintDays and PrintLives.
Prints a BCD number in the screen buffer, using the standard font. Every digit is printed, including leading zeroes.
Input
B Number of bytes (pairs of digits) to print
DE Address of the number
HL Address in the screen buffer to print at
PrintBCDNumber 48302 PUSH HL Stash the address in the screen buffer.
48303 LD HL,24840 Point HL at Font.
48306 LD (23495),HL Use it to print.
48309 POP HL Restore the address in the screen buffer.
PrintBCDNumber_NextByte 48310 LD A,(DE) Fetch two digits.
48311 RRCA Move the first digit into the lowest four bits.
48312 RRCA
48313 RRCA
48314 RRCA
48315 AND %00001111 Keep only the first digit.
48317 CALL PrintCharacter Print the first digit.
This entry point is used by the routine at PrintPercentageComplete.
PrintBCDNumber_SecondDigit 48320 LD A,(DE) Fetch two digits.
48321 AND %00001111 Keep only the second digit.
48323 CALL PrintCharacter Print the second digit.
48326 INC DE Move on to the next two digits.
48327 DJNZ PrintBCDNumber_NextByte Jump back to PrintBCDNumber_NextByte until all of the bytes have been printed.
48329 RET Return.
