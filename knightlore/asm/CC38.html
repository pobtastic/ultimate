CC38: Block Movement In Z
Used by the routine at BlockMovement.
Brings the speed in Z of an object closer to zero until it does not run into any other object. This works in the same way as BlockMovementInX, except that the object that is hit is flagged as triggered (bit 3 of its flags in byte 0D) as something is standing on it. An object that can be moved takes on the speeds in X and Y of the object that it stands on, if it has none of its own.
Input
C Speed in X
L Speed in Y
H Speed in Z
IX Address of the object
Output
H The new speed in Z
Test each object, then slow the Z speed if they overlap.
