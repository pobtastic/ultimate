D50E: Pause Game
Used by the routine at RunGame.
Pauses the game if the SPACE key is pressed on its own. The game waits for the key to be let go of, then for it to be pressed again and let go of again. There is a sound for the start and for the end of the pause.
PauseGame D50E LD A,$7E Read the keys SPACE, symbol shift, M, N and B.
D510 CALL ReadKeyboardPort
D513 BIT 0,A Test the SPACE key.
D515 RET Z Return if it is not pressed.
D516 AND %00011110 Keep the other keys.
D518 RET NZ Return if any of them is pressed.
PauseGame_Release D519 LD A,$7E Read the keys.
D51B CALL ReadKeyboardPort
D51E BIT 0,A Jump back to PauseGame_Release while it is pressed.
D520 JR NZ,PauseGame_Release
D522 CALL PlayMiddleBeep Play the sound of the pause.
PauseGame_Wait D525 LD A,$7E Read the keys.
D527 CALL ReadKeyboardPort
D52A BIT 0,A Jump back to PauseGame_Wait until it is pressed.
D52C JR Z,PauseGame_Wait
PauseGame_Finish D52E LD A,$7E Read the keys.
D530 CALL ReadKeyboardPort
D533 BIT 0,A Jump back to PauseGame_Finish while it is pressed.
D535 JR NZ,PauseGame_Finish
D537 JP PlayMiddleBeep Jump to PlayMiddleBeep.
