D50E: Pause Game
Used by the routine at RunGame.
Pauses the game if CAPS SHIFT or SPACE is pressed on its own. The game waits for the key to be let go of, then for it to be pressed again and let go of again. There is a beep for the start and for the end of the pause.
Return unless CAPS SHIFT or SPACE is pressed on its own.
PauseGame D50E LD A,$7E Read from the keyboard;
Port Number Bit
0 1 2 3 4
7E SHIFT / SPACE Z / SYM X / M C / N V / B
D510 CALL ReadKeyboardPort
D513 BIT 0,A Return if neither CAPS SHIFT nor SPACE is pressed.
D515 RET Z
D516 AND %00011110 Keep bits 1 to 4.
D518 RET NZ Return if any of them is pressed.
Wait for the key to be released.

D51E BIT 0,A Jump to PauseGame_Release while CAPS SHIFT or SPACE is pressed.
D520 JR NZ,PauseGame_Release

Wait for the key to be pressed.
