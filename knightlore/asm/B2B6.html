B2B6: Play Music Once
Used by the routine at GameMenu.
Plays the tune that DE points at, but only if no tune has been played since the flag was last cleared. The flag is set at the same time, so that the tune is only ever played once.
Input
DE Address of the tune
PlayMusicOnce B2B6 LD HL,$5BD1 Point HL at the flag that says a tune has been played.
B2B9 LD A,(HL) Return if the flag is already set.
B2BA AND A
B2BB RET NZ
B2BC SET 0,(HL) Set the flag and carry on to play the tune.
Continue on to PlayMusic_WaitKey.
