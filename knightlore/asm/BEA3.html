BEA3: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Switches on the flashing (bit 7) of one in a list of attributes and switches it off for all of the others.
Input
A Position in the list of the attribute that is to flash
B Number of attributes in the list
HL Address of the list
Output
HL Address just beyond the list
SetFlashingAttribute BEA3 AND A Test the position.
BEA4 JR NZ,SetFlashingAttribute_Steady Jump to SetFlashingAttribute_Steady if it is not the first.
SetFlashingAttribute_Flash BEA6 SET 7,(HL) Switch on the flashing of the attribute.
BEA8 JR SetFlashingAttribute_Advance Jump to SetFlashingAttribute_Advance.
SetFlashingAttribute_NextLine BEAA DEC A Count down to the attribute that flashes.
BEAB JR Z,SetFlashingAttribute_Flash Jump to SetFlashingAttribute_Flash if this is it.
SetFlashingAttribute_Steady BEAD RES 7,(HL) Switch off the flashing of the attribute.
SetFlashingAttribute_Advance BEAF INC HL Move on to the next attribute.
BEB0 DJNZ SetFlashingAttribute_NextLine Jump back to SetFlashingAttribute_NextLine until the whole list has been done.
BEB2 RET Return.
