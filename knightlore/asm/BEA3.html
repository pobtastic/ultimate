BEA3: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute BEA3 AND A Jump to SetFlashingAttribute_Steady if the line is not the first.
BEA4 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash BEA6 SET 7,(HL) Set bit 7 of the attribute.
BEA8 JR SetFlashingAttribute_Advance Jump to SetFlashingAttribute_Advance.
SetFlashingAttribute_NextLine BEAA DEC A Jump to SetFlashingAttribute_Flash if this is the line.
BEAB JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady BEAD RES 7,(HL) Reset bit 7 of the attribute.
SetFlashingAttribute_Advance BEAF INC HL Move on to the next line.
BEB0 DJNZ SetFlashingAttribute_NextLine Jump to SetFlashingAttribute_NextLine until all of the lines have been done.
BEB2 RET Return.
