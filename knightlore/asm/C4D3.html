C4D3: Set Pixel Adjustments
Used by the routine at HandleExtraLife.
Sets the number of pixels that the sprite of an object is moved by, in X and Y, from its position. There is an entry point for each of the sets of adjustments that are used, and the one that is used for an object depends on its sprite. The adjustment in X goes in L and the adjustment in Y goes in H.
Input
IX Address of the object
SetPixelAdjustments C4D3 LD HL,$FEF8 Set the adjustments of a tree wall, which are F8 in X and FE in Y.
C4D6 JR SetPixelAdjustments_Set Jump to SetPixelAdjustments_Set.
