D53A: Fill Memory
Used by the routines at StartGame, RestartGame, ClearScreenBitmap and ClearScreenBuffer.
Fills an area of memory with zero. The entry point at FillMemory_WithValue fills it with the byte in E.
Input
BC Number of bytes
HL Address of the first byte
FillMemory D53A LD E,$00 Set E to 00.
This entry point is used by the routines at ClearAttributes and FillAttributes.
FillMemory_WithValue D53C LD (HL),E Write E.
D53D INC HL Increment HL.
D53E DEC BC Decrement BC.
D53F LD A,B Jump to FillMemory_WithValue if BC is not zero.
D540 OR C
D541 JR NZ,FillMemory_WithValue
D543 RET Return.
