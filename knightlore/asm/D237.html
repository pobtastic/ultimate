D237: Set Sprite Details
Used by the routines at PrintTableSprite, DrawPanel and PrintBorder.
Sets the graphic number, the flags and the pixel coordinates of an object from four bytes of data.
Input
HL Address of the data
IX Address of the object
Output
HL Address of the byte after the data
SetSpriteDetails D237 LD A,(HL) Fetch the graphic number and move on.
D238 INC HL
D239 LD (IX+$00),A Set the graphic number of the object.
D23C LD A,(HL) Fetch the flags and move on.
D23D INC HL
D23E LD (IX+$07),A Set the flags of the object.
D241 LD A,(HL) Fetch the pixel X coordinate and move on.
D242 INC HL
D243 LD (IX+$1A),A Set the pixel X coordinate of the object.
D246 LD A,(HL) Fetch the pixel Y coordinate and move on.
D247 INC HL
D248 LD (IX+$1B),A Set the pixel Y coordinate of the object.
D24B RET Return.
