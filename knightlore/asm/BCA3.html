BCA3: Print Lives
Used by the routines at RunGame and HandleExtraLife.
Prints the number of lives that the player has left on the panel.
PrintLives BCA3 LD DE,$5BBA Point DE at the number of lives, Lives.
BCA6 LD B,$01 Set the number of bytes to print to 01.
BCA8 LD HL,$DDD7 Point HL at ScreenBuffer_PanelLives.
BCAB JP PrintBCDNumber Print the number of lives.
