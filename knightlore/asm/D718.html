D718: Print Sprite
Used by the routines at PrintLivesGraphic, PrintSprites, DisplayObjectsCarried, DisplaySunMoonFrame and PrintTableSprite.
Draws the sprite of an object into the screen buffer, at the pixel coordinates of the object. The sprite is made of pairs of bytes, a mask byte and then a data byte, which are put on the buffer with the mask clearing the background. A sprite that does not start on a byte boundary has each pair shifted across two bytes, with the tables built by BuildLookupTables. The routine copies the sprite with unrolled code, which it enters part of the way along, so that it does as many columns as the sprite has. To do this it changes the code, and it uses the stack pointer to read the data of the sprite, so the interrupts have to be off.
