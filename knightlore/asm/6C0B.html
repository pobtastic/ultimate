6C0B: Block Types
The objects that make up each type of block, which are in the table at BlockTypeTable. A list has a group of six bytes for every object, which ends with a zero byte. The bytes of an object are described by this table.
Byte Contents
00 The graphic number
01-03 The width, depth and height
04 The flags
05 The offsets of the position: bit 0 is half a step of X, bit 1 is half a step of Y, and bits 2-7 are added to the Z coordinate
