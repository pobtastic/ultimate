C47E: Initialise Special Objects
Used by the routine at InitialiseGame.
Chooses which objects are placed where, at the start of each game. Every entry in the table of special objects gets a graphic number from 60 to 67 one after another from a number that comes from the first random seed and the refresh register, and the place that the object starts in is copied to the place that it is in now.
InitialiseSpecialObjects C47E LD HL,$6FF2 Point HL at the first special object.
C481 LD A,($5BA0) Fetch the first random seed.
C484 LD E,A Stash it in E.
C485 LD A,R Fetch a random number from the refresh register.
C487 ADD A,E Add the seed.
C488 LD E,A Stash the result in E.
InitialiseSpecialObjects_Next C489 LD A,E Copy the number into A.
C48A AND %00000111 Keep the lowest three bits.
C48C OR %01100000 Make it a graphic number from 60 to 67.
C48E LD (HL),A Set the graphic number of the object.
C48F INC HL Move on to the starting position.
C490 INC E Change the number, for the next object.
C491 PUSH DE Stash it.
C492 EX DE,HL Point DE at the starting position.
C493 LD HL,$0004 Set HL to the offset of the current position.
C496 ADD HL,DE Point HL at the current position.
C497 EX DE,HL Point DE at the current position.
C498 LD BC,$0004 Set the number of bytes to copy to 04.
C49B LDIR Copy the starting position to the current position.
C49D EX DE,HL Point HL at the next object.
C49E PUSH HL Stash it.
C49F LD BC,$7112 Point BC at the end of the table.
C4A2 AND A Subtract the address of the end of the table.
C4A3 SBC HL,BC
C4A5 POP HL Restore the address of the next object.
C4A6 POP DE Restore the number.
C4A7 JR C,InitialiseSpecialObjects_Next Jump back to InitialiseSpecialObjects_Next until every object has been done.
C4A9 RET Return.
