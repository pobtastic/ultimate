BF11: Handle Last Appearing Sparkle
The handler for the last of the sparkles in which the player appears. The object turns into the player, who is no longer dead, and is updated as the player right away.
Input
IX The address of the object
Stop the sparkle and restore the player.
HandleLastAppearingSparkle BF11 CALL SetPixelAdjustments_Sparkle Call SetPixelAdjustments_Sparkle.
BF14 RES 6,(IX+$0D) Reset bit 6 of the flags.
BF18 LD A,(IX+$10) Fetch the sprite number which was kept.
BF1B LD (IX+$00),A Restore the sprite number of the object.
BF1E JP RunGame_UpdateObject Jump to RunGame_UpdateObject.
