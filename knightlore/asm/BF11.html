BF11: Handle Last Appearing Sparkle
Handles the last of the sparkles that show the player appearing. The object turns into the player, who is no longer dead, and is updated as the player right away.
Input
IX Address of the sparkle object
HandleLastAppearingSparkle BF11 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
BF14 RES 6,(IX+$0D) Clear the flag that says the player is dead.
BF18 LD A,(IX+$10) Fetch the graphic number of the player.
BF1B LD (IX+$00),A Make it the graphic number of the object.
BF1E JP RunGame_UpdateObject Update the object as the player.
