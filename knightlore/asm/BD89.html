BD89: Flash Menu Options
Used by the routine at GameMenu.
Makes the line of the menu for the selected control method flash, and the line for directional control if that is on.
Flash the chosen control method.
FlashMenuOptions BD89 LD HL,$BDA3 Point HL at MenuColours_ControlMethods.
BD8C LD A,($5BA4) Fetch ControlMethod.
BD8F RRCA Move the method to bits 0 and 1.
BD90 AND %00000011 Keep only bits 0 and 1.
BD92 LD B,$04 Set a counter of 04 lines.
BD94 CALL SetFlashingAttribute Call SetFlashingAttribute.
Flash directional control if it is on.
BD97 RES 7,(HL) Reset bit 7 of the attribute.
BD99 LD A,($5BA4) Fetch ControlMethod.
BD9C AND %00001000 Keep only bit 3.
BD9E RET Z Return if it is off.
BD9F SET 7,(HL) Set bit 7 of the attribute.
BDA1 RET Return.
