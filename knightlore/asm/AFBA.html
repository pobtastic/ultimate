AFBA: Run Game
Used by the routine at LeaveRoomToWest.
The main game loop. The first call builds the objects of the room the player is in. Then every pass of the loop visits each of the 28 objects in the objects table in turn, calling the routine for its graphic number from the jump table at UpdateRoutineTable to move and update it. Once every object has been dealt with the objects are sorted and drawn, the screen is brought up to date and the game waits a little (the more objects in view, the shorter the wait) before the next pass.
After the first pass
RunGame AFBA CALL BuildRoomObjects Build the objects for the room the player is in.
Every pass of the main loop starts here. The random seed used by the fire is refreshed, then each object in the table is updated in turn.

Jump to the routine whose address is held in word L of the table that BC points at (H is cleared first).
RunGame_JumpToHandler AFDB LD H,$00 Clear H, so that HL holds the graphic number.

AFE2 LD L,A Put the low byte into L.

The update routine of each object returns here.
