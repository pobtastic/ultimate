C3A4: Display Sun Moon Frame
Used by the routine at RunGame.
Shows the window of the panel that holds the sun or the moon, and the sun or moon in it. The sun and the moon go along an arc from pixel X coordinate B0 to E0, which is the height from the table at SunMoonHeights. When one of them gets to the end the other takes over, the player transforms, and each time the sun comes back a day is added and the day is shown on the panel. When 40 days have passed the game is over. Nothing is done when the final animation is under way.
Input
IX Address of the sun/moon object
DisplaySunMoonFrame C3A4 LD A,($5BC3) Fetch the flag that says the final animation has started from FinalAnimationFlag.
C3A7 AND A Test it.
C3A8 RET NZ Return if the final animation has started.
C3A9 LD A,(IX+$1A) Fetch the pixel X coordinate of the sun/moon.
C3AC CP $E1 Jump to DisplaySunMoonFrame_Toggle if the sun/moon has got there.
C3AE JR Z,DisplaySunMoonFrame_Toggle
C3B0 LD A,(IX+$1A) Fetch the pixel X coordinate.
C3B3 ADD A,$10 Add 10 to it.
C3B5 LD HL,$C440 Point HL at SunMoonHeights.
C3B8 RRCA Divide the number by four.
C3B9 RRCA
C3BA AND %00001111 Keep the lowest four bits.
C3BC CALL AddAToHL Find the address of the height.
C3BF LD A,(HL) Fetch the height.
C3C0 LD (IX+$1B),A Set the pixel Y coordinate of the sun/moon.
Draw the window in the screen buffer, wiping what was there first.

C3C9 PUSH BC Stash the size of the window on the stack.
C3CA PUSH HL Stash the position of the window on the stack.
C3CB LD A,C Swap B and C, so that B is the width and C is the height.
C3CC LD C,B
C3CD LD B,A
C3CE XOR A Clear A.

C3D2 CALL PrintSprite Draw the sun/moon.
C3D5 LD IX,$BFDB Point IX at PanelObject.

C3E1 LD (IX+$1A),$B8 Set the pixel X coordinate to B8.

C3F7 POP HL Restore the position of the window from the stack.
C3F8 POP BC Restore the size of the window from the stack.
C3F9 LD DE,$57F7 Point DE at the position of the window on the display.

The sun or the moon has gone round: change to the other one, which makes the player transform. Add a day when it is the sun that is coming back.
