AF88: Initialise Game
Used by the routine at StartGame.
Sets up everything needed to start a new game: builds the lookup tables, gives the player five lives, lets the player choose the control method on the menu, plays the start tune and then picks the random start location of the player and of the special objects.
Build the tables and set the starting state.
