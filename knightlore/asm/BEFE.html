BEFE: Handle Player Appearing
Handles the sparkles that show the player appearing, which go through the graphic numbers 78 to 7E. The graphic changes on every other frame, and each change makes a sound. The last sparkle is handled by HandleLastAppearingSparkle.
Input
IX Address of the sparkle object
HandlePlayerAppearing BEFE CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
BF01 LD A,($5BA2) Fetch the frame counter.
BF04 CPL Invert it.
BF05 AND %00000001 Keep the lowest bit.
BF07 RET NZ Return on every other frame.
BF08 INC (IX+$00) Change to the next graphic.
BF0B CALL PlayAppearingSound Play the sound of the player appearing.
BF0E JP SetWipeAndDrawFlags Flag the object to be drawn again.
