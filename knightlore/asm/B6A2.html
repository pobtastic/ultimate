B6A2: Handle Collapsing Block
Handles a block that crumbles into sparkles when something stands on it.
Input
IX Address of the block object
HandleCollapsingBlock B6A2 CALL SetPixelAdjustments_Block Set the pixel adjustments of a block.
B6A5 BIT 3,(IX+$0D) Test whether something is standing on the block.
B6A9 RET Z Return if nothing is.
B6AA LD (IX+$00),$B8 Change the block into a sparkle.
B6AE JP HandleDeathSparkles Carry on as the sparkles of a death.
