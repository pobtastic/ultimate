AF6C: Start Game
Used by the routine at GameEntry.
Clears the whole game variables area (from RandomSeed1 up to the end of the objects table at 6108) and then carries on to set up a new game. The low byte of the system FRAMES counter is kept across the clear and used as the first random seed, so that every game plays differently.
StartGame AF6C LD HL,$5BA0 Set HL to the start of the game variables.
AF6F LD BC,$0568 Set BC to the number of bytes to clear.
AF72 LD A,($5C78) Read the low byte of the FRAMES system variable.
AF75 PUSH AF Stash it on the stack.
AF76 CALL FillMemory Clear the game variables.
AF79 POP AF Restore the FRAMES value.
AF7A LD ($5BA0),A Store it in RandomSeed1 as the first random seed.
AF7D JR InitialiseGame Jump to InitialiseGame.
