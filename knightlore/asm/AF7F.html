AF7F: Restart Game
Used by the routine at GameOver.
Clears the variables that belong to a single game, leaving the random seeds and the chosen control method alone. This is used to go back to the game selection menu after a game has finished.
RestartGame AF7F LD HL,$5BA8 Set HL to the first of the variables that are cleared each game.
AF82 LD BC,$0560 Set BC to the number of bytes to clear.
AF85 CALL FillMemory Clear the variables.
Continue on to InitialiseGame.
