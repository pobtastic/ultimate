C722: Handle Far Arch
Handles the graphic numbers 03 and 05, which are the far side of an arch. They only need the pixel adjustments of the sprite, which are not the same when the sprite is flipped.
Input
IX Address of the arch object
HandleFarArch C722 BIT 6,(IX+$07) Jump to AdjustFlippedFarArch if the arch is flipped horizontally.
C726 JR NZ,AdjustFlippedFarArch
C728 LD HL,$FDF7 Set the adjustments of F7 in X and FD in Y.
