CCC7: Test Overlap In Z
Used by the routines at TestObjectIntersections, TestObjectCanBePickedUp, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether two objects overlap in Z, once the first has moved by its new speed in Z. They overlap when the distance between the Z coordinates is smaller than the height of whichever of the objects is lower.
Input
H New speed in Z of the first object
IX Address of the first object
IY Address of the second object
Output
F The carry flag is set if the objects overlap
TestOverlapInZ CCC7 LD A,(IX+$03) Take the Z coordinate of the second object off the Z coordinate of the first object plus the new speed.
CCCA ADD A,H
CCCB SUB (IY+$03)
CCCE JP P,TestOverlapInZ_Second Jump to TestOverlapInZ_Second if it is not negative.
CCD1 NEG Make it positive.
CCD3 LD D,(IX+$06) Fetch the height of the first object, which is the lower.
TestOverlapInZ_Compare CCD6 SUB D Take the height off it, which sets the carry flag if the objects overlap.
CCD7 RET Return.
TestOverlapInZ_Second CCD8 LD D,(IY+$06) Fetch the height of the second object, which is the lower.
CCDB JR TestOverlapInZ_Compare Jump to TestOverlapInZ_Compare.
