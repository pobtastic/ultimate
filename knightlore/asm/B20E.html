B20E: Start Game Tune
The tune played just before a new game starts. Each byte holds a note in bits 0-5 (the index of a note in MusicNotes, where 00 is a rest) and the length of the note in bits 6-7 (00 to 03 for one to four times the basic length of the note). The tune ends with FF. PlayMusic plays it.
StartGameTune B20E DEFB $59,$5C,$5B,$54,$19
B213 DEFB $17,$14,$17,$D9,$FF
