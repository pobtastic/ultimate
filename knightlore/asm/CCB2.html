CCB2: Test Overlap In Y
Used by the routines at TestObjectIntersections, TestObjectCanBePickedUp, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether two objects overlap in Y, once the first has moved by its new speed in Y. They overlap when the distance between the Y coordinates is smaller than the two depths added together.
Input
L New speed in Y of the first object
IX Address of the first object
IY Address of the second object
Output
F The carry flag is set if the objects overlap
TestOverlapInY CCB2 LD A,(IX+$05) Add the depth of the first object to the depth of the second object.
CCB5 ADD A,(IY+$05)
CCB8 LD D,A Stash the total in D.
CCB9 LD A,(IX+$02) Take the Y coordinate of the second object off the Y coordinate of the first object plus the new speed.
CCBC ADD A,L
CCBD SUB (IY+$02)
CCC0 JP P,TestOverlapInY_TakeDepths Jump to TestOverlapInY_TakeDepths if it is not negative.
CCC3 NEG Make it positive.
TestOverlapInY_TakeDepths CCC5 SUB D Take the total depths off it, which sets the carry flag if the objects overlap.
CCC6 RET Return.
