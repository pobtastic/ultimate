B923: Handle Special Object In Cauldron
Handles the graphics A8 to AF which show the object that is needed next above the cauldron. The object lasts for a single frame, as it is changed back to the bubbles.
Input
IX Address of the object
HandleSpecialObjectInCauldron B923 CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
B926 LD (IX+$00),$A0 Change the graphic of the object to the bubbles.
B92A JR HandleCauldronBubbles_Draw Jump to HandleCauldronBubbles_Draw.
