C692: Set Wipe And Draw Flags
Used by the routines at SetSparkleSpeed, HandleDroppingBlock, HandleBlockMovingEastWest, HandleGuardBottomHalf, HandleSpikedBall, SetDeadlyFlagsAndDraw, HandleCauldronBubbles, HandlePlayerAppearing, HandleDeathSparkles, DrawMovingObject, PrepareFinalAnimation, StartTransformation, HandleTransformation, SetWipeAndDrawFlagsForObject, HandleMovingPortcullis and HandlePlayerLegs.
Flags an object to be wiped and drawn again, and flags every other object that overlaps it to be drawn too.
Input
IX Address of the object
SetWipeAndDrawFlags C692 LD A,(IX+$07) Fetch the flags of the object.
C695 OR %00110000 Set the bits that flag the object to be wiped and drawn.
C697 LD (IX+$07),A Store the flags.
C69A JP FlagOverlappingObjects Flag the objects that overlap it to be drawn.
