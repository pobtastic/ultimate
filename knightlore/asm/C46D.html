C46D: Initialise Sun
Used by the routine at InitialiseGame.
Sets the sun/moon object to the sun at the start of the arc.
InitialiseSun C46D LD IX,$C44D Point IX at the sun/moon object.
C471 LD (IX+$00),$58 Set the graphic number to 58 which is the sun.
C475 LD (IX+$1A),$B0 Set the pixel X coordinate to B0.
C479 LD (IX+$1B),$09 Set the pixel Y coordinate to 09.
C47D RET Return.
