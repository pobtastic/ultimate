C432: Copy Area To Screen
Used by the routines at HandleExtraLife and DisplaySunMoonFrame.
Copies a block of the screen buffer, which is two bytes wide and eight lines high, to the display.
Input
B Pixel Y coordinate
C Pixel X coordinate
CopyAreaToScreen C432 CALL CalculateScreenAddress Find the address in the display.
C435 CALL CalculateBufferAddress Find the address in the screen buffer.
C438 LD L,C Copy it to HL.
C439 LD H,B
C43A LD BC,$0802 Set the number of lines to 08 and the number of bytes to 02.
C43D JP CopyBlockToScreen Copy the block to the display.
