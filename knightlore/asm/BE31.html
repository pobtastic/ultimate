BE31: Print Text Single Colour
Used by the routine at DisplayTextList.
Prints a line of text in the colour held in TextAttribute, using the font at Font. The last character of the text has bit 7 set.
Input
DE Address of the text
HL Pixel position
Point at the standard font and keep TextAttribute.
PrintTextSingleColour BE31 PUSH HL Stash the pixel position on the stack.
BE32 LD HL,$6108 Point HL at Font.
BE35 LD ($5BC7),HL Set FontPointer.
BE38 POP BC Copy the pixel position to BC (using the stack).
BE39 PUSH BC
BE3A CALL CalculateBufferAddress Call CalculateBufferAddress.
BE3D LD L,C Copy it to HL.
BE3E LD H,B
BE3F LD A,($5BB6) Fetch TextAttribute.
BE42 EX AF,AF' Keep the colour in AF'.
BE43 JR PrintText_Setup Jump to PrintText_Setup.
