BE31: Print Text Single Colour
Used by the routine at DisplayTextList.
Prints a line of text in the screen buffer, using the standard font and the attribute that is held in TextAttribute for every character. The text is in the format that is described at GameCompleteText.
Input
DE Address of the text
H Y coordinate
L X coordinate
PrintTextSingleColour BE31 PUSH HL Stash the coordinates.
BE32 LD HL,$6108 Point HL at Font.
BE35 LD ($5BC7),HL Use it to print.
BE38 POP BC Fetch the coordinates in BC.
BE39 PUSH BC Stash them again.
BE3A CALL CalculateBufferAddress Find the address in the screen buffer.
BE3D LD L,C Copy it to HL.
BE3E LD H,B
BE3F LD A,($5BB6) Fetch the attribute and keep it in AF'.
BE42 EX AF,AF'
BE43 JR PrintText_Setup Jump to PrintText_Setup.
