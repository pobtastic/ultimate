C4C3: Handle Table
Handles a table, which falls when there is nothing below it. It plays the sound of a moving object, and is drawn again, only when it is moving, with its speeds in X and Y cleared.
Input
IX Address of the table object
HandleTable C4C3 CALL SetPixelAdjustments_Block Set the pixel adjustments of a block.
This entry point is used by the routine at HandleExtraLife.
HandleTable_Fall C4C6 CALL ApplyGravityAndMove Apply gravity to the object and move it.
C4C9 CALL TestObjectMoving Test whether the object is moving.
C4CC RET Z Return if it is not.
C4CD CALL MovePlayer_Stop Clear the speeds in X and Y.
C4D0 JP DrawMovingObject Play the sound of a moving object and flag the object to be drawn again.
