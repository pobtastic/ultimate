C6AD: Start Portcullis Rising
Used by the routine at HandlePortcullis.
Starts a portcullis rising, on one frame in thirty-two.
Input
IX Address of the portcullis object
StartPortcullisRising C6AD LD A,($5BA5) Fetch the second random seed.
C6B0 AND %00011111 Keep the lowest five bits.
C6B2 RET NZ Return unless it is the time to set off.
C6B3 SET 0,(IX+$00) Change the graphic of the portcullis to the moving one.
C6B7 LD (IX+$0B),$01 Set the speed in Z to move it up.
C6BB JR HandlePortcullis_Flag Jump to HandlePortcullis_Flag.
