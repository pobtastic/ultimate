D3E2: Clear Remaining Objects
Used by the routines at RetrieveRoom and MakeRoomObjects.
Clears the objects in the objects table from a given place to the end of the table.
Input
DE Address of the first object to clear
ClearRemainingObjects D3E2 LD HL,$6108 Point HL at the end of the objects table, Font.
D3E5 AND A Compare it with the address.
D3E6 SBC HL,DE
D3E8 RET Z Return if the end has been reached.
D3E9 LD B,$20 Set the number of bytes to the size of an object.
D3EB CALL ClearBytes Clear the object.
D3EE JR ClearRemainingObjects Jump to ClearRemainingObjects.
