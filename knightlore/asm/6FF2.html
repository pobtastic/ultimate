6FF2: Special Objects Table
The special objects of the game, which are the seven objects that the player has to take to the cauldron and the extra life, four of each. Each one has nine bytes, which are described by this table. The graphic numbers are given out at random at the start of a game by InitialiseSpecialObjects, and the current place of each object is copied from where it starts, so that the objects are in a different room each time.
Byte Contents
00 The graphic number, which is 00 while the player is carrying the object or after it has been put in the cauldron
01-04 The X, Y and Z coordinates and the room number where the object starts
05-08 The X, Y and Z coordinates and the room number where the object is now
