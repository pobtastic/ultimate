B2DA: Play Note
Used by the routines at PlayMusic_WaitKey and PlayMusic.
Plays one note of a tune, or pauses for the length of the note if it is a rest. The note is a square wave made by switching the speaker on and off, so the game is stopped while it plays. Bits 0-5 of the note are the number of the note (see MusicNotes), and bits 6-7 are the length of the note, which is one to four times the basic length of the note.
Input
A The note
DE Address of the note
Output
DE Address of the next note
PlayNote B2DA AND %00111111 Isolate the number of the note.
B2DC JR Z,PlayNote_Rest Jump to PlayNote_Rest if it is a rest.
Look up the delays and the number of cycles in the table at MusicNotes.
B2DE LD L,A Multiply the number of the note by three.
B2DF LD H,$00
B2E1 ADD HL,HL
B2E2 CALL AddAToHL
B2E5 LD BC,$B332 Point HL at the entry of the note in the table.
B2E8 ADD HL,BC
B2E9 LD B,(HL) Fetch the first byte of the delay between the clicks of the speaker.
B2EA INC HL
B2EB LD C,(HL) Fetch the second byte of the delay.
B2EC INC HL
B2ED LD L,(HL) Fetch the basic length of the note.
B2EE LD H,$00
Bits 6 and 7 of the note are the length, less one.
B2F0 LD A,(DE) Fetch the note again and rotate bits 6-7 of it into the low bits.
B2F1 RLCA
B2F2 RLCA
B2F3 AND %00000011 Isolate the length of the note.
B2F5 INC A Make it one to four.
B2F6 PUSH DE Save the address of the note.
B2F7 LD E,L Copy the basic length into DE.
B2F8 LD D,H
Multiply the number of cycles by the length of the note.
PlayNote_Multiply B2F9 DEC A Jump to PlayNote_MultiplyDone when the basic length has been added enough times.
B2FA JR Z,PlayNote_MultiplyDone
B2FC ADD HL,DE Add the basic length to the total.
B2FD JR PlayNote_Multiply Jump back to PlayNote_Multiply.
PlayNote_MultiplyDone B2FF POP DE Restore the address of the note.
Each pass of this loop makes one cycle of the note, so the length of the note is the number of cycles.
PlayNote_Cycle B300 PUSH BC Save the delay.
B301 XOR A Switch the speaker off.
B302 OUT ($FE),A
PlayNote_OffDelay B304 DJNZ PlayNote_OffDelay Wait with the speaker off, using the first byte of the delay for the first pass and 0100 for each pass after it.
B306 DEC C Decrease the second byte of the delay and jump back to PlayNote_OffDelay until it is zero.
B307 JR NZ,PlayNote_OffDelay
B309 POP BC Restore the delay, and save it again.
B30A PUSH BC
B30B LD A,$10 Switch the speaker on.
B30D OUT ($FE),A
PlayNote_OnDelay B30F DJNZ PlayNote_OnDelay Wait with the speaker on for the same length of time.
B311 DEC C Decrease the second byte of the delay and jump back to PlayNote_OnDelay until it is zero.
B312 JR NZ,PlayNote_OnDelay
B314 POP BC Restore the delay.
B315 DEC HL Decrease the number of cycles left to play.
B316 LD A,H Jump back to PlayNote_Cycle until there are none left.
B317 OR L
B318 JR NZ,PlayNote_Cycle
B31A INC DE Point at the next note.
B31B RET Return.
A rest is a silent pause, which is made by waiting one to four times.
PlayNote_Rest B31C LD A,(DE) Fetch the length of the rest.
B31D INC DE Point at the next note.
B31E RLCA Rotate bits 6-7 of the note into the low bits.
B31F RLCA
B320 AND %00000011 Isolate the length of the rest.
B322 INC A Make it one to four.
B323 LD L,A Set the number of times to wait in L.
B324 LD BC,$430B Set the length of the wait.
PlayNote_RestUnit B327 PUSH BC Save the length of the wait.
PlayNote_RestDelay B328 DEC BC Decrease the length of the wait.
B329 LD A,B Jump back to PlayNote_RestDelay until the length of the wait is zero.
B32A OR C
B32B JR NZ,PlayNote_RestDelay
B32D POP BC Restore the length of the wait.
B32E DEC L Decrease the number of times to wait.
B32F JR NZ,PlayNote_RestUnit Jump back to PlayNote_RestUnit until it is zero.
B331 RET Return.
