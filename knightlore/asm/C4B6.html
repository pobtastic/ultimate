C4B6: Handle Chest
Handles a chest, which falls when there is nothing below it. It plays the sound of a moving object, and is drawn again, only when it is moving.
Input
IX Address of the chest object
HandleChest C4B6 CALL SetPixelAdjustments_Block Set the pixel adjustments of a block.
C4B9 CALL ApplyGravityAndMove Apply gravity to the chest and move it.
C4BC CALL TestObjectMoving Test whether the chest is moving.
C4BF RET Z Return if it is not.
C4C0 JP DrawMovingObject Play the sound of a moving object and flag the chest to be drawn again.
