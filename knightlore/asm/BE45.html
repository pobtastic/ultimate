BE45: Print Text Standard Font
Used by the routine at GameOver.
Prints a line of text, which starts with its attribute, using the font at Font. The last character of the text has bit 7 set.
Input
DE Address of the text
HL Pixel position
Point at the standard font.
PrintTextStandardFont BE45 PUSH HL Stash the pixel position on the stack.
BE46 LD HL,$6108 Point HL at Font.
BE49 LD ($5BC7),HL Set FontPointer.
Continue on to PrintText.
