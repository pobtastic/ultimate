BE45: Print Text Standard Font
Used by the routine at GameOver.
Prints a line of text in the screen buffer, using the standard font. The first byte of the text is the attribute of the line.
Input
DE Address of the text
H Y coordinate
L X coordinate
PrintTextStandardFont BE45 PUSH HL Stash the coordinates.
BE46 LD HL,$6108 Point HL at Font.
BE49 LD ($5BC7),HL Use it to print.
