C1A1: Test Object Moving
Used by the routines at HandleSpecialObject, HandleChest and HandleTable.
Tests whether an object is moving, which is when its speed in any of the three axes is not zero.
Input
IX Address of the object
Output
F Zero flag set if the object is not moving
TestObjectMoving C1A1 LD A,(IX+$09) Fetch the speed in X.
C1A4 OR (IX+$0A) Combine it with the speed in Y.
C1A7 OR (IX+$0B) Combine it with the speed in Z.
C1AA RET Return.
