BE7F: Print Character
Used by the routines at PrintBCDNumber and PrintText.
Prints one character in the screen buffer. A character is eight bytes, one for each row from the top. The rows of the screen buffer run from the bottom up, so the rows are stored 20 bytes apart and going down. The font is the one that FontPointer points to.
Input
A Number of the character
HL Address in the screen buffer of the top row
Output
HL Address in the screen buffer of the top row of the next character
PrintCharacter BE7F PUSH BC Stash BC.
BE80 PUSH DE Stash DE.
BE81 PUSH HL Stash the address in the screen buffer.
BE82 LD L,A Copy the number of the character into L.
BE83 LD H,$00 Clear H.
BE85 ADD HL,HL Multiply it by eight.
BE86 ADD HL,HL
BE87 ADD HL,HL
BE88 LD DE,($5BC7) Fetch the address of the font.
BE8C ADD HL,DE Find the data of the character.
BE8D EX DE,HL Point DE at it.
BE8E POP HL Restore the address in the screen buffer.
BE8F LD B,$08 Set the number of rows to 08.
PrintCharacter_NextRow BE91 LD A,(DE) Fetch a row of the character.
BE92 LD (HL),A Put it in the screen buffer.
BE93 INC DE Move on to the next row of the character.
BE94 PUSH BC Stash the counter.
BE95 LD BC,$FFE0 Set BC to FFE0 which is minus the length of a line of the screen buffer.
BE98 ADD HL,BC Move down a row in the screen buffer.
BE99 POP BC Restore the counter.
BE9A DJNZ PrintCharacter_NextRow Jump back to PrintCharacter_NextRow until all of the rows have been done.
BE9C POP DE Restore DE.
BE9D LD BC,$0101 Set BC to eight lines up and one byte along.
BEA0 ADD HL,BC Move to the top row of the next character.
BEA1 POP BC Restore BC.
BEA2 RET Return.
