BEBF: Display Text List
Used by the routines at GameOver and GameCompleted.
Prints a list of lines of text in the screen buffer, each in its own colour. If the border has not been drawn yet, it is drawn and the screen buffer is copied to the display.
Input
B Number of lines
DE Address of the text
HL Address of the coordinates of the lines (X and Y for each line)
DE' Address of the attributes of the lines
DisplayTextList BEBF EXX Switch to the registers that hold the attributes.
BEC0 LD A,(DE) Fetch the attribute of the line.
BEC1 LD ($5BB6),A Store it as the attribute to print with.
BEC4 INC DE Move on to the next attribute.
BEC5 EXX Switch back.
BEC6 PUSH BC Stash the number of lines.
BEC7 LD A,(HL) Fetch the X coordinate.
BEC8 INC HL Move on to the next pair of coordinates.
BEC9 INC HL
BECA PUSH HL Stash the address of the next pair.
BECB DEC HL Point HL at the Y coordinate.
BECC LD H,(HL) Fetch the Y coordinate.
BECD LD L,A Set the X coordinate.
BECE CALL PrintTextSingleColour Print the line.
BED1 POP HL Restore the address of the next pair.
BED2 POP BC Restore the number of lines.
BED3 DJNZ DisplayTextList Jump back to DisplayTextList until all of the lines have been printed.
BED5 LD A,($5BB8) Fetch the flag that says the border has been drawn.
BED8 AND A Test it.
BED9 RET NZ Return if it has.
BEDA INC A Set the flag.
BEDB LD ($5BB8),A Store it.
BEDE CALL PrintBorder Draw the border.
BEE1 JP UpdateScreen Copy the screen buffer to the display.
