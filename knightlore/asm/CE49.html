CE49: Save Sprite Info
Used by the routine at RunGame.
Keeps the size and the pixel coordinates of the sprite of an object as its old values, so that the area that it covered can be redrawn when it moves.
Input
IX Address of the object
SaveSpriteInfo CE49 LD A,(IX+$18) Save the width of the sprite in bytes.
CE4C LD (IX+$1C),A
CE4F LD A,(IX+$19) Save the height of the sprite in lines.
CE52 LD (IX+$1D),A
CE55 LD A,(IX+$1A) Save the pixel X coordinate.
CE58 LD (IX+$1E),A
CE5B LD A,(IX+$1B) Save the pixel Y coordinate.
CE5E LD (IX+$1F),A
CE61 RET Return.
