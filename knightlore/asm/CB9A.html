CB9A: Block Movement In X
Used by the routine at BlockMovement.
Brings the speed in X of an object closer to zero until it does not run into any other object. If the object does run into another, the objects may destroy each other: bit 7 of the flags in byte 0D of an object means that it destroys whatever it runs into, bit 5 means that it destroys whatever runs into it, and bit 6 means that the object is destroyed. An object that can be moved is pushed along at the same speed in X.
Input
C Speed in X
L Speed in Y
H Speed in Z
IX Address of the object
Output
C The new speed in X
Test each object, then slow the X speed if they overlap.
BlockMovementInX CB9A LD IY,$5C08 Point IY at the first object in the table, ObjectsTable.
CB9E LD B,$28 Set the number of objects to 28.

CBAA CALL TestOverlapInZ Test whether the objects overlap in Z.
CBAD JR NC,BlockMovementInX_Advance Jump to BlockMovementInX_Advance if they do not.

CBB4 SET 0,(IX+$0C) Flag the object as blocked in X.
CBB8 LD A,(IX+$0D) Fetch the flags of the object and move the bit that it destroys what it hits into bit 6.
CBBB RRCA

CBCA LD (IX+$0D),A

CBDF JR BlockMovementInX_Test Jump to BlockMovementInX_Test to test it again.
