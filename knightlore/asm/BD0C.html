BD0C: Game Selection Menu
Used by the routine at InitialiseGame.
Displays the menu and waits for the control method to be chosen and the game to be started. The keys "1" to "4" choose the keyboard, the Kempston joystick, the cursor joystick and Interface II, "5" turns directional control on or off, and "0" starts the game. A low beep sounds when the choice changes. The menu tune is played once. The choice is held in ControlMethod.
Prepare the menu.
GameMenu BD0C XOR A Write 00 to BorderDrawnFlag.
BD0D LD ($5BB8),A
BD10 LD HL,$BDA2 Point HL at MenuColours.
BD13 LD B,$08 Set the number of lines to 08.
GameMenu_StopFlashing BD15 RES 7,(HL) Stop the line flashing.
BD17 INC HL Move on to the next line.
BD18 DJNZ GameMenu_StopFlashing Jump to GameMenu_StopFlashing until all of the lines are done.
BD1A CALL ClearScreenBuffer Call ClearScreenBuffer.
BD1D CALL DisplayMenu Call DisplayMenu.
BD20 CALL FlashMenuOptions Call FlashMenuOptions.

GameMenu_MenuLoop BD23 CALL DisplayMenu Call DisplayMenu.
BD26 LD DE,$B253 Point DE at MenuTune.

BD38 BIT 0,E Jump to GameMenu_TestKempston if "1" is not pressed.
BD3A JR Z,GameMenu_TestKempston
BD3C AND %11111001 Choose the keyboard.
Choose a joystick if one of those keys is pressed.
GameMenu_TestKempston BD3E BIT 1,E Jump to GameMenu_TestCursor if "2" is not pressed.
BD40 JR Z,GameMenu_TestCursor
BD42 AND %11111001 Clear bits 1 and 2.
BD44 OR %00000010 Choose the Kempston joystick.
GameMenu_TestCursor BD46 BIT 2,E Jump to GameMenu_TestInterface if "3" is not pressed.

BD4A AND %11111001 Clear bits 1 and 2.

BD50 JR Z,GameMenu_SetMethod
BD52 OR %00000110 Choose Interface II.
GameMenu_SetMethod BD54 LD ($5BA4),A Set ControlMethod.
Toggle directional control once for each press of "5".
BD57 LD HL,$5BD2 Point HL at DirectionalKeyPressedFlag.
BD5A BIT 4,E Jump to GameMenu_ReleaseKey5 if "5" is not pressed.

BD5E BIT 0,(HL) Jump to GameMenu_TestStart if "5" was pressed last time as well.
BD60 JR NZ,GameMenu_TestStart

BD64 LD A,($5BA4) Fetch ControlMethod.

BD69 LD ($5BA4),A Set ControlMethod.
