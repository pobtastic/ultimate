D704: Draw Object
Used by the routine at DrawNextObject.
Draws an object into the screen buffer. An object that has the graphic number 01 is removed instead, by making it null.
Input
IX Address of the object
DrawObject D704 LD A,(IX+$00) Fetch the graphic number and test whether it is the one that removes the object.
D707 CP $01
D709 JR NZ,DrawNextObject_Draw Jump to DrawNextObject_Draw if it is not.
D70B LD (IX+$00),$00 Make the graphic number null.
D70F RET Return.
DrawNextObject_Draw D710 RES 4,(IX+$07) Flag the object as not to be drawn.
D714 CALL CalculatePixelCoordinates Work out the pixel coordinates.
D717 RET NC Return if the sprite is off the top of the screen.
