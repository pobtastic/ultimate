BA08: Guard Heading East
Keeps a guard heading east, at a speed of 02 until it hits something. It then turns south.
Input
IX Address of the guard
Output
H Speed in Y
L Speed in X
GuardHeadingEast BA08 LD HL,$0002 Set the speed in X to 02 and the speed in Y to 00.
BA0B BIT 0,(IX+$0C) Test whether the guard has hit something along the X axis.
BA0F RET Z Return if it has not.
BA10 LD HL,$FE00 Set the speed in X to 00 and the speed in Y to FE.
BA13 JR TurnGuard Jump to TurnGuard to turn the guard.
