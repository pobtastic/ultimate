B5F7: Read Keyboard Port
Used by the routines at PlayMusic_WaitKey, GameOver, WaitForKeyPress, GameMenu, ReadInterface2Joystick, ReadCursorJoystick, ReadKeyboard and PauseGame.
Reads one half-row of the keyboard (or several of them together, if more than one bit of the selector is zero). The bits of the result are set for the keys that are pressed.
Input
A High byte of the port address, which selects the half-rows
Output
A The keys of the half-rows (bits 0-4, set when pressed)
ReadKeyboardPort B5F7 OUT ($FD),A Put the half-row selector on the high byte of the address bus.
B5F9 IN A,($FE) Read the keyboard.
B5FB CPL Invert the bits so that the pressed keys are set.
B5FC AND %00011111 Keep only the five bits of the keys.
B5FE RET Return.
