C172: Test Object Can Be Picked Up
Used by the routine at HandlePickupAndDrop.
Tests whether an object is a special object that the player is on or close to. The routine continues at TestNearObject.
Input
IX Address of the player
IY Address of the object
Output
F Carry flag set if the object can be picked up
TestObjectCanBePickedUp C172 LD A,(IY+$00) Fetch the graphic number of the object.
C175 SUB $60 Take off the graphic number of the first special object.
C177 CP $07 Compare it with the number of special objects.
C179 RET NC Return if the object is not a special object.
