BF21: Start Death Sparkles
Used by the routines at HandleTransformation, HandlePlayerLegs and HandlePlayerTop.
Turns the object into the first of the sparkles that show the player dying, which go through the graphic numbers 70 to 76.
Input
IX Address of the object
StartDeathSparkles BF21 LD (IX+$00),$70 Set the graphic number to 70.
BF25 SET 1,(IX+$07) Flag the object to be ignored in the 3D calculations.
BF29 JR HandleDeathSparkles_Draw Jump to HandleDeathSparkles_Draw.
