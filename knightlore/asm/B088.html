B088: Reset Wipe Flags
Used by the routine at RunGame.
Clears the wipe flag (bit 5 of the flags byte) of every object in the objects table, now that the whole screen has been redrawn.
ResetWipeFlags B088 LD B,$28 Set B to the number of objects in the table.
B08A LD DE,$0020 Set DE to the size of an object.
B08D LD HL,$5C0F Point HL at the flags byte of the first object.
ResetWipeFlags_Loop B090 RES 5,(HL) Reset the wipe flag of the object.
B092 ADD HL,DE Move on to the flags byte of the next object.
B093 DJNZ ResetWipeFlags_Loop Decrease the object counter and loop back to ResetWipeFlags_Loop until all of the objects have been done.
B095 RET Return.
