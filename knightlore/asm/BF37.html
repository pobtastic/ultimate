BF37: Handle Vanishing Object Sparkles
Handles the graphic numbers B9 to BB which are for sparkles of an object that is going away for good. The entry in the table that the object points to is cleared, and then the object is removed in the same way as the last of the death sparkles.
Input
IX Address of the sparkle object
HandleVanishingObjectSparkles BF37 LD L,(IX+$10) Fetch the low byte of the address of the table entry that the object comes from.
BF3A LD H,(IX+$11) Fetch the high byte.
BF3D LD (HL),$00 Clear the graphic number of that entry.
Remove the last of the death sparkles.
HandleLastDeathSparkle BF3F CALL SetPixelAdjustments_Sparkle Set the pixel adjustments of a sparkle.
BF42 JP HandleRepelSpell_Vanish Remove the object.
