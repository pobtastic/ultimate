CA5A: Stop Object At Floor
Used by the routine at BlockMovement.
Stops an object from going through the floor. If the Z coordinate of the object after it has moved is below the floor of the room, the object is flagged as blocked in Z, and its speed in Z is brought closer to zero until the object no longer goes through the floor.
Input
H Speed in Z of the object
IX Address of the object
Output
H The new speed in Z of the object
StopObjectAtFloor CA5A LD A,($5BAE) Fetch the Z coordinate of the floor of the room and stash it in D.
CA5D LD D,A
StopObjectAtFloor_Test CA5E LD A,(IX+$03) Test whether the object ends up below the floor.
CA61 ADD A,H
CA62 CP D
CA63 RET NC Return if it does not.
CA64 SET 2,(IX+$0C) Flag the object as blocked in Z.
CA68 LD A,H Fetch the speed in Z.
CA69 CALL BringSpeedCloserToZero Bring it closer to zero.
CA6C LD H,A Store it.
CA6D JR NZ,StopObjectAtFloor_Test Jump back to StopObjectAtFloor_Test if it is not yet zero.
CA6F RET Return.
