D7AA: Draw Lines
Used by the routine at PrintSprite.
Draws the lines of a sprite one after the other. For each line the code jumps into the unrolled code, at a place that depends on the width of the sprite, and that is set by the jump that is changed by PrintSprite. The code for a sprite that is not on a byte boundary takes a pair of bytes off the stack, which are the mask and the data, shifts them across the two bytes of the buffer that they fall into with the table of shifted bytes in H, and keeps what is left of the second byte to go with the next pair.
DrawLines D7AA EX AF,AF' Stash the number of lines left.
D7AB LD A,(BC) Fetch the first byte of the buffer.
DrawLines_Jump D7AC JR DrawLines_Jump Jump into the unrolled code. The jump is changed to go to the right place.

DrawLines_Next D7FF LD A,C Fetch the low byte of the address in the buffer.
D800 ADD A,$00 Add the step to the start of the next line, which is changed for the width of the sprite.
D802 LD C,A Store it.
D803 LD A,B Fetch the high byte of the address in the buffer.
D804 ADC A,$00 Add the carry, as the step is a single byte.
D806 LD B,A Store it.
D807 EX AF,AF' Restore the number of lines left.
D808 DEC A Count down the lines.
D809 JP NZ,DrawLines Jump back to DrawLines until all of the lines are drawn.
D80C LD SP,($5BA9) Restore the stack pointer.
