6100: Game Entry Point
The first instruction run by the tape loader once the game has been loaded. The game uses 5BA0 as the top of its stack, so the stack grows down into the printer buffer, and then it jumps to StartGame to start a new game.
GameEntry 6100 DI Disable interrupts.
6101 LD SP,$5BA0 Set the stack pointer to 5BA0.
6104 NOP No operation.
6105 JP StartGame Jump to StartGame.
