CA9A: Leave Room To The West
Sends the player to the room to the west if it has gone past the west edge of the room. The X coordinate is set to 00 which PlacePlayerAtDoor takes as the sign that the player has come out of the west, and so puts it at the east side of the new room.
Input
HL The size of the room in X and Y
IX Address of the object
LeaveRoomToWest CA9A POP HL Unstack the size of the room in X and Y.
CA9B LD A,$80 Work out the coordinate of the west edge of the room.
CA9D SUB L
CA9E LD L,A
CA9F LD A,(IX+$01) Add the speed in X and the width of the player to the X coordinate.
CAA2 ADD A,(IX+$09)
CAA5 ADD A,(IX+$04)
CAA8 CP L Compare it with the west edge.
CAA9 RET NC Return if the player is still in the room.
CAAA LD (IX+$01),$00 Set the X coordinate to 00.
CAAE LD A,(IX+$08) Fetch the room number and stash it in L.
CAB1 LD L,A
CAB2 DEC A Go to the room to the west.
This entry point is used by the routine at LeaveRoomToEast.
Changes the column of the room number. The room number is the row in the high nibble and the column in the low nibble, and going past the last column wraps round to the first.
ChangeRoomEastWest CAB3 AND %00001111 Keep the column of the new room number.
CAB5 LD H,A Stash it in H.
CAB6 LD A,L Fetch the old room number.
CAB7 AND %11110000 Keep the row.
CAB9 OR H Combine the row with the new column.
This entry point is used by the routines at LeaveRoomToNorth and LeaveRoomToSouth.
Changes the room of the player. The player is flagged as entering the room, which gives the counter a start value of 03.
ChangeRoom CABA LD (IX+$08),A Store the new room number.
CABD LD A,(IX+$0C) Fetch the flags.
CAC0 OR %00110000 Set the counter of the player entering the room to 03.
CAC2 LD (IX+$0C),A Store the flags.
CAC5 LD A,(IX+$00) Fetch the graphic number and take 10 off it.
CAC8 SUB $10
CACA CP $40 Compare it with 40.
CACC RET NC Return if it is not one of the graphics of the human or the wulf.
CACD INC SP Drop the two return addresses on the stack, as the game loop starts again.
CACE INC SP
CACF INC SP
CAD0 INC SP
CAD1 PUSH IX Point HL at the player.
CAD3 POP HL
CAD4 LD DE,$D161 Point DE at PlayerCopy.
CAD7 LD BC,$0040 Set the length to 40 for the two halves of the player.
CADA LDIR Copy the player.
CADC LD A,($D161) Copy the graphic number of the bottom half into the field that holds the graphic the player has to have when it appears.
CADF LD ($D171),A
CAE2 LD A,($D181) Copy the graphic number of the top half into the same field of the top half.
CAE5 LD ($D191),A
CAE8 LD A,$78 Fetch the graphic number of the first of the sparkles that show the player appearing.
CAEA LD ($D161),A Set the graphic number of the bottom half of the copy.
CAED LD ($D181),A Set the graphic number of the top half of the copy.
CAF0 JP RunGame Start the game loop again, which builds the new room.
