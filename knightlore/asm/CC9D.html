CC9D: Test Overlap In X
Used by the routines at TestObjectIntersections, TestObjectCanBePickedUp, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether two objects overlap in X, once the first has moved by its new speed in X. They overlap when the distance between the X coordinates is smaller than the two widths added together.
Input
C New speed in X of the first object
IX Address of the first object
IY Address of the second object
Output
F The carry flag is set if the objects overlap
TestOverlapInX CC9D LD A,(IX+$04) Add the width of the first object to the width of the second object.
CCA0 ADD A,(IY+$04)
CCA3 LD D,A Stash the total in D.
CCA4 LD A,(IX+$01) Take the X coordinate of the second object off the X coordinate of the first object plus the new speed.
CCA7 ADD A,C
CCA8 SUB (IY+$01)
CCAB JP P,TestOverlapInX_TakeWidths Jump to TestOverlapInX_TakeWidths if it is not negative.
CCAE NEG Make it positive.
TestOverlapInX_TakeWidths CCB0 SUB D Take the total widths off it, which sets the carry flag if the objects overlap.
CCB1 RET Return.
