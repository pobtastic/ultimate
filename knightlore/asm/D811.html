D811: Calculate Buffer Address
Used by the routines at PrintTextSingleColour, PrintText, DisplayObjectsCarried, CopyAreaToScreen, DrawChangedObjects and PrintSprite.
Finds the address in the screen buffer of the byte that holds a pixel. The buffer has the lines of the screen from the bottom, 20 bytes to a line.
Input
B Pixel Y coordinate
C Pixel X coordinate
Output
BC Address in the buffer
CalculateBufferAddress D811 PUSH HL Stash HL.
D812 SRL B Divide BC by two.
D814 RR C
D816 SRL B Divide BC by four.
D818 RR C
D81A SRL B Divide BC by eight, to make the number of the byte.
D81C RR C
D81E LD HL,$D8F3 Point HL at ScreenBuffer.
D821 ADD HL,BC Add the two.
D822 LD C,L Put the address in BC.
D823 LD B,H
D824 POP HL Restore HL.
D825 RET Return.
