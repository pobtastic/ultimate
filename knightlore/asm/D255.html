D255: Draw Panel
Used by the routine at RunGame.
Draws the shapes of the panel at the bottom of the screen, using the sprites in the table at PanelSprites. On each side there is a run of five sprites that go up or down in steps, followed by two more sprites. The right side is the left side flipped.
After DrawPanel and UpdateScreen
Draw the left side of the panel, then the flipped right side.
DrawPanel D255 LD IX,$BFDB Point IX at the object that holds the details of the sprites of the panel, PanelObject.
D259 LD HL,$D27E Point HL at PanelSprites.
D25C CALL SetSpriteDetails Set the details of the first sprite.
D25F LD DE,$F810 Set the offsets to 10 in X and F8 in Y, which is 08 down.
D262 LD B,$05 Set the number of sprites to 05.
D264 CALL PrintSprites Draw the run of sprites on the left.
D267 CALL PrintTableSprite Draw the second sprite on the left.
D26A CALL PrintTableSprite Draw the third sprite on the left.
D26D CALL SetSpriteDetails Set the details of the first sprite on the right.
D270 LD DE,$0810 Set the offsets to 10 in X and 08 in Y, which is 08 up.
D273 LD B,$05 Set the number of sprites to 05.
D275 CALL PrintSprites Draw the run of sprites on the right.
D278 CALL PrintTableSprite Draw the second sprite on the right.
D27B JP PrintTableSprite Jump to PrintTableSprite.
