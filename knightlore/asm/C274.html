C274: Find Next Object Required
Used by the routines at HandleCauldronBubbles and HandleObjectAtCentreOfRoom.
Finds the number of the object that the player has to put into the cauldron next.
Output
HL Address of the number of the object in the list at RequiredObjects
FindNextObjectRequired C274 LD A,($5BBB) Fetch the number of charms in the cauldron from Charms.
C277 LD HL,$C27D Point HL at RequiredObjects.
C27A JP AddAToHL Find the address of the object that is needed.
