C4AA: Handle Block
Handles the graphic number 3E which is a block that can fall. Its speeds in X and Y are cleared, so that it only falls, and the sound of a block is played.
Input
IX Address of the block object
HandleBlock C4AA CALL SetPixelAdjustments_Block Set the pixel adjustments of a block.
C4AD CALL MovePlayer_Stop Clear the speeds in X and Y.
C4B0 CALL PlayPitchFromTable Play the sound of a block.
C4B3 JP MoveAndDrawObject Move the block and flag it to be drawn again.
