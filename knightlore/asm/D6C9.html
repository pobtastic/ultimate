D6C9: Calculate Pixel Coordinates
Used by the routines at HandlePickupAndDrop, CalculateSpriteSize and DrawObject.
Works out the pixel coordinates of an object on the screen from its X, Y and Z coordinates. The pixel X coordinate is X + Y - 80 and the pixel Y coordinate (from the bottom of the screen) is half of Y - X + 80 plus Z, less 68 each with the adjustments of the object added.
Input
IX Address of the object
Output
F The carry flag is set if the sprite is on the screen, and reset if
it is off the top
CalculatePixelCoordinates D6C9 LD A,(IX+$01) Add the Y coordinate to the X coordinate.
D6CC ADD A,(IX+$02)
D6CF SUB $80 Take 80 off it.
D6D1 ADD A,(IX+$12) Add the adjustment of the pixel X coordinate.
D6D4 LD (IX+$1A),A Set the pixel X coordinate.
D6D7 LD A,(IX+$02) Take the X coordinate off the Y coordinate.
D6DA SUB (IX+$01)
D6DD ADD A,$80 Add 80.
D6DF SRL A Halve it.
D6E1 ADD A,(IX+$03) Add the Z coordinate.
D6E4 SUB $68 Take 68 off it.
D6E6 ADD A,(IX+$13) Add the adjustment of the pixel Y coordinate.
D6E9 LD (IX+$1B),A Set the pixel Y coordinate.
D6EC CP $C0 Compare it with the number of lines of the screen.
D6EE RET Return.
