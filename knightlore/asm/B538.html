B538: Test Object Solid
Used by the routines at TestObjectIntersections, BlockMovementInX, BlockMovementInY and BlockMovementInZ.
Tests whether the object that IY points at is present and is not flagged to be ignored in the 3D calculations.
Input
IY Address of the object
Output
F Zero flag set if the object is empty or ignored
TestObjectSolid B538 LD A,(IY+$00) Fetch the graphic number of the object.
B53B AND A Test it, as zero means that there is no object.
B53C RET Z Return if there is no object.
B53D LD A,(IY+$07) Fetch the flags of the object.
B540 CPL Invert them.
B541 AND %00000010 Keep the ignore flag, which is now clear if the object is ignored.
B543 RET Return.
