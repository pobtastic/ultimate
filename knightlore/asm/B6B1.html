B6B1: Handle Block Moving North South
Handles a block that slides to and fro along the Y axis. The block follows a triangle wave that is worked out from the frame counter, so that it keeps in step however long the room has been on the screen. The code of HandleMovingBlock is modified to use the Y coordinate and Y speed of the block.
Input
IX Address of the block object
HandleBlockMovingNorthSouth B6B1 CALL PlaySoundFromYPosition Play the sound of a block moving along the Y axis.
B6B4 LD HL,$020A Set H to the offset of the Y coordinate and L to the offset of the speed in Y.
B6B7 JR HandleMovingBlock Jump to HandleMovingBlock.
