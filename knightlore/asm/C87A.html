C87A: Test Player In Room
Used by the routines at HandlePickupAndDrop and HandlePlayerLegs.
Tests whether the player is inside the room. The distance from the middle of the room (80) has to be smaller than the size of the room, less the width of the player in X and less the depth of the player in Y.
Input
IX Address of the object
Output
F The carry flag is set if the player is inside the room
TestPlayerInRoom C87A LD HL,($5BAB) Fetch the size of the room in X and Y.
C87D LD A,L Take the width of the player off the size in X.
C87E SUB (IX+$04)
C881 LD L,A
C882 LD A,H Take the depth of the player off the size in Y.
C883 SUB (IX+$05)
C886 LD H,A
C887 LD A,(IX+$01) Fetch the X coordinate relative to the middle of the room.
C88A SUB $80
C88C JP P,TestPlayerInRoom_LimitX Jump to TestPlayerInRoom_LimitX if it is not negative.
C88F NEG Make it positive.
TestPlayerInRoom_LimitX C891 CP L Compare it with the limit in X.
C892 RET NC Return with the carry flag reset if the player is outside the room.
C893 LD A,(IX+$02) Fetch the Y coordinate relative to the middle of the room.
C896 SUB $80
C898 JP P,TestPlayerInRoom_CompareY Jump to TestPlayerInRoom_CompareY if it is not negative.
C89B NEG Make it positive.
TestPlayerInRoom_CompareY C89D CP H Compare it with the limit in Y, which sets the carry flag if the player is inside.
C89E RET Return.
