D847: Update Destroyed Monster
The routine for objects of type 84 to 87, the flash that shows a monster that has been destroyed. The border of the screen is set to a colour from the frame counter, and on every other frame the object moves on to the next sprite. It is removed after the fourth sprite.
UpdateDestroyedMonster D847 LD A,($BBB2) Set the colour of the border from the frame counter.
D84A RLCA
D84B RLCA
D84C RLCA
D84D AND $38
D84F LD ($BBFB),A
D852 LD A,($BBB2) Return unless the frame counter is odd.
D855 AND $01
D857 RET Z
D858 INC (IX+$00) Move on to the next sprite, and return unless it was the last.
D85B LD A,(IX+$00)
D85E AND $03
D860 RET NZ
D861 LD (IX+$00),A Remove the object and return.
D864 RET
