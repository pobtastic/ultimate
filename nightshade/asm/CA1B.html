CA1B: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute CA1B AND A Jump to FlashChosenLine_NoFlash if the line is not the first.
CA1C JR NZ,FlashChosenLine_NoFlash
FlashChosenLine_Flash CA1E SET 7,(HL) Set bit 7 of the attribute.
CA20 JR FlashChosenLine_Skip Jump to FlashChosenLine_Skip.
FlashChosenLine_Next CA22 DEC A Jump to FlashChosenLine_Flash if this is the line.
CA23 JR Z,FlashChosenLine_Flash
FlashChosenLine_NoFlash CA25 RES 7,(HL) Reset bit 7 of the attribute.
FlashChosenLine_Skip CA27 INC HL Move on to the next line.
CA28 DJNZ FlashChosenLine_Next Jump to FlashChosenLine_Next until all of the lines have been done.
CA2A RET Return.
