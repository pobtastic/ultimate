CD02: Remove All Objects
Used by the routine at GameOver.
Removes every object by setting the types of all 17 objects to zero.
RemoveAllObjects CD02 LD HL,$BC8E Point at the object table, set the distance from one object to the next (10 bytes) and set a counter for the 17 objects.
CD05 LD DE,$0010
CD08 LD B,$17
RemoveAllObjects_Loop CD0A LD (HL),$00 Remove an object, and loop back until all of them have been removed.
CD0C ADD HL,DE
CD0D DJNZ RemoveAllObjects_Loop
CD0F RET Return.
