E2DA: Read Keyboard
Used by the routine at ReadControls.
Reads the controls from the keyboard. Left is X, V, M or B, right is C or N, forward is any key from A to G or from H to ENTER, fire is any key from Q to T or from Y to P, and down is any key from 1 to 5 or from 6 to 0.
ReadKeyboard E2DA LD A,$FE Read the keys CAPS SHIFT, Z, X, C and V.
E2DC CALL ReadKeyboardPort
E2DF RRCA Move the keys X and C into bits 0 and 1, for left and right.
E2E0 RRCA
E2E1 BIT 2,A Set the control for left as well if the key V is pressed.
E2E3 JR Z,ReadKeyboard_Right
E2E5 SET 0,A
ReadKeyboard_Right E2E7 AND $03 Keep the controls for X and C, and start with them.
E2E9 LD C,A
E2EA LD A,$7F Read the keys SPACE, SYMBOL SHIFT, M, N and B.
E2EC CALL ReadKeyboardPort
E2EF BIT 2,A Set the control for left if the key M is pressed.
E2F1 JR Z,ReadKeyboard_KeyN
E2F3 SET 0,C
ReadKeyboard_KeyN E2F5 BIT 3,A Set the control for right if the key N is pressed.
E2F7 JR Z,ReadKeyboard_KeyB
E2F9 SET 1,C
ReadKeyboard_KeyB E2FB BIT 4,A Set the control for left if the key B is pressed.
E2FD JR Z,ReadKeyboard_Forward
E2FF SET 0,C
ReadKeyboard_Forward E301 LD A,$BD Read the keys A to G and H to ENTER.
E303 CALL ReadKeyboardPort
E306 JR Z,ReadKeyboard_Fire Set the control for forward if any of them are pressed.
E308 SET 2,C
ReadKeyboard_Fire E30A LD A,$DB Read the keys Q to T and Y to P, and set the control for fire if any of them are pressed.
E30C CALL ReadKeyboardPort
E30F JR Z,ReadKeyboard_Down
E311 SET 3,C
ReadKeyboard_Down E313 LD A,$E7 Read the keys 1 to 5 and 6 to 0, and set the control for down if any of them are pressed.
E315 CALL ReadKeyboardPort
E318 JR Z,ReadViewKey
E31A SET 4,C
