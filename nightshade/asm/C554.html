C554: Check Overlap With Next Object
Used by the routine at UpdateThrownItem.
Checks whether the object at IX overlaps the object that is four places further along the object table.
Input
IX Object
Output
F The carry flag is set if the objects overlap

C556 POP IY
C558 LD DE,$0040 Move IY on by four objects.
