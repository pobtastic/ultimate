6576: Strip Lists
The lists of strips that draw the tiles. Each list is made of sixteen pairs of bytes, for the sixteen strips that lie along the edge of a cell (see DrawStripsLeftToRight and DrawWallStrips). The first byte of each pair is the number of the strip, which is an index into the table at StripVariants for a cell or the table at WallStripTable for a cell with walls. The second byte is the number of a strip that is drawn sixty-four pixels below it, when the cell has walls.
