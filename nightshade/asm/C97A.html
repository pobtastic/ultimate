C97A: Messaging: Menu Text
The text of each of the eight lines of the menu. The last character of each has bit 7 set. The character after the year is the copyright symbol.
MenuText C97A DEFM "NIGHT SHAD","E"+$80 "NIGHT SHADE".
C985 DEFM "1 KEYBOAR","D"+$80 "1 KEYBOARD".
C98F DEFM "2 KEMPSTON JOYSTIC","K"+$80 "2 KEMPSTON JOYSTICK".
C9A2 DEFM "3 CURSOR JOYSTIC","K"+$80 "3 CURSOR JOYSTICK".
C9B3 DEFM "4 INTERFACE I","I"+$80 "4 INTERFACE II".
C9C1 DEFM "5 DIRECTIONAL CONTRO","L"+$80 "5 DIRECTIONAL CONTROL".
C9D6 DEFM "0 START GAM","E"+$80 "0 START GAME".
C9E2 DEFM "; 1985 A:C:G",":"+$80 Copyright symbol, "1985 A.C.G.".
