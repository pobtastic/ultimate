DFFA: Test Cell Moving Up
Used by the routine at TestMoveUp.
Tests an object that is moving up the screen (along the positive Y axis) against the walls in one cell. If the object hits a wall then its velocity along the Y axis is reduced by twice the depth that it has gone into the wall, and the flag for a collision is set.
Input
DE X position to test
HL Y position to test
IX Object
Output
F The carry flag is set if there was a collision
Check the walls, then push the object back if it is touching one.
