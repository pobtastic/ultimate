E00B: Test Cell Moving Down
Used by the routine at TestMoveDown.
Tests an object that is moving down the screen (along the negative Y axis) against the walls in one cell, in the same way as TestCellMovingUp.
Input
DE X position to test
HL Y position to test
IX Object
Output
F The carry flag is set if there was a collision
TestCellMovingDown E00B CALL CheckWallsHorizontalFirst Check whether the object hits a wall in the cell.
E00E RET NC Return if it did not.
E00F NEG Make the depth positive, and jump to ReduceVelocityY to reduce the velocity.
E011 JR ReduceVelocityY
