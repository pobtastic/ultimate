E250: Read Interface 2 Joystick
Reads the controls from a Sinclair joystick, which can be in either of the two sockets (using the keys 1 to 5 or the keys 6 to 0).
ReadInterface2Joystick E250 LD A,$F7 Read the keys 1 to 5.
E252 CALL ReadKeyboardPort
E255 PUSH BC Save the registers, and count five keys.
E256 LD B,$05
ReadInterface2Joystick_Reverse E258 RRA Reverse the order of the five keys.
E259 RL C
E25B DJNZ ReadInterface2Joystick_Reverse
E25D LD A,C Get the registers back, and keep the reversed keys.
E25E POP BC
E25F LD C,A
E260 LD A,$EF Read the keys 6 to 0.
E262 CALL ReadKeyboardPort
E265 OR C Combine them with the keys 1 to 5, so that the joysticks are the same.
E266 LD C,$00 Start with none of the controls.
E268 BIT 0,A Set the control for fire if the key for fire is pressed.
E26A JR Z,ReadInterface2Joystick_Forward
E26C SET 3,C
ReadInterface2Joystick_Forward E26E BIT 1,A Set the control for forward if the key for up is pressed.
E270 JR Z,ReadInterface2Joystick_Down
E272 SET 2,C
ReadInterface2Joystick_Down E274 BIT 2,A Set the control for down if the key for down is pressed.
E276 JR Z,ReadInterface2Joystick_Right
E278 SET 4,C
ReadInterface2Joystick_Right E27A BIT 3,A Set the control for right if the key for right is pressed.
E27C JR Z,ReadInterface2Joystick_Left
E27E SET 1,C
ReadInterface2Joystick_Left E280 BIT 4,A Set the control for left if the key for left is pressed.
E282 JR Z,ReadInterface2Joystick_ViewKey
E284 SET 0,C
ReadInterface2Joystick_ViewKey E286 JP ReadViewKey Jump to ReadViewKey to read the key for turning the view.
