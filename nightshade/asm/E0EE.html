E0EE: Multiply A By DE
Used by the routine at FlipSprite.
Multiplies an 8-bit number by a 16-bit number.
Input
A Multiplier
DE Multiplicand
Output
HL The result
MultiplyAByDE E0EE LD HL,$0000 Start with a result of zero, and count eight bits.
E0F1 LD B,$08
MultiplyAByDE_Loop E0F3 ADD HL,HL Move on to the next bit of the multiplier, and jump to MultiplyAByDE_Next if it is not set.
E0F4 RLCA
E0F5 JR NC,MultiplyAByDE_Next
E0F7 ADD HL,DE Add the multiplicand to the result.
MultiplyAByDE_Next E0F8 DJNZ MultiplyAByDE_Loop Loop back until all the bits have been used.
E0FA RET Return.
