BDFE: Start Game
Used by the routine at GameEntry.
Checks that the game was started by the tape loader, clears the game variables, shows the game selection menu, sets up the status panel and the first life, and then falls into the main loop.
The first check is part of the copy protection: the game returns to BASIC if the high byte of the system variable FRAMES is not 63 (the loader arranges for it to be). The routine at BuildRandomTable makes a second check on the memory refresh register.

The main loop. Each pass updates every object, draws the view, and then checks for the game being paused.
MainLoop BE71 LD IX,$BC8E Start with the first object, which is the player.
MainLoop_UpdateObjects BE75 LD A,(IX+$00) Fetch the type of the object.
BE78 LD BC,$D599 Point at the table of routines that handle each type of object.
BE7B CALL JumpToTableRoutine Run the routine that handles this type of object.
BE7E CALL RandomNumber Update the random number generator.
BE81 LD BC,$0010 Set the size of an object to 10 bytes.
BE84 ADD IX,BC Move on to the next object.
BE86 PUSH IX Get the address of the next object.
BE88 POP HL
BE89 LD BC,$BDFE Point at the end of the object table.
BE8C AND A Subtract the end of the object table from the address of the next object.
BE8D SBC HL,BC
BE8F JR C,MainLoop_UpdateObjects Jump back to MainLoop_UpdateObjects until every object has been updated.
