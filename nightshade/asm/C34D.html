C34D: Sound Pitch Tables
Five tables of sixteen pitches: one for the ghost (see PlayGhostSound) and one for each of the four kinds of monster.
The game uses the table for the ghost. It does not use the four tables for the monsters: UpdateMonster passes only the offset of a table to PlayFlaggedSound, so the pitches of the monsters come from the ROM, starting at 80.
