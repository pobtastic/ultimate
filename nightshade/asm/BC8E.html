BC8E: Object Table
The table of objects, which holds everything that moves in the village. There are 17 objects of 10 bytes each, and MainLoop updates them in turn.
The type of an object chooses the routine that updates it (see ObjectHandlerTable) and the sprite that draws it (see SpriteTable). An object of type 00 is not in use.
Byte Contents
00 Type
01 Position along the X axis within the cell
02 Column of the cell
03 Position along the Y axis within the cell
04 Row of the cell
05 Speed (or the kind of tile, for an item)
06 Direction (bits 6 and 7) and timer (bits 0 to 5)
07 Flags
08 Half of the width
09 Half of the depth
0A Velocity along the X axis
0B Velocity along the Y axis
0C Offset of the sprite along the X axis
0D Offset of the sprite along the Y axis
0E Screen position of the sprite, low byte
0F Screen position of the sprite, high byte
The flags are bit 0 (the object has hit something), bit 1 (the object has been drawn), bit 5 (the object chases the player) and bits 6 and 7 (the sprite is to be turned round and upside down, see FlipSprite).
