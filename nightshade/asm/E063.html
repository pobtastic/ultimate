E063: Check Walls Vertical First
Used by the routines at TestCellMovingRight and TestCellMovingLeft.
Tests an object against the walls in a cell, by testing it against each rectangle of the tile of the cell in turn, with the position along the Y axis first. The rectangles are four bytes each (the X and Y positions of the centre, then the half width and half depth), and a zero X position ends the list.
Input
DE X position to test
HL Y position to test
IX Object
Output
A The depth that the object has gone into the wall along the X axis
negative
F The carry flag is set if there was a collision
CheckWallsVerticalFirst E063 CALL FindPositionInCell Find the position in the cell and the tile.
E066 LD BC,$6334 Find the list of rectangles for the tile.
E069 CALL GetTableEntry
E06C PUSH HL Use the list of rectangles.
E06D POP IY
CheckWallsVerticalFirst_Loop E06F LD A,(IY+$00) Return if there are no more rectangles.
E072 AND A
E073 RET Z
E074 CALL CheckOverlapAlongY Jump to CheckWallsVerticalFirst_Next to try the next rectangle if the object is not touching this one along the Y axis.
E077 JR NC,CheckWallsVerticalFirst_Next
E079 CALL CheckOverlapAlongX Return if it is touching along the X axis as well.
E07C RET C
CheckWallsVerticalFirst_Next E07D INC IY Move on to the next rectangle.
E07F INC IY
E081 INC IY
E083 INC IY
E085 JR CheckWallsVerticalFirst_Loop Jump back to check it.
