C949: Flash Menu Options
Used by the routine at GameMenu.
Makes the attributes of the lines of the menu for the chosen control method and for directional control flash.
FlashMenuOptions C949 LD HL,$C963 Point at the attribute of the first control method.
C94C LD A,($BBB0) Fetch the control options.
C94F RRCA Move the chosen control method into the lowest two bits.
C950 AND %00000011 Keep only the chosen control method.
C952 LD B,$04 Set a counter for the four control methods.
C954 CALL SetFlashingAttribute Make the line for the chosen control method flash.
C957 RES 7,(HL) Turn off the flashing of the line for directional control.
C959 LD A,($BBB0) Fetch the control options again.
C95C AND %00001000 Keep only the directional control bit.
C95E RET Z Return if directional control has not been chosen.
C95F SET 7,(HL) Make the line for directional control flash.
C961 RET Return.
