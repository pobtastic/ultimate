D4F3: Project Object
Used by the routine at DrawObject.
Works out where an object is on the screen, in the same way as ProjectCell. It fetches the position from the slot, calls ConvertPosition, and jumps to ProjectCell_Position. The result is put in ScreenXPosition and ScreenYPosition.
Input
IX The address of the object
Fetch the position and convert it.
ProjectObject D4F3 LD L,(IX+$03) Fetch the vertical position.
D4F6 LD H,(IX+$04)
D4F9 CALL ConvertPosition Call ConvertPosition.
D4FC PUSH HL Stash it on the stack.
D4FD LD L,(IX+$01) Fetch the horizontal position.
D500 LD H,(IX+$02)
D503 CALL ConvertPosition Call ConvertPosition.
D506 JR ProjectCell_Position Jump to ProjectCell_Position.
