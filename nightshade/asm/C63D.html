C63D: Play Music Once
Used by the routine at GameMenu.
Plays a tune, which is stopped by any key being pressed. A tune that has been started is not started again.
Input
DE Address of the tune
PlayMusicOnce C63D LD HL,$BBC1 Return if this tune has been played before.
C640 LD A,(HL)
C641 AND A
C642 RET NZ
C643 SET 0,(HL) Remember that the tune has been played.
PlayMusicOnce_Loop C645 XOR A Read every row of the keyboard at once.
C646 CALL ReadKeyboardPort Check whether a key is being pressed.
C649 JR Z,PlayMusicOnce_Note Jump to PlayMusicOnce_Note to play the next note if no key is being pressed.
C64B RET Return, to stop the tune.
PlayMusicOnce_Note C64C LD A,(DE) Fetch the next note and jump to PlayMusic_Return if it marks the end of the tune.
C64D CP $FF
C64F JR Z,PlayMusic_Return Play the note.
C651 CALL PlayNote
C654 JR PlayMusicOnce_Loop Jump back to PlayMusicOnce_Loop to check the keyboard again.
