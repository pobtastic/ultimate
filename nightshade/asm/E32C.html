E32C: Pause Game
Used by the routine at StartGame.
Pauses the game when CAPS SHIFT or SPACE is pressed on its own. The game continues when the key has been pressed again.
PauseGame E32C LD A,$7E Read the keys CAPS SHIFT, Z, X, C, V, SPACE, SYMBOL SHIFT, M, N and B.
E32E CALL ReadKeyboardPort
E331 BIT 0,A Return if neither of the keys CAPS SHIFT or SPACE is pressed.
E333 RET Z
E334 AND $1E Return if any of the other keys is pressed too.
E336 RET NZ
Wait for the key to be released.
PauseGame_Release E337 LD A,$7E Read the keys, and loop back until neither of the keys is pressed.
E339 CALL ReadKeyboardPort
E33C BIT 0,A
E33E JR NZ,PauseGame_Release
Wait for a key to be pressed.
PauseGame_Press E340 LD A,$7E Read the keys, and loop back until one of the keys is pressed.
E342 CALL ReadKeyboardPort
E345 BIT 0,A
E347 JR Z,PauseGame_Press
Wait for the key to be released.
PauseGame_ReleaseAgain E349 LD A,$7E Read the keys, and loop back until neither of the keys is pressed.
E34B CALL ReadKeyboardPort
E34E BIT 0,A
E350 JR NZ,PauseGame_ReleaseAgain
E352 RET Return.
