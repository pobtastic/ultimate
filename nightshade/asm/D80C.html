D80C: Update Thrown Item
The routine for objects of type 08 to 0B the items that the player has thrown. The item flies in a straight line. If it hits the object that is four places along the object table (the monster that it belongs to), the monster is destroyed, 25 hundred points are added to the score and the monster explodes into fragments. If the item hits something else, it lands and becomes an item that can be picked up again (type 04 to 07).
