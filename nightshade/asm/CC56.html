CC56: Game Over
Used by the routines at StartNewLife and CheckMonstersDefeated.
Shows the game over screen, with the percentage of the game that has been completed and the score, and plays a tune. A new game is started if any of the monsters is still alive. Otherwise all of the monsters have been killed, so the ending is shown.
