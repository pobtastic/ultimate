D356: Colour Wall Column
Used by the routine at DrawWallStrips.
Sets the attributes of a column of AttributeBuffer from the strip to the bottom of the view. The colour is bright green, cyan, yellow or white, from the lowest two bits of WallTile.
Input
D The vertical position of the strip
E The horizontal position of the strip
Return unless the strip is in the view.
ColourWallColumn D356 LD A,D Return if it is below the bottom of the view.
D357 SUB $BF
D359 RET NC
D35A NEG Make the number of pixel rows to the bottom.
D35C SRL A Divide it by eight.
D35E SRL A
D360 SRL A
D362 RET Z Return if there are none.
Colour the column.
D363 LD B,A Set the number of character rows.
