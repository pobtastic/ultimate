C481: Pick Up Special Item
Used by the routine at PickUpItem.
Works out the number of an item from the type of the object that has been picked up (an object of type 30 or above).
Input
A Type of the object
HL Address of the free place in the inventory
IX Object
PickUpItem_Special C481 RRA Divide the type by four, keep the lowest two bits and add five, to make the number of the item. Jump to PickUpItem_Store to put it in the inventory.
C482 RRA
C483 AND $03
C485 ADD A,$05
C487 JR PickUpItem_Store
