E528: End Sprite Row
Used by the routine at DrawAlignedColumns_Five.
Moves on to the next row of a sprite after one has been drawn. The number that is added to the address in the screen buffer is set by DrawSprite.
Input
BC Address in the screen buffer
EndSpriteRow E528 LD A,C Add the number of bytes to the next row to the low byte of the address (the number is set by the code that sets up the drawing).
E529 ADD A,$00
E52B LD C,A
E52C LD A,B Add the carry to the high byte.
E52D ADC A,$00
E52F LD B,A
E530 EX AF,AF' Get the number of rows left back.
E531 DEC A Count down the number of rows.
E532 JP NZ,DrawSpriteRow Loop back to draw the next row.
E535 LD SP,($BBAE) Get the stack pointer back, and return.
E539 RET
