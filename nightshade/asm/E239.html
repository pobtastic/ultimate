E239: Read Keyboard Port
Used by the routines at PlayMusicOnce, GameMenu, ReadInterface2Joystick, ReadCursorJoystick, ReadKeyboard, ReadViewKey and PauseGame.
Reads half of the keyboard. The bits of the half-row of keys to read are zero, and more than one half-row can be read at once.
Input
A Half-rows to read
Output
A The keys that are pressed (bits 0 to 4, with bit 0 for the key
nearest the edge of the keyboard)
F The zero flag is set if no keys are pressed
ReadKeyboardPort E239 OUT ($FD),A Write the half-row selector to port FD. The ULA only responds to even port numbers, so this has no effect on the 48K Spectrum, but it leaves the selector in A for the next instruction.
E23B IN A,($FE) Read the keyboard.
E23D CPL Make the pressed keys into set bits, and return.
E23E AND $1F
E240 RET
