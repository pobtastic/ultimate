BF48: Mark Cell Visited
Used by the routine at SpeedPlayerUp.
Records that the object at IX has entered a cell of the village by setting its bit in the bitmap of visited cells at VisitedCells. The bitmap holds one bit for each of the 20 by 20 cells.
The routine does nothing if the cell is the same as the one visited last time. When the cell holds anything other than open ground and has not been visited before, a four note sound effect is started.

IX Object

Find the byte and the bit of the bitmap for the cell. The byte is (row * 4 + column / 8) and the bit is (column MOD 8).

BF68 RLA Shift the column left by three places.
BF69 RLA
BF6A RLA
BF6B LD H,A Keep the shifted column.
BF6C RLA Shift the top bits of the column into L, so that L holds (row * 4 + column / 8).
BF6D RL L
BF6F RLA
BF70 RL L
BF72 LD A,H Fetch the shifted column.
BF73 LD H,$00 Clear the high byte of the offset.
BF75 LD BC,$BC0E Point at the bitmap of visited cells.
BF78 ADD HL,BC Add the offset to find the byte.
BF79 AND %00111000 Keep the bits that give the bit number (column MOD 8) in bits 3 to 5.
BF7B OR %01000110 Turn this into the opcode of a BIT n,(HL) instruction.
BF7D LD ($BF86),A Change the second byte of the instruction at BF85 to it.
BF80 OR %10000000 Turn it into the opcode of a SET n,(HL) instruction.
BF82 LD ($BF88),A Change the second byte of the instruction at BF87 to it.
BF85 BIT 0,(HL) Test the bit for the cell (the code changes itself). The zero flag is set if the cell has not been visited before.
BF87 SET 0,(HL) Set the bit (self-modifying code).
BF89 RET Return.

MarkCellVisited_Feature BF8A CALL MarkCellVisited_SetBit Record the cell as visited.
BF8D RET NZ Return if the cell has been visited before.
