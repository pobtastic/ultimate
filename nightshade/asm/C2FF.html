C2FF: Print Score
Used by the routine at StartGame.
Prints the score, as seven digits, in the status panel. The last two digits are always zero.
After PrintScore
Set the colour and the position of the score.
PrintScore C2FF LD A,$46 Use bright yellow ink (attribute 46), and stash it for printing the digits.
C301 EX AF,AF'
C302 LD HL,$50E6 Set the screen position of the score to 50E6 (in the screen buffer).
This entry point is used by the routine at GameOver.
Point at the score and the digit font.
PrintScore_Position C305 LD DE,$BBC9 Point at the score, and set the number of bytes to print to four.
C308 LD B,$04
C30A PUSH HL Stash the screen position on the stack.
C30B LD HL,$6CDE Point at the font of the digits.
C30E LD ($BBAC),HL Set it as the font.
C311 POP HL Restore the screen position from the stack.
C312 JR PrintBCDNumber_LowerDigit Jump to PrintBCDNumber_LowerDigit to print the digits, starting with the lower digit of the first byte.
