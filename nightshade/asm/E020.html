E020: Test Cell Moving Left
Used by the routine at TestMoveLeft.
Tests an object that is moving to the left (along the negative X axis) against the walls in one cell, in the same way as TestCellMovingRight.
Input
DE X position to test
HL Y position to test
IX Object
Output
F The carry flag is set if there was a collision
TestCellMovingLeft E020 CALL CheckWallsVerticalFirst Check whether the object hits a wall in the cell.
E023 RET NC Return if it did not.
E024 NEG Make the depth positive, and jump to ReduceVelocityX to reduce the velocity.
E026 JR ReduceVelocityX
