E0A0: Check Walls Horizontal First
Used by the routines at TestCellMovingUp and TestCellMovingDown.
Tests an object against the walls in a cell, in the same way as CheckWallsVerticalFirst but with the position along the X axis first.
Input
DE X position to test
HL Y position to test
IX Object
Output
A The depth that the object has gone into the wall along the Y axis
negative
F The carry flag is set if there was a collision
CheckWallsHorizontalFirst E0A0 CALL FindPositionInCell Find the position in the cell and the tile.
E0A3 LD BC,$6334 Find the list of rectangles for the tile.
E0A6 CALL GetTableEntry
E0A9 PUSH HL Use the list of rectangles.
E0AA POP IY
CheckWallsHorizontalFirst_Loop E0AC LD A,(IY+$00) Return if there are no more rectangles.
E0AF AND A
E0B0 RET Z
E0B1 CALL CheckOverlapAlongX Check whether the object is touching the rectangle along the X axis.
E0B4 JR NC,CheckWallsHorizontalFirst_Next Jump to CheckWallsHorizontalFirst_Next to try the next rectangle if it is not.
E0B6 CALL CheckOverlapAlongY Check whether the object is touching it along the Y axis too.
E0B9 RET C Return if it is, as the object has hit the wall.
CheckWallsHorizontalFirst_Next E0BA INC IY Move on to the next rectangle.
E0BC INC IY
E0BE INC IY
E0C0 INC IY
E0C2 JR CheckWallsHorizontalFirst_Loop Jump back to check it.
