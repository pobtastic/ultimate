E31C: Read View Key
Used by the routines at ReadInterface2Joystick, ReadKempstonJoystick, ReadCursorJoystick and ReadKeyboard.
Reads the key for turning the view (Z or SYMBOL SHIFT), and keeps the controls in Controls.
Input
C Controls
ReadViewKey E31C LD A,$7E Read the keys CAPS SHIFT, Z, SPACE and SYMBOL SHIFT.
E31E CALL ReadKeyboardPort
E321 BIT 1,A Set the control for turning the view if the key Z or SYMBOL SHIFT is pressed.
E323 JR Z,ReadViewKey_Store
E325 SET 5,C
ReadViewKey_Store E327 LD A,C Store the controls and return.
E328 LD ($BC01),A
E32B RET
