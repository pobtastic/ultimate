D942: Update Monster Item
The routine for objects of type 04 to 07 the items that the monsters need, lying in the village. When the player touches one, the item is picked up.
UpdateMonsterItem D942 CALL CheckPlayerCollision Return if the item is not touching the player.
D945 RET NC
D946 LD HL,$0304 Start the item sound, which is sound effect 03 and has four notes.
D949 LD ($BBF9),HL
D94C JP PickUpItem Pick up the item.
