D273: Draw Strip
Used by the routines at DrawCell and DrawStripsLeftToRight.
Draws one strip of a cell, which is a graphic that is sixteen pixels wide. A strip is not drawn if its position is outside the view.
Input
C Variant of the strip (0 or 1)
IY Entry in the list of strips
DrawStrip D273 LD DE,($BBB6) Return if the X position of the strip is more than CF which is off the right of the view.
D277 LD HL,$00CF
D27A AND A
D27B SBC HL,DE
D27D RET C
D27E LD HL,$0010 Return if the X position of the strip is 10 or less, which is off the left of the view.
D281 SBC HL,DE
D283 RET NC
D284 LD HL,($BBB8) Return if the Y position of the strip is outside the range 00 to FF.
D287 LD A,H
D288 AND A
D289 RET NZ
D28A LD D,L Use the Y position of the strip, and keep the variant of the strip.
D28B LD A,C
D28C PUSH BC
D28D LD C,(IY+$00) Fetch the number of the strip.
D290 LD B,$00
D292 LD HL,$6542 Combine the variant with the entry for the strip in the table at StripVariants.
D295 ADD HL,BC
D296 XOR (HL)
D297 LD BC,$6FDC Find the graphic for the strip.
D29A CALL GetTableEntry
D29D CALL DrawStripGraphic Draw the graphic.
D2A0 POP BC Get the variant back, and return.
D2A1 RET
