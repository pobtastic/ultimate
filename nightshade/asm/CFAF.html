CFAF: Find Objects In Cell
Used by the routine at DrawCellAndObjects.
Makes a list of the objects that are in a cell, at ObjectList, ending with a zero word.
Input
H Row in the view
L Column in the view
FindObjectsInCell CFAF LD IY,$D15D Point IY at the list and IX at the first object.
CFB3 LD IX,$BC8E
CFB7 CALL ConvertCell Turn the cell into the column and the row on the map.
CFBA EX DE,HL
FindObjectsInCell_Loop CFBB LD A,(IX+$00) Jump to FindObjectsInCell_Next to move on if the object is free.
CFBE AND A
CFBF JR Z,FindObjectsInCell_Next
CFC1 LD A,E Jump to FindObjectsInCell_Next to move on if the object is not in the column.
CFC2 CP (IX+$02)
CFC5 JR NZ,FindObjectsInCell_Next
CFC7 LD A,D Jump to FindObjectsInCell_Next to move on if the object is not in the row.
CFC8 CP (IX+$04)
CFCB JR NZ,FindObjectsInCell_Next
CFCD PUSH IX Get the address of the object.
CFCF POP HL
CFD0 LD (IY+$00),L Add the address of the object to the list.
CFD3 LD (IY+$01),H
CFD6 INC IY Move on to the next place in the list.
CFD8 INC IY
FindObjectsInCell_Next CFDA LD BC,$0010 Move on to the next object.
CFDD ADD IX,BC
CFDF PUSH IX Get the address of the object.
CFE1 POP HL
CFE2 LD BC,$BDFE Check whether the end of the object table at StartGame has been reached.
CFE5 AND A
CFE6 SBC HL,BC
CFE8 JR C,FindObjectsInCell_Loop Loop back until all 17 objects have been checked.
CFEA XOR A Add the zero word that marks the end of the list.
CFEB LD (IY+$00),A
CFEE LD (IY+$01),A
CFF1 RET Return.
