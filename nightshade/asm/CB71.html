CB71: Move Down Row
Used by the routines at PickUpItem, DrawInventoryTube, DrawVerticalEdge, PrintCharacterBlock and DrawLifeIcon.
Moves a screen address down by one character row.
Input
HL Screen address
Output
HL The screen address one character row below
MoveDownRow CB71 LD A,L Move down one character row, and return if that is still within the same third of the screen.
CB72 ADD A,$20
CB74 LD L,A
CB75 RET NC
CB76 LD A,H Otherwise move to the first row of the next third of the screen and return.
CB77 ADD A,$08
CB79 LD H,A
CB7A RET
