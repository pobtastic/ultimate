C057: Clear Short-Lived Objects
Used by the routine at StartNewLife.
Removes everything that is short-lived (the ghosts, bursts, fragments and bonuses held in the six objects at ObjectTable_Transient) by changing their types to zero.
ClearShortLivedObjects C057 LD HL,$BD9E Start with the first short-lived object.
C05A LD DE,$0010 Set the distance between one object and the next (10 bytes).
C05D LD B,$06 Set a counter for the six objects.
ClearShortLivedObjects_Loop C05F LD (HL),$00 Remove the object.
C061 ADD HL,DE Move on to the next object.
C062 DJNZ ClearShortLivedObjects_Loop Loop back until all six objects have been removed.
C064 RET Return.
