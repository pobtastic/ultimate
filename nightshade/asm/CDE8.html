CDE8: Spawn Ball
Used by the routine at StartGame.
Starts a ball (a type 80 object, which turns into a creature - see UpdateBall) in one of the short-lived objects at ObjectTable_Transient. It is done on every fourth frame, once the player has finished materialising, and the ball is placed in a cell that is next to the player or the same one as the player, as long as that cell is not solid.
SpawnBall CDE8 LD A,($BC02) Return unless the player has finished materialising.
CDEB CP $70
CDED RET NZ
CDEE LD A,($BBB2) Return unless this is the fourth frame (the frame counter is 03 modulo four).
