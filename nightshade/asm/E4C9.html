E4C9: Draw Sprite Row
Used by the routines at DrawSprite and EndSpriteRow.
Starts drawing a row of a sprite, by jumping into the code for the width of the sprite. The offset of the jump is set by DrawSprite.
Input
A' Number of rows left to draw
BC Address in the screen buffer
DrawSpriteRow E4C9 EX AF,AF' Keep the number of rows left to draw.
E4CA LD A,(BC) Fetch the first byte of the row from the screen buffer.
DrawSpriteRow_Jump E4CB JR DrawSpriteRow_Jump Jump into the row to draw the characters (the offset is changed by the code that sets up the drawing).
