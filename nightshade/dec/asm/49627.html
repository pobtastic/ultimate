49627: Build Random Table
Used by the routine at StartGame.
Fills the 34 bytes at ItemsLeft_Tiles with random numbers from 16 to 31, taken from a random place in the ROM.
The routine then makes the second part of the copy protection check: it returns if bit 7 of the memory refresh register is set (the loader sets it, see Decryption), and resets the computer if not.
