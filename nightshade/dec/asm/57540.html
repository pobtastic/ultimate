57540: Check Overlap Along Y
Used by the routines at CheckWallsVerticalFirst and CheckWallsHorizontalFirst.
Checks whether an object overlaps a rectangle along the Y axis, using the position that the velocity takes the object to.
Input
D Position of the object along the Y axis in the cell
IX Object
IY Rectangle
Output
A The depth that the object has gone into the rectangle (negative)
F The carry flag is set if the object overlaps the rectangle
CheckOverlapAlongY 57540 LD A,(IX+9) Work out the combined half depths of the object and the rectangle.
57543 SRL A
57545 ADD A,(IY+3)
57548 LD C,A
57549 LD A,(IX+11) Work out the distance along the Y axis, including the velocity.
57552 SRA A
57554 ADD A,D
57555 SUB (IY+1)
57558 JP P,CheckOverlapAlongY_Depth Make the distance positive.
57561 NEG
CheckOverlapAlongY_Depth 57563 SUB C Subtract the combined half depths and return.
57564 RET
