57936: Read Interface 2 Joystick
Reads the controls from a Sinclair joystick, which can be in either of the two sockets (using the keys 1 to 5 or the keys 6 to 0).
ReadInterface2Joystick 57936 LD A,247 Read the keys 1 to 5.
57938 CALL ReadKeyboardPort
57941 PUSH BC Save the registers, and count five keys.
57942 LD B,5
ReadInterface2Joystick_Reverse 57944 RRA Reverse the order of the five keys.
57945 RL C
57947 DJNZ ReadInterface2Joystick_Reverse
57949 LD A,C Get the registers back, and keep the reversed keys.
57950 POP BC
57951 LD C,A
57952 LD A,239 Read the keys 6 to 0.
57954 CALL ReadKeyboardPort
57957 OR C Combine them with the keys 1 to 5, so that the joysticks are the same.
57958 LD C,0 Start with none of the controls.
57960 BIT 0,A Set the control for fire if the key for fire is pressed.
57962 JR Z,ReadInterface2Joystick_Forward
57964 SET 3,C
ReadInterface2Joystick_Forward 57966 BIT 1,A Set the control for forward if the key for up is pressed.
57968 JR Z,ReadInterface2Joystick_Down
57970 SET 2,C
ReadInterface2Joystick_Down 57972 BIT 2,A Set the control for down if the key for down is pressed.
57974 JR Z,ReadInterface2Joystick_Right
57976 SET 4,C
ReadInterface2Joystick_Right 57978 BIT 3,A Set the control for right if the key for right is pressed.
57980 JR Z,ReadInterface2Joystick_Left
57982 SET 1,C
ReadInterface2Joystick_Left 57984 BIT 4,A Set the control for left if the key for left is pressed.
57986 JR Z,ReadInterface2Joystick_ViewKey
57988 SET 0,C
ReadInterface2Joystick_ViewKey 57990 JP ReadViewKey Jump to ReadViewKey to read the key for turning the view.
