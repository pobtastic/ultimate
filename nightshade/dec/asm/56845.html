56845: Set Direction From Velocity
Used by the routines at UpdateGhost, UpdateSpore and UpdateVillageItem.
Makes an object face the direction that it is moving in, and tests whether it can move that way. The direction along the X axis is used first, and then the one along the Y axis, so that an object that is moving along both axes ends up facing along the Y axis (if the velocity along that axis is not zero).
