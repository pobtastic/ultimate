49239: Clear Short-Lived Objects
Used by the routine at StartNewLife.
Removes everything that is short-lived (the ghosts, bursts, fragments and bonuses held in the six objects at ObjectTable_Transient) by changing their types to zero.
ClearShortLivedObjects 49239 LD HL,48542 Start with the first short-lived object.
49242 LD DE,16 Set the distance between one object and the next (16 bytes).
49245 LD B,6 Set a counter for the six objects.
ClearShortLivedObjects_Loop 49247 LD (HL),0 Remove the object.
49249 ADD HL,DE Move on to the next object.
49250 DJNZ ClearShortLivedObjects_Loop Loop back until all six objects have been removed.
49252 RET Return.
