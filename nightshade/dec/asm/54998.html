54998: Create Fragments
Used by the routine at UpdateThrownItem.
Creates four fragments (objects of type 140) at the position of an object, in the four objects from ObjectTable_Items. Each fragment flies off in a different direction.
Input
IY Object
Create four fragments at the object's position.
CreateFragments 54998 LD HL,48334 Point HL at the first fragment, and set a counter for four fragments.
55001 LD B,4
Copy the position and send this fragment on its way.
