58664: End Sprite Row
Used by the routine at DrawAlignedColumns_Five.
Moves on to the next row of a sprite after one has been drawn. The number that is added to the address in the screen buffer is set by DrawSprite.
Input
BC Address in the screen buffer
EndSpriteRow 58664 LD A,C Add the number of bytes to the next row to the low byte of the address (the number is set by the code that sets up the drawing).
58665 ADD A,0
58667 LD C,A
58668 LD A,B Add the carry to the high byte.
58669 ADC A,0
58671 LD B,A
58672 EX AF,AF' Get the number of rows left back.
58673 DEC A Count down the number of rows.
58674 JP NZ,DrawSpriteRow Loop back to draw the next row.
58677 LD SP,(48046) Get the stack pointer back, and return.
58681 RET
