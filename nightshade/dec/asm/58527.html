58527: Draw Aligned Columns
The code that draws a row of a sprite that is on a character boundary. There is a copy of the code for each of up to five characters, and the code is entered at the one that leaves the number of characters of the sprite, by DrawSprite. Each character takes a mask and pixels from the stack, and puts them on the screen buffer: the pixels under the mask are cleared, and then the pixels of the sprite are set.
Input
BC Address in the screen buffer
Draw the first character.
DrawAlignedColumns_Five 58527 POP DE Take the mask and the pixels of the first character from the stack.
58528 LD A,(BC) Fetch the byte of the screen buffer.
58529 CPL Clear the pixels under the mask, and set the pixels of the sprite.
