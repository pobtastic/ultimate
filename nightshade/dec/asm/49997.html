49997: Sound Pitch Tables
Five tables of sixteen pitches: one for the ghost (see PlayGhostSound) and one for each of the four kinds of monster.
The game uses the table for the ghost. It does not use the four tables for the monsters: UpdateMonster passes only the offset of a table to PlayFlaggedSound, so the pitches of the monsters come from the ROM, starting at 128.
SoundPitchTables 49997 DEFB 32,32,48,64,80,32,32,48,64,80,32,32,48,64,80,32 The pitches for the ghost.
SoundPitchTable_Monsters 50013 DEFB 32,32,48,48,64,64,80,80,96,96,112,112,128,128,144,144 The pitches for the four kinds of monster (not used by the game).
