51977: Draw Vertical Edge
Used by the routines at DrawPlayingAreaBorder and DrawFrame.
Draws a number of blocks of two by two characters down a column.
Input
A' Attribute
B Number of blocks
DE Address of the four characters in a block
HL Screen address of the first block
DrawVerticalEdge 51977 PUSH BC Keep the number of blocks and the address of the characters.
51978 PUSH DE
51979 CALL PrintCharacterBlock Print a block.
51982 CALL MoveDownRow Move down two rows.
51985 CALL MoveDownRow
51988 POP DE Get the number of blocks and the address of the characters back.
51989 POP BC
51990 DJNZ DrawVerticalEdge Loop back until all of the blocks have been drawn.
51992 RET Return.
