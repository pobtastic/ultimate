58030: Read Cursor Joystick
Used by the routine at ReadControls.
Reads the controls from a cursor joystick, which uses the keys 5 for left, 8 for right, 7 for up, 6 for down and 0 for fire.
Output
C The controls
Left from the 1-5 row.
ReadCursorJoystick 58030 LD C,0 Start with none of the controls.
58032 LD A,247 Read from the keyboard;

0 1 2 3 4
