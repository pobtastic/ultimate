58030: Read Cursor Joystick
Used by the routine at ReadControls.
Reads the controls from a Cursor joystick (which uses the keys 5, 6, 7, 8 and 0).
ReadCursorJoystick 58030 LD C,0 Start with none of the controls.
58032 LD A,247 Read the keys 1 to 5.
58034 CALL ReadKeyboardPort
58037 BIT 4,A Set the control for left if the key 5 is pressed.
58039 JR Z,ReadCursorJoystick_SecondRow
58041 SET 0,C
ReadCursorJoystick_SecondRow 58043 LD A,239 Read the keys 6 to 0.
58045 CALL ReadKeyboardPort
58048 BIT 0,A Set the control for fire if the key 0 is pressed.
58050 JR Z,ReadCursorJoystick_Forward
58052 SET 3,C
ReadCursorJoystick_Forward 58054 BIT 3,A Set the control for forward if the key 7 is pressed.
58056 JR Z,ReadCursorJoystick_Right
58058 SET 2,C
ReadCursorJoystick_Right 58060 BIT 2,A Set the control for right if the key 8 is pressed.
58062 JR Z,ReadCursorJoystick_Down
58064 SET 1,C
ReadCursorJoystick_Down 58066 BIT 4,A Set the control for down if the key 6 is pressed, and jump to ReadViewKey to read the key for turning the view.
58068 JR Z,ReadViewKey
58070 SET 4,C
58072 JR ReadViewKey
