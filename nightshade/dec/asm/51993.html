51993: Print Character
Used by the routine at PrintCharacterWithAttribute.
Prints a character on the screen, using the font whose address is held in FontPointer. A space is drawn as 60, which is blank in this font. The eight rows are written going down the screen, and the address is left at the top of the character.
After PrintScreen
Input
A The character
A' Attribute
HL Screen address of the top row
Output
HL Screen address of the top row
