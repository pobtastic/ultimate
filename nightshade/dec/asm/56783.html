56783: Choose Random Velocity
Used by the routines at UpdateSpore and UpdateVillageItem.
Chooses a new random velocity along both axes for an object when the timer has run out (the lowest six bits of the direction and timer) or when the object is not moving. The velocity along each axis is an even number, chosen from the random seeds. A new timer is set from the memory refresh register.
Input
B Number of random bits to use for each velocity
IX Object
