50785: Play Note
Used by the routines at PlayMusicOnce and PlayMusic.
Plays a note of a tune, or a rest if the note number is zero. Bits 0 to 5 select the entry in NoteTable that holds the two delays of a cycle and the number of cycles. Bits 6 and 7 are the length less one, which multiplies the number of cycles, so the note is one to four times as long.
Input
A The note
DE Address of the note
Output
DE Address of the next note
Look up the delays and the number of cycles.

50787 JR Z,PlayNote_Rest Jump to PlayNote_Rest if the note is a rest.
50789 LD L,A Set HL to the note number.
50790 LD H,0

50793 CALL AddAToHL Call AddAToHL.
Point HL at the entry for the note.
50796 LD BC,50873 Point BC at NoteTable.
50799 ADD HL,BC Find the entry for the note.
50800 LD B,(HL) Fetch the first delay.
50801 INC HL Move on.
50802 LD C,(HL) Fetch the second delay.
50803 INC HL Move on.
50804 LD L,(HL) Fetch the number of cycles.
50805 LD H,0 Set H to 0.
Bits 6 and 7 are the length, less one.
50807 LD A,(DE) Fetch the note again.

50809 RLCA
50810 AND %00000011 Keep bits 0 and 1.

50814 LD E,L Copy the number of cycles to DE.
50815 LD D,H
Multiply the number of cycles by the length.

50817 JR Z,PlayNote_Start Jump to PlayNote_Start if the length has been used up.
50819 ADD HL,DE Add the number of cycles again.
50820 JR PlayNote_Length Jump to PlayNote_Length.
PlayNote_Start 50822 POP DE Restore the note address from the stack.
Each pass makes one cycle of the note.
PlayNote_Cycle 50823 PUSH BC Stash the delays on the stack.
50824 XOR A Set A to 0.
50825 OUT (254),A Turn the speaker off.
