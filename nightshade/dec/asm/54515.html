54515: Project Object
Used by the routine at DrawObject.
Works out where an object is on the screen, in the same way as ProjectCell. It fetches the position from the slot, calls ConvertPosition, and jumps to ProjectCell_Position. The result is put in ScreenXPosition and ScreenYPosition.
Input
IX The address of the object
Fetch the position and convert it.
ProjectObject 54515 LD L,(IX+3) Fetch the vertical position.
54518 LD H,(IX+4)
54521 CALL ConvertPosition Call ConvertPosition.
54524 PUSH HL Stash it on the stack.
54525 LD L,(IX+1) Fetch the horizontal position.
54528 LD H,(IX+2)
54531 CALL ConvertPosition Call ConvertPosition.
