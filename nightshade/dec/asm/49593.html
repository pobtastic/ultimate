49593: Get Distance To Monster
Used by the routine at FindNearestMonster.
Works out the distance from the object at IX to a monster, which is the sum of the differences in their columns and rows.
Input
IX Object
IY Monster
Output
A The distance, or 255 if the monster is dead
Return 255 if the monster is dead.
GetDistanceToMonster 49593 LD A,(IY+0) Check whether the monster is alive, and jump to GetDistanceToMonster_Alive if it is.
49596 AND A
49597 JR NZ,GetDistanceToMonster_Alive
49599 LD A,255 The monster has been killed, so return a distance of 255, which is too far away to matter.
49601 RET Return.
