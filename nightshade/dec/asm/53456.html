53456: Compare Object Depths
Decides which of two objects that overlap along both axes is drawn first, by working out a value for each from the corners of the object, in units of half a cell, that measures how far it is along the diagonal of the view. The object at IX is kept if its value is not less than that of the object at IY, otherwise the object at IY is chosen. The edges which it uses are different when the view is rotated.
Input
IX The address of the first object
IY The address of the second object
Jump to CompareObjectDepths_Rotated if the view is turned round.
