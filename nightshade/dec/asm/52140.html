52140: Check Player Dead
Used by the routine at StartGame.
Checks whether the player has died. If so, a new life is started (or the game is over if there are no lives left).
The routine also checks that the instruction at 52189 has not been changed, which is part of the copy protection. The computer is reset if it has been.
CheckPlayerDead 52140 LD A,(48270) Return if the player is still alive.
