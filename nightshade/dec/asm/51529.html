51529: Flash Menu Options
Used by the routine at GameMenu.
Makes the attributes of the lines of the menu for the chosen control method and for directional control flash.
FlashMenuOptions 51529 LD HL,51555 Point at the attribute of the first control method.
51532 LD A,(48048) Fetch the control options.
51535 RRCA Move the chosen control method into the lowest two bits.
51536 AND %00000011 Keep only the chosen control method.
51538 LD B,4 Set a counter for the four control methods.
51540 CALL SetFlashingAttribute Make the line for the chosen control method flash.
51543 RES 7,(HL) Turn off the flashing of the line for directional control.
51545 LD A,(48048) Fetch the control options again.
51548 AND %00001000 Keep only the directional control bit.
51550 RET Z Return if directional control has not been chosen.
51551 SET 7,(HL) Make the line for directional control flash.
51553 RET Return.
