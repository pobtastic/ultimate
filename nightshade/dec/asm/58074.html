58074: Read Keyboard
Used by the routine at ReadControls.
Reads the controls from the keyboard. Left is X, V, M or B, right is C or N, forward is any key from A to G or from H to ENTER, fire is any key from Q to T or from Y to P, and down is any key from 1 to 5 or from 6 to 0.
ReadKeyboard 58074 LD A,254 Read the keys CAPS SHIFT, Z, X, C and V.
58076 CALL ReadKeyboardPort
58079 RRCA Move the keys X and C into bits 0 and 1, for left and right.
58080 RRCA
58081 BIT 2,A Set the control for left as well if the key V is pressed.
58083 JR Z,ReadKeyboard_Right
58085 SET 0,A
ReadKeyboard_Right 58087 AND 3 Keep the controls for X and C, and start with them.
58089 LD C,A
58090 LD A,127 Read the keys SPACE, SYMBOL SHIFT, M, N and B.
58092 CALL ReadKeyboardPort
58095 BIT 2,A Set the control for left if the key M is pressed.
58097 JR Z,ReadKeyboard_KeyN
58099 SET 0,C
ReadKeyboard_KeyN 58101 BIT 3,A Set the control for right if the key N is pressed.
58103 JR Z,ReadKeyboard_KeyB
58105 SET 1,C
ReadKeyboard_KeyB 58107 BIT 4,A Set the control for left if the key B is pressed.
58109 JR Z,ReadKeyboard_Forward
58111 SET 0,C
ReadKeyboard_Forward 58113 LD A,189 Read the keys A to G and H to ENTER.
58115 CALL ReadKeyboardPort
58118 JR Z,ReadKeyboard_Fire Set the control for forward if any of them are pressed.
58120 SET 2,C
ReadKeyboard_Fire 58122 LD A,219 Read the keys Q to T and Y to P, and set the control for fire if any of them are pressed.
58124 CALL ReadKeyboardPort
58127 JR Z,ReadKeyboard_Down
58129 SET 3,C
ReadKeyboard_Down 58131 LD A,231 Read the keys 1 to 5 and 6 to 0, and set the control for down if any of them are pressed.
58133 CALL ReadKeyboardPort
58136 JR Z,ReadViewKey
58138 SET 4,C
