57363: Test Cell Moving Right
Used by the routine at TestMoveRight.
Tests an object that is moving to the right (along the positive X axis) against the walls in one cell. If the object hits a wall then its velocity along the X axis is reduced by twice the depth that it has gone into the wall, and the flag for a collision is set.
Input
DE X position to test
HL Y position to test
IX Object
Output
F The carry flag is set if there was a collision
