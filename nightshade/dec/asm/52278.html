52278: Player Template
The initial state of the two objects that make up the player, copied into the object table by StartNewLife (see ObjectTable for the fields). The column and the row of the first object are set by ChooseStartPosition before it is used.
The first object is the player's legs and the second is the body.
PlayerTemplate 52278 DEFB 24,128,0,128,0,0,64,0,16,16,0,0,244,2,0,0 The legs (type 24).
52294 DEFB 32,0,0,0,0,0,0,0,16,16,0,0,244,13,0,0 The body (type 32).
