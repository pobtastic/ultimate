56729: Find Direction To Player
Used by the routine at UpdateDirection.
Works out which of the four directions an object has to face to move towards the player, using the axis along which the player is furthest away.
Input
IX Object
Output
A The direction (0 up, 1 right, 2 down and 3 left)
Find the axis along which the player is furthest away.
