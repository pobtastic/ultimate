58573: Draw Shifted Columns
The code that draws a row of a sprite that has been shifted by two, four or six pixels. There is a copy of the code for each of up to five characters, and the code is entered at the one that leaves the number of characters of the sprite, from DrawSpriteRow.
Each character takes a mask and pixels from the stack. The shifted halves of them come from the tables that BuildShiftTables builds, with the high byte of the address of the table in H, and the low byte of the address from the mask or the pixels. The part that goes into the first character of the screen buffer is combined with what is left over from the previous character, and the part that goes into the next character is kept for the next time.
Input
A The first byte of the row in the screen buffer
BC Address in the screen buffer
H Page of the table for the first parts of the shifted bytes
