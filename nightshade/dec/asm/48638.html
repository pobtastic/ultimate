48638: Start Game
Used by the routine at GameEntry.
Checks that the game was started by the tape loader, clears the game variables, shows the game selection menu, sets up the status panel and the first life, and then falls into the main loop.
The first check is part of the copy protection: the game returns to BASIC if the high byte of the system variable FRAMES is not 99 (the loader arranges for it to be). The routine at BuildRandomTable makes a second check on the memory refresh register.
