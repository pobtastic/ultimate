55367: Update Destroyed Monster
The routine for objects of type 132 to 135 the flash that shows a monster that has been destroyed. The border of the screen is set to a colour from the frame counter, and on every other frame the object moves on to the next sprite. It is removed after the fourth sprite.
UpdateDestroyedMonster 55367 LD A,(48050) Set the colour of the border from the frame counter.
55370 RLCA
55371 RLCA
55372 RLCA
55373 AND 56
55375 LD (48123),A
55378 LD A,(48050) Return unless the frame counter is odd.
55381 AND 1
55383 RET Z
55384 INC (IX+0) Move on to the next sprite, and return unless it was the last.
55387 LD A,(IX+0)
55390 AND 3
55392 RET NZ
55393 LD (IX+0),A Remove the object and return.
55396 RET
