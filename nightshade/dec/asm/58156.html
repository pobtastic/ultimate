58156: Pause Game
Used by the routine at StartGame.
Pauses the game when CAPS SHIFT or SPACE is pressed on its own. The game continues when the key has been pressed again.
PauseGame 58156 LD A,126 Read the keys CAPS SHIFT, Z, X, C, V, SPACE, SYMBOL SHIFT, M, N and B.
58158 CALL ReadKeyboardPort
58161 BIT 0,A Return if neither of the keys CAPS SHIFT or SPACE is pressed.
58163 RET Z
58164 AND 30 Return if any of the other keys is pressed too.
58166 RET NZ
Wait for the key to be released.
PauseGame_Release 58167 LD A,126 Read the keys, and loop back until neither of the keys is pressed.
58169 CALL ReadKeyboardPort
58172 BIT 0,A
58174 JR NZ,PauseGame_Release
Wait for a key to be pressed.
PauseGame_Press 58176 LD A,126 Read the keys, and loop back until one of the keys is pressed.
58178 CALL ReadKeyboardPort
58181 BIT 0,A
58183 JR Z,PauseGame_Press
Wait for the key to be released.
PauseGame_ReleaseAgain 58185 LD A,126 Read the keys, and loop back until neither of the keys is pressed.
58187 CALL ReadKeyboardPort
58190 BIT 0,A
58192 JR NZ,PauseGame_ReleaseAgain
58194 RET Return.
