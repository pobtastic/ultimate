28695: Sprite: Logo Piece 1
A piece of the title graphic that is shown at the end of the game (see UpdateLogoPiece). The sprite is used for object type 152.
A sprite is made of a byte for the width in characters (the flags that say whether the sprite has been turned round or upside down are in bits 6 and 7), a byte for the number of rows, and then the rows with the bottom row first. Each row has a pair of bytes for each character, which are the mask and then the pixels (see DrawSprite).
Sprite_Logo_Piece_1 28695 DEFB 4 Width = 4 characters.
28696 DEFB 26 Height = 26 rows.
