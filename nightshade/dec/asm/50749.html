50749: Play Music Once
Used by the routine at GameMenu.
Plays a tune, but only if this routine has not played one before. Bit 0 of TunePlayedFlag is set the first time and nothing clears it. The tune stops when a key is pressed.
The tunes played by this routine are:
Tune Sound
Main Tune
Input

Play only if TunePlayedFlag is clear.
