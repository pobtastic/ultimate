50749: Play Music Once
Used by the routine at GameMenu.
Plays a tune, which is stopped by any key being pressed. A tune that has been started is not started again.
Input
DE Address of the tune
PlayMusicOnce 50749 LD HL,48065 Return if this tune has been played before.
50752 LD A,(HL)
50753 AND A
50754 RET NZ
50755 SET 0,(HL) Remember that the tune has been played.
PlayMusicOnce_Loop 50757 XOR A Read every row of the keyboard at once.
50758 CALL ReadKeyboardPort Check whether a key is being pressed.
50761 JR Z,PlayMusicOnce_Note Jump to PlayMusicOnce_Note to play the next note if no key is being pressed.
50763 RET Return, to stop the tune.
PlayMusicOnce_Note 50764 LD A,(DE) Fetch the next note and jump to PlayMusic_Return if it marks the end of the tune.
50765 CP 255
50767 JR Z,PlayMusic_Return Play the note.
50769 CALL PlayNote
50772 JR PlayMusicOnce_Loop Jump back to PlayMusicOnce_Loop to check the keyboard again.
