Pokes
  • Infinite Lives
  • Infinite Health
  • Immunity To Monsters
  • No Throw Delay
Infinite Lives
POKE CBDD,00
POKE CBB5,00
Removes the instruction which would otherwise decrease Lives, and changes the copy protection check in CheckPlayerDead so that it still accepts the new instruction.
CBDA LD HL,BBCD
CBDD DEC (HL)
CBB1 LD A,(CBDD)
CBB4 CP 35
CBB6 JP NZ,C1F9
To:
CBDA LD HL,BBCD
CBDD NOP
CBB1 LD A,(CBDD)
CBB4 CP 00
CBB6 JP NZ,C1F9
Infinite Health
POKE CEC2,C9
Returns from HurtPlayer before one point is taken from Health, so the player never dies from a ghost, a creature or a spore. Monsters still kill the player on contact; see Immunity To Monsters.
CEBF LD HL,BBF3
CEC2 DEC (HL)
CEC3 RET NZ
To:
CEBF LD HL,BBF3
CEC2 RET
Immunity To Monsters
POKE D975,C9
Returns from UpdateMonster when a monster is touching the player, instead of jumping to KillPlayer.
D971 CALL C55F
D974 RET NC
D975 JP CEC4
To:
D971 CALL C55F
D974 RET NC
D975 RET
No Throw Delay
POKE DABC,18
Turns the timer check into an unconditional skip, so ThrowTimer is never counted down from here.
DAB7 LD HL,BBC8
DABA LD A,(HL)
DABB AND A
DABC JR Z,DAC0
DABE DEC (HL)
To:
DAB7 LD HL,BBC8
DABA LD A,(HL)
DABB AND A
DABC JR DAC0
