47440: Initialise Explosion
Copy an 8-byte explosion template into Explosion_Slot, which starts a sound. The entry point at InitialiseExplosion_Copy takes the template address in HL.
There are five templates. The first is read by TickWaveDuration (type 165) and the other four by TickWaveTable (type 161).
InitialiseExplosion 47440 LD HL,47452 HL=Explosion_Template_1.
InitialiseExplosion_Copy 47443 LD DE,24672 DE=Explosion_Slot.
47446 LD BC,8 Copy 8 bytes from HL to DE.
47449 LDIR
47451 RET Return.
Template for TickWaveDuration. It plays one note on each pass, starting from the pitch below and counting down to 1 so the sound rises over 39 notes. Nothing calls InitialiseExplosion, so this one is never used. The copy at InitialiseExplosion_Copy takes four more bytes than this, which are the first instructions at Copy_Explosion_Template, but TickWaveDuration never reads them.
Explosion_Template_1 47452 DEFB 165 Actor type, handled by TickWaveDuration.
47453 DEFB 32 Not read by TickWaveDuration.
47454 DEFB 8 Repeat count: each note is played 8 times.
47455 DEFB 40 Starting pitch.
This entry point is used by the routines at Handler_PlayerShot and Handler_Missile_ConvertExploding.
