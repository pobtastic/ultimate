36852: Land Jetman
Used by the routine at Handler_JetmanMovement.
Switch Jetman to the walking sprite, snap him to the ground line and redraw.
Input
IX Actor slot
The actor type is a 1-based sprite ID. Decrease it to work on the 0-based index, set bit 3 to switch from the flying frames to the walking frames, then write the 1-based ID back.
LandJetman 36852 LD A,(IX+0) Fetch the actor type.
36855 DEC A Decrease it to a 0-based sprite index.
36856 SET 3,A Set the walking-frame bit.
36858 INC A Restore the 1-based sprite ID.
36859 LD (IX+0),A Write it back to *IX+0.
Snap Jetman to the ground line at Y=175.
36862 LD (IX+4),175 Write 175 to Jetman's Y position.
Draw the standing sprite and continue the movement handler.
36866 JP Handler_JetmanMovement_Draw Jump to Handler_JetmanMovement_Draw.
