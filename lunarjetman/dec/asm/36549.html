36549: Face Jetman Left
Used by the routine at Handler_JetmanMovement.
Reset bit 2 of the actor type so Jetman faces left, then accelerate or cap the horizontal speed.
Input
IX Actor slot
Decrease to the 0-based sprite index, reset bit 2 to face left, then write the 1-based ID back.
FaceJetmanLeft 36549 LD A,(IX+0) Fetch the actor type.
36552 DEC A Decrease it to a 0-based sprite index.
36553 RES 2,A Reset the facing bit.
36555 INC A Restore the 1-based sprite ID.
36556 LD (IX+0),A Write it back to *IX+0.
Push the speed left while any fuel remains. Bit 0 of the actor flags is set while Jetman is carrying an item, which slows him down.
36559 BIT 0,(IX+8) Jump to FaceJetmanLeft_Carrying if Jetman is carrying an item.
36563 JR NZ,FaceJetmanLeft_Carrying
36565 LD A,(IX+5) Jump to FaceJetmanLeft_ReverseRight if the horizontal speed is positive.
36568 AND A
