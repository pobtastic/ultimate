Turn the level into the missile launcher countdown at Missile_Launcher_Countdown (the higher the level, the shorter it is), then jump to PrintPlayerLevels. Rotating left twice multiplies the level by 4. Inverting and masking that to bits 2-5 gives 60 minus 4 for each level, so adding 81 leaves a countdown that falls by 4 per level, from 141 to 81.
Level Rotate x2 Invert Keep bits 2-5 Add 81
0 0 255 60 141
1 4 251 56 137
2 8 247 52 133
7 28 227 32 113
15 60 195 0 81
16 and up 255 0 0 81
