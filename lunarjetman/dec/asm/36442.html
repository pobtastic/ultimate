36442: Face Jetman Right
Used by the routine at Handler_JetmanMovement.
Set bit 2 of the actor type so Jetman faces right, then accelerate or cap the horizontal speed.
Input
IX Actor slot
Decrease to the 0-based sprite index, set bit 2 to face right, then write the 1-based ID back.
FaceJetmanRight 36442 LD A,(IX+0) Fetch the actor type.
36445 DEC A Decrease it to a 0-based sprite index.
36446 SET 2,A Set the facing bit.
36448 INC A Restore the 1-based sprite ID.
36449 LD (IX+0),A Write it back to *IX+0.
Push the speed right while any fuel remains. Bit 0 of the actor flags is set while Jetman is carrying an item, which slows him down.
36452 BIT 0,(IX+8) Jump to FaceJetmanRight_Carrying if Jetman is carrying an item.
