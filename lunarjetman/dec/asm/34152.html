34152: Fetch Sprite
Looks up the sprite pointer for the ID in 24148. SpritesTable is the default table. On an odd level MapSpriteBand may switch the index and table to Sprite_Band_Table. Nothing calls this routine; the game uses FetchActorSprite instead.
