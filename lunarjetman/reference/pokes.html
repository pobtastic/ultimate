Infinite Lives
POKE 9065,00
Removes the instruction which would otherwise decrease ActivePlayer_Lives.
9062 LD A,(5EA1)
9065 DEC A
9066 LD (5EA1),A
To:
9062 LD A,(5EA1)
9065 NOP
9066 LD (5EA1),A
255 Lives
POKE A855,FF
POKE A86D,FF
This changes the starting lives from 04 (1UP) and 05 (2UP) to FF. The 2UP value is one higher than 1UP because of how ChangePlayer copies the inactive player.
A854 LD A,04
A856 LD (5EA1),A
A86C LD A,05
A86E LD (5EA5),A
To:
A854 LD A,FF
A856 LD (5EA1),A
A86C LD A,FF
A86E LD (5EA5),A
Infinite Fuel
POKE 8DAC,00
POKE 8DAD,00
Removes the subtract which would otherwise take the spent fuel off FuelLevel_1.
8DA4 LD HL,(608E)
8DAC SBC HL,BC
To:
8DA4 LD HL,(608E)
8DAC NOP
8DAD NOP
Immunity
POKE B2D0,C3
POKE B2D5,A7
TickThenExplode_TestHeight is the height test used before an actor explodes on Jetman.
B2D0 JP P,B2D5
B2D3 NEG
B2D5 CP E
B2D6 RET
To:
B2D0 JP B2D5
B2D5 AND A
B2D6 RET
The first poke always jumps to TickThenExplode_Compare. The second clears carry, so the following RET never comes back with carry set.
Infinite Time
POKE ABDD,18
Turns the type check into an unconditional skip, so *IX+17 is never decreased and Handler_Missile_ConvertExploding is never called from here.
ABD8 LD A,(6078)
ABDB CP 81
ABDD JR Z,ABE5
ABDF DEC (IX+17)
To:
ABD8 LD A,(6078)
ABDB CP 81
ABDD JR ABE5
No Enemies
POKE 946F,C9
Turns the delay check in SpawnAlien into an immediate return, so a new alien is never copied into a free slot.
946B LD A,(5E67)
946E AND A
946F RET NZ
To:
946B LD A,(5E67)
946E AND A
946F RET
Destroy Missile With One Shot
POKE AF6A,18
Treats the missile as destroyed as soon as one hit is taken off *IX+16.
AF67 DEC (IX+16)
AF6A JR Z,AFB1
To:
AF67 DEC (IX+16)
AF6A JR AFB1
