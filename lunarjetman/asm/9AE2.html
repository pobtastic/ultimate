9AE2: Handler: Shooter
Fire a shot when the Shooter is on screen, then chase Jetman's Y position.
Input
IX Actor slot
Handler_Shooter 9AE2 LD H,(IX+$03) Fetch the high byte of the world X.
9AE5 LD L,(IX+$02) Fetch the low byte of the world X.
9AE8 PUSH HL Stash the world X on the stack.
9AE9 LD DE,($607A) Fetch Jetman_Position.
9AED AND A Subtract the scroll position.
9AEE SBC HL,DE
9AF0 BIT 7,(IX+$05) Jump to Handler_Shooter_ChaseStillOnScreen if the horizontal speed is negative.
9AF4 JP NZ,Handler_Shooter_ChaseStillOnScreen
9AF7 LD A,H Fetch the high byte of the gap.
9AF8 AND %00011111 Keep only bits 0-4.
9AFA CP $01 Jump to Handler_Shooter_ChaseClearType if the alien has left the screen.
9AFC JP Z,Handler_Shooter_ChaseClearType
Skip firing and chase Jetman if the shooter is not on this screen.
Handler_Shooter_ShotTolerance 9AFF LD DE,$0078 Add a 78 tolerance.
9B02 ADD HL,DE
9B03 LD A,H Fetch the high byte.
9B04 POP DE Restore the world X into DE from the stack.
9B05 AND A Jump to Handler_Shooter_ChaseJetmanY if the alien is not on this screen.
9B06 JR NZ,Handler_Shooter_ChaseJetmanY
9B08 PUSH DE Stash the world X on the stack again.
Set the speed to 50 or B0 if bit 7 of *IX+01 differs from the direction of travel.
9B09 LD A,(IX+$01) Fetch the screen column.
9B0C XOR (IX+$05) XOR it with the horizontal speed.
9B0F AND %10000000 Keep only bit 7.
9B11 JR Z,Handler_Shooter_SpawnShot Jump to Handler_Shooter_SpawnShot if they already match.
9B13 LD A,(IX+$05) Jump to Handler_Shooter_ShotSpeedLeft if the horizontal speed is negative.
9B16 AND A
9B17 JP M,Handler_Shooter_ShotSpeedLeft
9B1A LD (IX+$05),$50 Write 50 to the horizontal speed.
9B1E JR Handler_Shooter_SpawnShot Jump to Handler_Shooter_SpawnShot.
Handler_Shooter_ShotSpeedLeft 9B20 LD (IX+$05),$B0 Write B0 to the horizontal speed.
Spawn a shot in a free alien slot.
Handler_Shooter_SpawnShot 9B24 CALL FindSlotAlien Call FindSlotAlien.
9B27 POP DE Restore the world X into DE from the stack.
9B28 JR NZ,Handler_Shooter_ChaseJetmanY Jump to Handler_Shooter_ChaseJetmanY if no alien slot is free.
9B2A LD (HL),$B6 Write type B6 to the new slot.
9B2C BIT 7,(IX+$05) Jump to Handler_Shooter_CopyShotX if the shot is moving left.
9B30 JR NZ,Handler_Shooter_CopyShotX
9B32 LD (HL),$B7 Write type B7.

Handler_Shooter_CopyShotX 9B34 INC HL Move onto the world X.
9B35 INC HL
9B36 LD (HL),E Write the shooter's world X into the slot.
9B37 INC HL
9B38 LD (HL),D
9B39 INC HL Move onto the Y position.
9B3A LD A,(IX+$04) Copy the shooter's Y position.
9B3D LD (HL),A
Give the shot a speed in the direction the shooter is moving.
9B3E INC HL Move onto the horizontal speed.
9B3F LD A,(IX+$05) Jump to Handler_Shooter_ShotSpeedRight if the shooter is moving left.
9B42 AND A
9B43 JP M,Handler_Shooter_ShotSpeedRight
9B46 LD (HL),$70 Write 70 to the shot speed.
9B48 JR Handler_Shooter_InitialiseShotSlot Jump to Handler_Shooter_InitialiseShotSlot.
Handler_Shooter_ShotSpeedRight 9B4A LD (HL),$90 Write 90 to the shot speed.
Zero the thrust, set the colour and clear the rest of the slot.
Handler_Shooter_InitialiseShotSlot 9B4C INC HL Write 00 to the thrust.
9B4D LD (HL),$00
9B4F INC HL
9B50 LD (HL),$47 Write INK:WHITE, PAPER:BLACK (BRIGHT) to the colour.
9B52 LD B,$0F Set a byte counter in B for 0F loops.
Handler_Shooter_ClearShotTail 9B54 INC HL Clear the next slot byte.
9B55 LD (HL),$00
9B57 DJNZ Handler_Shooter_ClearShotTail Decrease the byte counter by one and loop back to Handler_Shooter_ClearShotTail until the slot is cleared.
Chase Jetman's Y position.
Handler_Shooter_ChaseJetmanY 9B59 LD A,($607C) Fetch Jetman_Y.
9B5C SUB (IX+$04) Subtract the alien's Y position.
9B5F JP P,Handler_Shooter_ChaseAddThrustTest Jump to Handler_Shooter_ChaseAddThrustTest if Jetman is below the alien.

9B65 AND A
9B66 JP P,Handler_Shooter_ChaseSubtractThrust
9B69 CP $EF Jump to Handler_Shooter_ChaseApplyThrust if the thrust is already below EF.
9B6B JR C,Handler_Shooter_ChaseApplyThrust
Handler_Shooter_ChaseSubtractThrust 9B6D SUB $02 Subtract 02 from the thrust.
Apply the thrust to the Y position unless it would leave the play area.

9B83 JR NC,Handler_Shooter_ChaseTickAnimation

9B9B JP PlaceSpawnedAlien_Age Jump to PlaceSpawnedAlien_Age.
Test whether a left-moving shooter has gone off the left edge.
