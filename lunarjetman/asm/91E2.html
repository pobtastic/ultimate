91E2: Handler: Moon Rover
Drive the rover: refill the fuel gauge, read the controls and stop the rover at craters in the terrain ahead.
Input
IX Actor slot
Refill the tank, then steer from the controls.
Handler_MoonRover 91E2 LD A,($5E6C) Jump to Handler_MoonRover_DrawSprite if PlayerInactive is set.
91E5 AND A
91E6 JR NZ,Handler_MoonRover_DrawSprite
91E8 LD HL,$9000 Write 9000 to FuelLevel_1.
91EB LD ($608E),HL
91EE LD A,H Fetch the high fuel byte.
91EF LD HL,$1040 HL=1040 (gauge position).
91F2 CALL DrawGauge Call DrawGauge.
Read the controls and speed the rover up if LEFT or RIGHT is held.
91F5 CALL HandlerControls Call HandlerControls.
91F8 BIT 0,A Jump to Handler_MoonRover_AccelerateRight if RIGHT is pressed.
91FA JP Z,Handler_MoonRover_AccelerateRight
91FD BIT 1,A Jump to Handler_MoonRover_AccelerateLeft if LEFT is pressed.
91FF JP Z,Handler_MoonRover_AccelerateLeft
Neither direction is held, so ease the speed back towards zero.
9202 LD A,(IX+$05) Jump to Handler_MoonRover_Loop if the horizontal speed is zero.
9205 AND A
9206 JR Z,Handler_MoonRover_Loop
9208 JP P,Handler_MoonRover_Decelerate Jump to Handler_MoonRover_Decelerate if the rover is moving right.
920B ADD A,$01 Add 01 to the speed.
920D JR Handler_MoonRover_Loop Jump to Handler_MoonRover_Loop.
Handler_MoonRover_Decelerate 920F SUB $01 Subtract 01 from the speed.
Handler_MoonRover_Loop 9211 LD (IX+$05),A Write the speed to *IX+05.
Look ahead under the wheels for blocking terrain.
9214 LD HL,($607A) Fetch Jetman_Position.
9217 BIT 7,(IX+$05) Jump to Handler_MoonRover_LookLeft if the rover is moving left.
921B JP NZ,Handler_MoonRover_LookLeft
921E LD DE,$FFF8 DE=FFF8.
Handler_MoonRover_LookAhead 9221 ADD HL,DE Add the look-ahead offset.
9222 SRA H Divide the world position by 08.
9224 RR L
9226 SRA H
9228 RR L
922A SRA H
922C RR L
922E LD A,H Fetch the high byte.
922F AND %00000011 Keep only bits 0-1.
9231 LD H,A Write it back to H.
Scan the cells ahead of the rover and stop it at an empty cell or a crater.
9232 LD B,$06 Set a cell counter in B for 06 loops.
9234 EX DE,HL Switch the index into DE.
Handler_MoonRover_TestTerrain 9235 LD HL,$7000 HL=TerrainData_Active.
9238 ADD HL,DE Point HL at that terrain cell.
9239 LD A,(HL) Jump to Handler_MoonRover_Stop if the cell is empty.
923A AND A
923B JR Z,Handler_MoonRover_Stop
923D AND %00001000 Keep only bit 3.
923F JR NZ,Handler_MoonRover_Stop Jump to Handler_MoonRover_Stop if it is a crater.
Step on to the next cell, wrapping the index.
9241 INC DE Move onto the next cell.
9242 LD A,D Fetch the high byte.
9243 AND %00000011 Keep only bits 0-1.
9245 LD D,A Write it back to D.
9246 DJNZ Handler_MoonRover_TestTerrain Decrease the cell counter by one and loop back to Handler_MoonRover_TestTerrain until the scan is done.
9248 JR Handler_MoonRover_PickFrame Jump to Handler_MoonRover_PickFrame.
Stop the rover: it has reached an empty cell or a crater.
Handler_MoonRover_Stop 924A LD (IX+$05),$00 Write 00 to the horizontal speed.
924E JR Handler_MoonRover_ApplySpeed Jump to Handler_MoonRover_ApplySpeed.
Pick a facing frame from the fine X.
Handler_MoonRover_PickFrame 9250 LD A,(IX+$05) Jump to Handler_MoonRover_ApplySpeed if the horizontal speed is zero.
9253 AND A
9254 JR Z,Handler_MoonRover_ApplySpeed
9256 JP M,Handler_MoonRover_FineX Jump to Handler_MoonRover_FineX if the rover is moving left.
9259 LD A,(IX+$02) Fetch the low byte of the world X.
925C RRA Rotate it right.
925D AND %00000011 Keep only bits 0-1.

9261 LD (IX+$00),A Write it to the actor type.

While Jetman is inactive, step the inactive counter and hand over to Handler_RoverFrames_Tint.

92B2 JR Handler_MoonRover_ApplySpeed Jump to Handler_MoonRover_ApplySpeed.

92B7 JP Handler_MoonRover_LookAhead Jump to Handler_MoonRover_LookAhead.

92C8 JP Handler_MoonRover_Loop Jump to Handler_MoonRover_Loop.
