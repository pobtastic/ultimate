B950: Initialise Explosion
Copy an 8-byte explosion template into Explosion_Slot, which starts a sound. The entry point at InitialiseExplosion_Copy takes the template address in HL.
There are five templates. The first is read by TickWaveDuration (type A5) and the other four by TickWaveTable (type A1).
InitialiseExplosion B950 LD HL,$B95C HL=Explosion_Template_1.
InitialiseExplosion_Copy B953 LD DE,$6060 DE=Explosion_Slot.
B956 LD BC,$0008 Copy 08 bytes from HL to DE.
B959 LDIR
B95B RET Return.
Template for TickWaveDuration. It plays one note on each pass, starting from the pitch below and counting down to 01 so the sound rises over 27 notes. Nothing calls InitialiseExplosion, so this one is never used. The copy at InitialiseExplosion_Copy takes four more bytes than this, which are the first instructions at Copy_Explosion_Template, but TickWaveDuration never reads them.
Explosion_Template_1 B95C DEFB $A5 Actor type, handled by TickWaveDuration.
B95D DEFB $20 Not read by TickWaveDuration.
B95E DEFB $08 Repeat count: each note is played 08 times.
B95F DEFB $28 Starting pitch.
This entry point is used by the routines at Handler_PlayerShot and Handler_Missile_ConvertExploding.
Copy_Explosion_Template B960 LD HL,$B965 HL=Explosion_Template_2.
B963 JR InitialiseExplosion_Copy Jump to InitialiseExplosion_Copy.
