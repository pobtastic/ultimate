AD0B: Flash Attribute
Return attribute INK:RED, PAPER:BLACK (BRIGHT) or INK:RED, PAPER:YELLOW (BRIGHT) according to bit 04 of GameTimer.
Output
A Attribute value
Return attribute INK:RED, PAPER:BLACK (BRIGHT) or INK:RED, PAPER:YELLOW (BRIGHT) from the timer.
FlashAttribute AD0B LD A,($5E42) Fetch GameTimer.
AD0E AND %00010000 Keep only bit 4.
AD10 JR Z,FlashAttribute_Loop Jump to FlashAttribute_Loop if that bit is reset.
AD12 LD A,$30 A=30.
This entry point is used by the routine at FlashAttributeAlternative.
FlashAttribute_Loop AD14 OR %01000010 Set bits 1 and 6.
AD16 RET Return.
