84B4: Fill Memory
Used by the routine at ResetAttributes.
Writes C from the target address up to the page in B.
Input
HL Target address
B End-address MSB (the LSB is always 00)
C Value to write
ResetCopier 84B4 LD (HL),C Write the fill value to the target address.
84B5 INC HL Move onto the next byte.
84B6 LD A,H Compare the target page with the end page.
84B7 CP B
84B8 JR NZ,ResetCopier Jump back to ResetCopier until the end page is reached.
84BA RET Return.
