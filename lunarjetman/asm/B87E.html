B87E: Colourise Rover Lights
Write the rover lamp attributes at Rover_Lamp_Attributes from the Jetman type.
Write the rover lamp attributes from the Jetman type. Type 16 and above is seated facing right.
ColouriseRoverLights B87E LD A,($6078) Fetch Jetman_Slot.
B881 CP $16 Compare it with 16.
B883 LD HL,$BCA9 HL=Rover_Lamp_Attributes.
B886 JR C,ColouriseRoverLights_OnFoot Jump to ColouriseRoverLights_OnFoot if the type is lower.
Write the lamp attributes for type 16 and above: INK:WHITE, PAPER:RED (BRIGHT), INK:WHITE, PAPER:RED (BRIGHT), then INK:WHITE, PAPER:BLACK (BRIGHT).
B888 LD A,$57 A=INK:WHITE, PAPER:RED (BRIGHT).
B88A LD (HL),A Write A to *HL.
B88B INC HL Increment HL by one.
B88C LD (HL),A Write A to *HL.
B88D INC HL Increment HL by one.
B88E LD (HL),$47 Write INK:WHITE, PAPER:BLACK (BRIGHT) to *HL.
B890 RET Return.
Write the lamp attributes for the lower types: INK:WHITE, PAPER:BLACK (BRIGHT), INK:WHITE, PAPER:RED (BRIGHT), then INK:WHITE, PAPER:RED (BRIGHT).
ColouriseRoverLights_OnFoot B891 LD A,$57 A=INK:WHITE, PAPER:RED (BRIGHT).
B893 LD (HL),$47 Write INK:WHITE, PAPER:BLACK (BRIGHT) to *HL.
B895 INC HL Increment HL by one.
B896 LD (HL),A Write A to *HL.
B897 INC HL Increment HL by one.
B898 LD (HL),A Write A to *HL.
B899 RET Return.
