B2A2: Test Jetman Range
Used by the routines at PlaceSpawnedAlien, Handler_ThePip, Handler_UpwardMissile, Handler_SidewaysMissile, Handler_AlienBasePlasma and TickThenExplode.
Return carry if this actor is touching Jetman. This entry uses a vertical range of 0E; TickThenExplode_TestJetman takes the range in E. Carry is clear while the delay timer at GameDelayTimer is running or Jetman's type is 11 or above.
Input
IX Actor slot
TickThenExplode_CloseRange B2A2 LD E,$0E E=0E.
This entry point is used by the routines at Handler_MissileLauncher, Handler_AlienBase and Handler_MissileSpawner.
Return carry if this actor is close enough to Jetman. Type 11 and above means Jetman is not on foot.

B2AF LD L,(IX+$02) Fetch the actor world X.
B2B2 LD H,(IX+$03) Fetch the high byte.
B2B5 LD BC,$0008 Add an 08 box offset.
B2B8 ADD HL,BC
B2B9 LD BC,($607A) Fetch Jetman_Position.
B2BD AND A Subtract Jetman's world X.
B2BE SBC HL,BC
B2C0 LD A,H Fetch the high byte of the difference.
B2C1 AND %00011111 Keep only bits 0-4.
B2C3 RET NZ Return if they are on different screens.
B2C4 LD A,L Fetch the low byte.
B2C5 CP $10 Return if it is at least 10.
B2C7 RET NC
Work out the vertical gap to Jetman.
B2C8 LD A,($607C) Fetch Jetman_Y.
B2CB SUB $04 Subtract 04.
B2CD SUB (IX+$04) Subtract the actor Y.
A is (Jetman's Y minus 04) minus this actor's Y. Keep that gap as a positive distance, then compare it with E.
