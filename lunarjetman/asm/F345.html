F345: Insert High Score
Used by the routine at HallOfFame_Input.
Open a slot in the name table at HallOfFame_Names, copy the new 3-letter name from HallOfFame_Name, then insert the matching score into High_Score.
If the other player also made the table, rank their score too and start name entry for them.
DE is the byte after the name table and HL is three bytes before that, so copying backwards moves each byte on by three bytes, which is one name row.
InsertHighScore F345 LD DE,$5E38 DE=HallOfFame_NameEnd.
F348 LD HL,$5E35 HL=HallOfFame_LastName.
Work out how many bytes lie from the insert row down. HighScorePosition holds 08 minus the rank, so this gives back the row count that CompareHighScores returned in B (08 is first place).
