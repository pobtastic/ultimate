907B: Apply Jetman Speed
Used by the routines at Handler_JetmanMovement, Handler_MoonRover and TickActorFrame.
Use the horizontal speed in *IX+05 to update Jetman's world position.
Input
IX Actor slot
ApplyJetmanSpeed 907B LD A,(IX+$05) Fetch the horizontal speed.
907E SRA A Divide it by 10.
9080 SRA A
9082 SRA A
9084 SRA A
9086 LD E,A Store the pixel step in E.
9087 LD D,$00 Clear D for a positive step.
9089 JP P,ApplyJetmanSpeed_AddWorldX Jump to ApplyJetmanSpeed_AddWorldX if the step is positive.
908C LD D,$FF Set D=FF for a negative step.
Add the step to the world X and wrap it to the planet width.
ApplyJetmanSpeed_AddWorldX 908E LD H,(IX+$03) Fetch the high byte of the world X.
9091 LD L,(IX+$02) Fetch the low byte of the world X.
9094 LD A,L Fetch the fine X.
9095 AND %00000111 Keep only bits 0-2.
Draw a new terrain column on a cell boundary, then scroll the terrain bitmap by the step.
9097 PUSH HL Stash the world X and the step on the stack.
9098 PUSH DE
9099 CALL Z,DrawNewColumn Call DrawNewColumn if Jetman is on a cell boundary.
909C POP DE Restore the step from the stack.
909D CALL ApplyJetmanSpeed_ScrollLeft Call ApplyJetmanSpeed_ScrollLeft.
Add the step to the world X and write it back.
90A0 POP HL Restore the world X from the stack.
90A1 ADD HL,DE Add the step to the world X.
90A2 LD A,H Fetch the high byte.
90A3 AND %00011111 Keep only bits 0-4.
90A5 LD (IX+$03),A Write the high byte back to *IX+03.
90A8 LD (IX+$02),L Write the low byte back to *IX+02.
90AB RET Return.
Scroll the terrain bitmap left or right by the pixel step.
ApplyJetmanSpeed_ScrollLeft 90AC LD HL,$50C0 HL=50C0.
90AF LD C,$08 Set a pixel row counter in C for 08 loops.
90B1 LD A,E Return if there is no horizontal movement.
90B2 AND A
90B3 RET Z
90B4 JP P,ApplyJetmanSpeed_ScrollRight Jump to ApplyJetmanSpeed_ScrollRight if Jetman is moving right.
When Jetman is moving left, shift the terrain bitmap right.
90B7 NEG Negate the leftward step.
90B9 DEC A Jump to ApplyJetmanSpeed_RotateRowRight if the step is 01.
90BA JR Z,ApplyJetmanSpeed_RotateRowRight
90BC DEC A Jump to ApplyJetmanSpeed_TestOddPixel if the step is 02.
90BD JR Z,ApplyJetmanSpeed_TestOddPixel
90BF LD A,(IX+$02) Fetch the low byte of the world X.
90C2 AND %00000011 Keep only bits 0-1.
90C4 JR NZ,ApplyJetmanSpeed_TestOddPixel Jump to ApplyJetmanSpeed_TestOddPixel if Jetman is not on a 4-pixel boundary.
Rotate each pixel row right by four bits.
ApplyJetmanSpeed_Loop 90C6 XOR A Clear the accumulator.
90C7 LD B,$20 Set a column counter in B for 20 loops.
90C9 PUSH HL Stash the row start on the stack.
ApplyJetmanSpeed_RotateNibbleRight 90CA RRD Rotate the nibble through the current byte.
90CC INC HL Move onto the next column.
90CD DJNZ ApplyJetmanSpeed_RotateNibbleRight Decrease the column counter by one and loop back to ApplyJetmanSpeed_RotateNibbleRight until the row is done.
90CF POP HL Restore the row start from the stack.
90D0 INC H Move down one pixel row.
90D1 DEC C Decrease the row counter by one and loop back to ApplyJetmanSpeed_Loop until all eight rows are done.
90D2 JR NZ,ApplyJetmanSpeed_Loop
Return the step actually scrolled (-04) in DE.
90D4 LD DE,$FFFC DE=FFFC.
90D7 RET Return.

90E4 JR NZ,ApplyJetmanSpeed_RotateRowRight
Return the step actually scrolled (-01) in DE.
90E6 LD DE,$FFFF DE=FFFF.
90E9 RET Return.
