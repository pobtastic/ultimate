B128: Handler: Alien Base Plasma
Handle the alien base plasma (types 90-97). Jump to Handler_Missile_ExplodeObjects when it is close enough to its target (Handler_Missile_TestJetmanRange). Otherwise kill Jetman if he is close (TickThenExplode_KillJetman), try to spawn a linked C8 object (SpawnLinkedObject), step the frame through 90-97 and colour the sprite.
Input
IX Actor slot

B12B JP C,Handler_Missile_ExplodeObjects Jump to Handler_Missile_ExplodeObjects if this actor is in range.
B12E CALL TickThenExplode_CloseRange Call TickThenExplode_CloseRange.

B134 CALL SpawnLinkedObject Call SpawnLinkedObject.
