858E: XOR Sprite Loop
Used by the routines at PositionAndDrawSprite, DrawCachedSprite and DrawSprite.
XOR the old sprite (normal registers) and the new sprite (shadow registers) onto the screen one row at a time, using C as each sprite's row counter. Any rows left in SpriteCachedRows and SpriteRowsLeft are then picked up.
Input
HL Screen address
DE Graphic pointer
Draw remaining rows from the current graphic pair.
