8A5C: Mask Sprite
XOR the old (cached) image of a masked sprite off the screen and its new image on, row by row, using the remaining row counts in SpriteCachedRows (old image) and SpriteRowsLeft (new image).
Input
HL Screen address
DE Graphic pointer
Draw remaining rows from the current masked pair.
MaskSprite 8A5C LD A,C Jump to MaskSprite_TryShadow if the row counter is zero.
8A5D AND A
8A5E JR Z,MaskSprite_TryShadow
8A60 DEC C Decrease the row counter and draw the next row of the old image.
8A61 CALL MaskSprite_LoadMask
8A64 EXX Switch to the shadow registers.
8A65 LD A,C Jump to MaskSprite_NextSide if the shadow row counter is zero.
8A66 AND A
8A67 JR Z,MaskSprite_NextSide
MaskSprite_Loop 8A69 DEC C Decrease the shadow row counter and draw the next row of the new image.
8A6A CALL MaskSprite_LoadMaskAgain

8A6E JR MaskSprite
MaskSprite_TryShadow 8A70 EXX Switch to the shadow registers.
8A71 LD A,C Jump to MaskSprite_Loop if the shadow row counter is still live.
8A72 AND A
8A73 JR NZ,MaskSprite_Loop
Finish the sprite if any rows remain to be erased or drawn.
