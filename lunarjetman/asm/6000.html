6000: Laser Beam Parameters
Four 18-byte actor slots for the laser beams, in the same field order as Jetman_Slot. They are the first of the 18 actor slots, which run up to Actor_List_End. Every slot is laid out the same way:
Offset Contents
00 Type (the sprite ID)
01 Screen column
02-03 World X
04 Y
05 Horizontal speed
06 Vertical thrust
07 Colour
08 Flags
09-0F Sprite cache, cleared by ClearSpriteCaches
10-17 State specific to the actor type
