824A: Limit Frame Rate
Handler for an empty actor slot (type 00). Waits for a short delay unless a frame update is running. A larger counter here slows the game down.
Return if the frame is marked as updated, otherwise pause.
LimitFrameRate 824A LD A,($5E52) Return if FrameUpdated is marked as being updated.
824D AND A
824E RET NZ
824F LD HL,$00C0 Introduce a counter (00C0) for a slight pause.
LimitFrameRate_Loop 8252 DEC HL Decrease counter by one.
8253 LD A,L Keep jumping back to LimitFrameRate_Loop until the counter is zero.
8254 OR H
8255 JR NZ,LimitFrameRate_Loop
8257 RET Return.
