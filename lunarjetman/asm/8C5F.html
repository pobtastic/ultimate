8C5F: Unset Flash Text
Used by the routine at Handler_Jetman.
Clear the FLASH bit of the three score label attributes at the screen position in HL.
Input
HL Pixel address co-ordinates
UnsetFlashText 8C5F CALL AttributeAddress Call AttributeAddress.
8C62 LD B,$03 Set a letter counter in B for 03 loops.
UnsetFlashText_Loop 8C64 LD A,(HL) Fetch the attribute byte.
8C65 AND %01111111 Keep only bits 0-6 (i.e. everything except the flash bit).
8C67 LD (HL),A Write the attribute byte back to *HL.
8C68 INC HL Increment the attribute address pointer by one.
8C69 DJNZ UnsetFlashText_Loop Decrease the counter by one and jump back to UnsetFlashText_Loop until it is zero.
8C6B RET Return.
