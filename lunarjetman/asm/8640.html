8640: Draw Cached Sprite
Clear the scratch counts, load the actor's cached sprite with LoadSpriteScratch and start the draw through XORSpriteLoop.
Input
IX Actor slot
Before DrawCachedSprite After DrawCachedSprite
The cached image of the sprite is XORed off the screen, so the pixels of the sprite disappear.
