80FD: Queue Menu Tune
Used by the routine at Game_Restart.
Picks the 1UP or 2UP jingle from Player_Tune_Table and queues it.
Input
C Game options from GameOptions
Pick the 1UP or 2UP jingle and queue it.
QueueMenuTune 80FD LD DE,$BAA4 Set the tune table pointer to Player_Tune_Table.
8100 LD A,C Fetch the game options.
8101 RLCA Move the player-count bit into bit 1.
8102 AND %00000010 Keep only bit 1.
8104 LD L,A Create an offset using the player-count bit.
8105 LD H,$00
8107 ADD HL,DE Point HL at the matching entry in Player_Tune_Table.
8108 LD E,(HL) Fetch the 1UP or 2UP jingle address.
8109 INC HL
810A LD D,(HL)
810B JP QueueTune Jump to QueueTune.
