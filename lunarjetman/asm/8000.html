8000: Security Check
Used by the routine at GameEntry.
A short copy-protection test on the FRAMES timer. The game starts when the check passes.
SecurityCheck 8000 DI Disable interrupts.
8001 LD SP,$5E00 Set the stack pointer to GameOptions.
8004 LD A,($5C79) A=FRAMES+01.
8007 CP $83 Return if the timer is not 83.
8009 RET NZ
Continue on to GameInitialisation.
