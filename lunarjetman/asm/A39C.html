A39C: Attach Carried Item
Used by the routine at Handler_WorldObject.
Mark the object as carried and set RoverCargoFlag.

Mark the object as carried and set RoverCargoFlag.

A3A0 LD A,$01 Write 01 to RoverCargoFlag.

A3BC LD (IX+$08),A Write the flags back.
