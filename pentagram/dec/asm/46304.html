46304: Pause Game
Used by the routine at RunGame.
Pauses the game while CAPS SHIFT or SPACE is held down on its own. A click is made to say that the game has been paused, and the game then waits for the key to be released, pressed and released again before another click and returning.
Interrupts are enabled while the game is paused, and the system variable pointer in IY is set up to what the ROM interrupt routine expects.
Return unless CAPS SHIFT or SPACE is the only key being pressed.
PauseGame 46304 LD A,126 Read from the keyboard, with a call to ReadKeyboardPort that returns the pressed keys as set bits;
