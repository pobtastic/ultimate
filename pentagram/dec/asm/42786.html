42786: Inventory
The objects the player is carrying: four entries of four bytes. Each holds the object type, the object flags and the address of the object's entry in the persistent object store at ObjectStore. The first entry is only used while an object is being picked up or dropped, and is empty the rest of the time. The other three are the objects that are carried, and are the ones that DisplayObjectsCarried shows. A new object goes into the second entry; the older ones move along when it is picked up, and the one in the last entry is the one that HandlePickupAndDrop drops.
ObjectsCarried 42786 DEFB 0,0,0,0 The object that has just been picked up or dropped.
ObjectsCarried_Newest 42790 DEFB 0,0,0,0 The object that has been carried for the least time.
42794 DEFB 0,0,0 The first three bytes of the object that has been carried for a time between the others.
ObjectsCarried_MiddleEnd 42797 DEFB 0 The last byte of the object that has been carried for a time between the others.
ObjectsCarried_Oldest 42798 DEFB 0,0,0 The first three bytes of the object that has been carried for the longest time.
ObjectsCarried_OldestEnd 42801 DEFB 0 The last byte of the object that has been carried for the longest time.
