53841: Run Four Frame Wanderer
The handler of the object types 168 to 171, which are creatures that harm the player and wander about the room in the same way as RunWanderer. Bit 0 of the type is turned around each frame, to make the creature walk, and bit 1 is used to show which way it is going.
Input

Flip the walk frame, then move the creature.
