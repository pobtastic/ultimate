47206: Push Object On Block
Used by the routine at BlockMovementInZ.
Pushes an object that stands on a moving block. The type of the block gives the direction of the push, in the low two bits, and the object is pushed on every other frame. The pushes are in a table of pairs of speeds at ConveyorPushes.
A block is not pushed if it already has something on it, so the first thing on it does the pushing.
Input
A Type of the block
IX Object record
IY Block record
Return if the block already has something on it.
