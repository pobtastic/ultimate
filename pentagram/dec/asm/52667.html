52667: Run Lift
The handler of the object type 84 which is a lift. When the player (or a block of type 91) lands on it, it carries it up, to a height of 176. When there is nothing on it any longer, it comes down again to where it started.
The state of the lift is in the handler flags: bit 0 is set while it is going up, bit 1 is set while it is coming down, and bit 7 is set by MarkObjectBelow when something lands on it. The collision flag for being stopped along z is used to find out if something is pushing down on it.
