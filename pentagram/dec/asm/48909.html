48909: Reset Wipe Flags
Used by the routine at RunGame.
Clears the flag in all of the object records that says that an object has moved and that the area where it was has to be restored. This is done once the room has been drawn in full, as that makes the flag out of date.
ResetWipeFlags 48909 LD B,54 Set a counter in B of the number of object records, 54.
48911 LD DE,32 Set the size of an object record in DE.
48914 LD HL,42870 Start at the flags of the first record of ObjectsTable.
ResetWipeFlags_Loop 48917 RES 5,(HL) Clear bit 5 of the flags, to say that the object has not moved.
48919 ADD HL,DE Move on to the flags of the next object.
48920 DJNZ ResetWipeFlags_Loop Decrease the counter and loop until all the records have been done.
48922 RET Return.
