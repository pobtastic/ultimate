47330: Keep Object In Room In X
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along x until it stays inside the walls of the room, and flags a hit on x in the collision flags if it had to. Nothing is done if the object is allowed to ignore the walls, or has only just entered the room (which is when the top four bits of its collision flags are not zero), as it would be outside them.
The limit is in RoomSizeX, and the walls are placed an equal distance either side of position 128.
Input
C Distance to move along x
IX Object record
Output
C Distance that can be moved
