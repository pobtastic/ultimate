49415: Start Explosion
Used by the routines at RunProjectile, HandlePlayerLegs, HandlePlayerTop and RunHelper.
Turns an object into the first stage of an explosion, which is a type that has its own animation in RunExplosion. This is used for the player and for the projectiles.
Input
IX Record of the object
StartExplosion 49415 LD (IX+0),64 Change the object to the type of the first stage of an explosion.
49419 SET 1,(IX+7) Flag the object as being moved, so that nothing can push it.
49423 JR RunExplosion_MarkObjectMoved Jump to RunExplosion_MarkObjectMoved to mark it to be drawn.
