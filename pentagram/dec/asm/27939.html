27939: Template Data
The templates, each a list of objects of five bytes, which are the type, the half sizes along x and y, the size along z and the flags, and which ends with a 0 in place of the type of another object. The position of an object comes from the cell that BuildRoomScenery is making it for. Two of the template numbers are for the same template.
