52493: Speed Up Backwards
Used by the routine at RunHomingCreature.
Takes three off a stored speed of a creature, down to a limit of 184 (which is four and a half in sixteenths, backwards).
Input
A Stored speed
Output
A New stored speed
SpeedUpBackwards 52493 SUB 3 Take three off the speed.
52495 RET P Return if it is positive.
52496 CP 184 Return if it is not less than the limit.
52498 RET NC
52499 LD A,184 Set the speed to the limit.
52501 RET Return.
