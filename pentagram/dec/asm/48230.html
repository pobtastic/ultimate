48230: Print Text Single Colour
Used by the routines at PrintScoreLabel and DisplayMenu.
Prints a line of text in the colour held in TextAttribute, using the ASCII font at Font. The last character of the text has bit 7 set. Each character cell has its attribute set as well.
Input
DE Address of the text
H Pixel y position
L Pixel x position
Output
DE Address after the text
Point at the ASCII font and keep TextAttribute.
