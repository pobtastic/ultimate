45972: Calculate Screen Address
Used by the routines at CopyScoreToScreen, DrawChangedObjects and DisplayObjectsCarried.
Finds the address in the display file of the byte that holds a pixel. The y co-ordinate counts up from the bottom of the screen, so the first step is to invert it. A y co-ordinate of 192 or more is above the top of the screen, and gives an address below 16384.
Input
B Pixel y co-ordinate, counting up from the bottom of the screen
C Pixel x co-ordinate
Output
DE Address in the display file
Start with the column, which is the x co-ordinate divided by eight.
