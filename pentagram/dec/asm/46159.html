46159: Draw Aligned Columns
Draws the rows of a sprite that is not shifted. There is one unit of code for each byte column of the sprite, and the first unit that is used depends on the width of the sprite: the jump at DrawLines_Jump is patched with a displacement that enters the run at the right place. The last unit finishes by jumping to DrawLines_FinishRow.
Every unit fetches a mask and a pixel byte, clears the bits of the buffer under the mask and sets the pixel bits.
The first unit of the run, which is used by sprites of five bytes wide.
DrawAlignedColumns 46159 POP DE Fetch the mask byte into E and the pixel byte into D.
46160 LD A,(BC) Fetch the byte from the buffer.
46161 CPL Invert it.
46162 OR E Set the mask bits (which clears them once it is inverted back).
46163 CPL Invert it back, which leaves the bits under the mask cleared.
46164 OR D Set the pixel bits.
46165 LD (BC),A Write the byte to the buffer.
46166 INC BC Move on to the next byte of the buffer.
The second unit, which is used by sprites that are four bytes wide.
46167 POP DE Draw the second byte column in the same way as the first.
46168 LD A,(BC)
46169 CPL
46170 OR E
46171 CPL
46172 OR D
46173 LD (BC),A
46174 INC BC
The third unit, which is used by sprites that are three bytes wide.

46179 CPL

The fourth unit, which is used by sprites that are two bytes wide.

The last unit, which is used by sprites that are one byte wide.
46191 POP DE Draw the last byte column, but without moving on to the next byte.

46195 CPL
