47944: Print BCD Number
Used by the routines at DrawLives and PrintQuestPercentage.
Draws the digits of binary coded decimal bytes, two to a byte, into the buffer, using the digit glyphs at the start of the font.
Input
B Number of bytes
DE Address of the first byte
HL Address in the buffer of the top line of the place for the first
digit
