47373: Keep Object In Room In Y
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along y until it stays inside the walls of the room, in the same way as KeepObjectInRoomInX does for x. The limit is in RoomSizeY.
Input
L Distance to move along y
IX Object record
Output
L Distance that can be moved
KeepObjectInRoomInY 47373 LD A,(IX+12) Fetch the collision flags.
47376 AND %11110000 Keep only the countdown from entering the room.
47378 RET NZ Return if the object has only just entered the room.
47379 BIT 0,(IX+7) Return if the object ignores the walls.
47383 RET NZ
47384 LD A,(42782) Fetch the limit along y in B.
47387 LD B,A
KeepObjectInRoomInY_Test 47388 LD A,(IX+2) Work out the position of the object along y, once it has moved.
47391 ADD A,L
47392 SUB 128 Subtract 128 to get its distance from the middle.
47394 JR NC,KeepObjectInRoomInY_Compare Jump to KeepObjectInRoomInY_Compare if that is not negative.
47396 NEG Make the distance positive.
KeepObjectInRoomInY_Compare 47398 ADD A,(IX+5) Add the half size of the object, to get the distance of its edge from the middle.
47401 CP B Return if the edge is inside the limit.
47402 JR C,KeepObjectInRoomInY_Done
47404 SET 1,(IX+12) Flag that the object has been stopped along y.
47408 LD A,L Fetch the distance to move.
47409 CALL BringSpeedCloserToZero Call BringSpeedCloserToZero to step it one closer to zero.
47412 LD L,A Set the distance.
47413 JR NZ,KeepObjectInRoomInY_Test Jump to KeepObjectInRoomInY_Test to test again, unless the distance is zero.
KeepObjectInRoomInY_Done 47415 RET Return.
