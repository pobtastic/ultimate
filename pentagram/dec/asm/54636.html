54636: Play Moving Sound
Never used. Makes a short tone of a pitch from the table at MovingSoundPitches, which is picked by the frame counter, for an object that has been moved, as shown by the flag for it being moved.
Input
IX Object record
PlayMovingSound 54636 LD BC,54663 Take the table of pitches, MovingSoundPitches.
54639 BIT 1,(IX+7) Test the flag for the object being moved.
54643 RES 1,(IX+7) Clear the flag.
54647 RET Z Return if it was not set.
54648 LD A,(42773) Fetch the frame counter.
54651 AND %00001111 Keep the lowest four bits.
54653 LD L,A Put that in HL.
54654 LD H,0
54656 ADD HL,BC Add the table to it.
54657 LD B,(HL) Fetch the pitch.
54658 LD C,12 Set the length of the tone.
54660 JP PlayWaveSequence Jump to PlayWaveSequence to make the tone.
