46993: Block Movement In Y
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along y until it does not go through any other object, in the same way as BlockMovementInX does for x.
Input
L Distance to move along y
IX Object record
Output
L Distance that can be moved
Try the object against each of the objects in turn.
