51019: Set Sprite Offset Minus 8 0
Sets how far the sprite of an object is moved from the position on the screen that is worked out for it by CalculatePixelCoordinates, which is 8 to the left and none up. The same is done by each of the routines up to SetSpriteOffset_Minus8_Minus2, which differ in the distances. It is also the handler of the object type 57 which does nothing else.
Input
IX Object record
SetSpriteOffset_Minus8_0 51019 LD HL,248 Set the offsets in HL, which are 248 horizontally and 0 vertically.
51022 JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
