54940: Play Music Once
Used by the routine at GameMenu.
Plays the tune of the menu, until a key is pressed or the tune ends. The tune is only started once in a game, as the flag at TunePlayedFlag is set when it is, and it is only cleared when the game starts.
Input
DE Address of the tune
PlayMusicOnce 54940 LD HL,42823 Take the flag for the tune having been played, TunePlayedFlag.
54943 LD A,(HL) Fetch it.
54944 AND A Return if the tune has been played already.
54945 RET NZ
54946 SET 0,(HL) Set the flag.
PlayMusicOnce_Loop 54948 XOR A Clear A to read all of the rows of the keyboard.
54949 CALL ReadKeyboardPort Call ReadKeyboardPort to read the keyboard.
54952 JR Z,PlayMusicOnce_Note Jump to PlayMusicOnce_Note if no key is pressed.
54954 RET Return, as a key is pressed.
PlayMusicOnce_Note 54955 LD A,(DE) Fetch the next note.
54956 CP 255 Return if it is the end of the tune.
54958 JR Z,PlayMusic_Done
54960 CALL PlayNote Call PlayNote to play it.
54963 JR PlayMusicOnce_Loop Jump back to PlayMusicOnce_Loop to play the next.
