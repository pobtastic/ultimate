50339: Test Player In Room
Used by the routines at HandlePickupAndDrop and HandlePlayerLegs.
Tests if an object is clear of the walls of the room, which is to say that the middle of it is nearer to the middle of the room than the wall is, once the half size of the object has been taken off.
Input
IX Record of the object
Output
F Carry flag set if the object is clear of the walls
TestPlayerInRoom 50339 LD HL,(42781) Fetch the limits of the room, RoomSizeX along x and RoomSizeY along y.
50342 LD A,L Take the half size along x off the limit along x.
50343 SUB (IX+4)
50346 LD L,A
50347 LD A,H Take the half size along y off the limit along y.
50348 SUB (IX+5)
50351 LD H,A
50352 LD A,(IX+1) Fetch the x position of the object.
50355 SUB 128 Take away the middle of the room, 128 and jump to TestPlayerInRoom_LimitX if the distance is not negative.
50357 JP P,TestPlayerInRoom_LimitX
50360 NEG Make the distance positive.
TestPlayerInRoom_LimitX 50362 CP L Return with the carry flag clear if the distance is not less than the limit along x.
50363 RET NC
50364 LD A,(IX+2) Fetch the y position of the object.
50367 SUB 128 Take away the middle of the room, 128 and jump to TestPlayerInRoom_LimitY if the distance is not negative.
50369 JP P,TestPlayerInRoom_LimitY
50372 NEG Make the distance positive.
TestPlayerInRoom_LimitY 50374 CP H Test the distance against the limit along y.
50375 RET Return with the carry flag set if it is less than that.
