46368: Find Object Address
Used by the routines at DrawChangedObjects and DrawObjectsInOrder.
Finds the address of an object record, from its number. Bit 7 of the number is ignored, as that is used as a flag in the draw list.
Input
A Object number
Output
HL Address of the object record
Turn the object number into an address in the object table.
