48088: Flash Menu Options
Used by the routine at GameMenu.
Makes the line of the menu that shows the chosen control method flash, and stops the other three from flashing. The line that starts the game flashes if bit 3 of ControlMethod is set, which the menu never does.
Flash the chosen control method.
FlashMenuOptions 48088 LD HL,48114 Start at the colour of the first control method line, which is the byte after the first of MenuColours.
48091 LD A,(42761) Fetch the control method.
48094 RRCA Shift the method down to bits 0 and 1...
48095 AND %00000011 ...and keep only those bits.
48097 LD B,4 Set a counter in B of four lines.
48099 CALL SetFlashingAttribute Call SetFlashingAttribute to make that line flash.
Flash the start-game line if bit 3 of ControlMethod is set.
48102 RES 7,(HL) Stop the line that starts the game from flashing.
48104 LD A,(42761) Fetch the control method.
48107 AND %00001000 Keep only bit 3.
48109 RET Z Return if it is not set.
48110 SET 7,(HL) Make the line that starts the game flash.
48112 RET Return.
