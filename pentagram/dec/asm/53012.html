53012: Run Static Object
The handler of the object types 121 to 135, which include the eight parts of the pentagram. They do not move, unless they can be pushed and something pushes them.
Input
IX Object record
RunStaticObject 53012 CALL SetSpriteOffset_Minus16_Minus8 Call SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
53015 CALL ApplyGravityAndMove_Move Call ApplyGravityAndMove_Move to move the object, without gravity.
53018 BIT 2,(IX+7) Return if the object cannot be pushed.
53022 RET Z
53023 JP FinishObjectMove Jump to FinishObjectMove to finish.
