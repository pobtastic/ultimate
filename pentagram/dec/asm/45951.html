45951: Calculate Buffer Address
Used by the routines at CopyScoreToScreen, DrawChangedObjects, DrawObject, DisplayObjectsCarried, DrawScore, PrintTextSingleColour, PrintTextStandardFont and PrintQuestPercentage.
Finds the address in the buffer of the byte that holds a pixel. The buffer is 32 bytes wide with its bottom line first, so the address is 55439 + y * 32 + x / 8.
Input
B Pixel y co-ordinate, counting up from the bottom of the screen
C Pixel x co-ordinate
Output
BC Address in the buffer
