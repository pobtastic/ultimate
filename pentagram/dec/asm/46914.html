46914: Block Movement In X
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along x until it does not go through any other object. The speed is reduced by one each time until the object no longer overlaps the other object, or it is zero.
When the object hits another object, the two objects share their hit flags, and if the other object can be pushed, it is given the speed of this object.
Input
C Distance to move along x
IX Object record
Output
C Distance that can be moved
Try the object against each of the objects in turn.
