52484: Speed Up Forwards
Used by the routine at RunHomingCreature.
Adds three to a stored speed of a creature, up to a limit of 56 (which is three and a half in sixteenths).
Input
A Stored speed
Output
A New stored speed
SpeedUpForwards 52484 ADD A,3 Add three to the speed.
52486 RET M Return if it is negative.
52487 CP 56 Return if it is less than the limit.
52489 RET C
52490 LD A,56 Set the speed to the limit.
52492 RET Return.
