52502: Run Pentagram Stone
The handler of the object types 144 to 148, which are the five stones that have to be put on the pentagram. A stone can be picked up and dropped by the player, and falls like any other object, which is done by RunFallingObject_MoveFallingObject.
In the room of the pentagram (room 82), once it has been revealed by CheckObjectsCollected, a stone moves by itself instead. It is steered along x and y to the place that it has on the pentagram, which is one of the five pairs of positions at StonePlacesOnPentagram, with one for each of the stones, and it is not affected by gravity. When it gets there, it changes into the type that is 8 higher, which is a stone that is alight, and one is added to the count of stones in place. The game is won when the fifth is in place.
Input
IX Object record
Fall under gravity unless the pentagram is revealed.
