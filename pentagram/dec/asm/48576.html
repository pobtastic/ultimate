48576: Set Sprite Details
Used by the routines at DrawFrame, PrintBorder and PrintTableSprite.
Sets the sprite number, the flags and the pixel position of an object from four bytes of data.
Input
HL The address of the data
IX The address of the object
Output
HL The address of the byte after the data
Set the type of the object.
SetSpriteDetails 48576 LD A,(HL) Fetch the sprite number and move on.
48577 INC HL
48578 LD (IX+0),A Set the sprite number.
Set the flags of the object.
48581 LD A,(HL) Fetch the flags and move on.
48582 INC HL
48583 LD (IX+7),A Set the flags.
Set the screen x co-ordinate of the object.
48586 LD A,(HL) Fetch the pixel x and move on.
48587 INC HL
48588 LD (IX+26),A Set the pixel x position.
Set the screen y co-ordinate of the object.
48591 LD A,(HL) Fetch the pixel y and move on.
48592 INC HL
48593 LD (IX+27),A Set the pixel y position.
48596 RET Return.
