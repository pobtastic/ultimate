48576: Set Sprite Details
Used by the routines at DrawFrame, PrintBorder and PrintTableSprite.
Sets up the temporary object from the four bytes that describe a piece of a frame: the type, the flags and the screen position.
Input
HL Address of the data
IX Temporary object record
Output
HL Address of the data after the piece
SetSpriteDetails 48576 LD A,(HL) Set the type of the object.
48577 INC HL
48578 LD (IX+0),A
48581 LD A,(HL) Set the flags of the object.
48582 INC HL
48583 LD (IX+7),A
48586 LD A,(HL) Set the screen x co-ordinate of the object.
48587 INC HL
48588 LD (IX+26),A
48591 LD A,(HL) Set the screen y co-ordinate of the object.
48592 INC HL
48593 LD (IX+27),A
48596 RET Return.
