47442: Read Keyboard Port
Used by the routines at PauseGame, GameMenu, ReadControls and PlayMusicOnce.
Reads half-rows of the keyboard. The pressed keys come back as set bits, in the same order as the bits that the keyboard port gives, so bit 0 is the key that is nearest the outside edge of the keyboard.
The value is also written to port 253 first, whose effect on a 128K Spectrum, which uses that port number for paging, is not known.
Input
A High byte of the port, which selects the half-rows: a bit that is
clear selects a half-row
Output
A Keys pressed, in bits 0 to 4
ReadKeyboardPort 47442 OUT (253),A Write the value to port 253.
47444 IN A,(254) Read the keyboard half-rows.
47446 CPL Make the pressed keys set bits.
47447 AND %00011111 Keep only the five keys.
47449 RET Return.
