52597: Run Block
The handler of the object type 91 which is a block that falls but cannot be pushed along x or y. It is also treated like the player when it lands on something, see MarkObjectBelow. It carries on as RunTable.
Input
IX Object record
RunBlock 52597 XOR A Set the speeds along x and y to zero.
52598 LD (IX+9),A
52601 LD (IX+10),A
Continue on to RunTable.
