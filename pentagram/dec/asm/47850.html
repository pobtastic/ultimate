47850: Print Character
Used by the routines at PrintBCDNumber and PrintText.
Draws a character into the buffer, a 8 by 8 block of pixels, and leaves the address ready for the next character. A space is drawn as the glyph with code 61 which is blank. The glyph is found in the table at the address in FontPointer: the address of a glyph is that address plus the code times eight.
Input
A Character code
HL Address in the buffer of the top line of the place for the character
Output
HL Address in the buffer of the top line of the place to the right
Find the glyph.
PrintCharacter 47850 PUSH BC Stash BC, DE and HL on the stack.
47851 PUSH DE
47852 PUSH HL
47853 CP 32 Jump to PrintCharacter_Glyph if the character is not a space.
47855 JR NZ,PrintCharacter_Glyph
47857 LD A,61 Use the glyph for the code 61 instead, which is blank.
PrintCharacter_Glyph 47859 LD L,A Set HL to the character code.
47860 LD H,0
47862 ADD HL,HL Multiply it by eight.
47863 ADD HL,HL
47864 ADD HL,HL
47865 LD DE,(42802) Fetch the address of the glyph table from FontPointer.
47869 ADD HL,DE Add it to get the address of the glyph.
47870 EX DE,HL Set DE to it.
47871 POP HL Restore HL, the address in the buffer, from the stack.
Copy the eight lines of the glyph to the buffer, working down the buffer from the top line.
47872 LD B,8 Set a counter in B of eight lines.
PrintCharacter_Loop 47874 LD A,(DE) Copy a line of the glyph to the buffer.
47875 LD (HL),A
47876 INC DE Move on to the next line of the glyph.
47877 PUSH BC Stash the counter on the stack.
47878 LD BC,65504 Set BC to 65504 which is minus the length of a line of the buffer.
47881 ADD HL,BC Move HL down to the next line of the buffer.
47882 POP BC Restore the counter.
47883 DJNZ PrintCharacter_Loop Decrease the counter and loop until all eight lines have been copied.
Move on to the next character position, which is eight lines up and one byte to the right.
47885 POP DE Restore DE from the stack.
47886 LD BC,257 Add 257 to HL.
47889 ADD HL,BC
47890 POP BC Restore BC from the stack.
47891 RET Return.
