53562: Check Objects Collected
Used by the routine at RunCollectableObject.
Finds out if all four of the quest objects have been collected, which is when there are four entries in the object store that have the types 116 to 119. If they have, the eight parts of the pentagram are flagged as needing to be drawn, and the pentagram is flagged as being revealed, so that LoadRoomObjects brings the parts into a room.
Input
IX Record of the object that was collected

CheckObjectsCollected_Count 53567 LD A,(IY+0) Fetch the type of the entry.
53570 AND %11111100 Keep the type without its lowest two bits.
53572 CP 116 Jump to CheckObjectsCollected_Next unless it is one of the types 116 to 119.
53574 JR NZ,CheckObjectsCollected_Next
53576 INC C Add one to the count.
CheckObjectsCollected_Next 53577 ADD IY,DE Move on to the next entry.
53579 DJNZ CheckObjectsCollected_Count Jump to CheckObjectsCollected_Count until all of the entries have been tested.
53581 LD A,C Fetch the count.
53582 CP 4 Return unless all four have been collected.
53584 RET NZ
53585 CALL PointAtStore Call PointAtStore to point IY at the first entry of the object store again.
