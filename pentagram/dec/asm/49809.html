49809: Set Deadly Flags
Used by the routines at RunDangerousFixed, RunDangerousMarked, RunHarmfulFallingObject, RunHarmfulBobbingBlock, RunHarmfulSliderX, RunHarmfulSliderY, RunWanderingSpark, RunWanderer and RunFourFrameWanderer.
Flags an object as one that harms the player, both when it hits something that is not moving and when something moves into it.
Input
IX Record of the object
SetDeadlyFlags 49809 LD A,(IX+13) Fetch the hit flags of the object.
49812 OR %10100000 Set bits 5 and 7, which are the ones that harm anything that touches the object.
49814 LD (IX+13),A Set them in the object.
49817 RET Return.
