49425: Run Explosion
The handler of the object types 64 to 70, which are the stages of an explosion. Each time it is run the object moves on to the next type, which has the next sprite.
Input
IX Record of the object
RunExplosion 49425 CALL SetSpriteOffset_Minus12_Minus4 Call SetSpriteOffset_Minus12_Minus4 to set where the sprite is drawn.
49428 CALL PlayExplosionSound Call PlayExplosionSound to make a noise.
49431 INC (IX+0) Move on to the next type.
This entry point is used by the routines at StartExplosion and FinishExplosion.
RunExplosion_MarkObjectMoved 49434 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags to mark the object to be drawn.
