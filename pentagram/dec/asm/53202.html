53202: Run Helper Source
The handler of the object type 120, which makes a helper (the object type 90, run by RunHelper) when it has been hit by enough of the projectiles of the player. Nothing happens while there is a helper in the game already. Otherwise, a count at 20 of its record goes up by one for each frame that a projectile is touching it, and the helper is made when the count gets to 32.
The helper is made by copying the record of this object into a free object slot, and changing it. It starts in front of the object, rising. The type and room of the helper are also written to the last entry of the object store, ObjectStore_Helper, so that it is remembered when the player leaves the room.
