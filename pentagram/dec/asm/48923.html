48923: Test Object Intersections
Used by the routines at LoadRoomObjects, HandlePickupAndDrop and CreateCreature.
Tests if an object is overlapping any other object, where it is at the moment. This is used to find out if there is room to put the object somewhere, once its position has been changed.
Input
IX Record of the object
Output
F Carry flag set if the object overlaps another object

48924 PUSH DE

48938 SET 1,(IX+7) Flag the object as being moved, so that it is not tested against itself.
Test whether this object overlaps on all three axes.
