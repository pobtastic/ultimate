47266: Test Overlap In X
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along x, once the first one has moved by a distance. The objects overlap if the distance between their centres is less than the sum of their half sizes.
Input
C Distance that the first object moves along x
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInX 47266 LD A,(IX+4) Add the half sizes of the objects along x together, in D.
47269 ADD A,(IY+4)
47272 LD D,A
47273 LD A,(IX+1) Work out the distance between the centres, once the first has moved.
47276 ADD A,C
47277 SUB (IY+1)
47280 JP P,TestOverlapInX_Compare Jump to TestOverlapInX_Compare if the distance is positive.
47283 NEG Make the distance positive.
TestOverlapInX_Compare 47285 SUB D Subtract the sum of the half sizes, which sets the carry flag if they overlap.
47286 RET Return.
