47308: Test Overlap In Z
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along z, once the first one has moved by a distance. The z position of an object is its bottom, so the distance between the bottoms is compared with the height of the object that is the lower of the two.
Input
H Distance that the first object moves along z
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInZ 47308 LD A,(IX+3) Work out the distance between the bottoms of the objects, once the first has moved.
47311 ADD A,H
47312 SUB (IY+3)
47315 JP P,TestOverlapInZ_SecondLower Jump to TestOverlapInZ_SecondLower if the first object is the higher.
47318 NEG Make the distance positive.
47320 LD D,(IX+6) Fetch the height of the first object, which is the lower.
TestOverlapInZ_Compare 47323 SUB D Subtract the height of the lower object, which sets the carry flag if they overlap.
47324 RET Return.
TestOverlapInZ_SecondLower 47325 LD D,(IY+6) Fetch the height of the second object, which is the lower.
47328 JR TestOverlapInZ_Compare Jump to TestOverlapInZ_Compare.
