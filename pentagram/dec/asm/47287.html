47287: Test Overlap In Y
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along y, once the first one has moved by a distance, in the same way as TestOverlapInX does for x.
Input
L Distance that the first object moves along y
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInY 47287 LD A,(IX+5) Add the half sizes of the objects along y together, in D.
47290 ADD A,(IY+5)
47293 LD D,A
47294 LD A,(IX+2) Work out the distance between the centres, once the first has moved.
47297 ADD A,L
47298 SUB (IY+2)
47301 JP P,TestOverlapInY_Compare Jump to TestOverlapInY_Compare if the distance is positive.
47304 NEG Make the distance positive.
TestOverlapInY_Compare 47306 SUB D Subtract the sum of the half sizes, which sets the carry flag if they overlap.
47307 RET Return.
