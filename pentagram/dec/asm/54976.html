54976: Play Note
Used by the routines at PlayMusicOnce and PlayMusic.
Plays a note of a tune, or lets the time of a rest go by. The note is a byte in which the lowest six bits are the number of the note, with a rest if it is zero, and the highest two bits are one less than the length of the note, which is that number of times the length of the shortest note. The pitch and the number of cycles of the note come from the table at NoteTable. A note is made of the same number of cycles for each of its lengths, so that the notes are all as long, whatever their pitch.
Input
A Note
DE Address of the note in the tune
Output
DE Address of the next note
PlayNote 54976 AND %00111111 Keep the number of the note.
54978 JR Z,PlayNote_Rest Jump to PlayNote_Rest if it is a rest.
Look up the delays and the number of cycles in the table at NoteTable.

54981 LD H,0

54984 CALL AddAToHL Call AddAToHL to add the number, to make three times it.
54987 LD BC,55064 Find the note in the table at NoteTable.
54990 ADD HL,BC Add it to find the entry of the note.
54991 LD B,(HL) Fetch the count for the first run of the delay loop for half a cycle.
54992 INC HL Move on.
54993 LD C,(HL) Fetch the number of times that the delay loop is run on from there.
54994 INC HL Move on.
54995 LD L,(HL) Fetch the number of cycles for a note of the shortest length.
54996 LD H,0 Clear the high byte.
Bits 6 and 7 of the note are the length, less one.
54998 LD A,(DE) Fetch the note again.
54999 RLCA Move the highest two bits to the lowest.
55000 RLCA
55001 AND %00000011 Keep them.
55003 INC A Add one to get the length of the note.
55004 PUSH DE Save the address in the tune.
55005 LD E,L Copy the number of cycles to DE.
55006 LD D,H
Multiply the number of cycles by the length of the note.

55008 JR Z,PlayNote_Start Jump to PlayNote_Start if it is the last.

Each pass of this loop makes one cycle of the note, so the length of the note is the number of cycles.
PlayNote_Cycle 55014 PUSH BC Save the half length of a cycle.
55015 XOR A Set the speaker to off.
55016 OUT (254),A Write it to the ULA.
PlayNote_LowWait 55018 DJNZ PlayNote_LowWait Wait while the speaker is off.
55020 DEC C Count a loop of the high byte.

55023 POP BC Get the half length back.
55024 PUSH BC Save it again.
55025 LD A,16 Set bit 4 to turn the speaker on.
55027 OUT (254),A Write it to the ULA.
PlayNote_HighWait 55029 DJNZ PlayNote_HighWait Wait while the speaker is on.
55031 DEC C Count a loop of the high byte.
55032 JR NZ,PlayNote_HighWait Jump back to PlayNote_HighWait until the half cycle is over.
55034 POP BC Get the half length back.
55035 DEC HL Count the cycle.
55036 LD A,H Test whether there are any left.
55037 OR L
55038 JR NZ,PlayNote_Cycle Jump back to PlayNote_Cycle until all of the cycles have been made.
55040 INC DE Move on to the next note of the tune.
55041 RET Return.
