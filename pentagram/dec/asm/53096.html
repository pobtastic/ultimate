53096: Run Collectable Object
The handler of the object types 112 to 119 which are the four objects that are the aim of the quest, and the same four once they have been collected. An object is collected by the helper, RunHelper, which sets bit 0 of the handler flags at 22.
When that has happened, the player is given an extra life, and the object changes to the type that is 4 higher, in the object store as well. When all four have been collected, CheckObjectsCollected reveals the pentagram.
