49670: Test Creature Hit
Used by the routine at RunProjectile.
Tests if an object touches either of the two creatures that wander about the room, which are in the object records ObjectsTable_Creatures and ObjectsTable_SecondCreature. The touching is tested with a margin of 2.
Input
IX Record of the object
Output
D 0 if it touches a creature (and IY holds the record of the
creature), or 1 if it does not
TestCreatureHit 49670 LD D,1 Set the result to 1 as nothing has been hit.
49672 LD IY,42991 Start with the first of the creatures, ObjectsTable_Creatures.
49676 CALL TestCreatureHit_Test Call TestCreatureHit_Test to test it.
49679 LD A,D Fetch the result.
49680 AND A Return if the creature was hit.
49681 RET Z
49682 LD IY,43023 Move on to the second of the creatures, ObjectsTable_SecondCreature.
This entry point is used by the routine at TestProjectileHit.
Ignore objects that are free, are of a type below 8 or are explosions.
TestCreatureHit_Test 49686 LD A,(IY+0) Fetch the type of the creature.
49689 AND %11111000 Keep only the bits of the type that tell the kinds of object apart.
49691 RET Z Return if the object is free or of a type that is below 8.
49692 CP 64 Compare the kind of the object with 64 which is an explosion.
This entry point is used by the routine at TestProjectileHit.
TestCreatureHit_Projectile 49694 RET Z Return if it is an explosion.
