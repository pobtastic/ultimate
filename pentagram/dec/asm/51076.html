51076: Set Sprite Offset Minus 8 Minus 2
Sets the offsets of the sprite to 248 horizontally and 254 vertically. It is also the handler of the object types 12 to 15 and 52 which do nothing else.
Input
IX Object record
SetSpriteOffset_Minus8_Minus2 51076 LD HL,65272 Set the offsets in HL.
51079 JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
