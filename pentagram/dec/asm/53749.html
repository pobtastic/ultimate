53749: Run Flickering Wanderer
The handler of the object types 16 and 17, which are creatures that harm the player and wander about the room. It turns the sprite over each frame, to make it flicker, and carries on as RunWanderer.
Input
IX Object record
RunFlickeringWanderer 53749 LD A,(IX+7) Fetch the flags of the object.
53752 XOR %01000000 Turn the sprite over.
53754 LD (IX+7),A Store the flags.
Continue on to RunWanderer.
