24064: Game Entry Point
The entry point of the game, called by the loader once the code has been loaded.
GameEntry 24064 DI Disable interrupts.
24065 LD SP,24064 Set the stack pointer to GameEntry, so the stack grows downwards from the start of the game code.
24068 JP RunGame Jump to RunGame.
