55064: Note Table
The entries for the notes, which PlayNote uses, of three bytes each, for the notes 0 to 60. For each note, the first byte is the count for the first run of the delay loop that makes half a cycle, and the second byte is the number of times that it is run on from there, in runs of 256 and the third is the number of cycles that a note of the shortest length is played for. The entry for the note 0 is not used, as that is a rest.
