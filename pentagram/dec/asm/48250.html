48250: Print Text Standard Font
Prints a string like PrintTextSingleColour does, but takes the colour from the first byte of the string. This is not used by the game.
Input
DE Address of the colour and the string
H Pixel y co-ordinate of the string, counting up from the bottom of the
screen
L Pixel x co-ordinate of the string
PrintTextStandardFont 48250 PUSH HL Stash the position on the stack.
48251 LD HL,33237 Point the glyph table at 33237.
48254 LD (42802),HL
48257 POP BC Fetch the position into BC.
48258 PUSH BC Stash the position on the stack again.
48259 CALL CalculateBufferAddress Call CalculateBufferAddress to get the address in the buffer.
48262 LD L,C Copy it to HL.
48263 LD H,B
48264 LD A,(DE) Fetch the colour from the string.
48265 EX AF,AF' Stash the colour in AF'.
48266 INC DE Move on to the string.
