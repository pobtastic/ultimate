50540: Handle Jump
Used by the routine at HandlePlayerLegs.
Starts a jump, if the jump key is pressed and the player is standing on the ground and was not already jumping. The jump is started by giving the player an upward speed of 8 which is cut down by gravity in MovePlayer.
Input
C Controls
IX Record of the legs
HandleJump 50540 BIT 3,C Return if the jump key is not pressed.
50542 RET Z
50543 LD A,(IX+12) Fetch the collision flags.

50549 BIT 3,(IX+12) Return if the player is already jumping.
50553 RET NZ
50554 BIT 2,(IX+12) Return if the player is not on the ground.

50563 LD (IX+11),8 Set the speed along z to 8.

50571 POP BC Restore the controls from the stack.
