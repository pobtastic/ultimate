52785: Run Bobbing Block
Used by the routine at RunHarmfulBobbingBlock.
The handler of the object type 85 which no room uses. The block falls until it lands, and then it rises until it is at a height of 176 and falls again. It rises faster while something is standing on it. Flag bit 2 of the hit flags is used for the state: it is set while the block is rising.
