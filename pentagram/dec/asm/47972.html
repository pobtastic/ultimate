47972: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Makes one of the colours of a list of colours flash, and stops the others from flashing, by setting or clearing bit 7. This is used to show the chosen line of the menu.
Input
A Number of the colour to make flash
B Number of colours
HL Address of the first colour
SetFlashingAttribute 47972 AND A Jump to SetFlashingAttribute_Steady if this is not the first colour.
47973 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash 47975 SET 7,(HL) Make the colour flash.
47977 JR SetFlashingAttribute_Loop Jump to SetFlashingAttribute_Loop.
SetFlashingAttribute_Next 47979 DEC A Jump to SetFlashingAttribute_Flash when the countdown reaches that colour.
47980 JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady 47982 RES 7,(HL) Stop the colour from flashing.
SetFlashingAttribute_Loop 47984 INC HL Move on to the next colour.
47985 DJNZ SetFlashingAttribute_Next Decrease the counter and loop until all the colours have been done.
47987 RET Return.
