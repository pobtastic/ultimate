48632: Read Controls
Used by the routine at HandlePlayerLegs.
Reads the keyboard or the joystick, according to the control method that was chosen in the menu, and writes what is wanted to ControlsPressed as a set of bits:
Bit Meaning
0 Turn left
1 Turn right
2 Walk forward
3 Jump
4 Pick up or drop an object
6 Fire
With the keyboard, any of several keys do each action. With a joystick, up walks forward, down jumps and fire fires, and a long list of the keys of the keyboard picks up or drops an object.
CAPS SHIFT and SPACE are left alone by this routine, as they pause the game (see PauseGame).
Output
C The controls, also written to ControlsPressed
Find the control method: 0 is the keyboard, 1 is a Kempston joystick, 2 is a cursor joystick and 3 is an Interface II joystick.
