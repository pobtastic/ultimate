52615: Finish Object Move
Used by the routines at RunPentagramStone, RunSinkingBlock, RunLift, RunStaticObject and RunHelper.
Finishes the handler of an object that moves only by being pushed. The speeds of the object were set by whatever pushed it, so they are cleared for the next frame. If the object has moved, it is flagged to be drawn.
Input
IX Object record
FinishObjectMove 52615 LD A,(IX+9) Fetch the speeds of the object together.
52618 OR (IX+10)
52621 OR (IX+11)
52624 RET Z Return if there are none.
52625 LD (IX+9),0 Set the speeds along x, y and z to zero.
52629 LD (IX+10),0
52633 LD (IX+11),0
52637 JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags to flag the object as moved.
