51071: Set Sprite Offset Minus 8 Minus 4
Sets the offsets of the sprite to 248 horizontally and 252 vertically. It is also the handler of the object types 53 to 56 which do nothing else.
Input
IX Object record
SetSpriteOffset_Minus8_Minus4 51071 LD HL,64760 Set the offsets in HL.
51074 JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
