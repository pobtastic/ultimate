45765: Calculate Pixel Coordinates
Used by the routines at DrawObject, CalculateSpriteSize, DropObject, CreateCreature and RunHelperSource.
Works out where the sprite of an object goes on the screen, from its position in the room. Objects are shown in an isometric view: moving along x takes the object down and to the right and moving along y takes it up and to the right, while height lifts it straight up.
The screen x co-ordinate is x + y - 128 plus the sprite offset in the object, and is set to zero if that comes out below zero. The screen y co-ordinate is (y - x + 128) / 2 + z - 104 plus the sprite offset in the object. The y co-ordinate counts up from the bottom of the screen.
Input
IX Object record
Output
F Carry flag set if the sprite is not above the top of the screen
Work out the screen x co-ordinate.
CalculatePixelCoordinates 45765 LD A,(IX+1) Add the y position of the object to its x position.
45768 ADD A,(IX+2)
45771 SUB 128 Subtract 128 to centre the room on the screen.
45773 ADD A,(IX+18) Add the horizontal sprite offset.
45776 JR C,CalculatePixelCoordinates_SetX Jump to CalculatePixelCoordinates_SetX if the result is not below zero.
45778 XOR A Otherwise use zero.
CalculatePixelCoordinates_SetX 45779 LD (IX+26),A Write the screen x co-ordinate of the object.
Work out the screen y co-ordinate.
45782 LD A,(IX+2) Subtract the x position of the object from its y position.
45785 SUB (IX+1)
45788 ADD A,128 Add 128.
45790 SRL A Halve it.
45792 ADD A,(IX+3) Add the height of the object.
45795 SUB 104 Subtract 104 to put the floor at the bottom of the screen.
45797 ADD A,(IX+19) Add the vertical sprite offset.
45800 LD (IX+27),A Write the screen y co-ordinate of the object.
45803 CP 192 Compare it with 192 the number of lines on the screen.
45805 RET Return, with the carry flag set when the sprite is on the screen.
