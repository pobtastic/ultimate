49437: Finish Explosion
The handler of the last stage of an explosion, type 71. The object is changed into the marker that makes DrawObject erase it, which frees it.
Input
IX Record of the object
FinishExplosion 49437 CALL SetSpriteOffset_Minus12_Minus4 Call SetSpriteOffset_Minus12_Minus4 to set where the sprite is drawn.
This entry point is used by the routine at ScoreForCreature.
FinishExplosion_Erase 49440 LD (IX+0),1 Change the object to the type that makes it be erased.
49444 JR RunExplosion_MarkObjectMoved Jump to RunExplosion_MarkObjectMoved to mark it to be drawn.
