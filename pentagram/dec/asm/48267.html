48267: Print Text
Used by the routine at PrintTextSingleColour.
The part of PrintTextSingleColour that prints the characters and their attributes. The alternate registers hold the address in the attribute file, and the main registers hold the address in the buffer.
PrintText 48267 EXX Switch to the alternate registers.
48268 POP HL Fetch the position from the stack.
48269 PUSH DE Stash the string pointer on the stack.
48270 CALL CalculateAttributeAddress Call CalculateAttributeAddress to get the address in the attribute file.
48273 LD L,E Copy it to HL'.
48274 LD H,D
48275 POP DE Restore the string pointer.
PrintText_Next 48276 EXX Switch to the main registers.
48277 LD A,(DE) Fetch the next character.
48278 BIT 7,A Jump to PrintText_Last if it is the last character.
48280 JR NZ,PrintText_Last
48282 PUSH DE Stash the string pointer on the stack.
48283 CALL PrintCharacter Call PrintCharacter to print the character.
48286 POP DE Restore the string pointer.
48287 INC DE Move on to the next character.

48290 LD (HL),A
48291 INC L
48292 EX AF,AF'
48293 JR PrintText_Next Jump to PrintText_Next to print the next character.

48298 CALL PrintCharacter
48301 POP DE
48302 INC DE
48303 EXX Switch to the alternate registers.

48305 LD (HL),A
