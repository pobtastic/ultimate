28119: Sprite Table
The address of the sprite of each of the 172 object types, which GetSpriteAddress and DrawObject use to draw an object. A lot of the types share a sprite. A sprite has a byte for its width in bytes in the lowest four bits (the highest four are never set), a byte for its height in pixels, and then, for each pixel row up from the bottom, and for each byte of the width across, a pair of a mask byte and a pixel byte. DrawObject clears the bits of the background where the mask has a bit set, and merges in the pixel byte.
