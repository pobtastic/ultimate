53420: Run Helper
The handler of the object type 90 which is the helper. It can be picked up by the player, like the stones, and when it is not held it goes to an object of one of the types 112 to 115 in the room, and collects it.
The helper starts by falling to the floor. If there is an object of the right type, it takes the position of that as a target, which it keeps in its record. Then it rises, to a height of 176 and goes towards the target in a straight line along x and y, as SteerTowardsTarget sets its speeds. When it gets there it flags the object, so that RunCollectableObject collects it, makes a noise and disappears in an explosion, and its entry in the object store is removed.
