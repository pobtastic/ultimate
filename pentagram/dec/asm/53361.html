53361: Point At Objects
Used by the routines at CheckSpecialObjects, RunHelperSource and RunHelper.
Sets up the registers to go through the ordinary objects, which are the ones from the seventh to the last.
Output
B Number of objects
DE Size of an object
IY Address of the first object
PointAtObjects 53361 LD DE,32 Set the size of an object.
53364 LD IY,43055 Start with the first ordinary object, ObjectsTable_RoomObjects.
53368 LD B,48 Set the number of objects, which is 48.
