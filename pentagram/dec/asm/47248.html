47248: Mark Object Below
Used by the routine at BlockMovementInZ.
Flags the object that a part of the player, or a block of type 91 has landed on, by setting bit 7 of its handler flags. Nothing is done for any other type of object.
Input
IX Object record
IY Record of the object that has been landed on
MarkObjectBelow 47248 LD A,(IX+0) Fetch the type of the object.
47251 CP 91 Jump to MarkObjectBelow_Set if it is a block of type 91.
47253 JR Z,MarkObjectBelow_Set
47255 CP 32 Compare the type with 32 the first part of the player.
47257 RET C Return if it is lower.
47258 CP 40 Compare the type with 40.
47260 RET NC Return if it is higher, which means that it is not a part of the player.
MarkObjectBelow_Set 47261 SET 7,(IY+23) Flag the object as having a player or block on it.
47265 RET Return.
