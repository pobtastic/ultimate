49319: Pick Up Object
Used by the routine at HandlePickupAndDrop.
Picks up an object, which is put in the first place of the inventory (until it is moved along to the second place), and removed from the room. The object is changed into the marker that makes DrawObject erase it. If the carried objects are all in use, the oldest one is dropped where the other one was.
Input
IY Record of the object that is being picked up
Copy the object into the first place of the inventory.
