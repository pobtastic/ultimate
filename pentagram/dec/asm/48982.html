48982: Set Wipe And Draw Flags For Object
Used by the routines at DropObject and PickUpObject.
Does what SetWipeAndDrawFlags does for the object in IY, which is to say that it has to be drawn again, and that the area where it was has to be restored.
Input
IY Record of the object
SetWipeAndDrawFlagsForObject 48982 PUSH IY Stash IY and IX on the stack.
48984 PUSH IX
48986 PUSH IY Copy IY to IX, using the stack.
48988 POP IX
48990 CALL SetWipeAndDrawFlags Call SetWipeAndDrawFlags to mark the object.
48993 POP IX Restore IX and IY from the stack.
48995 POP IY
48997 RET Return.
