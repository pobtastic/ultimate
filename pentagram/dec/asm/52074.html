52074: Fill Attributes
Used by the routines at RunGame, ShowVictoryScreen and ShowGameOverScreen.
Sets all of the attributes of the screen to a colour, and sets the byte after them.
Input
A Attribute
FillAttributes 52074 LD HL,22528 Start at the first attribute.
52077 LD DE,22529 Move on to the next attribute.
52080 LD BC,768 Set the number of bytes to copy, which is the number of attributes.
52083 LD (HL),A Set the first attribute.
52084 LDIR Copy it through the rest.
52086 RET Return.
