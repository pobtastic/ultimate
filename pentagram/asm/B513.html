B513: Clear Bytes
Used by the routines at DropObject and BuildRoomScenery.
Fills a number of bytes with zero. The entry point at ClearBytes_FillBytes fills them with the byte in A.
Input
B Number of bytes
DE Address of the first byte
ClearBytes B513 XOR A Set A to 00.
This entry point is used by the routine at DrawLives.
ClearBytes_FillBytes B514 LD (DE),A Write A.
B515 INC DE Increment DE.
B516 DJNZ ClearBytes_FillBytes Decrease the counter and loop until all the bytes have been written.
B518 RET Return.
