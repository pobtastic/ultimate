B513: Clear Bytes
Used by the routines at DropObject and BuildRoomScenery.
Writes a value to a number of bytes. The entry point at ClearBytes_FillBytes writes the value in A instead of zero.
Input
B Number of bytes
DE Address of the first byte
ClearBytes B513 XOR A Set the value to write to 00.
This entry point is used by the routine at DrawLives.
ClearBytes_FillBytes B514 LD (DE),A Write the value to the next byte.
B515 INC DE Move on to the next byte.
B516 DJNZ ClearBytes_FillBytes Decrease the counter and loop until all the bytes have been written.
B518 RET Return.
