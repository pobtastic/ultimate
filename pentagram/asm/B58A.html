B58A: Draw Objects In Order
Used by the routine at DrawChangedObjects.
Draws every object in the draw list at DrawList, back to front, so that the nearer objects are drawn over the further ones.
The routine looks at the objects in the list in turn, and draws the first one that no other undrawn object has to be drawn before. To decide that, it compares the object that it is considering (held in IX) with each of the other undrawn objects (held in IY) along the three axes. Each axis gives a code of 0, 1 or 2: 1 when the two overlap on that axis, and 0 or 2 when they are apart. For x and for the height, 0 means that the object considered is in front of the other and 2 that it is behind it; for y it is the other way round. The three codes make up a number from 0 to 26 (the code for x is multiplied by 9, and for y by 3), which selects a routine from the table at SortJumpTable.
When the object considered is in front of the other one, and so must be drawn after it, the other one becomes the object that is considered instead and the search starts again from the beginning of the list. A list of the objects that have been looked at in this way, at ObjectsTriedList, stops this from going on forever if there is a loop of objects that each have to be drawn after another: in that case the object that closed the loop is drawn.
Each time an object is drawn, bit 7 of its entry in the list is set, and the sort starts again at the beginning of the list.
Start with no objects drawn.
