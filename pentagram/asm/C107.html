C107: Start Explosion
Used by the routines at RunProjectile, HandlePlayerLegs, HandlePlayerTop and RunHelper.
Turns an object into the first stage of an explosion, which is a type that has its own animation in RunExplosion. This is used for the player and for the projectiles.
Input
IX Record of the object
StartExplosion C107 LD (IX+$00),$40 Change the object to the type of the first stage of an explosion.
C10B SET 1,(IX+$07) Flag the object as being moved, so that nothing can push it.
C10F JR RunExplosion_MarkObjectMoved Jump to RunExplosion_MarkObjectMoved to mark it to be drawn.
