BF0D: Reset Wipe Flags
Used by the routine at RunGame.
Clears the flag in all of the object records that says that an object has moved and that the area where it was has to be restored. This is done once the room has been drawn in full, as that makes the flag out of date.
ResetWipeFlags BF0D LD B,$36 Set a counter in B of the number of object records, 36.
BF0F LD DE,$0020 Set the size of an object record in DE.
BF12 LD HL,$A776 Start at the flags of the first record of ObjectsTable.
ResetWipeFlags_Loop BF15 RES 5,(HL) Clear bit 5 of the flags, to say that the object has not moved.
BF17 ADD HL,DE Move on to the flags of the next object.
BF18 DJNZ ResetWipeFlags_Loop Decrease the counter and loop until all the records have been done.
BF1A RET Return.
