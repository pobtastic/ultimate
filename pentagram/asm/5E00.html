5E00: Game Entry Point
The entry point of the game, called by the loader once the code has been loaded.
GameEntry 5E00 DI Disable interrupts.
5E01 LD SP,$5E00 Set the stack pointer to GameEntry, so the stack grows downwards from the start of the game code.
5E04 JP RunGame Jump to RunGame.
