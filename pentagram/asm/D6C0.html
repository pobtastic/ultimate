D6C0: Play Note
Used by the routines at PlayMusicOnce and PlayMusic.
Plays a note of a tune, or lets the time of a rest go by. The note is a byte in which the lowest six bits are the number of the note, with a rest if it is zero, and the highest two bits are one less than the length of the note, which is that number of times the length of the shortest note. The pitch and the number of cycles of the note come from the table at NoteTable. A note is made of the same number of cycles for each of its lengths, so that the notes are all as long, whatever their pitch.
Input
A Note
DE Address of the note in the tune
Output
DE Address of the next note
PlayNote D6C0 AND %00111111 Keep the number of the note.
D6C2 JR Z,PlayNote_Rest Jump to PlayNote_Rest if it is a rest.
Look up the delays and the number of cycles in the table at NoteTable.
D6C4 LD L,A Put the number in HL.
D6C5 LD H,$00
D6C7 ADD HL,HL Double it.
D6C8 CALL AddAToHL Call AddAToHL to add the number, to make three times it.
D6CB LD BC,$D718 Find the note in the table at NoteTable.
D6CE ADD HL,BC Add it to find the entry of the note.
D6CF LD B,(HL) Fetch the count for the first run of the delay loop for half a cycle.
D6D0 INC HL Move on.
D6D1 LD C,(HL) Fetch the number of times that the delay loop is run on from there.
D6D2 INC HL Move on.
D6D3 LD L,(HL) Fetch the number of cycles for a note of the shortest length.
D6D4 LD H,$00 Clear the high byte.
Bits 6 and 7 of the note are the length, less one.
D6D6 LD A,(DE) Fetch the note again.
D6D7 RLCA Move the highest two bits to the lowest.
D6D8 RLCA
D6D9 AND %00000011 Keep them.
D6DB INC A Add one to get the length of the note.
D6DC PUSH DE Save the address in the tune.
D6DD LD E,L Copy the number of cycles to DE.
D6DE LD D,H
Multiply the number of cycles by the length of the note.
PlayNote_Multiply D6DF DEC A Take one off the length.
D6E0 JR Z,PlayNote_Start Jump to PlayNote_Start if it is the last.
D6E2 ADD HL,DE Add the number of cycles for the shortest note.
D6E3 JR PlayNote_Multiply Jump back to PlayNote_Multiply.
PlayNote_Start D6E5 POP DE Get the address in the tune back.
Each pass of this loop makes one cycle of the note, so the length of the note is the number of cycles.
PlayNote_Cycle D6E6 PUSH BC Save the half length of a cycle.
D6E7 XOR A Set the speaker to off.
D6E8 OUT ($FE),A Write it to the ULA.
PlayNote_LowWait D6EA DJNZ PlayNote_LowWait Wait while the speaker is off.
D6EC DEC C Count a loop of the high byte.
D6ED JR NZ,PlayNote_LowWait Jump back to PlayNote_LowWait until the half cycle is over.
D6EF POP BC Get the half length back.
D6F0 PUSH BC Save it again.
D6F1 LD A,$10 Set bit 4 to turn the speaker on.
D6F3 OUT ($FE),A Write it to the ULA.
PlayNote_HighWait D6F5 DJNZ PlayNote_HighWait Wait while the speaker is on.
D6F7 DEC C Count a loop of the high byte.
D6F8 JR NZ,PlayNote_HighWait Jump back to PlayNote_HighWait until the half cycle is over.
D6FA POP BC Get the half length back.
D6FB DEC HL Count the cycle.
D6FC LD A,H Test whether there are any left.
D6FD OR L
D6FE JR NZ,PlayNote_Cycle Jump back to PlayNote_Cycle until all of the cycles have been made.
D700 INC DE Move on to the next note of the tune.
D701 RET Return.
A rest is a silent pause, which is made by waiting one to four times.
PlayNote_Rest D702 LD A,(DE) Fetch the rest.
D703 INC DE Move on to the next note of the tune.
D704 RLCA Move the highest two bits to the lowest.
D705 RLCA
D706 AND %00000011 Keep them.
D708 INC A Add one to get the length of the rest.
D709 LD L,A Put it in L.
D70A LD BC,$430B Set the count of the delay.
PlayNote_RestOuter D70D PUSH BC Save it.
PlayNote_RestWait D70E DEC BC Count down.
D70F LD A,B Test whether it is zero.
D710 OR C
D711 JR NZ,PlayNote_RestWait Jump back to PlayNote_RestWait until the delay is over.
D713 POP BC Get the count back.
D714 DEC L Take one off the length.
D715 JR NZ,PlayNote_RestOuter Jump back to PlayNote_RestOuter until the rest is over.
D717 RET Return.
