B963: Stop Object At Floor
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along z until it stays above the floor of the room, whose height is in FloorHeight. Sets the flag in the collision flags that says the object is on the ground if it had to.
Input
H Distance to move along z
IX Object record
Output
H Distance that can be moved
StopObjectAtFloor B963 LD A,($A71F) Fetch the height of the floor in D.
B966 LD D,A
StopObjectAtFloor_Test B967 LD A,(IX+$03) Work out the height of the bottom of the object, once it has moved.
B96A ADD A,H
B96B CP D Return if it is not below the floor.
B96C RET NC
B96D SET 2,(IX+$0C) Flag that the object has been stopped along z, which is on the ground.
B971 LD A,H Fetch the distance to move.
B972 CALL BringSpeedCloserToZero Call BringSpeedCloserToZero to step it one closer to zero.
B975 LD H,A Set the distance.
B976 JR NZ,StopObjectAtFloor_Test Jump to StopObjectAtFloor_Test to test again, unless the distance is zero.
B978 RET Return.
