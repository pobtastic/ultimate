C323: Show Game Over Screen
Used by the routine at LoseLife.
Shows the screen for the end of the game, with the percentage of the quest that has been done. Once the tune has played and there has been a pause, the game starts again from the menu.
The game over screen
Show the game over screen.

C328 CALL FillAttributes Call FillAttributes to set all the attributes to it.
C32B CALL PrintBorder Call PrintBorder to draw the frame.
C32E LD DE,$C35D Take the colours of the lines, GameOverColours.
C331 EXX Switch to the shadow registers.

C335 LD DE,$C366 Take the text of the lines, GameOverText.
C338 LD B,$03 Set a counter in BC' of three lines.

Play the game over tune.

Wait for a time.
C34D LD B,$40 Set a counter in B of 40 loops.
ShowGameOverScreen_Wait C34F LD HL,$2000 Set a counter in HL of 2000.
ShowGameOverScreen_Count C352 DEC HL Decrease the counter.
C353 LD A,H Fetch the high byte of it.
C354 OR L Combine it with the low byte.
C355 JR NZ,ShowGameOverScreen_Count Jump to ShowGameOverScreen_Count until the delay has run out.
C357 DJNZ ShowGameOverScreen_Wait Repeat the delay for each of the remaining passes.
Throw away the return address, and start again.

C35A JP RunGame_Restart Jump to RunGame_Restart to start the game again.
