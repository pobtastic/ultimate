C74B: Set Sprite Offset Minus 8 0
Sets how far the sprite of an object is moved from the position on the screen that is worked out for it by CalculatePixelCoordinates, which is 08 to the left and none up. The same is done by each of the routines up to SetSpriteOffset_Minus8_Minus2, which differ in the distances. It is also the handler of the object type 39, which does nothing else.
Input
IX Object record
SetSpriteOffset_Minus8_0 C74B LD HL,$00F8 Set the offsets in HL, which are F8 horizontally and 00 vertically.
C74E JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
