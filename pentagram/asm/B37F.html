B37F: Calculate Buffer Address
Used by the routines at CopyScoreToScreen, DrawChangedObjects, DrawObject, DisplayObjectsCarried, DrawScore, PrintTextSingleColour, PrintTextStandardFont and PrintQuestPercentage.
Finds the address in the buffer of the byte that holds a pixel. The buffer is 20 bytes wide with its bottom line first, so the address is D88F + y * 20 + x / 08.
Input
B Pixel y co-ordinate, counting up from the bottom of the screen
C Pixel x co-ordinate
Output
BC Address in the buffer
CalculateBufferAddress B37F PUSH HL Stash HL on the stack.
B380 SRL B Divide the pixel co-ordinates by eight.
