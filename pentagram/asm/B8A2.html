B8A2: Test Overlap In X
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along x, once the first one has moved by a distance. The objects overlap if the distance between their centres is less than the sum of their half sizes.
Input
C Distance that the first object moves along x
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInX B8A2 LD A,(IX+$04) Add the half sizes of the objects along x together, in D.
B8A5 ADD A,(IY+$04)
B8A8 LD D,A
B8A9 LD A,(IX+$01) Work out the distance between the centres, once the first has moved.
B8AC ADD A,C
B8AD SUB (IY+$01)
B8B0 JP P,TestOverlapInX_Compare Jump to TestOverlapInX_Compare if the distance is positive.
B8B3 NEG Make the distance positive.
TestOverlapInX_Compare B8B5 SUB D Subtract the sum of the half sizes, which sets the carry flag if they overlap.
B8B6 RET Return.
