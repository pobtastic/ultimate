BB48: Print BCD Number
Used by the routines at DrawLives and PrintQuestPercentage.
Draws the digits of binary coded decimal bytes, two to a byte, into the buffer, using the digit glyphs at the start of the font.
Input
B Number of bytes
DE Address of the number
HL Address in the screen buffer
Point at the digit font.

BB49 LD HL,$8355 Set FontPointer to Font.
BB4C LD ($A732),HL
BB4F POP HL Restore the screen buffer address from the stack.
