D071: Point At Objects
Used by the routines at CheckSpecialObjects, RunHelperSource and RunHelper.
Sets up the registers to go through the ordinary objects, which are the ones from the seventh to the last.
Output
B Number of objects
DE Size of an object
IY Address of the first object
PointAtObjects D071 LD DE,$0020 Set the size of an object.
D074 LD IY,$A82F Start with the first ordinary object, ObjectsTable_RoomObjects.
D078 LD B,$30 Set the number of objects, which is 30.
D07A RET Return.
