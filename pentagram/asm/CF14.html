CF14: Run Static Object
The handler of the object types 79 to 87, which include the eight parts of the pentagram. They do not move, unless they can be pushed and something pushes them.
Input
IX Object record
RunStaticObject CF14 CALL SetSpriteOffset_Minus16_Minus8 Call SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
CF17 CALL ApplyGravityAndMove_Move Call ApplyGravityAndMove_Move to move the object, without gravity.
CF1A BIT 2,(IX+$07) Return if the object cannot be pushed.
CF1E RET Z
CF1F JP FinishObjectMove Jump to FinishObjectMove to finish.
