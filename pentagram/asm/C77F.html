C77F: Set Sprite Offset Minus 8 Minus 4
Sets the offsets of the sprite to F8 horizontally and FC vertically. It is also the handler of the object types 35 to 38 which do nothing else.
Input
IX Object record
SetSpriteOffset_Minus8_Minus4 C77F LD HL,$FCF8 Set the offsets in HL.
C782 JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
