CD0D: Speed Up Backwards
Used by the routine at RunHomingCreature.
Takes three off a stored speed of a creature, down to a limit of B8 (which is four and a half in sixteenths, backwards).
Input
A Stored speed
Output
A New stored speed
SpeedUpBackwards CD0D SUB $03 Take three off the speed.
CD0F RET P Return if it is positive.
CD10 CP $B8 Return if it is not less than the limit.
CD12 RET NC
CD13 LD A,$B8 Set the speed to the limit.
CD15 RET Return.
