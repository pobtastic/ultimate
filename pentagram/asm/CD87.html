CD87: Finish Object Move
Used by the routines at RunPentagramStone, RunSinkingBlock, RunLift, RunStaticObject and RunHelper.
Finishes the handler of an object that moves only by being pushed. The speeds of the object were set by whatever pushed it, so they are cleared for the next frame. If the object has moved, it is flagged to be drawn.
Input
IX Object record
FinishObjectMove CD87 LD A,(IX+$09) Fetch the speeds of the object together.
CD8A OR (IX+$0A)
CD8D OR (IX+$0B)
CD90 RET Z Return if there are none.
CD91 LD (IX+$09),$00 Set the speeds along x, y and z to zero.
CD95 LD (IX+$0A),$00
CD99 LD (IX+$0B),$00
CD9D JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags to flag the object as moved.
