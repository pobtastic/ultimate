B8CC: Test Overlap In Z
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along z, once the first one has moved by a distance. The z position of an object is its bottom, so the distance between the bottoms is compared with the height of the object that is the lower of the two.
Input
H Distance that the first object moves along z
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInZ B8CC LD A,(IX+$03) Work out the distance between the bottoms of the objects, once the first has moved.
B8CF ADD A,H
B8D0 SUB (IY+$03)
B8D3 JP P,TestOverlapInZ_SecondLower Jump to TestOverlapInZ_SecondLower if the first object is the higher.
B8D6 NEG Make the distance positive.
B8D8 LD D,(IX+$06) Fetch the height of the first object, which is the lower.
TestOverlapInZ_Compare B8DB SUB D Subtract the height of the lower object, which sets the carry flag if they overlap.
B8DC RET Return.
TestOverlapInZ_SecondLower B8DD LD D,(IY+$06) Fetch the height of the second object, which is the lower.
B8E0 JR TestOverlapInZ_Compare Jump to TestOverlapInZ_Compare.
