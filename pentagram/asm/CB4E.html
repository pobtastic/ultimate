CB4E: Run Scenery
The handler of the object types 0A 0B 4C 52 and 98 to 9F which are scenery that only has to be placed on the screen.
Input
IX Object record
RunScenery CB4E JP SetSpriteOffset_Minus16_Minus8 Jump to SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
