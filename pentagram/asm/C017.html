C017: Drop Object
Used by the routine at HandlePickupAndDrop.
Drops the oldest carried object into the free object record in IY, at the position of the player. If there is no object in the oldest place in the inventory, the carried objects are only moved along. The player rises by 0C to be out of the way of the object that is dropped.
Input
IX Record of the object of the legs of the player
IY Free object record
