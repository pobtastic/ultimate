B890: Mark Object Below
Used by the routine at BlockMovementInZ.
Flags the object that a part of the player, or a block of type 5B has landed on, by setting bit 7 of its handler flags. Nothing is done for any other type of object.
Input
IX Object record
IY Record of the object that has been landed on
MarkObjectBelow B890 LD A,(IX+$00) Fetch the type of the object.
B893 CP $5B Jump to MarkObjectBelow_Set if it is a block of type 5B.
B895 JR Z,MarkObjectBelow_Set
B897 CP $20 Compare the type with 20 the first part of the player.
B899 RET C Return if it is lower.
B89A CP $28 Compare the type with 28.
B89C RET NC Return if it is higher, which means that it is not a part of the player.
MarkObjectBelow_Set B89D SET 7,(IY+$17) Flag the object as having a player or block on it.
B8A1 RET Return.
