C66A: Set Player Speed
Used by the routine at MovePlayer.
Gives the player a speed of three along the direction that it faces, after adding any speed that something else has pushed it with, which comes from the two bytes of the object that hold the push. The last three instructions are also used by NudgeObjectsToArch, with a different table, to find the routine for the direction.
Input
IX Record of the legs
SetPlayerSpeed C66A LD A,(IX+$09) Add the push along x to the speed along x.
C66D ADD A,(IX+$0E)
C670 LD (IX+$09),A
C673 LD A,(IX+$0A) Add the push along y to the speed along y.
C676 ADD A,(IX+$0F)
C679 LD (IX+$0A),A
C67C XOR A Clear the pushes along x and y.
C67D LD (IX+$0E),A
C680 LD (IX+$0F),A
C683 LD BC,$C68D Take the table of the four routines that add the speed, WalkingRoutines.
This entry point is used by the routine at NudgeObjectsToArch.
SetPlayerSpeed_JumpByFacing C686 CALL GetFacingDirection Call GetFacingDirection to find out which way the player is facing.
C689 LD L,A Use the direction as the index into the table.
C68A JP RunGame_JumpViaTable Jump to RunGame_JumpViaTable to run the routine for the direction.
