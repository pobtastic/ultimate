CD7C: Run Table
The handler of the object type 49 which is an object that falls and can be pushed, in the same way as RunFallingObject.
Input
IX Object record
RunTable CD7C CALL SetSpriteOffset_Minus16_Minus12 Call SetSpriteOffset_Minus16_Minus12 to set the offsets of the sprite.
CD7F JR RunFallingObject_MoveFallingObject Jump to RunFallingObject_MoveFallingObject to move it.
