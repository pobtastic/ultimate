D2E9: Run Conveyor Block Minus X
The handler of the object type 8D which is a block that pushes whatever stands on it back along x, in the same way as RunConveyorBlockPlusX.
Input
IX Object record
RunConveyorBlockMinusX D2E9 CALL SetSpriteOffset_Minus16_Minus8 Call SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
D2EC RES 3,(IX+$0D) Clear the flag for something being on the block.
D2F0 CALL ApplyGravityAndMove_Move Call ApplyGravityAndMove_Move to move the block, without gravity.
D2F3 RET Return.
