BB64: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Makes one of the colours of a list of colours flash, and stops the others from flashing, by setting or clearing bit 7. This is used to show the chosen line of the menu.
Input
A Number of the colour to make flash
B Number of colours
HL Address of the first colour
SetFlashingAttribute BB64 AND A Jump to SetFlashingAttribute_Steady if this is not the first colour.
BB65 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash BB67 SET 7,(HL) Make the colour flash.
BB69 JR SetFlashingAttribute_Loop Jump to SetFlashingAttribute_Loop.
SetFlashingAttribute_Next BB6B DEC A Jump to SetFlashingAttribute_Flash when the countdown reaches that colour.
BB6C JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady BB6E RES 7,(HL) Stop the colour from flashing.
SetFlashingAttribute_Loop BB70 INC HL Move on to the next colour.
BB71 DJNZ SetFlashingAttribute_Next Decrease the counter and loop until all the colours have been done.
BB73 RET Return.
