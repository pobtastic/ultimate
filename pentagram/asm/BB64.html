BB64: Set Flashing Attribute
Used by the routine at FlashMenuOptions.
Sets bit 7 of the attribute of one line of text in a list of lines, and resets it for the other lines.
Input
A The number of the line
B Number of lines
HL Address of the attributes
Flash one line and steady the rest.
SetFlashingAttribute BB64 AND A Jump to SetFlashingAttribute_Steady if the line is not the first.
BB65 JR NZ,SetFlashingAttribute_Steady
SetFlashingAttribute_Flash BB67 SET 7,(HL) Set bit 7 of the attribute.
BB69 JR SetFlashingAttribute_Loop Jump to SetFlashingAttribute_Loop.
SetFlashingAttribute_Next BB6B DEC A Jump to SetFlashingAttribute_Flash if this is the line.
BB6C JR Z,SetFlashingAttribute_Flash
SetFlashingAttribute_Steady BB6E RES 7,(HL) Reset bit 7 of the attribute.
SetFlashingAttribute_Loop BB70 INC HL Move on to the next line.
BB71 DJNZ SetFlashingAttribute_Next Jump to SetFlashingAttribute_Next until all of the lines have been done.
BB73 RET Return.
