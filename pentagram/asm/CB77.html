CB77: Fill Memory
Used by the routines at RunGame, ClearObjects and ClearScreenBuffer.
Clears a number of bytes of memory.
Input
BC Number of bytes
HL Address of the first byte
FillMemory CB77 LD E,$00 Set the value to write to 00.
FillMemory_WithValue CB79 LD (HL),E Write the value to the next byte.
CB7A INC HL Move on to the next byte.
CB7B DEC BC Decrease the counter.
CB7C LD A,B Jump to FillMemory_WithValue until all the bytes have been written.
CB7D OR C
CB7E JR NZ,FillMemory_WithValue
CB80 RET Return.
