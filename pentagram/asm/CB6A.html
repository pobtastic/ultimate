CB6A: Fill Attributes
Used by the routines at RunGame, ShowVictoryScreen and ShowGameOverScreen.
Sets all of the attributes of the screen to a colour, and sets the byte after them.
Input
A Attribute
FillAttributes CB6A LD HL,$5800 Start at the first attribute.
CB6D LD DE,$5801 Move on to the next attribute.
CB70 LD BC,$0300 Set the number of bytes to copy, which is the number of attributes.
CB73 LD (HL),A Set the first attribute.
CB74 LDIR Copy it through the rest.
CB76 RET Return.
