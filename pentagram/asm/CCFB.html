CCFB: Reverse Speed Z
Never used. It would reverse the stored speed of a creature along z.
Input
IX Object record
ReverseSpeedZ CCFB LD A,(IX+$16) Fetch the stored speed along z.
CCFE NEG Reverse it.
CD00 LD (IX+$16),A Store it.
CD03 RET Return.
