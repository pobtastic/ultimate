D07B: Point At Store
Used by the routines at ChangeObjectType, RunHelper and CheckObjectsCollected.
Sets up the registers to go through the entries of the object store.
Output
B Number of entries
DE Size of an entry
IY Address of the first entry
PointAtStore D07B LD DE,$0010 Set the size of an entry.
D07E LD IY,$D432 Start with the first entry, ObjectStore.
D082 LD B,$12 Set the number of entries, which is 12.
D084 RET Return.
