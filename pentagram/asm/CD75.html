CD75: Run Block
The handler of the object type 5B, which is a block that falls but cannot be pushed along x or y. It is also treated like the player when it lands on something, see MarkObjectBelow. It carries on as RunTable.
Input
IX Object record
RunBlock CD75 XOR A Set the speeds along x and y to zero.
CD76 LD (IX+$09),A
CD79 LD (IX+$0A),A
Continue on to RunTable.
