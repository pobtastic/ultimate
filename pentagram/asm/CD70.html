CD70: Run Harmful Falling Object
The handler of the object type 1C which is an object that harms the player and falls, carries on as RunFallingObject.
Input
IX Object record
RunHarmfulFallingObject CD70 CALL SetDeadlyFlags Call SetDeadlyFlags to make the object harm the player.
CD73 JR RunFallingObject Jump to RunFallingObject to move it.
