BC66: Print Text Single Colour
Used by the routines at PrintScoreLabel and DisplayMenu.
Prints a line of text in the colour held in TextAttribute, using the ASCII font at Font. The last character of the text has bit 7 set. Each character cell has its attribute set as well.
Input
DE Address of the text
H Pixel y position
L Pixel x position
Output
DE Address after the text
Point at the ASCII font and keep TextAttribute.
PrintTextSingleColour BC66 PUSH HL Stash the pixel position on the stack.
BC67 LD HL,$81D5 Point HL at 81D5.
BC6A LD ($A732),HL Set FontPointer.
BC6D POP BC Copy the pixel position to BC (using the stack).
BC6E PUSH BC
BC6F CALL CalculateBufferAddress Call CalculateBufferAddress.
BC72 LD L,C Copy it to HL.
BC73 LD H,B
BC74 LD A,($A736) Fetch TextAttribute.
BC77 EX AF,AF' Keep the colour in AF'.
BC78 JR PrintText Jump to PrintText.
