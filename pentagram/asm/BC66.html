BC66: Print Text Single Colour
Used by the routines at PrintScoreLabel and DisplayMenu.
Prints a string to the buffer and sets the attributes of its characters to the text colour in TextAttribute. The last character of the string has bit 7 set. The font used is the one at 8355 whose first character is code 30 and which is shifted so that the address of the glyph for a code is found by adding the code times eight to 81D5. The attributes are written straight to the screen.
Input
DE Address of the string
H Pixel y co-ordinate of the string, counting up from the bottom of the
screen
L Pixel x co-ordinate of the string
Output
DE Address after the string

BC6A LD ($A732),HL

BC6E PUSH BC Stash the position on the stack again.
BC6F CALL CalculateBufferAddress Call CalculateBufferAddress to get the address in the buffer.
BC72 LD L,C Copy it to HL.
BC73 LD H,B
BC74 LD A,($A736) Fetch the text colour.
BC77 EX AF,AF' Stash the colour in AF'.
BC78 JR PrintText Jump to PrintText to print the string.
