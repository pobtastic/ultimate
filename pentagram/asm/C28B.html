C28B: Run Dangerous Marked
Makes an object harm the player, and marks it to be drawn.
Input
IX Record of the object
RunDangerousMarked C28B CALL SetDeadlyFlags Call SetDeadlyFlags to make the object harm the player.
C28E JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags to mark the object to be drawn.
