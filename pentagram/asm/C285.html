C285: Run Dangerous Fixed
The handler of the object types 17, 1E, 4A and 4B, which are objects that harm the player but do not move. The sprite is drawn without a change.
Input
IX Record of the object
RunDangerousFixed C285 CALL SetDeadlyFlags Call SetDeadlyFlags to make the object harm the player.
C288 JP SetSpriteOffset_Minus16_Minus8 Jump to SetSpriteOffset_Minus16_Minus8 to set where the sprite is drawn.
