B394: Calculate Screen Address
Used by the routines at CopyScoreToScreen, DrawChangedObjects and DisplayObjectsCarried.
Finds the address in the display file of the byte that holds a pixel. The pixel y position counts up from the bottom of the screen, so the first step is to invert it. A y position of C0 or more is above the top of the screen, and gives an address below 4000.
Input
B The pixel y position
C The pixel x position
Output
DE The address on the screen
Work out the byte from the position.

B396 RRCA
B397 RRCA
B398 AND %00011111 Keep only the five bits of the column.
B39A LD E,A Set E to the column.
Find the line within the character square.
