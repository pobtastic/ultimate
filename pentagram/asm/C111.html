C111: Run Explosion
The handler of the object types 40 to 46, which are the stages of an explosion. Each time it is run the object moves on to the next type, which has the next sprite.
Input
IX Record of the object
RunExplosion C111 CALL SetSpriteOffset_Minus12_Minus4 Call SetSpriteOffset_Minus12_Minus4 to set where the sprite is drawn.
C114 CALL PlayExplosionSound Call PlayExplosionSound to make a noise.
C117 INC (IX+$00) Move on to the next type.
This entry point is used by the routines at StartExplosion and FinishExplosion.
RunExplosion_MarkObjectMoved C11A JP SetWipeAndDrawFlags Jump to SetWipeAndDrawFlags to mark the object to be drawn.
