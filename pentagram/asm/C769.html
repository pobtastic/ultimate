C769: Set Sprite Offset Minus 16 Minus 12
Used by the routines at RunRaisedScenery and RunTable.
Sets the offsets of the sprite to F0 horizontally and F4 vertically.
Input
IX Object record
SetSpriteOffset_Minus16_Minus12 C769 LD HL,$F4F0 Set the offsets in HL.
C76C JR StorePixelAdjustments Jump to StorePixelAdjustments to set them.
