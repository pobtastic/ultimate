D2F4: Run Conveyor Block Plus Y
The handler of the object type 8E, which is a block that pushes whatever stands on it along y, in the same way as RunConveyorBlockPlusX.
Input
IX Object record
RunConveyorBlockPlusY D2F4 CALL SetSpriteOffset_Minus16_Minus8 Call SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
D2F7 RES 3,(IX+$0D) Clear the flag for something being on the block.
D2FB CALL ApplyGravityAndMove_Move Call ApplyGravityAndMove_Move to move the block, without gravity.
D2FE RET Return.
