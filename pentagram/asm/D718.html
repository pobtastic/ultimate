D718: Note Table
The entries for the notes, which PlayNote uses, of three bytes each, for the notes 00 to 3C. For each note, the first byte is the count for the first run of the delay loop that makes half a cycle, and the second byte is the number of times that it is run on from there, in runs of 0100 and the third is the number of cycles that a note of the shortest length is played for. The entry for the note 00 is not used, as that is a rest.
