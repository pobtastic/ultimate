A76F: Object Table
The 36 object records of the game, each 20 bytes long. A record whose type byte is 00 is free. The first two records hold the two halves of the player (see ObjectsTable and A78F); the rest hold the scenery, creatures and items of the current room, which BuildRoomScenery fills from the last record downwards. The fields of a record are:
Offset Contents
00 Object type; indexes the sprite table at SpriteTable and the handler table at ObjectHandlerTable
01 Position on the x axis (the centre of the object)
02 Position on the y axis (the centre of the object)
03 Height above the floor (the bottom of the object)
04 Half the size on the x axis
05 Half the size on the y axis
06 Size on the z axis
07 Flags, see below
08 Room the object belongs to (or the room a door leads to)
09 Speed on the x axis
0A Speed on the y axis
0B Speed on the z axis
0C Collision flags: bit 00 is set when the object hit something on the x axis, bit 01 on the y axis and bit 02 on the z axis (it is on the ground); bit 03 is set while it is jumping; the upper four bits count down the frames after entering a room
0D Collision state flags used by the handlers
0E Push from other objects on the x axis
0F Push from other objects on the y axis
10 Low byte of the address of the entry in the object store at ObjectStore, or handler workspace
11 High byte of the address of the entry in the object store
12 Offset on the x axis from the projected position to the sprite
13 Offset on the y axis from the projected position to the sprite
14 to 16 Handler workspace
17 Handler flags
18 Width in bytes of the sprite last drawn
19 Height of the sprite last drawn
1A Screen x position of the sprite last drawn
1B Screen y position of the sprite last drawn, counted from the bottom of the screen
1C to 1F Copy of 18 to 1B from the previous frame
The flags in byte 07 are:
Bit Meaning
00 Ignore the walls of the room
01 The object is being moved, so it is ignored by the collision tests
02 The object can be pushed
03 The object can open doors (the player)
04 The object needs drawing
05 The object has moved and its old area needs restoring
06 Mirror the sprite from left to right
07 Flip the sprite upside down
