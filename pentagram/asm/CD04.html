CD04: Speed Up Forwards
Used by the routine at RunHomingCreature.
Adds three to a stored speed of a creature, up to a limit of 38 (which is three and a half in sixteenths).
Input
A Stored speed
Output
A New stored speed
SpeedUpForwards CD04 ADD A,$03 Add three to the speed.
CD06 RET M Return if it is negative.
CD07 CP $38 Return if it is less than the limit.
CD09 RET C
CD0A LD A,$38 Set the speed to the limit.
CD0C RET Return.
