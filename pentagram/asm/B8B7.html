B8B7: Test Overlap In Y
Used by the routines at BlockMovementInX, BlockMovementInY, BlockMovementInZ, TestObjectIntersections and TestObjectCanBePickedUp.
Tests if two objects overlap along y, once the first one has moved by a distance, in the same way as TestOverlapInX does for x.
Input
L Distance that the first object moves along y
IX Record of the first object
IY Record of the second object
Output
F Carry flag set if the objects overlap
TestOverlapInY B8B7 LD A,(IX+$05) Add the half sizes of the objects along y together, in D.
B8BA ADD A,(IY+$05)
B8BD LD D,A
B8BE LD A,(IX+$02) Work out the distance between the centres, once the first has moved.
B8C1 ADD A,L
B8C2 SUB (IY+$02)
B8C5 JP P,TestOverlapInY_Compare Jump to TestOverlapInY_Compare if the distance is positive.
B8C8 NEG Make the distance positive.
TestOverlapInY_Compare B8CA SUB D Subtract the sum of the half sizes, which sets the carry flag if they overlap.
B8CB RET Return.
