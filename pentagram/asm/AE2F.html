AE2F: Object Handler Table
One address for each of the AC object types: the routine that RunGame calls for every object of that type once a frame, with IX pointing at the object record. Each handler ends by returning to RunGame_ObjectDone. The types are also the index into the table of sprites at SpriteTable.
