CD81: Run Falling Object
Used by the routine at RunHarmfulFallingObject.
The handler of the object types 3F, 48 and 4F, which are objects that fall and can be pushed by the player or by the objects that move.
Input
IX Object record
RunFallingObject CD81 CALL SetSpriteOffset_Minus16_Minus8 Call SetSpriteOffset_Minus16_Minus8 to set the offsets of the sprite.
This entry point is used by the routines at RunPentagramStone and RunTable.
RunFallingObject_MoveFallingObject CD84 CALL ApplyGravityAndMove Call ApplyGravityAndMove to apply gravity to the object and move it.
