BDF8: Read Controls
Used by the routine at HandlePlayerLegs.
Reads the keyboard or the joystick, according to the control method that was chosen in the menu, and writes what is wanted to ControlsPressed as a set of bits:
Bit Meaning
00 Turn left
01 Turn right
02 Walk forward
03 Jump
04 Pick up or drop an object
06 Fire
With the keyboard, any of several keys do each action. With a joystick, up walks forward, down jumps and fire fires, and a long list of the keys of the keyboard picks up or drops an object.
CAPS SHIFT and SPACE are left alone by this routine, as they pause the game (see PauseGame).
Output
C The controls, also written to ControlsPressed
Find the control method: 00 is the keyboard, 01 is a Kempston joystick, 02 is a cursor joystick and 03 is an Interface II joystick.
ReadControls BDF8 LD A,($A709) Fetch the control method.
BDFB RRCA Shift the method down to bits 0 and 1...
BDFC AND %00000011 ...and keep only those bits.
BDFE JP Z,ReadControls_Keyboard Jump to ReadControls_Keyboard to read the keyboard if the method is 00.
BE01 DEC A Jump to ReadControls_Kempston to read a Kempston joystick if the method is 01.
BE02 JR Z,ReadControls_Kempston
BE04 DEC A Jump to ReadControls_Cursor to read a cursor joystick if the method is 02.
BE05 JR Z,ReadControls_Cursor
Read an Interface II joystick, which can be either of the two ports of the interface: they are the keys 1 to 5 (left, right, down, up, fire) and the keys 6, 7, 8, 9 and 0 (left, right, down, up, fire).

BE10 RL C

Read the keyboard. The keys that turn left are Z, C, M and B and those that turn right are X, V, SYMBOL SHIFT and N.
ReadControls_Keyboard BE91 LD A,$FE Read from the keyboard, with a call to ReadKeyboardPort that returns the pressed keys as set bits;
Port Number Bit
0 1 2 3 4
FE CAPS SHIFT Z X C V
BE93 CALL ReadKeyboardPort
BE96 RRCA Shift the keys down by one, which drops CAPS SHIFT and leaves Z and C for turning left, and X and V for turning right.
BE97 LD C,A Stash them in C.
BE98 AND %00000011 Keep the keys Z and X.
BE9A SRL C Shift the keys C and V down to the same place.
BE9C SRL C
BE9E OR C Combine them with the keys Z and X.
BE9F AND %00000011 Keep the two bits for turning left and turning right.
BEA1 LD C,A Set the turning bits of the controls.

With a joystick, the keys of the keyboard other than CAPS SHIFT and SPACE are used to pick up and drop an object.
ReadControls_Keys BEFD LD A,$7E Read from the keyboard, with a call to ReadKeyboardPort that returns the pressed keys as set bits;
Port Number Bit
0 1 2 3 4
7E CAPS SHIFT or SPACE Z or SYMBOL SHIFT X or M C or N V or B
BEFF CALL ReadKeyboardPort
BF02 AND %00011110 Keep the keys other than CAPS SHIFT and SPACE.
BF04 JR Z,ReadControls_Done Jump to ReadControls_Done if none of them is pressed.
BF06 SET 4,C Set the bit for picking up and dropping.
ReadControls_Done BF08 LD A,C Copy the controls to A.
BF09 LD ($A737),A Write them to ControlsPressed.
