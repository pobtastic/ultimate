C7A8: Set Door Offset Type Eight
Used by the routine at HandleNearArch.
Sets the offsets of the sprite of a door of type 08 that is not mirrored, and carries on with the handler of the door.
Input
IX Door record
SetDoorOffsetTypeEight C7A8 LD HL,$FBF8 Set the offsets for the sprite in HL, which are F8 horizontally and FB vertically.
C7AB JR HandleNearArch_Place Jump to HandleNearArch_Place to carry on.
