B90D: Keep Object In Room In Y
Used by the routine at BlockMovement.
Cuts down the distance that an object moves along y until it stays inside the walls of the room, in the same way as KeepObjectInRoomInX does for x. The limit is in RoomSizeY.
Input
L Distance to move along y
IX Object record
Output
L Distance that can be moved
KeepObjectInRoomInY B90D LD A,(IX+$0C) Fetch the collision flags.
B910 AND %11110000 Keep only the countdown from entering the room.
B912 RET NZ Return if the object has only just entered the room.
B913 BIT 0,(IX+$07) Return if the object ignores the walls.
B917 RET NZ
B918 LD A,($A71E) Fetch the limit along y in B.
B91B LD B,A
KeepObjectInRoomInY_Test B91C LD A,(IX+$02) Work out the position of the object along y, once it has moved.
B91F ADD A,L
B920 SUB $80 Subtract 80 to get its distance from the middle.
B922 JR NC,KeepObjectInRoomInY_Compare Jump to KeepObjectInRoomInY_Compare if that is not negative.
B924 NEG Make the distance positive.
KeepObjectInRoomInY_Compare B926 ADD A,(IX+$05) Add the half size of the object, to get the distance of its edge from the middle.
B929 CP B Return if the edge is inside the limit.
B92A JR C,KeepObjectInRoomInY_Done
B92C SET 1,(IX+$0C) Flag that the object has been stopped along y.
B930 LD A,L Fetch the distance to move.
B931 CALL BringSpeedCloserToZero Call BringSpeedCloserToZero to step it one closer to zero.
B934 LD L,A Set the distance.
B935 JR NZ,KeepObjectInRoomInY_Test Jump to KeepObjectInRoomInY_Test to test again, unless the distance is zero.
KeepObjectInRoomInY_Done B937 RET Return.
