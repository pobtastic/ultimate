B6ED: Block Movement
Used by the routines at ApplyGravityAndMove and MovePlayer.
Moves an object by its speeds along the three axes, which are held in the object, and stops it where it is blocked by a wall or by another object. The speeds are changed to the distances that the object has actually moved. The routine records what blocked the object in its collision flags: bit 0 is set if it was stopped on x, bit 1 if it was stopped on y and bit 2 if it was stopped on z, which also means that the object is standing on the floor or on another object. These flags are cleared first.
The object is flagged as being moved while this happens, so that the tests for collisions with other objects ignore it, and so that this routine ignores a second call for it.
The z axis is done first, then x, then y. The speed is first cut down to what the walls (or the floor) allow, and then to what the other objects allow.
