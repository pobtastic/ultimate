BF56: Set Wipe And Draw Flags For Object
Used by the routines at DropObject and PickUpObject.
Does what SetWipeAndDrawFlags does for the object in IY, which is to say that it has to be drawn again, and that the area where it was has to be restored.
Input
IY Record of the object
SetWipeAndDrawFlagsForObject BF56 PUSH IY Stash IY and IX on the stack.
BF58 PUSH IX
BF5A PUSH IY Copy IY to IX, using the stack.
BF5C POP IX
BF5E CALL SetWipeAndDrawFlags Call SetWipeAndDrawFlags to mark the object.
BF61 POP IX Restore IX and IY from the stack.
BF63 POP IY
BF65 RET Return.
