D56C: Play Moving Sound
Never used. Makes a short tone of a pitch from the table at MovingSoundPitches, which is picked by the frame counter, for an object that has been moved, as shown by the flag for it being moved.
Input
IX Object record
PlayMovingSound D56C LD BC,$D587 Take the table of pitches, MovingSoundPitches.
D56F BIT 1,(IX+$07) Test the flag for the object being moved.
D573 RES 1,(IX+$07) Clear the flag.
D577 RET Z Return if it was not set.
D578 LD A,($A715) Fetch the frame counter.
D57B AND %00001111 Keep the lowest four bits.
D57D LD L,A Put that in HL.
D57E LD H,$00
D580 ADD HL,BC Add the table to it.
D581 LD B,(HL) Fetch the pitch.
D582 LD C,$0C Set the length of the tone.
D584 JP PlayWaveSequence Jump to PlayWaveSequence to make the tone.
