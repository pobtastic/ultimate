BDC0: Set Sprite Details
Used by the routines at DrawFrame, PrintBorder and PrintTableSprite.
Sets up the temporary object from the four bytes that describe a piece of a frame: the type, the flags and the screen position.
Input
HL Address of the data
IX Temporary object record
Output
HL Address of the data after the piece
SetSpriteDetails BDC0 LD A,(HL) Set the type of the object.
BDC1 INC HL
BDC2 LD (IX+$00),A
BDC5 LD A,(HL) Set the flags of the object.
BDC6 INC HL
BDC7 LD (IX+$07),A
BDCA LD A,(HL) Set the screen x co-ordinate of the object.
BDCB INC HL
BDCC LD (IX+$1A),A
BDCF LD A,(HL) Set the screen y co-ordinate of the object.
BDD0 INC HL
BDD1 LD (IX+$1B),A
BDD4 RET Return.
