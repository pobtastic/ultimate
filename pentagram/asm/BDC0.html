BDC0: Set Sprite Details
Used by the routines at DrawFrame, PrintBorder and PrintTableSprite.
Sets the sprite number, the flags and the pixel position of an object from four bytes of data.
Input
HL The address of the data
IX The address of the object
Output
HL The address of the byte after the data
Set the type of the object.
SetSpriteDetails BDC0 LD A,(HL) Fetch the sprite number and move on.
BDC1 INC HL
BDC2 LD (IX+$00),A Set the sprite number.
Set the flags of the object.
BDC5 LD A,(HL) Fetch the flags and move on.
BDC6 INC HL
BDC7 LD (IX+$07),A Set the flags.
Set the screen x co-ordinate of the object.
BDCA LD A,(HL) Fetch the pixel x and move on.
BDCB INC HL
BDCC LD (IX+$1A),A Set the pixel x position.
Set the screen y co-ordinate of the object.
BDCF LD A,(HL) Fetch the pixel y and move on.
BDD0 INC HL
BDD1 LD (IX+$1B),A Set the pixel y position.
BDD4 RET Return.
