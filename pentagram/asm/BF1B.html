BF1B: Test Object Intersections
Used by the routines at LoadRoomObjects, HandlePickupAndDrop and CreateCreature.
Tests if an object is overlapping any other object, where it is at the moment. This is used to find out if there is room to put the object somewhere, once its position has been changed.
Input
IX Record of the object
Output
F Carry flag set if the object overlaps another object
TestObjectIntersections BF1B PUSH BC Stash BC, DE and HL on the stack.
BF1C PUSH DE
BF1D PUSH HL
BF1E PUSH IY Stash IY on the stack.
BF20 LD IY,$A76F Start with the first object record, ObjectsTable.
BF24 LD B,$36 Set a counter in B of the number of object records, 36.
BF26 LD C,$00 Set the distance moved along x to zero.
BF28 LD L,C Set the distances moved along y and z to zero.
BF29 LD H,C
BF2A SET 1,(IX+$07) Flag the object as being moved, so that it is not tested against itself.
Test whether this object overlaps on all three axes.
TestObjectIntersections_Loop BF2E CALL TestObjectSolid Jump to TestObjectIntersections_Next to try the next object if this one is free, or is the object that is being tested.
BF31 JR Z,TestObjectIntersections_Next
BF33 CALL TestOverlapInX Jump to TestObjectIntersections_Next to try the next object if they do not overlap along x.
BF36 JR NC,TestObjectIntersections_Next
BF38 CALL TestOverlapInY Jump to TestObjectIntersections_Next to try the next object if they do not overlap along y.
BF3B JR NC,TestObjectIntersections_Next
BF3D CALL TestOverlapInZ Jump to TestObjectIntersections_Next to try the next object if they do not overlap along z.
BF40 JR NC,TestObjectIntersections_Next
The objects overlap on all three axes (and the carry flag is set), or there are none left to try (and it is not).
TestObjectIntersections_Done BF42 POP IY Restore IY from the stack.
BF44 POP HL Restore HL, DE and BC from the stack.
BF45 POP DE
BF46 POP BC
BF47 RES 1,(IX+$07) Clear the flag that says that the object is being moved.
BF4B RET Return.
Move on to the next object.
TestObjectIntersections_Next BF4C LD DE,$0020 Move on to the next object record.
BF4F ADD IY,DE
BF51 DJNZ TestObjectIntersections_Loop Decrease the counter and loop until all the records have been tried.
BF53 AND A Clear the carry flag, as nothing overlaps the object.
BF54 JR TestObjectIntersections_Done Jump to TestObjectIntersections_Done.
