BAEA: Print Character
Used by the routines at PrintBCDNumber and PrintText.
Draws a character into the buffer, a 08 by 08 block of pixels, and leaves the address ready for the next character. A space is drawn as the glyph with code 3D which is blank. The glyph is found in the table at the address in FontPointer: the address of a glyph is that address plus the code times eight.
Input
A Character code
HL Address in the buffer of the top line of the place for the character
Output
HL Address in the buffer of the top line of the place to the right
Find the glyph.
PrintCharacter BAEA PUSH BC Stash BC, DE and HL on the stack.
BAEB PUSH DE
BAEC PUSH HL
BAED CP $20 Jump to PrintCharacter_Glyph if the character is not a space.
BAEF JR NZ,PrintCharacter_Glyph
BAF1 LD A,$3D Use the glyph for the code 3D instead, which is blank.
PrintCharacter_Glyph BAF3 LD L,A Set HL to the character code.
BAF4 LD H,$00
BAF6 ADD HL,HL Multiply it by eight.
BAF7 ADD HL,HL
BAF8 ADD HL,HL
BAF9 LD DE,($A732) Fetch the address of the glyph table from FontPointer.
BAFD ADD HL,DE Add it to get the address of the glyph.
BAFE EX DE,HL Set DE to it.
BAFF POP HL Restore HL, the address in the buffer, from the stack.
Copy the eight lines of the glyph to the buffer, working down the buffer from the top line.
BB00 LD B,$08 Set a counter in B of eight lines.
PrintCharacter_Loop BB02 LD A,(DE) Copy a line of the glyph to the buffer.
BB03 LD (HL),A
BB04 INC DE Move on to the next line of the glyph.
BB05 PUSH BC Stash the counter on the stack.
BB06 LD BC,$FFE0 Set BC to FFE0 which is minus the length of a line of the buffer.
BB09 ADD HL,BC Move HL down to the next line of the buffer.
BB0A POP BC Restore the counter.
BB0B DJNZ PrintCharacter_Loop Decrease the counter and loop until all eight lines have been copied.
Move on to the next character position, which is eight lines up and one byte to the right.
BB0D POP DE Restore DE from the stack.
BB0E LD BC,$0101 Add 0101 to HL.
BB11 ADD HL,BC
BB12 POP BC Restore BC from the stack.
BB13 RET Return.
