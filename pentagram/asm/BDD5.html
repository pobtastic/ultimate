BDD5: Print Table Sprite
Used by the routines at DrawFrame and PrintBorder.
Sets up a piece of a frame from its data, and draws it.
Input
HL Address of the data
IX Temporary object record
Output
HL Address of the data after the piece
PrintTableSprite BDD5 CALL SetSpriteDetails Call SetSpriteDetails to set up the piece.
BDD8 PUSH HL Stash the data pointer on the stack.
BDD9 CALL DrawObject_Sprite Call DrawObject_Sprite to draw the piece.
BDDC POP HL Restore the data pointer.
BDDD RET Return.
