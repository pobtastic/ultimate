C75F: Set Sprite Offset Minus 16 Minus 8
Used by the routines at DropObject, RunDangerousFixed, RunScenery, RunPentagramStone, RunFallingObject, RunSinkingBlock, RunLift, RunBobbingBlock, RunSliderX, RunSliderY, RunStaticObject, RunWanderingSpark, RunCollectableObject, RunHelperSource, RunHelper, RunWanderer, RunFourFrameWanderer, RunCrumblingBlock, RunConveyorBlockPlusX, RunConveyorBlockMinusX, RunConveyorBlockPlusY and RunConveyorBlockMinusY.
Sets the offsets of the sprite to F0 horizontally and F8 vertically.
Input
IX Object record
SetSpriteOffset_Minus16_Minus8 C75F LD HL,$F8F0 Set the offsets in HL.
