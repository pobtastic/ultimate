BBD8: Flash Menu Options
Used by the routine at GameMenu.
Makes the line of the menu that shows the chosen control method flash, and stops the other three from flashing. The line that starts the game flashes if bit 3 of ControlMethod is set, which the menu never does.
FlashMenuOptions BBD8 LD HL,$BBF2 Start at the colour of the first control method line, which is the byte after the first of MenuColours.
BBDB LD A,($A709) Fetch the control method.
BBDE RRCA Shift the method down to bits 0 and 1...
BBDF AND %00000011 ...and keep only those bits.
BBE1 LD B,$04 Set a counter in B of four lines.
BBE3 CALL SetFlashingAttribute Call SetFlashingAttribute to make that line flash.
BBE6 RES 7,(HL) Stop the line that starts the game from flashing.
BBE8 LD A,($A709) Fetch the control method.
BBEB AND %00001000 Keep only bit 3.
BBED RET Z Return if it is not set.
BBEE SET 7,(HL) Make the line that starts the game flash.
BBF0 RET Return.
