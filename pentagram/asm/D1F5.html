D1F5: Run Flickering Wanderer
The handler of the object types 10 and 11, which are creatures that harm the player and wander about the room. It turns the sprite over each frame, to make it flicker, and carries on as RunWanderer.
Input
IX Object record
RunFlickeringWanderer D1F5 LD A,(IX+$07) Fetch the flags of the object.
D1F8 XOR %01000000 Turn the sprite over.
D1FA LD (IX+$07),A Store the flags.
Continue on to RunWanderer.
