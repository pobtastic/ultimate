6CA7: Catch Nasty
Used by the routine at CatchActor.
Part of CatchActor, used when the actor which has fallen into the mixing bowl is one of the nasties. The falling notes are started and five more ingredients are needed, up to a maximum of 99.
CatchNasty 6CA7 CALL StartFallingNotes Start the falling notes using StartFallingNotes.
6CAA LD B,$05 Set the penalty to 05 ingredients.
6CAC LD A,($5F2F) Fetch the number of ingredients which the active player needs.
6CAF ADD A,B Add the penalty to the number of ingredients needed.
6CB0 DAA Adjust A to BCD.
6CB1 JR NC,TakeIngredients_Store Jump to TakeIngredients_Store if the number has not gone above 99.
6CB3 LD A,$99 Set the number of ingredients needed to the maximum, 99.
6CB5 JR TakeIngredients_Store Jump to TakeIngredients_Store.
