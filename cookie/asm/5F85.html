5F85: Messaging: Copyright
The copyright messages. The second message is printed on the game menu by GameMenu; the first is not used by the game.
Message_Copyright 5F85 DEFM "COPYRIGHT" "COPYRIGHT".
47 is the text colour. 7F is the font code for the "©" symbol.
Message_Rights 5F8E DEFM $47 "© 1983 A.C.G. ALL RIGHTS RESERVED".
5F8F DEFM $7F
5F90 DEFM "1983 A.C.G. ALL RIGHTS RESERVE","D"+$80
