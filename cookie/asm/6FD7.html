6FD7: Controls: Cursor Joystick
Used by the routine at ReadControls.
Reads the cursor joystick, which uses the keys "5" (left), "6" (down), "7" (up), "8" (right) and "0" (fire). The bits of the result are the same as those which are returned by ReadControls.
