6002: Set Pantry Fill Colour
Used by the routine at DrawPantry.
Picks the attribute used for the blank tiles of one pantry shelf.
Input
B Shelf number
PantryFillColour 6002 LD A,B Fetch the shelf number.
6003 EXX Switch to the shadow registers.
6004 LD C,A Use the shelf number as an offset into the table of fill colours.
6005 LD B,$00
6007 LD HL,$6011 Find the fill colour for the shelf in PantryFillColours.
600A ADD HL,BC
600B LD A,(HL) Write the fill colour to PantryShelfColour.
600C LD ($5F27),A
600F EXX Switch back to the normal registers.
6010 RET Return.
