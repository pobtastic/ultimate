5B80: Game Entry Point
The address which the game is started from. It moves the main body of the game down by one byte, and then jumps to it.
GameEntry 5B80 DI Disable interrupts.
5B81 LD HL,$5F01 Move 20FF bytes from 5F01 to 5F00.
5B84 LD DE,$5F00
5B87 LD BC,$20FF
5B8A LDIR
5B8C JP SecurityCheck Jump to SecurityCheck.
