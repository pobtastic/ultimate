69D4: Handle Chocolate
The handler for the chocolate (IDs 10 and 11), which drifts about in random directions. Every 10 frames a new random direction is picked and stored in byte 06 of the actor (bit 0 is set for down, and bit 1 is set for right). The speeds are changed by one every other frame towards that direction, up to a maximum speed of 02 in either direction.
While the chocolate is still entering from the right of the screen (a horizontal co-ordinate of C4 or more) it is only moved.

69DE CP $C4 Jump to ChangeActorSpeeds_Move if the chocolate is still entering from the right.

69E2 CALL TestCharlieCollision Test whether the actor has hit Charlie using TestCharlieCollision.

69E6 JP Z,LoseHat Jump to LoseHat if Charlie has been hit.

69F0 JP NZ,HandleHitActor

69F7 LD A,(IX+$07) Fetch the frame counter (byte 07 of the actor).

69FE LD A,R Fetch a random number.
6A00 AND %00000011 Keep only bits 0-1.
6A02 LD (IX+$06),A Set a random direction (byte 06 of the actor).
