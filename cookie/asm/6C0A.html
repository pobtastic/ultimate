6C0A: End Game
Used by the routine at HandleEndOfLife.
Called when the last life has been lost in a one player game, or by the last player of a two player game. Checks the high score, shows the "GAME OVER" message for the active player, and then goes back to the game selection screen using Game_Restart.
GameOver_ControllerRestart 6C0A CALL CheckHighScore Check for a new high score using CheckHighScore.
6C0D LD A,($5F21) If Flag_ActivePlayer is not zero, jump to GameOver_Restart2UP.
6C10 AND A
6C11 JR NZ,GameOver_Restart2UP
6C13 CALL GameOver_1UP_Messaging Show the 1UP game over message using GameOver_1UP_Messaging.
GameOver_Restart 6C16 JP Game_Restart Jump to Game_Restart.
GameOver_Restart2UP 6C19 CALL GameOver_2UP Show the 2UP game over message using GameOver_2UP.
6C1C JR GameOver_Restart Jump to GameOver_Restart.
