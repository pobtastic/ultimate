74D4: Reset Screen Buffer
Used by the routines at CreateWindow, StartGame and CreateIntroductionIngredient.
Clears the screen buffer by filling it with zero.
ResetScreen 74D4 LD HL,$4000 Point HL at the start of the screen buffer.
74D7 LD B,$58 Set the end of the screen buffer (58 the start of the attributes).
ResetScreen_Fill 74D9 LD C,$00 Set the byte to write to 00 (blank).
