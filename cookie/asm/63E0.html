63E0: Write Menu Line
Used by the routine at GameMenu.
Prints one line of the game selection menu. This works in the same way as PrintStringColour, except that the text is pointed to by DE' and the screen position is in HL', and the attribute is not part of the string, it is taken from Current_MenuAttribute.
Before After
Input
DE' Address of the text
HL' Position of the line
MenuWriteText 63E0 PUSH HL Stash the position on the stack.
63E1 CALL ScreenAddress Convert the position to a screen address using ScreenAddress.
63E4 LD A,($5F24) Fetch the menu attribute byte from Current_MenuAttribute.
63E7 EX AF,AF' Switch to the shadow AF register.
63E8 EXX Switch to the normal registers.
63E9 POP HL Restore the position from the stack.
63EA CALL AttributeAddress Convert the position to an attribute address using AttributeAddress.
63ED JP PrintString_Loop Jump to PrintString_Loop to print the text.
