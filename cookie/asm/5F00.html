5F00: Security Check
Used by the routine at GameEntry.
The game only starts when the second byte of FRAMES is 32. If it is any other value then this returns to the caller instead.
SecurityCheck 5F00 LD A,($5C79) Fetch the second byte of FRAMES.
5F03 CP $32 Return if the second byte of FRAMES is not "2".
5F05 RET NZ
5F06 JP GameInitialisation Start the game by jumping to GameInitialisation.
