7149: Remove Actors
Used by the routine at RemoveAllActors.
Removes a number of actors, by writing zero to each of the IDs.
Input
B Number of actors
HL Address of the first actor
RemoveActors 7149 LD DE,$0008 Set the size of an actor to 08.
RemoveActors_Loop 714C LD (HL),$00 Write 00 to the actor ID.
714E ADD HL,DE Move on to the next actor.
714F DJNZ RemoveActors_Loop Decrease the actor counter by one and loop back to RemoveActors_Loop until all of the actors have been done.
7151 RET Return.
