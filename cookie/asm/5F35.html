5F35: Charlie
The first of the ten actor slots (up to Message_Copyright), which is always Charlie. Every actor has the same eight byte format, and is processed once for each pass through the game loop.
Offset Contents
00 ID (sprite ID and handler, see ActorHandlers)
01 Horizontal co-ordinate
02 Vertical co-ordinate
03 Colour attribute
04-07 Used by the handler
ActorCharlie 5F35 DEFB $00 ID.
ActorCharlie_X 5F36 DEFB $00 Horizontal co-ordinate.
5F37 DEFB $00 Vertical co-ordinate.
5F38 DEFB $00 Colour attribute.
5F39 DEFB $00,$00,$00,$00 Used by the handler.
