635E: Game Select Attribute Table
One attribute byte per menu line. The routines that flash the selected line set or clear FLASH in the byte for the line being updated. The first byte belongs to the title, so the flashing code starts at 635F.
GameSelection_Attributes 635E DEFB $47
Byte(n) Menu Item
01 Game Selection
02 1 Player Game
03 2 Player Game
04 Keyboard
05 Kempston Joystick
06 Cursor Joystick
07 Start Game
