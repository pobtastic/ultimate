7152: Limit Frame Rate
The handler for empty actor slots (IDs 00 0C and 17). It adds a short pause, which slows the game down when there are few actors. The pause is skipped while the frame update (FrameUpdate) is running.
LimitFrameRate 7152 LD A,($5F23) Return if FrameUpdated is set (the frame update is running).
7155 AND A
7156 RET NZ
7157 LD HL,$0100 Set the pause counter to 0100.
LimitFrameRate_Loop 715A DEC HL Decrease the pause counter by one.
715B LD A,L Keep jumping back to LimitFrameRate_Loop until the counter is zero.
715C OR H
715D JR NZ,LimitFrameRate_Loop
715F RET Return.
