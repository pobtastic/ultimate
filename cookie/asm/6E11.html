6E11: Start Charlie Running
Used by the routine at HandleLevelIntroduction.
Called when the ingredient in the introduction to a level has moved left of 90. The first time this happens CharlieRunningFlag is set, so Charlie starts to run, and the actor for Charlie is created again.
StartCharlieRunning 6E11 LD A,($5F29) Fetch the flag which says whether Charlie is running.
6E14 AND A Has Charlie started to run?
6E15 RET NZ Return if he has.
6E16 INC A A=01.
6E17 LD ($5F29),A Flag that Charlie is running (CharlieRunningFlag).
6E1A LD HL,$5F35 Point HL at ActorCharlie.
6E1D LD DE,$6D87 Point DE at IntroductionCharlie.
6E20 LD C,$07 C=07 (the ID for Charlie).
6E22 JP CreateIntroductionActor Jump to CreateIntroductionActor to create the actor for Charlie.
