6428: Start Game
Used by the routine at GameInitialisation.
Starts a new game when "0" is pressed on the game selection menu. The screen is blanked, the opening tune is played (unless the sound is muted) and the data for the game is reset. Then the first level is set up, and the game carries on in the main loop.
