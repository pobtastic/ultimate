65C8: Music Data
Three tunes. Each is a list of note numbers, ended by FF. The first is played when a game starts, the second when Charlie loses a life and the third when a level is finished.
The tune which is played when a game starts.
MusicData 65C8 DEFB $0E,$01,$0E,$03,$04,$05,$05,$01
65D0 DEFB $FF
The tune which is played when Charlie loses a life.
MusicData_LoseLife 65D1 DEFB $0E,$01,$0E,$03,$05,$06,$01,$06
65D9 DEFB $FF
The tune which is played when a level is finished.
MusicData_LevelFinished 65DA DEFB $0D,$05,$06,$07,$08,$06,$05,$03
65E2 DEFB $01,$05,$08,$05,$01,$FF
