669B: Handle Peel
The handler for the orange peel (IDs 14 and 15). It wanders about in a wavy path. Byte 06 of the actor holds the direction (bit 0 is set for right, bit 1 is set for down) and which byte of each pair in the table at WanderSpeeds is used for which direction (bit 2). Byte 07 is a counter, which chooses the speeds to use from the table, and changes the sprite frame.
While the peel is entering from the right of the screen (a horizontal co-ordinate of C4 or more) it can't hit Charlie or be hit.
