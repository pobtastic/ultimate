766D: Draw Old Sprite Row
Draws one row of the sprite prepared by PrepareOldSprite by exclusive ORing it onto the screen, then moves on to the row above.
Input
DE Address of the sprite data
HL Screen address
Output
DE Address of the next row of sprite data
HL Screen address of the row above
The entry point for a sprite which is aligned to a character cell.
DrawOldSpriteRow_Aligned 766D EX DE,HL DE=the row of sprite data, and HL=the address of the next row.
766E EX (SP),HL HL=the screen address, and the address of the next row of sprite data is stored on the stack.
766F JR DrawSpriteRow_Write Jump to DrawSpriteRow_Write.
This entry point is used by the routine at XORSpriteLoop.
The entry point for a sprite which is not aligned to a character cell.
