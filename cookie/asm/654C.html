654C: Handle Batter
The handler for the first three frames of the batter (IDs 28 to 2A). Each time it is called, the actor moves on to the next frame.
Input
IX Actor
HandleBatter 654C CALL StoreEntity Record the position of the sprite using StoreEntity.
654F LD HL,$5F1B Increase the number of actors in play (ActorsInPlay) by one.
6552 INC (HL)
6553 INC (IX+$00) Increase the actor ID by one, which chooses the next frame.
6556 CALL DisplayEntity Erase the sprite and draw the next frame using DisplayEntity.
6559 JP ColourSprite Jump to ColourSprite to colour the sprite.
