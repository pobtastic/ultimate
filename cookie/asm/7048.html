7048: Game Play Entry
The handler for Charlie (IDs 01 and 02). At the start of each life there is a delay (GameDelayTimer) before Charlie appears, and while it runs the score label of the active player flashes (see ScoreLabelFlash). When it has run out the label stops flashing, Charlie is drawn and a tone is played (see GameStartJingle). After that Charlie is moved by GamePlay_Start.
GamePlayEntry 7048 LD HL,$5F25 If GameDelayTimer is zero, jump to GamePlay_Start.
704B LD A,(HL)
704C AND A
704D JR Z,GamePlay_Start
704F DEC (HL) Decrease the game delay timer by one.
7050 JR NZ,ScoreLabelFlash Jump to ScoreLabelFlash if the delay timer is still active.
7052 LD A,($5F21) If Flag_ActivePlayer says this is a 2UP game, jump to Game2UP_UnsetFlash.
7055 AND A
7056 JR NZ,Game2UP_UnsetFlash
Handle turning off flash for 1UP score label.
7058 LD HL,$0018 HL=00,18 (position of the 1UP score label).
Game_UnsetFlash 705B CALL UnsetFlashText Turn off the flash using UnsetFlashText.
705E CALL DrawEntity Draw Charlie using DrawEntity.
7061 CALL GameStartJingle Play the game start tone using GameStartJingle.
7064 JR GamePlay_Start Jump to GamePlay_Start.
Handle turning off flash for 2UP score label.
Game2UP_UnsetFlash 7066 LD HL,$00D8 HL=00,D8 (position of the 2UP score label).
7069 JR Game_UnsetFlash Jump to Game_UnsetFlash.
