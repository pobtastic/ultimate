7468: Print Character
Used by the routines at DrawPantry, PrintTileBlock, DisplayPlayerLives, Score_1UP and PrintStringColour.
Prints a character on the screen, using the character set at 5C36 (CHARS), as eight rows of pixels. The screen address is then moved on by one column, ready to print the next character.
Input
A ASCII value to print
HL Screen address
Output
HL Screen address of the next character
