655C: Handle Final Batter
The handler for the last frame of the batter (ID 2B), which removes the batter from the screen and then the actor.
Input
IX Actor
HandleBatter_Final 655C CALL DrawEntity Erase the sprite using DrawEntity.
655F LD HL,$5F1B Increase the number of actors in play (ActorsInPlay) by one.
6562 INC (HL)
6563 LD (IX+$00),$00 Write 00 to the actor ID.
6567 RET Return.
