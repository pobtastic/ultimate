68C4: Start Rising Sweep
Used by the routine at TestCharlieCollision.
The sound effects are played by an actor which lives in the slot at SoundEffectActor. This copies the template for the effect into the slot, and the handler then plays it a bit at a time. Eight bytes are always copied, so the bytes of a template which are beyond the ones used are really the code which follows it.
StartRisingSweep 68C4 LD HL,$68D0 Point HL at the template for the rising sweep.
This entry point is used by the routines at StartFallingNotes, StartRisingNotes, StartWarble and StartFallingSlide.
StartSoundEffect 68C7 LD DE,$5F4D Point DE at the sound effect actor (SoundEffectActor).
68CA LD BC,$0008 Set the number of bytes to copy to 08.
68CD LDIR Copy the template to the sound effect actor.
68CF RET Return.
