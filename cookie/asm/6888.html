6888: Handle Rising Sweep
The handler for sound effect actors with the ID 19. Each time it is called it plays a number of cycles (IX+02), and then makes the period (IX+03) shorter, which raises the pitch. The actor is removed when the period reaches zero.
Input
IX Sound actor
Handler_RisingSweep 6888 DEC (IX+$03) Decrease the period by one, which raises the pitch.
688B JR Z,RemoveActor Jump to RemoveActor if the period is zero.
688D LD D,(IX+$03) Fetch the period.
6890 LD C,(IX+$02) Fetch the number of cycles.
This entry point is used by the routine at Handler_Notes.
Handler_PlayCycles 6893 CALL PlaySquareWave Play a cycle using PlaySquareWave.
6896 DEC C Decrease the cycle counter by one.
6897 JR NZ,Handler_PlayCycles Loop back to Handler_PlayCycles until all of the cycles have been played.
6899 RET Return.
