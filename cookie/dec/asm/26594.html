26594: Create Monster
Used by the routine at CreateActor.
Creates the monster in the last of the six actor slots (24445), unless that slot is already in use. The ID is 36 or 37 depending on bit 0 of the number of ingredients that are needed. The monster is put at the bottom of one of the four dustbins, which is chosen at random from the table at DustbinPositions, and is coloured green. Bytes 4 and 5 are the speeds which are used when the monster throws something (see HandleMonster_Throwing); they are made from the frame counter and a random number. A warble sound is then started.

26629 LD (DE),A Set the colour of the monster.

26631 LD A,(24349) Fetch the frame counter.
26634 AND %00000011 Keep only bits 0-1.
26636 NEG Negate the result, so that the monster is thrown to the left.
26638 LD (DE),A Set the horizontal speed.

26648 NEG Negate the result, so that it is an upward speed.
26650 LD (DE),A Set the vertical speed.

26652 XOR A Set the state to 0 (rising out of the dustbin).
