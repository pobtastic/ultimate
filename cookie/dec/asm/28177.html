28177: Start Charlie Running
Used by the routine at HandleLevelIntroduction.
Called when the ingredient in the introduction to a level has moved left of 144. The first time this happens CharlieRunningFlag is set, so Charlie starts to run, and the actor for Charlie is created again.
StartCharlieRunning 28177 LD A,(24361) Fetch the flag which says whether Charlie is running.
28180 AND A Has Charlie started to run?
28181 RET NZ Return if he has.
28182 INC A A=1.
28183 LD (24361),A Flag that Charlie is running (CharlieRunningFlag).
28186 LD HL,24373 Point HL at ActorCharlie.
28189 LD DE,28039 Point DE at IntroductionCharlie.
28192 LD C,7 C=7 (the ID for Charlie).
28194 JP CreateIntroductionActor Jump to CreateIntroductionActor to create the actor for Charlie.
