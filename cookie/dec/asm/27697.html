27697: Handle Level Timer
The handler for the actor which is created by SetUpLevel at the start of a level (IDs 10 and 11). It is not drawn; its horizontal co-ordinate is used as a timer, which is decreased by one each pass. When it reaches zero the introduction to the level is started by StartLevelIntroduction.
Input
IX Actor
HandleLevelTimer 27697 LD A,(IX+1) Fetch the timer (held in the horizontal co-ordinate).
27700 DEC A Decrease the timer by one.
27701 LD (IX+1),A Update the timer.
27704 CALL Z,StartLevelIntroduction Call StartLevelIntroduction if the timer is zero.
27707 RET Return.
