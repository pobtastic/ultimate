29908: Reset Screen Buffer
Used by the routines at CreateWindow, StartGame and CreateIntroductionIngredient.
Clears the screen buffer by filling it with zero.
ResetScreen 29908 LD HL,16384 Point HL at the start of the screen buffer.
29911 LD B,88 Set the end of the screen buffer (88 the start of the attributes).
ResetScreen_Fill 29913 LD C,0 Set the byte to write to 0 (blank).
