29800: Print Character
Used by the routines at DrawPantry, PrintTileBlock, DisplayPlayerLives, Score_1UP and PrintStringColour.
Prints a character on the screen, using the character set at 23606 (CHARS), as eight rows of pixels. The screen address is then moved on by one column, ready to print the next character.
Input
A ASCII value to print
HL Screen address
Output
HL Screen address of the next character

29807 ADD HL,HL
29808 ADD HL,HL

This entry point is used by the routine at DisplayPlayerLives.
PrintCharacter_Draw 29816 LD B,8 Set the pixel row counter to 8 (8 rows of pixels).
PrintScreen_Loop 29818 LD A,(DE) Copy a byte from the font data to the screen buffer.
29819 LD (HL),A
29820 INC DE Move on to the next byte of the font data.
29821 INC H Move onto the next pixel line.
29822 DJNZ PrintScreen_Loop Decrease the pixel row counter by one and loop back to PrintScreen_Loop until all eight rows have been copied.
29824 POP DE Restore the registers from the stack.
