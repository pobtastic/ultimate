24599: Draw Pantry
Used by the routine at StartLevel.
Draws the pantry down the right hand side of the screen, and the mixing bowl and pillars along the bottom. The scenery is built from the tiles at CupboardGraphic, which are printed as if they were a font.
The pantry has five shelves, each with a drawer. The drawer for the current level's ingredient is drawn highlighted, and has the colour of the ingredient inside it. The level number is printed in the bottom right corner.
The pantry is constructed like it is a font.

24602 PUSH HL
24603 LD HL,31562 Use the pantry tiles as the character set by writing CupboardGraphic to CHARS.
24606 LD (23606),HL
Make a mask which has a single bit set for the shelf that is highlighted. Shelf 5 is at the top and shelf 1 is at the bottom, so the mask is 32 shifted right by the level (modulo 8).
24609 LD A,(24365) Fetch the level of the active player.
24612 AND %00000111 Keep only bits 0-2 (the level within the set of five).
24614 LD B,A Use the level as the counter for moving the highlight down.
24615 LD A,32 Start with the mask for the top shelf.
24617 JR Z,DrawPantry_SetMask Jump to DrawPantry_SetMask if the top shelf is highlighted.

24621 DJNZ DrawPantry_Shift_Loop Decrease the level counter by one and loop back to DrawPantry_Shift_Loop until the highlight is on the shelf for this level.
DrawPantry_SetMask 24623 LD (24362),A Write the mask of the highlighted shelf to PantryHighlightMask.
