30084: Prepare Actor Sprite
Used by the routines at DisplayEntity and DrawEntity.
Does the same as PrepareOldSprite for the sprite of the actor in IX. As well as the screen address, it records the address of the first attribute cell in ActorSprite_Position, the width in character cells in ActorSprite_Width and the number of rows to draw in ActorSprite_RowsRemaining and ActorSprite_Rows. This is set up for the shifting routine at DrawActorSpriteRow.
Input
IX Actor
Output
C 0
DE Address of the first row of sprite data to draw
HL Screen address of the bottom row of the sprite

30090 LD H,(IX+2) Fetch the vertical co-ordinate of the actor.
30093 LD A,L Fetch the horizontal co-ordinate.

30102 LD A,241 Use the offset which jumps to the code for sprites which are aligned to a character cell.
Self modifying code; this updates the operand of the JR command at 30392.
PrepareActorSprite_Shift 30104 LD (30393),A Write the offset to the JR command at 30393.
A sprite which is aligned to a character cell is two cells wide, otherwise it is three cells wide.
