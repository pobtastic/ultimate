29010: Limit Frame Rate
The handler for empty actor slots (IDs 0 12 and 23). It adds a short pause, which slows the game down when there are few actors. The pause is skipped while the frame update (FrameUpdate) is running.
LimitFrameRate 29010 LD A,(24355) Return if FrameUpdated is set (the frame update is running).
29013 AND A
29014 RET NZ
29015 LD HL,256 Set the pause counter to 256.
LimitFrameRate_Loop 29018 DEC HL Decrease the pause counter by one.
29019 LD A,L Keep jumping back to LimitFrameRate_Loop until the counter is zero.
29020 OR H
29021 JR NZ,LimitFrameRate_Loop
29023 RET Return.
