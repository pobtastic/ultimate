24578: Set Pantry Fill Colour
Used by the routine at DrawPantry.
Picks the attribute used for the blank tiles of one pantry shelf.
Input
B Shelf number
PantryFillColour 24578 LD A,B Fetch the shelf number.
24579 EXX Switch to the shadow registers.
24580 LD C,A Use the shelf number as an offset into the table of fill colours.
24581 LD B,0
24583 LD HL,24593 Find the fill colour for the shelf in PantryFillColours.
24586 ADD HL,BC
24587 LD A,(HL) Write the fill colour to PantryShelfColour.
24588 LD (24359),A
24591 EXX Switch back to the normal registers.
24592 RET Return.
