26760: Handle Rising Sweep
The handler for sound effect actors with the ID 25. Each time it is called it plays a number of cycles (IX+2), and then makes the period (IX+3) shorter, which raises the pitch. The actor is removed when the period reaches zero.
Input
IX Sound actor
Handler_RisingSweep 26760 DEC (IX+3) Decrease the period by one, which raises the pitch.
26763 JR Z,RemoveActor Jump to RemoveActor if the period is zero.
26765 LD D,(IX+3) Fetch the period.
26768 LD C,(IX+2) Fetch the number of cycles.
This entry point is used by the routine at Handler_Notes.
Handler_PlayCycles 26771 CALL PlaySquareWave Play a cycle using PlaySquareWave.
26774 DEC C Decrease the cycle counter by one.
26775 JR NZ,Handler_PlayCycles Loop back to Handler_PlayCycles until all of the cycles have been played.
26777 RET Return.
