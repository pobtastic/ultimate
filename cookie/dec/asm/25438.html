25438: Game Select Attribute Table
One attribute byte per menu line. The routines that flash the selected line set or clear FLASH in the byte for the line being updated. The first byte belongs to the title, so the flashing code starts at 25439.
GameSelection_Attributes 25438 DEFB 71
Byte(n) Menu Item
1 Game Selection
2 1 Player Game
3 2 Player Game
4 Keyboard
5 Kempston Joystick
6 Cursor Joystick
7 Start Game
