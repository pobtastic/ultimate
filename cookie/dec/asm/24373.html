24373: Charlie
The first of the ten actor slots (up to Message_Copyright), which is always Charlie. Every actor has the same eight byte format, and is processed once for each pass through the game loop.
Offset Contents
0 ID (sprite ID and handler, see ActorHandlers)
1 Horizontal co-ordinate
2 Vertical co-ordinate
3 Colour attribute
4-7 Used by the handler
ActorCharlie 24373 DEFB 0 ID.
ActorCharlie_X 24374 DEFB 0 Horizontal co-ordinate.
24375 DEFB 0 Vertical co-ordinate.
24376 DEFB 0 Colour attribute.
24377 DEFB 0,0,0,0 Used by the handler.
