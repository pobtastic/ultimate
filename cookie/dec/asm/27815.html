27815: Catch Nasty
Used by the routine at CatchActor.
Part of CatchActor, used when the actor which has fallen into the mixing bowl is one of the nasties. The falling notes are started and five more ingredients are needed, up to a maximum of 153.
CatchNasty 27815 CALL StartFallingNotes Start the falling notes using StartFallingNotes.
27818 LD B,5 Set the penalty to 5 ingredients.
27820 LD A,(24367) Fetch the number of ingredients which the active player needs.
27823 ADD A,B Add the penalty to the number of ingredients needed.
27824 DAA Adjust A to BCD.
27825 JR NC,TakeIngredients_Store Jump to TakeIngredients_Store if the number has not gone above 153.
27827 LD A,153 Set the number of ingredients needed to the maximum, 153.
27829 JR TakeIngredients_Store Jump to TakeIngredients_Store.
