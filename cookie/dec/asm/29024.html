29024: Frame Update
Used by the routine at MainLoop_NewPass.
Called by MainLoop when the frame counter has changed since the last frame update. Runs an extra pass over only the first four actor slots, which include Charlie and the sound effect actor, before carrying on with the pass which was in progress.
