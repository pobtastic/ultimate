25687: Run Main Loop
Used by the routine at CreateActor.
The main loop of the game. Each pass through the loop runs the handler for one actor. The handler is chosen by the actor ID, using the table at ActorHandlers. The address of NextActor is put on the stack first, so that when the handler returns, the game moves on to the next actor.
A pass is started at MainLoop_NewPass with the first of the six actors which start at ActorSpawnSlots. Whenever the frame counter has changed, FrameUpdate runs an extra pass over the first four actors (which are Charlie and the sound effect actor).
