26217: Handle Monster Falling
State 2 of the monster; it moves down four pixels at a time until it is back inside the dustbin. A random delay (1 to 15 frames) is then set, and the monster moves on to the next state.
Input
IX Actor
HandleMonster_Falling 26217 LD A,(IX+2) Fetch the vertical co-ordinate.
26220 ADD A,4 Lower the monster by 4 pixels.
26222 CP 184 Jump to HandleMonster_StartDelay if the monster is back inside the dustbin.
26224 JR NC,HandleMonster_StartDelay
26226 JR HandleMonster_Move Jump to HandleMonster_Move to move the monster.
HandleMonster_StartDelay 26228 LD A,R Fetch a random number.
26230 AND %00001111 Keep only bits 0-3.
26232 OR %00000001 Set bit 0, so that the timer is never zero.
26234 LD (IX+7),A Write the random number to the timer (byte 7 of the actor).
26237 INC (IX+6) Increase the actor state by one.
26240 RET Return.
