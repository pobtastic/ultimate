26421: Find Wander Speeds
Used by the routine at HandlePeel.
Finds the pair of speeds in the table at WanderSpeeds which are used for the current value of the counter in byte 7 of the actor.
Input
IX Actor
Output
HL Address of the pair of speeds
F The Z flag is set when bit 2 of the actor state is not set
FindWanderSpeeds 26421 LD C,(IX+7) Fetch the counter (byte 7 of the actor).
26424 SLA C Multiply by 2 as there are two bytes for each speed.
26426 LD B,0 Set the high byte of the offset to 0.
26428 LD HL,26437 Point HL at WanderSpeeds.
26431 ADD HL,BC Find the pair of speeds for the counter.
26432 BIT 2,(IX+6) Test bit 2 of the actor state.
26436 RET Return.
