29922: Reset Attribute Buffer
Used by the routines at CreateWindow, StartGame and CreateIntroductionIngredient.
Sets the border to black, and clears the attribute buffer by filling it with zero (black ink on a black paper).
ResetAttributes 29922 XOR A Set the border to BLACK.
29923 OUT (254),A
29925 LD HL,22528 Point HL at the start of the attribute buffer.
29928 LD B,91 Set the end of the attribute buffer (91).
29930 LD C,0 Set the byte to write to 0 (black).
29932 JR ResetCopier Jump to ResetCopier.
