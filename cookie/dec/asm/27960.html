27960: Start Level Introduction
Used by the routine at HandleLevelTimer.
Starts the introduction to a level, which is when the level timer has run out (see HandleLevelTimer). The screen is cleared, and then the ingredient which is needed for the level runs across the screen from right to left, followed by Charlie. When Charlie has left the screen the level is started (see StartLevel). The actors for the ingredient and for Charlie are handled by HandleLevelIntroduction.
StartLevelIntroduction 27960 CALL CreateIntroductionIngredient Clear the screen and create the actor for the ingredient using CreateIntroductionIngredient.
27963 LD HL,24373 Point HL at ActorCharlie.
27966 LD DE,28039 Point DE at IntroductionCharlie.
27969 LD C,7 C=7 (the ID for Charlie).
27971 JR CreateIntroductionActor Jump to CreateIntroductionActor to create the actor for Charlie.
