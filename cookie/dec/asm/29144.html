29144: Create Actor
Used by the routine at NextActor.
Creates a new actor from the pantry, if the conditions are right. It is not done if six or more actors are in play, if the delay at the start of a life is running, if no more ingredients are needed, or if Charlie is not in his normal form (ID 1 or 2). It is also done on average only one pass in every 32 which is decided with the frame counter and a random number. The new actor is made from the template at Template_NewActor, in the first of the six slots from ActorSpawnSlots which is empty. It starts at the right, at the height of the shelf in the pantry for the level (47 71 95 119 or 143).
Usually it is the ingredient for the level (see IntroductionIngredients), but it is one of the nasties (the tack, the washer or the bolt) if the number of slots which are left (including this one) is not more than the set the level is in (up to a maximum of 4) plus one. So there are more nasties in the later sets of levels. The monster is also created by CreateMonster, if it is not already.

29182 DEC A Is Charlie's ID 2?

29190 LD DE,8 Set the size of an actor to 8.
CreateActor_FindSlotLoop 29193 LD A,(HL) Fetch the actor ID.

29217 LD A,8 A=8.
