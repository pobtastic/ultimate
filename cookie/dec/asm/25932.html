25932: Handle Batter
The handler for the first three frames of the batter (IDs 40 to 42). Each time it is called, the actor moves on to the next frame.
Input
IX Actor
HandleBatter 25932 CALL StoreEntity Record the position of the sprite using StoreEntity.
25935 LD HL,24347 Increase the number of actors in play (ActorsInPlay) by one.
25938 INC (HL)
25939 INC (IX+0) Increase the actor ID by one, which chooses the next frame.
25942 CALL DisplayEntity Erase the sprite and draw the next frame using DisplayEntity.
25945 JP ColourSprite Jump to ColourSprite to colour the sprite.
