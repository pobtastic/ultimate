27030: Handle Tack, Washer And Bolt
The handler for the tack, the washer and the bolt (IDs 30 to 35), which chase Charlie. Every 16 frames the actor works out which way Charlie is from it, and stores this in byte 6 of the actor (bit 0 is set when Charlie is below the actor, bit 1 is set when Charlie is to the right). The horizontal and vertical speeds are then changed by one every other frame towards that direction, up to a maximum speed of 2 in either direction.

Work out which direction Charlie is in.
27065 LD C,0 Set the direction to 0 (left and up).
27067 LD HL,24374 Point HL at ActorCharlie_X.
27070 LD A,(IX+1) Fetch the horizontal co-ordinate.

27076 LD C,2 The actor is left of Charlie, so set the direction to 2 (right).
HandleTackWasherBolt_Vertical 27078 INC HL Move on to Charlie's vertical co-ordinate.
27079 LD A,(IX+2) Fetch the vertical co-ordinate.
27082 SUB (HL) Subtract Charlie's vertical co-ordinate.
27083 JR NC,HandleTackWasherBolt_SetDirection Jump to HandleTackWasherBolt_SetDirection if the actor is below Charlie.
27085 SET 0,C The actor is above Charlie, so set bit 0 of the direction (down).
HandleTackWasherBolt_SetDirection 27087 LD (IX+6),C Set the direction of the actor (byte 6 of the actor).
