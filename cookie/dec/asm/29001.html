29001: Remove Actors
Used by the routine at RemoveAllActors.
Removes a number of actors, by writing zero to each of the IDs.
Input
B Number of actors
HL Address of the first actor
RemoveActors 29001 LD DE,8 Set the size of an actor to 8.
RemoveActors_Loop 29004 LD (HL),0 Write 0 to the actor ID.
29006 ADD HL,DE Move on to the next actor.
29007 DJNZ RemoveActors_Loop Decrease the actor counter by one and loop back to RemoveActors_Loop until all of the actors have been done.
29009 RET Return.
