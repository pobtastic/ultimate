25240: Game Initialisation
Used by the routine at SecurityCheck.
Blanks the high score and the scores for both players, and works out whether the sound should be muted. It then runs the game selection menu, which is shown until "0" is pressed to start the game.
The game comes back to Game_Restart to show the menu again when a game is over.
Blank the high score, the 1UP score and the 2UP score.
GameInitialisation 25240 LD HL,24329 Point HL at the high score.
25243 LD BC,2816 Set the counter to 11 (the high score, the game options, the sound flag and both scores) and the byte to write to 0.
GameInitialisation_Loop 25246 LD (HL),C Blank a byte.
25247 INC HL Move onto the next byte.
25248 DJNZ GameInitialisation_Loop Decrease the byte counter by one and loop back to GameInitialisation_Loop until everything has been blanked.
This calculates a "checksum" of the BEEPER routine. The expected value at the end is 0 and if Sound_Enable does not contain 0 then the game is muted.
25250 LD HL,949 Point HL at the start of the BEEPER routine.
25253 LD B,67 Set the counter to 67 (the number of bytes to add).
25255 XOR A Clear the checksum.
Mute_Loop 25256 ADD A,(HL) Add a byte of the routine to the checksum.
25257 INC HL Move onto the next byte.
25258 DJNZ Mute_Loop Decrease the byte counter by one and loop back to Mute_Loop until the whole routine has been added.
25260 ADD A,104 Add 104 which makes the checksum zero in the original ROM.
25262 LD (24333),A Store the result as the sound mute flag at Sound_Enable.
