30317: Draw Old Sprite Row
Draws one row of the sprite prepared by PrepareOldSprite by exclusive ORing it onto the screen, then moves on to the row above.
Input
DE Address of the sprite data
HL Screen address
Output
DE Address of the next row of sprite data
HL Screen address of the row above
The entry point for a sprite which is aligned to a character cell.
DrawOldSpriteRow_Aligned 30317 EX DE,HL DE=the row of sprite data, and HL=the address of the next row.
30318 EX (SP),HL HL=the screen address, and the address of the next row of sprite data is stored on the stack.
30319 JR DrawSpriteRow_Write Jump to DrawSpriteRow_Write.
This entry point is used by the routine at XORSpriteLoop.
The entry point for a sprite which is not aligned to a character cell.
DrawOldSpriteRow 30321 PUSH HL Stash the screen address on the stack.

30323 PUSH DE Stash the screen address on the stack again.
