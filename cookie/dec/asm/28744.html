28744: Game Play Entry
The handler for Charlie (IDs 1 and 2). At the start of each life there is a delay (GameDelayTimer) before Charlie appears, and while it runs the score label of the active player flashes (see ScoreLabelFlash). When it has run out the label stops flashing, Charlie is drawn and a tone is played (see GameStartJingle). After that Charlie is moved by GamePlay_Start.
GamePlayEntry 28744 LD HL,24357 If GameDelayTimer is zero, jump to GamePlay_Start.
28747 LD A,(HL)
28748 AND A
28749 JR Z,GamePlay_Start
28751 DEC (HL) Decrease the game delay timer by one.
28752 JR NZ,ScoreLabelFlash Jump to ScoreLabelFlash if the delay timer is still active.
28754 LD A,(24353) If Flag_ActivePlayer says this is a 2UP game, jump to Game2UP_UnsetFlash.
28757 AND A
28758 JR NZ,Game2UP_UnsetFlash

28772 JR GamePlay_Start Jump to GamePlay_Start.
Handle turning off flash for 2UP score label.
