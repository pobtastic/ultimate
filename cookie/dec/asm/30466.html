30466: Sprite Table
Maps each sprite ID to the address of its graphic. The table starts at ID 1 (there is no ID 0), so the lookup in GetSprite subtracts one before indexing the table. The same ID is also used as the index into the actor handler table at ActorHandlers, so an actor's ID selects both what is drawn and the code that moves it.
Several IDs point at the same graphic. Where they do, the extra IDs are not extra frames.
